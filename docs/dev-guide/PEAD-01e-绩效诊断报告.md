# PEAD 01e 绩效诊断报告：8.09% 为什么远低于原文 19.29%

> **日期**：2026-07-08 ~ 09
> **背景**：PEAD 01e QMT 回测完整跑通，年化 **8.09%**，只有原文小盘多头 19.29% 的 **4.2 折**，低于预期的 8-9 折（12-17%）。本文记录完整的根因调查过程与结论。

### 1.1 现象

| 指标 | 原文（招商 2021） | 我们的实测 | 折扣 |
|---|---|---|---|
| 小盘多头年化 | 19.29% | 8.09% | 4.2 折 |

### 1.2 原文档列出的怀疑方向

## 二、调查方法：独立复算"理想撮合"

### 2.1 关键思路

QMT 实测的 8.09% 是一个"黑盒"数字——它经过了 QMT 的下单引擎（撮合价、手续费、买不进、持仓不完整）。如果只看这个数字，无法区分是**选股不行**还是**撮合吃掉**。

解法：**绕过 QMT 引擎，用前复权收盘价独立复算"理想撮合"组合收益**——同样的选股清单（QMT 回测那 20 个调仓日 × 60 只票），但换一种"结账方式"：

- 不经过 QMT 下单引擎
- 直接查每只票"调仓日收盘价买入 → 下个调仓日收盘价卖出"的涨跌幅
- 60 只等权求平均，扣双边 0.6% 费用，累乘出净值

得到理想年化 X% 后：
- **X ≈ 8%** → 是 A 或 C（选股本身就不行 / 熊市）
- **X 远大于 8%** → 是 B（QMT 撮合吃掉了收益）

### 2.2 数据从哪来：MySQL 没有 A 股日线

服务器 `quant_voyager` 库**没有 A 股历史日线**（`sec_daily_kline` 表只有可转债 2026-05 的 659 只）。行情在 QMT 的 `C:\qmt\datadir` 下，是 QMT 私有二进制格式（`SH\86400\*.DAT`），mootdx 的 `reader.daily()` 读不了（它读通达信 `.day` 格式）。

最终方案：**用 mootdx 网络接口拉历史日线**。服务器 py310 原本没装，本次新装 `mootdx 0.11.7`。

### 2.3 mootdx 拉前复权日线的正确姿势（踩坑记录）

⚠️ **三个坑，这里一次性讲清，避免下次重踩**：

**坑 1：`bars()` 的 offset 上限硬卡 800**

```python
# mootdx/quotes.py 第 201 行写死：
offset = (offset, 800)[offset > 800]
```

5 年日线约 1200 根，单次拉不全。**必须用 `start` 参数分页**（`start` 是从最新的偏移量）：

```python
def fetch_full(symbol):
    frames, start = [], 0
    while True:
        df = client.bars(symbol=symbol, frequency=9, start=start, offset=800)
        if df is None or df.empty:
            break
        frames.append(df)
        n = len(df)
        start += n
        if n < 800:  # 拉完了
            break
    return pd.concat(frames)
```

**坑 2：`bars()` 默认返回不复权数据**

很多人以为 mootdx 只能拿不复权。其实 `bars()` 接受 `adjust` 参数，通过 `**kwargs` 传给 `to_data()`，内部自动调 `to_adjust`（走新浪 qfq 因子）：

```python
# 直接这样就拿前复权
df = client.bars(symbol='600519', frequency=9, adjust='qfq')
```

**坑 3：分页拼接后再复权，不能每页单独复权**

`adjust='qfq'` 是对**单次 bars() 的 800 根**做复权（用新浪因子只取该区间）。如果分页拉 1600 根，每页单独复权再拼接，因子基准不一致会错。

**正确做法**：不复权分页拉全历史 → 拼接 → 一次性 `to_adjust`：

```python
from mootdx.utils.adjust import to_adjust
bfq = fetch_full('600519')              # 不复权全历史
qfq = to_adjust(bfq.copy(), symbol='600519', adjust='qfq')
```

**验证**：茅台 2022-06-30 除权日（10 派 216.75 元），不复权无跳变（2036→2045→2029），前复权平滑过渡（2330→2323→2311→2293）。2020-01-02 茅台前复权 1319.68，与东财 qfq（约 1320）一致。✅

### 2.4 验证脚本可复用

本次调查的所有诊断脚本留在服务器 `C:\workspace\diag_*.py`，核心复算模板：

```python
# 理想撮合模板（前复权收盘价 + 等权 + 扣双边0.6%）
nav = 1.0
for i in range(len(rebalance_dates) - 1):
    d0, d1 = rebalance_dates[i], rebalance_dates[i+1]
    rets = []
    for sym in held_symbols[d0]:
        p0 = get_close(sym, d0)  # <=d0 的最后收盘价
        p1 = get_close(sym, d1)
        if p0 and p1 and p0 > 0:
            rets.append(p1/p0 - 1)
    nav *= (1 + np.mean(rets) - 0.006)  # 扣双边0.6%
```

## 三、调查结果：三组对照

同样在前复权收盘价、等权、扣双边 0.6% 费用、2020-01-08 ~ 2024-10-14（4.77 年）条件下跑：

| 组合 | 选股逻辑 | 年化 | 终值 | 含义 |
|---|---|---|---|---|
| **A** | 全A dReport **最小** top60（我们的实现） | **-2.55%** | 0.884 | 提前披露的票 |
| **B** | 小盘池 dReport **最小** top60（原文口径） | **-5.60%** | 0.760 | 原文小盘股定义 |
| **C** | 全A dReport **最大** top60（反向对照） | **-4.14%** | 0.818 | 延迟披露的烂股 |

> 小盘池定义（原文 §四.2）：全A 按流通市值三等分，取最小 1/3（市值 < 1.75 亿），再在其中按 dReport 选 top60。

### 3.1 这三组能下什么结论

**结论 1：撮合不是主因（推翻假设 B）**

理想撮合 A 组 = -2.55%，**比 QMT 实测 8.09% 还低 10.64 个百分点**。撮合没有"吃掉"收益——相反，QMT 实测反而虚高（见 §四）。

**结论 2：因子方向仍有效，但超额很弱（部分确认假设 A）**

A 组（-2.55%）**好于** C 组（-4.14%），差 **+1.59pp/年**。说明 dReport 因子方向是对的（提前披露确实优于延迟披露），**因子没失效**。

但超额只有 1.59pp/年，远不够把负的 beta 拉正。原文声称的超额 +12.26%（小盘）/ +8.48%（全A），在 2020-2024 **完全没复现**。

**结论 3：选股域不是主因（推翻"该用原文小盘池"的猜测）**

B 组（原文小盘池）= -5.60%，**比我们的全A选股更差**。原文的"小盘股池"（市值<1.75亿）在 2020-2024 跌得更狠——微盘股 2022-2024 大幅杀估值。**改用原文小盘池不会改善，只会更糟。**

## 四、意外发现：QMT 实测 8.09% 高于理想撮合 -2.55%（虚高约 10pp）

> ⚠️ **本节经二次调查后大幅修正**。初版（2026-07-08）把虚高归因于"重复触发污染净值"和"建仓买不满 60 只"，两个结论**都在 2026-07-09 的复测中被推翻**。下面是修正后的如实记录。

### 4.1 反常现象

QMT 实测 8.09% **高于**理想撮合 -2.55%（前复权）/ 0.89%（不复权），这违反直觉——理想撮合（无滑点）应该 ≥ 实测才对。虚高约 10pp，需查清来源。

### 4.2 已排除的两个假设（初版错误结论）

**假设一：重复触发污染净值** ❌ 推翻

QMT 日志显示 2020-01-08 首根 bar 触发了两次调仓（卖0买56 + 卖1买2）。初版据此推断"第二次触发的垃圾交易污染净值"。为此加了 `RebalanceGuard` 幂等保护（commit `f6a406f`）并重跑——**净值一模一样没变**（final_nav 仍 1.6559）。说明重复那点交易量（卖1买2）对总资产影响可忽略，这个假设是错的。

> 注：幂等保护本身仍有价值（防御性编程，避免极端情况），已保留在代码里。但它不是净值虚高的原因。

**假设二：建仓买不满 60 只** ❌ 推翻

初版看到净值表 `holding_count=3`，推断"只建仓了 3 只"。但日志铁证显示首根 bar **实际买了 56 只**（接近 60）。`holding_count=3` 的真实含义是**交易笔数（sold+bought=1+2）**，不是持仓数。

顺手把这个字段语义修正了（commit `f6a406f`，改记真实持仓数）。重跑后 `holding_count` 显示 **55-60**，证明**建仓基本满仓**，不是"买不满"。

### 4.3 虚高 10pp 的分解（部分查清）

用三种撮合方式跑同一份选股清单，逐段对比：

| 撮合方式 | 年化 | 终值 |
|---|---|---|
| 前复权收盘价（理想） | -2.55% | 0.884 |
| 不复权收盘价 | 0.89% | 1.043 |
| QMT 实测 | 8.09% | 1.449 |

- **3.4pp 来自复权**：不复权（0.89%）比前复权（-2.55%）高 3.44pp。QMT 回测**不做前复权**，分红/送股的收益被虚增。这部分查清了。
- **剩 ~7pp 根因未定**：QMT（8.09%）仍比不复权（0.89%）高 7.2pp。

### 4.4 未查清的 7pp：集中在二季度换手段

逐段对比（不复权 vs QMT），差异分布很不均匀：

| 段（4月→7月） | 不复权 | QMT | 差 |
|---|---|---|---|
| 2022-04 → 07 | +8.26% | **+14.58%** | -6.3pp |
| 2023-04 → 07 | -2.63% | **+6.04%** | -8.7pp |
| 2024-04 → 07 | -15.36% | -12.10% | -3.3pp |

这三个段全是**二季度（4→7月）**，且都是**换手最彻底的时段**（7 月调仓与 4 月只有 3-6/60 重叠，换手 54-57 只）。其余 16 段差异都在 ±1pp 内（正常撮合波动）。

已排除的子假设：
- ❌ 次日开盘价撮合（实测反而更低，方向相反）
- ❌ 选股不同（日志 vs 复算 CSV，目标持仓前 5 完全一致）

剩余可能性（需改代码打印 QMT 实际成交价才能定论，暂未做）：
- QMT 对"大量换手"的撮合有特殊处理（卖出价/买入价不对称）
- QMT 净值含分红再投资（除息日现金分红计入 total_asset）
- `_is_tradable` 过滤剔除的票在 60 只尾部有差异（前 5 一致不代表全部一致）

### 4.5 教训

1. **`holding_count` 已修正**为记真实持仓数（commit `f6a406f`）。这是实打实的改进，以后净值表能正确反映仓位。
2. **净值虚高的精确定位未完成**，但不影响本报告核心结论（§五）——8.09% 偏低的主因是时间段+因子衰减，不是净值精度。虚高的 10pp 让"偏低"看起来没那么严重，真实情况比 8.09% 还差（接近 -2.55%）。
3. **下次用 QMT 回测净值对标，要警惕不复权虚增 + 撮合机制黑盒**。理想撮合复算（§二）是更可信的基准。

## 五、最终结论：三个原因的权重

### 5.1 🔴 主因：对标基准不现实（时间段差异，决定性）

| | 原文 | 我们 |
|---|---|---|
| 样本期 | **2009.4 ~ 2020.10**（11.5 年，含 2014-2015 中小盘大牛市） | **2020.1 ~ 2024.10**（4.77 年） |

三组对照全是负的（-2.55% / -5.60% / -4.14%）——连"反向选最烂的票"也就 -4%。这说明 **2020-2024 这批小盘股本身就在跌**，不是因子选错。

原文 19.29% 里有很大一部分是 **2009-2020 小盘股整体 beta**（尤其 2014-2015 中小盘暴涨）。换到 2020-2024，这个 beta 消失甚至转负。

**拿原文 19.29%（或 8-9 折的 12-17%）作为预期，本身就不现实——那是另一个时代的数字。**

### 5.2 🟡 次因：因子超额在当前样本期大幅衰减

dReport 因子方向仍有效（A > C），但超额只有 **+1.59pp/年**，原文声称的 +8-12pp 超额完全没复现。可能原因：
- IC 衰减快（原文自己说滞后 1 期 IC 已降到 0.027）
- 小盘股流动性枯竭，披露时点信号被淹没
- 2020 年新冠特殊（原文 §七 失效红线也提过）

### 5.3 🟡 QMT 实测净值虚高约 10pp

8.09% 高于理想撮合 -2.55% 约 10pp。其中 3.4pp 来自不复权虚增（查清），剩 ~7pp 集中在二季度换手段、根因未定（详见 §四）。**这个数字偏高，真实情况接近 -2.55%，比 8.09% 还差。**`holding_count` 字段语义已修正（commit `f6a406f`）。

### 5.4 ⚪ 非主因（已排除）

| 原怀疑 | 结论 |
|---|---|
| 一字板过滤简化 | ❌ 不是主因（理想撮合也未过滤一字板，仍 -2.55%） |
| ST 近似 | ❌ 不是主因（影响极小） |
| 等权 vs 加权 | ❌ 不是主因（原文也是等权） |
| 选股域差异（该用小盘三等分） | ❌ 反而更差（B 组 -5.60% < A 组 -2.55%） |
| 撮合/费用吃掉收益 | ❌ 完全反了（理想撮合比实测还低） |
| 复权处理 | 🟡 部分原因（全 5 年累积虚增 3.44pp，非 0.05pp/季——初版只测了第一段低估了） |

## 六、方法论沉淀：如何诊断"回测偏低"

下次遇到"实测远低于预期"，按这个顺序排查，避免一上来就怀疑撮合/实现：

```
第1步：算对了吗？
  └─ 复核净值终值、年化公式、区间天数 → 排除计算错误

第2步：数据对吗？
  └─ 每个调仓日候选数、因子方向、前视偏差 → 排除数据/因子bug

第3步：理想撮合复算（最关键）
  └─ 前复权收盘价 + 等权 + 扣费，绕过引擎
  └─ 若理想 ≈ 实测 → 选股/时间段问题（往A/C查）
  └─ 若理想 >> 实测 → 撮合/实现问题（往B查）

第4步：三组对照定位
  └─ 正向选股 vs 反向选股 → 因子有没有超额
  └─ 不同选股域 → 选股域影响
  └─ 全A/指数基准 → 时间段 beta

第5步：查时间段
  └─ 原文样本期 vs 自己的 → beta 是否消失/转负
  └─ 同期指数收益 → 是不是纯熊市
```

⚠️ **最大教训：不要拿另一个时代、另一个样本期的原文绩效，作为当前实现的对标基准。** 尤其是因子类策略，beta 占比可能远超 alpha。
