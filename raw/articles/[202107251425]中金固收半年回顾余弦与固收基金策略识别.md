**策略观点**

  

**截止周四收盘，转债指数的年内回报来到12.8%、转债基金和二级债基也分别来到7.7%和3.9%的水平**
——转债、“固收+”市场连续第三年，给了投资者正面的回馈，显然这比年初市场普遍预期中的情况略好。当然，投资者的预期并非完全低估了市场给出回报的能力，事实是：1、市场有着比往年更高的波动，普遍来看收益回撤比，今年并没有比2020年更好——2020年的市场，有两次少见的冲击，分别发生在春节后首日以及3月初海外市场的强烈调整后；2、相比往年而言，今年更加考验投资者本身的技术水平，一个事实是：截至目前，转债基金平均而言依然跑输给了转债指数。
而下图更加清晰地显示着，以转债基金来看，今年与去年更加不同的是，用高的回撤风险，未能能换回高的回报。

**于是，在今年拿回更好的回报风险比，显得比此前更加难能可贵。**
显然，哪些产品做得更好，用简单的回报、回报风险比就可以大致地得到结论，但我们也希望在这种环境下，看到更多内容：比如，
这些产品都是通过怎样的策略，得到更好的效果。  我们此前曾经介绍过如何给包括转债基金在内的固收+产品核算风格与暴露（请见《 [
“固收+”们也换风格了吗？——兼论固收+基金风格的分步过滤测算及Python实现
](http://mp.weixin.qq.com/s?__biz=MzAwNzMzODYyNg==&mid=2650416842&idx=1&sn=b73453df3964489871e609756b113b41&chksm=83712927b406a0311a35a07a1f34f75ccc99d306f20f8e2e685831228eee757059dd6c1179d7&scene=21#wechat_redirect)
》），但当下的情况，我们可能需要看到更加细致的层面。我们通过此前设计的策略测试框架，可以得到更多 ** 细分策略  **
的回报，我们也就有可能找到，和那些脱颖而出的产品，最为接近的策略——直接复制基金有难度，但我们至少可以通过这些测算来知道，这些产品走的是怎样的路径。

  

**为了抵消仓位带来的影响，并兼顾计算效率，我们这里要用到“夹角余弦”的算法。**
假设我们有n个策略的净值曲线，与基金表现的净值曲线，我们可以先计算其每周的涨跌幅，分别设为x1~xn以及y。将这些x与y看做在多维空间上的向量，则夹角余弦为
x * y / sqrt(|x| *
|y|)，该值在[-1,1]分布，当x与y越接近同向时，其越接近1，反之则越接近-1。因此，我们可以借助夹角余弦，来找到我们广谱的策略族中，哪些或者哪个与绩优基金“最像”。程序逻辑十分简单，可表示如下：

  

**图表2：转债基金策略识别程序**

  

    
    
    def cosAB(srsA, srsB):  
        # 基础算法，A与B向量的夹角余弦  
        return (srsA.fillna(0) * srsB.fillna(0)).sum() / \  
        pd.np.sqrt(srsA.apply(lambda x: x**2).sum() * srsB.apply(lambda x: x**2).sum())  
      
    def cosFundVsStrategy(dfNav, dfRet, names=None):  
        # dfNav为基金净值，dfRet为策略净值组，批量处理得到cos矩阵  
      
              
        names = dfRet.columns if names is None else names  
        dfCos = pd.DataFrame(index=dfNav.columns, columns=dfRet.columns)  
        for fund in dfNav.columns:  
            for stg in dfRet.columns:  
                dfCos.loc[fund, stg] = cosAB(dfRet[stg].pct_change(), dfNav[fund].pct_change())  
        return dfCos

**1、把握趋势、压低溢价，是相对容易实现高额回报的路径。**
“趋势优先”组的平均回报达11%，是最接近“能跟上指数”的组别。因为趋势和估值，本身就是转债世界的两个核心矛盾。对该策略我们曾在转债的周报中进行过简单介绍，即在低溢价率的基础上，剔除正股存在缺陷的品种，再优先选择趋势良好的。年初至今回报突出的产品也多出自本组，10%以上回报的包括：例如易方达鑫转增利及安盈（分列万得偏债混基的第1、4位）、广发可转债、鹏华转债、南方希元、华宝转债、申万菱信转债、博时可转债增强以及多数时间定位为二级债基嘉实稳宏。其中如易方达的两个产品、南方希元及鹏华多数时间都稳定地在“趋势优先”组中，本次结果并不意外。而嘉实稳宏，则将最大回撤压到了仅仅4.5%的水平，按季报披露的情况看，与其主动调整仓位有关。
此外，这类的策略的容量并不太低，例如鹏华、南方希元、易方达安盈、中欧等规模都在20亿元以上。

**2、但上述策略不是唯一选择，低价类策略的平均回报也高于市场，且从基金营销角度而言，更容易被客户所接受。**
最为典型的是天弘添利，年初至今接近14%的回报，最大回撤也压在8.5%以内。我们广谱策略中与其最为接近的为110元以内买入、130元以上卖出策略，但也容易看到其在排序版EasyBall以及低估值股票上同样有暴露。不过样本内属于这一风格的仅2支，另一支为易方达双债。

**3、大盘仍然是最为密集的风格取向，自然一部分是源自流动性的妥协。**
我们前周周报中有提到，大盘策略在转债历史的多数阶段，都是比较拖累业绩的选择。而机构投资者持有这类品种，则多有保流动性以及在高效率策略无法顶满仓位的情况下，填补持仓所用。当然我们也看到了一些产品在规模不大的情况下，便选择了以此策略为主，实战角度讲没有必要，可能存在其他非市场角度的因素。

  

当然，该组中亦有业绩较为靠前、回撤控制也较强的——通常不是靠大盘转债本身，
而是在以大盘转债为基本盘的情况下，靠其他辅助策略拿到的高额回报（以及一些特殊情况，例如工银瑞信转债优选的东财转债就达到19%）。
当然辅助策略的选择比较多，巧合的是，该组中的前5名，除大盘外的第二近似策略各自不相同：

  

1）浙商丰利增强有向成长股的偏向；

  

2）华商可转债则是转债基金样本中，周期策略暴露值最大的一个；

  

3）富国可转债的第二策略是低溢价率——当然，这与趋势优先本身就较为接近；

  

4）汇添富可转债的第二大策略为“趋势优先”（实际上其在2年前，规模还相对不大时，多数时间以该策略为主要风格），以季报来看，这一策略的暴露可能来自其股票持仓；

  

5）东方红聚利则更为特别，虽然其测算的主要暴露在大盘转债上，第二大为低估值股，但其在标准EasyBall以及成长因子上的暴露也都不低——说明我们的测算模型可能不适用于该产品。结合其排在该组第五以及只有2.2%最大回撤的表现（所有样本中最低），我们考虑其可能在除了择券外，其采取了转债版的“杠铃型”策略，即大盘与低估值保底，高度分散化的小券负责填补进攻性，二者还一定程度上形成了对冲效果。此外，样本中少有的定开产品华商瑞鑫也有类似的数据特点。

**B、其他固收+型产品：**

在策略分布上有很多与转债基金类似的特点，包括：

  

1、选择大盘策略的产品最多，但对这些基金的帮助比较有限：这类产品的平均回报为3.1%，尚未达到二级债基的平均水平，且51个样本中只有8个回报超过5%。这些有较多超额回报的样本，也需要更多借助辅助策略来获得回报。例如华商稳定增利也与前述华商可转债一样，有较高的周期品种比重，易方达、东方红等旗下产品，也有与上文提到的同公司旗下产品类似的特征，在此不赘述；

  

2、趋势优先策略仍提供了更多超额回报，获得5%以上回报的固收+基金，有一半出自这一组。其中南方广利、圆信永丰强化收益的回报达8.36%、7.25%，规模已经很大的易方达安心回报、裕丰回报以及汇添富双利均在此组，且也都得到平均水平之上的回报。但以季报持仓来看，其中相当部分可能来自于股票持仓；

  

3、低价策略在固收+产品中也有较高的下限，但仓位不足的情况下，这类策略提供的帮助并不明显；

  

4、相比转债基金，其他固收+产品的分布更广，于是也有一些其他特点的产品出现，也获得了不错的效果，例如：

1）富国天利增长债券、富国稳健增强等均有股价低估值 + EasyBall特点；
