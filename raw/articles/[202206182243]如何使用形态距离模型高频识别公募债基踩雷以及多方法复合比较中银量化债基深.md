#  一、  筛选“疑似踩雷基金”——形状距离法

在前文中，我们介绍了如何运用“最大回撤”法和“异常值法”进行“疑似踩雷”基金的筛选。但最大回撤法的本质其实仅仅基于“回撤”这一单一维度，相较于整体思路上的“债券估值与基金净值之间的联动”存在着不小的差距，难免给人一种盲人摸象的感觉。因此我们希望找寻到更适合的方式来对“债券估值与基金净值之间的联动”进行量化描述。

##  2\.  欧氏距离无法有效捕捉“债券估值与基金净值之间的动态变化趋势”

经过分别测算验证，我们发现欧式距离、曼哈顿距离在筛选“疑似踩雷”债基表现并不显著。原因在于欧式距离存在以下缺陷：  1\.  不具有形态识别能力  2\.
无法有效体现动态变化趋势的相似性
![](https://mmbiz.qpic.cn/mmbiz_png/Q9WVC4Ebnpfl198cWVWbhYlibKiaOklnHvwxvUPVuokkMCCVw6iaH6Vj7XOibQNGwR46XgCQZ1uSE7hwAGl4VbNjNA/640?wx_fmt=png)
上图中A、B、C三条曲线中A与B曲线 的形态变化相反，与 C 的形态变化相同，但基于欧氏距离的计算，会认为 A与B 的相似性大于
A与C，从而形成误判。曼哈顿距离与欧式距离类似，只是对异常值更加敏感，依然存在上述问题。而在本报告中
，我们其实更加注重的是两条时间序列的动态变化趋势的相似性，即当债券估值出现大幅下降时，债基的净值也随之出现大幅下降。

##  3\.  皮尔逊相关系数（Pearson  Correlation）简介与缺陷

除各种距离外，皮尔孙相关系数（Pearson Correlation）也常被用于描述两条时间序列的相关性。  皮尔逊相关系数介于0到1之间：  a)
当相关系数为0时，X和Y两向量不线性相关  b)  当X的值增大（减小），Y值减小（增大），X和Y两向量负相关，相关系数在 -1 到 0 之间。  c)
当X的值增大（减小），Y值增大（减小），X和Y两向量正相关，相关系数在 0 到 1 之间。
![](https://mmbiz.qpic.cn/mmbiz_png/Q9WVC4Ebnpfl198cWVWbhYlibKiaOklnHvF9zlJgHrBfPzP0cz1ffVKjPzUhmd5Qs32vTBE1qawBmknITjKwKWew/640?wx_fmt=png)
皮尔逊相关系数是用于衡量线性相关关系的。因此在未确定线性关系前，直接比较皮尔逊相关系数不能说明任何问题，必须画出散点图进行比较。
上图中四组数据均的Pearson相关系数均为0  .816  ，但其所呈现出的关系各不相同，具体来看：  1)
左上图表示x1与y1呈线性关系，此时较高的pearson相关系数表示x1与y1线性相关性较强。  2)
右上图可以看出虽然pearson相关系数较高，但x2与y2并非线性关系，且y2不完全随x2增大而增大，因此在不能确定线性关系时，pearson相关系数高并不意味着两个序列之间存在相关性。
3)  左下图表示存在一个噪声点，如果没有噪声点的存在将是很完美的相性相关。  4)  右下图表示pearson相关系数易受极端值影响。
在筛选“踩雷基金”时，由于无法保证基金净值与债券估值一定存在线性关系，使用  Pearson  相关系数进行“踩雷债基”的筛选效果并不显著。

##  5\.  使用形状距离筛选“疑似踩雷基金”的具体方案

在使用形状距离法进行测算时，我们已经得到了使用“滚动5日最大回撤法”筛选出的“疑似违约”债券及其对应“违约信号”触发区间。每次触发“违约信号”对应的债券估值回撤区间为近5日。因此我们的形状距离法整体思路是通过计算每次“违约信号”对应的近5日债券回撤区间内债券估值与所有符合测算条件纯债基金净值的形状距离来对“疑似踩雷”基金进行筛选。形状距离越小，意味着两条序列的动态变化越趋于一致，则债券基金的踩雷风险越高。形状距离越大，意味着两条序列的动态变化区分度越大，债券基金的踩雷风险越低。如下图所示，通过分别计算基金1与基金2同“疑似违约”债券在回撤区间内的形状距离，可以对两只基金是否大概率持有“疑似违约”债券进行区分。

形状距离法主要通过计算“疑似违约债券”在估值显著下跌区间估值序列与其他债券基金的净值序列之间的距离，来推断债券基金持有该“疑似违约债券”的可能性。该方法相较于最大回撤法对两条序列的趋势变化捕捉能力更强，但会受到更多噪音的干扰。整体上对债基的信用风险管理能力区分度较强。

#  二、  三种方法的统一与合并

##  9\.  打分相关性测算

在将三种方法合并之前，我们需要对其的相关性进行检测。在进行相关性检测前，需要注意三种方法对于基金数据量的要求不同，例如最大回撤法需要基金在“违约信号”发出后存在最近5日的日度净值数据；形状距离法要求存在最近7日的日度净值数据；异常值法要求存在
63  个负收益的交易日。因此，可能出现部分基金在部分“疑似违约债券”发出“违约信号”时，仅有  1-2  种方法可以测算分数的情况。
因此在测算相关性时，仅针对三种方法都能够进行打分测算的基金。
由于三种方法得到的分数之间不具有可比性，我们首先需要对三种方法的得分均进行归一化处理，使三种方法的打分均处于0  -1
之间，并且保证分数越靠近1表示踩雷的概率越高，分数越靠近0表示踩雷的风险越低。
我们截取每个交易日三种方法针对市场所有符合条件的纯债基金打分，测算了相关系数，如下图所示。
![](https://mmbiz.qpic.cn/mmbiz_png/Q9WVC4Ebnpfl198cWVWbhYlibKiaOklnHvz3Br5iaNcwPWWv74FiareX4zzy9r0qocaDXXHtH7DE3GSlqkAH1PCejA/640?wx_fmt=png)
由上图可以看出除了最大回撤法与形状距离法2  019  年前和2  020  年末期少数时间相关系数较高外，其它时间段的相关系数均低于0  .4  。
我们认为三种方法在进行筛选的时候分别有不同侧重：  1)  最大回撤法使用基金超额收益的最大回撤更侧重通过单只基金以市场为基准的收益情况进行筛选；  2)
异常值法使用基金绝对收益率与下限阈值的差值更侧重结合各基投资策略与持仓体现的历史波动情况对纯债基金的绝对收益情况进行筛选；  3)
形状距离法使用基金日度净值与债券估值的时序距离更侧重通过两者形态变化的相似度进行筛选。

##  10\.  基金分组的重复率测算

相较于三种方法得分的相关性，我们其实更关心三种方法对市场上所有符合测算条件的纯债基金的分组归类的一致程度。理论上来说，三种方法的打分相关性越低，对基金信用风险控制能力分组的重合度也会越低，在综合三种方法筛选结果后能更加保证筛选出的具有优秀风险控制能力的基金未来踩雷的概率越低。
我们最为关注的是三种方法针对踩雷风险最高（第2  0  组）的分类情况。因此我们以最大回撤法所筛选出的第2  0
组基金为基准，分别测算了形状距离法与异常值法筛选的第2  0  组基金与基准第2  0  组的重合度情况，即两者第2  0  组中基金的交集占基准（第2
0  组基金数量）的比例，测算结果如下。
![](https://mmbiz.qpic.cn/mmbiz_png/Q9WVC4Ebnpfl198cWVWbhYlibKiaOklnHvGG8H3yFJxIl8DmRgKydibPnibxg7ic3lMsNx0OaBrDlMCYEWVn630SVKQ/640?wx_fmt=png)
整体来说，三种方法对基金的分组重合度基本处于2  0%  以下，同时考虑到之前三种方法的分组净值表现区分度均较为显著且符合预期，
我们认为该三种方法均能有效对基金的信用风险管理能力进行筛选，但筛选的角度不同导致了筛选结果的不完全一致。
因此若能将三种方法有效结合起来，便可以形成一套更加全面有效的债基筛选体系。

##  11\.  三种方法合并

###  1\. 计算各方法下基金各交易日分数横向排名

虽然三种方法均可以对纯债基金的风险管理能力进行较为有效的筛选，但由于三者的方法不同，因此
各基金在三种方法下的得分无法进行直接地横向比较。因此，我们需要在各自方法下，对基金的得分按照交易日进行横向排名。
三种方法的分数大小可能代表不同的踩雷概率（如最大回撤法分数越高，代表越可能踩雷；形状距离法分数越低，代表越可能踩雷），为了避免混淆，
我们通过分数正序与逆序的调整，统一使得踩雷风险越低的基金，排名越靠前，踩雷风险越高的基金排名越靠后 。

###  2\. 选取三种方法中排名靠后的排名作为该基金的分数

通过上述排名，对于任意一个符合测算条件的纯债基金在每个交易日都会存在源于三种不同方法的排名。债基信用风险测算系统的目的是筛选出那些可能存在踩雷风险的基金，因此这里
我们采用相对保守的做法，将三种方法中给出的最低排名（最高踩雷概率）作为该基金的最终排名分数。

###  3\. 将基金的最终排名分数按照大小划分为2  0  组

在得到各基金在各交易日的最终得分后，我们进一步将最终得分按照从小到大平均分为2  0
组。第1组的分数最低（排名最靠前），代表从三种方法综合来看整体踩雷概率最低的基金；第2  0
组的分数最高（排名最靠后），代表从三种方法综合来看整体踩雷风险最高的基金。

#  三、  踩雷信号与分组稳健性测试

基于“T日打分分组，T  +1
日换仓”的日度预警系统可能出现打分分组变化频繁，信用预警效果不够稳健的风险。为进一步检验打分分组的稳健性，我们进行了如下“信号递延”稳健性测试：
对于t日某纯债基金，若近N个交易日出现过“第20组（最高踩雷风险）”标识信号，则在t日继续归类为高风险组。系统按日度计算“高风险组”基金回报率的中位数，以及较“纯债型基金指数（9
30609.SCI）”的累计超额收益，以评估预警信号对未来债基超额收益的前瞻性与延续性。在该“信号递延”模式下，出现过“第20组”信号的基金，预警信号至少会连续出现N天及以上。
![](https://mmbiz.qpic.cn/mmbiz_png/Q9WVC4Ebnpfl198cWVWbhYlibKiaOklnHvY0XGH1Cm0OTaAvbBWCdiaMHQHaFFHywMeBH45zlgcPF6B6t68w5TKBw/640?wx_fmt=png)
由上图可知，在信号在递延时相较于原先每日按照最新分数分组换仓第2  0  组负向超额出现了一定衰减，但整体递延短时间内衰减并不显著；信号递延1  20
个交易日（约半年）衰减较为显著但组合模拟净值依旧无法跑赢基准，
说明本系统的打分分组结果在未来一个月之内存在显著的风险预测能力，该预测能力在未来半年内虽然出现一定衰减，但仍有一定的风险规避效应。
