**定价机的自我进化：新一代定价学习模型**

  

**无法自我进化，是原模型的主要“痛点"。**
距离我们首次发布转债的自动化定价模型（《新券定位：方法、边际变化与Python实践》），已经过去了接近3年的时间。虽然在日常参考上，原模型尚且可用，但投资焦点乃至市场规则都已经发生变化，这也导致原模型的定价效率下降，有时运算效率也不够强——事实上，出现较大偏差的时候已经不少了。

当然，一个3年前的模型，主要问题并不难找，甚至不难解决。下图为原模型的简要流程，不难发现其构造十分简单，实际用程序几乎完全模拟研究员人工预估价位的过程：先找可比，再根据可比券的平价、溢价率水平预估新券的溢价率，最后完成定价。寻找可比券的方式简单易行，K近邻的搜寻结果很快——
** 但问题再也这里，K近邻是标准的无监督模型，这也意味着没有纠正机制来使其随着市场变化完成自我进化。  **

**我们将要介绍的新模型，在特征和算法上都进行了较大改进，以便使其自我适应市场的变化。**

  

**一、特征处理**

  

首先，在构造算法前，我们需要对个券之间可比的特征值进行提取与预处理。相较旧模型，我们在新模型中进一步囊括与转债自身关系度更大的“债券持有人比例”和“债项评级”，以及正股的“180日波动”、“量比”和“收益率峰值”等。这里需要提醒投资者，
由于我们实际囊括了较多特征(15个)，对于目前存量超400只的转债市场，频繁获取数据可能存在超限问题。
此外，诸如日期和评级，需要进行数值化处理，均为常规操作，见下方程序逻辑。

  

**图表3：数据预处理程序**

    
    
    def preprocess(codes, trade_dt):

**二、算法改进**

K近邻的优点是简单，缺点是难以监督、优化——比如，哪些特征是重要的、重要性是否在变化，不同的特征是否应该给与不同的权重。这里我们选择了一个同样简单，但便于接受参数并进行优化的模型：注意力模型。简单来看如下图，仍以存量券为参考样本，其在不同特征上均与目标券存在空间距离（以二级范数为常用度量）。但我们不将各维度的距离直接加总，而是再与一个等待训练的权重向量相乘，得到训练后的"加权距离"。
然后再让距离更近的存量券拥有更高的权重，更远的有更低的权重甚至为零，从而得到对新券的预估——因此，核心变化在于加入了一个权重向量。之所以称作“注意力”机制也是因为，这个待训练的向量，实际承担了类似人类调动注意力的神经的作用——在某个环境下，人们通常只对环境里的几件事物敏感而会忽略其他次要信息。

几个处理上的细节：

1、如果只用新券，我们无法对这个模型进行训练，但存量券当然也可以互为样本和目标进行学习。例如我们可以让每一只存量券轮流作为预测目标，其他券为样本。这样一来，我们每个交易日理论上都能获得接近400个样本——而由于我们只有一个特征向量需要训练，一般来说4~5个交易日的样本足以将注意力机制训练到位。

  

2、"双高"要不要纳入考虑呢？我们曾经希望纳入，但一旦这些券进入训练集，就会成为对训练较为重要的样本（因为其溢价率距离正常样本很远，甚至在另一量级）——使得对正常样本训练造成干扰。
因此我们决定直接剔除“双高”。  所幸，一般投资者也无法投资这类品种，转债交易新规也在本月实施，这种现象也将逐步消失。

3、最终使用的模型比意料中更加简单（基于Pytorch构造），实际只有一层结构。传播函数（forward）中的X为存量样本经过前述标准化后的特征，y为溢价率（实际我们使用的是溢价率距离百元溢价率曲线的直线距离，这里为简单可以暂时理解为溢价率），key为目标券的特征。

  

**图表8：新模型核心算法**

    
    
    class attentionWeight(nn.Module):  
          
        def __init__(self):  
            super(attentionWeight, self).__init__()  
            self.w = nn.Parameter(torch.ones(15).type(torch.float64), requires_grad=True)  
          
        def forward(self, X, key, y):  
            weight = nn.functional.softmax( - (torch.mm((X - key),  
                                                self.w.type(torch.float64).reshape(15,1)).reshape(-1)) ** 2 / 2)   
      
            return (y * weight).sum()

**最后，近期在转债领域，关于人工与模型的取舍问题时常被讨论。**
例如有的投资者会困惑甚至焦虑于“机器是否要替代研究员”，另一些投资者则否定计算机在投研中的价值。实际这里就是一个很好的说明：

  

1、在算力方面，计算机提供的便利显然有帮助。
显然，在每日数百个券的情况下，人们无法达到计算机的运算、训练速度。就算已经训练好参数的情况下，研究员手动计算估价仍需时间，而这一模型每计算一只转债的定价只需要6ms左右。

  

2、但训练本身要提取特征向量，随后的计算方式也需要设计。
理论上在数据无穷多、算力充沛的情况下，计算机确实可以完成这些工作——但事实并非如此，尤其越是深度的学习对数据消耗越大。选择好特征向量、设计好计算方式，能够让很多在现有数据、算力情况下无法实现的模型得以完成——这些都需要人的经验结合测算去探索。
