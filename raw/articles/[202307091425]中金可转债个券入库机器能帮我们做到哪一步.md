**中金研究**

个券入库报告常被认为是诸多工作中“附加值不高”的一项。原因包括当下选择很多，例如多数账户都在采取组合投资，分散度也越来越高，这是长期趋势。例如转债毕竟有期限，转债投资者可选择的投资时间、兑现时间都很有限，过于“深度”的内容对转债投资者参考价值有限。我们希望做到的无非是两个方面：1、尽可能将需要的信息讲清楚，至少结论清晰明确；2、降低成本，尽可能快速、自动化地完成这一工作。

  

在此，我们介绍一个自动化的框架，并展示我们推荐的做法，供投资者参考。显然，限于篇幅我们无法展示全部这些内容，包括一些辅助函数、细节上的文本化处理。在此我们也强调，虽然可以产生文本数据，我们并不直接以程序输出为结论，但至少能够起到快速整理并梳理数据的效果。

  

**首先，我们要明确在“入库”阶段，需要明确的信息有哪些。** 结合我们及买方的经验而言，主要包括以下几方面：

  

1\. 公司基本情况介绍，是哪种类型的企业，收入、利润来自哪些业务。

  

2\. 财务分析，这里又分两个层面，一是从股票（进攻）角度看，公司的成长、盈利能力如何，二是是否存在较大的风险。

  

3\.
股权信息分析，尤其是公司是否存在特殊的风险点，主要包括股票质押、近期大额的解禁。此外，正股弹性、机构关注度也是重要信息，尤其弹性对投资价值、盈亏比有着关键作用；

  

4\. 转债条款及定价分析，尤其是条款中是否存在不寻常的、需要注意的内容，以及按照市场条件，如何定价才是合理的范围。

  

**完成上述任务，需要多个模块。**
显然与其他的专题研究不同，这里涉及到一支个券的多个层面，需要涉及到的模块很多。为便于整理及后续开发，我们用一个class变量进行汇总，并将分支模块分别写进不同的py文件，以下是一个大体的结构。

    def 主营业务处理(SEGMENT_SALES):  
        pattern = r'(\w+):(\d+(\.\d+)?)%'  
        ret = ''  
        if ";" in SEGMENT_SALES:  
            lstSeg = SEGMENT_SALES.split(";")   
            for i, str2parse in enumerate(lstSeg):  
                try:  
                    res = re.match(pattern, str2parse)  
                    product, ratio = res.group(1), res.group(2)  
                    if i == 0 and len(lstSeg) == 1:  
                        ret += f'收入全部来自{product}。'  
                    elif i == 0:  
                        ret += f'{product}占比最高，达到{ratio}%。其余包括'  
                    elif float(ratio) >= 5:  
                        ret += f'{product}(占比{ratio}%)'  
                        if i != len(lstSeg) - 1:  
                            ret += '、'  
                    else:  
                        ret += '其余业务占比较低'  
                        break  
                except AttributeError:  
                    continue                                           
            return ret  
        else:  
            return SEGMENT_SALES

    def 盈利性语句(stkCode, year):  
        sql = f'''select a.report_period rpt, a.s_fa_roa ROA, a.S_FA_GROSSPROFITMARGIN GROSSMARGIN  
        from Winddf.AShareFinancialIndicator a  
        where a.s_info_windcode = '{stkCode}' and  
        a.report_period >= '{year - 2}1231' and  
        a.report_period <= '{year}1231' and  
        a.report_period like '%1231'   
        order by a.report_period  
        '''  
        con = login()  
        dfEaring = pd.read_sql(sql, con)  
        con.close()  
        avgROA, ROA = dfEaring["ROA"].mean(), dfEaring["ROA"].iloc[-1]  
        stdMargin = dfEaring["GROSSMARGIN"].std()  
        ret = (f'公司盈利性{盈利性定级(avgROA, ROA)}。过去3年平均ROA在{avgROA:.1f}%，{year}年为{ROA:.1f}%。'  
               f'毛利率{毛利率稳定性(stdMargin)}，过去3年平均毛利率在{dfEaring["GROSSMARGIN"].mean():.1f}%，{year}年为{dfEaring["GROSSMARGIN"].iloc[-1]:.1f}%')  
      
        return dfEaring, ret

**转债条款及定价**

  

其中转债条款已经比较成熟，此处更多是格式化处理，在此不详细展开。而定价方面，由于投资者们目前仍主要采取相对定价法，我们也不引用理论定价模型，而是采用《定价机的自我进化：新一代定价学习模型》中的注意力模型
——
这个模型采用注意力机制来分配权重，给予参考价值更大的其他券更高的权重，通过学习溢价率进行定价。此外，根据这一模型的误差范围，实际价格偏差超过3%为明显偏差，5%以上为大幅偏差，也将在此予以提示。

图表13：定价函数示意（位于relativePricing.py）

  

    
    
    def predictOutput(net, code, date):  
        #predictPreprocess为获取样本及目标数据，此处不展开  
        dfTrain, dfTarget, conv, netOut, lr = predictPreprocess(net, code, date)  
        dis, wgts = float(netOut[0].detach()), netOut[1].detach()  
        prem = lr.predict([[1, conv / 100, 100. / conv]])[0]  
        priceAssign = conv * (1 + (prem + dis) / 100.0)  
        dfTrain['weights'] = wgts  
        # 文字  
        codes = dfTrain[dfTrain['weights'] >= 0.025].sort_values('weights', ascending=False).index  
        if len(codes) < 5:  
            codes = dfTrain.sort_values('weights').tail(5).index  
        cbNames = cbName(codes)  
        outStr = f'根据我们的定价模型, {"、".join(cbNames[:5])}等对本期转债的参考价值较大，我们预计其' \  
                 f'二级市场定价应在{round(priceAssign, 2)}元附近，溢价率约{round((priceAssign / conv - 1) * 100, 2)}%'

**小结**

  

至此，我们已经拥有了正股简介、财务分析、正股股权分析、转债条款及定价结果，我们只需要集中调用这些函数，并输出至即可。这里的集中调用，由于涉及顺序，我们建议使用OrderedDict。

    def makeDocument(self):  
      self.document.add_heading(f'{self.cbName}投资价值分析', 0)  
      oper = OrderedDict({'简介段': self._正股简介,  
                '财务段': self._财务分析,

                '条款总结': self._转债条款总结,

      for k, v in oper.items():
