**投资者会遇到这样的问题：转债和纯债怎么比较？**
显然股性券乃至平衡性券与纯债之间没有可比性，前者以股性为主，后者的重点也在不对称性上。但债性转债（即低价券），与纯债之间尚存一些比较的空间，尤其对考虑"是否该配"的固收+投资者来说。但显然，即便限定在70元平价以内，转债的YTM也很难与纯债比较。

这里我们提出一个"真实收益率"，以将下修或后续转股的预期收益纳入考量。

  

我们认为转债的真实收益倘若完全不考虑下修，至少可以表征为：

  

![](https://mmbiz.qpic.cn/mmbiz_png/icCuLLwGvltMqib8LPwgH8RGFaOxAbLgJv7DXAzZnOia2z3a3hyCm1ecI7XhENjpw5poU3vmtY5nZQMEuJYw3Vibnw/640?wx_fmt=png&from=appmsg)

  

其中，转股概率可以利用BS模型中的N(d2)进行计算( **在BS模型中。N(d2)表示期权行权的概率**
)。这一估算中，为简单统一，我们暂不展开关于"转股预期价值"的更细致的讨论，以赎回触发线（多数130）作为替代。具体计算上，我们还需要稍微注意几点细节：

  

1）
N(d2)需要利用BS模型进行计算，我们将转债整体视为一个期权，其中行权的触发价以含补偿利率的到期价格表征，波动以正股过去180日的年化波动率表征，贴现以同期限同评级的公司债到期收益率表征。

  

图表2：计算转债行权概率的代码实践

  

    
    
    def calNd2(s, x, t, vol, r):  
        d1 = (np.log(s / x) + (r + 0.5 * (vol ** 2)) * t) / (np.sqrt(t) * vol)  
        d2 = d1 - vol * np.sqrt(t)  
        return norm.cdf(d2)  
      
    def calcdelta2(obj, tempCodes, trade_dt):  
        dateStr = st._offset(obj, trade_dt)  
        dateIdx = obj.DB['stkClose'].index.get_loc(dateStr)  
      
        # 计算当期同期限同评级信用债的到期收益率  
        dfRateCB = getEquivalentRate(obj, tempCodes, dateStr)  
        tempCodes = dfRateCB.dropna().index  
          
        # 将转债整体进行BS模型定价  
        val = calNd2(s=obj.DB['ConvV'].loc[dateStr][tempCodes],  
                     # 期权行权价格利用含补偿利率的到期价格替代  
                     x=obj.maturityCall.loc[tempCodes]['MATURITYCALLPRICE'],  
                     t=np.maximum(obj.DB['Ptm'].loc[dateStr][tempCodes] -1.5, 0.1),  
                     # 波动利用正股过去180日的年化波动率进行替代  
                     vol=((obj.DB['stkClose'].iloc[dateIdx - 180:dateIdx + 1][  
                               tempCodes].pct_change() ** 2).mean() ** 0.5) * np.sqrt(250),  
                     r=dfRateCB['Rate'].loc[tempCodes].astype(float) / 100.)  
      
        return tempCodes, val

  

资料来源：中金公司研究部

  

  

2）
转债的剩余期限选择上，由于转债进入最后一年半时，市场对于其转股的预期都会快速调整。因此，对于转债无论是从定价(计算N(d2))而言，还是"真实收益率"中转股部分收益的计算而言，都应该将剩余期限进行一定程度的调整。这个问题可以通过更为复杂模型建模来实现，这里为了理解的方便和贴近实务的考虑，我们直接将剩余期限扣减1.5年，进行调整。

  

图表3：计算债型转债“真实收益率”

  

    
    
    # 计算N(d2)  
    tempCodes, srsNd2 = calcdelta2(obj, tempCodes, d)  
      
    dfRateCB = getEquivalentRate(obj, tempCodes, d)  
      
    dfTemp = pd.DataFrame(columns=['转债价格', 'YTM', '转股概率', '真实收益率',   
                                   '剩余期限', '发行规模', '对应机会成本'],  
                          index=tempCodes)  
      
    dfTemp['转债价格'] = obj.DB['Close'].loc[d, tempCodes]  
    dfTemp['YTM'] = obj.DB['YTM'].loc[d, tempCodes]  
    dfTemp['转股概率'] = srsNd2  
    dfTemp['剩余期限'] = obj.DB['Ptm'].loc[d, tempCodes]  
    dfTemp['发行规模'] = obj.DB['Outstanding'].max()[tempCodes]  
    dfTemp['真实收益率'] = (1 - dfTemp['转股概率']) * dfTemp['YTM'] + \  
                      dfTemp['转股概率'] * (np.power(130 / dfTemp['转债价格'],  
                                                 1 / (np.maximum(dfTemp['剩余期限'] - 1.5, 0.1))  
                                                 ) - 1).replace(np.inf, np.nan) * 100.  
      
    dfTemp['对应机会成本'] = dfRateCB['Rate']

  

资料来源：中金公司研究部

  

  

以上计算处理后，我们可以看到，债型转债历史以来的“真实收益”情况。典型如2018年四季度，以及2019年二季度，2020年11月至2021年8月，债型转债的真实收益中位数能够超过或至少接近对应同期限同评级信用债收益率的中位数，因而在那一阶段具备了很高的性价比。

就当下的水平看，我们认为：

  

1） 今年9月以来，债型转债持续回调，整体幅度也相对更大。但近期，无论是YTM还是含转股预期的真实收益率已略有修复。
只是整体上相比于股性、平衡型的品种仍略有差距。

3）
固收+做底仓策略时，可以考虑这一指标做择券。我们约束单券的持仓上限为5%，转债部分选择AA及以上评级债性转债中，真实收益率大于同期限同评级公司债收益率的标的进行等权或加权，剩余仓位分配给AAA信用债指数。这一组合作为底仓而言，仍具备不错的收益风险比。
