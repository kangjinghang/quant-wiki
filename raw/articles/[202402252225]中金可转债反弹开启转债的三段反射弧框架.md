**临时的弹性，以及负Gamma**

  

**低价券的“临时弹性”实际不难解释：毕竟此前跌出了退市风险的担忧。** 更定量化地理解，所谓的“进可攻、退可守”，往往仅仅是转债 vs
正股之间关系的一部分——通常所显露出的那一部分——但曲线的左侧，随着正股下跌，退市风险加大，转债重新“获得了弹性”。特别是，转债的极端风险不同于普通债券，它是与股价相关的：按照退市规则，当股价越接近1元、市值越接近3亿元，其风险越大。实际上有：

这个现象存在两个影响，对应转债的两个希腊字母，即delta与gamma：

  

1.Delta方面无需多言，股价上涨时公司与退市风险也渐行渐远，可以用下面的公式表示一个转债“不退市”的概率，即N(d3)。

  

图表3：转债不退市概率的模型

  

    
    
    from scipy.stats import norm  
    import numpy as np  
      
    def 不退市概率(S, K, vol_his, t):  
        '''S为平价，k为退市条件触发时转债平价，即退市线，vol_his和t分别为波动率和期限'''  
        d3 = np.log(S/K) / vol_his / t ** 0.5  
        return norm.cdf(d3)

**2\. 但更重要的是，实际上有的品种要迈入“负Gamma”的阶段了。**
显然在引入退市风险的情况下，求Gamma的解析式会更为冗长（更实用的是数值解，如下），但在上图中已经显示得很明确。

图表4：转债Delta和Gamma的计算

  

    
    
    def bsCB(s, x, t, vol, rf):  
        '''转债专用,忽略了期间票息,X为到期赎回价'''  
        d1 = (np.log(s / x) + (rf + 0.5 * (vol ** 2)) * t) / (np.sqrt(t) * vol)  
        d2 = d1 - vol * np.sqrt(t)  
        return s * norm.cdf(d1) + x * np.exp(-r * t) * (1 - norm.cdf(d2))  
          
    def delta(s, x, t, vol, rf, k, vol_his):  
        d1 = (np.log(s/x) + rf + 0.5 * t * vol ** 2) / (vol * t ** 0.5)  
        d3 = np.log(s/k) / vol_his / t ** 0.5  
        price = bsCB(s, x, t, vol, rf)  
        return norm.cdf(d1) * 不退市概率(S, K, vol_his, t) + \  
        norm.pdf(d3) * price / (s * vol * t ** 0.5)  
         
    def gamma(s, x, t, vol, rf, k, vol_his):  
        '''gamma直接用差分做，但请注意此处考虑择券使用，s的间隔取一倍标准差，稍大'''  
        ret = delta(s * np.exp(vol_his), x, t, vol, rf, k, vol_his) - \  
        delta(s * np.exp(-vol_his), x, t, vol, rf, k, vol_his)  
        ret /= s * (np.exp(vol_his) - np.exp(-vol_his))  
        return ret

就择券来讲，通常我们认为Gamma要比Delta更为重要——因为Delta的发挥依赖于股价的方向，而Gamma有波动就可以了。
而对于不必非常定量的投资者而言，需要进行的是一个更务实的选择：对于低价转债，剔除高违约风险券后（方法可见 [ 《退市风险模型与策略的Python实践》
](http://mp.weixin.qq.com/s?__biz=MzAwNzMzODYyNg==&mid=2650481184&idx=1&sn=55c13bd1c585cf853b51beda7fac2494&chksm=83702dcdb407a4db923884a560df9e646d43b6ac79bdc06b190b29a452a2fa947a599dd5cf86&scene=21#wechat_redirect)
），如果溢价率仍高且下修可能性不大，那么大概率其delta已经进入越涨越削弱的阶段了——以当下低价券的数量之庞大，我们没有必要在这样的个券上停留太久。

**倾斜的波动率曲线，平衡段的红利区**

  

**转债“反射弧”的异常还出现在“平价 vs 隐含波动率”曲线上。**
在转债市场，波动率的倾斜由来已久，近期随着风险偏好下滑，这种现象表现得非常“标准”——平价越高、隐含波动率（即估值）越低，下图为当前的情况。
这当然与市场仍不高涨的预期，以及更关键的条款博弈情况有关。但关键是，这将如何影响当下转债的投资性质。

至少，以下几点投资者应有所认识：

  

1、 当下，存在一个统计上的"红利区"：
当平价在90~105元附近时，平均隐含波动率下降不快，且在平价下跌时其隐含波动率能够得到提升。简单理解，若正股上涨，这些品种距离赎回还远，若下跌，市场开始期待下修保护。

  

2、 但对不同平价的转债而言，其意义不同：  平衡性品种对隐含波动率的敏感度更高，而偏股、偏债则较低。数字上可以抽象为：“vega /
close”，如下图。  结合当下市场状态，会出现对股性、平衡性品种更有利，债性品种相对弱化的性质：
对于股性转债来说，股价上涨伴随估值（隐含波动率）压缩，但此时转债对估值敏感度下降。而股价下跌伴随估值提升，此时转债对估值的敏感度也在提升，相当于附加了更多保护性。但对于平价80元以下的债性品种，情况则可能相反。
**自然这会影响转债的性价比，而优势与劣势的分界点大约在平价90元附近。**

**小结**

  

1、债性券的“弹性”与负Gamma：对于一些股价上涨即可远离退市担忧的券，此前及当下阶段表现出一些弹性是合理的现象，但随着风险化解，退市风险走远，此后可能也要迎来负Gamma的问题——而隐含波动率的倾斜也对这些品种的削弱；

  

2、显然市场上债性券数量最多，此前我们也建议投资者在此处布局，但当下到了可以更“挑剔”的时候。我们建议对低价券：

  

1）对动量做筛选，这是固定搭配，当下的意义在于高动量的品种有更大的可能性向平衡性乃至股性过渡；

  

2）对溢价率已经超过50%的品种，考虑下修的可能性，我们在 [ 此前的报告
](http://mp.weixin.qq.com/s?__biz=MzAwNzMzODYyNg==&mid=2650515087&idx=1&sn=09e666bc391d4c6aab40422f3f6433f6&chksm=8370a962b4072074e987f3de181e4f13cf7055d0abb01f9023e14038f380cc6351c05dc1d3c7&scene=21#wechat_redirect)
中给出过下修的一些规律，而近期下修的数量也达到了历史顶峰。至少对于溢价率高、下修可能性很低的品种而言，投入太多自然会降低持仓效率。

3、策略配置上投资者可能要逐步向平衡性、股性过渡，当下可能更主要受限于数量。

  

4、我们暂无必要讨论连续反弹中是否过热，届时市场会给出信号。
