**一、N-S模型的特征提取与注意事项**

  

  
N-S模型作为一个描述利率期限结构的静态模型，主要通过三个因子和一个参数来捕捉利率曲线的形状。

  

![](https://mmbiz.qpic.cn/mmbiz_png/icCuLLwGvltN7IZGvWSnicGRykOs3CncPics1UCiaUOLqia7SADgNIrhd7PcQz2njP6wno0tHKWTMfm2v40FDicmNsRA/640?wx_fmt=png&from=appmsg)

  

其中，

•  beta1衡量的是利率曲线的水平因子，是曲线理想情况下的长期利率  ，也是收益率曲线整体上下行的锚定点，实务中类比10年期国债收益率；

  

• beta2衡量利率曲线的斜率，即收益率曲线是陡是平的定量表达，实务中类比10年期和3个月国债收益率差；

  

• beta3衡量的是利率曲线的曲度因子，刻画中期利率对曲线的“调整”，实务中一般以2倍的中期利率减去长短期利率之和作为参考。

  

•  lambda作为因子载荷的控制参数，主要控制因子随时间推移而衰减的速率。
下图刻画的是2024年7月31日，依据国债收益率曲线所计算的各因子载荷情况。  较小的lambda值意味着衰减较慢，拟合长期利率效果更好
——长期利率测算误差更容易压缩；而较大的lambda值意味着衰减较快，拟合短期利率效果更好。同时lambda也表征斜率因子受哪一中期收益率影响更大。部分学术和实务量化中，为更灵活拟合收益率曲线的不同部分，每个因子可能都有对应的lambda，为更方面测算和减少过拟合，需要加入惩罚项来平衡。

**3.3 如何考虑模型的误差**

考虑到N-S模型本身对收益率存在误差，而基于N-S模型参数的预测也会带入误差，因此我们认为需要加入对误差的分析。
以此明确，在什么概率上我们策略的性价比相对较高。  由于我们的模型并不是简单线性回归，所以我们需要借助预测模型中in-sample的误差特征来对应建模。

  

具体计算中，第一步：我们将in-
sample的误差提取其平均值、标准差、偏度和峰度值；第二步：我们假定模型的误差满足某一类高斯分布，我们通过偏度和峰度来调整分位数值；第三步：在原数值的基础上进行叠加计算。这里我们引入一个准确度_level，准确度越高则模型预测的因子宽度越大，准确度越低则因子的宽度越窄，精准判断的能力越强。如下图所示，模型在85%“准确度”下都能较好覆盖因子实际情况。

  

图表8：针对模型误差数据的修正

  

    
    
    def retParaPct(z, skew, kurt):  
        # 假定符合高斯分布，以此来调整分位数值  
        z = (z + (z ** 2 - 1) * skew / 6 +  
             (z ** 3 - 3 * z) * (kurt - 3) / 24 -  
             (2 * z ** 3 - 5 * z) * (skew ** 2) / 36)  
        return z  
      
      
    def retParaInterval(std, skew, kurt, _level=95):  
        # 获取分位数，由于误差分布不完全正态分布，所以上下分位数的取值需要调整  
      
        _upLevel = norm.ppf(((_level / 2) + 50) / 100)  
        _downLevel = norm.ppf((50 - (_level / 2)) / 100)  
      
        _upError = retParaPct(_upLevel, skew, kurt)  
        _downError = retParaPct(_downLevel, skew, kurt)  
      
        return _upError * std, _downError * std

**四、纯债收益率模型的择时应用及复盘**

  

  

一个基于预测值和赔率的基础模型底座。在以上步骤中，我们已经获得了模型所计算出来的收益率以及误差的情况。在此基础上我们可以首先形成一个针对指数的策略模型，具体策略部署上：

  

1\. 利用模型，计算未来21个交易日后N-S模型各参数的数值。

  

2\. 基于当前各指数的剩余期限，确定指数未来在80%"准确率"上，指数潜在的收益变化。

  

3\. 赔率值计算：  计算收益率潜在下行bps与潜在上行bps的数值以此作为赔率值
，当赔率值均小于1时组合保留最短久期品种来维持参与，而当赔率值大于1时，我们在回撤约束的状态下选择赔率较高的策略。
其中，回撤约束是计算收益率上行风险在月度窗口，是否满足组合回撤要求。我们分别计算月度0.5%，0.75%，1%，2%和3%的回撤条件来进行回测。

  

4\. 考虑到我们模型更偏向交易策略， **故而我们选用国债综合全价指数作为基准，回测组合也仅用各全价标的。**

  

通过回测我们可以看到，模型的效率在月度回撤约束在3%以内的时候表现最好，纯全价指数2017年1月至2024年7月，年化收益2.06%，最大回撤2.6%；同期基准年化收益1.30%，最大回撤5.71%。

**小结**

  

1\. 该模型的预测逻辑在于1）通过预测N-
S模型各参数来测算收益率，其中预测的解释变量包括参数自身和与收益率整体相关的量价因子；2）在预测同时，引入模型的误差分布特征值，从而计算对应的策略赔率与回撤情况；3）最后依据组合可允许回撤幅度，来进行久期切换。

  

2\.
由于模型涉及机器学习和误差数据的利用，因此必然涉及参数设定的平衡——当Xgboost的深度过大或者自身参数量过多时，误差会被压缩，使得后续择时模型的效率降低。我们所作的平衡还是在于对克制模型的参数优化，而更关注于在多少准确度内进行计算的实务性。

  

  

**风险**

模型预测存在误差；收益率曲线偏离常规状态；机构投资者行为和政策约束下，收益率中枢出现超预期调整；红利板块公司基本面超预期调整。
