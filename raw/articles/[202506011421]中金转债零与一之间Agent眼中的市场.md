** “中性”当然不是一个容易被市场记住的观点，一定程度上，投研的价值也许就在于给出倾向性。  **
实际上，在《择时体系2：强化学习的逐步实现》中，我们设计的模型，总能给出一个0或1的结果 ——
只不过市场却不一定总能接受，乃至我们也甚少在周报中将它的结果展示出来。例如在样本外，它的决策和净值曲线如下。

不难看到，样本外的决策正确性甚至强于样本内（2010年以来），例如2022年的2次抄底、2024年把握住那次“信用风险潮”带来的机会 ——
但是，2022年后的多数时间，它就是一个空仓的状态，  投资者自然不易接受，尤其是以规模为主要考核的那部分
（但实际上，是否持有基金则是另一个维度的问题）。

  

** 但有两点需要说明：  **

  

1、我们的模型设有较高的  ** 交易成本假设  **
（进出各0.3%），因此一旦进入空仓状态，市场需要给一个足够大的理由，去“打动”模型，而不是仅仅中性、尚可，就可以让这个非0即1的模型，回到多头状态。强化学习模型更像是在交易，而不是在分析，这也造就了这样的“不直观”之处。

  

2、也正如市场进入那种不是非多（空）不可的状态时，卖方会更多强调"结构性机会"。自然，市场整体的结论不适用于每一支个券。也因此，即便在2022年后，亦有不少基金走出了强于固收的效果，例如高YTM户、双低户、基于行业轮动的偏进攻性产品等。

  

** 我们不妨做一个尝试，倘若把强化学习模型，用在个券上该会是怎样呢？  **
这个做法并不难，模型和环境设置请见《择时体系2：强化学习的逐步实现》，当然对应到个券上，会出现一些技术问题，我们列出自己遇到的一些情况：

  

** 1、市场整体情况的变量是用还是不用？  **
我们起初只用了转债估值和正股基础的量价因子，总共不到10个，但考虑到市场水位不同时，对相对估值的理解自然不同，我们只加入“市场价格中位数”这一个变量，作为“整体情况”的代理。

  

** 2、有的模型会很早认识到，"一直持有就好"  ** ** （毕竟长期历史看，转债收益大体上是不错的），从而进入局部最优，不再学习  ** 。
实际上，就中小盘、低估值起点的转债来说，投资者也会看到，不容易做出比一直持有更好的选择，反之亦然。
我们解决的方式比较简单，一是在此时必然特征值本身就不够有力（从而模型得不到有差别的结果），考虑加因子。二是让随机探索（训练时，模型有概率不根据agent的计算结果，而是随机做出动作）的系数加大，随后再变小，类似“退火”的原理。

  

** 3、是否考虑Transformer或者LSTM这样的带时间步的模型？  **
可以，但模型会比较快地"记住"形态，从而走向过拟或者停止学习，我们只是一次小小的尝试，不必如此。

  

** 4、也强化学习的一个小难点，它似乎会过于重视最近几个训练的结果。  ** 这会大幅弱化模型的泛化能力 ——
连样本内都做得不够好，更不用说样本外，模型完全未看到过的数据了。
我们的解决方案是建立缓存池，让模型每次学习时，进入缓存池随机学习，而非学习当下的一支个券。  ** 而真正的难度在于在计算层面，权衡时间和空间的消耗。
**
个券数据的量级是整体市场的几百倍，我们看到的情况供投资者参考，静态的数据大致占据7g内存，缓存池和训练时的张量，各自占据类似的尺寸，这样21g的内存（或内存
+ 显存）是必要的。

    classGlobalReplayBuffer:  
        def__init__(self, capacity, state_dim):  
            self.capacity = capacity  
            self.states = np.zeros((capacity, state_dim))  
            self.actions = np.zeros(capacity)  
            self.rewards = np.zeros(capacity)  
            self.next_states = np.zeros((capacity, state_dim))  
            self.position = 0  
            self.size = 0  
          
        defadd(self, state, action, reward, next_state):  
            idx = self.position  
            self.states[idx] = state  
            self.actions[idx] = action  
            self.rewards[idx] = reward  
            self.next_states[idx] = next_state  
            self.position = (self.position + 1) % self.capacity  
            self.size = min(self.size + 1, self.capacity)  
          
        defsample(self, batch_size):  
            indices = np.random.choice(self.size, batch_size)  
            return (  
                self.states[indices],  
                self.actions[indices],  
                self.rewards[indices],  
                self.next_states[indices]  
            )

下面是一些结果（只看样本外，我们的训练数据是从2018~2022年，2023年后是样本外）：

  

1、平均每支个券，可以增强0.19的卡玛比例和减少9.4%的最大回撤。重要的是其把握机会的机制，以下面的科数转债为例，2023年末有一次短暂尝试，买入日是23年的10月23日（这是该转债上市以来，首次YTM翻正，我们也看到模型对这个信息是敏感的），但直到11月中旬，正股未走出趋势行情，随即了结。另外两次是2024年的2月初和9月末，显然都是跌出来的机会，我们看到模型理智的一面在于，并非跌得够多就会买入，且后续发展如果不够好，即便承担着较高的交易成本，也要离场，这是模型对这类机会的态度。

  

而对于2025年后的趋势走势，模型却不急于离开，而由于我们没将赎回的信息纳入特征值，策略未因赎回离场，造成回撤。

但，更重要的是我们看到了：

  

1、实际上这就是“自下而上形成了自上而下”的结果，我们常见投资者将这两部分（策略、个券）工作分开，后续还会出现其他问题，例如覆盖个券的研究员与组合管理的鸿沟较大、负责策略的研究员不能推荐到个券层面等等。但
更简单的逻辑是，也是这里实现的，仓位就取决于，在一个统一的标准下，有多少可买的个券。

  

2、结论当然不止0或者1，还有很多介于0和1之间的数字，只不过交流的过程中，0和1更容易让人印象深刻，就现在来看，数字来到0.5附近，我们的精力应当就在于找到这50%。但如我们此前所说，投资经理层面，解释力和专业判断一样重要。

  

** 此外，近期还有另一个有关“解释力”的话题：一部分投资者密集地关注临期债。  ** 这个问题我们早在《转债中与直觉有关的常见弱点》中既有论述，见  _
“常见错误9：那至少，如果转债已经进入最后的期限，转股压力之下会有更强的表现”  _
。简而言之，历史表现不支持这个说法，最后1年的转债，即便限制价格，也跑出了远落后于市场的表现，即便希望从中选出更好的，或者“有动力的”，这也是个远落后于全样本的起点。

  

当然，一些投资者即便知道这一点，对于  “马上就要到期了，公司不尽力促成转股又该如何”  ——这个问题又很难解释。

  

我们有两种解答供参考：

  

1、临期品种有一定的逆向选择性，转股与否无非取决于促转股的能力或态度，那么临期券未能在前5年的行情里转股，有更大的概率是缺失了其中的至少一环；

  

2、这个问题，标的公司用了前五年的时间都未能解答，投资者当然也难以回答。实际上，这本就不应该是投资者该去思考、解决的问题，而是上市公司本身。

  

最后，这个问题再度出现，我们认为是因为转债市场由于横跨股债，投资者流动率相对较高，每一段时间都会有不熟悉的投资者，提出这样的问题。投资经理层面，要注意的是，尤其在这样的领域，解释力和专业判断同样重要。
