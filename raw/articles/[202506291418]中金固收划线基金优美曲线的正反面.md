** “划线基金”几乎满足了大部分投资者对于资产的持有预期。  **
但如何识别“划线基金”？本篇报告中，我们通过一类算法创新——测算各基金净值与货基指数之间的“修正后相似性”来进行识别，并结合基金其他特征值进行“贴标”。同时，我们进一步挖掘这类“划线基金”的共性以及基于历史“划线特征”的组合效果。

  

** 一、什么是“优美”的曲线  
——识别“划线基金”  **

  

  

“划线基金”一般是指曲线相对单调向上，持续具备赚钱能力的基金产品，本质是投资者基于净值曲线的视觉而做出的判别。  从实现“划线基金”的难易程度而言，货基 <
摊余成本法产品 < 纯债债基 < 固收+基金 < 偏股型基金，  关键是其持有资产“生息收益”比其资本利得变动的数值大小
，以纯债基金与固收+基金之间为例，前者票息保护相对后者更大，而纯债的资本利得变动相较含权型组合的更小，因此纯债基金更容易成为“划线基金”。含权债基部分，下图为分股票仓位的三类典型“划线基金”。

那么如何识别“划线基金”呢？
基本思路是将净值曲线进行降维，利用例如区间最大回撤、创新高比例、月度正收益率、卡玛比等方式进行。市场上过去通用的一类简易方法是：过去三年（1）年化回报大于10%；（2）卡玛比大于1；（3）年度均有创新高表现。
但显然这类方法受限于参数选择，对于各类标准及其参数的敏感度较高
(回看周期3年与5年所筛选的产品存在差异)，不同市场阶段这一参数适配性需要调节(2024年9月往前看3年，年化回报10%的偏股型产品相对有限)。

  

因此，我们直接通过“稳定右上延申”的货基指数(885009.WI)的差异水平来进行“划线基金”识别。具体方法为：

  

1\. 获取数据与标准化：
获取基金和货基指数的历史时序，前者为复权单位净值。对区间净值进行标准化处理，即净值减去净值区间均值后除以净值的标准差。下图为货币基金指数和基金A净值曲线调整前后的变化。可以看到标准化处理后，基金净值可以与货基指数直接进行对比。其逻辑约等于是将组合收益率中的漂移项进行归一。

2\. 计算曲线间，经调整的欧氏距离：
欧氏距离是指数据组之间绝对方差的总和，假定基金A的月度收益率序列为(R1,R2,...RN)，指数之间的月度收益率序列为(r1,
r2,...,rN)，那么这两组数组对齐后的欧氏距离便是

  

![](https://mmbiz.qpic.cn/mmbiz_png/icCuLLwGvltOwASico0bgl7BEbqrMJicjwfR6GI52L8EArqjHsALICG8x8a5ezUibmhfCMjGAU9aNcRO40XLNfhhtw/640?wx_fmt=png&from=appmsg)

  

在我们的测算场景中，  该数值越小，意味着基金与货币基金指数越类似，越呈现低波动下向右上方延申的特质。
考虑到我们更偏好基金的“赚钱效应”，其净值相较货指处于上方的差距是可以忍受(意味着更赚钱)，但是向下部分的距离约等于一定回撤幅度，需要尽可能避免。因此我们对于欧式距离进行调整，若Ri<ri时，给予距离两倍乘数。调整后的数学式和计算代码为：

图表3：经调整的欧氏距离算法

  

    
    
    defadjEuclidean(matSeries, r, LowerMul=2):  
        # 计算多个数组与零一数组之间的欧氏距离  
        diff = matSeries.subtract(r, axis=0)  
        adjDiff = diff.applymap(lambda x: LowerMul if x < 0else1) * (diff**2)  
        return np.sqrt(adjDiff.sum())

3\. 配合季度创新高和最大回撤修复天数来框定范围：
考虑到欧氏距离的绝对数额相对难解读，我们使用两类传统指标来作为辅助，分别为基金净值季度创新高概率，与区间最大回撤修复天数。前者计算逻辑为，以季度为单位，基金净值是否做到了创新高；而后者则计算基金区间内产生回撤后，需要多久爬出并创新高。但实际欧式距离本身具备筛选“划线基金”的能力。

  

图表4：快速矩阵式计算指标的代码

  

    
    
    defnewhighNAV(matNavs, freq='Q'):  
        # 创新高概率  
        matNewHigh = ((matNavs / matNavs.expanding().max()).resample(freq).max() == 1)  
        return (matNewHigh.sum()-1) / (matNewHigh.count()-1)  
      
    defrecoveryDays(matNavs):  
        # 最大回撤修复天数  
        belowMdd = (matNavs / matNavs.expanding().max()-1) < 0  
        return belowMdd.apply(  
               lambda x: x.groupby((x!=x.shift()).cumsum()).transform('sum')).max()

** 二、典型的“划线基金”做对了什么？  **

  

  

通过上述方法论，从过去五年的维度来看，以下基金是典型的“划线基金”。我们分类型展开一些讨论：

  

  

** 1\. 固收+基金中的“划线基金”：相对稳定的管理团队与策略目标  **

  

样本基金(过去五年规模均不低于1亿元，权益仓位不低于10%)维度，可以看到可归属于“划线基金”的固收+产品，普遍存在3点特征：
（1）基金经理相对稳定，整体策略保持较久  ——从权益中枢来看，绝大部分没有出现频繁和大跨度调仓；  （2）权益仓位存在一定股二债八的隐性上限
：转债部分经过delta调整后，所框定的“划线基金”的权益仓位加总基本被约束在30%以内；  （3）控制系统风险暴露和不弱的择股能力：
以二级债基指数作为市场收益表征，则大部分“划线”固收+基金的系统风险暴露均相对有限，个别典型产品甚至beta仅有0.2。偏债混基和灵活配置，与一二级债基稍有区别，部分产品市场暴露稍高，其需要依赖不俗且稳定的择股收益，才能平滑净值。但这类产品普遍市场接受度有限，规模提升偏慢。

** 2\. 偏股型中的“划线基金”：少数留存的Alpha  **

  

从跨5年的周期来看，样本偏股型基金中仅有少数产品相对实现“划线表现”：  （1）银行和低股息标的的“划线”属性相对较强：
但即使表现稍好的红利低波和银行ETF也面临20%左右的回撤幅度，相较固收+基金而言，欧氏距离的绝对值水平也较高；
（2）剩余偏股管理型产品主要集中在单一的管理人身上
：从跨五年的维度来看，仅有一家管理人和两位基金经理实现了长期的收益——(a)产品并不是跟踪上述指数，而是各自在小盘和大盘层面具备较好的择股能力；(b)+纯债来提高收益能力也相较其他偏股型产品做的更多，整体择时得分也处于前列；
(c)管理人在管时间也较为稳定。

总结而言，事后来看的“划线基金”：

  

（1）普遍具备较为稳定的管理团队，策略风格相对明确，拉长周期也具备正向的择股能力——
但显然2-3年的短考评周期内，若产品就实现较为显著的超额收益，在考评吸引力有限的情况下，基金经理有多大可能留任；

  

（2）固收+普遍存在一个隐形的仓位约束，这部分和择股Alpha整合来看，是为了抵御市场Beta的不确定性——持续的Alpha有多少管理人具备，因此定位的相对稳定反而更为重要。
但定位的相对稳定取决于投资者结构，在绝对牛市过程中，以“绝对收益”为目标的产品多大程度能够不被淘汰，因此也正如上述数据所呈现的，“划线基金”在管理人层面的分散度不高；

  

（3）回撤约束下基金的绝对收益其实并不突出，从过去五年累计回报的维度看，“划线基金”表现不弱，但在同类型中或许仍不属于绝对前列。

  

  

** 三、但要承认“优美”的错觉  **

  

  

“优美”的曲线是事后的表征，其特征值对于未来择基而言是相对困难的。下图中，我们采取月度调仓的测算规则，在股票型基金和固收+基金中分别针对当期的欧氏距离值(先以季度创新高不低于60%后，选择经调整后欧氏距离低于0.03的基金)来进行筛选，
可以看到虽然当期“划线基金”有一定收益提高，且回撤有所控制，但最终产品的指数仍达不到部分“划线基金”自身历史回看的表现。

2\. 预测欧氏距离的模型稳定性不高，
特征值权重的快速变化一定程度反映，即使每一个换仓期对历史可得数据进行训练，其预测效果可能也不及预期。同样也解释了，我们在上图中，换仓期通过特征值进行“划线基金”确认后，一年后其并不一定是“划线基金”。

  

若从当下判断可参与的“划线基金”角度入手，我们认为（1）权益市场方向性大幅变动的可能不大，因此尤其对于固收+基金而言，可以先从当前低“欧氏距离”基金入手进行筛选；（2）对于基金策略多样性的要求更高，或至少筛选出的基金的市场暴露因子要相对更低；（3）经理切换或是未来一段时间“划线基金”可持续性的关键。
