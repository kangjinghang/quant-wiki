## A. 策略类（信号怎么产生）

### A1. 🟢 动量与趋势（momentum-trend）
- **定义**：买入近期强势、卖出弱势。含长端动量、振幅切割动量、残差动量、龙头股动量、隔夜/日内动量、趋势跟踪（利弗莫尔/鳄鱼线/通道突破）等变体。
- **涉及 tag**：`momentum` `动量` `趋势跟踪` `长端动量` `振幅切割动量` `残差动量` `龙头股模型` `隔夜动量` `日内动量`
- **粗判数据**：日线 OHLCV ✅。多数变体日线够；少数（残差动量提纯）想要分钟级。
- **适配度**：🟢 核心。

### A2. 🟢 反转（reversal）
- **定义**：买跌多的、卖涨多的。含理想反转、锚定反转、残差反转、局部反转、短期反转效应。行为金融驱动（锚定偏误/处置效应）。
- **涉及 tag**：`反转因子` `反转效应` `锚定反转因子` `残差反转因子` `理想反转因子` `均值回归`
- **粗判数据**：日线 OHLCV ✅。理想反转/残差反转的"切割"想要分钟级大单数据（开源金工），但有日线降级版。
- **适配度**：🟢 核心。

### A3. 🟢 行业轮动（industry-rotation）
- **定义**：在申万/中信行业间动态配置。含动量+拥挤度、景气度、北向资金、盈利预期、资金流、宏观驱动等多条路径。wiki 最厚重的方向之一（42 篇源）。
- **涉及 tag**：`行业轮动` `行业景气度` `行业动量` `行业拥挤度` `北向资金行业轮动` `盈利预期行业轮动` `AIA-Timing` `板块配置轮盘`
- **粗判数据**：日线行业指数 ✅、景气度（财务+分析师预期）✅、北向 ✅、拥挤度量价派生 ✅。
- **适配度**：🟢 核心，且可由 ETF 落地。

### A4. 🟢 风格轮动（style-rotation）
- **定义**：在成长/价值、大盘/小盘间切换。含 PB-ROE 动态划分、宏观驱动、双轮驱动（估值+盈利）、Softmax 多分类。
- **涉及 tag**：`风格轮动` `成长价值风格轮动` `大小盘风格轮动` `pb-roe` `softmax风格轮动`
- **粗判数据**：风格指数/估值 PB-PE ✅、分析师预期 ROE ✅、宏观 ✅。
- **适配度**：🟢。

### A5. 🟢 事件驱动 / PEAD / 业绩超预期（event-driven-pead）
- **定义**：利用财报披露、盈余公告后的价格漂移（PEAD）。含 SUE、超预期Plus组合、盈余惯性、业绩预告/快报融合、下修/赎回/减持等公告事件。wiki 核心方向。
- **涉及 tag**：`事件驱动策略` `pead效应` `sue因子` `业绩超预期` `盈余惯性` `业绩预告` `业绩快报`
- **粗判数据**：财报/预告/快报 ✅（东财）、公告分类 ✅、龙虎榜 ✅、分析师一致预期 ✅。
- **适配度**：🟢 核心。注意：A 股 PEAD 做多有效、做空不显著（只能"超预期做多+不及预期规避"）。

### A5b. 🟢 指数成分股调整效应（index-rebalancing）
- **定义**：沪深300/500/1000 等指数半年一次定期调整，被动基金机械买入新纳入、卖出剔除成分股，带来可预测的短期价格冲击（纳入效应+、剔除效应−）。wiki 有专门概念页，逻辑独立于 PEAD（不是财报事件，是指数机械事件）。
- **涉及 tag**：`指数成分股调整效应` `etf` `指数增强` `建仓`
- **粗判数据**：调整名单 ✅（中证指数公司公告，免费公开）、成分股 ✅。
- **适配度**：🟢。低频事件型（每年 2 次），QMT 在生效日前布局即可。

### A6. 🟢 分析师预期因子（analyst-expectation）
- **定义**：基于卖方分析师预测数据（一致预期 EPS/目标价/评级）构建因子。含目标价 Alpha、盈利预期调整 FYR、关注度、上下调比例、预期景气度。
- **涉及 tag**：`分析师预期因子` `一致预期` `分析师目标价` `盈利预期调整` `分析师关注度` `评级变动因子`
- **粗判数据**：一致预期（EPS/目标价/评级分布）✅（东财 RPT_WEB_RESPREDICT）。⚠️ wiki 多处提 Wind/朝阳永续——你的源是东财，覆盖度待 L1 核。
- **适配度**：🟢。

### A7. 🟢 景气度 / 基本面量化（prosperity-fundamentals）
- **定义**：用财务指标（ROE/营收/毛利率/现金流）+ 分析师预期刻画企业或行业繁荣度与边际变化。含复合景气度、GARP、景气向上持续增长、企业生命周期分域。
- **涉及 tag**：`景气度` `基本面量化` `复合景气度` `garp策略` `企业生命周期` `景气向上`
- **粗判数据**：季度财务 ✅（东财/mootdx/新浪三表）、一致预期 ✅。
- **适配度**：🟢。

### A8. 🟢 估值与价值因子（value-estimation）
- **定义**：低 PE/PB 为主，含动态均衡估值 BET、可比公司法价值重构、剩余收益估值、估值历史分位、估值泡沫保护。
- **涉及 tag**：`估值因子` `价值因子` `均衡估值因子` `动态均衡估值` `可比公司法` `剩余收益估值` `估值分位` `估值泡沫`
- **粗判数据**：PE/PB ✅、估值分位 ✅（百度 gushitong）、一致预期 ✅。
- **适配度**：🟢。

### A9. 🟢 盈利质量 / 财务因子（quality-profitability）
- **定义**：从三大报表提纯不易操纵的指标（核心利润、异常经营现金流、真实盈余管理、ROA 拆解、应计利润）。含财报因子构建框架、财务危机预警。
- **涉及 tag**：`盈利质量` `核心利润` `真实盈余管理` `异常现金流因子` `财报因子构建框架` `财务危机预警`
- **粗判数据**：三大报表 ✅（新浪 fzb/lrb/llb）。
- **适配度**：🟢。

### A10. 🟢 低波 / 特质波动率（low-vol-idiovol）
- **定义**：低波动异象 + 特质波动率 + 风险不确定性（VOV）。A 股历史上低波/低 Beta 曾失效，近年机构化后回归。
- **涉及 tag**：`低波动异象` `特质波动率` `低波异象` `风险不确定性因子` `vov效应`
- **粗判数据**：日线波动率 ✅。VOV 原版用 5 分钟高频——日线可降级版（用日度已实现波动率的时序标准差）。
- **适配度**：🟢（VOV 降级版）。

### A11. 🟢 资金流 / 北向资金（fund-flow-northbound）
- **定义**：北向资金（配置盘/交易盘拆解）+ 主动买卖因子 + 龙虎榜机构席位 + 量化私募营业部识别。**主线用北向+龙虎榜+融资融券**。
- **涉及 tag**：`北向资金流` `资金面` `主动买卖因子` `龙虎榜` `量化私募营业部` `融资融券`
- **粗判数据**：北向分钟级 ✅（同花顺）、龙虎榜 ✅、融资融券 ✅。
- **适配度**：🟢。
- **⚠️ 重要分裂**：wiki 里的"大小单逐笔资金流""CNIR/ACT 因子"等依赖 **Level-2 逐笔**，DATA_SOURCES §5 标注**已主动移除（覆盖率天花板低）**。这部分转入 🔴 高频/L2 分支（B29），本卡只评估北向+龙虎榜+融资融券这条可得主线。

### A12. 🟡 微观结构 / 量价因子（microstructure-price-volume）
- **定义**：从日内/高频价量提取因子。含跳跃波动、半贝塔拆解、DPIN 知情交易概率、价量共振、日内成交量分布、LogSig-Alpha、时间重心偏离 TGD。
- **涉及 tag**：`高频量价因子` `市场微观结构` `跳跃波动因子` `半贝塔拆解` `dpin因子` `价量共振` `日内成交量分布` `logsig-alpha`
- **粗判数据**：⚠️ 大部分变体需 **分钟级或 tick 级**数据（🔵 QMT 可补分钟K；tick/L2 是 ❌）。日线派生版（MACD/RSI/量比）有，但 wiki 这里的 alpha 主要在高频。
- **适配度**：🟡 待 L1 逐变体判定哪些能用分钟K降级、哪些必须 tick（后者转🔴分支）。

### A13. 🟢 打新 / 抢权配售（ipo-strategy）
- **定义**：新股申购 + 可转债抢权配售 + 网下超额认购。注册制下从无风险收益变破发常态。
- **涉及 tag**：`打新策略` `打新` `抢权配售` `原股东优先配售` `网下超额认购` `ipo定价制度`
- **粗判数据**：IPO/转债发行公告 ✅、上市首日表现 ✅。
- **适配度**：🟢（事件型，T+0/T+1，QMT 适合做执行）。

### A14. 🟢 可转债（convertible-bond）
- **定义**：转债择券+择时。含双低/EasyBall、分层组合、多因子选券、估值择时（百元溢价率）、下修博弈、赎回预测、风格轮动、Smart Beta。wiki 极深方向（43 篇源）。
- **涉及 tag**：`可转债` `双低策略` `easyball` `转债分层组合` `转债多因子` `百元溢价率` `下修条款` `赎回预测` `转债择时`
- **粗判数据**：⚠️ wiki 多处依赖 Wind 转债数据。需 L1 查清：转债行情/溢价率/条款能否经 akshare/东财免费拿到（大概率 🔵 可补）。正股联动 ✅。
- **适配度**：🟡（数据源待 L1 核实，逻辑极成熟）。

### A15. 🟡 可转债套利 / 定价（convertible-bond-arbitrage）
- **定义**：CRR/BS 定价 → 定价偏差套利 + Delta 对冲（融券/股指期货）+ Vega 增强。
- **涉及 tag**：`可转债定价` `转债波动率套利` `crr定价` `delta对冲` `vega增强`
- **粗判数据**：转债行情 🔵、正股 ✅。⚠️ **融券对冲**对个人投资者门槛高/券源受限；股指期货需开期货账户。
- **适配度**：🟡（定价偏差信号可做多头端；对冲端是卡点，待 L1 评能否做"纯多头低估"降级版）。

### A16. 🟢 宏观择时 / 股债轮动（macro-timing）
- **定义**：用宏观因子（PMI/CPI/M2/利率/信用）做权益仓位择时 + 股债轮动。含货币-经济周期、宏观友好度评分、美林时钟、改良版 ERP、跨周期调节。
- **涉及 tag**：`宏观择时` `股债轮动` `货币-经济周期` `宏观友好度评分` `美林周期` `权益风险溢价` `跨周期调节`
- **粗判数据**：宏观指标 ✅（akshare→金十）、利率 ✅、估值 ✅。
- **适配度**：🟢。低频（月/季），QMT 做股债 ETF 调仓。

### A17. 🟢 资产配置 / 风险平价 / BL（asset-allocation-risk-parity）
- **定义**：多资产（股/债/商/黄金）配置。含风险平价、风险预算、Black-Litterman、全天候、宏观因子配置、因子风险平价、HMM 风险平价。
- **涉及 tag**：`资产配置` `风险平价` `风险预算模型` `black-litterman模型` `全天候策略` `宏观因子配置` `隐马尔可夫风险平价`
- **粗判数据**：股/债/黄金/大宗 ✅（你已有大宗商品期货日线）。商品期货实盘需期货账户（🔵/❌ 待定）。
- **适配度**：🟢（股债黄金 ETF 版本完全可做；扩展到商品期货待定）。

### A17b. 🟢 交易所回购 / 现金管理（repo-cash-management）
- **定义**：GC001/GC007 交易所债券质押式回购套息——利用利率周期性规律（日内尾盘跳水、周四最松、月末偏紧）做现金仓位增益。非月末尾盘买 GC001、月末切 GC007。
- **涉及 tag**：`交易所回购` `固收量化` `资金管理策略` `gc001`
- **粗判数据**：回购利率/行情 ✅（交易所公开）、宏观资金面 ✅。
- **适配度**：🟢。这是**权益策略现金仓位的增益器**——权益策略空仓时的钱不躺平，买回购吃息。独立但横切，和 A24 仓位管理互补。

### A18. 🟢 指数增强（index-enhancement）
- **定义**：在跟踪宽基（300/500/1000）基础上叠加多因子拿超额。是前述因子方向的"组合出口"之一。含中证500增强、生命周期增强、高质量股票池、负向因子剔除。
- **涉及 tag**：`指数增强` `指数增强策略` `多因子模型` `高质量股票池` `负面剔除策略`
- **粗判数据**：成分股 ✅、全维度因子 ✅。
- **适配度**：🟢。是因子研究成果的天然落地形态。

### A19. 🟢 ETF 轮动 / 主题（etf-rotation）
- **定义**：行业轮动/主题投资的 ETF 落地。含 ETF 打分法、聚类打分、跟踪误差优化、概念主题热度、电子行业择时。
- **涉及 tag**：`etf轮动` `行业主题etf` `概念主题投资` `概念热度指数` `跟踪误差优化`
- **粗判数据**：ETF 行情 ✅、概念热度 🔵（同花顺概念）。
- **适配度**：🟢。**QMT 最直接的落地形态**（ETF T+0、费率低）。

### A20. 🟢 技术分析 / 通道 / 形态（technical-channel）
- **定义**：经典技术指标（MA/MACD/RSI/KDJ/布林）+ 通道（Donchian/Bollinger/Keltner）+ K线形态学（华创 61 种形态）系统化为因子。
- **涉及 tag**：`技术面` `通道技术` `bollinger带` `donchian通道` `k线形态学` `技术指标多因子` `均线系统`
- **粗判数据**：日线 OHLCV ✅ 全部够。
- **适配度**：🟢。最易上手，DATA_SOURCES 已有 MACD/RSI/KDJ/布林/VPA。

### A21. 🟡 情绪 / 另类数据（可得部分）（sentiment-alternative-data）
- **定义**：新闻舆情边际变化、概念热度、投资者关注度（股吧/点击量）、月历效应。⚠️ wiki 里另类数据还包括招聘/卫星/ESG争议数据等商业源。
- **涉及 tag**：`另类数据` `新闻舆情` `情绪指标` `概念热度` `月历效应` `投资者关注度`
- **粗判数据**：新闻 ✅（问财/东财）、概念热度 🔵。❌ 招聘数量/卫星/ESG争议数据/股吧发帖量（商业源或难爬）。
- **适配度**：🟡（L1 拆出"可得子集"——新闻舆情/概念热度/月历，其余转🔴分支）。

### A22. 🟢 券商金股 / 机构推荐（brokerage-gold-stock）
- **定义**：跟踪券商月度金股（新进/重复）、行业金股、金股六维评价。新进金股年化显著高于重复金股。
- **涉及 tag**：`金股组合` `券商金股` `新进金股` `金股六维评价` `券商行业金股`
- **粗判数据**：金股名单 🔵（需爬或免费源，待 L1 查 akshare/东财能否拿）。
- **适配度**：🟢/🟡（取决于金股数据可得性）。

### A23. 🟢 机构行为（龙虎榜/调研/大宗）（institutional-behavior）
- **定义**：机构行为的多维信号——龙虎榜机构席位细分（不换手 vs 换手）、机构调研（公募/私募跟踪）、大宗交易折溢价、基金持仓还原。
- **涉及 tag**：`机构调研` `龙虎榜` `大宗交易` `不换手机构专用` `基金持仓还原` `机构行为事件组合`
- **粗判数据**：龙虎榜 ✅、大宗交易 🔵、机构调研 🔵（进门财经/东财）、基金持仓 ✅（季报十大重仓）。
- **适配度**：🟢（核心用龙虎榜+基金持仓；调研/大宗是增强）。

### A23b. 🟢 国家队资金跟踪（national-team）
- **定义**：跟踪中央汇金/证金/社保/外管局等"国家队"六大主体持仓与行为。国家队有独特"股市低位入场、先于高位离场"的逆向特征，与普通机构行为逻辑不同。可做择时信号（国家队市值比 Z-score）+ 选股因子（持仓跟踪）。
