# 量化方向挖掘 · strategy-directions

> 用分层索引法系统性、完整地挖掘 `quant-wiki` 知识库，产出**全量**可行量化方向目录。
> 服务于：A 股个人投资者 + QMT 实盘 + 不碰重 ML / 付费库 + 终极目标实盘盈利。

## 这是什么

把 ~2800 文件的 quant-wiki 压成一份「我能做哪些量化方向」的全量菜单。**不替你砍方向**——全部保留，档位（🟢🟡🔴）只是标注。你拿全量信息自己决定投入哪个。

## 三层结构

| 层 | 文件 | 说明 |
|---|---|---|
| L0 全景地图 | [`00-landscape.md`](00-landscape.md) | 全部候选方向清单（去重归一化） |
| L1 评估卡 | [`cards/`](cards/) | 每方向一张，统一模板 |
| L2 全量目录 | [`catalog.md`](catalog.md) | 按档位分组 + 组合建议 |

规则细节见 [`SPEC.md`](SPEC.md)。

## 如何恢复（任何新会话第一步）

1. 读 [`INDEX.md`](INDEX.md) → 知全局进度、哪些方向待做。
2. 读 [`catalog.md`](catalog.md)（若存在）→ 知已完成卡片的档位汇总。
3. 决定本次做哪 1-N 张 L1 卡，或推进 L2。
4. **永不从零重读 wiki**——做某方向 L1 时，只读该方向对应的 `synthesis` + 2-3 篇 `concept`。

## 数据可得性判定（评估每张卡时套用）

| 档 | 含义 |
|---|---|
| ✅ | 现有（DATA_SOURCES.md 已有） |
| 🟡 | 现有需派生（有原始数据，写代码算） |
| 🔵 | 需补但可得（难度等同接 QMT，能自己写代码稳定拿到） |
| ❌ | 不可得（付费 / 反爬严不公开 / 成本超个人范围） |

**核心数据依赖命中 ❌ → 整卡归 🔴「不适合我」。** 详见 SPEC §4。
