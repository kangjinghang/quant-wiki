## 一句话机制 / 为什么有效
卖方分析师的盈利预测、评级调整、覆盖行为蕴含市场尚未充分定价的信息。alpha 来源 = 信息效率（分析师覆盖越低、关注度越小，边际信息贡献越大）+ 行为偏差（分析师偏乐观→超预期非对称：好消息有效、坏消息无效）+ 关注度溢价。核心是**捕捉信息到达的时序差异**，而非预测本身。

## 研报证据（A 股实证）

| 团队 | 因子 | 关键数字 | 时间窗/池 |
|---|---|---|---|
| 开源金工 FYR_DISP | 盈利预期调整（分歧度标准化+时间加权+股价跟随加权）| ICIR 2.38→**3.14**，优选组合年化超额 26.89%，收益波动比 2.58 | 180 天窗 |
| 开源金工 TR-ICIR | 目标价三因子合成（WTR+MTR+CTR）| 多空年化 14.9%，IR 1.401，月胜率 67.4% | 月频 |
| 开源金工 金股增强 | 分析师预期+理想振幅+小单残差 | 行业金股年化 15.3%→24.8%；新进金股 ICIR 1.42 vs 重复金股 0.39 | 金股池 |
| 华创金工 AAT | 分析师关注度（120日距离加权）| 中证500 RankIC 4.67%，ICIR 1.79，多空年化 12.28% | 120 日 |
| 华创金工 SUE/ESP | 一致预期超预期 | 沪深300 年化超额 20.0%（IR 1.87），中证500 19.18%（IR 1.28）| 月频 |
| 评级变动 | 180天上下调个数差 | 盈利上调池内对冲 ICIR 1.41 | 180 天 |
| 国君配置 行业层 | 9 因子等权（异常覆盖度/预测ROE分位等）| 2010–2022 年化 16.65%，超额 11.44%，IR 1.40 | 行业轮动 |
| 华泰金工 共同覆盖 | 分析师关联改进反转 CF_REV | 中证1000 增强年化超额 16.92%，IR 2.21 | 日/周频 |
| **A 股特殊性** | 超预期**非对称**：超预期做多有效、低于预期不显著跑输（分析师偏乐观）| — | 与海外不同 |

**结论**：分析师预期是 ICIR 普遍 1.4–3.1 的强因子族。**A 股特殊性**：①超预期非对称（只能做多超预期端）②覆盖率从 2016 年 75% 降至 2022 年 50%（注册制+小盘股无覆盖），中小市值适用性收窄 ③行业层比个股层更稳健（IR 1.40，覆盖更均匀）④分析师推荐信号在沪深300 更适合做空而非做多。

| 一致预期 EPS（FY1/2/3/4） | 4 年 EPS 预测、增速、forward_pe、PEG | ✅ | 东财 RPT_WEB_RESPREDICT，已有 |
| 一致预期目标价 | 目标价区间(min,max) | ✅ | 东财，已有（TR-ICIR 用）|

| 分析师关注度 | AAT 需 120 日报告数 + 评级得分时序 | 🟡 | 用覆盖机构数 + 评级分布时序派生（每日落盘）；东财有覆盖机构数 ✅ |
| 异常分析师覆盖度 | 剥离市值后的覆盖度残差 | 🟡 | 覆盖机构数 × 市值横截面回归取残差，派生 |
| 预测 ROE 历史分位 | 行业层因子 | ✅ | 一致预期 ROE + 历史分位，派生 |
| 个股/行业归属 | 行业聚合（行业层因子更稳） | ✅ | 东财 industry，已有 |
| 股价（目标价验证）| WTR 用报告后股价验证分析师 | ✅ | 日线 close，已有 |
| **分析师路演数据** | 进门财经路演频率/文本情绪（首次覆盖超额 13.21%）| ❌ | 另类数据，商业源/难爬，不计入主线 |
| **分析师逐条明细**（共同覆盖关联网络）| 分析师-股票覆盖矩阵（华泰 CF_REV）| 🔵 | 东财有覆盖机构数但无逐分析师明细；关联网络需逐条明细，东财未必稳定给，待验证 |

**数据结论**：✅🟡 核心因子（FYR/评级变动/目标价/关注度/超预期）均可由东财一致预期派生——**但需每日落盘攒历史时序**（FYR/评级变动/AAT 的本质是"变化"，必须有历史序列才能算）。❌ 路演另类数据不可得（剔除）。🔵 共同覆盖关联网络待验证东财是否给逐分析师明细。**关键结构风险：东财覆盖度低于朝阳永续，小盘股常无一致预期**——这限制了因子在小市值的应用（与 wiki 覆盖率下降趋势叠加）。

## 频率 / 持仓周期 → QMT 用法
- **信号频率**：月度调仓为主（FYR/目标价/评级），信号衰减快（"晚一个月基本无收益"），需尽早建仓
- **持仓周期**：1–3 个月（漂移期 + 预期调整消化）
- **QMT 用法**：**盘后批量**。每日盘后拉一致预期 → 算 FYR/评级变动变化 → 月初调仓。**注意信号时效**：研报强调超预期/预期调整信号要尽早买入，QMT 盘后算次日开盘执行正好契合。行业层因子可月/季频。

## 红线检查

| 红线 | 是否触线 | 说明 |
|---|---|---|
| 重 ML | ❌ 不触 | 全是因子打分+ICIR 加权+横截面回归，无 ML |
| 付费库 | 🟡 **需诚实标注** | wiki 多处用朝阳永续（❌ 付费库）；**投资者的源是东财免费一致预期**——核心因子（FYR/评级/目标价）东财能给，覆盖度低但非付费。路演另类数据 ❌ 剔除。故主线不触付费库红线，但覆盖度是限制 |
| 分钟级 | ❌ 不触 | 日线 + 一致预期快照 |
| Level-2 逐笔 | ❌ 不触 | — |

**红线结论**：**主线不触硬红线**（东财替代朝阳永续，核心因子可得）。诚实标注：①wiki 原版用朝阳永续，东财覆盖度更低（小盘股缺失）②路演另类数据 ❌ 剔除 ③共同覆盖关联网络 🔵 待验证。这三点限制了因子在小市值/另类维度的发挥，但核心 alpha 路径（FYR/目标价/评级/超预期）可做。

## 落地难度：中
- **卡点**：
  1. **历史一致预期时序**——FYR/评级变动/AAT 的本质是"变化"，必须有历史序列。需每日落盘东财一致预期（已有 calls 落盘机制可复用），攒够窗口（180 天）才能算因子。**这是启动门槛**——不能即开即用，要先攒数据。
  2. **覆盖度风险**——东财一致预期覆盖度低于朝阳永续，小盘股/新上市股常无覆盖，需在因子计算时处理缺失（如限定有覆盖的股票池，或注册制后用业绩预告/快报补一致预期）。
  3. **信号时效**——衰减快，月初调仓要紧跟财报/分析师调整披露。
- 非数据获取卡点（数据源有），是"攒时序 + 覆盖度处理"工作量。

## 组合潜力（能和哪些方向叠加）
- **+ 事件驱动 PEAD (A5)**：天然互补——超预期看"已发生的超预期"，FYR 看"预期的边际变化"，两者同源（分析师/财报）。
- **+ 景气度/基本面 (A7)**：景气度的预期维度（F1–F3）核心用分析师预期，直接复用本卡因子。
- **+ 行业轮动 (A3)**：分析师预期行业因子（国君 IR 1.40）是行业轮动四路径之一。
- **+ 券商金股 (A22)**：分析师预期是新进金股核心因子（ICIR 1.42），与金股名单组合增强。
- **+ 指数增强 (A18)**：FYR/目标价是中证 500/1000 增强的核心因子。
- **+ 反转 (A2)**：华泰共同覆盖关联反转 CF_REV（若东财明细可得）。

## 档位：🟢 立即可做
核心因子（FYR/目标价 TR-ICIR/评级变动/关注度/超预期）均可由东财一致预期派生，不触红线（东财替代朝阳永续），多团队 A 股实证强（ICIR 1.4–3.1）。**诚实提醒两点**：①需先每日落盘攒一致预期时序（180 天窗口）才能算"变化类"因子，不能即开即用 ②东财覆盖度低于朝阳永续，小盘股缺失，因子更适合中大盘/行业层。这两点不改变"可做"判定，但影响适用范围。

## 落地路径草图
```
1. 信号实现（基于 DATA_SOURCES 现有字段）
   ├─ 前置：每日盘后落盘东财一致预期（EPS/目标价/评级/覆盖机构数）攒历史时序
   │   └─ 复用现有 calls 落盘机制；攒满 180 天后可算变化类因子
   ├─ 因子族（月度计算）：
   │   ├─ FYR_DISP：前后两次一致预期 EPS 变化 / 横截面分歧度标准化
   │   │   └─ 时间加权（半衰期 N=60）+ 股价跟随性加权 → ICIR 目标 3.14
   │   ├─ 评级变动：180 天回看评级上调个数 − 下调个数
   │   ├─ TR-ICIR：目标价 WTR（股价验证加权）+MTR（WTR同比）+CTR（×关注度），ICIR 加权
   │   ├─ AAT 分析师关注度：120 日报告数×评级得分距离加权
   │   └─ 超预期 SUE：实际盈利 vs 一致预期（复用 event-driven 卡的多报告融合）
   ├─ 覆盖度处理：限定有覆盖的股票池；小盘股缺失用业绩预告/快报补一致预期
   └─ 只做多头端（超预期/上调做多 + 下调规避，不做空——分析师偏乐观非对称）

2. QMT 下单
   ├─ 月初盘后算因子排序 → 次日开盘批量调仓
   ├─ 信号时效：紧跟财报/分析师调整披露，尽早建仓
   └─ 行业层因子可季频（覆盖更均匀、IR 1.40）

3. 验证
   ├─ 攒满 180 天时序后回测（对标 FYR_DISP ICIR 3.14、TR-ICIR IR 1.40）
   ├─ 重点验：①东财一致预期覆盖度对因子池的影响 ②变化类因子时序对齐 ③非对称性（多头端有效）
   └─ 先中大盘/行业层跑通，再评估小市值（覆盖度可能不足）
```
