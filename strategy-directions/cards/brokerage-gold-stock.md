## 一句话机制 / 为什么有效
券商分析师每月披露的金股组合，融合了"行业风格选择 + 个股择时"的综合判断——本质是"量化拥抱主动"，把卖方的基本面研究当作 alpha 信号源。核心发现：**新进金股年化显著高于重复金股**（信息发现价值），且金股有时效性（越早调仓越好，信息优势）。alpha 来源 = 分析师的信息优势 + 市场对推荐行为的反应不足。

## 频率 / 持仓周期 → QMT 用法
- **信号频率**：月度调仓（跟随券商月初披露金股）。
- **持仓周期**：月度（每月初调仓）。
- **QMT 用法**：**盘后批量**。月初盘后拉新月股名单→标记新进/重复/多家推荐→叠加因子优化→次日开盘批量调仓。金股有时效性，**越早调仓越好**（信息优势）——建议月初第 1-2 个交易日即完成调仓。

## 落地路径草图
```
1. 信号实现
   ├─ 一次性准备：
   │   ├─ 接入金股名单（akshare stock_em_jggs，东财源）
   │   ├─ 验证字段：股票代码/名称/推荐券商/推荐月份/行业
   │   └─ 建历史金股表（攒 3-6 个月用于算分析师能力 R 值）
   ├─ 每月初盘后：
   │   ├─ 拉本月金股名单
   │   ├─ 标记新进（不在上月名单）/ 重复（在上月）/ 多家推荐（≥N家券商）
   │   ├─ 拉一致预期 EPS（东财 RPT_WEB_RESPREDICT）
   │   ├─ 算交易行为因子（聪明钱/理想振幅/长端动量，日线派生）
   │   ├─ 差异化因子优化：
   │   │   ├─ 新进金股：聪明钱 + 理想振幅 + 分析师预期（ICIR加权，个股权重偏离≤2%）
   │   │   └─ 重复金股：长端动量 + 大单资金流 + 分析师预期
   │   └─ 输出目标持仓清单
   └─ （可选）景气度筛选：剔除低景气行业金股

2. QMT 下单
   ├─ 月初第 1-2 个交易日开盘批量调仓（时效性优先，越早越好）
   └─ 月度持有，次月初刷新

3. 验证
   ├─ 用历史金股名单回测（akshare 可拉历史月度金股）
   ├─ 重点验：新进 vs 重复的收益差异、因子优化增益、时效性（月初 vs 月末介入）
   └─ 小钱实盘 → 加仓
```
