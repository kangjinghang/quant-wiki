## 一句话机制 / 为什么有效
用理论定价模型（CRR 二叉树 / LSMC 蒙特卡洛）给每只转债算"公允价值"，买入**市价低于模型价**的转债（被低估），对冲掉正股 Beta，赚取**隐含波动率修复**（市场对转债期权定价偏低→回归）的绝对收益。alpha 来源 = 定价偏差的均值回归 + 转债期权价值被系统性低估（尤其含下修条款的"免费期权"）。

## 研报证据（A 股实证）
| 团队 | 结论 | 关键数字 | 时间窗 |
|---|---|---|---|
| 招商定量（固收量化之三） | CRR 定价偏差 → 波动率套利，两路径对冲 | **融券对冲费后年化 7.06%/回撤 4.33%**；股指期货对冲回撤>10% | 2022.06 |
| 招商定量（Vega 增强） | 筛高历史波动率正股，增厚 Vega 暴露 | **费后年化 17.97%/回撤 8.47%/回撤比 2.12** | — |
| 招商定量（正股信用增强） | 负面剔除基本面差标的 | 期货版回撤 10%→8.14%，回撤比 1.67 | — |
| 东北金工（LSMC 价差因子） | LSMC 定价偏差选券，转股溢价率中性化 | 多空年化 18.40%/IR 1.80；**多头超额 8.13%/IR 1.40** | 2018-2023 |
| 东吴固收（MC 定价） | MC 内生赎回/回售/下修概率 | 多空周收益 3.72% | — |

**结论**：定价偏差选券（多头端）A 股有效且多团队验证。**但对冲端是硬卡点**——融券对个人门槛高/券源受限（仅覆盖约五成标的），股指期货需期货账户且风格不匹配（转债正股偏中小盘 vs 沪深300 大盘）。**关键判断：可降级为"纯多头低估"版**（只买低估、不对冲），把对冲拆给仓位管理/选股质量承担。

## 数据需求（逐字段）

> 同 convertible-bond 卡：转债专属数据经 akshare（集思录 `bond_cb_jsl` + 东财 `bond_zh_hs_cov_*`）可补（🔵）。定价模型输入的正股波动率/无风险利率/信用利差均可得。

| 字段 | 需要什么 | 档 | 说明 / 来源 |
|---|---|---|---|
| 转债行情+溢价率 | 转债现价、转股溢价率、转股价值、剩余年限 | 🔵 | akshare `bond_cb_jsl`（集思录，已验证字段全） |
| 正股价格 | 正股日线（定价模拟用） | ✅ | DATA_SOURCES 日线 OHLCV |
| 正股波动率 σ | 历史波动率（CRR/LSMC 输入） | 🟡 | 派生：正股日收益 std |
| 无风险利率 r | 国债收益率 | ✅ | DATA_SOURCES 已有 `bond_china_yield` 类（akshare 国债收益率） |
| 信用利差 | 发行人信用风险补偿 | 🟡 | 派生/近似：按评级分档估算（AA/AA+/AAA），不依赖中债估值付费库 |
| 转债条款参数 | 赎回/回售/下修触发条件、转股价 | 🔵 | akshare `bond_cb_jsl`（触发价）+ `bond_cov_issue_cninfo`（初始转股价/转股期） |
| **对冲工具：融券** | 正股融券卖出 | ❌ | 个人投资者**门槛高、券源受限**（可融标的约五成）、成本高 → 对冲版做不了 |
| **对冲工具：股指期货** | IF/IH/IC 空头 | ❌ | 需**商品/金融期货账户**（投资者未提开通）；且风格不匹配、信用风险无法对冲 |
| 正股信用因子（增强） | ROE/净利增速/资产负债率/流动比率/利息保障/OCF | ✅ | DATA_SOURCES 基本面（新浪三表+东财季度）全有 |

**数据结论**：**定价信号（多头端）数据全可补/可得**（🔵 转债行情 + ✅ 正股 + 🟡 波动率派生）。**但完整套利版的对冲工具命中 ❌**——融券个人门槛高、股指期货需另开户。因此：①完整对冲版 = 🔴；②**纯多头低估降级版 = 🟡**（只做定价偏差选券的多头，不对冲，把 Beta 暴露交给仓位管理/择时）。

## 频率 / 持仓周期 → QMT 用法
- **信号频率**：日频/周频（重算定价偏差，CRR/LSMC 计算量中等，全市场百只级可接受）
- **持仓周期**：数周（定价偏差修复期）
- **QMT 用法**：盘后批量。每日盘后拉转债行情+正股 → CRR/LSMC 定价 → 算偏差 → 低估池 → 次日开盘下单。对冲版需盘中动态调对冲比例（个人难做，故降级）。

## 红线检查
| 红线 | 是否触线 | 说明 |
|---|---|---|
| 重 ML | ❌ 不触 | CRR/LSMC 是数值方法（二叉树/蒙特卡洛），非 ML；KNN+OLS 新券定位是轻量统计，可接受 |
| 付费库 | ❌ 不触（信号端） | 转债数据 akshare 免费；定价参数可派生/近似。⚠️ 精确信用利差若要中债估值则 ❌，但可降级为评级分档 |
| 分钟级 | ❌ 不触 | 日线+盘后即可 |
| **对冲工具** | 🔴 **硬卡点** | 融券（个人门槛高/券源受限）+ 股指期货（需期货账户）= **完整对冲版触线** |
| Level-2 逐笔 | ❌ 不触 | — |

**红线结论**：**分裂判定**——
- ❌ **完整对冲套利版**：依赖融券/股指期货对冲，对个人投资者是硬约束 → 🔴。
- 🟡 **纯多头低估降级版**：只做定价偏差选券（CRR/LSMC 低估多头 + Vega 增强 + 正股信用增强剔除），不对冲。alpha 来源仍是定价偏差回归，但承受市场 Beta（交给仓位管理/百元溢价率择时控制）。**这个降级版可做**。

## 落地难度：高（完整版）/ 中（降级版）
- **完整版卡点**：对冲端 ❌（融券门槛+期货账户），无法落地。
- **降级版卡点**：①定价模型实现（CRR 二叉树/LSMC，wiki 有 Python 实现可参考，工作量中等偏重）②转债数据接入（🔵 同 convertible-bond 卡）③定价偏差的稳定性（条款参数估计误差影响大，需校准）。
- **主要工作量**：转债数据层 + CRR/LSMC 定价引擎 + 偏差因子（转股溢价率中性化）+ 信用增强剔除 + 百元溢价率择时控 Beta。

## 组合潜力（能和哪些方向叠加）
- **+ 可转债择券择时 (A14)**：本卡的"低估"信号（CRR/LSMC 偏差）可作为 convertible-bond 多因子框架的一个因子嵌入（[LSMC 价差因子] 本就是转债多因子的成员）。
- **+ 仓位管理 (A24)**：降级版承受 Beta，必须叠 ERP/百元溢价率择时做仓位开关。
- **+ 盈利质量 (A9)**：[正股信用增强] 的剔除逻辑（ROE/资产负债率/偿债）本质是盈利质量因子在转债正股上的应用。
- **+ 宏观择时 (A16)**：转债低估修复依赖权益环境，宏观择时决定整体转债仓位。

## 档位：🟡 需补数据（纯多头低估降级版）
- **完整对冲套利版 = 🔴**：对冲工具（融券/股指期货）对个人是硬约束，不适合。保留理由：写清"为什么对冲版做不了"，并指出降级路径。
- **纯多头低估降级版 = 🟡**：定价信号数据全可补/可得（🔵 转债行情 + ✅ 正股 + 🟡 波动率），不触红线（定价是数值方法非 ML），逻辑有 A 股实证（东北金工 LSMC 多头超额 8.13%/IR 1.40）。补转债数据层 + 实现定价引擎后可做。**建议作为 convertible-bond (A14) 的因子增强嵌入，而非独立策略**——单独跑降级版的 Beta 暴露不如直接做择券择时。

## 落地路径草图（纯多头低估降级版）
```
1. 数据层（同 convertible-bond 卡，🔵 需补已验证可得）
   ├─ akshare bond_cb_jsl() → 转债现价/溢价率/剩余年限/触发价
   ├─ 正股日线（DATA_SOURCES）→ 派生历史波动率 σ
   ├─ 无风险利率：国债收益率（akshare bond_china_yield）
   └─ 信用利差：按评级(AA/AA+/AAA)分档估算（不依赖中债估值付费库）

2. 定价引擎（核心工作量）
   ├─ CRR 二叉树：内嵌强赎/回售条款（触发价→行权判断）+ 信用利差贴现
   │   └─ wiki 可转债定价-综合分析.md 有三模型(BS/二叉树/MC)Python实现参考
   ├─ LSMC（可选，更准但更慢）：正股路径模拟→倒向回归→理论价
   └─ 定价偏差 = (市场价 - 模型价) / 模型价

3. 信号
   ├─ 低估池：偏差 < 阈值（被低估）的转债
   ├─ 转股溢价率中性化：OLS 回归还残差（[LSMC价差因子] 做法）
   ├─ Vega 增强：筛正股高历史波动率（增厚期权修复弹性）
   ├─ 正股信用增强：剔 ROE 低/资产负债率高/偿债差（[正股信用增强策略]）
   └─ 百元溢价率择时控 Beta：>27% 降仓（嵌入 [convertible-bond] 择时）

4. QMT 下单（盘后批量，纯多头）
   ├─ 低估池 → 次日开盘买入
   ├─ 偏差修复（回归模型价）或止损 → 卖出
   └─ 不做对冲（Beta 交给择时/仓位管理）

5. 验证
   ├─ 重点验：CRR 定价误差（对照 wiki 中位 ~5 元）、条款参数校准、偏差因子 IC
   ├─ 对比：降级版 vs 纯双低/分层（看定价偏差是否有增量 alpha）
   └─ 小钱实盘 → 加仓
```
