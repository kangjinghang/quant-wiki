## 一句话机制 / 为什么有效
可转债 = 债底（下行保护）+ 正股看涨期权（上行弹性）。alpha 来源多元且互补：①**估值因子**（转股溢价率/双低）——转债定价非线性，低溢价率品种正股上涨传导效率高，IC 显著；②**正股联动**（动量/振幅/景气）——转债本质是正股变种；③**条款博弈**（下修/赎回/回售）——发行人促转股意愿创造事件收益；④**估值择时**（百元溢价率）——转债市场整体估值有均值回复，27% 以上危险。组合多个低相关策略可显著改善风险收益比（"一加一大于二"）。

## 频率 / 持仓周期 → QMT 用法
- **信号频率**：日频（择券打分）+ 周/月度调仓（分层组合）+ 事件触发（下修/赎回公告）
- **持仓周期**：周至月（趋势/估值修复）+ 事件型（下修博弈数日）
- **QMT 用法**：**盘后批量为主**。每日盘后拉全市场转债快照+溢价率+条款 → 算双低/分层打分/百元溢价率择时 → 次日开盘批量调仓。转债 T+0，QMT 可做日内执行但非必需。

## 落地路径草图
```
1. 数据层（需补，已验证可得）
   ├─ 新建 trading-convertible skill：
   │   ├─ akshare bond_cb_jsl()  → 全市场转债（现价/溢价率/双低/触发价/剩余年限/到期收益）
   │   ├─ akshare bond_zh_hs_cov_spot() → 东财实时快照（兜底/扩字段）
   │   ├─ akshare bond_zh_hs_cov_daily(symbol) → 单券日线
   │   └─ akshare bond_cb_redeem_jsl() → 赎回/下修状态
   ├─ 正股联动复用 DATA_SOURCES 现有源（日线/基本面/行业）
   └─ 派生：百元溢价率（全样本拟合）、正股波动率、退市风险分

2. 信号实现
   ├─ 择券（三策略可叠加/分仓）：
   │   ├─ EasyBall：双低 = 价格 + 溢价率×100，取最低 N 只，叠加正股上行趋势过滤
   │   ├─ 分层组合：按平价溢价率分偏股/平衡/偏债，各层用对应因子（溢价率/振幅差/即期收益率）
   │   └─ 多因子：正股因子(理想振幅) + 联动因子(溢价率/涨跌幅差) + 转债量价(换手率)
   ├─ 择时（决策树/阈值版，非 RL）：
   │   ├─ 百元溢价率 > 27% → 降仓位/转防御
   │   ├─ 甜点转债数 < 55 且中位价 > 127 → 高风险，减仓
   │   └─ 弱势品种表现指标 > 2.5% → 过热预警
   ├─ 事件：下修公告后参与（>2% 绝对收益）；赎回预警剔除
   └─ 风控：退市风险模型剔除（正股基本面+转债条款，用规则版非随机森林）

3. QMT 下单
   ├─ 盘后产出次日目标转债池 + 权重
   ├─ 次日开盘批量下单（转债 T+0，可市价）
   └─ 周/月度调仓

4. 验证
   ├─ 先回测（用集思录历史 + 正股日线）
   ├─ 重点验：条款对齐（转股价调整/下修）、退市剔除、百元溢价率择时阈值
   └─ 小钱实盘 → 加仓
```
