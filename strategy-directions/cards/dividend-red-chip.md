## 一句话机制 / 为什么有效
高股息 + 低波动是经典防御性因子组合：高股息提供安全边际和现金流（类债属性），低波过滤高风险投机股，二者叠加天然抗跌。央企/中特估叠加政策催化（2022.11 证监会提"中特估"，纠正国企长期估值折价）+ 央企 ROE 略高于行业、股息率高于行业但估值低于行业的基本面错配，构成"红利 + 政策重估"双击。alpha 来源 = 价值回归（低估值修复）+ 行为偏差（散户忽视高股息稳健股）+ 政策驱动（中特估）。

## 研报证据（A 股实证）
| 团队 | 结论 | 关键数字 | 时间窗 |
|---|---|---|---|
| 华安金工 红利低波 plus | 红利+低波基石 → 负面清单剔尾（应收异常/特异度高/股价业绩偏离）→ 价值盈利增强 → 波动率倒数加权 | **自 2013 年年化 17.51%**；2018 熊市 −19.09%、2022 熊市 −9.86%（抗跌） | 2013– |
| 央企基本面错配 | 央企 ROE 略高、股息率高于行业、但估值低于行业 | 重估空间 | 国企改革背景下 |
| 央企筛选逻辑 | "国改基本完成的央企 + 估值低 + 涉及经济安全"三重标签 | 信息技术/高端制造/资源品/农产品集中 | — |
| 中特估催化 | 2022.11 证监会提出 → 市场对"中字头"低估值标的关注度显著提升 | 政策催化 | 2022.11 |

**结论**：红利低波 plus 是被华安金工完整验证、抗熊市能力强的成熟组合（年化 17.51% + 熊市抗跌）。央企/中特估提供政策 alpha 加成。适合作为稳健型固收+的权益端核心。

## 频率 / 持仓周期 → QMT 用法
- **信号频率**：月度/季度调仓（红利低波是低换手策略；分红数据季/年频）。
- **持仓周期**：中长期（数月–数年，红利股适合长期持有吃息）。
- **QMT 用法**：**盘后批量 + 月度调仓**。每月盘后更新股息率/波动率/估值/负面清单 → 筛选红利低波 plus 池 → 波动率倒数加权 → QMT 次日开盘批量调仓。可叠加央企/中特估标签做增强子集。

## 组合潜力（能和哪些方向叠加）
- **+ 仓位管理 (A24)**：红利低波 plus 是目标波动率"生息"权益端的最佳素材（中金固收指出的"水土不服"解法）。
- **+ 低波/特质波动率 (A10)**：本方向的"低波"半边就是 A10，天然同源，可共享低波因子。
- **+ 估值/价值因子 (A8)**：价值增强维度与 A8 共用估值因子。
- **+ 宏观择时 (A16)**：红利策略在利率下行/熊市表现突出，与股债轮动天然搭配（红利 = 类债权益）。
- **+ 交易所回购/现金管理 (A17b)**：红利低波 + 现金仓回购 = 完整的"固收+"权益+现金底。
- **+ 国家队资金 (A23b)**：央企是国家队重仓标的，叠加国家队跟踪信号增强。

## 落地路径草图
```
1. 信号实现（基于 DATA_SOURCES 现有字段）
   ├─ 基石筛选（全市场 → 红利+低波股票池）
   │   ├─ 股息率：近12月分红/总市值，排序取高股息
   │   ├─ 低波：20日波动率排序取低波
   │   └─ 交集 = 红利低波基础池
   ├─ 负面清单剔除（剔尾部风险）
   │   ├─ 应收账款占比异常（新浪资产负债表）
   │   ├─ 特异度指标过高（日特质收益波动派生）
   │   └─ 股价业绩偏离度过大（股价收益 vs 盈利增长）
   ├─ 因子增强：叠加价值（PE/PB低/分位低）+ 盈利（ROE高）打分
   ├─ 央企/中特估增强子集（补实控人标签，三重标签筛选）
   └─ 加权：波动率倒数加权（高波动降权）

2. QMT 下单
   ├─ 月度盘后产出目标持仓清单（红利低波 plus 池）
   ├─ 次日开盘批量调仓（低换手，月度）
   └─ 可分两个子组合：纯红利低波 + 央企中特估增强

3. 验证
   ├─ 历史回测重点：熊市抗跌（对标 2018/2022）、年化收益
   ├─ 验负面清单三规则的剔尾效果
   └─ 小钱实盘 → 加仓（适合大钱、长期持有）
```
