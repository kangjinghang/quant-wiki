## 一句话机制 / 为什么有效
盈余公告后，市场对超预期信息**反应不足**（投资者注意力有限、处置效应、信息扩散有延迟），导致股价在公告后数周至数月持续朝超预期方向漂移（PEAD）。做多超预期个股、规避不及预期个股可获超额收益。alpha 来源 = 行为偏差（反应不足）+ 信息不对称。

| 开源金工（魏建榕）超预期 Plus 1.0 | SUE+OER+JUMP+理想反转+残差反转 5 因子 | 多头年化 43.13%，对冲夏普 3.6，月胜率 >80% | — |
| 开源金工 超预期 Plus 2.0 | 加分析师行为修正+交易行为修正 | 年化 40.46%，IR 1.39 | — |
| **A 股特殊性** | PEAD **非对称**：超预期做多有效，做空不显著 | — | 与海外对称漂移不同 |

**结论**：A 股 PEAD 是被多团队反复验证、样本外仍有效的核心 alpha。**只能做多头端（超预期做多 + 不及预期规避），不能做空**。

## 频率 / 持仓周期 → QMT 用法
- **信号频率**：事件触发（财报/预告/快报披露日）+ 月度调仓（分析师调整因子）
- **持仓周期**：数周至数月（漂移期）
- **QMT 用法**：**盘后批量**。每日盘后扫描新披露的业绩公告 + 分析师调整 → 更新超预期股票池 → 次日开盘批量下单。不需要盘中信号。

## 落地路径草图
```
1. 信号实现（基于 DATA_SOURCES 现有字段）
   ├─ 每日盘后：
   │   ├─ 拉业绩预告/快报/定期报告（东财 np-anotice，按重要性分级）
   │   ├─ 拉一致预期 EPS（东财 RPT_WEB_RESPREDICT）
   │   ├─ 多报告融合：同月取最新，补一致预期覆盖不足
   │   ├─ 算 SUE = (实际 - 预期) / σ(历史预期误差)，带漂移项
   │   ├─ 算 OER = 公告日前后超额收益之和
   │   └─ 合成超预期得分（SUE+OER+JUMP+反转，等权或 ICIR 加权）
   ├─ 排序 → 超预期股票池（多头端）
   └─ 剔除不及预期（规避端，不做空）

2. QMT 下单
   ├─ 盘后产出次日目标持仓清单
   ├─ 次日开盘价批量下单（市价或限价）
   └─ 月度调仓（按超预期得分刷新）

3. 验证
   ├─ 先用历史公告数据回测（用 data/cache 落盘的东财响应）
   ├─ 重点验：多报告融合逻辑、SUE 漂移项、公告日对齐
   └─ 小钱实盘 → 加仓
```
