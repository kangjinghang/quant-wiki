## 一句话机制 / 为什么有效
跟踪"聪明钱"——北向资金（尤其配置盘/银行托管）有长期价值发现能力；龙虎榜揭示游资活跃度（左侧信号）；融资融券反映杠杆资金方向。alpha 来源 = 信息优势（外资/机构研究能力强）+ 资金推动（净流入→价格漂移）+ 行为信号（龙虎榜活跃→小盘风格启动）。**关键认知**：北向资金"整体法"已失效，必须穿透到配置盘（银行托管）才有 alpha。

## 频率 / 持仓周期 → QMT 用法
- **信号频率**：日度（龙虎榜 T+1 盘后/融资融券日度）+ 月度（北向行业轮动月末调仓）
- **持仓周期**：周~月（北向配置盘是中期信号）；龙虎榜做择时开关
- **QMT 用法**：**盘后批量**为主。日度盘后扫龙虎榜+融资融券变化 → 月末用北向配置盘行业净流入做行业轮动。北向分钟级可选盘中信号（资金流盘中异动预警），但主线不必盘中。

## 红线检查
| 红线 | 是否触线 | 说明 |
|---|---|---|
| 重 ML | ❌ 不触 | 纯资金流排序/占比 + 换手率分位数，无 ML |
| 付费库 | ❌ 不触（主线） | 北向/龙虎榜/融资融券全免费。⚠️ 逐笔分支需 L2（付费）→ 已转红线 |
| 分钟级 | ⚠️ 部分触 | 北向本身有分钟级（已接），主线用法是日度/月度聚合，不算触"需补分钟K"。逐笔分支需逐笔非分钟K，性质不同 |
| Level-2 逐笔 | ❌ 主线不触 | 主线不依赖逐笔 |

**红线结论**：主线全通过。逐笔分支（ACT/CNIR/大小单）触 ❌（L2 逐笔已移除），转 🔴 分支（见 B29 高频/L2 卡）。

## 落地难度：中
- **卡点**：
  - ①北向托管机构精细拆分难（公开接口粗），需用换手率分位数降级——研报验证有效但精度打折
  - ②北向行业净流入需个股层面北向持股按行业聚合（数据工程，非硬卡）
  - ③龙虎榜指标的"剔除市值前30%大盘股"过滤逻辑、低通滤波参数需实现
- **逐笔分支**：不可做，不投入。

## 组合潜力（能和哪些方向叠加）
- **+ 行业轮动 (A3)**：北向配置盘行业轮动是行业轮动的核心资金面路径（多空年化 8.2%）。
- **+ 大小盘风格轮动 (A4)**：龙虎榜指标做市值因子择时（左侧信号），与动量等右侧信号天然互补。
- **+ 仓位管理 (A24)**：北向净流入波动率作尾部风险规避开关（突破 1.5σ 触发减仓）。
- **+ 国家队资金 (A23b)**：北向 + 国家队 = 两类"聪明钱"叠加，低相关。

## 档位：🟢 立即可做（主线）
主线（北向配置盘 + 龙虎榜 + 融资融券）数据全有、不触红线、研报证据强（北向行业轮动 IR 0.91、龙虎榜胜率 77.78%）。**逐笔资金流因子（ACT/CNIR/大小单）转 🔴**——数据已移除，依赖 Level-2，见高频/L2 卡。

> ⚠️ 诚实标注：主线 alpha 强度（IR 0.91、胜率 77.78%）**弱于**逐笔分支（IR 4.82、年化 35%）。逐笔分支是 wiki 里资金流方向最强的因子，但数据不可得——这是投资者硬约束下的真实代价，不要被 wiki 的高 ICIR 数字误导而忽视数据缺口。

## 落地路径草图（仅主线）
```
1. 信号实现（基于 DATA_SOURCES 现有字段）
   ├─ 【北向行业轮动 · 月度】
   │   ├─ 拉北向持股明细（同花顺，已有分钟级，月末聚合）
   │   ├─ 配置盘/交易盘拆分：用换手率分位数（前40%交易盘/后40%配置盘）替代托管机构硬分类
   │   ├─ 算各行业配置盘净流入占比
   │   ├─ 月末分三组，做多高净流入行业（或 ETF）
   │   └─ 剔除近半数无效行业（煤炭/银行/食品饮料等，研报指出北向择时无效）
   ├─ 【龙虎榜择时 · 日度/月末】
   │   ├─ 拉龙虎榜（东财，T+1盘后，已有）
   │   ├─ 算龙虎榜指标 = 龙虎榜成交额（剔除市值前30%）/ 沪深300成交额
   │   ├─ 低通滤波(d=30)，方向增大→看多小盘/市值因子
   │   └─ 作为大小盘风格轮动的开关信号
   ├─ 【融资融券 · 日度】
   │   ├─ 拉融资融券（东财，已有 1-3-5-10日累计净买入）
   │   └─ 融资净买入连续放量 → 杠杆资金方向确认
   └─ 【风控开关】北向净流入波动率突破 1.5σ → 减仓/止损

2. QMT 下单
   ├─ 北向行业轮动：月末盘后产出目标行业/ETF，次日调仓
   ├─ 龙虎榜择时：月末切换大小盘 ETF 持仓
   └─ 融资融券+北向波动率：盘中/盘后预警触发风控

3. 验证
   ├─ 回测北向行业轮动（对照研报 IR 0.91，验换手率分位数降级版效果折损）
   ├─ 验龙虎榜指标 2017 后胜率（对照 77.78%）
   ├─ 重点验：配置盘降级方案、无效行业剔除、滤波参数
   └─ 小钱实盘 → 加仓
```
