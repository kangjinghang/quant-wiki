## 一句话机制 / 为什么有效
从**日内逐笔成交/委托 + 十档盘口**的微观结构数据中提取短期 alpha（订单失衡、知情交易概率 PIN/DPIN、撤单毒性 TOX、盘口压力），做日内 T+0 或极短周期持仓，赚取微观结构失衡和流动性补偿。alpha 来源 = 知情交易者的信息优势 + 流动性提供者的补偿 + 散户的被动成交。

## 研报证据（A 股实证，展示"有效但个人够不着"）
| 团队/因子 | 结论 | 关键数字 | 数据 |
|---|---|---|---|
| 开源金工 TOX 因子（撤单毒性） | 高频撤单占比识别有毒流动性，收益补偿高 | 多空主要由特定区间贡献；与 Barra 风格低相关 | **逐笔委托** |
| 广发金工 DPIN 因子（动态知情交易概率） | 均值/标准差/稳定性三维 | 周度 IC 0.044，多头年化超额 23.4%，多空 44.3% | **日内高频量价** |
| 国债期货订单流交易 | 订单失衡/堆积识别主力 | — | **盘口切片/逐笔** |
| 张红庆 日内程序化交易 | A 股量化日均成交占比约 30%；AI 程序化（7bps、胜率 60%）仍不及优秀手工（20bps、70%） | 高度依赖 IT 系统能力（tick-to-order 延迟） | **逐笔 + 低延迟** |

**结论**：高频/L2 因子在 A 股实证有效，**但全部建立在逐笔/L2 数据 + 低延迟执行之上**，这是个人投资者的硬墙。

## 数据需求（逐字段）

| 字段 | 需要什么 | 档 | 说明 |
|---|---|---|---|
| **逐笔成交** | 每一笔成交（价/量/时间/方向） | ❌ | **Level-2 逐笔，付费**（券商高阶行情/万得等）。DATA_SOURCES §5 明确：无分钟级 K 线，更无逐笔。 |
| **逐笔委托** | 每一笔挂单/撤单 | ❌ | Level-2 逐笔委托，付费。TOX/TRI 因子核心依赖。 |
| **十档盘口** | 买卖各十档实时挂单 | ❌ | Level-2 十档，付费。订单流交易核心。 |
| 分钟级 K 线 | 日内分钟 OHLCV | 🔵 | QMT 可补分钟K（DATA_SOURCES §5 标注当前无，但可接）。**但分钟级只是高频的"粗降级"，做不了真正的微观结构 alpha**。 |
| 日线 OHLCV | — | ✅ | 已有，但日线是另一个世界（见边界） |
| 低延迟执行通道 | tick-to-order 毫秒级 | ❌ | 个人 QMT 难达标；高频是延迟军备竞赛 |

**数据结论**：**核心数据（逐笔成交/委托/十档）全部 ❌ 付费不可得**。分钟K（🔵）能补但只能做"高频低频化"的粗降级，丢失真正的微观结构 alpha。叠加低延迟执行 ❌，**整支不可做**。

### 为什么 DATA_SOURCES §5 标注的"逐笔资金流已移除"也归到这里
A11 资金流里"大小单逐笔资金流/CNIR/ACT 因子"依赖 Level-2 逐笔，DATA_SOURCES §5 明确"已主动移除（同花顺个股资金流覆盖率天花板过低，深市~1400 只/沪市几乎不收录）"。这部分**本质就是高频/L2 分支**，统一归入本卡 🔴。

## 频率 / 持仓周期 → QMT 用法
- **信号频率**：日内 tick 级 / 秒级 / 分钟级。
- **持仓周期**：日内（T+0）或极短（秒–分钟）。
- **QMT 限制**：QMT 是日线/分钟级批量执行通道，**不是低延迟高频执行通道**。即便有数据，QMT 也做不了毫秒级 tick-to-order。个人做高频需专线 + co-location + 极低延迟系统，非 QMT 定位。

## 红线检查
| 红线 | 是否触线 | 说明 |
|---|---|---|
| 重 ML | ⚠️ 部分触 | 高频因子部分用 DL（StockGNN/全频段融合），但本卡红线主要在数据和执行。 |
| 付费库 | ⚠️ **触线（核心）** | 逐笔成交/委托/十档 = Level-2 付费，**核心数据 ❌**。 |
| 分钟级 | ⚠️ 需更细 | 高频需 tick/秒级，分钟级只是粗降级。 |
| **Level-2 逐笔** | ⚠️ **触线（核心）** | 这是本方向的命门。TOX/DPIN/订单流全部依赖逐笔/L2。 |
| **执行门槛** | ⚠️ **触线** | 高频是延迟军备竞赛，个人 QMT 难达标；专线/co-location 成本超出个人范围。 |

**红线结论**：**多红线齐触**——核心数据（L2 逐笔）❌ + 低延迟执行 ❌。这是个人投资者最硬的墙。

## 落地难度：极高（且被多重红线否决）
- 数据付费 + 低延迟系统 + 算法迭代 + 与机构军备竞赛（机构有专线/co-location/FPGA），个人全方位劣势。

## 组合潜力
- 高频/L2 本身不与个人日线波段组合叠加（不同时间尺度、不同基础设施）。
- **唯一接口**：高频因子的"低频化"（如 DPIN/TOX 降频到周/月）理论上可作日线多因子的增强项，**但因数据 ❌ 仍做不了**。这是边界。

## 档位：🔴 不适合我
**核心数据（Level-2 逐笔/十档）付费不可得 + 日内低延迟执行个人 QMT 难达标 + 与机构延迟军备竞赛全方位劣势**。整支不可做。

## 边界澄清：高频/L2 vs 日线波段（划清你能做的）

> 这张卡的核心价值之一：让投资者明白"日线波段"和"高频"是两个世界，自己站在日线这一侧。

| 维度 | 高频/L2（🔴 本卡，做不了） | 日线波段（🟢 你的战场） |
|---|---|---|
| 数据 | 逐笔成交/委托/十档（L2 付费 ❌） | 日线 OHLCV（✅ 已有） |
| 频率 | tick/秒/分钟 | 日/周/月 |
| 持仓 | 日内 T+0 / 秒–分钟 | 数日–数月 |
| 执行 | 毫秒级 tick-to-order、专线、co-location | QMT 盘后批量 / 开盘下单（✅ 你的通道） |
| alpha 来源 | 微观结构失衡、知情交易、流动性补偿 | 动量/反转/事件/基本面/资金面（你那些 🟢 方向） |
| 竞争对手 | 机构延迟军备竞赛 | 散户+部分机构，信息扩散有延迟（PEAD/动量有效） |

**结论**：你的 QMT + 日线数据，天然适合"数日–数月"波段，不适合"日内高频"。日线世界里 PEAD/动量/反转/行业轮动/红利低波等 alpha 对个人仍有效（因为信息扩散有延迟、散户行为偏差可利用）；高频世界里你与专线机构竞争，毫无胜算。**专注日线波段**。

## 落地路径草图
**🔴 → 为什么做不了**：
```
高频/L2的三重硬墙：
1. 数据墙：TOX/DPIN/订单流的核心数据是逐笔成交+逐笔委托+十档盘口 = Level-2付费。
   DATA_SOURCES §5 明确无逐笔、无分钟K（分钟K🔵可补但只是粗降级）。
   附：A11里"逐笔资金流/CNIR/ACT"也因覆盖率天花板被DATA_SOURCES主动移除，同属此墙。
2. 执行墙：高频是延迟军备竞赛（tick-to-order毫秒级、专线、co-location、FPGA）。
   QMT是日线/分钟批量通道，不是低延迟高频通道。个人无专线/co-location成本优势。
3. 竞争墙：对手是机构量化（专线+顶级IT），个人全方位劣势。
   张红庆：AI程序化(7bps)仍不及优秀手工(20bps)，市场是开放博弈。

→ 即便买得起L2数据，执行和竞争墙仍翻不过。高频对个人无意义。
```

**边界提示（你能做的相邻方向）**：
```
微观结构因子里，有"日线降级版"的属于其他🟢/🟡卡，不属于本卡：
- DPIN/TOX 的日线降级 → A12 微观结构/量价因子（分钟K🔵可补做粗版，但非真正高频alpha）
- 高频PCR信号 → B30 期权信号型（期权日线🔵可做辅助）
- 半贝塔拆解/日内成交量分布 → A12（分钟K降级版）
这些是"用日线/分钟近似微观结构"，alpha衰减但可探索。真正的逐笔L2交易=本卡🔴。
```
