## 一句话机制 / 为什么有效
从**日内逐笔成交/委托 + 十档盘口**的微观结构数据中提取短期 alpha（订单失衡、知情交易概率 PIN/DPIN、撤单毒性 TOX、盘口压力），做日内 T+0 或极短周期持仓。alpha 来源 = 知情交易者的信息优势 + 流动性提供者的补偿 + 散户的被动成交。

## 研报证据（A 股实证）
| 团队/因子 | 结论 | 关键数字 | 数据 |
|---|---|---|---|
| 开源金工 TOX 因子（撤单毒性） | 高频撤单占比识别有毒流动性 | 多空主要由特定区间贡献；与 Barra 风格低相关 | **逐笔委托** |
| 广发金工 DPIN 因子（动态知情交易概率） | 均值/标准差/稳定性三维 | 周度 IC 0.044，多头年化超额 23.4%，多空 44.3% | **日内高频量价** |
| 国债期货订单流交易 | 订单失衡/堆积识别主力 | — | **盘口切片/逐笔** |
| 张红庆 日内程序化交易 | A 股量化日均成交占比约 30%；AI 程序化（7bps、胜率 60%）仍不及优秀手工（20bps、70%） | 高度依赖 IT 系统能力（tick-to-order 延迟） | **逐笔 + 低延迟** |

**结论**：高频/L2 因子在 A 股实证有效，建立在逐笔/L2 数据 + 低延迟执行之上。

## 数据需求（逐字段 · 现状清单）

| 字段 | 需要什么 | 现状 | 说明 |
|---|---|---|---|
| **逐笔成交** | 每一笔成交（价/量/时间/方向） | 🔵 **可补** | QMT xtquant 有 `l2transaction` 接口，**现在没开 L2 权限**。向券商开通 Level-2 行情权限即可取（付费，部分券商达资金量赠送）。 |
| **逐笔委托** | 每一笔挂单/撤单 | 🔵 **可补** | QMT xtquant 有 `l2order` 接口，同上需 L2 权限。TOX/TRI 因子核心依赖。 |
| **十档盘口** | 买卖各十档实时挂单 | 🔵 **可补** | QMT xtquant 有 `l2quote` 接口（千档 `l2thousand`），同上需 L2 权限。订单流交易核心。 |
| 分钟级 K 线 | 日内分钟 OHLCV | 🔵 **可补** | QMT 基础行情**自带免费**（`get_market_data_ex(period="1m")`），开通 QMT 即有，不需额外权限。DATA_SOURCES §5 标注"当前无"是指项目代码里没接，**QMT 侧能力已具备**。 |
| Tick 分笔 | 3 秒五档快照 | 🔵 **可补** | QMT 基础行情自带（`period="tick"`），注意这是 **Level-1 的 3 秒快照含五档**，不是真逐笔。 |
| 日线 OHLCV | — | ✅ 已有 | — |
| 低延迟执行通道 | tick-to-order 毫秒级 | ⚠️ **QMT 受限** | QMT 是日线/分钟级批量执行通道，非毫秒级低延迟高频通道。即便有 L2 数据，QMT 也做不了 tick-to-order 毫秒级。个人无专线/co-location。 |

**数据结论**：逐笔/L2 数据**不是"拿不到"，而是"现在没开权限"**——QMT 通道里有现成接口（l2quote/l2order/l2transaction），向券商开通 L2 行情权限就能取，分界线在行情权限而非平台能力。分钟 K 和五档 tick 是 QMT 自带免费。
**真正的硬限制在执行端**：QMT 不是低延迟高频执行通道，做不了毫秒级 tick-to-order，这是平台定位决定的。

### 为什么 DATA_SOURCES §5 标注的"逐笔资金流已移除"也归到这里
A11 资金流里"大小单逐笔资金流/CNIR/ACT 因子"依赖逐笔数据，DATA_SOURCES §5 明确"已主动移除（同花顺个股资金流覆盖率天花板过低，深市~1400 只/沪市几乎不收录）"——那是**免费同花顺源的覆盖率问题**。若改走 QMT L2 接口，覆盖率不再是问题，但需开 L2 权限。

## 频率 / 持仓周期 → QMT 用法
- **信号频率**：日内 tick 级 / 秒级 / 分钟级。
- **持仓周期**：日内（T+0）或极短（秒–分钟）。
- **QMT 现状**：数据侧（L2 接口）可经权限开通获得；**执行侧受限**——QMT 是日线/分钟批量通道，不是毫秒级高频执行通道。

## 红线检查
| 红线 | 是否触线 | 说明 |
|---|---|---|
| 重 ML | ⚠️ 部分触 | 高频因子部分用 DL（StockGNN/全频段融合），但主要约束在数据和执行 |
| **L2 逐笔数据** | 🟡 **现在没有，可补** | QMT 有 l2 接口，需向券商开 L2 权限（付费/赠送）。不是平台够不着 |
| 分钟级 | 🟡 **现在没接，可补** | QMT 自带免费，项目代码接一下即有 |
| **QMT 执行能力** | ⚠️ **硬限制** | QMT 非低延迟高频执行通道，做不了毫秒级 tick-to-order，这是平台定位 |

## 落地难度：极高
即便开 L2 数据：低延迟执行系统（专线/co-location/FPGA）成本超出个人范围 + 与机构延迟军备竞赛全方位劣势。

## 组合潜力
- 高频/L2 与日线波段不在同一时间尺度，一般不叠加。
- **唯一接口**：高频因子"低频化"（DPIN/TOX 降频到周/月）可作日线多因子增强项——但需先开 L2 数据。

## 档位：🔴 暂不可做（缺数据 + 执行受限）
**不是"永远做不了"，是"现在缺两块"**：
1. **数据**：逐笔/L2 现在没开权限（QMT 有接口，向券商开通可取，非平台能力缺失）；分钟K QMT 自带但项目没接。
2. **执行**：QMT 是批量执行通道，非毫秒级高频通道——这是平台定位的硬限制。

数据可经权限开通解决，执行能力是 QMT 的天花板。这两块补不补、值不值得为高频补，由你判断。

## 边界澄清：高频/L2 vs 日线波段

| 维度 | 高频/L2（本卡，暂不可做） | 日线波段（🟢 现在就能做） |
|---|---|---|
| 数据 | 逐笔成交/委托/十档（QMT 有接口，需开 L2 权限🔵） | 日线 OHLCV（✅ 已有） |
| 频率 | tick/秒/分钟 | 日/周/月 |
| 持仓 | 日内 T+0 / 秒–分钟 | 数日–数月 |
| 执行 | 毫秒级 tick-to-order（QMT 不支持） | QMT 盘后批量 / 开盘下单（✅） |
| alpha 来源 | 微观结构失衡、知情交易、流动性补偿 | 动量/反转/事件/基本面/资金面 |
| 竞争对手 | 机构延迟军备竞赛 | 散户+部分机构，信息扩散有延迟（PEAD/动量有效） |

**数据侧**：L2 是"现在没开权限"而非"拿不到"；**执行侧**：QMT 做毫秒级是平台定位的天花板。

## 落地路径草图
**补数据 + 执行受限的现状**：
```
现状缺口：
1. 数据：逐笔/L2 现在“没开权限”（非“拿不到”）。
   - QMT xtquant 有 l2quote/l2order/l2transaction/l2thousand 接口
   - 向券商开通 Level-2 行情权限即可（付费，部分券商资金量达赠送）
   - 分钟K 是 QMT 基础行情自带免费，项目接一下即有
2. 执行（硬天花板）：QMT 是日线/分钟批量通道，非毫秒级高频执行。
   做不了 tick-to-order，个人无专线/co-location/FPGA。
   → 即便补了 L2 数据，执行端仍翻不过平台定位这堵墙。

高频 T+0 对个人投资者的意义：
- 数据可补（开 L2 权限）
- 执行受限（QMT 定位）+ 与机构军备竞赛全方位劣势
- 是否值得为高频补 L2 数据，由你判断
```

**相邻可做方向（用日线/分钟近似微观结构）**：
```
微观结构因子里有"低频化"版本的，归在其他卡，不属于本卡：
- DPIN/TOX 的分钟降级 → A12 微观结构/量价因子（补 QMT 分钟K🔵可做粗版）
- 高频PCR信号 → B30 期权信号型（期权日线🔵可做辅助）
- 半贝塔拆解/日内成交量分布 → A12（分钟K降级版）
这些 alpha 衰减但数据门槛低。真正的逐笔L2交易=本卡（受QMT执行限制）。
```
