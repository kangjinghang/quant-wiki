# 指数增强

> 方向 slug: `index-enhancement` · 档位: 🟢 立即可做
> wiki 源：`wiki/syntheses/指数增强策略-综合分析.md`（15 篇源）+ concepts: 高质量股票池构造体系 / 负面剔除策略
> ⚠️ **定位**：指数增强不是独立 alpha 源，而是**因子研究成果的落地形态/组合出口**——把 PEAD/估值/盈利质量/动量/反转等因子打包，跟踪宽基拿超额。

## 方向名 / 别名变体
- **主名**：指数增强（中证 500/1000/沪深 300 增强）
- **别名变体**（wiki 概念页，点链接看原文）：
  - [高质量股票池构造体系](../../wiki/concepts/高质量股票池构造体系.md)（光大金工，三层池：原始→刚性(流动性1500)→柔性(负向因子剔除)）
  - [负面剔除策略](../../wiki/concepts/负面剔除策略.md) / [负面清单机制](../../wiki/concepts/负面清单机制.md)（去劣：剔 ST/低流动/财务危机/续亏/立案）
  - 中证 500 基本面因子增强（廖静池，11 大类近 100 因子，年化超额 17.86%/IR 3.65）
  - 行业景气+增强（行业轮动 × 个股因子复合，中证 800 超 25%/中证 1000 超 33.5%）
  - SemiBeta 因子 / UMR2.0 动量反转 / 长端动量 2.0 / 供应链动量（理论驱动因子增强）

## 一句话机制 / 为什么有效
在跟踪宽基指数（300/500/1000）Beta 的基础上，用多因子选股**超配因子分高的成分股、低配/剔除因子分低的**，拿超额收益（alpha）。alpha 来源 = 各因子家族（PEAD 反应不足/估值均值回归/盈利质量/动量惯性/风险定价异常）。指数增强的本质是**把零散的因子研究成果系统化打包成一个可投资组合**——它是因子研究的"出口"，而非新 alpha。超额空间随市值减小而增大：沪深 300（5-8%）< 中证 500（5-18%）< 中证 1000（12-33%）。

**结论**：指数增强是 A 股最成熟的绝对收益策略，多团队验证。**核心共识**：①基本面因子体系仍具韧性，等权加权即可（廖静池 IR 3.65）②市值越小 alpha 越大 ③行业轮动是超额放大器 ④负面剔除（去劣）+ 正面因子（选优）双层结构最稳健。注意：wiki 含遗传规划/神经网络因子挖掘——这些触重 ML 红线，降级为基本面+轻量因子即可。

## 频率 / 持仓周期 → QMT 用法
- **信号频率**：月度/双周调仓（基本面因子月频；量价因子可周频）
- **持仓周期**：月度（因子溢价兑现期）
- **QMT 用法**：**盘后批量**。每月盘后算多因子得分 → 在成分股内超配高分/剔除低分 → 次日开盘批量调仓。需控跟踪误差（限制个股权重偏离）和换手率（降交易成本）。

## 红线检查
| 红线 | 是否触线 | 说明 |
|---|---|---|
| 重 ML | ⚠️ 部分触线 | 主路径（基本面+估值+预期+动量等权/ICIR 加权）❌ 不触。⚠️ wiki 含**遗传规划因子工厂/神经网络多频率因子挖掘**——这些是**重 ML，触线**，降级剔除即可（廖静池基本面版 IR 3.65 不需重 ML）。LightGBM/有序回归属轻量集成，可接受 |
| 付费库 | ❌ 不触 | 全部因子免费源；⚠️ 供应链动量依赖数库科技 SAM（❌ 商业源），该增强项剔除 |
| 分钟级 | ❌ 不触 | 日线 + 月度调仓 |
| Level-2 逐笔 | ❌ 不触 | — |

**红线结论**：主路径（基本面多因子增强）全通过。剔除 GP/神经网络/供应链（重 ML + 付费库）降级版完全可做，且廖静池基本面版 IR 3.65 已极优。

## 落地难度：中
- **卡点**：①因子体系的层次化构建（理论驱动因子作底仓 + 多因子合成）②组合优化（跟踪误差约束 + 换手率控制 + 行业/风格中性）③因子衰减的实盘监控。
- **主要工作量**：是因子研究的**集成工程**——需先把单因子（PEAD/估值/盈利质量/动量）各自跑通，再合成。本质是"前面所有因子方向的汇总落地"。建议先做单因子 IC 检验，再等权/ICIR 合成。

## 组合潜力（能和哪些方向叠加）
- **= 所有因子方向的出口**：[PEAD (A5)](/估值 (A8)/盈利质量 (A9)/动量 (A1)/反转 (A2)/分析师预期 (A6)) 的因子都可注入指增框架。指数增强是这些方向的**天然落地形态**。
- **+ 行业轮动 (A3)**：行业景气信号 × 个股因子复合，超额放大器（中证 800 超 25%）。
- **+ 仓位管理 (A24)**：指增拿超额，仓位管理控 Beta 暴露/回撤。
- **+ 资产配置/风险平价 (A17)**：指增是权益端，风险平价定股债比例。
- **+ 高质量股票池（本卡内）**：负面剔除（去劣）是所有指增的前置过滤层。

## 档位：🟢 立即可做
数据全有（成分股 + 全维度因子 ✅）、主路径不触红线（基本面多因子，剔除重 ML）、研报证据极强（廖静池 IR 3.65）。**推荐作为因子研究的"组合出口"**——但前提是先有若干跑通的单因子。可作为中后期目标：先做 1-2 个单因子方向（如 PEAD/估值），再集成为指增。

## 落地路径草图
```
1. 股票池构造（前置，光大三层框架）
   ├─ 原始池：全市场（akshare stock_info_a_code_name）
   ├─ 刚性优化（保证可交易）：
   │   ├─ 剔 ST（实时快照标记）
   │   ├─ 剔次新股（上市<1年）
   │   ├─ 剔低流动（成交额/换手率后 X%）
   │   └─ 限定到指数成分股（沪深300/中证500/1000，中证指数公司清单）
   └─ 柔性优化（负面剔除，去劣）：
       ├─ 11 个负向因子 ICIR 加权剔除（剔除阈值 4-6%）
       ├─ 财务危机预警（续亏/立案/商誉减值，东财公告）
       └─ 事件型风险（解禁/减持，DATA_SOURCES 已有）

2. 因子体系（多因子合成，本卡=因子方向汇总）
   ├─ 基本面因子：估值(PE/PB分位) + 盈利质量(ROE/应计/现金流) + 成长(营收/净利增速)
   ├─ 预期因子：PEAD(超预期) + 分析师上调（东财一致预期）
   ├─ 量价因子：长端动量 + 反转（日线派生）
   ├─ 合成：等权 或 ICIR 加权（廖静池基本面版 IR 3.65）
   └─ ⚠️ 剔除：GP/神经网络因子（重 ML）、供应链动量（付费库 SAM）

3. 组合优化
   ├─ 在成分股内：超配因子高分、低配/剔低分
   ├─ 约束：跟踪误差(<X%)、行业/风格中性、换手率上限
   └─ 月度调仓

4. QMT 下单（盘后批量）
   ├─ 每月盘后：更新股票池 + 因子得分 → 新权重
   ├─ QMT 批量调仓（控跟踪误差，偏离阈值才调）
   └─ 业绩基准 = 宽基指数

5. 验证
   ├─ 单因子 IC 检验（先证各因子有效）
   ├─ 多因子合成回测（vs 等权/单因子/指数基准）
   ├─ 重点验：跟踪误差、换手率、交易成本侵蚀、因子衰减
   └─ 小钱实盘（先 500 增强，alpha 空间适中）→ 加仓
```
