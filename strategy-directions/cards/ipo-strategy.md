## 一句话机制 / 为什么有效
打新/抢权的 alpha = 一级市场发行价系统性低于二级市场均衡价（核准制下的"隐形红利"，注册制后收窄但仍存）+ 转债上市首日溢价。机制是事件驱动：发行公告→申购/抢权→上市首日卖出。**关键变化**：注册制（尤其 2021.10 询价修订）后破发占比约 25%，无风险打新收益被打破，**必须用多因子判断是否参与**（网下超额认购、投机资金盈余、风口行业、发行估值溢价率）。alpha 来源 = 一二级价差 + 信息优势（机构认购信号）。

## 研报证据（A 股实证）
| 团队 | 结论 | 关键数字 | 时间窗 |
|---|---|---|---|
| 光大金工 量化打新系列一 | 抢权配售期望收益 E 指标有显著分类预测力 | 直接抢权平均收益 **<1%**；提前布局（核准公告后 20 天）**+3.1%** 绝对收益 | 注册制前 |
| 光大金工 量化打新系列二 | 首日卖出仍为最佳策略（首日>5日>20日涨幅递减）；注册制深化期破发常态 | 2021.10-2022.6 破发占比 **~25%** | 2022 |
| 兴证固收 转债策略设计 | 直接抢权难获收益，需提前布局+对冲+精选 | 直接抢权 <1%；提前布局 +3.1% | — |
| 原股东优先配售 | 长期投资者应无条件参与；2021 新规大股东 6 月限售 | 前 10 大股东放弃配售比例中位数 16%→32.63% | 2021 后 |

**结论**：A 股打新/抢权在注册制下从"无脑打"变为"**筛选打**"。①新股打新：首日卖出仍最优，但需用网下超额认购+投机资金盈余+风口行业筛掉高破发风险标的。②转债抢权：直接抢权收益微薄（<1%），**提前布局版（核准公告后介入）才有 +3.1%**。③原股东配售：若已持有正股，无条件参与增厚。

## 数据需求（逐字段）
| 字段 | 需要什么 | 档 | 说明 |
|---|---|---|---|
| 新股/转债发行公告 | 发行日期、发行价、申购代码、网下申购信息 | ✅ | 东财 np-anotice（公告分类含"增发配股"，重要性分级，已有）+ 东财 IPO/转债发行日历 |
| 网下超额认购倍数 | 网下申购总金额/可申购金额 | 🔵 | 公开发布（中证登/交易所公告），公开可得但需爬取/整合。可用作参与否的信号 |
| 上市首日表现 | 新股/转债上市首日涨幅 | ✅ | 东财/akshare 上市首日行情（日线 close） |
| 正股日线（抢权用） | 转债正股 OHLCV + T-2/T-1/T 涨幅 | ✅ | mootdx/akshare 日线 |
| 转债行情 | 转债上市首日价、近 10 只首日涨幅均值 | 🔵 | akshare/东财可拿转债日线（公开，免费），需确认覆盖 |
| 投机资金盈余 | 近期 IPO 募资消耗的资金面指标 | 🟡 | 派生：用近期 IPO 募资金额累计（东财公告）构造，纯计算 |
| 新股发行估值溢价率 | 发行 PE vs 行业 PE | 🟡 | 派生：发行价对应 PE（公告）/ 行业 PE（东财 em_datacenter），纯计算 |
| 风口行业标签 | 新股所属行业是否近期热点 | 🟡 | 派生：用行业近期涨幅排序 + 概念热度 |
| 证监会核准公告日 | 转债提前布局的触发时点 | ✅ | 东财公告（转债发行进度：受理→反馈→过会→核准→发行，公告分类可拿） |

**数据结论**：✅ 核心字段全有（发行公告/正股日线/上市首日/核准公告）。🔵 两项（网下超额认购、转债行情）公开免费但需爬取整合，难度等同接 QMT 分钟 K（自己写代码稳定拿）。🟡 项纯派生。**无 ❌ 缺口**。

## 频率 / 持仓周期 → QMT 用法
- **信号频率**：事件触发（发行公告/核准公告日）
- **持仓周期**：极短——打新 T+0/T+1 卖出（首日卖出）；抢权提前布局持正股~20 天到配售
- **QMT 用法**：**事件触发**。①打新：发行日 QMT 自动申购 → 上市首日开盘/盘中自动卖出。②抢权：核准公告触发 → 买入正股 → 登记日确认配售 → 发行后卖出正股+转债上市卖出。这是 QMT 最适合的"执行型"用法（自动化打新/抢权流程）。

## 红线检查
| 红线 | 是否触线 | 说明 |
|---|---|---|
| 重 ML | ❌ 不触 | 多因子打分（网下认购/估值溢价/风口），无 ML |
| 付费库 | ❌ 不触 | 发行公告/正股/转债行情全免费 |
| 分钟级 | ❌ 不触 | 日线 + 事件日即可 |
| Level-2 逐笔 | ❌ 不触 | — |

**红线结论**：全通过。事件驱动 + 日线，最干净。

## 落地难度：低~中
- **卡点**：数据无硬卡点。主要工作量：
  - ①QMT 自动化打新流程（申购→中签查询→上市卖出）需对接券商打新接口（QMT 支持，但需测试）
  - ②网下超额认购/转债行情的爬取整合（🔵，需写采集脚本）
  - ③抢权"提前布局版"需追踪转债发行进度（核准公告日），比"发行公告日"更早介入
  - ④⚠️ 收益空间收窄：注册制后破发 25%，需严格筛选否则负贡献
- **注意**：这是**收益增强型辅助策略**，不是主力 alpha 源——打新/抢权贡献的是低相关性绝对收益，额度受中签率/配售比例限制。

## 组合潜力（能和哪些方向叠加）
- **横切所有多头策略**：打新/抢权是"**现金仓位增益器**"——任何持仓策略的空闲资金/底仓都可叠加打新，与 A17b 交易所回购同类（现金管理）。
- **+ 可转债 (A14)**：抢权配售是可转债方向的一级市场入口，天然互补。
- **+ 仓位管理 (A24)**：投机资金盈余既是打新信号也是市场情绪指标（资金面过热/过冷）。
- **底仓复用**：若已有红利/指数增强底仓，原股东配售可无成本增厚（持股即享配售权）。

## 档位：🟢 立即可做
数据全有、不触红线、逻辑成熟。⚠️ 诚实标注：注册制后收益空间收窄（破发 25%），需筛选参与；抢权直接版收益微（<1%），只有提前布局版（+3.1%）值得做。**定位为低相关性的收益增强/现金管理，非主力 alpha**。

## 落地路径草图
```
1. 信号实现（基于 DATA_SOURCES 现有字段）
   ├─ 【新股打新 · 事件触发】
   │   ├─ 监听东财公告（np-anotice）：新股发行公告 → 提取发行价/申购日/行业
   │   ├─ 多因子打分决定是否参与：
   │   │   ├─ 网下超额认购倍数（🔵 爬取）→ 高倍数优先
   │   │   ├─ 投机资金盈余（🟡 派生：近期IPO募资消耗）→ 充足时打
   │   │   ├─ 新股发行估值溢价率（🟡 派生：发行PE/行业PE）→ 低溢价优先
   │   │   └─ 风口行业（🟡 派生：行业近期涨幅）→ 风口优先
   │   └─ 通过筛选的标的 → QMT 申购
   ├─ 【转债抢权 · 提前布局版】
   │   ├─ 监听转债发行进度：证监会核准公告日（早于发行公告）
   │   ├─ 提前 20 天布局正股（研报验证 +3.1%）
   │   ├─ 算期望收益 E = 近10只转债首日涨幅均值×1000 − 单位配售资金×max(正股T-2/T-1/T涨幅)
   │   ├─ E > 0 → 参与；E < 0 → 放弃
   │   └─ 登记日确认配售 → 转债上市首日卖出 + 正股择机卖出
   ├─ 【原股东配售】
   │   └─ 已持有正股的转债发行 → 无条件参与配售（增厚）
   └─ 上市首日：QMT 自动卖出（首日>5日>20日，首日最优）

2. QMT 下单（事件触发执行型）
   ├─ 打新：申购日自动申购 → 上市首日开盘/盘中自动卖出
   ├─ 抢权：核准公告触发买正股 → 登记日确认 → 双卖（正股+转债）
   └─ 原股东配售：自动按持股比例配售

3. 验证
   ├─ 回测打新筛选规则（对照注册制后破发率 25%，验筛选能否规避）
   ├─ 验抢权期望收益 E 指标的分类预测力（对照研报）
   ├─ 重点验：QMT 打新接口对接、转债发行进度追踪、提前布局时点
   └─ 小钱实盘 → 加仓（中签率/配售比限制额度）
```
