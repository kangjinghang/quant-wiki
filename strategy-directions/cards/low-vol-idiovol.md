## 一句话机制 / 为什么有效
低波动异象：低风险股票反而收益更高（悖论）。原因 = 高波动股票被套利者拒绝卖空（套利不对称）+ 杠杆约束让高风险偏好者扎堆高波股（需求过度）+ 彩票效应（散户追逐高波股）+ 分析师偏好推荐高波股。**做多低波/低特质波动，规避高波**。VOV 进一步发现"波动率的稳定性"比"波动率水平"更能预测收益（风险越可预测，收益越好）。alpha 来源 = 行为偏差（彩票偏好/过度追逐）+ 套利不对称维持的错误定价。

## 数据需求（逐字段）
| 字段 | 需要什么 | 档 | 说明 |
|---|---|---|---|
| 日线收益率 | 日 OHLCV 算日收益率 | ✅ | mootdx/akshare 日线（120 日，已有 volatility_20d 派生） |
| IVOL（特质波动率） | 个股收益率对市场/FF3 因子回归的残差标准差 | 🟡 | 派生：日线收益率 + 市场指数/规模/价值因子做时序回归取残差，算 60 日标准差。原始数据全有 |
| 低波/振幅因子 | 日收益率标准差 / 日内振幅 | ✅/🟡 | volatility_20d 已有；振幅 = (high-low)/close 派生 |
| 理想振幅因子 | 振幅按价格维度切割 | 🟡 | 派生：振幅 × 价格档位权重，纯日线计算 |
| 复合特质波动率 | FF3 残差 60 日波动率 + 上行/信息维度复合 | 🟡 | 派生：日线残差波动率 + 显著交易日筛选，纯日线（⚠️ 含"大单净流入率"子因子需资金流数据，见下） |
| 显著大单净流入率子因子 | 大单资金流（复合因子的 1/5 子项） | ❌ | 个股逐笔/大单资金流已移除（DATA_SOURCES §5）。**降级处理**：复合因子去掉该子项，用其余 4 项等权 |
| **VOV 增强版**：日内已实现波动率 | 5 分钟收益率序列算已实现波动率 | 🔵 | 需补 QMT 分钟 K（5 分钟线）。当前只有日线 + 北向分钟级，无个股分钟 K |
| **ID_VOV 增强版**：特异性日内收益 | 分钟级收益剥离系统性因子后的特异性已实现波动率 | 🔵 | 同上，需 5 分钟 K |

**数据结论**：
- **日线版（🟢）**：✅+🟡 全部满足，无 ❌（"大单净流入率"子因子可去掉降级）。可立即做 IVOL + 复合特质波动率 + 振幅切割。
- **高频 VOV 版（🟡）**：核心缺**个股 5 分钟 K 线**（🔵 QMT 可补，与接分钟 K 难度相当）。补上后可做 VOV/ID_VOV，效果更强。

## 频率 / 持仓周期 → QMT 用法
- **信号频率**：日度更新（波动率随价变）或周度（降换手）
- **持仓周期**：周~月（波动率因子中等换手）
- **QMT 用法**：**盘后批量**。每日盘后算 IVOL/低波/振幅因子 → 排序选低波池 → 次日开盘批量下单。高频 VOV 版需每日盘后拉分钟 K 重算（数据量增大但仍盘后）。

## 红线检查
| 红线 | 是否触线 | 说明 |
|---|---|---|
| 重 ML | ❌ 不触 | 纯因子模型回归（FF3 OLS）+ 标准差/分位数计算，无 ML |
| 付费库 | ❌ 不触 | 日线 + 指数全免费；分钟 K 走 QMT |
| 分钟级 | ⚠️ **仅 VOV 增强版触** | 日线版不触；VOV/ID_VOV 原版需 5 分钟 K（🔵 可补，非硬否）。日线降级版完全绕开 |
| Level-2 逐笔 | ❌ 不触 | 用分钟 K，不需要逐笔 |

**红线结论**：日线版全通过。VOV 高频版触"分钟级"但属 🔵 可补（非 ❌ 硬否），故整方向 🟢（日线版）/🟡（高频增强）。

## 落地难度：低（日线版）/ 中（高频版）
- **日线版卡点**：几乎无。FF3 残差回归是标准操作。
  - 主要工作量：①搭建市场/规模/价值因子序列做 FF3 回归 ②60 日残差标准差窗口对齐 ③理想振幅的价格档位切割。
- **高频版卡点**：需先接 QMT 5 分钟 K 线（数据工程），之后 VOV/ID_VOV 计算逻辑同日线版（把日收益换成已实现波动率序列）。

## 组合潜力（能和哪些方向叠加）
- **+ 红利 (A26)**：红利低波是经典组合（DATA_SOURCES 有 dividend-lowvol 标签），最稳健的固收+权益端。
- **+ 估值 (A8)**：低估值 + 低波 = 价值防御型。
- **+ 仓位管理 (A24)**：低波因子本身是目标波动率/风控的基础构件。
- **横切应用**：低波/IVOL 是**负向剔除层**的理想候选（剔除高波高投机股，降组合回撤），可叠在所有多头策略上。

## 档位：🟢 立即可做（日线版）+ 🟡 高频 VOV 增强（需补分钟K）
日线版数据全有、不触红线、研报证据强（复合 IVOL Rank IC -9.7%，ICIR -3.63）。**优先做日线版**；若接了 QMT 分钟 K，再做 VOV/ID_VOV 增强版（年化超额 17.83%，更优）。

## 落地路径草图
```
1. 信号实现
   ├─ 【日线版 · 立即可做】每日盘后：
   │   ├─ 拉日线 OHLCV（mootdx/akshare）+ 市场指数/规模/价值因子序列
   │   ├─ 算 IVOL：日收益对 FF3 因子回归取残差，算 60 日标准差
   │   ├─ 算低波：日收益 20/60 日标准差（volatility_20d 已有，可扩 60 日）
   │   ├─ 算理想振幅：日内振幅 (high-low)/close，按价格档位切割加权
   │   ├─ 算复合 IVOL：FF3 残差波动率 + 上行/信息维度复合（去掉"大单净流入率"子因子，用其余项）
   │   └─ 复合：IVOL + 低波 + 振幅 等权或 ICIR 加权 → 低波得分（值越低越买）
   ├─ 【高频版 · 补分钟K后】每日盘后：
   │   ├─ 拉 QMT 5 分钟 K（需先接入数据工程）
   │   ├─ 算日内已实现波动率（5 分钟收益平方和开方）
   │   ├─ 算 VOV = 21 日已实现波动率的标准差 / 均值
   │   ├─ 算 ID_VOV = 剥离系统性因子后的特异性已实现波动率的不确定性（同上）
   │   └─ 用作日线低波因子的增强项
   └─ 输出：低波多头池 + 高波剔除名单（规避端）

2. QMT 下单
   ├─ 盘后产出次日低波池
   ├─ 次日开盘批量下单；周度调仓控换手（波动率因子中等换手）
   └─ 高波剔除名单作为负面剔除层供其他策略共用

3. 验证
   ├─ 先验 IVOL 单因子 IC（对照研报 -9.7%）
   ├─ 重点验：FF3 因子构建口径、残差窗口稳定性、价格档位切割阈值
   ├─ 日线版跑通后，若接了分钟 K 再验 VOV/ID_VOV 增量
   └─ 小钱实盘 → 加仓
```
