## 一句话机制 / 为什么有效
用宏观慢变量（货币松紧/经济景气/通胀/库存/信用）刻画当前经济所处周期象限，据此决定**权益 vs 债券**的配置比例与仓位。alpha 来源 = ①宏观因子对资产回报的系统性解释力（国君六因子模型 R²40-80%，名义利率对 A 股/债解释力最高）；②货币-经济周期对万得全A 月均收益有显著区分度（宽+上 2.56% vs 紧+下 -0.35%）；③A股与国债负相关（股债跷跷板），轮动可降波动。本质是**自上而下的仓位/资产开关**，低频但方向性强。

## 频率 / 持仓周期 → QMT 用法
- **信号频率**：月度/季度（宏观慢变量，PMI/社融月频，GDP 季频）
- **持仓周期**：数月至半年（周期级别）
- **QMT 用法**：**盘后批量 + 低频调仓**。每月宏观数据公布后更新友好度评分/ERP/货币-经济象限 → 调整股债 ETF（如 510300 股票 ETF + 511260 国债 ETF）比例 → QMT 批量调仓。无需盘中信号。

## 落地难度：低
- **卡点**：几乎无。宏观数据全有、逻辑清晰、研报给了完整指标配方（货币-经济四象限/友好度评分/改良 ERP）。
- **主要工作量**：①实现货币-经济周期象限划分（三指标投票×领先扩散指数）或宏观友好度评分（滞胀/滞销/货币缺口加权→分位）②ERP 改良版（利率重构+log 调整）③历史宏观数据回测验证阈值④宽基/债基 ETF 调仓。可先从最简版（ERP 择时单信号）起步。

## 组合潜力（能和哪些方向叠加）
- **+ 所有权益 alpha 方向**：宏观择时是**顶层仓位开关**——友好度评分/ERP 决定权益总仓位，具体买什么交给 PEAD/行业轮动/因子选股。这是它最大的价值。
- **+ 仓位管理 (A24)**：本质重叠——ERP 择时、目标波动率都是仓位层。宏观择时是 A24 的宏观输入。
- **+ 风格轮动 (A4)**：货币-经济周期可驱动成长/价值切换（多空年化 13.8%）。
- **+ 资产配置/风险平价 (A17)**：宏观择时给风险平价的"风险预算"提供动态调整；股债轮动是风险平价的核心组成。
- **+ 可转债 (A14)**：百元溢价率（转债择时）与 ERP（股债择时）互补，转债是股债轮动的落地标的之一。
- **+ 回购现金管理 (A17b)**：宏观择时判空仓时，现金切给回购增益。

## 落地路径草图
```
1. 信号实现（基于 DATA_SOURCES 现有宏观字段）
   ├─ 路径A（最简，ERP 择时）：
   │   ├─ 算标准 ERP = 1/PE_TTM(宽基) - 十年国债收益率
   │   ├─ 改良版：无风险利率重构（国债10Y + 中票AA+近似）+ log 非线性调整
   │   ├─ 布林带择时：ERP 60日均线 ± 2σ → 高位加仓权益/低位减仓
   │   └─ 或跨周期调节指标调整无风险利率后再布林带（[跨周期调节指标]）
   ├─ 路径B（货币-经济周期，开源金工）：
   │   ├─ 货币松紧 = vote(Shibor_3M, 十年国债, M2-社融)
   │   ├─ 经济状态 = 领先扩散指数(金融条件/产出/价格)
   │   ├─ 四象限 → 权益仓位（宽+上 满仓 / 紧+下 空仓）
   │   └─ 隐含变量精细切割（社融/风险溢价）二次分域
   ├─ 路径C（宏观友好度评分，廖静池）：
   │   ├─ 滞胀=景气-通胀(20%) + 滞销=PMI生产-PMI库存(50%) + 货币缺口=社融/M2(30%)
   │   ├─ 合成 → 分位数 → 0-100 评分
   │   └─ 评分>70 满仓 / <20 空仓 / 中间线性
   └─ 合成：多信号加权（ERP + 友好度 + 货币经济象限）

2. QMT 下单（低频调仓）
   ├─ 月度（宏观数据公布后）更新信号
   ├─ 调整股债 ETF 比例（510300 等宽基 + 511260 国债 ETF）
   ├─ QMT 批量调仓（T+0 ETF，费率低）
   └─ 信号无变化则不调

3. 验证
   ├─ 历史宏观数据回测（重点验阈值/象限划分对大顶大底的覆盖）
   ├─ 单信号 vs 多信号合成（看是否稳定提升夏普/降回撤）
   └─ 先小仓位跟踪信号准确性 → 实盘
```
