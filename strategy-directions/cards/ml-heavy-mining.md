## 一句话机制 / 为什么有效
用机器学习/深度学习/进化算法**自动发现**或**端到端预测**股票收益因子，替代人工因子构造。重 ML 的卖点是在低信噪比金融数据上自动提取非线性结构、多频率融合、跨股票关联建模。

## 数据需求（逐字段）

| 字段 | 需要什么 | 档 | 说明 |
|---|---|---|---|
| 日频量价因子 | Alpha101 等人工因子 | ✅/🟡 | 日线可派生 |
| **日内高频特征（核心）** | 分钟级/15分钟/L2 高频价量 | 🔵/❌ | 深度学习因子挖掘的 76 特征来自**日内高频/L2**。分钟K 🔵 可补，但 tick/L2 ❌。多频率 GRU 需 15 分钟K（🔵）。**核心 alpha 在高频端**。 |
| 逐笔成交/委托 | StockGNN/全频段融合需逐笔 | ❌ | Level-2 逐笔付费 |
| GPU 算力 | 训练深度网络/大规模 GP 搜索 | — | 个人 GPU 算力受限，迭代慢 |
| 因子库/标注 | 大规模因子工程基础设施 | — | 个人工程量大 |

**数据结论**：**深度学习因子的核心 alpha 来自高频/L2 数据**（广发 76 特征、华泰 15 分钟融合），而 L2 ❌ 不可得。日频端深度学习的增量 alpha 有限（综合分析明确：日频低频数据上深度模型优势非压倒性）。

## 频率 / 持仓周期 → QMT 用法
- **信号频率**：日度/周度（视模型）。但个人算力下模型迭代慢，且 QMT 是日线/分钟级执行通道，做不了 tick 级预测执行。
- **不适用**于个人实盘（见红线）。

## 红线检查
| 红线 | 是否触线 | 说明 |
|---|---|---|
| **重 ML** | ⚠️ **触线（投资者明确排除）** | 端到端 DL 因子挖掘、Transformer/GRU/GNN 选股、RL 择时、GPT 因子工厂、大规模 GP 搜索——**全部是"重 ML"，投资者明确不碰**。 |
| 付费库 | ⚠️ 部分触线 | 深度学习因子的核心 alpha 来自 L2/逐笔 ❌ 付费。日频端不触，但 alpha 衰减。 |
| 分钟级 | ⚠️ 部分需 | 多频率 GRU 需 15 分钟K（🔵 可补），但配合重 ML 仍触第一条红线。 |
| Level-2 逐笔 | ⚠️ 部分触 | StockGNN/全频段融合需逐笔 ❌。 |
| **算力/工程** | ⚠️ 个人受限 | 深度网络训练 + GP 大规模搜索 + 多智能体迭代，个人 GPU/时间投入产出比极低；且过拟合风险高（综合分析：GP 有多重检验问题、比赛结果实盘难复制）。 |

**红线结论**：**重触"重 ML"红线**（投资者明确排除）+ 部分"付费库/L2"红线。三重障碍使其对个人投资者无意义：(1) 投资者不碰重 ML；(2) 核心 alpha 的高频/L2 数据不可得；(3) 个人算力/工程/过拟合风险投入产出比极差。

## 落地难度：高（且被红线否决）
- 工程量大、算力受限、过拟合风险高、实盘可复制性存疑（综合分析专门讨论"比赛/回测优秀表现能否转实盘"）。

## 组合潜力
- 重 ML 方向本身不与个人实盘组合叠加（被排除）。但其**轻量 ML 子集**可作为其他方向的增强工具（见下方边界判定）。

---

## 🎯 核心贡献：重 ML vs 轻量 ML 边界判定标准

> 投资者"不碰重 ML"≠ "不用任何 ML"。以下是清晰判定。

### 🔴 重 ML（被排除，不碰）
| 类型 | 例子 | 为什么排除 |
|---|---|---|
| **端到端深度学习因子挖掘** | 7层MLP 从高频数据自动提因子、GRU 时序建模 | 端到端黑箱 + 高频数据依赖 + 算力 |
| **Transformer/GNN 选股** | Transformer 量价选股、StockGNN 图网络 | 重架构 + 过拟合风险 |
| **强化学习（RL）择时/交易** | RL 端到端择时、RLHF 交易决策 | 端到端 RL 是投资者明确排除项 |
| **GPT/LLM 因子工厂** | GPT 因子工厂多智能体端到端挖因子 | 全自动黑箱 + LLM 随机性（综合分析：输出随机性 vs 量化确定性冲突） |
| **大规模遗传规划搜索** | GP 穷举表达式空间挖因子 | 多重检验过拟合 + 计算密集 |

### 🟢 轻量 ML（可接受，可嵌入其他方向）
| 类型 | 例子 | 为什么可接受 |
|---|---|---|
| **XGBoost/LightGBM 因子打分** | 用 XGBoost 对已知人工因子做非线性合成/打分 | 树模型结构化表格强、内置正则化、可解释、训练快。综合分析明确：XGBoost 在表格数据上稳健，是集成标配。 |
| **集成学习复合因子** | 多模型加权/Stacking 合成因子 | 降低方差，稳健性基石（综合分析：集成是稳健超额的基石） |
| **AdaBoost / 随机森林分类** | 二分类/排序打分（如基金分类、风险预警） | 经典轻量 ML，可解释 |
| **有序回归/Logistic 用于排序** | 把收益预测转有序分类 | 综合分析推崇："模糊的正确优于精确的错误"，轻量且抗过拟合 |
| **PCA/聚类做降维或分组** | 因子降维、股票聚类 | 无监督、轻量 |

**判定口诀**：
> **"输入是人工因子 + 输出是打分/排序" → 轻量，可用（XGBoost/集成/AdaBoost/有序回归）。
> "输入是原始价量/高频 + 端到端学出因子/决策" → 重 ML，不碰（DL/Transformer/GNN/RL/GP/GPT工厂）。**

**分界线 = 是否端到端从原始数据自动发现特征 + 是否需要重算力/重架构 + 是否黑箱不可解释。**

### 已在其他卡片出现的"轻量 ML 可用"案例（供参考）
- [仓位管理](position-risk-management.md)：拥挤度择时研报用 XGBoost/LSTM，**结论是"不如规则每期做多"**——支持用规则版，轻量 ML 备选。
- [指数成分股调整](index-rebalancing.md)：研报用随机森林增强，**核心效应是事件驱动不依赖 ML**，ML 是可选增强。
- 文本因子（另类数据方向）：FinBERT 提特征 + XGBoost 二次训练——**FinBERT 预训练模型属于轻量使用（不训练大模型，只用现成特征）**，可接受。

## 档位：🔴 不适合我（重 ML 整体排除）
- **重 ML 因子挖掘整体 🔴**：触"重 ML"投资者硬约束 + 高频/L2 数据依赖 + 个人算力/过拟合/实盘可复制性三重障碍。
- **但轻量 ML（XGBoost/集成/AdaBoost/有序回归）可接受**，作为其他 🟢 方向的增强工具，不属于本卡范围。

## 落地路径草图
**🔴 → 为什么做不了（重 ML 整体）**：
```
重ML因子挖掘的三重不可逾越障碍：
1. 投资者硬约束：明确"不碰重ML"（端到端DL/RL/GPT工厂/GP搜索）→ 直接排除。
2. 数据：深度学习因子的核心alpha来自日内高频/L2逐笔（广发76特征、华泰15分钟融合），
   L2逐笔❌付费不可得；纯日频端深度模型增量alpha有限（综合分析结论）。
3. 工程与风险：个人GPU算力迭代慢 + GP/DL过拟合风险高 + 比赛/回测优秀表现实盘难复制
   （综合分析专章讨论可复制性矛盾）。

→ 即便数据齐了，也触投资者第一条硬约束。重ML方向对个人无意义。
```

**🟢 轻量 ML 降级用法（属于其他方向，不在此卡）**：
```
在已选定的🟢方向（如PEAD/行业轮动/红利低波）里，用XGBoost/LightGBM对人工因子
做非线性合成打分，或用集成学习复合因子。这是"轻量ML增强"，不是"重ML挖掘"。
口诀：输入人工因子+输出打分=可用；输入原始数据+端到端=不碰。
```
