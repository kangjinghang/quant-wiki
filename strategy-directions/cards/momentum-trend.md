## 一句话机制 / 为什么有效
买入近期强势、卖出弱势。alpha 来源分两支：(1) **行为金融**——投资者注意力有限、信息扩散有延迟，价格对新信息反应不足 → 趋势延续；(2) **风险补偿**——动量是对承担特质波动的补偿。A 股特殊性在于：散户主导使个股层面呈现**短期反转**为主，需用"振幅切割/残差剥离/行业层"等手段把隐藏在反转里的动量提出来。

## 研报证据（A 股实证）

| 团队 | 结论 | 关键数字 | 时间窗 |
|---|---|---|---|
| 开源金工（振幅切割动量） | 按日度振幅切涨跌幅：低振幅日=动量、高振幅日=反转 | A(λ=70%,N=160) 全市场 IC 0.036 / ICIR 1.31；沪深300 多头年化 9.72%（基准 3.05%）；最优 λ=70% | 2010 起，月调 |
| 开源金工（龙头股模型） | 行业内龙头股牵引普通股，G=R_龙头−R_普通 预测行业收益 | λ=60% 多空年化 12.9%，波动 11.2%，IR 1.15；2.0 版 ND 因子 RankIC 均值 5.37% | 月频/周频 |
| 国君配置（残差动量，行业层） | 剥离三因子后行业残差动量优于传统动量；复合最优 | 2010–2023 多头年化 13.93%；行业层隔夜动量 > 日内动量 | 中长期（剔除近1月） |
| 华泰金工（双因子残差动量，资产配置） | PCA 提市场/风格因子，残差动量是单一信号里对风险平价提升最明显者 | 显著提升 Sharpe/Calmar（跨大类资产） | 12 月窗 |
| 趋势跟踪综述 | A 股趋势平均持续 15–25 天（短于美股 30–60 天）；牛市强、熊市回撤大 | Donchian 20 日通道 Calmar 最优；价量共振择时胜率 52%→58% | 5–20 日 |

**结论**：A 股个股层"裸动量"无效甚至反转（20 日 IC −0.054），但**行业层动量 + 振幅切割提纯 + 残差动量**三条路线均被多团队验证有效。是核心 alpha 家族，但**必须用对提纯方法**，不能直接搬海外 6m-1m。

## 数据需求（逐字段）

| 字段 | 需要什么 | 档 | 说明 |
|---|---|---|---|
| 日线 OHLCV | open/high/low/close/volume/amount（120 日前复权） | ✅ | mootdx+akshare，DATA_SOURCES §2.1 |
| 涨跌幅/动量 | pct_5d / pct_20d / N 日累计收益 | 🟡 | K 线派生，已有 |
| 日度振幅 | (high−low)/prev_close | 🟡 | 振幅切割必需；用日线 H/L 派生 |
| 隔夜收益率 | ln(Open_t / Close_{t-1}) | 🟡 | 隔夜动量必需；用日线 O/C 派生 |
| 行业指数收益 | 申万/中信行业指数日线 | 🟡 | 龙头股/行业动量/残差动量行业版必需；用成分股加权或东财行业指数派生（个股 industry 字段已有 ✅） |
| 行业成交额/成分股 | 按成交额切龙头/普通股 | 🟡 | 龙头股模型必需；用成分股 amount 字段派生 |
| 风险因子（MKT/SMB/HML） | Fama-French 三因子时序 | 🟡 | 残差动量必需；用全市场日线自算（标准三因子构建，无需付费库） |
| 波动率/ATR | volatility_20d、ATR | 🟡 | 趋势跟踪止损/波动率仓位；已有派生 |
| 技术指标 | MACD/RSI/ADX/布林/Donchian | 🟡 | 趋势择时用；已有派生 |
| 通道（Donchian/Keltner） | N 日最高/最低 | 🟡 | K 线派生 |

**数据结论**：✅🟡 全部覆盖。**无缺口、无 ❌**。残差动量需自建三因子（标准做法，全市场日线即可）；供应链/GNN 动量溢出见红线检查（不计入本卡主线）。

## 频率 / 持仓周期 → QMT 用法
- **信号频率**：月度调仓（行业动量/龙头股/残差动量）或日度择时（趋势跟踪/通道突破）
- **持仓周期**：行业层月频；趋势跟踪 5–25 天波段
- **QMT 用法**：**盘后批量**为主（月末算因子排序 → 次日开盘调仓）。趋势跟踪可日度盘后算信号、次日开盘执行。无需盘中信号。

## 红线检查

| 红线 | 是否触线 | 说明 |
|---|---|---|
| 重 ML | ❌ 不触（主线）| 振幅切割/残差动量/龙头股/隔夜动量/趋势跟踪全是规则+回归，无 ML |
| 付费库 | ❌ 不触（主线）| 全用日线 OHLCV + 行业指数（派生），免费 |
| 分钟级 | ❌ 不触 | 日线足够（隔夜动量用日线 O/C 即可，非分钟）|
| Level-2 逐笔 | ❌ 不触 | — |

**红线结论（主线全通过）**。注：[动量溢出效应](../../wiki/syntheses/动量溢出效应-综合分析.md)的三条路径里——供应链动量依赖数库科技 SAM 商业产业链数据（❌ 付费库）、跳跃关联需高频逐笔（❌）、DAM-GAT 是深度学习（❌ 重ML）——**这三条溢出路径均转 🔴，不计入本卡主线**。本卡只评估日线可得的动量提纯路线。

## 落地难度：中
- **卡点**：
  1. **个股裸动量不能直接用**（A 股是反转市场）——必须实现提纯逻辑（振幅切割 / 残差剥离 / 行业层），这是主要工作量。
  2. 残差动量需自建 Fama-French 三因子时序（标准流程，但要有全市场历史日线）。
  3. 行业层动量需先构建行业指数（用现有 industry 字段 + 成分股加权，或接东财行业指数日线）。
- 无数据卡点，全是"代码 + 研究调参"工作量。

## 组合潜力（能和哪些方向叠加）
- **+ 行业轮动 (A3)**：龙头股模型、行业残差动量本身就是行业轮动因子，天然融合。
- **+ 反转 (A2)**：振幅切割的 B 因子（高振幅日）就是反转因子；A/B 两因子天然互补，可同框架产出。
- **+ 事件驱动 PEAD (A5)**：超预期个股的动量确认（双信号过滤假突破）。
- **+ 仓位管理 (A24)**：趋势跟踪 + ATR 止损 + 波动率目标仓位，天然是风控+择时组合。
- **+ 宏观择时 (A16)**：宏观趋势（信贷脉冲/PMI 动量）作为行业动量的顶层方向过滤。

## 档位：🟢 立即可做
数据全有（✅+🟡）、不触红线、逻辑清楚、多团队 A 股实证（振幅切割 ICIR 1.31、龙头股 IR 1.15、残差动量年化 13.93%）。**关键提醒：必须用行业层 / 振幅切割 / 残差提纯版，不能用个股裸动量。** 推荐首批实盘候选（行业动量维度优先，落地最干净）。

## 落地路径草图
```
1. 信号实现（基于 DATA_SOURCES 现有字段）
   ├─ 行业动量（最易上手）：
   │   ├─ 用 industry 字段 + 成分股日线构建行业指数收益序列
   │   ├─ 算行业 N 月动量（剔除近 1 月，国君建议）
   │   └─ 月末排序 → 多头行业池
   ├─ 振幅切割动量（个股层提纯）：
   │   ├─ 日线 (high−low)/prev_close 算日度振幅
   │   ├─ 回看 N=160 日按振幅排序，取低 70%（A 因子）/ 高 30%（B 因子）
   │   └─ A 因子排序选股（动量端）；B 因子交给反转方向
   ├─ 残差动量（进阶）：
   │   ├─ 自建 Fama-French 三因子（全市场日线）
   │   ├─ 个股/行业收益对三因子回归取残差
   │   └─ 取前 12 月残差和（剔除近 1 月）排序
   └─ 龙头股牵引 G 因子（行业层）：行业内按成交额切龙头/普通，G=R_龙头−R_普通

2. QMT 下单
   ├─ 月末盘后算因子 → 次日开盘批量调仓
   └─ 行业层：买行业 ETF / 龙头股；个股层：直接买股票

3. 验证
   ├─ 用 data/cache 历史日线回测三因子构建 + 各动量变体
   ├─ 重点验：行业指数自建是否对齐官方、振幅切割 λ/N 参数敏感性、残差动量三因子构建
   └─ 先证伪个股裸动量（应得反转 IC），再验提纯版
```
