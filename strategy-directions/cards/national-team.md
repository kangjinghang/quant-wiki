## 一句话机制 / 为什么有效
跟踪中央汇金/证金/社保/外管局等"国家队"六大主体的持仓与行为。国家队有独特的**"股市低位入场、先于高位离场"的逆向特征**（资金强度与宽基指数负相关），是 A 股独有的"聪明钱"信号源。用市值比 Zscore 择时（判断入场/退出状态）+ 持仓因子选股（入场期做加仓股动量、存量期做轻仓股防御），构成择时+选股闭环。**数据完全公开（上市公司十大股东披露），且与北向/机构调研低相关**——是分散化组合的独立信号源。

| 中银量化（股价空间因子） | 有基本面支撑的价格反转逻辑；过去一年（250日）回撤深度最佳 | 入场期找"加仓+空间大"弹性品种；存量期找"低配+跌幅大"防御品种 | — |

**结论**：国家队是中银量化系统验证的方向。**核心价值不在绝对收益多高，而在它是与北向/机构调研低相关的独立信号源**——国家队行为逻辑（政策稳定市场）与外资/公募（逐利）完全不同，组合使用能显著分散。逆向择时特征（低位入场、高位离场）是独特的顶层仓位信号。

## 数据需求（逐字段）

| 字段 | 需要什么 | 档 | 说明 |
|---|---|---|---|
| **国家队持仓** | 六大主体（汇金/证金/外管局/社保/大基金/国新）持有非限售股数 | ✅ | **完全公开**：上市公司十大股东/十大流通股东披露（季报/年报），akshare/东财可拉（`stock_gdfx_free_holding_detail`），免费 |
| 国家队主体识别 | 十大股东中识别六大主体 | 🟡 | 派生：维护六大主体及子公司名单（汇金/汇金资管/证金/各证金资管计划/梧桐树/社保各组合/大基金/国新），匹配股东名称 |
| 持仓市值 | 持股数 × 收盘价 | 🟡 | 派生：持仓股数 × 日线 close |
| 宽基自由流通市值 | 中证800自由流通市值 | ✅ | 东财/akshare 指数成分流通市值 |
| 市值比 Zscore | 持仓市值/宽基流通市值比，滚动3年（756日）Zscore | 🟡 | 派生：时序计算，用中位数+标准差 |
| Zscore 斜率 | 近一季度（63日）Zscore 对时间 OLS 回归系数 | 🟡 | 派生：判断入场(>0)/存量(≤0) |
| 持仓市值变动 | 当期-上期持仓市值 | 🟡 | 派生：需连续季度持仓数据 |
| 股价空间因子 | 过去250日最高价/当前价 - 1 | 🟡 | 派生：日线 high 取滚动250日最大值 |
| 个股日线行情 | 收盘价/最高价 | ✅ | 日线 OHLCV，已有 |
| 宽基指数行情 | 中证800日线 | ✅ | 日线 OHLCV，已有 |

**数据结论**：✅ 核心数据（国家队持仓=十大股东披露）**完全公开免费**。🟡 其余全是派生（市值/Zscore/斜率/变动/空间），写代码即可。**无❌缺口，无🔵补数据需求——是数据约束最宽松的方向之一。** 唯一工作量是维护国家队主体名单 + 季度持仓拼接。

## 频率 / 持仓周期 → QMT 用法
- **信号频率**：季度（跟随十大股东披露，季报后更新）+ 择时斜率可日频更新（基于已披露持仓×每日市值）。
- **持仓周期**：中线（季度至半年，跟随国家队行为周期）。
- **QMT 用法**：**盘后批量**。季报披露后更新国家队持仓→重算 Zscore 择时+选股因子→调仓。**注意数据滞后性**：十大股东披露有 1-3 月滞后（季报后），但国家队行为周期长，滞后影响可控。择时斜率可日频刷新（用最新持仓×每日市值）。

## 落地难度：低-中
- **卡点**：①维护国家队六大主体及子公司名单（一次性，公开可查）②季度持仓数据拼接（akshare 拉十大股东，按主体匹配）③数据滞后性的认知（1-3月，但国家队周期长可接受）。
- **主要工作量**：数据接入 + 主体识别。逻辑清晰（中银量化给了完整因子配方：择时+3因子闭环）。

## 组合潜力（能和哪些方向叠加）
- **+ 北向资金 (A11)**：国家队与北向**低相关**——国家队是政策逆向资金，北向是逐利外资，组合使用分散性强。这是本方向最大的组合价值。
- **+ 机构行为 (A23)**：国家队 vs 普通机构（龙虎榜/调研/基金）行为逻辑不同，互为独立信号。
- **+ 仓位管理 (A24)**：国家队市值比 Zscore 是天然的顶层仓位择时信号（国家队入场=市场低位，加仓；退出=高位，减仓）。
- **+ 宏观择时 (A16)**：国家队行为与宏观周期（政策托市）相关，可互相印证。
- **+ 反转 (A2)**：股价空间因子本质是反转因子变体（高点回撤深度）。
- **+ 央企/红利 (A26)**：国家队高度偏好大金融（银行71%），与红利低波/央企方向天然重合。

## 落地路径草图
```
1. 信号实现
   ├─ 一次性准备：
   │   ├─ 维护国家队六大主体名单（汇金/汇金资管/证金/证金资管计划/梧桐树/
   │   │   社保各组合/大基金/国新及子公司），公开可查
   │   └─ 拉 A 股全市场十大流通股东历史（akshare stock_gdfx_free_holding_detail）
   ├─ 季度更新（季报披露后）：
   │   ├─ 匹配国家队主体 → 拼接国家队全持仓（股数×收盘价=市值）
   │   ├─ 算市值比 = 国家队持仓非限售市值 / 中证800自由流通市值
   │   ├─ 算 Zscore = (Ratio - Median(756日)) / Std(756日)
   │   └─ 算持仓市值变动（当期-上期）
   ├─ 日频刷新（基于最新持仓×每日市值）：
   │   ├─ 算 Zscore 斜率（63日 OLS 回归系数）
   │   ├─ 斜率>0 → 入场期；斜率≤0 → 存量/流出期
   │   └─ 切换因子组合：
   │       ├─ 入场期：持仓市值变动（正向）+ 股价空间 → 弹性品种
   │       └─ 存量期：股价空间 + 持仓市值（负向，选轻仓股）→ 防御品种
   └─ 股价空间因子 = max(250日高价)/当前价 - 1

2. QMT 下单
   ├─ 择时层：Zscore 斜率 → 总仓位开关（入场期加仓，存量期防守）
   ├─ 选股层：按当前期因子组合打分 → 目标持仓清单
   └─ 季度调仓（季报披露后）+ 日频仓位刷新

3. 验证
   ├─ 用历史十大股东数据回测（akshare 可拉历史季度数据）
   ├─ 重点验：主体识别覆盖率、Zscore 斜率的入场/退出判断准确性
   ├─ 注意数据滞后性：季报后 1-3 月才拿到，验滞后对信号的影响
   └─ 小钱实盘 → 加仓
```
