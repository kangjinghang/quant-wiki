## 方向名 / 别名变体
- **主名**：景气度 / 基本面量化 / GARP（景气度=边际繁荣度，基本面量化=多维度财务因子体系，GARP=合理价格买成长，三者高度交叉合并）
- **别名变体**（wiki 概念页，点链接看原文）：
  - [复合景气度指标](../../wiki/concepts/复合景气度指标.md)（开源金工，历史财报景气度+预期景气度等权，IC 9.49%，多空年化 19.2%）
  - [动态均衡估值 BET_STD](../../wiki/concepts/动态均衡估值.md)（华安金工，GARP 代理，RankIC −4.7%，ICIR −3.71）
  - [企业生命周期](../../wiki/concepts/企业生命周期.md)（Dickinson 现金流符号法五阶段分域，中证500增强年化超额 16.23%）
  - [景气向上与持续增长策略](../../wiki/concepts/景气向上与持续增长策略.md)（广发金工，ROE+成长+质量+价值多维，年化超额 19.84%）
  - 六维共振框架、财报披露时序效应

## 一句话机制 / 为什么有效
用财务指标（ROE/营收/毛利率/现金流）+ 分析师预期刻画企业或行业的繁荣度与边际变化，在景气拐点介入。alpha 来源 = 基本面分化（盈利能力/成长性的截面差异）+ 信息扩散延迟（财报披露后市场反应不足）+ 生命周期分域（不同阶段因子有效性分化）。核心洞察：**景气变化率（二阶导）> 景气绝对水平**——超额来自边际改善而非绝对高低。

## 研报证据（A 股实证）

| 团队 / 模型 | 方法 | 关键数字 | 时间窗/池 |
|---|---|---|---|
| 开源金工 复合景气度 | 历史财报景气度(PEAD)+预期景气度(戴维斯双击)等权 | IC 9.49%，ICIR 1.60，多空年化 19.2%，IR 1.62 | 行业轮动 |
| 华安金工 BET_STD（GARP）| 动态均衡估值（折现未来盈利的回收期 Z-score）| RankIC −4.7%，ICIR −3.71，多头超额 21.45%（全市场）/11.24%（中证500）| 252日标准化 |
| 华安金工 GARP 优选（固收+权益端）| BET+保守估计法 | 权益端年化 34.25%，夏普 1.18；2018 仅 −10.19%，2022 仅 −6.05% | 2015–2022 |
| 广发金工 景气向上持续增长 | ROE+成长+质量+价值多维，年3次调仓 | 年化 30.32%，超额 19.84%，IR 1.45（vs 中证800）| 2009–2021 |
| 华安金工 企业生命周期增强 | Dickinson 现金流五阶段分域选股 | 中证500 增强年化超额 16.23%；成熟期 PB-ROE 年化超额 23.58% | 分域 |
| 财报披露时序效应 | 早披露公司基本面更好 | 独立 alpha 因子 | 季报披露期 |
| 六维共振 | 盈利质量+成长+估值+资本配置+财务健康+情绪动量 | 多维共振胜率/赔率显著提升 | — |

**结论**：景气度/基本面量化是 A 股多团队验证、IC 普遍 5–9% 的稳健 alpha 家族。**A 股特殊性**：①景气变化率>绝对水平 ②财报季频披露有天然滞后，需用分析师预期/业绩预告补高频 ③生命周期分域后因子有效性分化（成长期用进攻因子、成熟期用 PB-ROE、衰退期用防御因子）④GARP 在震荡市/温和牛市最强，疯牛市因估值约束跑输纯成长。

## 频率 / 持仓周期 → QMT 用法
- **信号频率**：季度调仓为主（跟随财报披露，广发策略年 3 次：4/8/10 月）；月度微调（预期景气度/分析师调整）
- **持仓周期**：季度至半年（景气半衰期 2–4 月）
- **QMT 用法**：**盘后批量**。财报披露季后盘后算多维财务因子 → 选景气向上+估值合理的股票池 → 次日开盘批量调仓。**事件增强**：业绩预告/快报披露日触发即时更新（复用 event-driven 卡的多报告融合）。低频，QMT 适配。

## 红线检查

| 红线 | 是否触线 | 说明 |
|---|---|---|
| 重 ML | ❌ 不触 | 全是财务因子打分+多维共振+Z-score 标准化，无 ML（六维共振是规则加权）|
| 付费库 | ❌ 不触 | 财务三表+一致预期+估值全免费源（东财/新浪/百度）；复合景气度预期维度用东财替代 Wind，覆盖度低但非付费 |
| 分钟级 | ❌ 不触 | 全是季报/日线/月度 |
| Level-2 逐笔 | ❌ 不触 | — |

**红线结论**：全通过。这是最"基本面扎实、数据最干净"的方向之一。

## 落地难度：低–中
- **卡点**：
  1. **多维度财务因子工程**——六维共振/景气向上策略都需从三表派生多个财务比率（ROE 趋势、毛利率改善、投入资产现金回报率等），是主要工作量但数据全有。
  2. **BET 因子成长性估计**——需一致预期增速 + 保守估计法（取预测增速和历史同比较小值），依赖一致预期覆盖度。
  3. **生命周期现金流符号**——需从现金流量表正确提取 OCF/ICF/FCF 符号（大金融板块特殊处理：银行贷款增致 OCF 为负）。
  - 无数据卡点，是"财务因子计算 + 调参"工作量，研报给了完整配方。
- 整体偏低——数据齐全、逻辑透明、研报配方完整。

## 组合潜力（能和哪些方向叠加）
- **+ 行业轮动 (A3)**：景气度是行业轮动四路径之一（本卡聚焦个股/行业景气打分，industry-rotation 卡聚焦行业间配置），高度协同。
- **+ 分析师预期 (A6)**：复合景气度的预期维度直接用分析师预期（戴维斯双击），复用本卡因子。
- **+ 事件驱动 PEAD (A5)**：历史景气度核心捕捉 PEAD（盈余惯性），与超预期策略同源——业绩预告/快报是两者共同的高频输入。
- **+ 估值与价值 (A8)**：BET/GARP 的估值维度与价值因子融合（PB-ROE 成熟期策略）。
- **+ 指数增强 (A18)**：生命周期分域增强（中证500 超额 16.23%）、景气向上（中证800 超额 19.84%）是指数增强的核心因子来源。
- **+ 宏观择时 (A16)**：GARP 权益端 + ERP 风险预算资产配置 = 固收+ 绝对收益产品（华安验证）。

## 档位：🟢 立即可做
数据全有（✅+🟡，无 ❌）、不触红线、基本面最扎实、多团队 A 股实证强（IC 5–9%、年化超额 16–34%）、低频季调适合 QMT。**推荐作为首批实盘候选**——尤其 GARP/景气向上策略，攻守兼备（2018/2022 熊市回撤可控），适合作为组合的"核心持仓底仓"。

## 落地路径草图
```
1. 信号实现（基于 DATA_SOURCES 现有字段）
   ├─ 财务因子工程（从三表派生）：
   │   ├─ 盈利：ROE（趋势向上）、毛利率（改善）、净利率
   │   ├─ 成长：营收/净利同比增速、持续增长
   │   ├─ 质量：OCF净利比、投入资产现金回报率、资产负债率
   │   └─ 现金流符号：OCF/ICF/FCF 符号 → 企业生命周期五阶段（大金融特殊处理）
   ├─ 四条可选策略（按复杂度）：
   │   ├─ A. 景气向上持续增长（广发，最直接）：
   │   │   └─ ROE高且向上 + 营收/利润持续增长 + 毛利率改善 + 现金回报高 + 估值合理
   │   │       → 年3次调仓（4/8/10月，财报披露后），选 ~50 只
   │   ├─ B. GARP / BET_STD（华安，攻守兼备）：
   │   │   ├─ BET = 折现未来盈利的回收期（一致预期增速，保守估计法取 min(预测,历史)）
   │   │   └─ BET_STD = BET 过去 252 日 Z-score → 选低 BET_STD（回收快）
   │   ├─ C. 复合景气度（开源，行业层）：
   │   │   ├─ 历史景气度：业绩预告/快报/定期报告高频聚合（PEAD）
   │   │   ├─ 预期景气度：分析师预期边际变化（戴维斯双击）
   │   │   └─ 等权合成 → 行业景气打分
   │   └─ D. 生命周期分域增强（华安，进阶）：
   │       └─ 按现金流符号分五阶段 → 成长期用进攻因子、成熟期用 PB-ROE、衰退期用防御
   └─ 财报披露时序：早披露公司加分（独立 alpha）

2. QMT 下单
   ├─ 财报披露季后盘后算多维因子 → 选股池
   ├─ 次日开盘批量调仓（季频，费率影响小）
   └─ 业绩预告/快报披露日触发即时更新（事件增强）

3. 验证
   ├─ 用历史季报回测（对标景气向上超额 19.84%、BET ICIR 3.71、生命周期增强 16.23%）
   ├─ 重点验：①三表现金流符号正确性（尤其大金融）②BET 一致预期覆盖度 ③生命周期分域因子适用性
   └─ GARP 优先跑（攻守兼备），稳定后扩展复合景气度/生命周期分域
```
