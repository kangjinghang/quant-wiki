## 一句话机制 / 为什么有效
A 股利润表"营业利润"口径脏（含投资收益、公允价值变动、政府补贴），可被操纵。盈利质量因子从三大报表提纯"**不易操纵、跨报表自洽**"的指标（核心利润、异常现金流、应计利润），做多高质量、规避操纵型公司。alpha 来源 = 市场对"表面利润"反应过度、对"利润含金量"反应不足 + 操纵型公司后续业绩塌方。

## 研报证据（A 股实证）
| 团队 | 结论 | 关键数字 | 时间窗 |
|---|---|---|---|
| 中银量化 财报因子框架 | 不易操纵 + 跨报表验证 + 聚类优选 7 因子 | B/P 中性化后选出 7 个单因子（ROA 变形/现金资产匹配/盈利增长/战略扩张） | — |
| 申万宏源 真实盈余管理 | 异常经营现金流 ABCFO 因子 | 全 A 多空年化 ~14%；季度版更稳；与风格因子相关性 <15%（独特 alpha）；食品/医药/交运最有效 | 含 2021 回撤 |
| 中银量化 核心利润 | 核心利润及同比/环比边际变化 | 多因子选股表现优异（纳入价值盲区掘金因子） | — |
| 光大金工 财务危机预警 | 45 指标 WOE 打分，剔最低 10% | 剔除后沪深300 年化超额 **12.50%**、中证500 **13.62%**；2016 注册制后预警更佳 | 2022.05 |

**结论**：A 股盈利质量因子是被多团队验证的稳定 alpha。**强项是"规避端"**——财务危机预警剔除（年化超额 12-13%）和真实盈余管理规避，比单纯做多更稳。与常见风格因子相关性低（独特信息）。

## 数据需求（逐字段）
| 字段 | 需要什么 | 档 | 说明 |
|---|---|---|---|
| 利润表 | 营收/毛利/营业利润/净利/三费/投资收益/公允价值变动/资产减值 | ✅ | 新浪 lrb（利润表） |
| 现金流量表 | 经营/投资/筹资活动现金流、明细科目 | ✅ | 新浪 llb（现金流量表） |
| 资产负债表 | 总资产/净资产/应收/存货/商誉/有息负债 | ✅ | 新浪 fzb（资产负债表） |
| 核心利润计算项 | 毛利、税金及附加、销售/管理/财务费用 | 🟡 | 派生：从利润表逐项取，公式 = 毛利−税金−三费 |
| 异常现金流 ABCFO | 经营现金流对营收的 OLS 回归残差（Roychowdhury/Cohen 模型） | 🟡 | 派生：需用历史季度面板做截面回归算正常水平，取残差。原始字段（CFO/营收/营收变化）全有，纯计算 |
| ROE/ROA/毛利率 | 季度趋势 | ✅ | 东财 em_quarterly（revenue_yoy/net_profit_yoy/roe/gross_margin 近4季） |
| OCF/净利比 | 盈利质量（经营现金流/净利润） | ✅ | 新浪三大报表 + DATA_SOURCES 已有"OCF净利比"派生 |
| 财务危机 45 指标 | 偿债/营运/盈利/现金流多维度 | 🟡 | 派生：从三表组合出 45 个比率（负债率/流动/速动/OCF/CapEx/周转率等），字段全有 |

**数据结论**：✅ 核心全有（三大报表新浪源已落盘），🟡 项都是"有原始数据、写代码派生"（核心利润=逐项加减、ABCFO=面板回归残差、危机评分=比率组合）。**无 ❌ 缺口**。这是纯基本面方向，数据最干净之一。

## 频率 / 持仓周期 → QMT 用法
- **信号频率**：季度刷新为主（财报披露后），季度因子比年度因子更稳（申万宏源结论）
- **持仓周期**：季~半年（财务因子变化慢）
- **QMT 用法**：**盘后批量**。每季度财报披露季（4/8/10月）盘后批量重算盈利质量打分 → 更新高质量池 + 操纵/危机剔除名单 → 次日调仓。不需要盘中信号。

## 红线检查
| 红线 | 是否触线 | 说明 |
|---|---|---|
| 重 ML | ❌ 不触 | ABCFO 是 OLS 回归（轻量统计，不算 ML）；财务危机评分用 WOE 分箱（规则型）。中银框架提"集成学习复合"，但那是增强可选，基础因子纯规则 |
| 付费库 | ❌ 不触 | 三大报表全用新浪免费源 |
| 分钟级 | ❌ 不触 | 纯季度财务 + 日线（若加估值过滤） |
| Level-2 逐笔 | ❌ 不触 | — |

**红线结论**：全通过。纯基本面 + 轻量统计。⚠️ 仅注意：中银"集成学习复合因子"那步算轻 ML（可接受），但不是必需——基础可用等权/ICIR 加权。

## 落地难度：低~中
- **卡点**：数据无卡点。主要工作量在**派生逻辑**：
  - ①ABCFO 需搭建季度面板做截面 OLS 回归（Roychowdhury 模型），比简单比率复杂
  - ②核心利润要正确解析利润表科目（A 股报表格式有口径变更历史，需注意 2018 后新准则）
  - ③财务危机 45 指标工程量中等，但 WOE 分箱逻辑明确
- **建议**：先做最简单的 OCF净利比 + 核心利润同比/环比，再逐步加 ABCFO。

## 组合潜力（能和哪些方向叠加）
- **+ 估值 (A8)**：低估值 + 高盈利质量 = 经典价值增强（最自然组合，规避价值陷阱）。
- **+ 景气度 (A7)**：盈利质量是景气度的"含金量"过滤（高景气但低质量→剔除）。
- **+ 事件驱动 PEAD (A5)**：超预期 + 高盈余质量 = 真·超预期（过滤掉靠操纵"做出来"的超预期）。
- **+ 指数增强 (A18)**：财务危机预警剔除是高质量股票池的核心组成（光大体系）。
- **横切应用**：盈利质量因子更适合做**剔除/规避层**（负面剔除策略），叠在所有多头策略之上降回撤。

## 档位：🟢 立即可做
数据全有（三大报表）、不触红线、研报证据强（财务危机剔除年化超额 12-13%、ABCFO 独特 alpha）。**强项在规避端**，适合做高质量股票池的基础设施。

## 落地路径草图
```
1. 信号实现（基于 DATA_SOURCES 现有字段）
   ├─ 每季财报披露后盘后：
   │   ├─ 拉三大报表（新浪 fzb/lrb/llb）+ 季度趋势（东财 em_quarterly）
   │   ├─ 算核心利润 = 毛利 − 税金及附加 − 销售/管理/财务费用
   │   ├─ 算核心利润同比/环比边际变化（中银验证有效）
   │   ├─ 算 OCF净利比（已有派生）+ 自由现金流占比
   │   ├─ ABCFO（进阶）：用 Roychowdhury 模型对 CFO~营收+营收变化做截面 OLS，取残差
   │   ├─ 财务危机评分（进阶）：45 指标 WOE 打分，标出最低 10%
   │   └─ 复合：核心利润边际 + OCF净利比 + ABCFO（等权或 ICIR）
   ├─ 输出：高质量多头池 + 操纵/危机剔除名单
   └─ 剔除名单作为"负面剔除层"供其他策略共用

2. QMT 下单
   ├─ 季度调仓为主（4/8/10 月财报季批量重算）
   ├─ 盘后产出次日目标池，开盘批量下单
   └─ 剔除名单实时过滤其他策略持仓

3. 验证
   ├─ 先验 OCF净利比 + 核心利润单因子 IC（对照研报）
   ├─ 重点验：ABCFO 面板回归的截面设定、报表科目口径（2018 新准则）
   └─ 剔除层：回测剔除危机预警 10% 后组合回撤改善
```
