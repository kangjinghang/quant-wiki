## 一句话机制 / 为什么有效
交易所债券质押式回购（GC001/GC007）利率有显著的**周期性规律**——日内尾盘（下午 3 点后）闲置资金集中释放致利率跳水、周四最松、月初/月中缴税/月末跨月偏紧。作为**资金借出方（逆回购）**，在这些规律的低息时点（尾盘/周四）按加权价买入 GC001，可稳定获得高于活期的现金收益；月末切 GC007 锁定成本。alpha 来源 = 资金供需的日内/周内/月内周期性（结构性，非零和）+ 尾盘流动性溢价。本质是**把闲置现金的收益率从活期（~0.3%）提升到回购（~1.5-3%，月末冲高时更高）**。

## 频率 / 持仓周期 → QMT 用法
- **信号频率**：每日尾盘（14:50-15:00）+ 月末品种切换（23 号起）
- **持仓周期**：T+0/T+1（GC001 隔夜）/ 7 天（GC007 跨月）
- **QMT 用法**：**盘中自动化（尾盘触发）**。这是少数需要**盘中信号**的方向——每日 14:50 检查：非月末 → 尾盘自动买 GC001；月末(23号起) → 切 GC007。规避早盘股市大涨(>1.2%)日。QMT 定时任务执行。

## 红线检查
| 红线 | 是否触线 | 说明 |
|---|---|---|
| 重 ML | ❌ 不触 | 纯规则（日历 + 阈值），无 ML |
| 付费库 | ❌ 不触 | 回购行情公开（QMT/交易所），资金面免费 |
| 分钟级 | ⚠️ 需尾盘时点 | 需要在 14:50-15:00 尾盘下单——但这是**定时执行**（QMT 定时任务），不是高频信号/低延迟，QMT 完全能做 |
| Level-2 逐笔 | ❌ 不触 | — |

**红线结论**：全通过。唯一注意是需尾盘定时下单（QMT 定时任务即可，非高频）。

## 落地难度：低
- **卡点**：几乎无。规则简单、数据简单、QMT 可直接交易 GC 品种。
- **主要工作量**：①写一个 QMT 定时任务（14:50 触发）②判断月末/规避日③自动下单 GC001/GC007。是最快能落地的方向。

## 组合潜力（能和哪些方向叠加）
- **+ 所有权益方向（仓位空仓时）**：这是它**唯一的价值**——任何权益策略（PEAD/行业轮动/因子选股）在空仓/低仓时，闲置现金切给回购吃息，不躺平。
- **+ 仓位管理 (A24)**：仓位管理决定权益仓位高低，本方向管"非权益那部分现金"的增益。**天然互补**（A24 管风险/仓位，本方向管现金收益）。
- **+ 宏观择时 (A16)**：宏观择时判空仓时，现金切给回购。
- **+ 资产配置/风险平价 (A17)**：风险平价的"低风险/现金"权重可切给回购，替代纯现金拖累。
- **⚠️ 独立价值有限**：单独跑（全仓回购）只是货币基金替代，不是量化 alpha。它的价值在**嵌入其他策略的现金仓位**。

## 档位：🟢 立即可做
数据全有（QMT 直接交易 GC）、不触红线、规则极简、确定性高。**最快落地的方向**——建议作为所有权益策略的"现金仓位默认归宿"先行搭建。它本身不是高收益策略，但能把闲置资金的活期收益（~0.3%）提升到回购水平（~1.5-3%，月末更高），是免费的收益增厚。

## 落地路径草图
```
1. 信号（纯规则，无数据复杂度）
   ├─ 每日 14:50 定时触发（QMT 定时任务）
   ├─ 判断日历状态：
   │   ├─ 月末(每月23号起至月底) → 买 GC007（跨月，锁成本）
   │   ├─ 非月末 → 买 GC001（尾盘低息点吃息）
   │   └─ 规避日：早盘中证800 涨幅>1.2% / 周五尾盘 / 节后首日 → 不借出（或推迟）
   ├─ 辅助：DR007/Shibor 早盘情绪（>65 高点则少配/<35 低点则多配，可选增强）
   └─ 金额 = 当前现金仓位（权益策略空仓/低仓释放的闲置资金）

2. QMT 下单（盘中尾盘自动化）
   ├─ 14:50 触发 → 自动下单 GC001/GC007 逆回购
   ├─ 按尾盘加权价（资金供给充裕，利率跳水点）
   └─ T+1 资金到账可循环（GC001）/ 7 天后到账（GC007）

3. 验证
   ├─ 用历史回购利率回测日内/周内/月内规律（确认 wiki 结论在当前市场仍成立）
   ├─ 重点验：月末 GC001 利率飙升幅度、尾盘跳水时点稳定性
   └─ 实盘直接跑（风险极低，货币市场工具）

4. 嵌入（关键）
   ├─ 与仓位管理/宏观择时联动：权益仓位 = X% → 剩余 (1-X%) 现金自动进回购
   └─ 作为所有权益策略的"现金仓位默认归宿"
```
