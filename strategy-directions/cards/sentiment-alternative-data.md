## 一句话机制 / 为什么有效
用传统量价之外的非结构化/半结构化数据（新闻舆情、概念热度、月历规律、社交关注度、招聘数据）捕捉增量 alpha。核心规律：**市场对信息的"边际变化"比"绝对水平"更有定价意义**（ΔMS 因子），且低关注度股票有认知补偿溢价（投资者认知假说）。但另类数据**获取难度差异极大**——必须拆分可得子集 vs 不可得子集。

## 研报证据（A 股实证）
| 团队 | 结论 | 关键数字 | 数据源（可得性） |
|---|---|---|---|
| 开源金工（新闻舆情 ΔMS） | 舆情**边际变化**有效，绝对水平无效；中证500最优，N=20 | 双周频多空年化 12%，ICIR -2.3；剔除10因子残差 ICIR -2.27 | 通联数据 ❌→**可降级**（见下） |
| 华安金工（社交媒体 SMF） | 低发帖量-高发帖量多空；认知补偿溢价 | 样本外年化 ~32%，夏普 1.168 | 东财股吧发帖量 ❌（难爬） |
| 开源金工（招聘数量因子） | 高成长域 IR 1.46，多头超额 ~15% | 全域 IR 1.15 | 通联数据 ❌（商业另类） |
| 招商定量（概念热度异动） | 热度破布林上轨触发，结合多因子 | 120日超额 4%→7%+，事件驱动年化超额 11.61% | 同花顺热度 🔵 |
| 月历效应（大小盘/转债） | 2月小盘占优（春节效应）；1/4/8/10月规避小盘暴雷 | 2010 以来 2 月均小盘占优（除2024） | 日线派生 ✅ |

**结论**：另类数据的 alpha 真实存在（ΔMS/SMF/招聘/概念热度均有显著 IC），但**核心数据源多为商业另类（通联数据）或难爬取（股吧发帖量）**，对个人投资者大量转🔴。**可得子集 = 新闻舆情边际变化（降级版）+ 概念热度 + 月历效应**，这三块可做。

## 数据需求（逐字段）—— 必须拆分

### 🟢 可得子集（本卡可做部分）

| 字段 | 需要什么 | 档 | 说明 |
|---|---|---|---|
| 新闻舆情分数（降级版） | 个股新闻的情感倾向/热度 | 🟡 | DATA_SOURCES 已有个股新闻（问财+东财，title/content/time/source）。**降级版**：用新闻条数边际变化 + LLM 情感打分替代通联商业打分——这是关键创新点 |
| ΔMS 因子 | 过去 N=20 天舆情均值变化量 | 🟡 | 派生：基于上述降级舆情分数算 |
| 月历效应 | 大小盘/行业月度胜率 | ✅ | 日线 OHLCV 派生（沪深300/中证2000 月度收益） |
| 概念热度（降级版） | 概念受关注程度 | 🔵 | 同花顺概念热度可爬；或用龙虎榜 reason 频次/热门股 reason 近似 |

### 🔴 不可得子集（转 ❌，本卡不做）

| 字段 | 需要什么 | 档 | 为什么不可得 |
|---|---|---|---|
| 招聘数量因子 | 上市公司月度新增招聘广告总量 | ❌ | 通联数据商业源，个人拿不到；招聘网站无标准 API |
| 社交媒体因子 SMF | 东财股吧月度发帖量 | ❌ | 东财股吧反爬严、无 API、不稳定爬取，且发帖量含大量噪声 |
| 卫星/ESG争议数据 | 另类商业数据 | ❌ | 付费商业另类，成本超个人范围 |
| 投资者点击量/自选股 | 同花顺脱敏点击量 | ❌ | 平台内部数据，不对外开放（synthesis 笔记明确"部分平台数据仅供内部使用"） |

**数据结论**：**混合**。可得子集（新闻舆情降级 + 概念热度 + 月历）🟡/🔵/✅ 可做；不可得子集（招聘/股吧发帖量/卫星/点击量）❌ 转🔴分支。**关键：新闻舆情 ΔMS 的"降级版"——用已有新闻数据 + LLM 情感打分替代通联商业数据——是本方向最有价值的突破口。**

## 频率 / 持仓周期 → QMT 用法
- **信号频率**：ΔMS 双周频（开源金工最优）；月历效应月度；概念热度事件触发。
- **持仓周期**：ΔMS 双周至月；月历效应按月；概念热度数日（事件型）。
- **QMT 用法**：**盘后批量**。ΔMS 双周盘后算→次日调仓；月历效应月初判断→月度调仓。概念热度事件触发可次日开盘介入。

## 红线检查
| 红线 | 是否触线 | 说明 |
|---|---|---|
| 重 ML | ❌ 不触（可得子集） | ΔMS 是均值变化量，纯统计；LLM 情感打分属轻量应用可接受。**注意**：wiki overview 里高频因子深度学习挖掘、GPT因子工厂等属重ML，转🔴分支（B28） |
| 付费库 | ⚠️ 部分触线 | 可得子集不触（新闻/概念热度/月历）；不可得子集（通联招聘/股吧）触线→已拆出转🔴 |
| 分钟级 | ❌ 不触 | 日线 + 新闻 + 月历 |
| Level-2 逐笔 | ❌ 不触 | — |

**红线结论**：**可得子集通过，不可得子集触线（已拆分）**。本卡只评可得子集。

## 落地难度：中
- **卡点**：新闻舆情 ΔMS 的降级版需要用 LLM 对已有新闻做情感打分（替代通联商业数据），这是主要工程量。需验证"LLM 打分的 ΔMS"能否复现开源金工的 IC。
- **主要工作量**：①对已有个股新闻（问财/东财）做 LLM 情感打分→构造 MS→算 ΔMS ②验证降级版 ΔMS 的 IC 是否显著 ③概念热度补同花顺源（或用龙虎榜 reason 降级）。

## 组合潜力（能和哪些方向叠加）
- **+ 事件驱动 (A5)**：新闻舆情 ΔMS 与 PEAD 同属"信息反应"类，可叠加（一个看公告、一个看新闻）。
- **+ 行业轮动 (A3) / ETF 轮动 (A19)**：概念热度做主题轮动信号；月历效应做大小盘风格择时。
- **+ 机构行为 (A23)**：概念热度 + 龙虎榜 reason + 北向，组合刻画"市场在关注什么"。
- **+ 风格轮动 (A4)**：月历效应天然是大小盘风格轮动的择时层。

## 档位：🟡 需补数据或研究（混合结论）
- **可得子集（新闻舆情ΔMS降级版 + 概念热度 + 月历效应）**：逻辑强、研报证据充分，但 ΔMS 需用 LLM 打分替代商业数据并验证 IC——补完即可做，倾向 🟢。
- **不可得子集（招聘/股吧发帖量/卫星/点击量）**：❌ 商业另类或难爬，转🔴分支。
- **整体定 🟡**：取决于降级版 ΔMS 能否复现 alpha。建议优先做月历效应（纯日线派生，零数据成本）+ 概念热度，ΔMS 降级版作为研究项验证后再上。

## 落地路径草图（仅可得子集）
```
1. 信号实现
   ├─ 月历效应（最易，先做）：
   │   ├─ 算沪深300/中证2000 历史月度胜率
   │   ├─ 次周所在月胜率>50% → 大盘占优；否则小盘占优
   │   └─ 月初输出大小盘 ETF 仓位建议（叠加到风格轮动/ETF轮动）
   ├─ 概念热度（事件驱动）：
   │   ├─ 补同花顺概念热度（或龙虎榜 reason 频次降级）
   │   ├─ 热度破布林上轨 → 概念异动信号
   │   └─ 结合多因子筛选概念股（成长/价值/预期/交易/盈利）
   └─ 新闻舆情 ΔMS（研究项，验证后再上）：
       ├─ 对已有个股新闻（问财/东财 title+content）做 LLM 情感打分 → MS
       ├─ 算 ΔMS = MS(N=20) 的变化量
       ├─ 中证500 选股域，双周频
       └─ 验证降级版 IC 是否显著（对标开源金工 ICIR -2.3）

2. QMT 下单
   ├─ 月历：月初判断 → 大小盘 ETF 调仓
   ├─ 概念热度：事件触发次日 → 概念股/主题 ETF 介入
   └─ ΔMS：双周盘后 → 选股池调仓

3. 验证
   ├─ 月历效应：纯历史日线回测，零数据成本，先证伪
   ├─ ΔMS 降级版：重点验 LLM 情感打分与通联打分的相关性
   └─ 小钱实盘 → 加仓
```
