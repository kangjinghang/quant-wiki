# 风格轮动

> 方向 slug: `style-rotation` · 档位: 🟢 立即可做
> wiki 源：`wiki/syntheses/大小盘风格轮动-综合分析.md` `成长价值风格轮动-综合分析.md` + 概念页

## 方向名 / 别名变体
- **主名**：风格轮动（成长/价值 + 大盘/小盘 两维正交）
- **别名变体**（wiki 概念页，点链接看原文）：
  - [PB-ROE 动态风格划分](../../wiki/concepts/pb-roe动态风格划分.md)（开源，ln(PB)对预期ROE回归残差动态归类成长/价值，避免后视镜偏差）
  - [Softmax 风格轮动模型](../../wiki/concepts/softmax风格轮动模型.md)（中银量化，多分类逻辑回归预测四风格占优概率，年化超额 9%）
  - [风格轮动双轮驱动体系](../../wiki/concepts/风格轮动双轮驱动体系.md)（中银，超额收益=相对估值变动+相对盈利变动，跷跷板效应）
  - 方正三维预判（动量+龙虎榜+国债期货）
  - 赔率-胜率框架（估值=赔率，宏观+动量=胜率）

## 一句话机制 / 为什么有效
在成长/价值、大盘/小盘间动态切换。alpha 来源 = 风格切换受**宏观因子**（经济周期/流动性/信用）+ **估值相对位置**（赔率）+ **风格动量**（胜率）结构性驱动，非随机游走。核心难点是**估值-盈利跷跷板**：货币宽松利好成长估值但常伴随经济下行（利空成长盈利），故需多维信号共振判断。

## 研报证据（A 股实证）

| 团队 / 模型 | 方法 | 关键数字 | 时间窗 |
|---|---|---|---|
| 中银量化 Softmax | 多分类逻辑回归（PMI/M1-M2/十年国债等慢变量）| 年化绝对 13.5%，超额 9%，季度胜率 67%，年度胜率 87% | 2009–2021 样本外 |
| 开源金工 PB-ROE 动态划分 | ln(PB)对预期ROE回归残差归类+四维行业信号 | 多空年化 15.6% | — |
| 方正金工 三维预判 | 动量+龙虎榜+国债期货共振 | 三维共振时风格切换概率显著提升 | — |
| 中银双轮驱动 | 超额=相对估值变动+相对盈利变动 | 2013 后估值主导行情；跷跷板效应 | — |
| 经济中周期框架 | Juglar(8-10年)+基钦(3-4年)嵌套 | 中周期上行→成长，下行→价值 | 长周期 |
| 赔率-胜率框架 | 估值=赔率，宏观+动量=胜率 | 高胜率+高赔率共振区最佳 | — |

**结论**：风格轮动是低频（季/年）但可预测的现象。**A 股特殊性**：①大小盘有 3–5 年中周期，与库存周期强相关 ②2013 后估值变动主导风格超额（流动性驱动）③政策敏感（监管/产业政策可打断因子规律）④2024 高股息行情挑战传统成长-价值二元（价值内部分化为"红利价值"vs"周期价值"）。

| PB / PE（个股+风格聚合）| 相对估值、PB-ROE 回归 | ✅ | 实时快照 PB/PE（腾讯），已有 |

| 估值分位 | pe_percentile/pb_percentile（赔率维度） | ✅ | 百度 gushitong，已有 |
| 宏观慢变量 PMI/M1-M2/M2-GDP | Softmax 模型核心输入 | ✅ | akshare→金十（PMI/M2），已有；M1-M2/GDP 派生 |
| 十年国债利率 | 无风险利率锚、流动性代理 | ✅ | akshare（LPR/利率），已有；十年国债可补日线 |
| CPI/PPI 剪刀差 | 通胀因子、成长价值驱动 | ✅ | akshare→金十，已有 |
| 社融/信用利差 | 信用因子 | ✅ | akshare 宏观（社融），已有 |
| 龙虎榜（风格层聚合）| 方正三维模型的资金面信号 | ✅ | 东财龙虎榜，已有 |
| 风格动量 | 风格指数 N 期收益 | 🟡 | 风格指数派生 |
| 国债期货信号 | 方正三维模型的宏观信号 | 🔵 | 需国债期货行情；akshare/QMT 或可拿，非核心（可只用宏观利率替代）|
| 个股分化度 | 风格切换领先微观信号 | 🟡 | 全市场日线派生（横截面波动/分化度）|

**数据结论**：✅🟡 全部覆盖，无 ❌。国债期货是唯一 🔵（可补/可替代），非核心。所有主流风格轮动模型（Softmax/PB-ROE/双轮驱动/赔率胜率）的数据均已有或可派生。

## 频率 / 持仓周期 → QMT 用法
- **信号频率**：季度为主（Softmax 季频优于月频，慢变量黏性），估值/动量可月频微调
- **持仓周期**：季度至年级（风格中周期 3–5 年）
- **QMT 用法**：**盘后批量**。季末盘后算宏观象限+风格打分 → 选 1–2 个占优风格 → 次日开盘批量调仓。**ETF 落地**（沪深300/中证500/中证1000/创业板/风格 ETF）。低频，QMT 适配。

## 红线检查

| 红线 | 是否触线 | 说明 |
|---|---|---|
| 重 ML | ❌ 不触（轻 ML 可接受）| Softmax 是逻辑回归（轻量 ML，多分类打分），属"可接受的轻 ML"；PB-ROE 是 OLS 回归；其余是规则/打分。**非深度学习/强化学习** |
| 付费库 | ❌ 不触 | 风格指数自建/东财免费 + 宏观 akshare 免费源 |
| 分钟级 | ❌ 不触 | 全是日线/月度/季度宏观 |
| Level-2 逐笔 | ❌ 不触 | — |

**红线结论**：全通过。Softmax 逻辑回归属投资者可接受的"轻量 ML（打分/分类）"范畴，非红线。

## 落地难度：中
- **卡点**：
  1. **风格指数自建/选取**——需确定风格代理（国证四风格指数 vs 申万风格 vs ETF），是基础设施。
  2. **信号冲突**——多维因子（宏观/估值/动量）同一时点可能指向相反风格，赔率-胜率框架的阈值需调参。
  3. **风格拐点判断**——风格剧烈切换时模型回撤大（"防御性比进攻性更重要"，风格模糊时保持中性）。
  4. **2024 后结构变化**——高股息行情使价值内部分化，需验证传统二元框架是否要升级。
- 低数据门槛，主要是"宏观建模+调参"研究工作量。

## 组合潜力（能和哪些方向叠加）
- **+ 行业轮动 (A3)**：行业即风格（板块轮盘同时给风格和行业信号）——PB-ROE 动态划分本就是行业层风格归类，两卡高度协同，可一体化（风格定大方向、行业定细分）。
- **+ 宏观择时 (A16)**：风格轮动的宏观因子（PMI/流动性/信用）与宏观择时同源，共用宏观信号层。
- **+ 仓位管理 (A24)**：风格轮动 + 风格暴露约束 + 风格模糊时降仓位，横切叠加。
- **+ ETF 轮动 (A19)**：风格 ETF 是最直接落地。
- **+ 景气度 (A7)**：成长风格的景气驱动（盈利上行→成长占优）与景气度信号互补。

## 档位：🟢 立即可做
数据全有（✅+🟡，无 ❌）、不触红线（Softmax 属可接受轻 ML）、多个 A 股实证（Softmax 超额 9%/PB-ROE 多空 15.6%）、ETF 落地干净。**低频（季/年）、宏观驱动、与行业轮动天然协同**，适合作为组合的"风格大方向层"。

## 落地路径草图
```
1. 信号实现（基于 DATA_SOURCES 现有字段）
   ├─ 基础设施：选风格代理（国证四风格指数 / 或沪深300+中证500+中证1000+创业板 ETF）
   ├─ 三条可选模型（按复杂度递增）：
   │   ├─ A. 赔率-胜率框架（最简）：
   │   │   ├─ 赔率 = 风格相对估值分位（pe_percentile 派生）
   │   │   ├─ 胜率 = 宏观象限（PMI/M2/信用）+ 风格动量
   │   │   └─ 高胜率+高赔率共振 → 重配该风格
   │   ├─ B. PB-ROE 动态划分 + 行业信号：
   │   │   ├─ ln(PB) 对预期ROE 截面回归取残差 → 归类成长/价值
   │   │   └─ 结合行业轮动四维信号（复用 industry-rotation 卡）
   │   └─ C. Softmax 多分类（进阶，轻 ML）：
   │       ├─ 输入 PMI(3MA)/PMI(12MA)/M1-M2/十年国债
   │       └─ 输出四风格占优概率，季度预测
   └─ 风格模糊（信号冲突/概率接近）时保持中性或均衡

2. QMT 下单（ETF 落地）
   ├─ 季末盘后算风格打分 → 选 1–2 占优风格 ETF
   ├─ 次日开盘批量调仓（低频，费率影响小）
   └─ 估值/动量可月频微调权重

3. 验证
   ├─ 用历史宏观+风格指数回测（Softmax 对标超额 9%）
   ├─ 重点验：①风格指数自建对齐 ②信号冲突时赔率-胜率阈值 ③2024 后高股息行情的适应
   └─ 季频信号样本长（需 10 年+），注意 2022 后机构化影响
```
