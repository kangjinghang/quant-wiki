## 一句话机制 / 为什么有效
产业链上下游企业股价之间存在**动量溢出**：供应商的涨价/景气会沿供应链传导到客户（或反向），但市场对这种跨企业、跨行业的基本面联动反应迟缓（有限关注 + 信息扩散延迟）。用供应链关系数据加权合成对手方历史动量 → 预测目标企业未来收益；或用企业在网络中的中心性解释横截面收益。业务动量因子进一步用主营业务拆分捕捉"复杂公司股价对次要业务信息反应慢"。alpha 来源 = 跨标的的信息扩散延迟 + 供应链基本面绑定。

## 研报证据（A 股实证）
| 团队 | 结论 | 关键数字 | 时间窗 |
|---|---|---|---|
| 招商定量任瞳 供应链动量（行业轮动/指数增强） | 供应商动量优于客户动量；TCV 加权优于关系数量加权 | IC 胜率 >70%（100日窗口）；沪深300 增强 8%、中证500 5.33% 年化超额 | — |
| 招商定量 供应链中心性初探 | 网络中心性对横截面收益有显著解释力（借鉴 Ahern 学术） | — | — |
| 业务动量因子（数库科技 SAM 拆分） | 主营拆分收益差，反映次要业务信息消化时滞 | 月度 IC 6.59%，ICIR 0.84，多头超额年化 4.44%，多空 23.80%；中证1000 最佳 | — |

**结论**：逻辑扎实、招商定量系列三篇深度验证。**但全部建立在商业另类数据（数库科技 SAM / 秩鼎公司 TCV）之上**——这是核心矛盾。

## 数据需求（逐字段）

| 字段 | 需要什么 | 档 | 说明 |
|---|---|---|---|
| **供应链关系（核心）** | 企业级供应商-客户关系 + 合同总金额 TCV | ❌ | **核心依赖**。研报用 [数库科技 SAM](../../wiki/concepts/数库科技sam产业链数据.md) + 秩鼎公司 TCV——均为**商业另类数据，付费**。个人投资者不可得。 |
| 标准化主营拆分 | 业务动量因子需要十二层标准化主营 | ❌ | 数库科技 SAM 付费数据（GICS 扩至十二层） |
| 行业间关联度矩阵 | 供应链动量行业层版本 | ❌ | 派生自 TCV 关系，源头仍是商业数据 |
| 个股日线（动量计算） | 对手方历史动量 | ✅ | mootdx + akshare |
| 个股/行业指数 | 收益计算 | ✅ | 已有 |
| 前五大供应商/客户（财报披露） | 上市公司年报附注披露 | 🔵 | **公开但有重大缺陷**：仅前五大、仅大头、披露口径极不统一、多数不披露金额。可用于自建粗版网络，但覆盖率和质量远低于 SAM。 |

**数据结论**：**核心数据 ❌ 不可得**。供应链动量的 alpha 强度直接来自 TCV 加权（研报明确"TCV 加权优于关系数量加权"）和 SAM 标准化拆分——这两块是商业付费源。财报披露的前五大供应商/客户（🔵）理论上可爬，但覆盖率低、口径混乱、无金额，**做不出研报级的因子**。这是本方向归 🔴 的根本原因。

### 有没有免费替代？（关键判定）
- **东财行业链 / 同花顺概念链**：能拿到"行业层面的产业链关系"（如锂电上游→中游→下游），可做**行业层的粗版供应链动量**。但：(1) 颗粒度是行业而非企业，丢失企业级中心性因子；(2) 无 TCV 金额加权，只能等权/数量加权（研报已证效果差）；(3) 同花顺概念链是主题聚类，非严格供应链。
- **财报附注前五大供应商/客户**：可自建企业级网络，但覆盖率低（很多公司不披露或不全）、口径不一、无金额。
- **结论**：**无等价免费替代**。粗版（行业链 + 等权）只能做到研报效果的"形似"，alpha 大幅衰减，且投入产出比对个人不划算。

## 频率 / 持仓周期 → QMT 用法
- **信号频率**：季度更新（供应链关系季/年频变化慢）+ 中等持仓窗口（100 个交易日）。
- **QMT 用法**：若能做，是盘后批量 + 季度调仓。但因数据不可得，**不适用**。

## 红线检查
| 红线 | 是否触线 | 说明 |
|---|---|---|
| 重 ML | ❌ 不触 | 因子合成是加权平均（线性），中心性是图论指标，无端到端 ML。 |
| 付费库 | ⚠️ **触线（核心）** | 供应链关系+TCV（数库科技/秩鼎）= 商业另类数据 ❌。这是本方向的**核心数据依赖**，非增强项 → 整支归 🔴。 |
| 分钟级 | ❌ 不触 | 日线/中等窗口 |
| Level-2 逐笔 | ❌ 不触 | — |

**红线结论**：**触付费库红线（核心依赖）**。供应链关系数据是本方向的"命门"，无它则因子不成立。

## 落地难度：高（核心数据不可得）
- **卡点**：**数据是硬卡点**。没有 SAM/TCV，做不出研报级供应链动量因子。
- **粗版降级**的卡点：行业链粗版需自建行业供应链关系表（人工整理 + 东财行业链），工程量大、颗粒度粗、alpha 衰减。

## 组合潜力（能和哪些方向叠加）
- **+ 行业轮动 (A3)**：供应链动量天然是行业轮动信号（上下游景气传导）。若拿到数据，与 A3 强互补。
- **+ 指数增强 (A18)**：研报主应用场景（沪深300/中证500 增强）。
- **+ 基本面量化 (A7)**：供应链中心性是另类基本面视角。

## 档位：🔴 暂不可做（附 🟡 粗版降级）
- **核心 🔴**：供应链动量/中心性/业务动量的研报级实现，**核心依赖数库科技 SAM + 秩鼎 TCV 商业数据，个人不可得，无等价免费替代** → 整支归 🔴。
- **粗版 🟡（可选，投入产出比低）**：用东财行业链 + 财报附注前五大供应商/客户自建企业级关系网络，做行业层等权供应链动量。能做但 alpha 大幅衰减、工程量大，**不推荐作为个人投资者优先项**。

## 落地路径草图
**🔴 核心方向 → 为什么做不了**：
```
研报供应链动量因子 = f(企业级供应商-客户关系 × TCV合同金额加权, 对手方历史动量)
                    ↑
              这一块是数库科技SAM/秩鼎商业数据，付费，个人拿不到。
没有TCV加权 → 研报明确"关系数量加权效果差" → 因子失效。
没有SAM标准化 → 业务动量因子(主营拆分)无法跨公司可比 → 因子失效。
→ 核心方向对个人投资者无意义。
```

**🟡 粗版降级（若坚持要做，不推荐优先）**：
```
1. 自建粗版行业供应链关系表
   ├─ 东财行业链/同花顺概念链 → 行业上下游拓扑（人工/半自动整理）
   └─ 财报附注前五大供应商/客户（akshare/东财爬，覆盖率低需容忍）
2. 行业层供应链动量（等权，无TCV）
   ├─ 对手方行业历史动量等权加权 → 行业主体动量因子
   └─ 用于行业轮动（A3增强）
3. 企业层（仅限有披露的子集）
   └─ 前五大关系网络中心性（覆盖率低，样本有偏，谨慎）
⚠️ 预期：alpha远低于研报，投入产出比低。建议优先做其他🟢方向。
```
