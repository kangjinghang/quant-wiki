## 一句话机制 / 为什么有效
把经典技术指标（MA/MACD/RSI/KDJ/布林）+ 通道突破（Donchian/Bollinger/Keltner）+ K线形态（华创 61 种）**系统化为因子**，做截面选股或择时。alpha 来源 = 价格对信息的反应模式（趋势延续/超买超卖反转/形态博弈），是行为金融与市场结构的直接体现。**DATA_SOURCES 已内置 MACD/RSI/KDJ/布林/VPA**，是最易上手的方向。

## 频率 / 持仓周期 → QMT 用法
- **信号频率**：日线级（盘后批量）。择时型可日频，选股型可周/月频。
- **持仓周期**：短线（形态/择时，数日）至中线（通道趋势，数周）。
- **QMT 用法**：**盘后批量**为主。盘后算全部技术因子→打分/择时信号→次日开盘下单。形态择时（如多空形态比率剪刀差做指数择时）可日频更新仓位。**不需要盘中信号**——技术分析日线级即可，分钟级是微观结构方向（A12）的事。

## 落地路径草图
```
1. 信号实现（基于 DATA_SOURCES 现有字段）
   ├─ 已有指标直接取用：MACD/RSI/KDJ/布林/ARBR/支撑阻力/波动率/量比
   ├─ 补派生：
   │   ├─ Donchian 通道（20日高低点，直接法）
   │   ├─ K线形态识别（华创规则：十字孕线/乌云压顶/母子线/三内部…，输出形态得分）
   │   └─ 多空形态比率剪刀差（全市场统计，做指数择时）
   ├─ 截面选股路径（中银金工法）：
   │   ├─ 13 指标原始值（非金叉死叉）→ 趋势型/震荡型分组
   │   ├─ 市值行业中性化（OLS 取残差 + Zscore）
   │   └─ 多因子复合（等权/ICIR/ElasticNet）→ 选股打分
   └─ 择时路径（形态/通道）：
       └─ 通道突破（Donchian）或形态比率剪刀差 → 指数/ETF 仓位开关

2. QMT 下单
   ├─ 盘后算因子 → 目标持仓清单（选股型）/ 仓位比例（择时型）
   └─ 次日开盘批量下单

3. 验证
   ├─ 用 data/cache 日线回测（重点：参数高原检验，避免孤岛过拟合）
   ├─ 分市场环境验：趋势类牛市强、震荡类震荡市强（需做 regime 区分）
   └─ 小钱实盘 → 加仓
```
