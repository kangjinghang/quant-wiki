- **别名变体**（wiki 概念页，点链接看原文）：

  - [均衡估值因子](../../wiki/concepts/均衡估值因子.md)（BET，投资回收期，GARP 核心）
  - [动态均衡估值](../../wiki/concepts/动态均衡估值.md)（BET_STD，时序 Z-score）

## 一句话机制 / 为什么有效
价值因子的 alpha = 市场对"便宜"的系统性低估（行为偏差）+ 安全边际。但 A 股静态低 PE/PB 近年持续失效（价值陷阱 + 行业结构变迁），所以现代价值因子都转向"**动态/相对化**"：把成长性内嵌进估值（BET）、看估值的变化方向而非水平（dEP）、或找真正可比的同伴再比估值（可比公司法）。alpha 来源 = 静态低估被动态化修正后重新有效。

## 研报证据（A 股实证）
| 团队 | 结论 | 关键数字 | 时间窗 |
|---|---|---|---|
| 华安金工（严佳炜）均衡估值 BET | BET_CAGR_STD 全市场 Rank IC -4.75%，ICIR -3.52 | 多头年化超额 17%；保守法修正后精选策略年化超额 **25.38%** | 2015-2022 |
| 华安金工 GARP 权益端 | GARP 优选做固收+权益端 | 年化 34.25%，夏普 1.18；2018 仅 -10%、2022 仅 -6%（防御性） | 2015-2022 |
| 开源金工 估值变动因子 dEP | 静态 EP 失效后用 EP 的 60 日变化量 | ICIR **2.70**，多空年化 **22.9%**；剔除动量后仍显著 | — |
| 开源金工 可比公司法 | 13 维财务特征 + 余弦相似度找可比，重构价值因子 | 关联价值因子显著优于传统 BP 横截面排序 | — |
| 东北金工 剩余收益估值 | 内在价值/价格 V/P 选低估值 | 全市场低估选股第 1 组年化 16.10%，多空 13.49% | — |

**结论**：A 股价值因子"静态失效、动态回归有效"是被反复验证的。**BET（动态均衡估值）和 dEP（估值变动）是最稳的两个现代化变体**，纯 BP/EP 直接用会踩价值陷阱。

## 数据需求（逐字段）
| 字段 | 需要什么 | 档 | 说明 |
|---|---|---|---|
| 静态估值 PE/PB | PE_TTM / PB（含流通市值、总市值） | ✅ | 腾讯实时快照（PE_TTM/PE静/PB/总市值/流通市值） |
| 估值历史分位 | PE/PB 近 5 年百分位 | ✅ | 百度 gushitong（pe_percentile/pb_percentile） |
| 归母净利润 E | TTM 净利润（算 EP、BET） | ✅ | 东财 em_quarterly + mootdx finance |
| 每股净资产 B | BVPS / 净资产（剩余收益估值、BP） | ✅ | mootdx finance + 新浪 fzb |
| 一致预期增速 | 分析师 FY1/2/3 EPS、净利润预测 | ✅ | 东财 RPT_WEB_RESPREDICT（BET 的 CAGR 增速、剩余收益的预期 EPS 都用它） |
| 股息率 / 分红率 | 剩余收益估值参数 | ✅ | 新浪 fzb + mootdx（历史分红） |
| dEP 的历史 EP | 60 交易日前的 EP | 🟡 | 派生：用日线 close 回看 + TTM 盈利算 EP(t-60)，全有 |
| BET_STD 时序 | BET 过去 252 日 Z-score | 🟡 | 派生：每日算 BET 存序列，回看 252 日标准化 |
| 可比公司财务特征 | 13 维财务指标（生命周期/规模/盈利/资产结构/运营效率） | 🟡 | 派生：从三大报表（新浪 fzb/lrb/llb）+ 季度趋势（东财 em_quarterly）组合出 13 维，再算余弦相似度 |
| 权益资本成本 | 无风险利率 + 风险溢价（剩余收益用） | ✅ | 宏观 LPR（akshare→金十）+ 行业历史 PE 派生风险溢价 |

**数据结论**：✅ 核心字段全有，🟡 项都是"有原始数据、写代码派生"（BET/dEP/可比公司特征都是纯计算）。**无 ❌ 缺口**。⚠️ 唯一注意：一致预期在小盘股覆盖不足（DATA_SOURCES 已标），BET 在小盘股需用历史增速兜底（研报的保守法本就是"取预期与历史较小值"，天然处理了这个覆盖问题）。

## 频率 / 持仓周期 → QMT 用法
- **信号频率**：日度更新（估值随价变）+ 季度刷新（财报出 E/B 新值时大调）
- **持仓周期**：周~月（dEP）、季（BET/剩余收益）
- **QMT 用法**：**盘后批量**。每日盘后算 BET_STD/dEP → 排序选低估 + 估值改善池 → 次日开盘批量下单。季度财报披露后做一次大调仓。不需要盘中信号。

## 红线检查
| 红线 | 是否触线 | 说明 |
|---|---|---|
| 重 ML | ❌ 不触 | 纯因子计算（BET 公式、dEP 差值、余弦相似度），无 ML |
| 付费库 | ❌ 不触 | wiki 提 Wind 一致预期，但你的源是东财免费源，覆盖够用（小盘股兜底历史增速） |
| 分钟级 | ❌ 不触 | 全部日线 + 季度财务 |
| Level-2 逐笔 | ❌ 不触 | — |

**红线结论**：全通过。价值因子是纯基本面 + 日线方向，最干净。

## 落地难度：低
- **卡点**：几乎无。数据全有，研报给了完整公式。
- **主要工作量**：①实现 BET 公式（含 CAGR 增速估计 + 保守法修正）②dEP 的历史 EP 回看对齐（注意 TTM 盈利在财报披露日跳变）③可比公司法若做全量需算 N×N 余弦相似度（全市场计算量大，可先按行业分组缩范围）。

## 组合潜力（能和哪些方向叠加）
- **+ 盈利质量 (A9)**：低估值 + 高盈利质量 = 经典价值增强（规避价值陷阱）。
- **+ 景气度 (A7)**：BET 本身就是 GARP（估值+成长），与景气度天然一家。
- **+ 分析师预期 (A6)**：BET/剩余收益都依赖一致预期，预期调整 FYR 与估值变动 dEP 互补。
- **+ 事件驱动 PEAD (A5)**：估值分位可作为 PEAD 的"低位超预期"增强过滤。
- **+ 红利低波 (A26)**：低估值是红利策略的天然底色。

## 落地路径草图
```
1. 信号实现（基于 DATA_SOURCES 现有字段）
   ├─ 每日盘后：
   │   ├─ 拉 PE_TTM/PB/市值（腾讯快照）+ TTM 净利润/BVPS（东财季度/mootdx）
   │   ├─ 算静态 EP/BP（基线，对比用）
   │   ├─ 算 BET = ln(1+PE_TTM×r)/ln(1+r)，r 用一致预期 CAGR（东财），小盘无覆盖用历史增速兜底（保守法）
   │   ├─ 算 BET_STD = (BET_t - μ_252)/σ_252（需存 BET 时序）
   │   ├─ 算 dEP = EP(t) - EP(t-60)（用日 close 回看 + TTM 盈利）
   │   └─ 复合：BET_STD + dEP 等权或 ICIR 加权 → 价值得分
   ├─ 季度财报披露后：刷新 E/B，重算剩余收益 V/P
   └─ 估值泡沫保护：剔除 pe_percentile > 95 的极端高估（规避端）

2. QMT 下单
   ├─ 盘后产出次日低估 + 估值改善池
   ├─ 次日开盘价批量下单
   └─ 月度调仓（日度信号变化慢，不必日日调）

3. 验证
   ├─ 先回测 BET_STD 和 dEP 单因子 IC（对照研报 -4.7% / 2.70）
   ├─ 重点验：TTM 盈利财报日跳变对齐、BET 时序窗口稳定性
   └─ 小钱实盘 → 加仓
```
