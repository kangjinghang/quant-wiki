# #02g 行业轮动 · 龙头扩散效应策略（双驱优选） — 详细实现

> **定位**：本文是 [`02-industry-rotation.md`](../../strategy-playbooks/02-industry-rotation.md) §七组合潜力（龙头扩散）的**策略详细实现**。改进 SUE + 改进主动超大单双驱，**行业 alpha + 选股 alpha** 同时获取。
>
> **角色**：行业轮动的**双驱优选路径**。不仅是行业轮动，还在选中的行业内做选股——行业+选股双 alpha。
>
> **来源**：[广发金工 2025.11《龙头扩散效应·双驱优选组合构建》](../../../raw/articles/[202511191740]广发金工龙头扩散效应行业轮动之三双驱优选组合构建.md)。

## 一、策略定位

### 1.1 赚什么钱

**行业龙头领涨后的扩散效应**：龙头股先动（SUE 超预期 / 超大单抢筹），然后带动行业内普通股补涨。在龙头扩散阶段，既能选对行业（行业 alpha），又能在行业内选对个股（选股 alpha）。

**双驱**：
- **改进 SUE**（基本面驱动）：龙头股业绩超预期 → 龙头先涨 → 扩散到行业
- **改进主动超大单**（资金面驱动）：超大单抢筹龙头 → 龙头先涨 → 扩散到行业

### 1.2 这个策略的特殊价值

**行业 alpha + 选股 alpha 双层获取**——其他 02 系列策略只做行业轮动（行业 ETF 落地），本策略在选中的行业内进一步选股：

| 维度 | 02a-f（纯行业轮动）| **02g 双驱优选** |
|---|---|---|
| 第一层 | 行业轮动 | **行业轮动（改进 SUE + 改进超大单）** |
| 第二层 | — | **行业内选股（同样的双驱因子）** |
| 落地 | 行业 ETF | **个股**（或 ETF + 个股混合）|

### 1.3 绩效对照

| 维度 | 年化超额 | IR |
|---|---|---|
| 仅选行业（优选行业）| **19.9%** | **1.92** |
| **双驱选股**（行业 + 个股）| **28.3%** | **2.07** |

> 📖 [02 playbook](../../strategy-playbooks/02-industry-rotation.md) §八迭代期对照表：广发金工 2025.11 龙头扩散效应——改进 SUE + 改进主动超大单，行业 Alpha + 选股 Alpha 双驱优选。

## 二、信号逻辑：双驱因子

### 2.1 驱动一：改进 SUE（基本面）

**SUE**（标准化预期外盈利）的构造详见 [01a §二](01a-pead-sue-single-factor.md#二信号逻辑sue-怎么算)。本策略用**改进版** SUE 聚合到行业层选行业，再在选中的行业内选个股。

**改进点**（广发 2025.11 的具体改进需查阅原文，playbook 未详述）：
- 行业聚合用自由流通市值加权
- 个股层做风格中性化（详见 [02-shared §三](02-shared-industry-rotation-infrastructure.md#三风格中性化层基本面类因子强制)）

### 2.2 驱动二：改进主动超大单（资金面）

**改进主动超大单强度**的构造详见 [02b §2.2](02b-capital-flow.md#22-子因子-1改进主动超大单强度月频)。本策略同样聚合到行业层。

**改进点**（开源 2024 原版，广发 2025.11 沿用）：
- 防高位：× (1/K)，K = 过去 2 个月均值 / 过去 12 个月均值
- 只用极端净流入：突破过去 120 天均值 ± 0.5σ

### 2.3 双驱合成

$$\text{双驱得分} = \text{rank}(\text{改进 SUE}) + \text{rank}(\text{改进主动超大单})$$

两驱动等权合成（各自转截面 rank 后相加）。

## 三、选行业 + 选股规则（双层）

### 3.1 第一层：选行业

```
每月末：
1. 对每个申万一级行业，算行业层的双驱得分
   ├─ 行业改进 SUE = 成分股改进 SUE 按自由流通市值加权聚合
   └─ 行业改进主动超大单 = 成分股改进超大单按自由流通市值加权聚合
2. 行业双驱得分 = rank(行业改进 SUE) + rank(行业改进主动超大单)
3. 按行业双驱得分排序，选前 N 个行业
```

### 3.2 第二层：选股（在选中的行业内）

```
对每个选中的行业：
1. 对该行业内的所有个股，算个股层的双驱得分
   ├─ 个股改进 SUE
   └─ 个股改进主动超大单
2. 个股双驱得分 = rank(个股改进 SUE) + rank(个股改进主动超大单)
3. 按个股双驱得分排序，选前 M 只个股
4. 等权持仓
```

### 3.3 龙头扩散四阶段（机理）

> 📖 [02 playbook](../../strategy-playbooks/02-industry-rotation.md) §七：广发龙头扩散四阶段。

| 阶段 | 现象 | 策略动作 |
|---|---|---|
| ① 龙头启动 | 龙头股 SUE 超预期 + 超大单抢筹 | 识别龙头扩散初期行业 |
| ② 龙头领涨 | 龙头股持续跑赢行业 | 重仓龙头股 |
| ③ 扩散开始 | 普通股开始补涨 | 从龙头切换到普通股 |
| ④ 扩散完成 | 行业整体到位 | 减仓/退出 |

### 6.2 个人投资者降级预期

**主要折扣**：
- 改进 SUE 需分析师预期数据（覆盖率 <50%）
- 改进主动超大单需资金流数据（akshare 可能不区分主动/非主动）
- 双层选股复杂度高

**预期**：原文的 **5-6 折**（即双驱选股年化超额 14-17%）。

## 七、失效红线

| 红线 | 表现 | 监控动作 |
|---|---|---|
| 🔴 **SUE 数据覆盖不足** | 分析师覆盖率 <50% | 小盘股缺失，配合 01d AOG |
| 🔴 **超大单数据口径** | akshare 可能不区分主动/非主动 | 用全部超大单近似 |
| 🟡 龙头扩散未发生 | 龙头涨但普通股不跟 | 监控行业内分化 |
| 🟡 双层选股换手高 | 个股层换手 > 行业层 | 缓冲机制 |

## 八、与其他策略叠加

02g 是**行业+选股双层**，与其他策略关系：

```
02g 双驱优选（本策略）
   │
   ├─ 第一层（行业）与 02a-e 正交，可叠加
   ├─ 第二层（选股）与 01a（SUE）/ 01d（AOG）选股正交
   │
   ↓ 完整组合
   │
02g 行业层 + 02e 四路径合成 → 强化行业选择
02g 选股层 + 01a SUE / 01d AOG → 强化个股选择
```
