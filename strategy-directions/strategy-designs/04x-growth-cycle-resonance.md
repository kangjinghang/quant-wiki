## 一、策略定位

### 1.1 赚什么钱

**成长性（增量）+ 周期性（存量）双因子共振**：改进净利润增速因子衡量业绩的"增量"（成长性），景气周期因子衡量业绩的"存量"（周期位置），两者合成兼顾成长性与周期性。

**一句话逻辑**：传统增速因子只看"增量"（成长快不快），景气周期因子补上"存量"（在周期什么位置），合成后既能抓成长又能避周期顶部。

> 📖 [开源 2025.3](../../raw/articles/[202503301630]成长与周期共振基于业绩增速与景气定位的双因子协同开源金工.md) §04："考虑到景气周期因子与改进净利润增速因子，**分别刻画个股单季净利润的存量与增量特征**……我们将二者合成作为**周期成长因子**，兼顾业绩成长性与周期性。"

### 1.2 在 04 家族里的角色

| 策略 | 角色 | 与本策略（04x）的关系 |
|---|---|---|
| 04a 盈利加速度 | 入门单因子（二阶导）| 04x 是 04a 的改进升级版 |
| 04b 景气向上 | 个股多维度 | 04x 是单因子精进而非多维度 |
| **04x 成长与周期共振** | **个股进阶（改进增速+周期）** | — |

### 1.3 不适合什么场景

- **追求最简实现**：比 04a 复杂（双因子合成），入门先做 04a
- **沪深 300 大盘股增强**：因子在沪深 300 内有效性较弱（多空仅 7.6%/IR 0.99），中小盘（500/1000）更强

## 二、信号逻辑：改进增速 + 景气定位怎么合成

### 2.1 整体架构

```
改进净利润增速因子（成长性，增量）    景气周期因子（周期性，存量）
  ├─ 传统：分母=去年同期单季净利绝对值   ├─ 定义：单季净利 / 净利 TTM
  ├─ 改进：分母=净利润 TTM（更稳定）    ├─ 含义：定位业绩周期位置（淡旺季）
  ├─ 降低异常值，IR 1.96→2.66          └─ 刻画业绩周期性
  └─ RankIC 3.1%/ICIR 1.9
         ↓                                    ↓
         └──────── 合成（权重未披露）──────────┘
                       ↓
              周期成长因子
              RankIC 4.2%/ICIR 2.4
              多空 18.8%/IR 3.5
```

### 2.2 改进净利润增速因子（成长性）

**问题**：传统增速因子的分母是"去年同期单季净利润绝对值"，作为去量纲指标，单季度净利润负值比例较高且不稳定，产生大量异常值。

**改进**：把分母端的"去年同期单季净利绝对值"替换为"净利润 TTM"。

> 📖 [开源 2025.3](../../raw/articles/[202503301630]成长与周期共振基于业绩增速与景气定位的双因子协同开源金工.md) §02："原始净利润增速因子分母端是去年同期单季净利润绝对值，作为去量纲指标，单季度净利润负值比例较高且不稳定。因此，我们在分母端用**净利润 TTM 替换**。相较而言，**净利润 TTM 正值比例更高且更加稳定**，作为改进净利润增速因子中的去量纲指标，可以有效降低因子因分母端基数效应导致的异常值比例，从而提升因子稳定性。"

**改进效果**：

| 指标 | 原始增速因子 | 改进增速因子 |
|---|---|---|
| RankIC 均值 | — | **3.1%** |
| RankICIR | — | **1.9** |
| 多空年化 | 11.7% | **13.6%**（提升有限）|
| **年化 IR** | **1.96** | **2.66**（显著改善）|
| 月度胜率 | 65% | **71%** |

> 📖 [开源 2025.3](../../raw/articles/[202503301630]成长与周期共振基于业绩增速与景气定位的双因子协同开源金工.md) §02："相比于原始净利润增速因子，改进净利润增速因子多空组合年化收益**提升幅度有限，从 11.7% 提升至 13.6%**，而**年化 IR 从 1.96 提升至 2.66，收益稳健性显著改善**。"

**含义**：改进的核心价值不是提收益（11.7%→13.6% 幅度有限），而是**提稳健性**（IR 1.96→2.66 大幅改善）——分母替换让因子更稳定。

### 2.3 景气周期因子（周期性）

**定义**：单季度净利润占净利润 TTM 的比例。

$$\text{景气周期因子} = \frac{Q_t}{TTM_t} = \frac{Q_t}{Q_t + Q_{t-1} + Q_{t-2} + Q_{t-3}}$$

**物理含义**：定位个股业绩的周期位置（淡旺季状态）。占比高 = 当季在全年占比大 = 旺季；占比低 = 淡季。

> 📖 [开源 2025.3](../../raw/articles/[202503301630]成长与周期共振基于业绩增速与景气定位的双因子协同开源金工.md) §03："我们通过**单季度净利润占净利润 TTM 的比例**作为景气周期因子，**定位个股业绩周期位置，刻画个股业绩淡旺季状态**。"

> 💡 **不是历史分位数，不是周期相位**：景气周期因子本质是"存量占比"——当季净利在 TTM 中的比重，简单但有效。

### 2.4 双因子合成（周期成长因子）

**合成方式**：原文未明确给出加权系数或合成公式，仅笼统称"合成"。

> 📖 [开源 2025.3](../../raw/articles/[202503301630]成长与周期共振基于业绩增速与景气定位的双因子协同开源金工.md) §04："我们将二者合成作为**周期成长因子**。"

> ⚠️ **合成权重原文未披露**。常见实现：等权合成（Rank 标准化后相加），或用 ICIR 加权。落地需自定并回测。

**备选方案（单因子融合，效果弱）**：

> 📖 同上 §5.1："本节我们尝试构建**景气周期增速因子**，通过对景气周期指标做同比增速处理，兼顾成长与周期，为成长与周期的融合提供单因子方案。"；"其融合过程对成长与周期的信息折损较高，致使景气周期增速因子收益表现**整体弱于成长与周期单因子表现**。"

**含义**：双因子合成（周期成长因子）优于单因子融合（景气周期增速因子）。

### 2.5 算法完整流程（以 A 公司 2026Q1 为例）

```
步骤 1：算改进增速因子
  ├─ Q_t（2026Q1 单季净利）= 1.2 亿
  ├─ TTM_t（2026Q1 的净利 TTM）= Q_t + Q_{t-1} + Q_{t-2} + Q_{t-3}
  │   例：= 1.2 + 1.0 + 0.9 + 1.1 = 4.2 亿
  └─ 改进增速 = (Q_t − Q_{t-4}) / TTM_{t-4}
      （⚠️ 分母用 TTM，非绝对值；具体 TTM 口径见原文图表）

步骤 2：算景气周期因子
  └─ 景气周期 = Q_t / TTM_t = 1.2 / 4.2 ≈ 0.286（当季占 TTM 28.6%）

步骤 3：合成周期成长因子
  ├─ 两个因子分别 Rank 标准化
  └─ 等权相加（推断，原文未披露权重）

步骤 4：行业 + 市值中性化（强制）
  └─ 对中性化后的纯净因子排序选股

步骤 5：前视偏差检查（强制）
  └─ 确认 2026Q1 数据在调仓日真实可见
```

## 三、选股规则

### 3.1 月末盘后例行流程

```
每月末盘后：
1. 拉全市场单季净利 + TTM 数据
2. 样本剔除：ST、上市天数不足、停牌等
3. 算改进增速因子（分母 TTM）
4. 算景气周期因子（Q_t / TTM_t）
5. 两因子 Rank 标准化后合成（周期成长因子）
6. 行业 + 市值中性化（强制）
7. 10 分组排序，选多头组（第 10 组）
8. 等权持仓 → 次月首个交易日开盘买入
```

### 3.2 指数增强（约束优化）

原文还做了指数增强测试（沪深300/中证500/中证1000），用约束优化：风格偏离 ±0.01、行业偏离 ±0.01、成分股权重下限 0.8。

### 3.3 ⚠️ 前视偏差检查

详见 [04-shared §三](04-shared-prosperity-infrastructure.md)。月频调仓，用截止月末最新财报。
