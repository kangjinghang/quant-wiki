# #05e 资金流 · 散户羊群效应因子 — 详细实现

> **定位**：本文是 [`05-fund-flow-northbound.md`](../strategy-playbooks/05-fund-flow-northbound.md) 配方 E 的**策略详细实现**——介于 playbook 与代码之间的中间层。读完本文，任何人都能照着写出代码，但本文不陷入代码细节。
>
> **角色**：05 资金流家族的**负向选股因子 + 行业轮动第二信号**。度量每只股票"涨跌 ↔ 未来散户小单流入"的同步程度，越同步（散户越追涨杀跌）未来收益越差。
>
> ⚠️ **数据门槛**：需逐笔/L2 数据。多头端弱（IR 仅 0.4-0.6），做多-only 慎用。
>
> **来源**：[开源金工 2022.6《新型因子资金流动力学与散户羊群效应》](../../raw/articles/[202206041322]新型因子资金流动力学与散户羊群效应开源金工.md)。

---

## 一、策略定位

### 1.1 赚什么钱

**散户追涨杀跌行为的反向 alpha**。逻辑：散户"看到涨了，明天才追进去"（错位追涨杀跌）。这种"错位"行为用同步净流入捕捉不到——要算"过去 N 日收益率"与"小单未来 N 日净流入"的相关系数。散户羊群效应越强（相关系数越大），后市越差。

> 📖 [开源 2022.6](../../raw/articles/[202206041322]新型因子资金流动力学与散户羊群效应开源金工.md)："对于每只股票，都可以计算'过去 N 日收益率'与'小单未来 N 日净流入'的相关系数，前者代表市场涨跌，后者代表散户行为。"

### 1.2 与配方 B/C 的区别（重要）

| 配方 | 小单视角 | 信号方向 |
|---|---|---|
| 05b 大单残差 | 小单净流入（被动接盘痕迹）| 负向（小单流入→跌）|
| 05c ACT 切割 | 小单 ACT 在低收益日 | 负向 |
| **05e 散户羊群** | **小单"错位"追涨杀跌** | **负向**（相关系数→跌）|

**关键差异**：05b/05c 用的是"小单净流入"（散户被动接盘的痕迹），但散户还有另一种行为——"看到涨了，明天才追进去"。这种"错位"行为用同步净流入捕捉不到，要换角度（相关系数）。

### 1.3 这个策略在 05 家族里的角色

| 策略 | 角色 | 与本策略关系 |
|---|---|---|
| 05b 大单残差 | 个股（正向）| 同源数据，正交 |
| 05c ACT 切割 | 个股 | 同源不同处理 |
| **05e 散户羊群** | **负向选股 + 行业轮动第二信号** | — |
| 02b 资金流 | 行业轮动 | 行业版可叠加 |

### 1.4 不适合什么场景

- **做多-only 主力**：多头端 IR 仅 0.4-0.6，收益主要来自空头端
- **大盘股**：沪深300/中证500 IR 仅 1.32-1.35，中证1000 才强（2.05）
- **无 L2 数据**：需逐笔小单

## 二、信号逻辑

### 2.1 因子构造（个股版）

计算"过去 N 日收益率"与"小单未来 N 日净流入"的相关系数——

$$\text{散户羊群}_N = \text{corr}(\text{Ret}_{过去 N 日}, \text{小单净流入}_{未来 N 日})$$

散户羊群效应越强，这个相关系数越大（散户越紧跟昨日涨跌操作），后市越差。

> 📖 [开源 2022.6](../../raw/articles/[202206041322]新型因子资金流动力学与散户羊群效应开源金工.md)："对于每只股票，都可以计算'过去 N 日收益率'与'小单未来 N 日净流入'的相关系数……**在 N=1 时选股效果最好，并且衰减得较快**，滞后 1 期的散户羊群效应因子是较为有效的选股因子。"

⚠️ **N=1 最优**：用"昨日收益 ↔ 今日小单净流入"的相关系数。

### 2.2 因子方向：负向选股

> 📖 [开源 2022.6](../../raw/articles/[202206041322]新型因子资金流动力学与散户羊群效应开源金工.md)："该因子为负向选股因子，即'股票的散户羊群效应越高，未来预期收益越差'。"

**含义**：相关系数越大（散户越追涨杀跌）→ 排序越靠后 → 做空端；相关系数越小 → 做多端。

### 2.3 完整流程（个股版）

```
每月末盘后（N=1）：
1. 拉逐笔小单数据（需 L2）
2. 对每只股票，算过去一段时间内：
   ├─ Ret_t = 每日收益率（过去 N=1 日）
   └─ 小单净流入_{t+1} = 次日小单净流入（未来 N=1 日）
3. 算 corr(Ret_t, 小单净流入_{t+1})，回看窗口约 20 天
4. 该因子为负向：相关系数小的（散户不追涨）→ 多头；大的（散户强烈追涨）→ 空头
5. ⚠️ A 股做空难，多头端 IR 仅 0.4-0.6，做多-only 效果有限
6. 按因子值排序选股，月频调仓
```

## 三、选股规则

### 3.1 分样本绩效（中小盘更强）

| 股票池 | 多空 IR | 多头 IR |
|---|---|---|
| 沪深300 | 1.35 | 0.60 |
| 中证500 | 1.32 | 0.43 |
| **中证1000** | **2.05** | **0.61** |

> 📖 [开源 2022.6](../../raw/articles/[202206041322]新型因子资金流动力学与散户羊群效应开源金工.md)："在沪深300内多空和多空收益波动比分别为 1.35 和 0.60，中证500内因子的多空和多头的收益波动比分别为 1.32 和 0.43，中证1000内因子的多空和多头的收益波动比分别为 2.05 和 0.61。"

**含义**：中证1000 显著强于沪深300/500，适合小盘股池。

### 3.2 ⚠️ 多头端弱（做多-only 落地注意）

> ⚠️ **重要**：分样本的**多头**收益波动比为沪深300 **0.60**、中证500 **0.43**、中证1000 **0.61**——都很低，说明该因子**收益主要来自空头端**。

**含义**：别误以为"中证1000 多空 IR 2.05 = 做多也能拿 2.05"。做多-only 落地效果有限。

### 3.3 前视偏差检查

- **"小单未来 N 日净流入"**：N=1 时用次日小单净流入，回测时要注意时点对齐
- 因子计算时点 t：用 t-1 及之前的 Ret + t 及之前的小单净流入（"未来"是相对 Ret 而言）

## 四、行业轮动版（与 02-行业轮动的真实交叉点）

开源金工把这个因子移植到行业层面，用"行业小单资金净流入日度变化跟随昨日行业收益日度变化"的紧密程度作代理——

### 4.1 行业版因子构造

$$\text{行业散户羊群} = \text{紧密程度}(\Delta \text{行业小单净流入}_t, \text{行业收益}_{t-1})$$

行业小单净流入日度变化跟随昨日行业收益越紧密，该行业散户羊群效应越高，后市表现越差。

> 📖 [开源 2022.6](../../raw/articles/[202206041322]新型因子资金流动力学与散户羊群效应开源金工.md)："对于某行业小单资金净流入的日度变化而言，若其跟随昨日行业收益日度变化越紧密，我们则认为该行业散户羊群效应较高，后市表现可能较差。"

### 4.2 行业版绩效

| 指标 | 数值 |
|---|---|
| IC 均值 | **−5.85%** |
| ICIR | **−1.04** |
| 多空年化收益 | **11.99%** |
| 信息比率 | **1.25** |
| 胜率 | **66.07%** |
| 最大回撤 | **8.22%** |

> 📖 [开源 2022.6](../../raw/articles/[202206041322]新型因子资金流动力学与散户羊群效应开源金工.md)："IC 均值 -5.85%，ICIR 为 -1.04。我们对其进行 3 分组回测，多空对冲的年化收益 11.99%，信息比率 1.25，胜率 66.07%，最大回撤 8.22%，整体绩效较为优异。"

**含义**：这是独立于北向的行业轮动信号，与北向信号正交，可叠加（见 [02b](02b-capital-flow.md) 改进羊群效应）。

## 七、绩效预期与可信度

### 7.1 个股版绩效（开源 2022.6，摘要口径）

| 指标 | 数值 | 口径 |
|---|---|---|
| IC 均值 | **−4.52%** | 负向 |
| ICIR | **−2.35** | |
| 多空年化收益 | **12.51%** | 多空对冲 |
| 信息比率 | **2.18** | 多空 |
| 胜率 | **77.48%** | 月度 |
| 回测期 | 2013.1–2022.4 | 全 A 剔除 ST/停牌/次新 |

> 📖 [开源 2022.6](../../raw/articles/[202206041322]新型因子资金流动力学与散户羊群效应开源金工.md) 摘要："IC 均值 -4.52%，ICIR -2.35，多空对冲年化收益率 12.51%，收益波动比 2.18，胜率 77.48%。"

⚠️ **口径提示**：上述精确数字仅见于摘要。正文 §2.2 的多空绩效为另一组（8.45%/2.05/76.58%，实际对应"小单-小单错位相关性因子"）。设计引用以摘要数字为准。

### 7.2 中性化后绩效（提纯反而更强）

> 📖 [开源 2022.6](../../raw/articles/[202206041322]新型因子资金流动力学与散户羊群效应开源金工.md)："纯净新因子多空对冲的年化收益为 8.49%，信息比率为 **2.27**，胜率为 75%，最大回撤为 **2.37%**。"

**含义**：与 ACT（中性化后折损 22%）不同，散户羊群中性化后 **IR 不降反升**（2.18→2.27）、**最大回撤仅 2.37%**（极小）——纯化版是"干净且稳健的 alpha"，这点比 ACT 更友好。

### 7.3 个人投资者降级预期

| 折扣因素 | 影响 | 应对 |
|---|---|---|
| **需 L2 数据** | 无则无法复现 | ⚠️ 无法日线降级（需逐笔小单）|
| **多头端弱** | IR 仅 0.4-0.6 | 与正向因子合成；或指增用 |
| 中小盘限定 | 沪深300 弱 | 用中证1000 池 |
| 风格暴露 | 与流动性/波动率相关 | 必须中性化 |

**预期实战绩效**：
- **多空（有对冲）**：原文的 **7-8 折**
- **做多-only**：多头 IR 约 **0.4-0.5**（收益有限）

> ⚠️ **三档实现路径**：
> - **档 1**：❌ 不可用——需逐笔小单，日频无法还原"未来 N 日净流入"
> - **档 2（必需）**：QMT L2 逐笔——需开权限
> - **档 3（付费源）**：聚宽/米筐/Wind

## 八、失效红线

| 红线 | 表现 | 监控动作 |
|---|---|---|
| 🔴 **多头端弱** | IR 仅 0.4-0.6 | 不单独做多，与正向因子合成 |
| 🔴 **伪动力学警示** | "同步相关性"是假 alpha | 必须用"错位相关性/散户羊群" |
| 🔴 **L2 必需** | 无法日线降级 | 开 L2 权限 |
| 🟡 大盘股失效 | 沪深300 IR 仅 1.35 | 用中证1000 池 |
| 🟡 风格暴露 | 与流动性/波动率相关 | 必须中性化 |

### 伪动力学警示（极易踩的坑）

> 📖 [开源 2022.6](../../raw/articles/[202206041322]新型因子资金流动力学与散户羊群效应开源金工.md)："对于同步相关性因子而言，超大单和小单的同步相关性表现最好，IC 均值为 5.13%，ICIR 达 2.43。但其 alpha 来源是'伪动力学'……在恒等式'超大单+大单+中单+小单=0'的约束下，资金流同步相关性 alpha，可以被两者流入量级所解释……其底层 alpha 来源仍是资金流强度。"

⚠️ **实盘不要直接用"同步相关性因子"**（超大单-小单同步 IC 5.13% 看似很好但是假 alpha），要用经回归证实的**"错位相关性/散户羊群"因子**（Ret ↔ 未来小单流入）。
