# #06 估值与价值因子 · REP/CCP 留存收益双因子轮动 — 详细实现

> **定位**：本文是 [`06-value-estimation.md`](../../strategy-playbooks/06-value-estimation.md) 配方 D 的**策略详细实现**——介于 playbook 与代码之间的中间层。读完本文，任何人都能照着写出代码，但本文不陷入代码细节。

> **角色**：估值家族的**趋势适配版**。把账面价值（BP 的分母）拆成"留存收益"和"投入资本"两部分，分别做因子，再根据市场趋势切换——上涨用 CCP，下跌用 REP。适合想做"风格择时"的投资者。

## 一、策略定位

### 1.1 赚什么钱

**会计拆分 + 趋势适配**：传统 BP（账面价值/市值）把"内生价值"（留存收益，靠历史盈利积累）和"外生价值"（投入资本，股东原始投入）混在一起。拆开后发现两者表现互补——**市场上涨时 CCP（投入资本）表现更好，下跌时 REP（留存收益）表现更好**。用价量趋势信号切换，在不同市场环境选"合适的因子"。

**alpha 来源**：留存收益和投入资本承载不同的经济信息——留存收益 ≈ EP 的多年存量版（更稳），投入资本体现企业风险偏好（弹性大）。两者在不同市场风格下的相对强弱可被价量趋势信号预测。

> 📖 [华安 2020.8](../../../raw/articles/[202008241515]华安金工留存收益投入资本视角下的估值因子改进量化基本面系列报告之一.md)："REP 与 CCP 的相对强弱与市场趋势密切相关，**市场上涨趋势中 CCP 表现更优，反之 REP 表现更优**。"

### 1.2 这个策略在估值家族里的角色

| 策略 | 角色 | 与本策略（06d）的关系 |
|---|---|---|
| 06a dEP | 入门 | 06a 不择时，06d 双因子轮动 |
| 06b BET | 主力（GARP）| 06b 不择时，06d 趋势适配 |
| 06c 可比公司 | 指数增强 | 06c 重塑基准，06d 拆账面价值 |
| **06d REP/CCP** | **趋势适配** | — |
| 06e 价值盲区 | 正交通道 | 06d 纯估值拆分，06e 含 PEAD |
| 06f 神奇公式 | 被动指数化 | 06d 含择时，06f 不择时 |
| 06g 改进矩阵 | 工具箱 | 06d 属分子端（拆账面价值，华泰分类）|

### 1.3 不适合什么场景

- **不想做择时**：本策略核心是双因子轮动，需判断市场趋势；不想择时用 06a/06b
- **纯多头投资者慎用 CCP**：CCP 收益集中在空头，A 股不能做空会损失大部分 CCP alpha
- **改良均线 MA_NEW 无法获取**：复现最大障碍（见 §7）

## 二、信号逻辑：REP/CCP 怎么算

### 2.1 会计拆分：账面价值 = 留存收益 + 投入资本

> 📖 [华安 2020.8](../../../raw/articles/[202008241515]华安金工留存收益投入资本视角下的估值因子改进量化基本面系列报告之一.md)："账面价值主要由**留存收益**和**投入资本**两部分组成。**留存收益**是指企业从历年实现的利润中提取或形成的留存于企业的内部积累（盈余公积 + 未分配利润）；**投入资本**是指所有者在企业注册资本的范围内实际投入的资本（资本公积 + 股本 − 库存股）。"

| 组成 | 公式 | 经济本质 |
|---|---|---|
| **留存收益** | 盈余公积 + 未分配利润 | 企业靠历史盈利积累的"内生价值" |
| **投入资本** | 资本公积 + 股本 − 库存股 | 股东原始投入的"外生价值" |

### 2.2 两个因子

| 因子 | 公式 | 含义 |
|---|---|---|
| **REP** | 留存收益 / 总市值 | 衡量企业靠历史盈利积累的"内生价值"（≈ EP 多年存量版）|
| **CCP** | 投入资本 / 总市值 | 衡量股东原始投入的"外生价值" |

> 💡 **REP ≈ EP 的多年存量版**：

> 📖 [华安 2020.8](../../../raw/articles/[202008241515]华安金工留存收益投入资本视角下的估值因子改进量化基本面系列报告之一.md)："留存收益**本质上反映了公司过去累积的净利润……在一定程度上和市盈率有点相似，只是市盈率 TTM 中的净利润部分是最近一年的净利润数据，而留存收益是历年来企业累积的和净利润相关的存量数据**。"

> ⚠️ **负留存收益的处理**：原文明确"对于**留存收益为负值的情况，我们选择保留以体现其包含的特定信息，而不是作为异常值处理**"——亏损企业的负留存收益承载"历史累计亏损"信号，落地时切勿按异常值剔除。

### 2.4 双因子轮动信号（配方 D 核心）

REP 和 CCP 的相对强弱跟市场趋势有关，需用价量趋势信号切换：

#### 信号构造

> 📖 [华安 2020.8](../../../raw/articles/[202008241515]华安金工留存收益投入资本视角下的估值因子改进量化基本面系列报告之一.md)："使用**中证全指**作为市场表征指数，并且计算指数的**能量潮指标 OBV**。其次，分别对价格与 OBV 计算**短期改良均线（10 日）MA_NEWshort，与长期改良均线（480 日）MA_NEWlong**……对于价格与 OBV 分别定义长短趋势比较指标：**MA_NEWshort / MA_NEWlong**。"

> "将价格趋势值与成交量趋势值**两者等权平均**后作为因子轮动信号，即当信号的值**大于 1 时**……使用 **CCP**……**小于等于 1，则使用 REP**。"

#### 轮动规则

```
信号 = (价格趋势值 + 成交量趋势值) / 2
价格趋势值 = MA_NEWshort(10日) / MA_NEWlong(480日)  [中证全指]
成交量趋势值 = MA_NEWshort(10日) / MA_NEWlong(480日)  [中证全指 OBV]

if 信号 > 1:  → 市场上涨趋势 → 用 CCP
if 信号 ≤ 1:  → 市场下跌趋势 → 用 REP
```

#### 信号预测力的统计验证（不是过拟合）

> 📖 [华安 2020.8](../../../raw/articles/[202008241515]华安金工留存收益投入资本视角下的估值因子改进量化基本面系列报告之一.md)："使用回归法进行验证，将 CCP 和 REP 的多头组合的月收益差值对前月月末趋势指标值进行单变量回归……价格和成交量趋势指标对未来一个月 REP 和 CCP 多头收益差值的预测能力均较为显著，**p 值分别为 0.025 和 0.029**"（5% 显著性水平）。

#### 背后的风格机制（为什么上涨用 CCP、下跌用 REP）

> 📖 [华安 2020.8](../../../raw/articles/[202008241515]华安金工留存收益投入资本视角下的估值因子改进量化基本面系列报告之一.md)（Barra CNE5 分解）：**REP 多头组合呈现低 beta、高价值（高 BP）、高盈利、低杠杆的风格**。"在市场上涨的时候，市场更关注**弹性（beta）更大、杠杆更高**……的股票 CCP；而在市场下跌时，**弹性低、价值高、盈利高、确定性强**的股票的超额收益会相对更大。"

> 💡 **市场拐点领先于因子切换**："市场的最高点**略微早于** CCP 和 REP 相对收益的最高点，说明**市场下跌领先于因子间的相对收益**"——用市场趋势信号去切换因子在时序上是合理的。

### 2.5 REP/CCP 算法完整流程（以 2026-06-30 为例）

```
步骤 1：算 REP 和 CCP（全市场）
  ├─ REP = (盈余公积 + 未分配利润) / 总市值   [最新季报，MRQ]
  └─ CCP = (股本 + 资本公积 - 库存股) / 总市值  [最新季报，MRQ]
  └─ ⚠️ 负留存收益保留（不剔除）

步骤 2：行业市值中性化（见 06-shared §三）
  ├─ REP 对【中信一级行业哑变量 + ln(自由流通市值)】OLS 取残差 → Z-score
  └─ CCP 同上

步骤 3：算轮动信号
  ├─ 取中证全指过去 480 日的收盘价和 OBV
  ├─ 算价格趋势值 = MA_NEW(10日) / MA_NEW(480日)
  ├─ 算成交量趋势值 = MA_NEW_OBV(10日) / MA_NEW_OBV(480日)
  └─ 信号 = (价格趋势值 + 成交量趋势值) / 2

步骤 4：根据信号选因子
  ├─ if 信号 > 1: 用 CCP 排序
  └─ if 信号 ≤ 1: 用 REP 排序

步骤 5：选股 + 调仓
  └─ 取中性化后因子值最高的 10%（Q10），等权持仓

步骤 6：前视偏差检查（强制）
  └─ 确认 2026-06-30 的信号用的是 2026-06-30 当天及之前的中证全指数据
```

## 三、选股规则

### 3.1 每月盘后例行流程

```
每月末盘后：
1. 拉全市场股票的资产负债表（盈余公积/未分配利润/股本/资本公积/库存股）
2. 算 REP 和 CCP（负留存收益保留）
3. 行业市值中性化（OLS 残差 + Z-score，见 06-shared §三）
4. 算轮动信号（中证全指 + OBV + 改良均线 10/480 日）
5. 根据信号选因子（>1 用 CCP，≤1 用 REP）
6. 全市场按选中因子排序，取前 10%（Q10）
7. 等权持仓，输出候选清单 → 次日开盘买入
```

### 3.2 硬过滤

| 过滤条件 | 阈值 | 作用 | 优先级 |
|---|---|---|---|
| 上市天数 | >180 | 有足够历史算均线 | **必加** |
| 日成交额 | >100 万 | 流动性 | **必加** |
| ST/涨跌停/停牌 | 剔除 | 风险 | 推荐 |

> ⚠️ **负留存收益不剔除**：原文明确保留负值以体现特定信息。

### 3.3 ⚠️ 前视偏差检查

见 [06-shared §五](06-shared-valuation-infrastructure.md)。REP/CCP 用最新季报 MRQ 数据，必须确认季报在计算日已披露。
