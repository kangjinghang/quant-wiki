## 二、信号逻辑：5类走势+状态机（核心）

### 2.1 核心规则——5 类走势 + 关键点

走势分为 5 类：

| 走势 | 定义 |
|---|---|
| **上行趋势（up）** | 不断创新高 |
| **下行趋势（down）** | 不断创新低 |
| **自然回撤（upDraw）** | 上行中的回调（回撤超过阈值）|
| **自然反弹（downDraw）** | 下行中的反弹 |
| **次要走势（minority）** | 回撤/反弹中的小波动 |

**关键点**：以上行趋势为例：不断创新高即为上行，一旦回撤超过一定幅度（如 **6 个点**）计入"自然回撤"，**此前高点为高关键点**、**首次自然回撤低点为低关键点**——**有效突破高点=趋势延续，有效跌破低点=转入下行**。

### 2.2 双参数体系（关键落地参数）

| 参数 | 含义 | Python 默认 |
|---|---|---|
| **阈值 reverseThreshold** | 判断拐点的最低回撤标准 | 0.05 |
| **边际值 margin** | 有效突破的标准 | 0.02 |

⚠️ **不同弹性资产不能共用参数**——普通债、转债、股应该适用不同的参数。

> 📖 [中金固收 2022.2](../../raw/articles/[202202131426]中金固收技术如何快速分辨趋势Python实现趋势分析及债市中的适应性调整.md)："对于不同产品（弹性不同）、不同交易时间尺度、不同风险偏好，有不同适用参数……普通债、转债、股不应该适用同样的参数。"

### 2.3 状态机转移规则（落地核心，复现必看）

5 类走势之间的转移由阈值（`reverseThreshold`）和边际值（`margin`）触发，**关键在于阈值乘在哪个关键点上**。以上行为例（`newPoint` 为当日价，`upperLim`/`lowerLim` 为当前高/低关键点）：

```
up（上行）:        newPoint > upperLim → upperUpdate（刷新高点）
                  newPoint <= lowerLim*(1-margin) → 转 down（跌破低关键点）
                  newPoint <= upperLim*(1-reverseThreshold) → 转 upDraw（自然回撤）

upDraw（自然回撤）: newPoint <= lowerLim → lowerUpdate（刷新低点）
                  newPoint >= upperLim*(1+margin) → 转 up（突破高关键点=趋势延续）
                  newPoint >= lowerLim*(1+reverseThreshold) → 转 minority（次要走势）

minority（次要）:  newPoint >= upperLim*(1+margin) → 转 up
                  newPoint <= lowerLim*(1-margin) → 转 down
```

**关键**：阈值（reverseThreshold）乘在**当前趋势的关键点**上（上行时乘在高关键点判断回撤、回撤时乘在低关键点判断反弹）。

### 2.4 起点冷启动

序列初始无方向，按累积变化值（`(pct_change+1).cumprod()-1`）达到某阈值（如 2%）时，由其正负判定首个趋势方向。

**关键点日志区分两类动作**：
- `upper/lowerUpdate`：同趋势内刷新关键点（覆盖最后一条）
- `upper/lowerBreak`：趋势改变（新增一条）

### 2.5 利弗莫尔趋势算法完整流程

```
对每个标的（股/债/转债）的价格序列：
1. 冷启动：累积变化值达 2% 时，由正负判定首趋势（up 或 down）
   ├─ 首个高关键点 = 起始最高点
   └─ 首个低关键点 = 起始最低点

2. 逐日遍历价格，按当前状态套用转移规则：
   ├─ 当前 up：按 §2.3 up 规则判断
   ├─ 当前 upDraw：按 §2.3 upDraw 规则判断
   ├─ 当前 down：镜像 up 规则
   ├─ 当前 downDraw：镜像 upDraw 规则
   └─ 当前 minority：按 §2.3 minority 规则判断

3. 记录关键点日志（区分 Update vs Break）

4. 输出：当前趋势状态 + 关键点序列
   ├─ up/down → 趋势延续，顺势仓位
   ├─ upDraw/downDraw → 趋势中回调/反弹，观望或减仓
   └─ minority → 次要波动，无信号
```

## 三、跨资产适应性调整（本篇差异化价值）

### 3.1 固定一套参数会踩坑

不同弹性资产需分别设阈值：

| 资产 | 阈值经验 | 结论 |
|---|---|---|
| **利率债** | 大阈值 0.8%/**边际 0.4%** 反向、小阈值 0.2% 顺势 | **双阈值叠加最佳**：小波动顺势 + 大级别（0.8%+）趋势确认后反向 |
| **信用债**（城投/企债）| 0.2% 阈值 / 0.05% 边际 | **反转式建仓更优**：自然回撤时建仓买入、趋势确认后卖出 |
| **转债** | 忽略 1% 波动顺势有长期获利；2.5%+ 阈值确认的下行趋势 | 下行趋势确认后"反向抄底可以考虑" |

### 3.2 纯债参数总纲（最重要的经验总结）

> 💡 **纯债参数总纲**：设定 **20bps 左右的阈值**（注：bps 指价格波动而非收益率）即可刻画多数纯债券类的趋势——这是全文最重要的经验总结，可作为纯债落地的默认起点。

**债券示例参数**：反转阈值 50bps、有效突破 20bps（`srsAnalysis(initThres=0.02, reverseThreshold=0.005, margin=0.002)`）。

> 📖 [中金固收 2022.2](../../raw/articles/[202202131426]中金固收技术如何快速分辨趋势Python实现趋势分析及债市中的适应性调整.md)："设定 20bps 左右的阈值即可刻画多数纯债券类的趋势。"（编者注：bps 指价格波动而非收益率）

### 3.3 ⚠️ 固收/低弹性资产的确认滞后风险

> 📖 [中金固收 2022.2](../../raw/articles/[202202131426]中金固收技术如何快速分辨趋势Python实现趋势分析及债市中的适应性调整.md)："除转债之外，**债券类资产的移动边界有限，已经明确形成字面意思的趋势后，是否还是好的入场点**（尤其考虑到确认时滞后）。"

**含义**：低波动资产做趋势跟踪，信号确认时往往行情已走完，入场点差。利率债大阈值趋势确认后反成反向指标。

## 四、选股/择时规则（需配仓位规则才成策略）

### 4.1 趋势状态信号

```
每日盘后，对每个标的：
1. 用状态机算当前趋势状态（up/down/upDraw/downDraw/minority）
2. 判断信号：
   ├─ up → 上升趋势，顺势持仓/加仓
   ├─ down → 下行趋势，空仓或反向
   ├─ upDraw → 上行中回调，观望（可能是自然回撤，也可能转 down）
   ├─ downDraw → 下行中反弹，观望
   └─ minority → 次要波动，无信号
3. ⚠️ 配仓位规则：
   ├─ up 时满仓、upDraw 时半仓、down 时空仓
   └─ 或结合关键点：突破高关键点+margin 加仓、跌破低关键点+margin 清仓
```

### 4.2 与动量因子的配合

07y 可作为 07a-e 动量因子的**趋势状态过滤层**：

```
组合策略（07e 动量 + 07y 趋势状态）：
1. 07e 选出动量股
2. 07y 过滤：只保留状态为 up（非 upDraw/down/minority）的
3. 等权持仓
```
