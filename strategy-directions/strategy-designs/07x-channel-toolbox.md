## 一、策略定位

### 1.1 工具定位（不是策略）

⚠️ **先纠正一个定位**：通道技术**不是策略，是工具**——判断价格相对高低的方法，要配上仓位/止盈止损规则才成为策略。

> 📖 [国君 2022.10](../../raw/articles/[202210281436]国君配置通道技术之历史沿革直接法vs间接法通道技术面面观系列之01.md)："通道技术提供的并不是一种策略，而是一种旨在判断价格相对高低的**工具**。"

**直接把"突破"当买入信号会过度解读**——通道只告诉你"价格到了相对高位/低位"，至于买不买、买多少、何时卖，要另配规则。

### 1.2 这个工具在 07 家族里的角色

| 策略 | 角色 | 形态 | 与本工具（07x）的关系 |
|---|---|---|---|
| 07a/b/c/e | 个股 alpha | 因子选股 | 07x 给它们做趋势确认 |
| 07d | 行业 alpha | 因子选行业 | — |
| **07x 通道技术** | **趋势工具** | **价格相对高低判断** | — |
| 07y 利弗莫尔 | 趋势工具 | 状态机 | 与 07x 互补 |

**定位**：07x 是趋势跟踪的系统化表达——动量是"买强卖弱"，通道突破是"趋势确认后顺势"。可作为 07a-e 的**趋势确认层**（如：07e 选出的动量股，再用通道过滤"是否在上升趋势中"）。

### 1.3 不适合什么场景

- **当独立策略用**：通道本身不是策略，直接用"突破"信号会过度解读
- **追求 A 股回测绩效**：本篇无 A 股回测，只有方法论
- **震荡市**：通道突破在震荡市频繁假突破，需配过滤规则

## 二、信号逻辑：通道技术分类与统一引擎（核心）

### 2.1 核心分类——直接法 vs 间接法

所有通道技术按"上下轨怎么生成"分两派：

| 派系 | 上下轨生成方式 | 代表 |
|---|---|---|
| **直接法** | 直接用价格数据生成上下轨（如 N 日最高/最低）| Donchian |
| **间接法**（**主流**）| 先生成价格中枢（均线），再在中枢上下加减偏移 | Bollinger/Keltner/Bomar/PB |

> 📖 [国君 2022.10](../../raw/articles/[202210281436]国君配置通道技术之历史沿革直接法vs间接法通道技术面面观系列之01.md)："间接法和直接法之间的区别在于上下道带的生成方式是否需要依赖中枢：直接法 = 直接通过数据生成通道上下道带；间接法 = 利用价格中枢生成通道上下道带……**间接法是通道技术的主流方法**。"

### 2.2 统一引擎——"中枢+偏移"（一套代码实现所有通道）

> 📖 [国君 2022.10](../../raw/articles/[202210281436]国君配置通道技术之历史沿革直接法vs间接法通道技术面面观系列之01.md)："直接法可通过'反向工程'归一为间接法——令中枢 =（上轨 + 下轨）/2 即可。"

**落地关键**：用一套"中枢 + 偏移"的间接法引擎就能统一实现所有通道（含 Donchian 这类直接法），显著简化代码。

```
统一引擎（所有通道共用）：
  上轨 = 中枢 + 上偏移
  下轨 = 中枢 − 下偏移

各通道的差异只在"中枢怎么算、偏移怎么算"：
  ├─ Donchian：中枢 = (N日最高 + N日最低)/2，偏移 = (N日最高 − N日最低)/2
  ├─ Bollinger：中枢 = N日均线，偏移 = K × N日收盘价标准差
  ├─ Keltner：中枢 = 典型价TP的N日均线，偏移 = 日内极差DR的N日均线
  ├─ Bomar：中枢 = 均值，上轨 = 过去250周期>均值数据的85%分位，下轨 = <均值数据的15%分位
  └─ PB百分比带：中枢 = 移动平均，偏移 = 中枢 × 固定百分比
```

### 2.3 五个可落地的经典通道

| 通道 | 派系 | 规则 | 关键参数 |
|---|---|---|---|
| **Donchian** | 直接法 | 突破 N 周最高买入、突破 N 周最低卖出 | 经典 **四周规则（N=4 周）** |
| **Bollinger 带** | 间接法 | 均线 ± K×标准差；正规化为 %B（价格在带中位置）和 BandWidth（带宽）| 业界标准 20 日均线 ±2σ；可换指数加权做"指数型 Bollinger"加快响应 |
| **Keltner 通道** | 间接法 | 典型价 TP 的 10 日均线 ± 日内极差 DR 的 10 日均线 | 用真实波动（极差）而非收盘标准差 |
| **Bomar 带** | 间接法（自适应）| **史上第一种自适应/分位数通道**：中枢=均值，上轨=过去 250 周期大于均值数据的 85% 分位、下轨=小于均值数据的 15% 分位 | N=250、85%/15% 分位；非参数化、对极端值稳健 |
| **PB 百分比带** | 间接法 | 中带=移动平均，上下带=中带 ×（1±固定百分比）| 如 ±5%；最朴素、适合做 baseline |

> 💡 **唯一融合基本面的通道——EV 估值包络**（Geraldine Weiss 1966）：与上述纯价格派不同，EV 用**股息折现模型（DDM）**确定包络上下界，是通道技术史上"把基本面塞进通道"的唯一范式。可启发"估值通道"思路（用 PE/PB 分位构造上下界）做价值+技术混合策略。

### 2.4 通道信号的解读（%B 与 BandWidth）

Bollinger 正规化为两个指标，比单纯看突破更有信息量：

| 指标 | 定义 | 含义 |
|---|---|---|
| **%B** | （价格 − 下轨）/（上轨 − 下轨）| 价格在带中位置：0=下轨、0.5=中枢、1=上轨 |
| **BandWidth** | （上轨 − 下轨）/ 中枢 | 带宽：小=波动压缩（酝酿变盘）、大=波动扩张 |

## 三、选股/择时规则（需配仓位规则才成策略）

### 3.1 通道突破信号（基础，需配规则）

```
每日盘后，对每只标的（股/债/转债/ETF）：
1. 用统一引擎算上轨、下轨、中枢
2. 判断信号：
   ├─ 收盘价 > 上轨 → 突破上轨（趋势向上确认）
   ├─ 收盘价 < 下轨 → 跌破下轨（趋势向下确认）
   └─ 下轨 ≤ 收盘价 ≤ 上轨 → 区间内（无信号）
3. ⚠️ 信号本身不构成买卖，需配规则：
   ├─ 仓位规则：突破上轨买入 X 仓位、跌破下轨清仓
   ├─ 止盈止损：跌破中枢止损、突破上轨+N% 止盈
   └─ 过滤规则：BandWidth 压缩到阈值以下才认突破（避免震荡市假突破）
```

### 3.2 与动量因子的配合（推荐用法）

07x 最有价值的用法是**作为 07a-e 动量因子的趋势确认层**：

```
组合策略（07e 动量 + 07x 通道确认）：
1. 07e 长端动量 2.0 选出前 10% 动量股
2. 07x 通道过滤：只保留"收盘价 > 上轨"（上升趋势确认）的
3. 等权持仓，月末调仓
```

这种"动量选股 + 通道择时"的组合，比单纯动量因子多一层趋势保护。

### 3.3 跨资产适用

通道技术天然跨资产——股/债/转债/ETF/期指都能用：

| 资产 | 推荐通道 | 备注 |
|---|---|---|
| 股票/ETF | Donchian 四周规则、Bollinger 20日±2σ | 经典趋势跟踪 |
| 债券 | Keltner（用极差而非标准差，债市波动小）| 07y 利弗莫尔也推荐 |
| 转债 | Bomar（自适应分位数，转债弹性变化大）| 对极端值稳健 |

## 四、调仓与持仓（取决于配的规则）

### 4.1 调仓频率

通道技术本身是**日频跟踪**（每日判断是否突破），但实际调仓频率取决于配的规则：
- 日频跟踪 + 月末调仓（与动量因子配合）
- 日频跟踪 + 信号触发即调仓（纯趋势跟踪，换手高）

### 4.2 持仓方式

取决于配的仓位规则：
- 等权持仓（突破上轨的等权配置）
- 仓位缩放（按 BandWidth 或波动率缩放）

### 4.3 费用

**双边千三**（股票）/ ETF 更低。纯趋势跟踪换手高，费用侵蚀需注意。
