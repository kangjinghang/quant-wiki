## 一、策略定位

### 1.1 赚什么钱

**风格偏移的均值回归 + 动量**：A 股风格相对跑赢幅度在两个月窗口（40 交易日）下基本在 **±20% 以内**。未到边界时市场倾向延续原方向（动量），触及边界后大概率均值回归（反转）。一个规则两种模式自动切换。

**alpha 来源**：用动态阈值（95% 分位，随波动自适应）+ 缓冲带（0.5σ，防抖）判断当前偏移度是否触及反转边界。比固定 ±20% 更稳健。

> 📖 [中金 2022](../../raw/articles/[202204101426]中金固收风格轮动规律策略与Python实现.md) §一："两个月窗口下，市场整体的轮动偏移幅度基本在正负 20% 以内（不考虑 2015 年那一次过大的波动）……正负 20% 是风格偏移的边际值，若触及则后续大概率会出现均值回归……正负 10% 已经具备较大约束力。但值得注意的是，在来到边界值之前，市场倾向于延续原来的方向。"

## 二、信号逻辑（核心）

### 2.1 核心机制：±20% 是反转边界，未到边界就顺势

> 📖 [中金 2022](../../raw/articles/[202204101426]中金固收风格轮动规律策略与Python实现.md) §一："我们对近 10 年的风格相对跑赢幅度进行统计，以上证 50 和中证 1000 分别代表大\小盘，国证成长和国证价值代表成长\价值。相对稳定的结论是，两个月窗口下，市场整体的轮动偏移幅度基本在正负 20% 以内（不考虑 2015 年那一次过大的波动）。"

**这给了"动量 vs 反转为什么共存"的机制答案**：**未到边界=动量（顺势），到边界=反转（均值回归）**。一个规则两种模式自动切换。

**成长价值分化较大小盘弱**：

> 📖 [中金 2022](../../raw/articles/[202204101426]中金固收风格轮动规律策略与Python实现.md) §一："同时我们发现成长价值的分化较大小盘而言更弱，即使不考虑 2014-2015 年。"

### 2.2 风格对定义（现成宽基，最简）

> 📖 [中金 2022](../../raw/articles/[202204101426]中金固收风格轮动规律策略与Python实现.md) §二 图表4：

```python
def getDictPairs():

            "ValueGrowth": ["399371.SZ", "399370.SZ"]})
```

| 风格对 | 成分 [0]（被减数）| 成分 [1]（减数）| divergence 正值含义 |
|---|---|---|---|
| BigSmall | 上证 50（000016.SH）| 中证 1000（000852.SH）| 大盘跑赢 |
| ValueGrowth | 国证价值（399371.SZ）| 国证成长（399370.SZ）| 价值跑赢 |

⚠️ **方向符号易错**：divergence 公式是 `成分[0] − 成分[1]`，即 `BigSmall = 上证50 − 中证1000`（正值=大盘跑赢）、`ValueGrowth = 国证价值 − 国证成长`（正值=价值跑赢）。

### 2.3 divergence() 函数（算 N 日滚动跑赢幅度）

> 📖 [中金 2022](../../raw/articles/[202204101426]中金固收风格轮动规律策略与Python实现.md) §二 图表4：

```python
def divergence(dictPairs, start, end, lstDay=None):
    if lstDay is None:
        lstDay = [40]
    lstCodes = []
    for v in dictPairs.values():
        lstCodes += v
    _, dfPct = w.wsd(",".join(lstCodes), "Close", dayOffset(start, -max(lstDay) - 1), end, usedf=True)
    dfRet = pd.DataFrame(index=dfPct.index)
    for n in lstDay:
        for k, v in dictPairs.items():
            dfPctRolling = dfPct.rolling(n).apply(lambda x: 100 * (x[-1] / x[0] - 1))
            dfRet[k + ":{_n} days".format(_n=n)] = dfPctRolling[v[0]] - dfPctRolling[v[1]]
    dfRet.index = map(lambda x: x.strftime("%Y/%m/%d"), pd.to_datetime(dfRet.index))
    return dfRet.dropna(how="any")
```

**公式**：

$$\text{divergence}_k = 100 \times \left(\frac{P_{t}^{\text{成分}[0]}}{P_{t-n}^{\text{成分}[0]}} - 1\right) - 100 \times \left(\frac{P_{t}^{\text{成分}[1]}}{P_{t-n}^{\text{成分}[1]}} - 1\right)$$

即：成分 [0] 的 N 日累计涨跌幅（%）− 成分 [1] 的 N 日累计涨跌幅（%）。默认 N=40。

### 2.4 rotation() 择时函数（动态阈值 + 缓冲带）

> 📖 [中金 2022](../../raw/articles/[202204101426]中金固收风格轮动规律策略与Python实现.md) §二 图表6：

**阈值/缓冲带计算**：

```python
thetaSize, thetaStyle = obj.divergence.iloc[idx - 250:idx].abs().quantile(0.95)
epsilonSize, epsilonStyle = obj.divergence.iloc[idx - 250:idx].abs().std() / 2.
```

| 参数 | 含义 |
|---|---|
| **theta** | 过去 1 年（250 交易日）40 日累计偏移度的 **95% 分位数**（动态阈值）|
| **epsilon** | 偏移度绝对值的 **0.5 倍标准差**（缓冲带）|

**决策逻辑**：

```python
for k, v in stylePicks.items():
    # direction = sign(score)（当前偏移方向）
    # 判定：当前状态距离阈值是否较远
    if abs(v['score'] - v['theta'] * v['direction']) >= v['epsilon']:
        v["choice"] = v["direction"] if abs(v["score"]) < v["theta"] else -v["direction"]
    else:
        v['choice'] = -v['direction']
    v['choice'] = v['category'][0] if v['choice'] == 1 else v['category'][1]
```

**逻辑翻译**：

| 条件 | choice | 模式 |
|---|---|---|
| 距阈值远 且 未突破（`abs(score) < theta`）| `direction`（顺势）| **动量**（延续原方向）|
| 距阈值远 且 已突破（`abs(score) ≥ theta`）| `−direction`（反向）| **均值回归**（反转）|
| 距阈值近（落入 epsilon 缓冲带）| `−direction`（反向）| **提前反转**（防抖）|

### 2.5 为什么用动态阈值而非固定 ±20%

> 📖 [中金 2022](../../raw/articles/[202204101426]中金固收风格轮动规律策略与Python实现.md) §二 图表6 注释："这里我们采取动态把控，而非定量的阈值。"，"当换仓时，风格偏离未接近阈值时，我们遵循市场风格偏移的势能；若突破阈值，则做反向处理。"

**机制内涵**（原文实现，口语化解释属合理推断）：
- 95% 分位随波动自适应——行情剧烈时阈值自动放宽，避免频繁误触发
- 0.5σ 缓冲带防止在阈值附近来回抖动
- 逼近阈值（缓冲带内）即提前反向，进一步防抖

### 2.6 中长期 vs 短期的时间窗口分层（关键认知）

> 📖 [中金 2022](../../raw/articles/[202204101426]中金固收风格轮动规律策略与Python实现.md) §一："而如果我们拉长窗口，能看到成长更容易在长时间窗口占据优势。也即，上述'40 交易日 20%'的约束关系聚焦于中短期，与更长期限视角下，风格的优劣势具备趋势性不矛盾。但在大小盘中，这样的趋势性则更不明显。"

**含义**：±20% 边界聚焦**中短期（40 交易日）**；长期趋势**偏好成长**（大小盘则无此长期趋势性）。

**落地启示**：用动态阈值做波段反转时，**对成长方向的"反向做空"要更谨慎**——长期趋势在成长这边，反转收益的天花板天然更低。

### 2.7 算法完整流程（以 2026 年 6 月末为例）

```
步骤 1：算 divergence（每日）
  ├─ 取上证50、中证1000、国证价值、国证成长收盘价
  ├─ BigSmall = rolling_40日涨幅(上证50) − rolling_40日涨幅(中证1000)
  └─ ValueGrowth = rolling_40日涨幅(国证价值) − rolling_40日涨幅(国证成长)
      正值=大盘/价值跑赢

步骤 2：算动态阈值（每日）
  ├─ theta = 过去250日的 divergence 绝对值的 95% 分位数
  └─ epsilon = 过去250日的 divergence 绝对值的 std / 2

步骤 3：判定（每日）
  ├─ direction = sign(divergence)
  ├─ if abs(score - theta*direction) >= epsilon:  # 距阈值远
  │   ├─ if abs(score) < theta: choice = direction   # 未突破→顺势（动量）
  │   └─ else: choice = -direction                   # 已突破→反向（反转）
  └─ else: choice = -direction                        # 距阈值近→提前反向（防抖）

步骤 4：落地
  ├─ BigSmall choice=+1 → 配大盘（上证50 ETF）
  ├─ BigSmall choice=-1 → 配小盘（中证1000 ETF）
  ├─ ValueGrowth choice=+1 → 配价值（国证价值 ETF / 红利 ETF）
  ├─ ValueGrowth choice=-1 → 配成长（国证成长 ETF / 创业板 ETF）
  └─ 信号触发即调（实战日/周频）
```

## 三、选股/选风格规则

### 3.1 每日盘后例行流程

```
每日盘后：
1. 算 divergence（4 个指数的 40 日滚动偏移度）
2. 算动态阈值 theta + 缓冲带 epsilon（过去 250 日）
3. 判定 choice（顺势/反向/提前反向）
4. 落地：按 choice 配对应 ETF
5. 信号触发即调（日/周频）
```

### 3.2 硬过滤

本策略无硬过滤——直接用现成宽基指数的偏移度，不涉及个股选股。

### 3.3 ⚠️ 前视偏差检查

- **divergence**：用 T 日收盘价算 T 日的 40 日滚动偏移度，T 日盘后即可用
- **动态阈值**：用 T 日及之前 250 日的 divergence，无前视
- **无财报数据**：本策略纯量价，不涉及 PIT 问题
