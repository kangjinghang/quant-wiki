# #08z 风格轮动 · 华安 BP 因子改造 — 详细实现

> **定位**：本文是 [`08-style-rotation.md`](../strategy-playbooks/08-style-rotation.md) **配方 D 的副产品 + §七组合潜力里的选股方向**——把风格轮动信号反过来改造 alpha 选股因子（BP），把风险因子 alpha 化。属于 playbook 之外的独立 alpha。
>
> **角色**：**选股落地路径**。其他策略（08a/b/c/d/e）都是"选风格"（配置风格 ETF），本策略是"用风格信号选个股"——看好价值时用 BP、看好成长时用 PB 替代当期因子值，把 BP 因子多头超额从 3.74% 提到 11.48%。
>
> **来源**：[📖 华安金工 2023.12《风格轮动三部曲》](../../raw/articles/[202312191611]华安金工风格轮动三部曲重构探索和实践量化研究系列报告之十四.md) §4.2（BP 因子改造，唯一主源）。

## 一、策略定位

### 1.1 赚什么钱

**风格轮动信号的第二条应用路径**——轮动信号不只用来选风格 ETF，还能反过来改造 alpha 选股因子。

**alpha 来源**：BP（账面市值比）因子在价值风格占优时效果好，但在成长风格占优时失效（因为成长股 PB 高、BP 低，被 BP 因子错误剔除）。华安的改造：**看好价值时 BP 不变，看好成长时以 PB 替代当期因子值**——让 BP 因子在不同风格环境下都有效。

> 📖 [华安 2023](../../raw/articles/[202312191611]华安金工风格轮动三部曲重构探索和实践量化研究系列报告之十四.md) §4.2："以改进 BP 因子为例，当轮动信号看好价值风格时，因子值保持不变；看好成长风格时，以 PB 作为当期的因子值。"

### 1.2 在家族里的角色

| 策略 | 角色 | 与本策略（08z）的关系 |
|---|---|---|
| **08z 华安 BP 改造** | **选股落地** | — |
| 08d 华安三层 | 最稳（轮动信号源）| 本策略用 08d 的轮动信号改造 BP |
| 08a 招商赔率胜率 | 个股层主力 | 本策略的轮动信号也可来自 08a |
| 06 估值与价值因子 | 选股因子库 | 本策略与 [06](06-shared-valuation-infrastructure.md) 叠加价值极高 |

**与 06 估值与价值因子的关系**：本策略是风格轮动 → 选股因子的桥梁，与 [06 估值与价值因子](06-shared-valuation-infrastructure.md) 天然耦合（详见 §七）。

### 1.3 适合什么场景

- **选股落地**：不想只配风格 ETF，想在风格池内选个股
- **价值因子增强**：把 BP 因子多头超额从 3.74% 提到 11.48%
- **风格 + 选股双层 alpha**：风格层用轮动信号，选股层用改造后的 BP

### 1.4 不适合什么场景

- **只要风格敞口**：直接用风格 ETF 更省事（08a/d/e）
- **无轮动信号源**：本策略依赖 08a/d 的轮动信号，需先跑通其中一个
- **2023 后（分析师预期失效）**：改造后的 BP 用到中性化，质量受影响

## 二、信号逻辑（核心）

### 2.1 改造规则

**核心规则**：

$$\text{改造后 BP}_i = \begin{cases} \text{BP}_i & \text{if 轮动信号看好价值} \\ \text{PB}_i & \text{if 轮动信号看好成长} \end{cases}$$

> 📖 [华安 2023](../../raw/articles/[202312191611]华安金工风格轮动三部曲重构探索和实践量化研究系列报告之十四.md) §4.2："当轮动信号看好价值风格时，因子值保持不变；看好成长风格时，以 PB 作为当期的因子值。"

**逻辑**：
- **看好价值时**：市场偏价值，BP 因子天然有效（价值股 BP 高），保持不变
- **看好成长时**：市场偏成长，BP 因子失效（成长股 BP 低被错误剔除），用 PB 替代（PB 低的成长股反而被低估，是机会）

### 2.2 轮动信号来源

本策略的轮动信号来自 [08d 华安三层](08d-huaan-three-layer-event.md) 或 [08a 招商赔率胜率](08a-odds-winrate-framework.md)——任一跑通的回测策略都可作为信号源。

**推荐用 08d**（IR 2.27，最稳）：
- 08d 复合得分 > 0 → 看好成长 → 用 PB
- 08d 复合得分 < 0 → 看好价值 → 用 BP

### 2.3 未中性化的改造效果

> 📖 [华安 2023](../../raw/articles/[202312191611]华安金工风格轮动三部曲重构探索和实践量化研究系列报告之十四.md) §4.2："未做中性化处理的新 BP 因子的 Rank IC 均值达 7.6%，年化 ICIR 为 1.6，多头年化超额为 14.3%，空头年化超额 -19.11%，均远胜于原始 BP 因子。"

| 指标 | 改造后 BP（未中性化）| 原始 BP |
|---|---|---|
| Rank IC 均值 | **7.6%** | 较低 |
| 年化 ICIR | **1.6** | 较低 |
| 多头年化超额 | **14.3%** | 较低 |
| 空头年化超额 | -19.11% | — |

### 2.4 中性化后的改造效果（关键提升）

> 📖 [华安 2023](../../raw/articles/[202312191611]华安金工风格轮动三部曲重构探索和实践量化研究系列报告之十四.md) §4.2："经过行业市值中性化处理后，改进后的因子同样在 IC 表现、多空收益和回撤方面有明显提升，尤其是多头端，年化超额由 3.74% 提升至 11.48%。"

| 指标 | 中性化后改造 BP | 中性化后原始 BP |
|---|---|---|
| 多头年化超额 | **11.48%** | **3.74%** |

**含义**：中性化后，改造 BP 把多头超额从 3.74% 提到 11.48%（提升 3 倍）。

### 2.5 中性化处理（行业市值中性化）

详见 [02-shared §三](02-shared-industry-rotation-infrastructure.md) 的风格中性化工程规范。要点：

**第一步**：股票层回归取残差

对改造后 BP 因子 $f$，在截面对行业哑变量 + log(市值) 做线性回归，取残差：

$$f_{\text{neutralized}} = f - (\beta_0 + \sum_{j} \gamma_j \cdot \text{行业}_j + \beta_{\text{size}} \cdot \log(\text{市值}))$$

**第二步**：残差即为中性化后的改造 BP，用于选股排序。

### 2.6 算法完整流程（以 2026 年 6 月末为例）

```
步骤 1：获取轮动信号（来自 08d 或 08a）
  ├─ 跑 08d 三层事件法 → 复合得分
  └─ 复合得分 > 0 → 看好成长；< 0 → 看好价值

步骤 2：构造改造后 BP（每月末）
  ├─ 看好价值 → 改造 BP = 原始 BP
  └─ 看好成长 → 改造 BP = PB（市净率）

步骤 3：行业市值中性化
  ├─ 对改造 BP 回归：行业哑变量 + log(市值)
  └─ 取残差 = 中性化后改造 BP

步骤 4：选股
  ├─ 全市场按中性化后改造 BP 排序
  ├─ 取前 10%（或前 50 只）
  └─ 等权持仓

步骤 5：落地（月频调仓）
  └─ 次月首个交易日开盘买入
```

## 三、选股/选风格规则

### 3.1 每月末盘后例行流程

```
每月末盘后：
1. 获取轮动信号（08d 复合得分 或 08a 赔率胜率期望）
2. 构造改造后 BP（看好价值用 BP、看好成长用 PB）
3. 行业市值中性化（回归取残差）
4. 全市场排序取前 10%
5. 落地：等权持仓 30-50 只
6. 月频调仓
```

### 3.2 硬过滤

| 过滤条件 | 阈值 | 作用 | 优先级 |
|---|---|---|---|
| 负 BP/PB | 剔除（亏损股）| 避免负值干扰 | **必加** |
| 上市天数 | >250 | 砍新股次新股 | 推荐 |
| ST 股 | 剔除 | 避免退市风险 | 推荐 |
| 行业市值中性化 | 强制 | 提纯效果（3.74%→11.48%）| **必加** |

### 3.3 ⚠️ 前视偏差检查

- **轮动信号**：来自 08d/08a，需遵循其前视防护（见各策略 §3.3）
- **BP/PB**：用 T 日收盘价计算（市值/净资产），T 日盘后可用
- **净资产**：用最新已披露季报（PIT 对齐，季报披露日 ≠ 报告期）
