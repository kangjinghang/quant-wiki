## 一、整体架构

盈利质量策略与 PEAD/景气等"成长型 alpha"不同——它的核心价值是**剔除坏公司**（规避暴雷），而非选出最赚的。因此家族架构以"多层过滤漏斗"为主线：

```
┌──────────────────────────────────────────────────────────────┐
│  数据层（财务三表 + 现金流构成 + 财务附注 + 事件公告）          │
│  ├─ 季度财报：利润表 / 资产负债表 / 现金流量表（单季值）        │
│  ├─ 现金流构成：支付给职工 / 其他经营相关 / 上期现金流           │
│  ├─ ROE_ttm + 历史序列（9 季以上）                              │
│  ├─ 财务附注（Wind）：存货在产品 / 坏账准备明细                 │
│  ├─ 事件公告：ST/监管处罚 / 8 类负向事件                        │
│  ├─ 过滤数据：金融行业 / ST / 涨跌停 / 上市天数                 │
│  └─ 行业分类：中信一级（>100 只下沉二级）                       │
│         ↓                                                      │
├──────────────────────────────────────────────────────────────┤
│  前视偏差防护层（所有策略强制调用）                             │
│  ├─ 财报可见性检查：T 时点能否看到本期财报？                    │
│  ├─ 单季值算法：累计数相减（见 §三）                            │
│  └─ TTM 算法：最近 4 个单季值求和（见 §三）                     │
│         ↓                                                      │
├──────────────────────────────────────────────────────────────┤
│  信号层（各策略独立，见 09a/b/c/d/e/x/y）                       │
│  ├─ 09a：异常现金流 ABCFO（Q1/Q5，正向因子）                    │
│  ├─ 09b：IV/WOE 评分卡（45 指标，事前剔除）                     │
│  ├─ 09c：ROE 三维稳定性（盈利/成长/杠杆，反向因子）             │
│  ├─ 09d：7 维度 18 指标阈值（规则驱动，避雷）                   │
│  ├─ 09e：附注质量（存货管理 + 坏账管理，复合因子）              │
│  ├─ 09x：8 类负向事件（日频事后剔除）                           │
│  └─ 09y：质量增长 / 质量加速（进攻型增量）                      │
│         ↓                                                      │
├──────────────────────────────────────────────────────────────┤
│  下单层（QMT xtquant.xttrader，所有策略共享）                   │
│  ├─ 读各策略输出的 order_list.csv                              │
│  ├─ 批量下单（开盘价限价 / VWAP）                              │
│  ├─ 多频率协调：日频(09x) / 月频(09c/d/y) / 季频(09a/b) / 半年(09e) │
│  └─ 费用扣除（双边千三）                                       │
└──────────────────────────────────────────────────────────────┘
```

### 多层过滤漏斗（家族默认组合方式）

> 📖 招商金工 2025.3《基于财务健康指标体系的投资全解析》：即便专业投资者的高质量多头组合（6 大类因子综合评分第 5 组）里**仍含约 6.14% 的风险股**——证明多层剔除叠加到任何多头策略上都能进一步净化组合。

```
原始候选池（如某指数成分股，剔除金融 + ST + 上市<1 年）
   │
   ├─【第一层·事前剔暴雷】09b 评分卡 OR 09d 阈值避雷（二选一或叠加）
   │   └─ 剔除评分最低 10% / 综合风险前 5%
   │
   ├─【第二层·事后兜底】09x 日频事件黑名单
   │   └─ 命中 8 类负向事件即时剔除
   │
   ├─【第三层·剔盈余操纵】09a 异常现金流
   │   └─ 剔除 ABCFO 显著偏低（真实盈余管理嫌疑）
   │
   ├─【第四层·选真稳健】09c ROE 稳定性（从高 ROE 池选）
   │   └─ 取稳定性最高组（波动性最小）
   │
   └─【正交增量】09e 附注质量 + 09y 质量增长（叠加进多因子打分）
       └─ 与上述信息源正交，提供增量 alpha
```

### 2.3 关键数据字段说明

#### 财务数据（所有策略基础）——必须用"单季值"

A 股财报给的是**累计数**，必须自己减算单季度：

| 报告 | 累计数 | 单季值算法 |
|---|---|---|
| 一季报 | Q1 累计 | = Q1 累计（本身）|
| 中报 | H1 累计 | = H1 累计 − Q1 累计 |
| 三季报 | 9M 累计 | = 9M 累计 − H1 累计 |
| 年报 | FY 累计 | = FY 累计 − 9M 累计 |

⚠️ **09a 异常现金流的特殊处理**：**剔除 Q4（四季度）数据**。

> 📖 [东北金工 2022.11](../../../raw/articles/[202211071013]基于异常现金流模型的真实盈余管理因子一因子选股系列之二.md) §4.1.1："鉴于年报公布日期与一季报公布日期非常接近，在因子的使用过程中，**我们剔除了四季度的因子数据**。"

#### TTM（滚动 12 个月）算法

09c/09d 多处用到 TTM 指标（ROE_ttm、营收_ttm 等）：

$$\text{TTM}_t = \text{单季}_t + \text{单季}_{t-1} + \text{单季}_{t-2} + \text{单季}_{t-3}$$

即最近 4 个单季值求和。⚠️ 跨年报时要注意 FY 单季 = FY 累计 − 9M 累计，不能直接用 FY 累计。

#### 现金流构成（09a 必需）

09a 的 ABCFO_Q5 模型需要现金流量表的细项构成，不是单一"经营活动现金流净额"：

| 字段 | 用途 |
|---|---|
| 经营活动现金流入小计 | 总规模 |
| **支付给职工以及为职工支付的现金** | Q4/Q5 解释变量 |
| **其他与经营活动有关的现金** | Q4/Q5 解释变量 |
| 上期经营活动现金流净额 | Q4 解释变量 |
| 销售商品提供劳务收到的现金 | 模型辅助 |

#### 行业分类（所有策略分行业处理用）

统一用**中信行业分类**。注意 09d 的 ST 预警模型有下沉规则：

> 📖 [招商金工 2025.3](../../../raw/articles/[202503181515]基于财务健康指标体系的投资全解析基本面量化系列研究之二.md) §3.1："当某一级行业的成分股数量少于 100 只时，直接使用该一级行业分类，当某一级行业成分股数量超过 100 只时，则下沉至对应的二级行业。"

#### 事件数据（09b/09x 必需）

| 事件类型 | 来源 | 用于 |
|---|---|---|
| ST/*ST（仅亏损导致）| 东财公告 | 09b 负例样本 |
| 监管处罚（标的为公司+两类违规）| 东财公告 | 09b 负例样本 |
| 业绩预告：续亏/略减/预减/首亏 | 东财公告 | 09x 事后剔除 |
| 公司改名/立案调查/董事长离职/高管减持>10% | 东财公告 | 09x 事后剔除 |

> 📖 [光大金工 2022.5](../../../raw/articles/[202205301200]光大金工高质量股票池构造体系Ⅱ事件型风险研究量化选股系列报告之六.md) §2：8 类负向事件 = 基本面 4 类（续亏/略减/预减/首亏）+ 经营 4 类（公司改名/立案调查/董事长离职/高管减持>10%）。

## 三、前视偏差防护层（所有策略强制调用）

### 3.1 财报可见性检查（最关键）

财务数据有严格披露窗口，**报告期 ≠ 可用时点**：

| 报告期 | 法定披露截止 | 最早可用时点（保守）|
|---|---|---|
| 一季报（Q1）| 4 月 30 日 | **4 月底** |
| 中报（H1）| 8 月 31 日 | **8 月底** |
| 三季报（9M）| 10 月 31 日 | **10 月底** |
| 年报（FY）| 4 月 30 日 | **4 月底** |

**强制规则**：任何策略在 T 时点用某期财报数据，必须确认该期财报**法定披露截止日 ≤ T**。

> 📖 这是量化最常翻车的地方。例：3 月底**还没看到**一季报（4 月才发），绝对不能在 3 月底用一季报数据选股。

### 3.2 调仓时点与因子更新频率（多频率协调）

盈利质量家族有**五个频率**，QMT 下单层要按各自时点触发：

| 频率 | 触发时点 | 策略 | 动作 |
|---|---|---|---|
| **日频** | 每日盘后 | 09x | 扫描事件黑名单，命中即时剔除 |
| **月频** | 每月调仓日 | 09c / 09d / 09y | 因子更新 + 组合再平衡 |
| **季频** | 每年 4/8/10 月底 | 09a / 09b | 财报披露后更新因子 |
| **半年频** | 每年 4 月末/8 月末 | 09e | 附注披露后更新因子 |
| **年频** | 每年 4 月底 | 09c 高 ROE 池筛选 | 圈定高 ROE 池（仅池筛选年频，组合月频再平衡）|

⚠️ **09c 的双层频率**：高 ROE 池筛选是**年频**（4 月底），但优选组合调仓是**月频**——别混。

> 📖 [申万宏源 2025.9](../../../raw/articles/[202509011600]剔除害群之马ROE稳定性视角构建高质量选股组合质量因子新语之系列一.md) §4.1："组合月度调仓，每月初停牌和一字板涨跌停的股票不参与交易，北交所股票不参与交易。"

### 3.3 行业内标准化（统一处理）

大部分财务因子需**分行业**处理（消除行业固有差异），统一用行业内 z-score 或行业内排名：

- **09a**：分行业、分年度（或分季度）回归 + **行业内标准化**
- **09c**：稳定性因子分行业计算波动性
- **09d**：连续型指标在中信一级行业内取头部/尾部 5%
- **09b**：分箱代替标准化（见 09b，更适合风控场景）

### 3.4 单边做空限制（A 股特殊性）

A 股不能做空，所有策略**只做多头端**：

- 多空绩效仅作因子有效性参考
- 实盘收益 = **多头超额**（多头年化 − 基准年化）
- 配方 A/B/D 的核心价值是"剔除器"——剔除坏公司，剩余做多

> 📖 [东北金工 2022.11](../../../raw/articles/[202211071013]基于异常现金流模型的真实盈余管理因子一因子选股系列之二.md) §4.1.1：全A 多头年化 9.90%、空头 -4.53%——A 股只能拿到多头端的 9.90%（超额 7.63%）。

## 四、公共规则

### 4.1 股票池基础剔除（所有策略共用）

| 剔除条件 | 阈值 | 理由 | 适用 |
|---|---|---|---|
| 金融行业 | 银行/非银/综合金融 | 财务结构特殊 | 09a（强制）、其余可选 |
| ST/*ST | 风险警示股 | 已暴雷 | 所有策略 |
| 上市天数 | >250 日（约 1 年）| 新股次新股数据不全 | 所有策略 |
| 停牌 | 当日停牌 | 无法交易 | 所有策略 |
| 涨跌停 | 一字板 | 无法成交 | 09c（明示）、其余建议 |

> 📖 [招商金工 2025.3](../../../raw/articles/[202503181515]基于财务健康指标体系的投资全解析基本面量化系列研究之二.md) §1.2："本篇在测试过程中所使用的股票池已剔除以下类型的股票：上市时间不足 1 年的新股、ST 及 *ST 等风险警示股票，过去三个月内存在 ST 或 *ST 等风险警示的股票。"

### 4.2 加权方式

| 场景 | 加权 | 依据 |
|---|---|---|
| 因子分组测试 | **市值加权** | 东北金工/光大/招商默认 |
| 多头选股组合 | **等权** | 申万宏源/东北金工·王琦默认（等权好于市值加权）|
| 指数增强（09a）| **指数权重迁移** | 东北金工系列二沪深300 增强 |

> 📖 [东北金工·王琦 2025.8](../../../raw/articles/[202508242040]资产负债表财务附注质量因子因子选股系列之十一.md) §2.2："全市场测试中等权结果好于市值加权结果。"

### 4.3 交易费用

**双边千三**（买入 + 卖出各 0.3%），与所有原文回测口径一致。

> 📖 [东北金工 2023.1](../../../raw/articles/[202301041958]基于异常现金流模型的真实盈余管理因子二因子选股系列之三.md) §2.1："交易费用采取双边千三。"

⚠️ **重要折扣**：原文绩效**多数未计涨跌停限制与冲击成本**——实战需打折，详见各策略 §六。

### 4.4 注册制时间红线（重要）

**多个配方的效力以 2016 年（注册制推进）为分界**：

> 📖 [光大金工 2022.5](../../../raw/articles/[202205301200]光大金工高质量股票池构造体系Ⅱ事件型风险研究量化选股系列报告之六.md) §3.5.1："低分组合在 **2016 年之后**表现明显弱于高分组合，而在此之前并没有明显的区分度。这是因为**注册制的推进**使得低质量股票的'壳价值'降低。"

**强制规则**：回测样本务必用 **2016 年后**的数据，否则高估剔暴雷效力。

## 五、QMJ 坐标系（理解家族定位的统一框架）

盈利质量家族的各配方在学界 QMJ（Quality Minus Junk）框架里的位置：

> 📖 [华泰金工 2024.12](../../../raw/articles/[202412051505]华泰金工基本面量化的当下和未来因子篇.md)：AQR 的 Asness 等 2019 从**盈利能力、成长性、安全性** 3 个维度拆解质量因子（6 盈利 + 5 成长 + 5 安全指标，等权合成）。

| 配方 | QMJ 维度 | 子类 | 性质 |
|---|---|---|---|
| 09a 异常现金流 | 安全性 | 会计质量/应计 | 防御·剔除 |
| 09b 财务危机预测 | 安全性 | 破产风险 | 防御·剔除 |
| 09c ROE 稳定性 | 成长性/稳定性 | 盈利稳定性（波动性口径）| 防御·精选 |
| 09d 7 维度阈值 | 安全性 | 综合扫雷 | 防御·剔除 |
| 09e 附注质量 | 安全性 | 会计质量（附注颗粒度）| 增量·多头 |
| 09x 事件型风险 | 安全性 | 事件冲击 | 防御·事后兜底 |
| 09y 质量增长/加速 | 成长性 | 质量变化量 | **进攻·增量** |

### 维度有效性的取舍依据

> 📖 [华泰金工 2024.12](../../../raw/articles/[202412051505]华泰金工基本面量化的当下和未来因子篇.md) 引 Hsu, Kalesnik & Kose (2019)：**盈利能力、会计质量（应计量）、派息/摊薄、投资能力**这 4 个维度存在显著超额收益；**资本结构、盈利稳定性、盈利增长**这 3 个维度没有超额收益（行业市值中性多空口径）。

⚠️ **张力提示**："盈利稳定性/盈利增长"单独无效，但本家族 09c 用的是"ROE 的**波动性**"（与稳定性同名但构造不同），波动性维度仍有效。09y 的"质量增长/加速"是"质量因子的变化量"，与单纯的"盈利增长"不同——华泰引述 Ma 等(2024) 证实 A 股有效。

> 📖 [华泰金工 2024.12](../../../raw/articles/[202412051505]华泰金工基本面量化的当下和未来因子篇.md) 引 Kyosev 等(2020)：从 8 项质量指标中筛出仅"**毛利润/总资产、应计项目、投资能力**"3 项能预测未来盈利增长（EP 类）。
