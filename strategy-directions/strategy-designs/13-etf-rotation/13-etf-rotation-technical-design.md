# #13 ETF轮动 · 资金流反向 — QMT 落地技术设计

> **定位**：本文是 [`13-etf-rotation.md`](../../strategy-playbooks/13-etf-rotation.md) 的**代码级落地设计**。#13 是 **#10 龙虎榜的扩容备选**——当资金从 <100万 长到 300万+，#10 容量开始吃紧（大宗3500万/调研1.1亿）时，转 #13 做主力。ETF T+0、费率低、无踩雷，是 QMT 最自然的落地标的。
>
> **数据现实（关键）**：ETF 日线行情 QMT xtquant 可覆盖；但**配方B的核心数据"ETF申赎资金流"QMT 完全没有**，必须走 akshare。更严峻的是——**深市 ETF 历史份额 akshare 无接口**（沪市有，深市只能拿当日快照），这是配方B落地的数据缺口，必须用日终累积快照自建历史。
>
> **所有 akshare 接口名/字段已对照源码确认**；策略参数来自 #13 playbook 原文。

## 0. 系统架构（三层分离 + 数据缺口应对）

```
┌─────────────────────────────────────────────────────────────┐
│  数据层（混合：QMT 行情 + akshare 申赎资金流）               │
│  ├─ ETF日线OHLCV：xtquant.get_market_data_ex(period="1d")   │
│  │                  或 akshare.fund_etf_hist_em             │
│  ├─ ⭐ETF申赎资金流（配方B核心）：                            │
│  │   资金流 = Δ份额 × 单位净值                               │
│  │   ├─ 份额：沪市 fund_etf_scale_sse(date)【可取历史】      │
│  │   │         深市 fund_etf_scale_szse() 【仅快照，无历史】 │
│  │   │         → 深市需日终累积快照自建历史（缺口应对）      │
│  │   └─ 净值：fund_etf_fund_info_em(fund)【单只历史】        │
│  └─ ETF基础信息：fund_etf_spot_em（规模/上市日近似）         │
├─────────────────────────────────────────────────────────────┤
│  信号层（纯 Python，周频盘后）                                │
│  ├─ 配方A（最简）：行业信号→两步法映射ETF                    │
│  ├─ 配方B（最强）：资金流滚动分位数→极端净流出开仓            │
│  └─ 配方D（前置工具）：实际偏离度选同指数最优ETF              │
├─────────────────────────────────────────────────────────────┤
│  下单层（QMT xtquant，周频开盘批量）                          │
│  └─ ETF T+0，盘后选→次日开盘买入，可日内调                   │
└─────────────────────────────────────────────────────────────┘
```

### 1.2 ⭐ 申赎资金流数据链路（配方B核心）

**资金流公式**：`net_flow = (今日份额 − 昨日份额) × 单位净值`

```
数据链路（伪代码）：
1. 份额序列：
   ├─ 沪市ETF：fund_etf_scale_sse(date) 按历史日逐日取 → 完整份额序列 ✅
   └─ 深市ETF：fund_etf_scale_szse() 仅当日快照
              → 必须每日盘后累积快照，自建深市份额历史表 ⚠️
2. 净值序列：fund_etf_fund_info_em(fund) 单只历史单位净值 ✅
3. 资金流：net_flow[t] = (share[t] - share[t-1]) × nav[t]
```

> 🔴 **数据缺口（深市历史份额）**：`fund_etf_scale_szse` 无日期参数，无法回溯深市 ETF 历史份额。两个应对：
> - **方案A（推荐起步）**：**只做沪市 ETF**（华泰配方B本就限行业ETF，沪市行业ETF覆盖足够起步）
> - **方案B（完整覆盖）**：从今日起每日盘后调 `fund_etf_scale_szse` + `fund_etf_spot_em` 累积快照，**3-6个月后**才能形成可回测的深市份额历史。即配方B深市部分有"冷启动期"。

### 1.3 ETF 标的筛选（国君硬门槛，所有配方通用）

```
筛选规则（每日更新）：
剔除以下ETF：
  ├─ 过去5日日均成交额 < 2000万元
  ├─ 最新规模 < 1亿元
  └─ 上市不足5个交易日
数据来源：fund_etf_spot_em（成交额/规模/上市日近似）
```

> ⚠️ **规模/上市日/跟踪指数**：akshare 无单一接口完整给出。规模用 `fund_etf_spot_em` 的总市值/流通市值近似；上市日仅深市 `fund_etf_scale_szse` 有；跟踪指数 akshare 未覆盖，需东财网页或手工维护映射表。

### 1.4 PCF 缺口（配方B广发三维法）

🔴 **akshare 无 PCF 申赎清单接口**。配方B广发三维法（PCF 下沉到成分股）所需每日 PCF 清单 akshare 完全没有，需交易所官网/基金公司/付费源。**本设计默认不实现广发三维法**，专注华泰时序法（不依赖 PCF）。

## 2. 信号层设计

### 2.1 配方B 华泰时序分位数法（最强，周频）

**机制**：ETF 申赎资金流是**反转信号**——极端净流出→反弹开仓，极端净流入→规避。

```
算法（伪代码）：
输入：某行业ETF的 net_flow 序列（至少2年）
1. 滚动分位数：quantile = rolling_rank(net_flow, window≈2年)
2. 信号：
   ├─ quantile < 0.05-0.10（极端净流出）→ 开仓（反弹博弈）
   ├─ quantile > 高阈值（极端净流入）→ 规避（只减仓，不加仓）
   └─ 否则 → 维持
3. 周频调仓（每周最后一个交易日盘后算）
```

**绩效对标**（playbook §二）：周频多头年化 >20%/年化超额 >26%/Sharpe>1/月开仓胜率~70%/盈亏比>1.4（2018.1-2024.7，基准=行业等权）。

> ⚠️ **阈值过拟合红线**（华泰）：5%/10% 阈值是 3窗口×5阈值全样本网格寻优结果，**存在过拟合风险**。实盘别盲目沿用最优组合，建议取参数高原（如 5%-10% 区间）而非孤岛点。

> ⚠️ **只在行业ETF有效**（playbook 红线）：宽基ETF无效（规模占比低、价格压力被稀释），板块ETF弱有效（~15%）。**必须剔除救市宽基**（2024汇金救市污染，剔后广发从10.2%→15.3%）。

### 2.2 配方A 行业信号映射（最简，月频）

**机制**：行业轮动模型选强势行业 → 两步法映射成 ETF 组合。

```
算法（伪代码，国君两步法）：
1. 行业信号：来自 #02 行业轮动（选前20%强势行业）
2. 映射规则（收益率匹配法）：
   ├─ 对每个行业，找日频收益相关 ≥ 0.6 的ETF
   ├─ 每行业选 N=3 只
   └─ 重合度 ≥ 30% 作为备选判据
3. 权重：等权 或 跟踪误差优化（行业偏离b=10%，双边换手T=2）
4. 月频调仓
```

**绩效对标**：国君最优组合年化17.87%（2020.1-2023.3）。

### 2.3 配方D ETF选优（前置工具，所有配方共用）

```
算法（伪代码）：
实际偏离度 = 跟踪偏离度(复权单位净值) + 溢价率变化(单位净值) − 日均冲击成本
  ├─ 冲击成本：单位变动成交额 = 使价格波动0.001元所需资金量（需分钟线）
  └─ 选偏离度最稳定的ETF
输入：M（计划交易金额）、T1-T2（持有区间）
```

> ⚠️ **评价结果非静态**（playbook 红线）：排名随 M 和时段变化，**不能抄原文排名**，要用自己的参数重算。

## 3. 下单层设计（QMT xtquant）

```
每周最后一个交易日盘后（配方B）：
1. 对备选池内每个行业ETF算资金流分位数信号
2. 极端净流出 → 开仓；极端净流入 → 减仓
3. 输出 order_list.csv

每周一开盘前（T+1）：
1. 读 order_list.csv
2. QMT xtquant 批量下单（ETF T+0，可市价或开盘价限价）
3. 持仓管理：周频调仓，信号反转才平仓
```

> 💡 **ETF T+0 优势**：相比 #10 个股（T+1），ETF 可日内调仓，下单层更灵活。资金容量也远大于 #10（中信建投实证 >5亿）。

## 5. 回测验证方案

**目标**：复现华泰配方B周频年化>20%/Sharpe>1。

```
1. 选5-10个行业ETF（沪市优先，避开数据缺口）
2. 拉沪市份额历史(fund_etf_scale_sse) + 净值历史
3. 算资金流，滚动2年分位数
4. 极端净流出(<10%)开仓，周频调仓
5. 对标年化>20%/Sharpe>1
   ├─ 偏差大：检查是否误含宽基/救市ETF
   └─ 行业ETF是否选对（有色/医药/家电/非银/电子优先）
```

> ⚠️ **样本期红线**：行业ETF 2019后才起量，有效回测期不足2年，结论可信度受限。回测达标后建议**纸面模拟1-2个月**再上实盘。

## 6. 红线与失效监控

| 红线 | 说明 | 应对 |
|---|---|---|
| 🔴 配方C周频失效 | 周度换仓ICIR边际提升不明显 | 配方C只月频；周频用配方B |
| 🔴 深市份额历史缺口 | fund_etf_scale_szse无日期参数 | 起步只做沪市；或日终累积自建 |
| 🔴 救市宽基污染 | 2024汇金救市宽基ETF大流入 | 剔除宽基，只留行业ETF |
| 阈值过拟合 | 5%/10%是网格寻优结果 | 取参数高原非孤岛 |
| 空头不可实操 | 融券费~10%、券源紧张 | 只做多+规避，不做空 |
| PCF缺数据 | 广发三维法依赖每日PCF | 不实现广发法，专注华泰时序法 |
| 配方D非静态 | 排名随M/时段变 | 用自己参数重算 |
