# #14x 指数增强 · 中证A500 基准增强 — 详细实现

> **定位**：本文是 [`14-index-enhancement.md`](../../strategy-playbooks/14-index-enhancement.md) 附加策略（来自 §二证据表）的**策略详细实现**——以中证A500（2024.9 新发）为基准的指数增强。A500 是沪深300 的行业中性升级版，可作 300 增强的替代基准。
>
> **角色**：指增家族的**基准升级选项**。当 300 增强想换更中性的基准、或 500 增强难度太高想迁移时，A500 是中间选项——与 300 重合 80.08% 但行业更中性、覆盖新兴产业更全。
>
> **来源**：📖 [广发金工 2025.2《中证A500 指数复制与增强》](../../../raw/articles/[202502051427]广发金工中证A500指数复制与增强.md)

## 一、策略定位

### 1.1 赚什么钱

**A500 基准上的复合因子增强**：用广发复合因子（从 Alpha 因子库挑选多个绩优因子合成）给 A500 成分股打分，在约束下做组合优化拿超额。

**一句话**：A500 与 300 重合 80.08%、行业更中性、覆盖新兴产业更全，是 2024-2025 指增产品的新热点（被动产品规模超 3440 亿、增强产品超 105 亿）。A500 增强超额年化 9.39%/夏普 1.31（已计费）。

### 1.2 A500 vs 其他基准的定位

> 📖 [广发金工 2025.2](../../../raw/articles/[202502051427]广发金工中证A500指数复制与增强.md)："A500 指数与沪深300 指数有 236 只个股重合，重合权重为 **80.08%**；A500 指数与中证500 指数有 214 只个股重合，重合权重为 **16.82%**；A500 指数与中证1000 指数有 38 只个股重合，重合权重为 **2.05%**。"

| 重合对象 | 重合股数 | 重合权重 |
|---|---|---|
| 沪深300 | 236 只 | **80.08%** |
| 中证500 | 214 只 | 16.82% |
| 中证1000 | 38 只 | 2.05% |

**定位结论**：A500 与 300 重合 80.08%（远高于 500/1000），实质是**沪深300 的升级版**——而非 500/1000 的延伸。

> 📖 [广发金工 2025.2](../../../raw/articles/[202502051427]广发金工中证A500指数复制与增强.md)："从历史净值走势来看，A500 指数与沪深300 指数高度重合，其中 **A500 指数在整体上略微跑赢沪深300 指数**。"

### 1.3 这个策略在指增家族里的角色

| 策略 | 角色 | 与本策略（14x）的关系 |
|---|---|---|
| 14a 组合优化器 | 引擎 | 14x 用本优化器，θ 参数不同 |
| 14d 规模+集中度 | 300 极简 | 14x 是 300 的基准升级 |
| 14e 国君 500 | 500 主力 | 14x 是 500 难度太高时的替代 |
| **14x A500 增强** | **基准升级** | — |

### 1.4 不适合什么场景

- **追求小盘 alpha**：A500 与 1000 重合仅 2.05%，小盘覆盖少
- **想要最长回测历史**：A500 于 2024.9 发布，回测数据有限（基期可回溯但编制规则是新）
- **复合因子库未搭建**：本策略依赖广发 Alpha 因子库

## 二、信号逻辑：复合因子怎么算

### 2.1 复合因子的跨板块有效性

> 📖 [广发金工 2025.2](../../../raw/articles/[202502051427]广发金工中证A500指数复制与增强.md)（三、（一）Alpha 因子在 A500 指数成分股中的表现统计）：

| 板块 | RankIC 均值 | RankIC 胜率 |
|---|---|---|
| 全市场 | **13.4%** | 90.3% |
| 沪深300 | 10.2% | 72.9% |
| 中证500 | **9.5%** | 79.3% |
| 中证800 | 9.7% | 78.5% |
| 中证1000 | 11.8% | 89.8% |
| **中证A500** | **9.8%** | **76.5%** |
| 创业板 | 15.2% | 94.0% |
| 国证2000 | 13.5% | 91.8% |

**关键结论**：**跨板块 RankIC 均 ≥ 9.5%**（最低为中证500 的 9.5%），复合因子在 A500 的 RankIC 为 9.8%、胜率 76.5%——有效性稳健。

> 📖 [广发金工 2025.2](../../../raw/articles/[202502051427]广发金工中证A500指数复制与增强.md)："A500 复合因子在 A500 成分股内的历史 RankIC 均值为 9.8%、胜率为 76.5%。"

### 2.2 复合因子的合成方式

> 📖 [广发金工 2025.2](../../../raw/articles/[202502051427]广发金工中证A500指数复制与增强.md)："本文从上述因子库中挑选出多个绩优因子，构建适用于 A500 指数增强的复合因子。"

⚠️ **复合因子的具体因子大类名称原文以图表呈现，正文未逐项文字列出**。从 [14 playbook §七](../../strategy-playbooks/14-index-enhancement.md) 的国君 11 大类映射看，复合因子应覆盖 PEAD/景气/估值/质量/动量/分析师预期等维度（详见各方向）。**实操建议**：用 14e 的 11 大类框架或自选绩优因子合成。

**RankIC 测试区间**：2020/01/01 ~ 2024/12/31。

### 2.3 A500 增强的约束参数（θ 四参数）

> 📖 [广发金工 2025.2](../../../raw/articles/[202502051427]广发金工中证A500指数复制与增强.md)："若以收益回撤比作为优先考量指标以控制约束条件，则最优约束条件为：**指数成分股占比下限 θ_index=0.99，指数成分股个股偏离上限 θ_bias=0.01，市值暴露偏离上限 θ_mkv=0.05，行业暴露偏离上限 θ_ind=0.01**。"

| 参数 | 推荐值 | 含义 |
|---|---|---|
| **θ_index** | **0.99** | 指数成分股占比下限（99%，几乎全选成分股）|
| **θ_bias** | **0.01** | 成分股个股偏离上限（1%，严控个股）|
| **θ_mkv** | **0.05** | 市值暴露偏离上限（5%）|
| **θ_ind** | **0.01** | 行业暴露偏离上限（1%，严控行业）|

**特点**：广发的约束比 14a 中银更严（个股偏离 0.01 vs 中银 300 的 0.015；行业 0.01 vs 中银 0.1）——更接近 14e 国君的"严格中性"风格。

### 2.4 A500 增强完整流程

```
每月末盘后（建议月频，原文未披露频率）：
1. 取中证A500 成分股（500 只）

2. 股票池三分法（A/B/C，见 14-shared §三）

3. 算复合因子 r
   ├─ 从 Alpha 因子库挑选多个绩优因子
   ├─ 因子预处理：去极值→标准化→行业填补→中性化
   └─ 合成复合因子（等权或 ICIR 加权）

4. 算调仓前权重 w₀（按市值漂移重算）

5. 组合优化器求解（θ 四参数约束）
   ├─ 目标：max(w'r − c·双边换手)  c=0.0015
   ├─ 约束：
   │   ├─ 成分股占比 ≥ 0.99（θ_index）
   │   ├─ 个股偏离 ≤ 0.01（θ_bias）
   │   ├─ 市值暴露 ≤ 0.05（θ_mkv）
   │   └─ 行业暴露 ≤ 0.01（θ_ind）
   └─ 无解 → 异常处理（见 14a §3.2）

6. 输出目标权重，次日批量调仓

7. 跟踪误差监控（日均≤0.5% / 年化≤7.75%）
```

## 三、选股规则

### 3.1 每月盘后例行流程

```
每月末盘后：
1. 取中证A500 成分股 + 当日基准权重

2. 股票池三分法（A 锁定 / B 清仓 / C 入优化池）

3. 算复合因子（绩优因子合成）

4. 优化器求解（θ_index=0.99, θ_bias=0.01, θ_mkv=0.05, θ_ind=0.01）

5. 输出目标权重 → 次月首个交易日调仓

6. 跟踪误差监控
```

### 3.2 硬过滤条件（θ 约束）

| 条件 | 阈值 | 作用 |
|---|---|---|
| 成分股占比 | ≥ **0.99**（θ_index）| 几乎全选成分股 |
| 个股偏离 | ≤ **0.01**（θ_bias）| 严控个股 |
| 市值暴露 | ≤ **0.05**（θ_mkv）| 控市值偏离 |
| 行业暴露 | ≤ **0.01**（θ_ind）| 严控行业 |
| 单边费率 | **0.0015** | 含在目标函数 |

### 3.3 ⚠️ 前视偏差检查

复合因子涉及的财报数据必须遵守时点规则（见 14-shared §6.3）。

## 四、调仓与持仓

### 4.1 建仓时点

**次月首个交易日开盘买入**。

### 4.2 调仓频率与时点

⚠️ **原文未披露调仓频率**（仅说明"双边千三换手计费"）。建议**月频**（与 14a 一致，A500 增强类产品多为月频调仓）。

### 4.3 持仓方式

按优化器输出的目标权重持有。个股权重偏离 ≤ 0.01（严控），成分股占比 ≥ 99%。

### 4.4 费用

双边千三（原文已计费）。⚠️ **广发绩效是费后数字**（与中银/国君不同，那些多为费前）。

## 八、升级路径

```
14x A500 增强（本策略，300 升级基准，9.39%/1.31）
   │
   ├─ 基准选择
   │   ├─ 300 增强想升级 → A500（行业更中性，本策略）
   │   ├─ 500 增强太难 → A500（与 300 重合 80%，难度低于 500）
   │   └─ 1000 增强想升级 → ⚠️ A500 与 1000 重合仅 2%，不适合
   │
   ├─ 因子升级
   │   ├─ 用 14e 的 11 大类框架（超预期占 40%）
   │   ├─ 加 14c 高质量池（剔暴雷）
   │   └─ 加 14b 行业配置增强
   │
   ├─ 约束调整
   │   ├─ 严控版（广发 θ：θ_bias=0.01, θ_ind=0.01）
   │   └─ 宽松版（中银 θ：θ_bias=0.015, θ_ind=0.1）→ 更多超额但跟踪误差升
   │
   └─ 产品形态
      ├─ 基金型增强（本策略，优化器调权）
      └─ Smart Beta（见 14y，规则化指数）
```
