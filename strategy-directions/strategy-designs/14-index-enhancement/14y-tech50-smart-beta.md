# #14y 指数增强 · 科技50 策略指数（Smart Beta）— 详细实现

> **定位**：本文是 [`14-index-enhancement.md`](../../strategy-playbooks/14-index-enhancement.md) 附加策略（来自 §二证据表 + §七组合潜力）的**策略详细实现**——把因子选股**直接写进指数编制规则**，用得分加权而非市值加权。本质是"规则化的指数增强"。
>
> **角色**：指增家族的**规则化形态**。与基金型增强（14a-x 用优化器调权）不同，Smart Beta 不用优化器，而是用固定的"调整后得分加权"编制规则——实现最简单、最透明、最可复现。
>
> **来源**：📖 [申万金工 2026.1《融合多因子策略的科技指数科技50 策略指数投资价值分析》](../../../raw/articles/[202601091800]融合多因子策略的科技指数科技50策略指数投资价值分析.md)

## 一、策略定位

### 1.1 赚什么钱

**Smart Beta 的因子倾斜收益**：把多因子选股写进指数编制规则，用"自由流通市值占比（基础得分）+ 11 因子倾斜得分 = 调整后得分"加权——保留市值加权底座，叠加因子倾斜。

**一句话**：从科技行业选 50 只股票，用 11 因子（成长/创新/价值/低波/质量等）打分，按"调整后得分"加权。年化 11.96%/夏普 0.44（2020-2025），偏向大市值（千亿以上 31 只）。

### 1.2 Smart Beta vs 基金型增强

| 维度 | 基金型增强（14a-x）| Smart Beta（14y）|
|---|---|---|
| 加权方式 | 优化器调权（跟踪误差约束）| **调整后得分加权**（固定规则）|
| 实现复杂度 | 高（LP 求解）| **低**（按规则算分加权）|
| 透明度 | 较低（优化器黑盒）| **高**（规则完全公开）|
| 跟踪误差控制 | 显式约束 | 隐式（市值底座 + 权重上下限）|
| 调仓频率 | 月/周频 | **季频**（3/6/9/12 月）|
| 适合 | 精细控制、机构产品 | 简单透明、规则化、个人可复刻 |

### 1.3 这个策略在指增家族里的角色

| 策略 | 角色 | 与本策略（14y）的关系 |
|---|---|---|
| 14a 组合优化器 | 基金型引擎 | 14y 不用优化器 |
| 14x A500 增强 | 基金型（优化器）| 14y 是规则化对照 |
| **14y 科技50 Smart Beta** | **规则化形态** | — |

### 1.4 不适合什么场景

- **追求精细跟踪误差控制**：Smart Beta 用市值底座 + 权重上下限隐式控制，不如优化器精确
- **非科技板块**：科技50 只覆盖科技行业（计算机/半导体/电子/通信等 12 子行业）
- **想要月/周频调仓**：Smart Beta 季频调仓（3/6/9/12 月）

### 2.3 加权方式：调整后得分加权（市值底座 + 因子倾斜）

> 📖 [申万金工 2026.1](../../../raw/articles/[202601091800]融合多因子策略的科技指数科技50策略指数投资价值分析.md)："计算待选样本的**自由流通市值占比，作为基础得分**，并将基础得分与上述所有因子倾斜得分相加得到待选样本的**调整后得分**；将待选样本按照调整后得分由高到低排名，选取排名前 50 的证券作为指数样本。"

**公式**：

$$\text{调整后得分}_i = \text{基础得分}_i + \sum_{k=1}^{11} \text{因子倾斜得分}_{i,k}$$

其中：
- **基础得分**$_i$ = 证券 $i$ 的自由流通市值占比（市值底座）
- **因子倾斜得分**$_{i,k}$ = 证券 $i$ 在因子 $k$ 上的倾斜得分

**权重上下限**：

> 📖 [申万金工 2026.1](../../../raw/articles/[202601091800]融合多因子策略的科技指数科技50策略指数投资价值分析.md)："科技50 策略指数采用调整后得分加权，且单个样本权重**不超过 10%，不低于 0.1%**。"

| 约束 | 阈值 |
|---|---|
| 单样本权重上限 | **10%** |
| 单样本权重下限 | **0.1%** |
| 选样数 | **前 50** |
| 调样频率 | **季频**（3/6/9/12 月第二个星期五次一交易日）|

### 2.4 Smart Beta 不是"纯因子加权"（关键认知）

> 📖 [申万金工 2026.1](../../../raw/articles/[202601091800]融合多因子策略的科技指数科技50策略指数投资价值分析.md)：调整后得分 = 自由流通市值占比（基础得分）+ Σ 11 因子倾斜得分。

**含义**：科技50 **保留了市值加权的底座**，再叠加因子倾斜——因此成分股偏向大市值（千亿以上 31 只），**并非脱离市值的纯因子加权**。

### 2.5 单因子得分构造方法

> 📖 [申万金工 2026.1](../../../raw/articles/[202601091800]融合多因子策略的科技指数科技50策略指数投资价值分析.md)："每个因子得分由下表中对应细分指标的**百分比排名经简单平均并线性转换**得到。"

**步骤**：
1. 对每个细分指标，计算其在待选样本中的百分比排名；
2. 同一因子内的细分指标简单平均；
3. 线性转换到统一量纲；
4. 输出该因子的倾斜得分。

### 2.6 科技50 完整编制流程

```
每季度调样日（3/6/9/12 月第二个星期五次一交易日）：
1. 选股池构造
   ├─ 中证全指内，过去一年日均成交金额排名前 80%
   └─ 属于科技 12 子行业

2. 算 11 因子倾斜得分（每个证券）
   ├─ 每个细分指标算百分比排名
   ├─ 同因子内简单平均 + 线性转换
   └─ 得到 11 个因子倾斜得分

3. 算基础得分
   └─ 基础得分 = 自由流通市值占比

4. 算调整后得分
   └─ 调整后得分 = 基础得分 + Σ 11 因子倾斜得分

5. 选样
   ├─ 按调整后得分降序排名
   └─ 选前 50 只

6. 加权
   ├─ 按调整后得分加权
   ├─ 单样本权重 ∈ [0.1%, 10%]
   └─ 归一化到总和 100%

7. 成分股生效（调样日次一交易日）
```

## 三、选股规则

### 3.1 每季盘后例行流程

```
每季调样日（3/6/9/12 月第二个星期五次一交易日）：
1. 构造科技选股池（流动性前 80% + 科技 12 子行业）

2. 算 11 因子倾斜得分（见 §2.5）

3. 算基础得分（自由流通市值占比）

4. 算调整后得分 = 基础得分 + Σ 因子倾斜得分

5. 选前 50 只，按调整后得分加权（权重 ∈ [0.1%, 10%]）

6. 输出成分股 + 权重 → 调样日次一交易日生效
```

### 3.2 硬过滤条件（编制规则）

| 条件 | 阈值 | 作用 |
|---|---|---|
| 流动性 | 过去一年日均成交金额前 **80%** | 流动性门槛 |
| 行业 | 科技 **12 子行业** | 板块限定 |
| 选样数 | 调整后得分前 **50** | 成分股数 |
| 单样本权重 | **[0.1%, 10%]** | 防集中/防边缘 |

### 3.3 ⚠️ 前视偏差检查

11 因子涉及的财报数据（成长/盈利/偿债等）必须遵守时点规则（见 14-shared §6.3）。一致预期因子用分析师数据（2023 后失效需监控）。
