## 一、策略定位

### 1.1 赚什么钱

**风格轮动**：成长股和价值股在不同宏观环境下表现分化——信用扩张期成长占优（弹性高）、经济复苏期价值占优、利率上升期成长承压。用宏观信号判断每月该看多成长还是价值，赚取风格相对收益。

**alpha 来源**：宏观周期对风格的系统性影响。成长股对流动性（分母端）敏感、价值股对经济周期（分子端）敏感，宏观信号能捕捉这种分化。

### 1.2 1.0 vs 2.0 的选择

| | 1.0 版（2022.2）| 2.0 版（2023.6）|
|---|---|---|
| **信号** | 货币-经济周期四象限 | 盈利 + 估值压力 + **动量** |
| **绩效** | 多空年化 **13.8% / IR 1.05 / 月胜率 62.4%** | 多头超额年化 **5.39% / IR 0.74 / 月胜率 58.4%** |
| **口径** | **多空**（买成长卖价值）| **多头超额**（相对等权基准）|
| **创新** | 四象限规则 | 加**动量维度**防风格切换时前期延续 |

⚠️ **不可直接比**：1.0 的 13.8% 是多空（含做空价值端），2.0 的 5.39% 是多头超额（只做多看多风格、相对成长/价值等权基准）。2.0 更保守、更易落地（A 股做空难）。

### 1.3 这个策略在 18 家族里的角色

| 策略 | 角色 | 与本策略（18x）的关系 |
|---|---|---|
| 18a/18e | 主线择时 | 18x 复用 18a 的货币-经济周期（1.0）/18e 的盈利+估值（2.0）|
| **18x 成长价值** | **风格轮动扩展** | — |
| 18c 国君友好度 | 货币缺口指标对成长强 | 可作 18x 的成长信号验证 |

### 1.4 不适合什么场景

- **绩效横向对比**：1.0 多空 vs 2.0 多头超额，口径不同
- **做空价值端**：1.0 的 13.8% 含做空，A 股做空难，实盘只能做多头版
- **2020 疫情复苏期**：成长抱团导致价值风格误判（2.0 已知失效点）

## 二、信号逻辑

### 2.1 1.0 版：货币-经济周期四象限（开源 2022.2）

基于 [18a](18a-multi-dimension-timing.md) 的货币-经济周期，每个象限判断成长/价值占优：

| 周期状态 | 占优风格 | 逻辑 |
|---|---|---|
| 货币宽 + 经济下（信用为矛）| **成长**（信用扩张期）| 信用扩张期成长弹性更高；信用收缩期价值相对抗跌 |
| 货币宽 + 经济上（风险溢价为矛）| **价值** | 受益经济复苏，价值板块明显占优；风险溢价过低时价值也回调 |
| 货币紧（利率为矛）| **规避成长** | 利率上升的估值压力在成长股上非常突出 |

**标的**：每月看多风格对应的**国证成长 / 国证价值指数**；基准 = 二者等权。

> 📖 [开源 2022.2](../../raw/articles/[202202131712]宏观择时多维度结合下的新视角开源金工.md)：
> - 货币宽+经济下（信用为矛）：**信用扩张期成长占优**（弹性更高）；信用收缩期价值相对抗跌
> - 货币宽+经济上（风险溢价为矛）：受益经济复苏，**价值板块明显占优**；风险溢价过低（情绪过热），价值股也面临回调
> - 货币紧（利率为矛）：**利率上升带来的估值压力在成长股上非常突出，要尽量规避成长股**
> - 标的：每月看多风格对应的**国证成长/国证价值指数**；基准=二者等权

### 2.2 2.0 版：盈利 + 估值压力 + 动量（开源 2023.6）

**完整四象限轮盘**（盈利维度 × 估值压力维度，加动量验证）：

| 盈利 | 估值压力 | 占优风格 | 动量验证 |
|---|---|---|---|
| 下行 | ≠ 0（有压力）| **价值**（防御）| 不需验证 |
| 下行 | = 0（无压力）| **成长**（流动性拔估值）| ⚠️ **用动量验证**（防风格切换时前期延续）|
| 上行 | = 0（无压力）| **成长**（复苏前半段，弹性高）| 不需验证 |
| 上行 | ≠ 0（有压力）| **价值**（复苏后半段/过热）| ⚠️ **用动量验证** |

> 📖 [开源 2023.6](../../raw/articles/[202306112017]宏观择时20轮盘重构与应用升级开源金工.md)：
> - "（1）在盈利下行，存在估值压力时，此时市场情绪往往较为悲观，**偏防御的价值板块会相对更强势**"
> - "（2）在盈利下行，估值压力为 0 时，此时**成长股往往受益于流动性拔估值而表现更好**，但为了防止风格切换时前期风格会有所延续，我们采取**动量维度进行验证**"
> - "（3）在盈利上行，估值压力为 0 时，此时往往位于复苏前半段，市场风险偏好在提升，此时**弹性更高的成长股往往会表现更为出色**"
> - "（4）在盈利上行，估值压力不为 0 时，此时往往位于复苏后半段及过热期……**价值板块会明显占优**，但为了防止风格切换时前期风格会有所延续，我们采取**动量维度进行验证**"

**单维度观点**（用于动量验证失效时的兜底）：
- 盈利维度：盈利上行看多价值、看空成长；盈利下行看空价值、看多成长
- 估值压力维度：估值压力=0 看多成长、看空价值；估值压力≠0 看多价值、看空成长

> 📖 [开源 2023.6](../../raw/articles/[202306112017]宏观择时20轮盘重构与应用升级开源金工.md)："对于盈利维度给出的多空观点为：**当盈利上行看多价值，看空成长；盈利下行看空价值，看多成长**。对于估值压力维度给出的多空观点为：**当估值压力为 0 看多成长，看空价值；估值压力不为 0 看多价值，看空成长**。"

**动量维度**：若当月成长/价值强度位于**过去 12 月均值之上**，则代表成长趋势强，看多成长；反之看多价值。

> 📖 [开源 2023.6](../../raw/articles/[202306112017]宏观择时20轮盘重构与应用升级开源金工.md)："若当月成长/价值强度位于**过去 12 月均值之上**，则代表成长趋势强，看多成长，看空价值；反之，看多价值，看空成长"

**基准**：每月等权配置国证成长、国证价值作为业绩基准。

### 2.3 算法完整流程（2.0 版）

```
每月末盘后：

步骤 1：盈利端（Nowcasting 或简化代理）
  └─ 盈利领先指数 vs 基准（归母净利 TTM 同比）→ 上行/下行
      （起步可用工业增加值同比或 PMI 作简化代理）

步骤 2：估值压力（同 18e）
  ├─ 国内：十年国债下行 且 M2-社融上行 → 0；否则 → -1
  ├─ 国外：美国通胀预期 < 2% → 0；≥ 2% → -1
  └─ 综合：都为 0 → 0；否则 → -1

步骤 3：四象限判定占优风格
  ├─ 盈利下行 + 估值压力≠0 → 价值
  ├─ 盈利下行 + 估值压力=0 → 成长（待动量验证）
  ├─ 盈利上行 + 估值压力=0 → 成长
  └─ 盈利上行 + 估值压力≠0 → 价值（待动量验证）

步骤 4：动量验证（仅盈利下行+无压力 / 盈利上行+有压力 两象限）
  ├─ 成长/价值强度 vs 过去 12 月均值
  ├─ 强度在均值上 → 看多成长
  └─ 强度在均值下 → 看多价值

步骤 5：输出看多风格 → 持国证成长或国证价值 ETF
```

## 三、选股/择时规则

### 3.1 信号生成（月频）

每月末按上述流程判定看多成长还是价值，次月持有对应风格指数。

### 3.2 ⚠️ 前视偏差检查

- 货币-经济周期（1.0）/ 盈利+估值（2.0）都用**截止月末**数据
- 动量维度用**过去 12 月**历史（不含当月）
- 美国通胀预期用当日数据

## 四、调仓与持仓

### 4.1 建仓时点

**次月首个交易日开盘**（T+1）。

### 4.2 调仓频率

**月频**。

### 4.3 持仓方式

**单风格满仓**：看多成长 → 持国证成长 ETF（或创业板 ETF 近似）；看多价值 → 持国证价值 ETF（或红利 ETF 近似）。基准 = 成长/价值等权。

### 4.4 费用

双边千三。

| 折扣因素 | 影响 | 应对 |
