## 一、策略定位

### 1.1 赚什么钱

**三资产轮动**：股票、债券、商品三类资产在不同美林时钟阶段表现分化——复苏期股票好、过热期商品好、衰退/滞胀期债券好。用美林时钟做商品/债券配置 + 股票择时信号（18e）+ 风险预算，实现三资产动态配置。

**alpha 来源**：
- **股票端**：用 18e 的盈利+估值压力信号（看多/看空）
- **商品端**：美林时钟 + **美国通胀预期共振**看多商品（过热期 + 通胀预期升 → 商品最佳）
- **债券端**：美林时钟的衰退/滞胀期债券表现好（避险）

### 1.2 美林时钟在各资产的效果差异（关键洞察）

> 📖 [开源 2023.6](../../../raw/articles/[202306112017]宏观择时20轮盘重构与应用升级开源金工.md)："虽然由于中国货币政策的多目标制，导致**美林时钟在 A 股的配置效果较差**，但是在**商品的配置上还是堪用的**。"

| 资产 | 美林时钟效果 | 原因 |
|---|---|---|
| **A 股** | ❌ 较差 | 中国货币政策多目标制，美林水土不服 |
| **商品** | ✅ 堪用 | 商品受全球需求+通胀驱动，美林更贴合 |
| **债券** | ✅ 堪用 | 债券回撤集中在复苏/过热期，衰退/滞胀期表现好 |

**含义**：股票端不用美林时钟（用 18e 的盈利+估值信号），商品/债券端用美林时钟——这是三资产配置的方法论分工。

### 1.3 这个策略在 18 家族里的角色

| 策略 | 角色 | 与本策略（18z）的关系 |
|---|---|---|
| 18b 股债轮动 | 股债双资产 | 18z 是 18b 加商品维度 |
| 18e 择时 2.0 | 股票信号源 | 18z 复用 18e 的股票看多/看空 |
| **18z 股债商** | **三资产扩展** | — |

### 1.4 不适合什么场景

- **纯股票择时**：本策略必须股债商三资产配（风险预算），不是纯股票
- **无商品 ETF**：商品端需黄金 ETF / 商品 ETF，缺标的无法落地
- **美林时钟用于 A 股**：原文明确美林在 A 股效果差，股票端要用 18e 信号

## 二、信号逻辑

### 2.1 三资产的风险预算权重（核心）

**股票**（Wind 全 A）：
- 看多信号（18e）→ 风险预算赋值 **20**
- 看空信号 → 风险预算赋值 **0.1**

**商品**（南华商品指数）：
- 美国通胀预期 + 美林时钟**皆看多** → 赋值 **20**
- **仅一者看多** → 赋值 **1**
- **两者皆空** → 赋值 **0.1**

**债券**（中债-新综合财富总值指数）：
- **衰退期** → 赋值 **5**
- **滞涨期** → 赋值 **2.5**
- **其余**（复苏/过热）→ 赋值 **0.1**

**归一化**：三类资产的预算值归一化得最终权重。

> 📖 [开源 2023.6](../../../raw/articles/[202306112017]宏观择时20轮盘重构与应用升级开源金工.md) §2.4："（1）使用**风险预算模型**作为权重调节初始模型；（2）对于股票而言，若看多信号，**风险预算赋值为 20**，看空赋值为 **0.1**；（3）对于商品而言，若**美国通胀预期和美林时钟皆看多，赋值为 20**，若只有一者看多，则赋值为 **1**，两者皆看空赋值为 **0.1**；（4）对于债券而言，若处于**衰退期，赋值为 5，处于滞涨期风险预算赋值为 2.5**，其余情况赋值为 **0.1**；（5）将上述的风险预算值进行**归一化**，就得到了每个资产的风险预算权重。"

### 2.2 底层逻辑（为什么这么赋值）

**债券权重规则**：中债新财富综合指数几波较大的回撤基本上都发生在**复苏期和过热期**（股票/商品涨时债券跌），在**衰退期和滞涨期表现较好**。

**商品权重规则**：南华商品指数主要的**两段涨幅皆在过热期发生**；商品叠加"美国通胀预期上升阶段表现更好"。

> 📖 [开源 2023.6](../../../raw/articles/[202306112017]宏观择时20轮盘重构与应用升级开源金工.md) §2.3、§2.1："中债新财富综合指数几波较大的回撤基本上都发生在**复苏期和过热期**……其在**衰退期和滞涨期表现较好**，在复苏期和过热期表现较差。" / "以南华商品指数为例，我们可以发现**主要的两段涨幅皆在过热期发生**。"

### 2.3 美林时钟的阶段判定

**四阶段**（用于商品/债券配置，不用 A 股）：

| 阶段 | 特征 | 商品/债券配置 |
|---|---|---|
| **复苏期** | 经济上 + 通胀下 | 债券 0.1（回撤期）|
| **过热期** | 经济上 + 通胀上 | 商品看多（若通胀预期共振→20）；债券 0.1 |
| **滞涨期** | 经济下 + 通胀上 | 债券 2.5（表现好）|
| **衰退期** | 经济下 + 通胀下 | 债券 5（最佳）|

### 2.4 美国通胀预期的商品择时

**商品看多条件**：美国通胀预期（10y 美债 YTM − 10y Tips）**上升阶段** + 美林时钟过热期。

> 📖 [开源 2023.6](../../../raw/articles/[202306112017]宏观择时20轮盘重构与应用升级开源金工.md) §2.1：商品叠加"**美国通胀预期上升阶段表现更好**"。

### 2.5 算法完整流程

```
每月末盘后：

步骤 1：股票信号（同 18e）
  ├─ 盈利端（Nowcasting）+ 估值压力（含海外）→ 戴维斯双杀判定
  ├─ 看多 → 股票预算 = 20
  └─ 看空 → 股票预算 = 0.1

步骤 2：商品信号（美林时钟 + 美国通胀预期）
  ├─ 美林时钟过热期？（经济上 + 通胀上）
  ├─ 美国通胀预期上升？（10y美债 − Tips 上行）
  ├─ 两者皆看多 → 商品预算 = 20
  ├─ 仅一者看多 → 商品预算 = 1
  └─ 两者皆空 → 商品预算 = 0.1

步骤 3：债券信号（美林时钟）
  ├─ 衰退期 → 债券预算 = 5
  ├─ 滞涨期 → 债券预算 = 2.5
  └─ 复苏/过热 → 债券预算 = 0.1

步骤 4：风险预算归一化
  ├─ 总预算 = 股票预算 + 商品预算 + 债券预算
  ├─ 股票权重 = 股票预算 / 总预算（风险预算比，非资金比）
  ├─ 商品权重 = 商品预算 / 总预算
  └─ 债券权重 = 债券预算 / 总预算

步骤 5：风险预算求解（60 交易日协方差）
  ├─ 用过去 60 交易日股债商日收益率算 3×3 协方差矩阵
  ├─ 给定风险预算比（股票:商品:债券）
  └─ 数值求解资金权重 w（使边际风险贡献比 = 预算比）

步骤 6：输出股债商资金权重 → 次月首日开盘调仓
```

## 三、选股/择时规则

### 3.1 信号生成（月频）

每月末按上述流程算三资产的风险预算权重。

### 3.2 ⚠️ 前视偏差检查

- 股票信号（18e）用截止月末数据
- 美林时钟判定用截止月末的经济+通胀数据（滞后一期）
- 美国通胀预期用当日数据
- 协方差矩阵用过去 60 交易日（不含未来）
