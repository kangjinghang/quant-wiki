## 一、策略定位

### 1.1 赚什么钱

**规避戴维斯双杀**：戴维斯双杀 = 盈利下行 + 估值压力（流动性收紧）同时发生，此时股票遭遇"盈利跌 + 估值杀"双重打击。2.0 的择时规则极简——**把戴维斯双杀情景空仓，其余情景看多**，就能规避大部分主要下跌段（除 2015 年）。

**alpha 来源**：
- **盈利端**：Nowcasting（动态因子模型 DFM，以周为步长）实时拟合盈利领先指数，领先真实盈利 1-2 个季度——比 1.0 的月频扩散指数更前瞻、可解释性直接落到盈利
- **估值端**：含**海外因子**（美国通胀预期 > 2% → A 股估值承压），这是 1.0 完全没有的维度

### 1.2 1.0（18a）被自我修正的三个问题

> 📖 [开源 2023.6](../../raw/articles/[202306112017]宏观择时20轮盘重构与应用升级开源金工.md)："样本外跟踪下来发现有如下几点问题：1、主要矛盾确定的依据是历史收益，并没有落实到盈利和估值的影响上，**可解释性一般**；2、……我们在每一个周期内只确定了唯一的矛盾，但这种方式在多变的宏观环境中较难适应；3、就领先指数编制而言，**原始的扩散指数编制方式以及较少的宏观指标，往往会导致宏观状态的误判**。"

| 问题 | 1.0（18a）| 2.0（18e）修正 |
|---|---|---|
| 可解释性一般 | 主要矛盾靠历史收益归纳 | 落实到**盈利 + 估值**两端 |
| 单一矛盾难适应 | 每周期只定一个矛盾 | 盈利+估值**双因子**驱动 |
| 扩散指数误判 | 月频扩散指数 + 少量指标 | **Nowcasting DFM**（周频，~400 指标）|

### 1.3 这个策略在 18 家族里的角色

| 策略 | 角色 | 与本策略（18e）的关系 |
|---|---|---|
| 18a 多维度择时 | 1.0 版 | **18e 是 18a 的下一代**（作者团队自我修正）|
| 18b/c/d | 其他主线 | 不同方法论 |
| **18e 择时 2.0** | **下一代（含海外因子）** | — |
| 18x/y/z | 附加 | 18e 的盈利+估值框架可迁移到风格/行业 |

### 1.4 不适合什么场景

- **绩效横向对比**：2.0 只给胜率 59.6%（未公布纯多头年化），**不能和 1.0 的 20.48%/65.14% 直接比**——口径不同（2.0 是更简洁的二值规则）
- **简单复现**：Nowcasting DFM 需自实现（开源未开源代码），工程难度高
- **无海外数据**：估值端依赖美国通胀预期（10y 美债 − Tips），缺海外数据无法运行

## 二、信号逻辑：盈利端 + 估值端 → 戴维斯双杀空仓

### 2.1 盈利端：Nowcasting 高频领先指标

**指标筛选**（从约 400 个宏观指标，货币-信用-经济-通胀四维度，月/周/日频）：
- **三大逻辑**：① B-B 拐点识别；② 时差相关系数法；③ 逻辑判断
- **预处理**：频率对齐 / 缺失值填充 / 季调（含春节效应）

**实时拟合**：用 **Nowcasting（动态因子模型 DFM，以周为步长）** 实时拟合，"拟合出的盈利领先指数大致**领先真实盈利 1-2 个季度**"。

**盈利基准** = 归母净利润 TTM 同比。

> 📖 [开源 2023.6](../../raw/articles/[202306112017]宏观择时20轮盘重构与应用升级开源金工.md)："我们主要围绕着**货币-信用-经济-通胀这四大维度**去寻找指标，指标频率主要包括月、周、日三种，大致涵盖 **400 个指标**。" / "我们主要遵循的是三大逻辑：（1）**B-B 拐点识别**；（2）**时差相关系数法**；（3）**逻辑判断**。" / "（1）指标频率对齐；（2）缺失值填充；（3）季调，**其中季调中需考虑春节效应**。" / "Nowcasting 本质是**动态因子模型（DFM）**，我们**以周为步长**，结合上述筛选出的盈利领先指标，使用 Nowcasting 进行实时拟合……其拟合出的盈利领先指数大致**领先真实盈利 1~2 个季度**。" / "对于盈利基准指标我们选用**归母净利润 TTM 同比**，估值基准指标我们选用 **PE_TTM**。"

### 2.2 估值端：含海外因子的估值压力

**三步**：

#### ① 国内货币估值压力

当**十年期国债利率下行**和 **M2-社融存量上行**同时发生时，国内货币政策估值压力为 **0**，否则为 **-1**。

#### ② 国外货币估值压力

当**美国通胀预期水平在 2% 以下**为 **0**，否则为 **-1**。

**美国通胀预期** = 10y 美债 YTM − 10y Tips 美债 YTM 的差值。

> 📖 [开源 2023.6](../../raw/articles/[202306112017]宏观择时20轮盘重构与应用升级开源金工.md)："在衡量国外货币状况时，我们主要观察美国的通胀预期水平，并使用 **10y 美债 YTM 与 10y Tips 美债 YTM 的差值**进行替代。" / "当美国通胀预期在 2% 以上时，往往代表着加息概率加大，此时外资的流出以及风险偏好的降低都会使得 A 股估值承压。"

#### ③ 综合估值压力

当国内和国外都为 0 时综合估值压力为 **0**，否则为 **-1**。

> 📖 [开源 2023.6](../../raw/articles/[202306112017]宏观择时20轮盘重构与应用升级开源金工.md)："（1）国内货币估值压力：当十年期国债利率下行和 M2-社融存量上行同时发生时，此时国内货币政策估值压力为 **0**，否则为 **-1**；（2）国外货币估值压力：当美国通胀预期水平在 **2% 以下为 0**，否则为 **-1**；（3）国内外综合估值压力：当国内货币估值压力和国外货币估值压力都为 0 时，综合估值压力为 **0**，否则为 **-1**。"

> 💡 **首次引入海外因子**：美国通胀预期高于 2% 时 A 股估值承压——这是 1.0 完全没有的维度，对 2022 年以来美联储加息周期的解释力尤其重要。

### 2.3 招牌机制：戴维斯双杀空仓

**择时规则极简**：

$$\text{信号} = \begin{cases} \text{空仓} & \text{若经济下行 且 估值压力} \neq 0 \text{（戴维斯双杀）} \\ \text{看多} & \text{其余情景} \end{cases}$$

> 📖 [开源 2023.6](../../raw/articles/[202306112017]宏观择时20轮盘重构与应用升级开源金工.md)："最后，我们将**经济处于下行，且估值压力不为 0 的戴维斯双杀情景空仓，其余情景看多**……择时的胜率为 **59.6%**，在除了 2015 年的下跌没有规避外，其余的主要下跌段均有一定程度的规避，为**较为有效且简洁的择时方案**。"

**含义**：只有"盈利下行 + 估值压力"同时发生才空仓，其他所有情况都看多。这是极简的二值规则。

### 2.4 算法完整流程

```
每周（Nowcasting 周步长）+ 每日（估值压力日频）：

步骤 1：盈利端（Nowcasting，周频）
  ├─ 从 ~400 个宏观指标筛选领先指标（B-B拐点/时差相关/逻辑判断）
  ├─ 预处理（频率对齐/缺失填充/季调含春节）
  ├─ DFM 以周为步长实时拟合 → 盈利领先指数
  └─ 盈利领先指数 vs 基准（归母净利 TTM 同比）→ 判盈利上行/下行

步骤 2：估值端（日频）
  ├─ 国内货币估值压力：
  │   ├─ 十年国债利率下行？ + M2-社融存量上行？
  │   ├─ 两者同时 → 压力 = 0
  │   └─ 否则 → 压力 = -1
  ├─ 国外货币估值压力：
  │   ├─ 美国通胀预期 = 10y美债YTM − 10y Tips YTM
  │   ├─ < 2% → 压力 = 0
  │   └─ ≥ 2% → 压力 = -1
  └─ 综合：国内国外都为 0 → 综合 = 0；否则 → 综合 = -1

步骤 3：戴维斯双杀判定
  ├─ 若（盈利下行 且 估值压力 ≠ 0）→ 空仓
  └─ 其余 → 看多

步骤 4：输出信号 → 调整权益仓位（满仓/空仓）
```

## 三、选股/择时规则

### 3.1 信号生成

- **盈利端**：Nowcasting 周更新
- **估值端**：日频（十年国债、M2-社融、美国通胀预期都是日频可得）
- **合成**：戴维斯双杀判定可日频执行

### 3.2 ⚠️ 前视偏差检查

- Nowcasting 用**截止当周**的数据拟合（DFM 不能用未来）
- 美国通胀预期用**当日**的 10y 美债/Tips
- M2-社融存量是月频，月内用最新月度值

## 四、调仓与持仓

### 4.1 建仓时点

**信号变化即调仓**（盈利周频 + 估值日频，信号变化时 T+1 调仓）。

### 4.2 调仓频率

**周/双周频**（Nowcasting 周步长为主，估值压力日频辅助）。

### 4.3 持仓方式

**二元仓位**：看多 = 满仓股票（Wind 全 A）；空仓 = 切债券/货币基金。

### 4.4 费用

双边千三。
