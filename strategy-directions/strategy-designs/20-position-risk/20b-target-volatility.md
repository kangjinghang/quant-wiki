# #20b 仓位管理 · 目标波动率（先"生息"再控波动） — 详细实现

> **定位**：本文是 [`20-position-risk-management.md`](../strategy-playbooks/20-position-risk-management.md) 配方 B 的**策略详细实现**——介于 playbook 与代码之间的中间层。读完本文，任何人都能照着写出代码，但本文不陷入代码细节。

## 一、策略定位

### 1.1 赚什么钱

**控波动 = 长期生息的钱**。目标波动率策略不是赚 alpha，而是通过控制组合波动率来减少"波动率拖累"——波动越大，复利下的长期收益损耗越大（几何平均 ≈ 算术平均 − 方差/2）。控住波动本身就等于增长期收益。

**一句话逻辑**：设定一个目标波动率，市场波动大时减权益仓、波动小时加仓，让组合波动维持目标水平。但 A 股**直接对宽基用会水土不服**——必须先"生息"调整权益端（让权益具备稳定的正收益能力），再套目标波动率才有效。

> 📖 [中金固收 2025.12](../../raw/articles/[202512141420]中金固收作底仓低波实践的思考.md) §脚注[1]："参考波动率拖累（volatility drag）……根据泰勒近似，其**几何平均收益率约等于其算术平均收益率减去样本收益率方差的一半**。"

### 1.2 在家族里的角色

| 策略 | 层面 | 与 20b 的关系 |
|---|---|---|
| 20a 三因子择时 | ①总量择时 | 不同层面（20a 控总仓位方向，20b 控股债比例波动）|
| **20b 目标波动率** | **②组合波动** | 本策略，固收+底仓专用 |
| 20c 拥挤度避险 | 顶部避险 | 可叠加（生息权益端可加拥挤度剔除）|
| 20d 宏观友好度 | ①总量择时（宏观）| 不同层面 |
| 20e 时点风险 | ③超额回撤护栏 | 不同层面 |

### 1.3 不适合什么场景

- **直接对宽基用**：A 股宽基"牛短熊长、暴涨暴跌"，波动率和收益不对等，直接套公式会在错误时点加仓
- **进取型权益择时**：本策略定位"固收+底仓"求稳，非激进权益
- **追求高 alpha**：本策略是控波动非赚 alpha，alpha 来自"生息"权益端的选股

## 二、信号逻辑（核心）

### 2.1 核心公式

$$\text{权益仓位} = \frac{\text{目标波动率}}{\text{实际权益波动率}}$$

**逻辑**：实际波动率高 → 仓位自动降低（避险）；实际波动率低 → 仓位自动升高（加仓）。让组合波动维持目标水平。

> 📖 [中金固收 2025.12](../../raw/articles/[202512141420]中金固收作底仓低波实践的思考.md) §二："一是**目标波动率策略**：我们在《固收+智能体的基础与路径》中提及，由于宽基策略的波动与收益存在'不匹配'，因此目标波动率策略在国内出现'水土不服'。但经过上述调整后，权益策略的收益与波动更为平衡。"

⚠️ **诚实标注**：原文未给出"目标波动率/实际波动率"这一精确数学表达式（属目标波动率策略的通用公式），仅以文字描述策略机制。精确的仓位计算式需查其引用的《固收+智能体的基础与路径》。

### 2.2 "水土不服"问题——为什么直接对宽基用会失效

> 📖 [中金固收 2025.12](../../raw/articles/[202512141420]中金固收作底仓低波实践的思考.md) §二："由于宽基策略的波动与收益存在'**不匹配**'，因此目标波动率策略在国内出现'**水土不服**'。"

**问题**：A 股宽基"牛短熊长、暴涨暴跌"，波动率和收益不对等：
- 高波动时（熊市）→ 减仓是对的
- 低波动时（震荡市）→ 加仓不一定赚（可能继续阴跌）

直接套公式会在错误时点加仓。

### 2.3 解法——先"生息"再控波动（两步走）

> 📖 [中金固收 2025.12](../../raw/articles/[202512141420]中金固收作底仓低波实践的思考.md) §一："权益策略若要具备'长期生息能力'，往往需要在显著提升 alpha 和约束波动回撤上入手……作为组合中的'底仓'，我们暂不细化如何增强 alpha，而着重从**控回撤提 Calmar**角度展开增强。"

**核心**：先让权益端具备"生息"能力（稳定的正收益），再套目标波动率才有效。"生息"调整用三类手段：

### 2.4 "生息"调整三类手段

#### 手段一：估值与质量因子

先过 ROE>5% 的质量门槛，再按综合估值因子排序择券。

> 📖 [中金固收 2025.12](../../raw/articles/[202512141420]中金固收作底仓低波实践的思考.md) §一："挖掘'低估值'是固收+权益部署的常规思路，但低估值本身并不是持续的'生息因子'，我们在财务质量层面通过引入 **ROE 大于 5%** 来作为第一重筛选门槛，而后根据综合估值因子排序进行择券。具体而言，我们通过将 **TTM 的 PE 和 PB 分别计算其倒数的排序值**，选择合并排序值处于前 N 分位数的个券构建组合。"

| 步骤 | 操作 |
|---|---|
| 1. 质量筛选 | ROE > 5%（第一重门槛）|
| 2. 估值排序 | PE 倒数排序值 + PB 倒数排序值，合并排序 |
| 3. 择券 | 选合并排序值前 N 分位的个股 |

#### 手段二：低波动量因子（简易"生息"因子）

> 📖 [中金固收 2025.12](../../raw/articles/[202512141420]中金固收作底仓低波实践的思考.md) §一："低波动量因子从历史回测来看，也具备提高'生息'能力的效果。一个简易的因子是**最近 20 日涨跌幅与过去 180 日波动率（倒数）的排序值加总**。"

$$\text{生息因子} = \text{Rank}(\text{近 20 日涨跌幅}) + \text{Rank}\left(\frac{1}{\text{近 180 日波动率}}\right)$$

**逻辑**：买"近期涨得好 + 长期波动低"的股票——这类股票更具备持续"生息"特征（动量 + 低波的组合）。

#### 手段三：波动率排序加权（优于倒数法）

> 📖 [中金固收 2025.12](../../raw/articles/[202512141420]中金固收作底仓低波实践的思考.md) §一："个券按波动率加权是长周期降低组合波动的主要工具……二是**波动率排序法**：计算成分券波动率后，计算其逆序排序值，再除以全样本的加总值，以此作为个券权重。"

**为什么排序法优于倒数法**（原文给 3 条理由）：

| 理由 | 倒数法的问题 | 排序法的优势 |
|---|---|---|
| ①**天然截断** | 某券波动率极低 → 权重趋于无穷大，需额外设上限 | 权重上限 = **2/N+1**，内生约束，无需额外设上限 |
| ②**分散化更稳** | 有效持仓数依赖截面分布形态，不确定 | 有效持仓数 ≈ **75% 总样本**（按 Herfindahl 指数算）|
| ③**对估计误差鲁棒** | 低波动券的估计误差被权重函数放大 | 类似"非参数方法"，对估计误差敏感度低 |

> 📖 [中金固收 2025.12](../../raw/articles/[202512141420]中金固收作底仓低波实践的思考.md) §一："一是排序法对于个券持仓有天然的'截断'作用……个券的权重上限为 **2/N+1**……二是分散化水平相对倒数法可能更好……有效持仓数若按照 Herfindahl 指数计算，则约等于 **75% 的总样本**……三是对于权重分配更为稳定……排序值加权可以算作'非参数方法'，对估计误差敏感度稍低。"

### 2.5 一个具体例子走一遍

假设做目标波动 2% 的固收+底仓组合：

```
第一步：选"生息"权益端（用手段一+二）
   ├─ 质量筛选：全市场 ROE > 5% 的股票（假设剩 800 只）
   ├─ 估值排序：PE 倒数 + PB 倒数合并排序，取前 N 分位（如前 30%，240 只）
   ├─ 生息因子：Rank(近 20 日涨跌幅) + Rank(1/近 180 日波动率)，取高分
   └─ 最终选 50-100 只"生息"股票池

第二步：波动率排序加权（手段三）
   ├─ 对选中的 50-100 只股票，算各自的近 60 日波动率
   ├─ 按波动率逆序排序（低波动排前）
   ├─ 排序值 / 总和 = 权重（权重上限 2/N+1，低波动股权重高）
   └─ 得到"生息权益组合"

第三步：套目标波动率
   ├─ 算"生息权益组合"的实际波动率（如 15%）
   ├─ 目标波动率 = 2%
   ├─ 权益仓位 = 2% / 15% ≈ 13.3%
   └─ 剩余 86.7% 切债券底仓

动态调整：
   ├─ 市场波动↑（如权益波动率升到 20%）→ 仓位 = 2%/20% = 10%（自动减仓）
   └─ 市场波动↓（如权益波动率降到 10%）→ 仓位 = 2%/10% = 20%（自动加仓）
```

### 2.6 第二条路径：合成期权策略（备选）

> 📖 [中金固收 2025.12](../../raw/articles/[202512141420]中金固收作底仓低波实践的思考.md) §二："我们对此有两条路径来将股票策略和纯债资产'打包'：**一是目标波动率策略**……**二是合成期权策略**：我们在《'合成期权'对固收+配置的参考价值》提到该策略在目前环境下的实用性，在此不赘述。"

**定位**：合成期权策略是固收+包装的**备选路径**，非本配方主讲。

## 三、选股规则（"生息"权益端）

### 3.1 每月盘后例行流程

```
每月最后一个交易日盘后：
1. 质量筛选：全市场 ROE > 5% 的股票
2. 估值排序：
   ├─ 算每只股票 TTM 的 PE 倒数排序值、PB 倒数排序值
   └─ 合并排序，取前 N 分位（如前 30%）
3. 生息因子：
   ├─ 算近 20 日涨跌幅的截面排序值
   ├─ 算近 180 日波动率的倒数排序值
   └─ 两者相加，取高分股
4. 波动率排序加权：
   ├─ 对选中股票，算近 60 日波动率
   ├─ 逆序排序（低波动排前）
   └─ 排序值 / 总和 = 权重（上限 2/N+1）
5. 套目标波动率：
   ├─ 算"生息权益组合"的实际波动率
   ├─ 权益仓位 = 目标波动率 / 实际波动率
   └─ 剩余仓位切债券底仓
```

### 3.2 ⚠️ 前视偏差检查

| 检查项 | 规则 |
|---|---|
| 波动率计算 | 用截止当日的滚动波动率（如 60/180 日），不含未来 |
| 估值因子 | 用当日收盘后的 PE/PB，T+1 才能交易 |
| ROE | 用最新已披露的季报 ROE，不用未披露的 |

- 债券端：费率低
- ⚠️ 目标波动率策略换手相对低（月频调仓），交易成本可控

## 七、失效红线

| 红线 | 表现 | 监控动作 |
|---|---|---|
| 🔴 **直接对宽基用** | A 股宽基波动收益不匹配，错误时点加仓 | 必须先"生息"调整权益端 |
| 🔴 **"生息"因子失效** | 权益端失去稳定正收益能力 | 监控权益端滚动正收益概率 |
| 🟡 目标波动率取值 | 2%（固收+）vs 5%-8%（进取）差异大 | 按风险偏好选，固收+用 2% |
| 🟡 波动率估计误差 | 滚动窗口选择影响仓位 | 用排序法加权（对误差鲁棒）|
| 🟡 加权方式 | 倒数法会被极低波动券放大误差 | 用波动率排序法（非倒数法）|

## 八、升级路径

```
20b 目标波动率（本策略，固收+底仓）
   │
   ├─ 验证"生息"权益端是否有效
   │   └─ 有效（权益端年化 >15%、回撤 <40%）→ 继续
   │   └─ 无效 → 检查 ROE 门槛/估值因子；或用红利/成长增强
   │
   ↓ 加路径（任选）
   │
加 20c 拥挤度避险 —— 在"生息"权益端剔除拥挤股
   │
加 20a/20d 总量择时 —— 给整个底仓组合套总仓位开关
   ├─ 20a 做空 → 整个底仓组合减权益
   └─ 20d 评分低 → 整个底仓组合减权益
   │
   ↓ 终极合成
   │
20a + 20b + 20c 三层（总量择时 + 目标波动率 + 拥挤度剔除）
```
