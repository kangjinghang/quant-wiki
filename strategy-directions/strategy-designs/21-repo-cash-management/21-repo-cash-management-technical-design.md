# #21 回购/现金管理 — QMT 落地技术设计

> **定位**：本文是 [`21-repo-cash-management.md`](../../strategy-playbooks/21-repo-cash-management.md) 的**代码级落地设计**。#21 是 **#10 龙虎榜空仓资金的现金增益**——#10 持仓 20 日窗口期间未满仓的闲置资金，放回购吃息（T+1 滚动），年化 2-5% 的纯增量。不是独立 alpha 策略，是现金管理。
>
> **🔴 最高优先级风险（开工前必读）**：akshare 的交易所回购行情接口**已确认存在**（`bond_buy_back_em`），但 **QMT xtquant 能否对回购代码（如 204001）下单，在 [QMT数据能力.md](../reference/QMT数据能力.md) 中完全未记载**。这是整个方向在 QMT 上可行性的最终判据——若 QMT 不支持回购交易下单，#21 只能用 akshare 做信号 + 人工/其他通道下单。**开工第一步必须实测验证此项**。
>
> **第二个缺口**：配方A/B/C 的盘中信号"银行间市场情绪指数"（35/65 阈值），**akshare 无接口**。需用 Shibor/回购利率代理，或走金十/万得。
>
> 所有 akshare 接口已对照源码确认；策略参数来自 #21 playbook 原文。

## 1. Day 0 可行性验证（最高优先级）

在写任何代码前，必须先确认 QMT 能否做回购交易。两个测试：

### 测试1：回购行情订阅
```python
# 伪代码：测试 xtquant 能否取回购实时行情
from xtquant import xtdata
# 尝试订阅 GC001（沪市逆回购）
xtdata.subscribe_quote("204001.SH", period="tick", callback=on_tick)
# 观察是否返回有效数据（回购代码非普通股票，可能不被支持）
```

### 测试2：回购下单
```python
# 伪代码：测试 xtquant 能否对回购下单
# 注意：交易所回购方向特殊——"卖出"=逆回购（融出资金借出吃息）
from xtquant import xttrader
# 尝试对 204001 下"卖出"单
xttrader.order_stock(account, "204001.SH", xt.STOCK_SELL, volume, ...)
# 观察券商是否接受此委托
```

**结果分支**：
- ✅ 两项通过 → 走全自动架构（§2-§4）
- ❌ 行情通过但下单不通过 → akshare 做信号 + QMT 提醒 + 人工券商APP下单
- ❌ 都不通过 → #21 在 QMT 上不可行，改用券商条件单或货币基金（`fund_money_fund_daily_em`）

### 2.3 🔴 银行间情绪指数缺口

playbook 配方A/B/C 的核心盘中信号是"银行间市场情绪指数"（10:15读，<35=低点、>65=高点）。**akshare 全量搜索无此接口**（仅有外汇投机情绪、美国密歇根消费者信心等无关指标）。

**代理方案**（按优先级）：
1. **Shibor隔夜利率代理**：`rate_interbank(indicator="隔夜")`，根据利率绝对水平/分位数设代理阈值（如 >历史80%分位≈情绪>65）
2. **回购定盘利率代理**：`repo_rate_query`，FR001/FR007 水平代理
3. **金十数据**：手动接入或爬取（akshare 的 `macro_fx_sentiment` 是金十源，但针对外汇非银行间）
4. **简化方案（推荐起步）**：跳过情绪信号，只用 11:30 中证800 + 日历周期，先跑通基础版

## 3. 信号层设计

### 3.1 配方A 回购周期+双信号（最简，平均利率2.167%）

**唯一盘中信号方向**——三个时点决策：

```
算法（伪代码，每日盘中）：
10:15 读取情绪代理（Shibor隔夜分位数）：
  ├─ 分位 > 80%（代理情绪>65）→ 利率高点，尾盘借出吃息
  ├─ 分位 < 20%（代理情绪<35）→ 利率低点，等待/锁成本
  └─ 中间 → 观望

11:30 读中证800 9:30-11:30涨跌：
  ├─ 涨 > 1.2% → 尾盘利率上行预期 → 加码借出
  ├─ 跌 > 1.2% → 午后利率走低 → 借出不利，等待
  └─ |涨跌| < 1.2% → 中性

日历周期规则：
  ├─ 每月23号最后一小时 → 按加权价持续买 GC007（锁跨月）
  ├─ 非月末：
  │   ├─ 周四尾盘 → 买 GC001（占款3天，含周末）
  │   └─ 其他日尾盘最后一小时 → 按加权价买 GC001
  ├─ 节前第三天 → 利率最高，借出最优
  └─ 节前最后一天 → 勿借GC001（节后首日到期偏紧），改借GC002/GC003
```

**绩效对标**：平均利率 2.167%（回测2020.3-2022.12）。

> ⚠️ **容量红线**：单笔 >即时成交量10% 有冲击。**GC007容量小**（尾盘GC001成交均值5276亿、GC007仅269亿），大资金需提早分批。

### 3.2 与 #10 的协同（现金增益）

```
协同流程：
#10 龙虎榜持仓20日窗口期间：
  ├─ 未满仓的闲置资金 → 每日盘尾买GC001（T+1滚动）
  ├─ #10无新信号的资金空窗期 → 持续回购滚动
  └─ #10产生新信号需建仓时 → 回购到期资金（T+1）释放建仓
收益增量：闲置资金吃年化2-5%，纯增量无额外风险
```

    """10:15情绪信号。返回 '借出'/'等待'/'中性'。"""

## 4. 下单层设计（待 Day 0 验证）

```
每日盘尾（依赖Day0验证通过）：
1. 读 decide() 输出
2. QMT xtquant 下单：
   ├─ 非月末 → GC001（204001）"卖出"方向（逆回购）
   └─ 每月23号 → GC007（204007）"卖出"方向
3. 容量控制：单笔 < 即时成交量10%
4. 次日到期自动滚回资金账户
```

> ⚠️ **方向关键**：交易所回购"借出资金吃息"= **卖出**方向（融出资金方卖出回购），与直觉相反。下单层务必确认方向参数，避免做反。

## 6. 回测验证方案

**目标**：验证配方A 能否达到平均利率 2.167%。

```
1. 拉 GC001/GC007 历史K线（bond_buy_back_hist_em，2020起）
2. 模拟每日按日历规则+双信号借出
3. 统计平均年化利率
4. 对标 2.167%
   ├─ 偏差小 → 信号逻辑正确
   └─ 偏差大 → 检查情绪代理是否有效（无真实情绪指数是主要误差源）
```

> 💡 **简化起步建议**：跳过情绪信号（缺口），只用"日历周期 + 中证800"两信号，先验证能否拿到基础利率（~2%）。情绪信号作为进阶增强，等接入金十/万得情绪源后再加。

## 7. 红线与失效监控

| 红线 | 说明 | 应对 |
|---|---|---|
| 🔴🔴 **QMT回购交易能力未确认** | reference未记载，整个方向可行性判据 | **Day0必测**，不过则降级 |
| 🔴 银行间情绪指数缺口 | akshare无接口 | Shibor代理 或 简化起步 |
| GC007容量小 | 仅GC001的5% | 大资金提早分批或主用GC001 |
| 节前品种错配 | GC001节后首日到期偏紧 | 节前最后一天改借GC002/003 |
| 利率波动 | 非稳赚，时点判断错误会买在低点 | 严格按信号，情绪低点等待 |
| 固收+容量天花板 | >10-20亿组合效率缩减（对个人不构成约束）| 个人资金无忧 |
