# #21 交易所回购 · 回购利率周期 + 双信号现金管理 — 详细实现

> **定位**：本文是 [`21-repo-cash-management.md`](../strategy-playbooks/21-repo-cash-management.md) 配方 A 的**策略详细实现**——介于 playbook 与代码之间的中间层。读完本文，任何人都能照着写出代码，但本文不陷入代码细节。
>
> **角色**：21 现金管理家族的**入门主配方**。用日历周期定大方向 + 盘中两个即时信号（股市 ±1.2%、银行间情绪 35/65）做精细择时，每月 23 号切 GC007 锁跨月成本。**先把现金仓的回购吃息跑起来**，再向债市/固收+ 延伸。
>
> **来源**：[📖 基于量化视角看交易所回购交易策略（中金固收 2023.3）](../../raw/articles/[202303222142]中金固收量化基于量化视角看交易所回购交易策略.md)（日历四维 + 双信号 + 操作规则 + 回测绩效）。

## 一、策略定位

### 1.1 赚什么钱

**一句话**：利用交易所回购利率的**周期性规律**（日内/周内/月内/节假日）+ **即时信号**（股市盘中表现、银行间早盘情绪），在利率高时借出（吃高息），规避利率低/紧缩时点。它是**权益策略空仓时现金仓位的增益器**——钱不躺平，买回购吃息。

**alpha 来源**：交易所回购利率存在稳定的日历波动（资金供需周期性松紧），且可通过盘中即时信号提前预判当日利率走向——借出方在利率高点出借，吃比"全天持有"更高的利息。

> 📖 [中金固收 2023.3](../../raw/articles/[202303222142]中金固收量化基于量化视角看交易所回购交易策略.md) §一："GC001 和 GC007 作为交易所回购的主要交易品种，成交量远超交易所其他回购品种……投资者可以利用这一点，合理进行资金管理。"

### 1.2 在 21 家族里的角色

| 策略 | 角色 | 复杂度 | 与本策略（21a）的关系 |
|---|---|---|---|
| **21a 回购现金管理** | **入门主配方** | 低 | — |
| 21b 债基久期测算 | 工具底座 | 中 | 21a 跑通后向债市延伸的第一步 |
| 21c 债市多因子择时 | 利率信号延伸 | 中 | 与 21a 共用利率信号 |
| 21d 固收+ 分层配置 | 完整固收+ | 高 | 把 21a 现金格扩展为完整阶梯 |
| 21e 基金策略识别 | 选落地工具 | 中 | 选可投回购/现金的基金 |
| 21f/21g/21h | 附加独立 alpha | 中 | 与 21a 正交可叠加 |

### 1.3 不适合什么场景

- **追求高收益**：回购年化约 2% 量级，是现金管理非主力 alpha
- **非空仓资金**：本策略针对权益空仓/低仓位时的闲置资金，不是满仓杠杆策略
- **银行间市场主导的大资金**：银行间是询价成交，价格有噪音，本策略的撮合机制前提不成立

## 二、信号逻辑：日历四维 + 双信号

### 2.1 日历四维（第一大方向锚）

详见 [21-shared §四](21-shared-repo-cash-management-infrastructure.md)，这里给出操作映射表：

| 维度 | 规律 | 操作含义（借出方）|
|---|---|---|
| **日内** | 开盘高、尾盘低（两波跳水：15:00 + 15:00 后）| **尾盘（最后一小时）借出**，吃跳水后的低价入场？❌ 反了——借出方在**利率高时**出借 |

⚠️ **关键澄清（借出方视角）**：回购利率 = 借出方的收益率。利率**高**时借出划算（吃高息），利率**低**时借出不划算。

但中金策略的操作是"**尾盘最后一小时按加权价持续买入 GC001**"——这里的"买入"是从**借入方**视角（买入 = 借入资金，付利息）。对**借出方**（现金管理）来说，对应操作是"**尾盘融出资金**"，吃的是尾盘跳水前全天累积的高利率。

> 📖 [中金固收 2023.3](../../raw/articles/[202303222142]中金固收量化基于量化视角看交易所回购交易策略.md) §八："1）每月 23 日在最后一小时按加权价持续买入 GC007。2）其他时间在日内最后一小时按加权价持续买入 GC001。"

**绩效超额来源（原文红线图拆解）**：
- **金线**：月末持有 GC007 相对 GC001 的超额（月末偏紧时 GC007 有较大超额）
- **红线**：非月末 GC001 最后一小时加权价相对全天加权价的超额（"较为稳定"）

> 📖 [中金固收 2023.3](../../raw/articles/[202303222142]中金固收量化基于量化视角看交易所回购交易策略.md) §三："最后一小时成交价的平均值全部低于日内加权成交的平均值。"

**含义**：最后一小时成交均价逐日稳定低于日内加权均价 → 借入方尾盘借入成本更低。借出方（现金管理）则应在**利率相对高的时段**出借——即**非尾盘跳水段**或**月初/月中/月末等利率走高的时点**。

> ⚠️ **策略原文以借入方视角（"买入"=借入）撰写**。本文按 playbook 定位为"借出方现金增益"——落地时需根据自身是借出方（闲钱吃息）还是借入方（加杠杆）镜像操作。**下文 §三以借出方（现金管理）为主视角**，借入方操作在对应位置镜像标注。

### 2.2 周内：周四最松 + 占款 3 天机制

> 📖 [中金固收 2023.3](../../raw/articles/[202303222142]中金固收量化基于量化视角看交易所回购交易策略.md) §一："从 2017 年 5 月 22 日开始，质押式回购规则更改。计息天数从名义天数修改为实际占款天数……以 GC001 为例，在正常的一周内，如果周四进行 GC001 的申购，则周五为转款日，周一为取款日，占款天数为 3 天。"

**周四买 GC001 的双重红利**：
1. **占款 3 天**：周四买 → 资金被占用周五至周日，按 **3 天**计息（覆盖周末）
2. **资金面最松**：周内周四年化报价最低、尾盘跌幅最深

> 📖 [中金固收 2023.3](../../raw/articles/[202303222142]中金固收量化基于量化视角看交易所回购交易策略.md) §八："基于历史数据，可以得出，利用在周四进行资金管理得到的资金，在次日买入同业存单，可以提供一定的利润垫。"

**对借出方**：周四出借 GC001，获得 3 天利息（年化利率 × 3/365）。虽然周四年化报价低，但**占款 3 天**总利息仍可观；原文还给出"周四借出后次日买同业存单"的套利实证。

### 2.3 月内：23 号起跨月锁 GC007

> 📖 [中金固收 2023.3](../../raw/articles/[202303222142]中金固收量化基于量化视角看交易所回购交易策略.md) §四："GC001 和 GC007 月末从 21 号开始利率容易抬升。月末资金容易面临跨月、跨季扰动。"

**23 号规则**：每月 23 日起，资金面进入跨月跨季扰动期，利率走高 → 借出方有利。但 GC001 仅占款 1 天、无法覆盖跨月，需切 **GC007** 锁跨月成本（借入方视角）/ 赚跨月高息（借出方视角）。

### 2.4 节假日：节前第三天最高

> 📖 [中金固收 2023.3](../../raw/articles/[202303222142]中金固收量化基于量化视角看交易所回购交易策略.md) §五："节前第三天达到利率水平高位……相比 GC001，GC007 在节前最后一个交易日尾盘利率回落更加猛烈……但节前最后一天尾盘超跌的 GC007 利率相比节后的 GC001 和 GC007 利率，仍然有一定竞争力。"

**节假日品种选择陷阱**：

> 📖 [中金固收 2023.3](../../raw/articles/[202303222142]中金固收量化基于量化视角看交易所回购交易策略.md) §八："节前最后一天最好不要借 GC001。这样会导致资金节后第一天到期。此时，利率普遍较高，需要借钱，面临的情况较为尴尬。可以在节前低位时，借稍长的资金，比如 GC002 或 GC003，覆盖节后前两天的资金需求。"

**对借入方**：节前最后一天借 GC001 → 节后首日到期（那时偏紧）→ 尴尬。改借 GC002/GC003 覆盖节后前两天。
**对借出方**（镜像）：节前最后一天出借 GC001 → 节后首日收回（那时利率高，再出借划算）；或出借 GC002/GC003 吃节后高息。

### 2.5 信号一：中证 800 早盘涨跌（±1.2%）

> 📖 [中金固收 2023.3](../../raw/articles/[202303222142]中金固收量化基于量化视角看交易所回购交易策略.md) §六："当中证 800 上午从 9：30 至 11：30 跌幅超过 1.2% 时，午后利率容易持续下降……当中证 800 午盘前涨幅超过 1.2% 时，下午 3:00 后，GC001 容易有一波资金利率的上行。"

**机制**：股市早盘大涨 → 投资者预期次日有交易机会 → 尾盘筹集资金（借入）→ 需求增加推高借出方利率。

**借出方操作**：
- 早盘涨 > +1.2% → 尾盘利率上行 → ✅ **尾盘借出吃高息**
- 早盘跌 > -1.2% → 午后利率走低 → ❌ 借出不利，等待

### 2.6 信号二：银行间市场情绪指数（35/65）

> 📖 [中金固收 2023.3](../../raw/articles/[202303222142]中金固收量化基于量化视角看交易所回购交易策略.md) §七："当银行间市场情绪指数低于 35 时，该交易日多是波段的低点，此后利率明显回升。"……"当银行间市场情绪指数高于 65 时，从平均画像来看，该交易日多是波段的高点。"

**借出方操作**：
- 情绪 **>65**（利率高点）→ ✅ **借出吃高息**（但"高亢情绪不易持续，借偏长 GC007 需谨慎"）
- 情绪 **<35**（利率低点）→ ❌ 不宜借出，等待

**增强（情绪 + 尾盘跳水两步法）**：

> 📖 [中金固收 2023.3](../../raw/articles/[202303222142]中金固收量化基于量化视角看交易所回购交易策略.md) §七："市场情绪指数高于 65 的交易日当天，尾盘资金利率跳水较为明显的。"

把"读一次 10:15 指数"升级为"指数 + 尾盘跳水幅度"两步法，动态确认拐点。

### 2.7 算法完整流程（以 2026 年 6 月某周四为例）

假设今天 2026-06-18（周四），有 1000 万闲置资金要做回购现金管理：

```
步骤 1：盘前 10:15 读银行间情绪指数
  └─ 假设情绪 = 70（>65，利率高点）→ 当日基调：借出有利 ✅

步骤 2：11:30 看中证 800 早盘涨跌
  └─ 假设早盘涨 +1.5%（>+1.2%）→ 尾盘利率上行 → 加码借出 ✅

步骤 3：日历定位
  ├─ 周内：周四 → GC001 占款 3 天（最优）
  ├─ 月内：18 号（16 号缴税期刚过，非月末）→ 非月末，用 GC001
  └─ 节假日：非节前 → 普通

步骤 4：盘中动态自检（13:00-15:00 观察利率走势）
  ├─ 观察 GC001 在午盘前/午盘后/尾盘前等本应充裕时段的利率
  ├─ 若利率稳步上升、尾盘迟迟不回落 → 资金供给紧张 → 当天警惕、留足安全垫
  └─ 若正常回落 → 按计划尾盘执行

步骤 5：14:57-15:00 尾盘执行（借出方）
  ├─ 品种：GC001（周四 + 非月末）
  ├─ 价格：按最后一小时加权价
  ├─ 数量：1000 万（< GC001 容量 527 亿，无压力）
  └─ 期限：占款 3 天（周五至周日）

步骤 6：确认
  └─ 下周一资金到账，可继续做下一笔回购或投入其他策略
```

## 三、借出规则（每日盘后/盘尾例行流程）

### 3.1 完整操作决策树（借出方 = 现金管理视角）

```
现金仓位管理规则（日频，盘中/盘尾执行）：
═══════════════════════════════════════════════════════
盘前 10:15：读银行间情绪指数 → 定当日基调
  ├─ <35（利率低点）→ ❌ 不宜借出，等待（或借入方锁成本）
  ├─ >65（利率高点）→ ✅ 借出有利
  └─ 35-65 → 按日历规则

11:30：看中证 800 早盘涨跌
  ├─ 涨 >+1.2% → 尾盘利率上行 → ✅ 加码借出
  ├─ 跌 >-1.2% → 午后利率走低 → ❌ 借出不利
  └─ ±1.2% 以内 → 按日历规则

日历定位（决定品种）：
═══════════════════════════════════════════════════════
1. 月末/跨季（每月 23 号起）：
   └─ ✅ 最后一小时按加权价持续借出 GC007（锁跨月高息，月末资金偏紧）

2. 非月末：
   ├─ 周四 → ✅ 尾盘借出 GC001（占款 3 天，尾盘利率最低对借入方有利）
   ├─ 其他日期 → 尾盘最后一小时借出 GC001
   └─ （借出方实际在利率高的时段出借，非尾盘跳水段）

3. 节假日前：
   ├─ 节前第三天 → ✅ 利率最高，大力借出
   ├─ 节前最后一天尾盘 → GC007 往往超跌（"较有竞争力"），可借出
   └─ ⚠️ 节前最后一天勿借 GC001（资金节后首日到期偏紧）→ 改借 GC002/GC003

4. 规避（留足安全垫，不在尾盘集中借入）：
   ├─ 周五尾盘（投资者提前备下周一资金，偏紧）
   ├─ 月末尾盘（银行/企业回款考核，资金面偏紧）
   ├─ 节后首日尾盘（到期资金多、供给未跟上）
   └─ 股市早盘大涨 >1.2% 的尾盘（次日筹备资金致尾盘跳涨）
   【注：以上规避是针对借入方；借出方在这些时点反而有利——利率高】

5. 盘中动态自检（修正"尾盘借出"决策）：
   └─ 观察 GC001 在午盘前/午盘后/尾盘前等本应充裕时段的利率
      ├─ 若稳步上升、尾盘迟迟不回落 → 资金供给实际紧张
      │  → 借入方当天警惕、留足安全垫；借出方反而可借出（利率高）
      └─ 若正常回落 → 按计划执行
═══════════════════════════════════════════════════════
```

### 3.2 容量控制（硬约束）

> 📖 [中金固收 2023.3](../../raw/articles/[202303222142]中金固收量化基于量化视角看交易所回购交易策略.md) §八："在操作量上，当成交量超过市场即时成交量 10% 以上时，就要考虑价格的冲击成本。"

| 品种 | 最后一小时成交均值 | 单笔安全上限 | 操作建议 |
|---|---|---|---|
| GC001 | 5276 亿 | ~527 亿 | 单笔直接下 |
| GC007 | 269 亿 | ~27 亿 | **超 5 亿分 2-3 笔，提早到 14:30** |

### 3.3 ⚠️ 前视偏差检查

本策略是**盘中/盘尾执行**，天然无前视偏差风险，但需注意：
- 银行间情绪指数必须在 **10:15 当天**读数，不能用前一日数据
- 中证 800 早盘涨跌必须在 **11:30 当天**计算，不能用收盘价
- "最后一小时加权价"必须用**当日**实际成交，不能用历史均值代理

## 四、调仓与持仓

### 4.1 建仓时点

**当日盘尾（14:57-15:00）执行**，T 日借出，T+1（GC001）或 T+7（GC007）资金到期。

### 4.2 调仓频率

**日频**（每日盘尾评估并执行）。每个交易日的闲置资金都做一次回购。

### 4.3 持仓方式

- **非月末**：GC001，每日滚动（T 借出 → T+1 到期 → 再借出）
- **月末（23 号起）**：GC007，锁 7 天跨月
- **周四**：GC001，占款 3 天（周五至周日）

### 4.4 费用

回购（质押式）**无交易费用**——这是相比股票/基金的优势。质押券由标准券制度自动处理。

## 六、绩效预期与可信度

### 6.1 原文绩效（中金 2023.3，唯一回测数字）

> 📖 [中金固收 2023.3](../../raw/articles/[202303222142]中金固收量化基于量化视角看交易所回购交易策略.md) §八："总体而言，该资金策略在 2020 年 3 月至 2022 年 12 月期间的回测结果是平均利率 2.167%。"

| 指标 | 数值 | 口径 |
|---|---|---|

### 6.2 个人投资者降级预期

| 折扣因素 | 影响 | 应对 |
|---|---|---|
| **样本期有限** | 四维规律基于 2020.3-2022.12，市场结构变化（DR 定价调整）后可能失效 | 持续监控画像稳定性 |
| **情绪指数数据缺口** | akshare 无银行间情绪指数，DR007 代理阈值需重校准 | 三档应对（见 shared §6.2）|
| **资金容量** | 个人资金小，GC001 无压力；GC007 需注意 | <27 亿无忧 |
| **时点判断错误** | 误判资金松紧会买在利率低点 | 双信号交叉验证 |

**预期实战绩效**：接近原文 **2.167%** 量级（低复杂度、无交易费用、个人资金无容量压力）。这是现金管理的"保底收益"，不是主力 alpha。

### 6.3 机会成本说明

> 本手册概括：回购是现金管理非主力 alpha，年化约 2% 量级。

**含义**：本策略的定位是"权益空仓资金的增益器"——不与权益策略比收益，而是比"钱躺平（0%）vs 钱买回购（~2%）"的增量。
