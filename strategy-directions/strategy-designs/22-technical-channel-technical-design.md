```
┌─────────────────────────────────────────────────────────────┐
│  数据层（QMT xtquant 优先 / akshare 备选）                   │

│         ↓                                                    │

│  信号层（纯 Python，日频盘后）                                │

│  └─ 输出 trigger_signal.csv（code/方向/强度/日期）           │
```

### 1.1 接口选择（QMT 优先，akshare 备选）

| 数据 | 主路径（QMT） | 备路径（akshare） | 选择依据 |

| 函数名 | 文件路径 | 参数 | 返回字段 | 备注 |
|---|---|---|---|---|
| `stock_zh_a_hist` | `stock_feature/stock_hist_em.py:952` | `symbol="000001"`;`period="daily"`;`start_date`;`end_date`;**`adjust=""/"qfq"/"hfq"`** | 日期/股票代码/开盘/收盘/最高/最低/成交量/成交额/振幅/涨跌幅/涨跌额/**换手率** | 东财主力；支持前复权qfq；默认空串=不复权 |

> ⚠️ **复权处理**（技术分析对复权敏感）：通道/均线/形态必须用 **前复权 qfq** 保证连续性，避免除权缺口产生假突破信号。QMT `get_market_data_ex` 的复权参数需对照你的版本确认；akshare 明确支持 `adjust="qfq"`。

### 1.3 配方 D 的降级方案（规避期权数据依赖）

配方 D 技术打分体系原版 10 指标含期权隐波/PCR（波动/拥挤维度）。playbook 明确**震荡市改进版剔除量价 4 因子、仅留趋势/波动/拥挤 6 因子**。本设计**默认走降级版**（6 因子），不依赖期权数据：

| 维度 | 原版指标 | 降级处理 |
|---|---|---|
| 价格 | 20日乖离率、20日布林 | ✅保留（日线即可）|
| 量能 | 20/60日换手率乖离率 | ✅保留（akshare现成 / QMT派生）|
| 趋势 | 20日ADX、20日创新高天数占比 | ✅保留（日线派生）|
| 波动 | ~~期权隐波~~、60日换手率波动 | ⚠️隐波剔除，留换手率波动 |
| 拥挤 | 涨停占比5日均、~~期权PCR~~ | ⚠️PCR剔除，留涨停占比 |

## 2. 信号层设计

### 2.1 配方 A 通道突破（最简，推荐起步）

**机制**：价格中枢（MA/EMA）+ 带宽（标准差/ATR）画上下轨，突破上轨=趋势向上。

**进阶实现·价量共振（华创 2019）**——价能与量能共振才出信号，避免放量下跌误判：

```
算法（伪代码）：
输入：日线OHLCV（前复权）
1. 算价能  PRICE_POWER = BMA_close_t / BMA_close_{t-N}
         （BMA = BMA(L=50日)，N=3）
2. 算量能  VOL_POWER  = AMA_short / AMA_long
         （AMA_long = AMA(100日)）
3. 价量共振值 = PRICE_POWER × VOL_POWER
4. 信号（牛熊双阈值，防误判）：
   ├─ 价量共振值 > T1=1.125 → 看多（趋势向上）
   ├─ 价量共振值 < -T2=1.275 → 看空
   └─ 否则维持原状
```

**绩效对标**（playbook §二）：价量共振沪深300 年化 18.4%/胜率61%；市场划分版宽基均值14.61%。

> ⚠️ **放量下跌红线**（华创）：价量共振"放量下跌量能远超价能易误发抄底"——必须用**牛熊双阈值**（多头 T1=1.125、空头 T2=1.275），不能单阈值。

### 2.2 配方 D 技术打分（最强，进阶）

**机制**：10（降级版6）指标各自转多空信号，等权取均值落 [-1,+1]，±0.33 阈值转多/空/平。

```
算法（伪代码，降级版6指标）：
1. 各指标转信号 ∈ {-1, 0, +1}：
   ├─ 价格维：20日乖离率（>+阈值=多）、20日布林%b（>+0.8=多）
   ├─ 量能维：20日换手率乖离、60日换手率乖离
   ├─ 趋势维：20日ADX（>25=多）、20日创新高天数占比
   └─ 拥挤维：涨停占比5日均（反向，过高=空）
2. 综合分 = 等权均值(各指标信号) ∈ [-1, +1]
3. 转档：
   ├─ 综合分 > +0.33 → 看多
   ├─ 综合分 < -0.33 → 看空
   └─ 否则 → 中性（平）
```

**绩效对标**：年化 21%/夏普1.2。**🔴 上证50失效**（华泰2025.12，超大盘指数效果不佳）。

### 2.3 与 #10 的叠加逻辑（核心用法·模式1）

```
叠加流程（伪代码）：
每日盘后：
1. #10 龙虎榜信号层产出 candidates.csv（选股域）
2. #22 对每只候选股算通道突破信号（配方A）
3. 叠加过滤：
   ├─ 候选股 ∈ 通道看多（价量共振>T1）→ 进入 order_list（确认入场）
   ├─ 候选股 ∈ 通道看空 → 暂缓入场（等突破）
   └─ 候选股 ∈ 中性 → 观察（可设3日窗口，未突破则放弃）
4. 输出 filtered_orders.csv → #10 下单层执行
```

> 💡 **为什么叠加有价值**：#10 单独的问题是"选对了股但买在下跌通道中"（事件信号不看时点）；#22 单独的问题是"满仓跑回撤40%+"（纯技术没选股域）。叠加后——#10 给高质量选股域，#22 给精确入场时点，**两个短板互相弥补**。

## 5. 回测验证方案

**目标1（配方A独立）**：复现价量共振沪深300 年化18.4%/胜率61%。
```
1. 拉沪深300指数或ETF前复权日线（2020起）
2. 每日算价量共振值，按双阈值出多空信号
3. 多头满仓/空头空仓，统计年化、胜率、最大回撤
4. 对标18.4%/胜率61%，偏差大检查N/T参数
```

**目标2（与#10叠加增益）**：验证叠加后是否优于 #10 单独跑。
```
1. 取#10候选股池（2023起）
2. 对照组：#10单独（候选即买）
3. 实验组：#10候选 ∩ #22通道看多（确认才买）
4. 对比：年化超额、最大回撤、胜率
   ├─ 实验组回撤显著更低 → 叠加有效（#22过滤了下跌通道入场）
   └─ 实验组年化也显著更高 → 双向增益成立
```
