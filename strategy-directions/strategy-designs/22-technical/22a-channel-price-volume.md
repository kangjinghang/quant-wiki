## 一、策略定位

### 1.1 赚什么钱

**价量共振的钱**：成交量是市场情绪的温度计，价格是共识的结果。当**成交量放大（量能）+ 价格走强（价能）同时出现**时，说明有增量资金在推动趋势——跟进这股力量。

**alpha 来源**：趋势追随 + 信息发现。价量共振本质是把"价"和"量"各做一条均线、相乘，捕捉"放量上涨"这一最经典的趋势启动信号。

> 📖 [华创 2019.4](../../../raw/articles/[201904222145]华创金工成交量的奥秘另类价量共振指标的择时.md)：构造价量共振指标，"当价量共振指标大于 Threshold 则做多，否则平仓"。

**VMACD_MTM 的钱**：成交量 MACD 的金叉死叉滞后，改用"N 日累计动量"刻画成交量放量/缩量趋势——成交量放量程度与指数未来收益正相关。

> 📖 [东北 2024.9](../../../raw/articles/[202409210821]成交量择时指标VMACD_MTM.md)："成交量放量程度与指数未来收益正相关"。

### 1.2 在家族里的角色

| 策略 | 角色 | 复杂度 | 与本策略（22a）的关系 |

### 1.3 不适合什么场景

- **持续放量下跌的市场**：价量共振会误发做多信号（量能放大但价能崩塌），必须加牛熊双阈值
- **中小创/创业板**：华创自承"除了中小创以外的大部分其他宽基指数表现较好"，小盘信号偏弱
- **震荡市**：通道突破类策略在震荡市频繁假突破，需升级到 22d 震荡市改进版（阈值改 0）

## 二、信号逻辑

本文给三套独立可用的信号：① 纯价格通道（国君理论框架）② 价量共振（华创主力）③ VMACD_MTM（东北量能动量）。落地时**推荐②或③**，①是理论基础。

### 2.1 纯价格通道（国君理论框架，理解通道工具用）

#### 中枢 + 带宽双构件

> 📖 [国君 2022.10 系列02](../../../raw/articles/[202210301551]国君配置通道技术的技术构件中枢和带宽通道技术面面观系列之02.md)："**中枢和带宽组成了通道技术的全部技术构件**。"

| 通道 | 中枢 | 带宽 | 分类 |
|---|---|---|---|
| Donchian | 无（直接取极值）| N 日最高/最低 | 偏直接法 |
| Bollinger 带 | MA（N 日）| MA ± k·标准差 | 间接法 |
| Keltner | EMA（N 日）| EMA ± k·ATR | 间接法 |

#### 中枢-带宽动态制约（核心设计原则）

> 📖 [国君 2022.10 系列02](../../../raw/articles/[202210301551]国君配置通道技术的技术构件中枢和带宽通道技术面面观系列之02.md)："**中枢越是呈现波动性、灵活性的时候，道带宽度应该趋于收窄；中枢越是呈现趋势性、稳健性的时候，道带宽度应该趋于走阔**。"

#### 布林带必须正规化（%b / BandWidth）

> 📖 [国君 2022.10 系列01](../../../raw/articles/[202210281436]国君配置通道技术之历史沿革直接法vs间接法通道技术面面观系列之01.md)："中枢本身是一个和价格的绝对水平高度相关的指标，因此我们需要'进阶信息'去消除价格的量纲。"

- **%b** = (收盘价 − 下轨) / (上轨 − 下轨) —— 价格在通道内的相对位置
- **BandWidth** = (上轨 − 下轨) / 中枢 —— 通道张口程度

> ⚠️ **跨期/跨标的不可比是绝对价格中枢的硬伤**，实战必须用 %b / BandWidth。

### 2.2 价量共振指标（华创主力，5 步构造法）

#### 核心公式

> 📖 [华创 2019.4](../../../raw/articles/[201904222145]华创金工成交量的奥秘另类价量共振指标的择时.md) §02："1，成交量使用的移动平均线为 AMA，收盘价使用的移动平均线为 BMA(长度为 L)。2，**价能 = BMA(Today)/BMA(Today−N)**。3，**量能 = AMA5 / AMA Long**。4，**价量共振指标 = 价能×量能**。5，当价量共振指标大于 Threshold 则做多，否则平仓。"

```
价能 = BMA(今日收盘) / BMA(Today − N)         # 价格相对 N 日前的强弱
量能 = AMA(短期=5日) / AMA(长期=100日)         # 量能放大程度
价量共振指标 = 价能 × 量能
若指标 > Threshold → 做多；否则 → 平仓
```

**均线说明**：
- AMA：原文定义为"灵敏度较高的移动平均线"用于成交量，未给出全称展开（技术分析界常指 Kaufman 自适应均线，但不能据原文断定）
- BMA：收盘价用的移动平均线，长度 L

#### 普通版参数

> 📖 [华创 2019.4](../../../raw/articles/[201904222145]华创金工成交量的奥秘另类价量共振指标的择时.md)："在 AMA 长期移动平均线长度为 100，BMA 移动平均线长度为 L 为 50，N=3，Threshold=1.15……"

| 参数 | 值 | 含义 |
|---|---|---|
| AMA 长期 | 100 日 | 量能分母 |
| AMA 短期 | 5 日 | 量能分子 |
| BMA 长度 L | 50 | 收盘价均线 |
| N | 3 | 价能回看天数 |
| Threshold | 1.15 | 做多阈值 |

#### 牛熊双阈值迟滞（核心改进，应对放量下跌）

**问题**：单纯价量共振在"持续放量下跌"时会误判——量能放大使指标突破阈值，发出错误的做多信号。

> 📖 [华创 2019.4](../../../raw/articles/[201904222145]华创金工成交量的奥秘另类价量共振指标的择时.md)："尤其是在持续放量下跌的市场……由于量能较大，甚至使得价量指标依旧能够突破阈值发出错误的做多信号。"

**改进设计**：用 MA5 vs MA90 划分多/空头市场，不同市场用不同阈值：

> 📖 [华创 2019.4](../../../raw/articles/[201904222145]华创金工成交量的奥秘另类价量共振指标的择时.md)："当 5 日均线高于 90 日均线，市场划分为多头市场；当 5 日均线小于 90 日均线，市场划分为空头市场。" "当前为多头市场下，若价量共振指标大于 Threshold1 则做多……当前为空头市场下，若价量共振指标大于 Threshold2 则做多。"

| 市场状态 | 划分 | 阈值 |
|---|---|---|
| 多头市场 | MA5 > MA90 | Threshold1 = **1.125** |
| 空头市场 | MA5 < MA90 | Threshold2 = **1.275** |

> 💡 **为什么空头要更高阈值**：空头市场里放量下跌多见，要求指标更高（1.275 vs 1.125）才做多，过滤"放量下跌误判"。

### 2.3 VMACD_MTM（东北量能动量，成交量 MACD 改良）

#### 为什么不用裸 VMACD 的金叉死叉

经典 VMACD 的金叉死叉（DIF 与 DEA 交叉）相对滞后：

> 📖 [东北 2024.9](../../../raw/articles/[202409210821]成交量择时指标VMACD_MTM.md)："这一交叉点相比于价格趋势变动而言相对滞后，交易信号可能在趋势已经形成一段时间后才出现。"

#### 改良：累计动量代替金叉死叉

> 📖 [东北 2024.9](../../../raw/articles/[202409210821]成交量择时指标VMACD_MTM.md)："单日的 VMACD 边际变动值波动的随机性较大……所以我们考虑采用一定时间窗口之内的累计变化来刻画区间内成交量的变动情况。"

#### 构造（3 步，关键工程坑）

> ⚠️ **工程坑**：标准化的对象是 **VMACD 指标**（先算 VMACD 再标准化），**不是原始成交量**——两者顺序颠倒会得到不同数值。

```
步骤 1：算 VMACD（参数沿用经典 12, 26, 9）
  ├─ DIF = EMA(volume, 12) − EMA(volume, 26)
  ├─ DEA = EMA(DIF, 9)
  └─ VMACD = (DIF − DEA) × 2

步骤 2：对 VMACD 指标做 Z-score 标准化（滚动 N=60 日窗口）
  └─ VMACD_std = (VMACD − mean_60) / std_60
  ⚠️ 原文："我们在计算 VMACD_MTM 之前，首先对 VMACD 指标进行 Z-score 标准化。"
  ⚠️ 减参数：Z-score 窗口 N 取与 MTM 窗口相同的 60，"为减少择时策略中的参数数量"

步骤 3：算 VMACD_MTM
  ├─ VMACD_diff = 当日 VMACD_std − 前一日 VMACD_std
  └─ VMACD_MTM = 近 N=60 个交易日 VMACD_diff 的总和（窗口内累计动量）
```

#### 双阈值迟滞规则

> 📖 [东北 2024.9](../../../raw/articles/[202409210821]成交量择时指标VMACD_MTM.md)："设定阈值 T（T≥0）：若当日 VMACD_MTM 大于 T，则判断为应当持仓；若当日 VMACD_MTM 小于 −T，则判断为应当空仓；**若当日 VMACD_MTM 介于 −T 与 T 之间，则保持当前状态不变**。"

| 状态 | 条件 | 动作 |
|---|---|---|
| 持仓 | VMACD_MTM > T | 持仓 |
| 空仓 | VMACD_MTM < −T | 空仓 |
| 滞回 | −T ≤ VMACD_MTM ≤ T | **保持当前状态不变** |

最优参数：**N=60，T=1**。T=1 对应标准化后分布约 1/3 与 2/3 分位。

### 2.4 算法完整流程（以沪深300 为例）

假设今天是 2026-07-06（周一），要算今日的价量共振信号（市场划分版）：

```
步骤 1：取数据
  └─ 沪深300 近 100+ 日 OHLCV + 成交量

步骤 2：算价能
  ├─ BMA(今日收盘) = 近 50 日收盘价的 BMA（长度 L=50）
  ├─ BMA(Today − 3) = 3 个交易日前那天的 BMA 值
  └─ 价能 = BMA(今日) / BMA(Today−3)

步骤 3：算量能
  ├─ AMA 短期 = 近 5 日成交量的 AMA
  ├─ AMA 长期 = 近 100 日成交量的 AMA
  └─ 量能 = AMA5 / AMA100

步骤 4：算价量共振指标
  └─ 指标 = 价能 × 量能（例如 1.05 × 1.20 = 1.26）

步骤 5：判定市场状态（决定用哪个阈值）
  ├─ MA5 = 近 5 日收盘均值
  ├─ MA90 = 近 90 日收盘均值
  └─ 若 MA5 > MA90 → 多头市场，阈值 = 1.125
     若 MA5 < MA90 → 空头市场，阈值 = 1.275

步骤 6：生成信号
  ├─ 若指标 > 阈值 → 做多信号
  └─ 否则 → 平仓信号

步骤 7：执行（T+1 开盘）
  ├─ 今日（T）盘后发信号
  └─ 次日（T+1）开盘集合竞价执行做多/平仓
  ⚠️ 前视偏差检查：步骤 1-6 用到的所有数据在 T 日收盘后都真实可见
```

## 三、选指数/择时规则

### 3.1 每日盘后例行流程

```
每日盘后：
1. 计算技术指标（三套独立可选）：
   ├─ 纯价格通道：布林带 MA±2σ、Donchian N 日高低
   ├─ 价量共振：价能×量能 + 牛熊双阈值
   └─ VMACD_MTM：VMACD(12,26,9) → Z-score(60) → MTM(60) → ±1 迟滞
2. 生成择时信号（做多/空仓）
3. 输出信号 → 次日开盘（或 VMACD 次日开盘集合竞价）执行
4. 空仓期默认配固收（CBA00101.CS）—— 见 22-shared §4.3
```

### 3.2 标的指数适配性（重要）

| 指数 | 价量共振适配 | VMACD_MTM 适配 | 备注 |
|---|---|---|---|
| 沪深300 | ✅ **最佳**（年化 18.4%/胜率 61%）| ✅ 优秀 | 价量共振沪深300 表现最好 |
| 中证500/800/1000 | ✅ 较好 | ✅ 良好 | 宽基均值 14.61%（市场划分版）|
| 中小创/创业板 | ⚠️ **偏弱** | — | 华创自承"除了中小创以外表现较好" |

### 3.3 硬过滤与边界条件

| 条件 | 阈值 | 作用 |
|---|---|---|
| 成交量异常缺失 | 当日成交量为 0 或停牌 | 跳过该日信号，维持上期状态 |
| 数据预热期 | AMA 长期 100 日、BMA 50 日、Z-score 60 日 | 前 100 个交易日不生成信号 |
| 涨跌停处理 | 涨停买不进、跌停卖不出 | 实战需打折（见 §6.3）|

### 3.4 ⚠️ 前视偏差检查

- 价量共振指标用的 BMA(Today)、AMA(Today) 都基于今日及之前的数据 → T 日收盘后可见 ✅
- VMACD_MTM 的 Z-score 用滚动 60 日窗口 → T 日收盘后可见 ✅
- **执行必须在 T+1 日开盘**，不能在 T 日收盘就用 T 日信号成交

### 4.3 持仓方式

## 七、失效红线

| 红线 | 表现 | 监控动作 |
|---|---|---|
| 🔴 **放量下跌误判（价量共振）** | 2016-02-23~02-29 量能放大使指标突破阈值，发出错误做多 | **必须加牛熊双阈值**（Threshold2=1.275）|

| 🔴 **VMACD_MTM 标准化顺序错** | 对原始成交量标准化而非 VMACD 指标 → 数值完全不同 | 严格按"先算 VMACD 再 Z-score"顺序 |
| 🔴 **量化拥挤赛道失效** | 国君价量 ML 中证500 仅 7.04%（量化拥挤）| 监控中证500 拥挤度 |
| 🟡 **震荡市假突破** | 通道突破在震荡市频繁假突破 | 升级到 22d 震荡市改进版（阈值改 0）|
| 🟡 **布林带量纲错** | 用绝对价格跨期不可比 | 强制用 %b / BandWidth |
| 🟡 **中枢-带宽不匹配** | 线性中枢配普通标准差 → 通道失真 | 线性中枢用带权重标准差 |
