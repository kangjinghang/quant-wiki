## 一、策略定位

### 1.1 赚什么钱

**形态延续的钱**：某些 K 线形态（如双底、杯柄）出现后，价格有统计上的延续/反转倾向。赚这个倾向的钱。

> 📖 [华创 2023.5 开篇](../../raw/articles/[202305121502]专题报告K线形态研究开篇形态学初识与应用.md)："K 线的本质内涵是**多空双方资金在争夺主导权而留下来的轨迹**，通过研究 K 线形态，我们能够深入地观察到市场的真正变化。"

**形态为什么值得研究（华创立论）**：

> 📖 [华创 2023.5 开篇](../../raw/articles/[202305121502]专题报告K线形态研究开篇形态学初识与应用.md)："在一切可以得到的股票信息中，**仿制 K 线形态是成本最高的**。如果想仿制股票的 K 线形态，必须用钱'堆'出来，这比财务造假、发布一份造势公告来的成本高很多。所以 K 线形态更值得关注。"

### 1.2 在家族里的角色

| 策略 | 角色 | 信号类型 | 与本策略（22b）的关系 |
|---|---|---|---|
| **22b 形态选股** | **因子型（个股选股）** | 形态识别 | — |
| 22a 通道/价量 | 工具型（指数择时）| 通道/量价 | 22a 指数层，22b 个股层 |
| 22x 形态剪刀差 | 成分股聚合（指数择时）| 形态聚合 | 22b 是个股层，22x 聚合到指数 |
| 22y DTW | 形态相似性（指数择时）| 序列匹配 | 22b 单形态，22y 序列相似 |

### 1.3 形态学的三层用法（绩效性质截然不同，不可混比）

| 用法 | 代表形态 | 绩效性质 | 机制 |
|---|---|---|---|
| **形态选股（多头，正 beta）** | 双底 | 多头组合，跑赢基准看市场环境 | 欧奈尔体系，趋势延续 |
| **形态做空提示（负 beta）** | 十字孕线/母子线/乌云压顶/停顿线 | 做空策略收益（beta 为负）| 形态+均线上方→看空 |
| **形态信号市场择时** | 形态比率剪刀差 | 指数纯多头择时 | 全市场聚合（见 [22x](22x-pattern-scissor.md)）|

> ⚠️ **重要口径区分**：本策略涉及的"年化"一半是做空策略收益（负 beta）、一半是多头选股收益（正 beta），**口径不可直接比较**。

### 1.4 不适合什么场景

- **震荡/熊市的双底选股**：双底是牛性持续形态，指数低位及连续上涨期胜率高，震荡/熊市失效
- **直接做空**：A 股做空无效，做空形态（十字孕线等）仅作**多头持仓的风险提示/减仓信号**
- **追求形态学综合打分**：华创只把它作为展望，**原文未给出个股层打分具体公式**

> 📖 [华创 2023.5 开篇](../../raw/articles/[202305121502]专题报告K线形态研究开篇形态学初识与应用.md)："终极的 K 线形态学研究，是通过 K 线形态对某个股进行形态学综合打分。该打分可以作为多因子选股框架中的独立因子。"（但"会在后续报告中详细说明最佳加权方式"——**截至形态学研究之二仍未落地**）

## 二、信号逻辑

### 2.1 双底形态（牛性持续，做多信号，正 beta）

#### 极点构成（A/B/C/D/E 五极点）

> 📖 [华创 2019.3](../../raw/articles/[201903281852]华创金工基于双底形态的识别与交易探索.md) §2.1："A=形态的起点；B=第一个底部；C=W 中间的最高点；D=第二个底部；E=决定买入点。"

#### 识别判据（6 条全部阈值）

| 判据 | 阈值 | 原文 |
|---|---|---|
| ① 形态前上涨趋势 | **≥30%** | "至少 30%" |
| ② 形态深度 | **15%-30%**（熊市可达 40%-50%）| "从 A 到 D 应在 15% 到 30% 之间" |
| ③ 形态长度 | **7-65 周** | "至少 7 周，最长 65 周" |
| ④ 第二底 vs 第一底 | **D 应低于 B** | "在大部分情况下，第二个底部都要低于第一个底部，这样也就能够淘汰那些意志薄弱的投资者。如果第二个底部不比第一个低，就会形成一个有缺陷、更易于失败的'类'双底形态" |
| ⑤ 理想买入点 E | 与 C 同价且低于 A | "双底成型后达到最佳买入点时，即图中 E 点价格" |
| ⑥ 成交量突破 | **≥平均值 20%** | "成交量至少应比平均值高 20%，这表明有机构在大量买入" |

#### 最优参数（参数高原，非孤岛）

> 📖 [华创 2019.3](../../raw/articles/[201903281852]华创金工基于双底形态的识别与交易探索.md)："形态长度最佳为 **15 周—18 周**，该组的胜率、收益率均是最优。" "形态深度最佳为 **20%—25%** 分组。"

**参数样本分布支撑**（回应过拟合质疑）：

| 参数区间 | 样本数 | 占比 | 原文 |
|---|---|---|---|
| 长度 15-18 周 | 1007 个 | **21.22%** | "15 周—18 周分组个数最多" |
| 深度 20-35% | 3560 个 | **75%** | "形态的深度集中在 20%-35% 之间……占样本总数 75%" |

> 💡 **最优参数恰落在样本最密集区**——是"参数高原"非"参数孤岛"，直接回应过拟合质疑。

#### 失效边界（禁区）

| 禁区 | 表现 | 原文 |
|---|---|---|
| 长度 >27 周 | 胜率/收益远不及平均 | "超过 27 周以后形态突破的胜率、收益率远不及平均水平" |
| 31-34 周 | 胜率波动最大，持有 12 天胜率仅 40% | "表现最差的分组是 31 周—34 周……持有 12 个交易日左右胜率仅为 40%" |
| 深度 >35% | 胜率/收益远不及平均 | "深度超过 35% 以后形态突破的胜率、收益率远不及平均水平" |
| 深度 45%+ | 稳定性最差 | "深度在 45% 以上的分组胜率波动最大" |

### 2.2 倒杯子形态（熊性持续，卖出信号，华创独创）

#### 识别判据（6 要素）

> 📖 [华创 2018.9](../../raw/articles/[201809031810]华创金工形态选股系列之一基于倒杯子形态的识别与交易探索.md) §02："倒杯子形态作为威廉·欧奈尔提出的杯柄形态(Cup-with-a-handle)的镜像。"

| 要素 | 阈值 | 原文 |
|---|---|---|
| ① 形态前下跌趋势 | **≥30%** | "至少 30%" |
| ② 形态高度 | **15%-30%** | "顶部的高度——从倒杯子左侧的底点到倒杯子的最高点一般控制在 15% 到 30% 之间" |
| ③ 形态长度 | **≥7 周** | "最小长度是 7 周，但有些可以持续更长" |
| ④ 手柄深度 | **<12%**，形成在倒杯子下半部分 | "手柄深度一般小于 12%，并形成在倒杯子的下半部分。手柄高度应在倒杯子左侧的最低点的 15% 以内" |
| ⑤ 卖出点 | 突破 B 点 | "如果还持有该股票，我们建议赶快将其卖出" |
| ⑥ 日突破量 | **≥平均值 40%-50%** | "至少高于平均值 40%-50%……表明还有机构在大量卖出" |

#### 最优杯长与失效边界（非单调关系）

| 杯长 | 30 天胜率 | 备注 |
|---|---|---|
| **6 周** | **69.75%**（收益 5.04%）| 最优 |
| **12 周** | **67.11%**（收益 8.14%，胜率均超 54%）| 次优 |
| >14 周 | 胜率很不稳定 | "杯长超过 14 周后的分组的胜率很不稳定" |
| 19-20 周 | **胜率均低于 50%** | "19—20 周分组的胜率均低于 50%" |
| 21-25 周 | 胜率又多在 50% 以上 | 非单调，操作需注意 |

> 💡 **杯长与胜率非单调关系**——19-20 周禁区内胜率最低，但 21-25 周又回升，操作时不能简单"越长越差"。

#### 倒杯子是市场环境的内生产物

| 年份 | 倒杯子个数 | 市场环境 |
|---|---|---|
| 2017 | **1006**（最多）| 震荡/熊市 |
| 2012 | 763 | 调整 |
| 2015 | **34**（牛市）| 牛市 |
| 2009 | **4**（最少）| 牛市 |

> 💡 **牛市几乎不出现倒杯子信号**，熊市/震荡市大量出现——倒杯子是市场环境的内生产物，这解释了为何它在 2017 至今持续回撤。

#### 透明度提示

> 📖 [华创 2018.9](../../raw/articles/[201809031810]华创金工形态选股系列之一基于倒杯子形态的识别与交易探索.md)："倒杯子形态是**我们完全独创**的形态。"

⚠️ **倒杯子无外部经典文献背书**（区别于双底的欧奈尔体系），有效性完全依赖华创自身回测。

### 2.3 二/三日做空提示形态（2023 系列，负 beta）

#### 总规律：形态 + 均线位置耦合

> 📖 [华创十字孕线 2023.7](../../raw/articles/[202307030853]专题报告K线形态学研究系列之三十字孕线.md) §2.1："对于正面信号，股价在均线下方的胜率超过股价在均线上方，表明十字孕线提示了短期股价止跌回升。对于负面信号，股价在均线上方的胜率超过股价在均线下方，表明十字孕线提示了短期股价有下跌风险。"

**核心规律**：**正向形态配均线下方胜率高（止跌回升），负向形态配均线上方胜率高（下跌风险）**。

#### 四种做空形态对照

| 形态 | 判据（关键）| 做空策略（耦合均线）|
|---|---|---|
| **十字孕线**（二日）| 第一长实体 + 第二须为**十字线**（非普通短实体）| 耦合 **MA60** |
| **母子线**（二日）| 后一根**实体处于前一根实体之内**（实体包实体，区别于孕线的影线包影线）| 耦合 **MA60** |
| **乌云压顶**（二日）| 阳线 + 第二根**跳空高开却收回第一根实体内**| 耦合 **MA30** |
| **停顿线**（三日）| 前两大阳/中阳 + 第三根**实体很短的阳线**| 耦合 **MA30** |

### 2.4 形态识别完整流程（以双底为例）

假设今天是 2026-07-06，扫描全市场找双底形态：

```
步骤 1：对每只个股，取近 65 周日线
  └─ 确保有足够长度覆盖形态

步骤 2：找 A/B/C/D/E 五极点
  ├─ A = 形态起点（要求 A 之前有 ≥30% 上涨趋势）
  ├─ B = 第一个底部
  ├─ C = W 中间最高点
  ├─ D = 第二个底部（要求 D < B）
  └─ E = 买入点（与 C 同价且低于 A）

步骤 3：判据过滤
  ├─ ① 形态前上涨 ≥30%？
  ├─ ② 深度 (A−D)/A ∈ [15%, 30%]？（熊市可放宽到 40-50%）
  ├─ ③ 长度 ∈ [7, 65] 周？最优 [15, 18] 周
  ├─ ④ D < B？
  └─ ⑥ 成交量突破 ≥ 平均值 20%？
  全部满足 → 入选

步骤 4：规避禁区
  ├─ 长度 >27 周（尤其 31-34 周）→ 剔除
  └─ 深度 >35%（尤其 45%+）→ 剔除

步骤 5：生成买入清单 → 次周首交易日买入，固定持有 20 交易日
```

## 三、选股规则

### 3.1 双底选股例行流程（周度）

```
每周一盘后：
1. 扫描全市场，识别双底形态（按 §2.4 流程）
2. 硬过滤：
   ├─ 剔除当天涨停不能买入的个股
   ├─ 剔除 ST 股
   └─ 形态参数落在禁区（长度>27周、深度>35%）→ 剔除
3. 等权配置，单票上限 10%（>10 只后等权）
4. 次周第一个交易日买入，固定持有 20 交易日
```

> 📖 [华创 2019.3](../../raw/articles/[201903281852]华创金工基于双底形态的识别与交易探索.md) §4："调仓频率：周度调仓，固定持有 20 个交易日。在每周的第一个交易日买入上周实现突破的个股。" "剔除当天涨停不能买入的个股，同时剔除 ST 股票。" "组合是按照等权配置，单只股票的最大持仓为 10%。"

### 3.2 做空提示形态用法（A 股改造）

A 股做空无效，把华创做空形态策略改造为**多头持仓的风险提示**：

```
每日盘后（针对多头持仓股）：
1. 识别持仓股是否出现做空形态（十字孕线/母子线/乌云压顶/停顿线）
2. 检查均线位置：
   ├─ 十字孕线/母子线 + 股价在 MA60 上方 + 负面信号 → 减仓/离场提示
   ├─ 乌云压顶/停顿线 + 股价在 MA30 上方 + 负面信号 → 减仓/离场提示
   └─ 正向形态 + 股价在均线下方 → 止跌回升提示（可加仓）
3. 输出风险提示清单 → 次日开盘执行减仓
```

### 3.3 ⚠️ 前视偏差检查

- 双底形态识别用的极点都是**历史已形成**的（A/B/C/D 都在 E 之前）→ T 日可见 ✅
- 做空形态（二/三日 K 线）形态完成后 T 日可见 ✅
- 执行在次日开盘，不能用当日收盘信号当日成交

## 六、绩效预期与可信度

### 6.1 双底形态原文绩效

## 七、失效红线

| 红线 | 表现 | 监控动作 |
|---|---|---|
| 🔴 **倒杯子实盘跑输** | 2009-2018 超额 −6.6%，2017 至今持续回撤 | **不作选股，仅作卖出提示** |
| 🔴 **双底震荡/熊市失效** | 双底是牛性持续形态，震荡/熊市胜率低 | 指数低位+连续上涨期再用 |
| 🔴 **停顿线单纯胜率<50%** | 48.77%，本组唯一 | **必须耦合 MA60（50.5%）或用 60 日口径（52.35%）** |
| 🔴 **形态学综合打分未落地** | 华创只作为展望，无具体加权公式 | 不要照搬"综合打分"，用单形态或聚合（22x）|
| 🟡 **双底长度禁区** | 31-34 周胜率仅 40% | 长度 >27 周剔除 |
| 🟡 **双底深度禁区** | 深度 >35% 胜率/收益差 | 深度 >35% 剔除 |
| 🟡 **倒杯子杯长非单调** | 19-20 周胜率<50%，21-25 周又回升 | 不能简单"越长越差" |
| 🟡 **做空形态 beta 为负** | 收益来自做空 alpha | 不能与多头选股绩效直接比 |
