## 一、策略定位

### 1.1 赚什么钱

**成分股聚合的钱**：形态学对短期（5 天）预测准，但中期预测不能只用指数本身形态。改为用 Wind 全A 成分股的形态信号聚合——当全市场看多形态比例显著高于看空形态比例时，指数大概率上涨。

> 📖 [华创 2023.5](../../../raw/articles/[202305220958]专题报告形态学研究之二如何利用形态信号进行市场择时.md)："形态学研究系统的**历史胜率统计时间为 5 天，对市场短期的走势预测较准**，但**如果想做市场中期的预测，则不能仅使用指数本身形态信号，需要另辟蹊径，见微知著**。"

**alpha 来源**：个股层形态信号 → 聚合到指数层。与单纯指数形态（[22b](22b-kline-pattern-selection.md)）正交。

### 1.2 在家族里的角色

| 策略 | 角色 | 信号类型 | 与本策略（22x）的关系 |
|---|---|---|---|
| 22b 形态选股 | 因子型（个股）| 单形态选股 | 22b 个股层，22x 聚合到指数 |
| **22x 形态剪刀差** | **成分股聚合（指数择时）**| 形态聚合 | — |
| 22y DTW | 序列相似性（指数）| 序列匹配 | 22x 单形态聚合，22y 序列相似 |

### 1.3 方法论血统（成熟方法论迁移）

> 📖 [华创 2023.5](../../../raw/articles/[202305220958]专题报告形态学研究之二如何利用形态信号进行市场择时.md)："通过指数成分股对指数进行未来走势的建模，我们已经在《涨跌停剪刀差择时系列》……四篇报告进行了充分的挖掘，本篇报告**沿用涨跌停模型的建模方式**。" "推波助澜 V3 模型是涨跌停择时系列中**最稳健**的模型。"

**血统**：形态剪刀差是华创"涨跌停剪刀差 V1/V2/V3"系列（涨停比率−跌停比率→连板比率剪刀差→V3 自由流通市值加权）在"个股 K 线形态信号"上的迁移。属经过多代迭代的成熟方法论。

### 1.4 不适合什么场景

- **追求低回撤**：原文最大回撤 40.3%，是高波动策略
- **形态识别平台缺失**：需华创 61 种形态识别能力（mark.hcquant.com）

## 二、信号逻辑

### 2.1 多空形态比率剪刀差算法

> 📖 [华创 2023.5](../../../raw/articles/[202305220958]专题报告形态学研究之二如何利用形态信号进行市场择时.md)："我们选择 Wind 全A 的成分股，计算每天**从形态学角度看多的个股数量与看空的个股数量，除以当天的 Wind 全A 成分股数量**，计算**看多形态比例与看空形态比例**。" "与涨跌停模型的推波助澜比率（涨停比率−跌停比率）类似，我们可以计算每天**多空比率的剪刀差，即多空形态比率剪刀差**。"

```
看多形态比例 = 形态看多个股数 ÷ Wind全A 成分股总数
看空形态比例 = 形态看空个股数 ÷ Wind全A 成分股总数
多空形态比率剪刀差 = 看多形态比例 − 看空形态比例
```

### 2.2 HMA 均线平滑

对该剪刀差做 **N=30 日 HMA 均线平滑**：

> 📖 [华创 2023.5](../../../raw/articles/[202305220958]专题报告形态学研究之二如何利用形态信号进行市场择时.md)："我们亦对多空形态比率剪刀差进行 **30 日均线**的 HMA 平滑……参数 N 等于 30。"

> ⚠️ **精读核对**：HMA 短期参数由 20 每隔 5 遍历至 40，"**平滑参数等于 30 仅仅是次优参数**"——N=30 是遍历 [20, 40] 步长 5 的**次优**（非最优），但"回测结果受制于短期参数影响较低"（参数高原宽）。

### 2.3 买卖规则

> 📖 [华创 2023.5](../../../raw/articles/[202305220958]专题报告形态学研究之二如何利用形态信号进行市场择时.md)："当多空形态比率剪刀差的 N 日 HMA 均线指标值**大于 0 的时候（此时市场大概率上涨），我们做多万得全A 指数，第二天开盘做多，否则空仓**。"

| 条件 | 动作 |
|---|---|
| HMA 平滑值 > 0 | 做多 Wind全A（T+1 开盘）|
| HMA 平滑值 ≤ 0 | 空仓 |

### 2.4 算法完整流程

假设今天是 2026-07-06：

```
步骤 1：取 Wind 全A 成分股清单
  └─ 例如 5000+ 只股票

步骤 2：对每只成分股识别当日形态信号
  ├─ 用华创 61 种 K 线形态识别
  ├─ 统计形态看多个股数（出现看多形态的）
  └─ 统计形态看空个股数（出现看空形态的）

步骤 3：算剪刀差
  ├─ 看多比例 = 看多个股数 / 成分股总数
  ├─ 看空比例 = 看空个股数 / 成分股总数
  └─ 剪刀差 = 看多比例 − 看空比例

步骤 4：HMA 平滑（N=30）
  └─ 对近 30 日剪刀差序列做 HMA 平滑，取今日平滑值

步骤 5：生成信号
  ├─ 平滑值 > 0 → 做多
  └─ 平滑值 ≤ 0 → 空仓

步骤 6：执行（T+1 开盘做多 / 空仓配固收）
```

## 三、选指数/择时规则

### 3.1 每日盘后例行流程

```
每日盘后：
1. 对 Wind 全A 全部成分股识别当日形态信号
2. 统计看多/看空个股数，算剪刀差
3. HMA(30) 平滑
4. 平滑值 > 0 做多，否则空仓
5. T+1 开盘执行，空仓期配固收
```

### 3.2 标的指数

- **Wind 全A**（主）：成分股最多，聚合信号最稳定

### 3.3 ⚠️ 前视偏差检查

- 成分股形态识别用 T 日收盘数据 → T 日可见 ✅
- HMA 平滑用滚动 30 日窗口 → T 日可见 ✅
- 执行 T+1 开盘

## 六、绩效预期与可信度

### 6.1 原文绩效（Wind全A 纯多头）

> 📖 [华创 2023.5](../../../raw/articles/[202305220958]专题报告形态学研究之二如何利用形态信号进行市场择时.md)："多空形态比率剪刀差择时模型的万得全A 历史回溯表现。**年化 20.05%**，**最大回撤 40.3%**，平均每年交易次数为 7.5 次，**夏普比率 0.876**，**胜率 53.1%**，**盈亏比 2.49**，平均看多持有周期为 25 个交易日。"

| 指标 | 数值 | 口径 |
|---|---|---|
| 年化 | **20.05%** | Wind全A 纯多头 |
| 最大回撤 | **40.3%** | ⚠️ 高波动 |
| 夏普 | 0.876 | — |
| 胜率 | 53.1% | — |
| 盈亏比 | 2.49 | — |
| 年交易次数 | 7.5 次 | 低频 |
| 多头持有 | 25 天 | 较长 |

> ⚠️ **回测区间原文未明确**——报告仅给"历史回溯表现"，未写起止日期。

> 💡 **相比涨跌停 V3 的优势**：形态剪刀差的"多头持有周期更长"（25 天 vs V3 中期模型更短）。

| 折扣因素 | 影响 | 应对 |
