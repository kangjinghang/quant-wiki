## 二、反转因子的方向约定（全家族统一，最容易翻车的地方）

### 2.1 反转因子是负向因子

A 股反转策略的 alpha 来源是"均值回归"——过去跌得多的未来会涨回来。所以**反转因子值越小（越负）→ 未来越看多**。

> 📖 [开源 2019.12](../../../raw/articles/[201912231258]A股反转之力的微观来源.md) 第三章："M_high 的 IC 为 **-0.046**，M_low 的 IC 为 **-0.019**，两个成分都呈现了反转特性"——注意 IC 都是**负**的。

### 2.2 全家族方向统一表

| 策略 | 因子 | 方向 | 选股逻辑 |
|---|---|---|---|
| 23a 理想反转 | M_high（单笔成交额高分位日涨幅）| **负向** | 因子越负（跌得越狠）→ 越看多 |
| 23b 锚定反转 | (P_T − P_anchor)/P_anchor | **负向** | 因子值越小（越靠近买入点）→ 越看多 |
| 23c 昼夜分离 | 0.4×\|隔夜\| + 0.6×日内 | **负向** | 因子越负 → 越看多 |
| 23d ERR | 极端收益率 + 前1分钟（排序相加）| **负向** | 因子越负 → 越看多 |
| 23e SNR | ln(σ_信号/σ_噪声) | **正向** ⚠️ | 信噪比越大 → 越看多（作乘数时方向跟随基础因子）|
| 23f 筹码收益 | holding_ret_enhanced | **正向**（择时后）| 浮盈月做动量、浮亏月做反转，合成后看多头端 |
| 23g UMR2.0 | 增强后三个月反转 | **负向** | 因子越负 → 越看多 |

> 💡 **方向翻车是反转策略的高发 bug**：如果你发现"选出来的全是前期大涨的股票"，那一定是方向搞反了。回测前用常识检查——多头组合应该是"前期跌得多的"。

### 2.3 SNR 的特殊处理（23e）

SNR 是**正向因子**（信噪比越大下月收益越高），但它作增强层时是**乘数**——乘到负向反转因子上，方向跟随基础因子，不改变方向。

> 📖 [华安 2020.7](../../../raw/articles/[202007241516]华安金工信息提纯寻找高质量反转因子市场微观结构剖析之八.md) 2.3 节："从 IC 符号，分组收益来看，该因子为正向因子，也即：股票的信噪比越大，股票的下个月收益越高。"

## 三、风格中性化层

### 3.1 反转因子要不要做风格中性化

| 反转因子类型 | 是否做风格中性化 | 原因 |
|---|---|---|
| **纯量价反转**（23a M_high / 23c 昼夜分离 / 23d ERR）| **可选** | 量价本身已含风格信息；中性化会损失部分 alpha |
| **行为金融反转**（23b 锚定反转）| **增强一时强制** | 剥离基本面，只留"情绪超跌"那部分 |
| **基本面增强反转**（23b 增强一）| **强制做** | 对 [市值/行业/FY1/BP] 做 OLS 取残差 |
| **筹码派生反转**（23f 筹码收益）| 可选 | 与其他 Barra 风格因子相关 ≤±10%，独立性已较好 |

### 3.2 中性化的精确做法（参考 02-shared §三）

对个股因子 $f$，在截面对风格变量做线性回归取残差：

$$f_{\text{neutralized}} = f - (\beta_0 + \sum_{i} \beta_i \cdot \text{Style}_i)$$

**反转策略常用的中性化变量**（按机构分）：

| 机构 | 中性化变量 | 来源 |
|---|---|---|
| 中银 2022（23b 增强一）| 对数自由流通市值 + 中信一级行业 + FY1 一致预期 + B/P | 📖 [中银 2022.9](../../../raw/articles/[202209042055]锚定反转因子构建与增强中银量化多因子选股系列三.md) §四 |
| 开源 2019/2022（23a）| 市值 + 行业 | 📖 [开源 2022.5](../../../raw/articles/[202205022118]理想反转因子的四年总结理想值得坚持么开源金工.md) §1.1 "因子做市值、行业中性化处理" |
| 开源 2022（23d）| 市值 + 行业 | 📖 [开源 2022.12](../../../raw/articles/[202212031735]日内极端收益前后的反转特性与因子构建开源金工.md) §01 |

**预处理**：截面填充缺失值、去极值（缩尾）后再回归。

### 3.3 中性化的效果（23d ERR 实例）

ERR 中性化前后对比（去掉市值/行业 + Barra 风格暴露）：

| 指标 | 中性化前 | 中性化后（纯净因子）|
|---|---|---|
| 多空年化 | 19.58% | 9.49% |
| IR | 3.01 | 1.88 |
| 胜率 | 81.90% | 68.57% |
| 最大回撤 | 5.71% | 4.84% |

> 📖 [开源 2022.12](../../../raw/articles/[202212031735]日内极端收益前后的反转特性与因子构建开源金工.md) §3.3："纯净新因子多空对冲的年化收益为 9.49%，信息比率为 1.88，胜率 68.57%，最大回撤 4.84%……该因子和流动性、波动性因子相关性较高。"

**含义**：ERR 的 alpha 里有相当部分来自流动性/波动率风格暴露。中性化后收益减半但更纯净。**叠加到多因子模型时必须中性化；独立跑反转策略可不中性化（吃满 alpha）**。

### 5.3 反转效应的持续性

反转效应持续数周（不是数天），所以：

- **月频**：持仓 1 个月，吃满反转周期 ✅
- **周频**：持仓 1 周，信号更敏感、换手更高，但 IR 更高（23f 实证）
- **日频**：❌ 反转不是高频效应，日频换手会吃掉 alpha

## 六、A 股只做多 + 负向剔除（全家族通用）

### 6.1 为什么不做空

A 股做空机制有限（融券难、成本高），反转策略**只做多 + 负向剔除**：

- **做多**：因子值最小（最负）的一组——前期跌得多的，赌反弹
- **负向剔除**：删掉因子值最大（前期涨太多）的股票——规避高位接盘

### 6.2 多头端的特殊问题（反转策略的痛点）

反转策略普遍存在"**空头端准、多头端钝**"的问题——跌多的会反弹（空头端准），但"涨不多"的未必会涨（多头端钝）。

> 📖 [开源 2025.4](../../../raw/articles/[202504181710]筹码结构视角下的动量反转融合开源金工.md) §01："从十分组月均超额来看，在短期涨幅较高分组中的股票未来表现相对更弱，而在短期涨幅较低分组中的股票则表现较为接近。该现象说明**反转因子在空头端区分表现较好，而多头端区分效果不佳**。"

**解法**：
1. **23f 筹码收益增强**——专治多头乏力（用筹码成本替换价格均线作锚）
2. **负向剔除 + 正向选股组合**（华泰机构调研 + 反转，见 §七组合潜力）——反转作过滤器，配合其他正向因子选股

### 6.3 多头拥挤度（23b 锚定反转特有）

> 📖 [中银 2022.9](../../../raw/articles/[202209042055]锚定反转因子构建与增强中银量化多因子选股系列三.md) §四："2016-2019 期间的因子多空超额依旧保持上行……多头走平的原因是**多头拥挤度较高**，侵蚀了多头的超额收益。"

**含义**：锚定反转多头端在 2016-2019 走平（不是失效，是被拥挤交易侵蚀）。监控多头拥挤度是该策略的红线之一。

## 七、增强层叠加框架（反转家族的核心优势）

### 7.1 三层增强（可叠加任意基础反转）

```
基础反转因子（23a/b/c/d 任一）
   │
   ├─ 增强层 1：风格中性化（量价反转可选）
   │   └─ 对 [市值/行业/FY1/BP] 做 OLS 取残差
   │   └─ 效果：提纯，剥离基本面/风格干扰
   │
   ├─ 增强层 2：23e SNR 质量增强（需 EMD）
   │   └─ SNR 作乘数乘到基础反转因子上
   │   └─ 效果：rankIC -0.068→-0.074，ICIR -2.270→-2.727，多头 7.83%→11.90%
   │
   └─ 增强层 3：23g UMR2.0 特殊时点增强（纯日线）
       └─ 特殊时点日权重从 +1 翻成 -1
       └─ 效果：ICIR -1.99→-3.66（接近翻倍），胜率 74%→87%
```

### 7.2 增强层的叠加顺序

**推荐叠加顺序**（从底到顶）：

1. **最底层**：基础反转因子（23a/b/c/d 任一）
2. **中层**：23g UMR2.0 特殊时点增强（重构因子，改变日期权重）
3. **上层**：23e SNR 质量增强（乘数，放大高信噪比股的因子值）
4. **最顶层**：风格中性化（OLS 取残差，最后做）

**为什么这个顺序**：
- UMR2.0 重构的是"日期权重"，必须在算因子值之前做（重构收益率序列）
- SNR 是乘数，在因子值算出来之后做
- 风格中性化是最后的提纯，避免被风格污染

### 7.3 增强层的适用范围

| 增强层 | 适用基础反转 | 数据需求 | 效果 |
|---|---|---|---|
| **23g UMR2.0** | 任意"过去 N 日累计收益"型（裸 Ret20 / 23a / 23b）| 日线 + 事件日历 | ICIR 接近翻倍 |
| **23e SNR** | 任意反转因子（23a/b/c/d）| 日内/分钟（EMD）| 多头收益 +50% |
| 风格中性化 | 任意（基本面增强强制）| 风格因子数据 | 提纯，叠加到多因子模型时必做 |

> 💡 **UMR2.0 是性价比最高的增强层**——纯日线、ICIR 接近翻倍、可叠加任意"累计收益"型反转。个人投资者最该补的增强。
