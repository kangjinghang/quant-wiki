# #23e 反转 · SNR 信息提纯（质量增强层）— 详细实现

> **定位**：本文是 [`23-reversal.md`](../../strategy-playbooks/23-reversal.md) 配方 E 的**策略详细实现**——介于 playbook 与代码之间的中间层。读完本文，任何人都能照着写出代码，但本文不陷入代码细节。
>
> **角色**：反转家族的**质量增强层**。用 EMD（经验模态分解）把价格拆成"信号（趋势）+ 噪音（震荡）"，用**信噪比 SNR 给反转打质量分**——噪音大的反转不可信，过滤掉。SNR 既能**独立选股**（IC 4.5%/ICIR 2.265），又能**增强任一基础反转因子**（让 rankIC/ICIR/多头收益全面提升）。
>
> **来源**：[📖 华安金工 2020.7《信息提纯寻找高质量反转因子》](../../../raw/articles/[202007241516]华安金工信息提纯寻找高质量反转因子市场微观结构剖析之八.md)。

## 一、策略定位

### 1.1 赚什么钱

**反转质量的高低取决于价格信噪比**：如果价格的噪声振幅非常大，意味着多空方向的不明确，这种情况下提供的反转是质量较低的。EMD 把价格拆成趋势（信号）+ 震荡（噪音），用信噪比 SNR 识别"真反转"（高信噪比）和"假反转"（低信噪比=噪音）。

**alpha 来源**：趋势性强、受到噪声扰动少的股票，下个月的表现更好。反转 + 高信噪比 = 真反转；反转 + 低信噪比 = 噪音，要剔除。

> 📖 [华安 2020.7](../../../raw/articles/[202007241516]华安金工信息提纯寻找高质量反转因子市场微观结构剖析之八.md) §3.2："如果**价格的噪声振幅非常大，意味着多空方向的不明确，这种情况下提供的反转是质量较低的**。"

### 1.2 在家族里的角色

| 策略 | 角色 | 数据门槛 | 与本策略（23e）的关系 |
|---|---|---|---|
| 23a 理想反转 | L2 主力 | 🔴 逐笔 | 23e 可增强 23a |
| 23b 锚定反转 | 日线入门 | ✅ 日线 | 23e 可增强 23b |
| 23c 昼夜分离 | 分钟K 最强 | 🔵 | 23e 可增强 23c |
| 23d ERR | 分钟K | 🔵 | 23e 可增强 23d |
| **23e SNR** | **质量增强层 + 独立 alpha** | ⚠️ EMD | 可叠加任意基础反转 |

**双重角色**：
1. **独立选股**：SNR 本身是正向因子（IC 4.5%/ICIR 2.265），与传统因子正交，可独立选股
2. **增强层**：SNR 作乘数，乘到任意基础反转因子上，让多头收益 +50%（7.83%→11.90%）

### 1.3 不适合什么场景

- **没有 EMD 工程能力**：需对价格序列做经验模态分解（工程量大，需 PyEMD 库）
- **追求简单实现**：EMD 分解较复杂，入门不建议从此开始
- **没有日内数据**：SNR 用日内价格序列做 EMD，纯日线效果会衰减

## 二、信号逻辑：SNR 因子怎么算

### 2.1 核心方法——EMD 分解 + SNR 定义

#### EMD 分解

> 📖 [华安 2020.7](../../../raw/articles/[202007241516]华安金工信息提纯寻找高质量反转因子市场微观结构剖析之八.md) §2.1："任意价格序列都是由若干个噪音函数（震荡部分）和一个信号函数（趋势部分）组成的……**P(t) = ΣIMF_i(t) + r(t)**"——EMD 把价格分解为多个本征模态函数 IMF 之和 + 残差趋势 r。

> 📖 [华安 2020.7](../../../raw/articles/[202007241516]华安金工信息提纯寻找高质量反转因子市场微观结构剖析之八.md) §2.1："其中 IMF_i(t) 被称为本征模函数，可以理解为价格序列分离出的各层**数据震荡**，r(t) 是价格序列的**整体趋势部分**，代表价格在一天内的总体走势。"

**层数**：实际分解至**二或三层**——

> 📖 [华安 2020.7](../../../raw/articles/[202007241516]华安金工信息提纯寻找高质量反转因子市场微观结构剖析之八.md) §2.1："对日内价格序列进行信噪分离时发现，当分解至**二或三层**时，信号序列平滑特性明显，能够接近地描述原始序列。"

#### SNR 定义

> 📖 [华安 2020.7](../../../raw/articles/[202007241516]华安金工信息提纯寻找高质量反转因子市场微观结构剖析之八.md) §2.1："将日内信噪比（Signal to Noise Ratio, SNR）定义为**信号序列的标准差与噪声序列标准差的比值的对数**。"

$$\text{SNR} = \ln\left(\frac{\sigma_{\text{信号}}}{\sigma_{\text{噪声}}}\right)$$

- $\sigma_{\text{信号}}$ = 趋势项 r(t) 的标准差
- $\sigma_{\text{噪声}}$ = 所有 IMF 之和（即原始序列减去趋势序列）的标准差

**剥离噪声特性**：

> 📖 [华安 2020.7](../../../raw/articles/[202007241516]华安金工信息提纯寻找高质量反转因子市场微观结构剖析之八.md) §2.1："将日内价格序列分离至第二或三层时，趋势表现出剥离噪声的特性且与原股价保持高相关。"

### 2.2 为什么提纯能增强反转（理论支撑）

> 📖 [华安 2020.7](../../../raw/articles/[202007241516]华安金工信息提纯寻找高质量反转因子市场微观结构剖析之八.md) §3.2："**反转因子多头端收益向信噪比高的股票倾斜**，即反转因子值小，信噪比高的股票下个月的预期收益较高（右上角分组），主要原因在于噪声含量高的股票提供的反转其实是无意义的，信号强的股票反转效果更强。"

**3×3 双排序验证**：把股票按"反转因子值"和"信噪比"双排序，发现"反转因子值小（看多）+ 信噪比高"的组合下月收益最高——即反转 + 高信噪比 = 真反转。

### 2.4 增强反转的构造方法

> 📖 [华安 2020.7](../../../raw/articles/[202007241516]华安金工信息提纯寻找高质量反转因子市场微观结构剖析之八.md) §3.3："改进的基本思路是**强化高信噪比股票的反转因子值**，即对于高信号趋势、低噪声扰动的股票，对其 20 日反转因子值给予更高的信噪比乘数。"

> 📖 [华安 2020.7](../../../raw/articles/[202007241516]华安金工信息提纯寻找高质量反转因子市场微观结构剖析之八.md) §3.3："在横截面上，对**信噪比因子归一标准化作为信噪比乘数**，然后对调整方向以及标准化后的反转因子加权。"

**算法**：

```
增强反转 = 基础反转因子 × SNR_乘数

其中：
├─ 基础反转因子：先调整方向（统一为负向）+ 标准化
└─ SNR_乘数：SNR 横截面归一标准化（0-1 之间）
```

**效果**：高信噪比股的反转信号被放大，低信噪比（噪音大）的被压低。

### 2.6 关键参数

> 📖 [华安 2020.7](../../../raw/articles/[202007241516]华安金工信息提纯寻找高质量反转因子市场微观结构剖析之八.md) §2.4："从天数来看，因子的计算以 **15~20 天最佳**，加权方式是**指数加权移动平均更好**，越靠近月末的日期价格表现，对下月的影响更大。"

**新 SNR 合成**：用 SNR_layer2 + SNR_layer3 加权合成——

> 📖 [华安 2020.7](../../../raw/articles/[202007241516]华安金工信息提纯寻找高质量反转因子市场微观结构剖析之八.md) §2.5："我们推测'合适的'信噪分离层数在二至三层之间，运用 SNR_layer2 和 SNR_layer3 合成新 SNR 因子，当股票日内价格波动较大时，剥离更多的噪声，因子值向 SNR_layer3 偏离……最后对二层、三层信噪比因子加权合成每只股票的新 SNR 因子。"（delta=5 时最优）

### 2.7 SNR 算法完整流程（增强层用法）

```
每月末盘后（需日内/分钟数据做 EMD）：

步骤 1：对每只股票过去 ~20 日价格序列做 EMD 分解
  ├─ 取日内价格序列（或日收盘价序列）
  ├─ EMD 分解 2-3 层，得 IMF_1, IMF_2, ... + 趋势项 r(t)
  └─ 信号 = r(t)；噪声 = ΣIMF_i

步骤 2：算 SNR
  └─ SNR = ln(σ_信号 / σ_噪声)

步骤 3：SNR 横截面归一标准化（0-1）作为乘数

步骤 4：增强基础反转因子
  ├─ 取基础反转因子（Ret20 / 23a M_high / 23b 锚定反转）
  ├─ 调整方向 + 标准化
  └─ 增强反转 = 基础反转因子 × SNR_乘数

步骤 5：用指数加权移动平均（EWMA）合成，窗口 15-20 日

步骤 6：按增强后反转因子排序选股
```

> 💡 **独立用法**：SNR 本身也能独立选股（IC 4.5%/ICIR 2.265）——按 SNR 从大到小排序，买信噪比高的（正向因子）。

## 三、选股规则（增强层用法）

### 3.1 每月末盘后例行流程

```
每月末盘后（需日内数据做 EMD）：
1. 对每只股票过去 ~20 日价格序列做 EMD 分解（2-3 层）
2. 算 SNR = ln(σ_信号/σ_噪声)，横截面归一化为乘数
3. 取你的基础反转因子（如 Ret20 / 23a / 23b / 23c / 23d）
4. 增强反转 = 基础反转因子 × SNR_乘数
5. 市值 + 行业中性化（可选）
6. 全市场按增强后因子排序
   ├─ 取因子最负（跌得最狠 + 高信噪比）的一组
   └─ ⚠️ 负向剔除
7. 输出候选清单 → 次月首个交易日开盘买入
```

### 3.2 硬过滤条件

| 过滤条件 | 阈值 | 作用 | 优先级 |
|---|---|---|---|
| 上市天数 | >180 天 | 砍新股 | **必加** |
| 日成交额 | >100 万 | 砍流动性极差股 | **必加** |
| ST/停牌 | 剔除 | — | **必加** |
| 涨跌停 | 剔除 | EMD 分解失真 | **必加** |

> 📖 [华安 2020.7](../../../raw/articles/[202007241516]华安金工信息提纯寻找高质量反转因子市场微观结构剖析之八.md) 回测说明："在全部 A 股中，剔除涨停、跌停、停牌、日成交额低于 100 万、上市不满 180 天的新股等特殊股票。"

### 3.3 ⚠️ 前视偏差检查

- **月末盘后**用当日及之前 ~20 日的数据算 SNR → **次月首日开盘**买入：无前视偏差
- EMD 分解用的价格序列必须是 T 日及之前的
- SNR 乘数用 T 日截面归一化，不能用未来数据

| 🟡 SNR 与 layer3 相关 | SNR_layer3 与换手/波动相关 -0.2 | 用新合成 SNR（layer2+layer3）|
