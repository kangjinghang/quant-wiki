# #23g 反转 · UMR2.0 特殊时点增强（通用增强层）— 详细实现

> **定位**：本文是 [`23-reversal.md`](../strategy-playbooks/23-reversal.md) 配方附（UMR2.0 特殊时点增强）的**策略详细实现**——介于 playbook 与代码之间的中间层。读完本文，任何人都能照着写出代码，但本文不陷入代码细节。
>
> **角色**：反转家族的**通用增强层（纯日线）**。把盈余公告次日、一字跌停日、反弹动量日等"特殊日"从反转里按动量处理——这些日子的收益本质是动量不是反转，混在反转里会造成回撤。可叠加在裸 Ret20 / 23a / 23b 任一之上，**只用日线 + 事件日历**，让 ICIR 接近翻倍。

## 一、策略定位

### 1.1 赚什么钱

**"高风险日反转、低风险日动量"在反转因子侧的落地**：同一个收益率序列里，高风险日（盈余公告次日、一字跌停日、反弹动量日）的收益本质是动量不是反转——传统反转把它们误当反转日，是回撤的微观成因。把特殊日的权重从 +1 翻成 -1（按动量处理），反转因子显著增强。

**alpha 来源**：风险溢价视角——高风险日获得的收益往往是承担风险带来的，源于投资者过度自信导致的价格反应过度（→反转）；但特殊时点的"高风险"其实是基本面动量捕捉/做空机制缺失/底部反弹，本质是动量。

> 📖 [东方 2023.7](../../raw/articles/[202307170758]专题研究UMR20风险溢价视角下的动量反转统一框架再升级.md) 核心观点："**高风险日获得的收益往往是承担风险带来的，其更多源于投资者过度自信导致的价格反应过度，因此未来更倾向于反转效应**，而低风险日获得的收益并不源于承担高风险，因此未来更偏向于动量效应。"

### 1.2 波动率十分组实证（理论根基）

> 📖 [东方 2023.7](../../raw/articles/[202307170758]专题研究UMR20风险溢价视角下的动量反转统一框架再升级.md) §1.1："波动率较高（第10组）的股票当月平均跑赢市场 **11%**……波动率较高的股票在下月平均跑输市场 **1.2%**。这一现象告诉我们高风险下能够获得高收益，但是这种高收益往往是通过承担高风险带来的，因而其难以持续且未来呈现出强反转的特征。"

**直觉**：高波动涨幅越大，下月反转越狠。这解释了为什么所有改进版反转（23a/c/d）的共同主线都是"把高反应/高情绪的那部分涨跌单独切出来"。

### 1.3 在家族里的角色

| 策略 | 角色 | 数据门槛 | 与本策略（23g）的关系 |
|---|---|---|---|
| 23a 理想反转 | L2 主力 | 🔴 逐笔 | 23g 可增强 23a |
| 23b 锚定反转 | 日线入门 | ✅ 日线 | 23g 可增强 23b |
| 23c 昼夜分离 | 分钟K | 🔵 | 23g 可增强 23c（若用累计收益形式）|
| 23d ERR | 分钟K | 🔵 | 23g 不适用（非累计收益形式）|
| 23e SNR 增强 | 质量增强层 | ⚠️ EMD | 与 23g 互补（噪音 vs 特殊时点）|
| **23g UMR2.0** | **通用增强层（纯日线）** | ✅ 日线 + 事件日历 | 可叠加任意"过去 N 日累计收益"型反转 |

**适用范围**：任意"过去 N 日累计收益"型反转（裸 Ret20 / 23a M_high / 23b 锚定反转）。不适用于非累计收益形式（如 23d ERR 的极端收益、23c 的昼夜分离合成）。

### 1.4 不适合什么场景

- **基础反转不是"累计收益"形式**：23d ERR（极端收益）、23c 昼夜分离（合成因子）不适用
- **没有事件日历**：盈余公告日需一致预期/财报日历
- **追求独立 alpha**：本策略是增强层，不独立选股（UMR 复合主体的动量产出归 07-动量）

## 二、信号逻辑：UMR2.0 特殊时点增强怎么算

### 2.1 核心逻辑——"特殊时点"是高风险日里的动量日

> 📖 [东方 2023.7](../../raw/articles/[202307170758]专题研究UMR20风险溢价视角下的动量反转统一框架再升级.md) §1.2.3："动量不一定都出现在低风险日，而反转也不一定都出现在高风险日，在一些特殊时点，例如**盈余公告日、一字跌停日、反弹动量日**当日的收益可能更偏动量。"

### 2.2 三种特殊时点的精确识别规则

#### (a) 盈余公告次日——按动量处理

> 📖 [东方 2023.7](../../raw/articles/[202307170758]专题研究UMR20风险溢价视角下的动量反转统一框架再升级.md) §1.2.3："重大事件日第二天市场往往会对于公司最新发生的基本面变化做出同向的响应，例如**盈余公告日第二天业绩好的公司往往伴随着股价大幅跳空高开、波动率提高、换手率放大等看似'高风险'的行为**，但是这种价格行为往往是在反映市场对公司基本面动量的捕捉。"

> 📖 [东方 2023.7](../../raw/articles/[202307170758]专题研究UMR20风险溢价视角下的动量反转统一框架再升级.md) §1.2.3："**盈余公告次日开盘跳空幅度越大的股票往往未来表现越好**，即表现出明显的动量效应。"

**为什么按动量**：业绩好公司大幅跳空高开"看似高风险，实为基本面动量捕捉"——该日收益应按**动量**处理，而非反转。

**识别规则**：原文未给出精确算法，需用财报日历标记"盈余公告日"，取次日。

> ⚠️ **三档实现路径**（盈余公告日历）：
> - **档 1（推荐起步）**：akshare `stock_yysj_em`（预约披露时间）+ 财报实际披露日——✅ 立即可用
> - **档 2（数据升级后）**：一致预期/付费财报日历——更准
> - **档 3（付费源）**：Wind/Choice 业绩公告日历——需付费

#### (b) 一字跌停日——按动量处理

> 📖 [东方 2023.7](../../raw/articles/[202307170758]专题研究UMR20风险溢价视角下的动量反转统一框架再升级.md) §1.2.3："**A 股缺少做空机制**，因此股价向上拉升更为容易，而向下寻底时往往效率较低……这种一字跌停和大幅下挫会表现为股票的高波动从而体现出'高风险'的特征，但是往往后续是倾向于延续这种下跌的**动量特征**而不是立即反转的状态。"

**为什么按动量**：A 股缺做空机制→下跌寻底效率低→一字跌停后未来 6 个交易日超额持续下挫（动量延续）。

**识别规则**：日线派生——开盘价 = 最高价 = 最低价 = 收盘价（且处于跌停状态）。

#### (c) 反弹动量日——按动量处理

> 📖 [东方 2023.7](../../raw/articles/[202307170758]专题研究UMR20风险溢价视角下的动量反转统一框架再升级.md) §1.2.3："我们在中证全指收盘价序列上取**下跌深度 -5%、反弹阈值 0.5%**作为标准来筛选时点动量信号，**平均每年触发 5 次信号**，我们将触发日标记为动量触发日。"

> 📖 [东方 2023.7](../../raw/articles/[202307170758]专题研究UMR20风险溢价视角下的动量反转统一框架再升级.md) §1.2.3："该日的收益虽然伴随着'高波动'，但是我们更倾向于认为当日的收益具有'**动量**'而非'反转'趋势。"

**识别规则**：
- 在中证全指收盘价序列上
- **下跌深度 -5%**（从近期高点下跌超 5%）
- **反弹阈值 0.5%**（当日反弹超 0.5%）
- 年均触发约 **5 次**

**为什么按动量**：底部反弹日当日反弹幅度对未来收益具显著动量预测作用。

### 2.3 增强操作——把特殊日的权重从 +1 翻成 -1

> 📖 [东方 2023.7](../../raw/articles/[202307170758]专题研究UMR20风险溢价视角下的动量反转统一框架再升级.md) §四："**正常日期权重为 1，而特殊时点日期的权重为 -1**，以此来计算特殊时点调整后的三个月反转因子。"

**算法**：

```
增强后反转因子 = Σ_{过去N日} (weight_d × r_d)

其中：
├─ 正常日 weight_d = +1（按反转处理：跌→看多）
└─ 特殊时点日 weight_d = -1（按动量处理：跌→看空，与反转相反）
```

**直觉**：特殊时点日的收益本质是动量，所以它的贡献方向应该和正常反转日相反——把权重翻成 -1，相当于"把那天的收益从反转扣出去，加到动量那侧"。

### 2.4 第二步——影响因素剥离（可选，进一步增强）

> 📖 [东方 2023.7](../../raw/articles/[202307170758]专题研究UMR20风险溢价视角下的动量反转统一框架再升级.md) §四："我们也可以将三个月反转因子对过去三个月内**日度超额为负的占比**也进行剥离来降低下跌过程对于因子的影响。"

**为什么剥离**：下跌过程（暴跌集中几天 vs 每天阴跌）会让区间跌幅相同的股票不可比——同样是 -20% 跌幅，"3 天暴跌"和"20 天阴跌"的反转含义不同。剥离"负超额占比"能剔除这种路径差异。

**方法**：对"过去 N 日日度超额收益为负的天数占比"做回归取残差。

> 📖 [东方 2023.7](../../raw/articles/[202307170758]专题研究UMR20风险溢价视角下的动量反转统一框架再升级.md) §1.2.4："为了使得因子收益更加稳健，我们在中性化时同时将因子对风险系数为负的天数占比和日度超额为负的天数占比进行剥离，即对下式回归取残差。"

### 2.5 UMR2.0 特殊时点增强算法完整流程

假设今天是月末（T 日），要算增强后的三个月反转因子：

```
步骤 1：取基础反转因子 = 过去 N 日（如 60 日/三个月）累计收益率
  └─ 基础反转 = Σ_{d=T-60}^{T} r_d（日度超额收益）

步骤 2：标记过去 N 日内的【特殊时点】
  ├─ 盈余公告次日：用财报日历标记
  ├─ 一字跌停日：日线派生（开=高=低=收且跌停）
  └─ 反弹动量触发日：中证全指下跌深度 -5%、反弹阈值 0.5%

步骤 3：重构反转因子（权重翻转）
  ├─ 正常日 weight_d = +1
  └─ 特殊时点日 weight_d = -1
  └─ 增强反转_step1 = Σ (weight_d × r_d)

步骤 4（可选第二步）：影响因素剥离
  ├─ 算"过去 N 日日度超额为负的占比" neg_ratio
  └─ 对 neg_ratio 做回归取残差 → 增强反转_step2

步骤 5：全市场按增强后反转因子排序，买因子最负（跌得最狠）的一组
```

> 💡 **方向**：增强后因子仍是负向因子——因子越负 → 越看多。特殊时点日权重翻成 -1 后，那些"假反转"（实际是动量）的日子贡献被反向计算，不再拖累因子。

## 三、选股规则（增强层用法）

### 3.1 每月末盘后例行流程

```
每月末盘后（只需日线 + 事件日历）：
1. 取基础反转因子（裸 Ret60 / 23a M_high / 23b 锚定反转）
2. 标记过去 N 日内的特殊时点：
   ├─ 盈余公告次日（财报日历）
   ├─ 一字跌停日（日线派生）
   └─ 反弹动量触发日（中证全指 -5% 下跌深度 + 0.5% 反弹阈值，年均 ~5 次）
3. 重构反转因子：正常日权重 +1，特殊时点日权重 -1
4. 可选第二步：对"过去 N 日负超额占比"做回归剥离
5. 全市场按增强后因子排序
   ├─ 取因子最负（跌得最狠，且剔除了特殊时点干扰）的一组
   └─ ⚠️ 负向剔除
6. 输出候选清单 → 次月首个交易日开盘买入
```

### 3.2 硬过滤条件

| 过滤条件 | 阈值 | 作用 | 优先级 |
|---|---|---|---|
| 上市天数 | >90 天（3 个月）| 砍新股 | **必加** |
| ST 标记 | 剔除（ST 摘帽 3 个月内也剔除）| 砍退市风险 | **必加** |
| 停牌 | 剔除 | 无法交易 | **必加** |

> 📖 [东方 2023.7](../../raw/articles/[202307170758]专题研究UMR20风险溢价视角下的动量反转统一框架再升级.md) §二："全市场股票剔除上市未满 3 个月的新股、ST、ST 摘帽 3 个月以内的股票。"

### 3.3 ⚠️ 前视偏差检查

- **月末盘后**用当日及之前 N 日的数据算因子 → **次月首日开盘**买入：无前视偏差
- 特殊时点标记用 T 日及之前的，不能用未来事件
- 反弹动量触发日标记用 T 日及之前的中证全指数据
- 盈余公告次日：必须用已公告的（T 日已披露的财报），不能用未公告的

| 折扣因素 | 影响 | 应对 |
|---|---|---|
| **盈余公告日历可得性** | 需事件日历 | akshare 预约披露 + 财报日 |
| **未计涨跌停** | -1~2% | 涨停买不进、跌停卖不出 |
| **反弹动量触发参数** | -5%/0.5% 可能随市场结构变化 | 定期回测参数敏感性 |

**预期实战绩效**：增强后 ICIR 约 -2.5 到 -3（而非 -3.66），胜率约 80-83%（而非 87%）。仍显著强于原始反转（-1.99）。

## 八、升级路径

```
23g UMR2.0 特殊时点增强（本策略，通用增强层）
   │
   ├─ 用法：叠加到任意"过去 N 日累计收益"型反转上
   │   ├─ 增强 裸 Ret60（三个月反转）→ ICIR -1.99→-3.66
   │   ├─ 增强 23a 理想反转（对 20 日收益）
   │   └─ 增强 23b 锚定反转
   │
   ↓ 与其他增强层叠加（最强组合）
   │
   23e SNR 信息提纯（质量增强层）
   └─ 与 23g 互补：23g 处理特殊时点，23e 过滤噪音
   └─ 叠加顺序：基础反转 → 23g（重构日期权重）→ 23e（乘数）→ 风格中性化
   │
   ↓ 互补叠加（不同 alpha 路径）
   │
   23f 筹码收益增强（日线最新，专治多头乏力）
   └─ 23g 增强反转 + 23f 筹码视角，多头端双修复
```

> 💡 **性价比最高的增强层**：23g 是纯日线、ICIR 接近翻倍、可叠加任意累计收益型反转——个人投资者最该补的增强。
