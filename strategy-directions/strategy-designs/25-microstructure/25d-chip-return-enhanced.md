# #25d 微观结构 · 筹码收益增强因子 — 详细实现

> **定位**：本文是 [`25-microstructure-price-volume.md`](../../strategy-playbooks/25-microstructure-price-volume.md) 配方 C 的**筹码子策略详细实现**。把每日成交均价作为持仓成本、按换手率滚动累积估筹码分布，再用**赚钱效应择时**回答"反转何时失效"——浮亏月做反转、浮盈月做动量。日线派生（零额外数据），多空 36.6%。
>
> **角色**：日频族的**筹码视角主力**。与 25c 的 CGO 同源（都估持仓成本），但创新在**赚钱效应择时**——动态切换动量/反转。
>
> **来源**：📖 [开源金工 2025.4《筹码结构视角下的动量反转融合》](../../../raw/articles/[202504181710]筹码结构视角下的动量反转融合开源金工.md)。

## 一、策略定位

### 1.1 赚什么钱

**筹码收益增强**：估算全市场投资者的平均浮盈浮亏（筹码收益），用**市场赚钱效应**做择时切换：

- **浮亏态**（市场筹码收益 < -2%，占 62.5% 月份）：投资者受前景理论/处置效应驱动，过度反应 → 做**反转**（买浮亏深的、卖浮盈的）
- **浮盈态**（市场筹码收益 > -2%，占 37.5% 月份）：投资者受过度自信/确认偏误驱动，risk-on → 做**动量**（买浮盈的）

**alpha 来源**：行为金融的**条件性反转/动量**——不是固定反转或固定动量，而是根据市场状态切换。这回答了 [23 反转] 方向的核心问题："反转何时失效？"

> 📖 [开源 2025.4](../../../raw/articles/[202504181710]筹码结构视角下的动量反转融合开源金工.md)："当市场赚钱效应较好时，投资者会由于'过度自信'与'确认偏误'……市场风险偏好提升(risk-on)，进而产生惯性上涨的动量效应。而当市场赚钱效应较差时，投资者会由于'前景理论'与'处置效应'……市场风险偏好降低(risk-off)，进而变为自我修正的反转效应。"

### 1.2 在家族里的角色

| 策略 | 角色 | 与本策略（25d）的关系 |
|---|---|---|
| 25a 加速换手 | 情绪反转 | 25d 的反转段与 25a 同源 |
| 25b 主力杠杆 | 资金流方向 | 25d 的筹码是"成本分布"，25b 是"资金方向" |
| 25c CGO 低频 | 浮亏反转 | CGO 是 25d 的"浮亏"组件（无择时）|
| **25d 筹码收益增强** | **条件性反转/动量** | — |

### 1.3 不适合什么场景

- **追求固定方向**：本策略方向会切换（动量/反转），需接受状态依赖
- **周频换手不可承受**：周频多空 60% 但年化单边换手 8.14 倍
- **大盘股为主**：沪深300 月频多空 24.2%，远弱于中证1000（52.3%）

## 二、信号逻辑

### 2.1 筹码分布估算（日线派生）

#### 核心假设

> 📖 [开源 2025.4](../../../raw/articles/[202504181710]筹码结构视角下的动量反转融合开源金工.md)："我们可以采用强假设'**全部历史筹码均会以当天换手率进行均匀交易**'来简化近似计算筹码结构。相应地，我们将**每日的成交均价作为该成交量的持仓成本**，通过每日滚动累积即可算出不同持仓价格下对应存量筹码分布。"

#### 回溯期

> 📖 [开源 2025.4](../../../raw/articles/[202504181710]筹码结构视角下的动量反转融合开源金工.md)："对于 **250 日**以前的成交量，由于换手逐步衰减我们暂且忽略不计。"——"回溯期参数在 **60 日~500 日**区间内变化连续，因子对回溯期参数的**敏感性较低**。"

**回溯期 250 日最优**，60-500 日敏感性低。

#### 筹码收益因子

估算出筹码分布后，算"按筹码分布加权的平均持仓成本"，再与现价对比，得**筹码收益因子 holding_ret**（刻画个股投资者的平均浮盈浮亏）。

### 2.2 赚钱效应择时（灵魂机制）

#### 市场赚钱效应代理

> 📖 [开源 2025.4](../../../raw/articles/[202504181710]筹码结构视角下的动量反转融合开源金工.md)："为了刻画市场赚钱效应，我们将**全市场股票的筹码收益因子加权计算均值**作为 A 股的市场筹码收益(mkt_holding_ret)。"

市场筹码收益加权均值 = 赚钱效应代理。

#### 切分阈值 -2%

> 📖 [开源 2025.4](../../../raw/articles/[202504181710]筹码结构视角下的动量反转融合开源金工.md)："当切分阈值为 **-2%** 时，市场做动量效应占比为 **37.5%**。"

> 📖 [开源 2025.4](../../../raw/articles/[202504181710]筹码结构视角下的动量反转融合开源金工.md)："由于 A 股赚钱效应长期处于浮亏状态，我们仅对 **18.8%** 的月份下做筹码收益动量，其余月份下做筹码收益的反转。"（阈值=0 时）

| 阈值 | 动量占比 | 反转占比 |
|---|---|---|
| 阈值=0 | 18.8% | 81.2% |
| **阈值=-2%** | **37.5%** | **62.5%** |

⚠️ 阈值不是 0，是 **-2%**（放宽动量段占比）。

#### 行为金融解释

> 📖 [开源 2025.4](../../../raw/articles/[202504181710]筹码结构视角下的动量反转融合开源金工.md)："当市场赚钱效应较好时，投资者会由于'**过度自信**'与'**确认偏误**'(上涨解读为'基本面被验证'，强化买入信心)，市场风险偏好提升(risk-on)，进而产生惯性上涨的**动量**效应。而当市场赚钱效应较差时，投资者会由于'**前景理论**'与'**处置效应**'(潜在损失的厌恶远大于相同金额的收益，过早卖出盈利股票而持有亏损股票)，市场风险偏好降低(risk-off)，进而变为自我修正的**反转**效应。"

### 2.3 筹码收益增强因子（最终合成）

#### 合成方法

> 📖 [开源 2025.4](../../../raw/articles/[202504181710]筹码结构视角下的动量反转融合开源金工.md)："我们将**筹码收益调整因子的多头端与反转因子的空头端进行合成**，构建筹码收益增强因子(holding_ret_enhanced)。"

**把"筹码收益调整因子（条件性动量/反转）的多头端"与"反转因子的空头端"合成**。因为两者相关 -15%，互补。

> 📖 [开源 2025.4](../../../raw/articles/[202504181710]筹码结构视角下的动量反转融合开源金工.md)："从之前 Barra 风格因子相关性分析可知，筹码收益因子与反转因子相关性 **-0.153**，两个因子能够有效互补。"

#### 条件性切换逻辑

```
每月末：
  if mkt_holding_ret > -2%:  # 浮盈态（37.5% 月份）
      用筹码收益做动量（买浮盈的）
  else:                      # 浮亏态（62.5% 月份）
      用筹码收益做反转（买浮亏深的）
```

### 2.4 算法完整流程（以 2026-06 月末为例）

```
步骤 1：估筹码分布（每只股票）
  ├─ 取过去 250 交易日的每日成交均价 + 换手率
  ├─ 成交均价作为该日成交量的持仓成本
  ├─ 按换手率衰减加权（250 日外的忽略）
  └─ 得筹码分布 → 加权平均持仓成本

步骤 2：算个股筹码收益
  └─ holding_ret_i = (现价_i - 加权持仓成本_i) / 加权持仓成本_i

步骤 3：算市场赚钱效应
  └─ mkt_holding_ret = 全市场 holding_ret_i 加权均值

步骤 4：择时切换
  ├─ if mkt_holding_ret > -2%:  # 浮盈态
  │     筹码收益做动量（holding_ret 大→买）
  └─ else:                      # 浮亏态
        筹码收益做反转（holding_ret 小→买）

步骤 5：与反转因子合成
  ├─ 筹码收益调整因子的多头端
  └─ + 反转因子的空头端（两者相关-15%互补）

步骤 6：前视偏差检查
  └─ 确认 250 日成交均价/换手率在月末可见 ✅
```

## 三、选股规则

### 3.1 每月/周末盘后例行流程

```
每月/周末盘后（仅用日成交均价 + 换手率）：
1. 估筹码分布（回溯 250 日）
2. 算个股筹码收益 holding_ret
3. 算市场赚钱效应 mkt_holding_ret（全市场加权均值）
4. 按 mkt_holding_ret 是否 > -2% 切换动量/反转
5. 与反转因子合成（多头端+空头端）
6. 全市场排序，取前 10%（或前 50）
7. 输出候选清单 → 次月/周首个交易日开盘买入
```

### 3.2 硬过滤条件

| 过滤条件 | 阈值 | 作用 |
|---|---|---|
| 上市天数 | >250 日 | 筹码分布需足够回溯期 |
| ST/停牌 | 剔除 | 流动性 |
| 股票池 | 小盘域优先（中证1000/国证2000）| 大盘弱 |

### 3.3 ⚠️ 前视偏差检查

- 成交均价/换手率：T+1 才能拉到（Wind 盘后更新）
- 250 日回溯：严格用 t-1 到 t-250
- 调仓信号：月末盘后生成，**次月首个交易日开盘执行**
