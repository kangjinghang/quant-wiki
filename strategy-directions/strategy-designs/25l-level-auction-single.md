## 二、信号逻辑

### 2.1 档位突破（广发）

#### 因子构造

> 📖 [广发 2024.9 档位](../../raw/articles/[202409161007]广发金工2024精选深度报告系列之十档位突破因子.md)："本报告尝试基于 **Level2 快照数据**，利用更深的订单簿数据挖掘 Alpha 因子。""Level2 的快照数据以约 3 秒为间隔对个股的日内成交情况及**十档挂单状况**做存储。""通过记录每次击穿(档位突破)信号的**类型(买或卖)与深度(击穿档位数)**，并以**日度层面全天的击穿信号平均水平**作为因子值。"

#### 提纯方法

> 📖 [广发 2024.9 档位](../../raw/articles/[202409161007]广发金工2024精选深度报告系列之十档位突破因子.md)："为了提纯因子信息，我们尝试**从档位突破因子中剥离收益率影响**。"

#### 绩效

> 📖 [广发 2024.9 档位](../../raw/articles/[202409161007]广发金工2024精选深度报告系列之十档位突破因子.md)："提纯'档位突破'因子中证1000 内月度选股 IC 2.9%，年化 ICIR 2.1，IC 胜率 79%……**多头组费后相对中证1000 年化超额 8.3%，信息比率 1.5**。""回测区间：2017.01.03 - 2024.06.28。"

#### 周度 ICIR 更高但费后≈月度

> 📖 [广发 2024.9 档位](../../raw/articles/[202409161007]广发金工2024精选深度报告系列之十档位突破因子.md)："分调仓周期看，**周度选股的 ICIR 较月度更高**，但受换手提升的影响，**交易成本的损耗使得周度多头未较月度有明显提高**。"——月度多头费后 8.3%/IR1.5；周度 8.4%/IR1.53。

#### 负面发现

> 📖 [广发 2024.9 档位](../../raw/articles/[202409161007]广发金工2024精选深度报告系列之十档位突破因子.md)："**'档位突破'因子及强度因子具有较显著的 IC**，其中'档位突破'因子的多头表现更优……**波动因子则未呈现出明显的选股能力**。""由于均值保留了因子的原始内涵，下文中我们以'档位突破'因子指代均值因子。"

- 标准差（波动）口径失效，只有均值口径有效
- 强度因子（均值/标准差）多头不如均值

#### 与日度收益相关性约 20%

> 📖 [广发 2024.9 档位](../../raw/articles/[202409161007]广发金工2024精选深度报告系列之十档位突破因子.md)："从结果看，不同域内**时序相关性均在 20% 左右**。""档位突破较收益率具有额外信息。"

### 2.4 算法完整流程

```
每月盘后（需 L2 快照 + 竞价逐笔 + 逐笔成交）：
1. 档位突破：
   ├─ 记录大额主动单击穿十档的类型+深度
   ├─ 取日度全天击穿信号均值
   └─ 回归剥离收益率（提纯）
2. 集合竞价：
   ├─ 09:15-09:25 成交买单（RankIC -10.10%）
   ├─ 09:15-09:20 撤单买单（多头超额 11.88%）
   └─ 14:57-15:00 收盘竞价卖单（RankIC -9.60%，尾盘抛压）
3. 单笔成交金额：
   ├─ 算 QUA（分位数）/ MTS / MTE / SR 四子因子
   └─ 合成（强小市值偏好）
4. 三族合成选股 → T+1 开盘买入
```

## 三、选股规则

### 3.1 每月盘后例行流程

```
每月盘后（需 L2 多类数据）：
1. 算三族因子（按 §二 流程）
2. 全市场排序：
   ├─ 档位突破（提纯后）：中证1000 多头超额 8.3%
   ├─ 集合竞价：开盘撤单多头 / 收盘卖单空头
   └─ 单笔金额 QUA：负向，取前 10%
3. 合成选股 → 次月首个交易日开盘买入
```

### 3.2 硬过滤条件

| 过滤条件 | 阈值 | 作用 |
|---|---|---|
| 股票池 | **中证1000**（档位/单笔）/ 全市场（竞价）| 单笔沪深300仅1.13% |
| L2 权限 | 已开（快照+竞价+成交）| 必需 |

### 3.3 ⚠️ 前视偏差检查

- L2 数据：当日 15:00 收盘后才能完整获取
- 调仓信号：月末盘后生成，**次月首个交易日开盘执行**
