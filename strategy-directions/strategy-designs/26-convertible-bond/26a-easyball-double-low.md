# #26a 可转债 · 双低 / EasyBall — 详细实现

> **定位**：本文是 [`26-convertible-bond.md`](../../strategy-playbooks/26-convertible-bond.md) 配方 A 的**策略详细实现**——介于 playbook 与代码之间的中间层。读完本文，任何人都能照着写出代码，但本文不陷入代码细节。
>
> **角色**：可转债家族的**入门验证版**。只用"价格+溢价率"双排名，全市场取前 50%。目标不是收益最大化，而是**用最小复杂度验证双低逻辑在你手里是否有效**——验证通过后再升级到 26b 多因子 / 26x 分层多因子。

## 一、策略定位

### 1.1 赚什么钱

**双低 alpha**：同时筛"低价"（债底保护，跌有限）+ "低溢价率"（正股弹性，涨跟足）。低价与低溢价各自都是正收益因子，相关系数约 −0.6（负相关），两者排名合成即 EasyBall。

> 📖 [中金固收 2020.6《转债也能做因子模型吗》](../../../raw/articles/[202006071736]中金固收可转债转债也能做因子模型吗附简易Python框架20200607.md)："溢价率因子和价格因子都有持续负收益（反过来低价、低溢价就有正收益），相关系数为负且并不绝对（**-0.6左右**）。那么，'2 * 价格分位数倒序 + 溢价率分位数倒序'会有怎样的效果呢？……所以，**easy ball 不是偶然，也不难提出来**。"

**alpha 来源**：
1. 低价：跌时有债底托底（下行有限）
2. 低溢价率：涨时紧贴正股（上行充分），且"差的正股不会到低溢价"（被动选股效果）

### 1.2 这个策略在可转债家族里的角色

| 策略 | 角色 | 复杂度 | 与本策略（26a）的关系 |
|---|---|---|---|
| **26a 双低 EasyBall** | **入门验证** | 低 | — |
| 26b 转债多因子 | 主力实盘 | 中 | 26a 的价格+溢价是 26b 多因子的两个 |
| 26c 下修博弈 | 机会型事件 | 高 | 与 26a 正交，可叠加 |
| 26d 4 大类组合 | 组合管理 | 中 | 26a 是均衡型分支的代表 |
| 26e 估值择时 | 时机信号 | 中 | 给 26a 加减仓 |
| 26x 分层多因子 | 进阶主力 | 高 | 26a 升级版（按股债性分域）|
| 26y 资金流增强 | 增强信号 | 中 | 叠加 26a 提升选券 |

### 1.3 不适合什么场景

- **追求收益最大化**：双低是均衡型，进攻性弱于纯低溢价（进攻型），需升级到 26b/26x
- **资金量大、要求高容量**：双低（尤其严苛版）出勤率低、容量小
- **2018 年前的回测**：行业因子 2018 前不可靠，样本不足

## 二、信号逻辑：EasyBall 怎么算

### 2.1 精确定义（双排名法，中金 2022.8 可运行代码）

> 📖 [中金固收 2022.8《转债量化策略框架2.0》](../../../raw/articles/[202208141421]中金转债量化策略框架20与Python实现.md)："针对每只个券计算：1.其**价格在全体转债中的排名**（从小到大）记做 RankClose；2.其**溢价率在全体转债中的排名**（从小到大）记做 RankPrem；3.将两者**加总**记做 TR，并在每一个换仓日**取 TR 靠前的 50%** 品种。"

（代码即 `data.Close.rank() + data.ConvPrem.rank()`，取 `quantile(0.5)` 以下）

### 2.2 算法完整流程

```
每月末/双周末盘后：
1. 拉全市场转债：价格、转股溢价率（来自 26-shared 数据层）
2. 经样本池剔除（见 §三，剔除双高/小余额/低评级/退市风险等）
3. 算双排名：
   ├─ RankClose = 价格在全市场样本中的排名（从小到大，1=最便宜，pct=True）
   ├─ RankPrem  = 转股溢价率在全市场样本中的排名（从小到大，1=溢价最低，pct=True）
   └─ TR = RankClose + RankPrem（等权双排名）
4. 取 TR 靠前的 50%（即 TR ≤ quantile(0.5)）
   ⚠️ "更低≠更好"，50% 即可，不要盲目取前 30%
5. 等权持仓，月频/双周频调仓
6. ⚠️ 避开 100 元以下破发券（瑕疵券比例高）
7. 公告强赎的券剔除（减少损失，但对低溢价策略效果有限）
```

### 2.3 为什么用等权双排名而非 2:1 加权

早期探索式为"2×价格分位+1×溢价分位"（价格更主导），但：

> 📖 [中金固收 2020.6](../../../raw/articles/[202006071736]中金固收可转债转债也能做因子模型吗附简易Python框架20200607.md)：原探索式是"2 * 价格分位数倒序 + 溢价率分位数倒序"。

中金 2022.8 框架2.0 的可运行代码**简化为等权双排名**（`Close.rank() + ConvPrem.rank()`）——实证下等权与 2:1 效果接近，且更通用。**落地统一用等权双排名法**。

### 2.4 走一个具体例子

假设 2026-07-31 盘后，全市场经剔除后剩 400 只转债：

```
例：A 转债 价格 108 元、溢价率 15%
步骤 1：RankClose = 108 元在 400 只中的分位（假设第 120 名）→ pct = 0.30
步骤 2：RankPrem = 15% 在 400 只中的分位（假设第 100 名）→ pct = 0.25
步骤 3：TR = 0.30 + 0.25 = 0.55
步骤 4：若 TR 50% 分位线 ≈ 1.0（即两排名都靠中间），A 的 0.55 < 1.0 → 入选
```

等权持有所有 TR ≤ 分位线的券，下月初第一交易日开盘建仓。

## 三、选券规则

### 3.1 每月盘后例行流程

```
每月末盘后：
1. 拉全市场转债数据（26-shared 数据层）：
   ├─ 价格、转股溢价率
   ├─ 余额、评级、剩余期限、上市天数
   └─ 正股价、市值（退市风险检查）

2. 样本池剔除（26-shared §四，7 条红线）：
   ├─ 上市≤10 交易日
   ├─ 双高（换手>100% 且 价>130 且 溢价>30%，同时满足）
   ├─ 余额<2 亿
   ├─ 评级<A+
   ├─ 近 10 日均量后 10%
   ├─ 剩余期限<3 个月
   └─ 退市风险（正股价<1 元 或 市值<3 亿 或 N(d3)<0.95）

3. 算双排名 TR = RankClose + RankPrem
4. 取 TR ≤ quantile(0.5)
5. ⚠️ 额外剔除：100 元以下破发券（"低价"非单调）
6. 公告强赎券剔除
7. 等权持仓 → 目标清单
```

### 3.2 硬过滤条件（阈值表）

| 过滤条件 | 阈值 | 作用 | 优先级 |
|---|---|---|---|
| 样本池 7 条 | 见 26-shared §四 | 流动性/信用/退市防护 | **必加** |
| **100 元以下破发券** | 价格 <100 剔除 | 瑕疵券比例高，效果适得其反 | **必加** |
| 公告强赎 | 已公告强赎剔除 | 减少损失 | **必加** |
| 严苛版双低（可选）| 价<120 **且** 溢价<15% | 提升质量，降出勤率/容量 | 可选 |

### 3.3 ⚠️ 前视偏差检查

- 价格、溢价率用**当日收盘**数据，次日开盘建仓——无前视
- 样本池剔除用当日已知信息（上市天数/余额/评级均无前视）
- 退市风险 N(d3) 用历史波动率，无前视
- ⚠️ 条款触发计数：若用到下修/强赎进度，确保用 T-1 及之前的数据

## 四、调仓与持仓

### 4.1 建仓时点

**T+1 开盘买入**（T = 月末信号生成日）。

> 📖 [开源 2022.2 分层](../../../raw/articles/[202202122142]量体裁衣可转债的分层组合方法开源金工.md) §3.1："下月初第一个交易日，按照开盘价等权建仓"。

### 4.2 调仓频率与时点

| 频率 | 推荐场景 | 依据 |
|---|---|---|
| **月频**（推荐起步）| 默认 | 中金 2020/2022 测试口径 |
| 双周频 | 追求时效 | 东方 2023.9 分类型口径 |
| 42 交易日（≈2 月）| 股债性漂移匹配 | 中金框架2.0 建议 |

**推荐**：**月末盘后信号 → 次月首个交易日开盘调仓**。

### 4.3 持仓方式

**等权持仓**。持仓数量：

| 方式 | 持仓数 | 适用场景 |
|---|---|---|
| 比例法 | TR 前 50%（约 100-200 只，看样本量）| 默认，容量大 |
| 严苛版 | 价<120 且 溢价<15%（约 30-60 只）| 追求质量，容量小 |

### 4.4 费用

**双边千 1.5-千 3**（买+卖各千 0.75-1.5）。

> ⚠️ **重要折扣**：中金 2020.11 的年化 ~23% 绩效**未计交易费用**——实战需打折。

## 六、绩效预期与可信度

### 6.1 原文绩效（中金 2020.11，均衡型综合排名前 40%）

> 📖 [中金固收 2020.11《转债策略库及测试》](../../../raw/articles/[202011221425]中金固收可转债是时候选出更好的策略了转债策略库及测试20201122.md) §3 均衡型："限定价位与溢价率的**综合排名至 40%**（对于现在的转债市场来说，也有**100余个样本**）时，**年化收益接近 23%**，基本与纯进攻型策略在侵略性处于同一档次，而 **12.81% 的年化波动、12.64% 的最大回撤**与等权组合也相差无几。"

| 指标 | 均衡型（综合排名前 40%）|
|---|---|
| 年化收益 | **接近 23%** |
| 年化波动率 | 12.81% |
| 最大回撤 | 12.64% |
| 回测期 | 2017 年转债扩容以来 |

**口径标注**：原文为均衡型（综合排名前 40%）口径，回测期 2017 起，**未计交易费用与涨跌停限制**。

### 6.2 东北框架的独立验证（2024.8）

> 📖 [东北固收 2024.8《可转债研究框架》](../../../raw/articles/[202408271502]东北固收可转债研究框架从理论概念到实战策略.md) §4.2："双低策略表现最佳，夏普比率达 **1.26**，但当前其所展现的有效性正在减弱。低估值策略夏普比率1.04，在各技术性策略中仅次于双低策略。"

### 6.3 个人投资者降级预期

原文绩效直接搬到个人投资者手上要打折：

| 折扣因素 | 影响 | 应对 |
|---|---|---|
| **未计交易费用** | −1~2% | 双边千 1.5-3 + 冲击成本 |
| **未计涨跌停** | −0.5~1% | 涨停买不进、跌停卖不出 |
| **出勤率/容量** | 严苛版容量小 | 大资金用前 50% 而非严苛版 |
| **数据时延** | 错过最早信号 | akshare T+0 盘后即可拉到 |
| **退市新规（2024 起）** | 双低选到低价瑕疵券概率升 | 强制 N(d3) + 信用排雷 |

**预期实战绩效**：原文的 **7-8 折**（即年化 16-18% 而非 23%）。双低本身是攻守兼备的稳健策略，夏普最稳，是入门首选。

### 6.4 进攻型（低溢价率）的对比（理解逻辑，非本策略）

> 📖 [中金固收 2020.11](../../../raw/articles/[202011221425]中金固收可转债是时候选出更好的策略了转债策略库及测试20201122.md) §2 进攻型："进攻型策略是样本内收益上最优秀的策略……**最低 23% 的年化收益率**，不仅在转债策略中拔群，甚至好过了这些年的主动股票型基金"；"低溢价不仅从定义上保证了进攻性，**也有一定的被动选股效果——差的正股，不会到低溢价甚至负溢价的地步**"。

进攻型收益更高但回撤显著高于均衡型（20%+），卡玛仍可接受。**入门选双低（均衡型），追求弹性可叠加低溢价**。

## 七、失效红线

| 红线 | 表现 | 监控动作 |
|---|---|---|
| 🔴 **退市新规**（2024 起）| 双低选到低价瑕疵券/退市券（蓝盾/鸿达先例）| N(d3) 修正 + 信用排雷 + 硬剔除 |
| 🔴 **双低有效性减弱** | 东北 2024.8 指出"当前有效性正在减弱" | 拥挤度监控；升级到 26b/26x 多因子 |
| 🔴 **低价券信用风险扩散** | 2020 末起信用问题，低价策略降波动不降回撤 | 信用排雷；偏债破解版（见 26d）|
| 🟡 **高波动最高档失效** | 120 日波动率最高档"极盛而衰"（前 4 档才遵循高波→高回报）| 波动率五分组监控，剔最高档 |
| 🟡 **大盘品种负超额** | "少买大盘、不买偏债"有 alpha | 小盘倾斜（但注意流动性）|
| 🟡 **百元溢价率过高**（>26%）| 转债整体偏贵，双低也难逃系统回撤 | 叠加 26e 择时减仓 |

## 八、升级路径

```
26a 双低 EasyBall（本策略）
   │
   ├─ 验证双低逻辑在你手里是否有效
   │   └─ 有效（年化 >15%）→ 继续
   │   └─ 无效 → 检查数据/退市防护；仍无效 → 升级到 26b/26x
   │
   ↓ 升级（加因子）
   │
26b 转债多因子（主力）
   ├─ 加债底溢价率、转债存量市值、动量、正股基本面
   ├─ WLS 回归处理异方差
   └─ 对标绩效：开源 9 因子年化 34.6%/超额 26.1%
   │
   ↓ 升级（按股债性分域）
   │
26x 分类型/分层多因子（进阶主力）
   ├─ 按 ±20% 划分偏股/平衡/偏债
   ├─ 各域用不同有效因子
   └─ 对标绩效：开源分层年化 29%/回撤 7%
   │
   ↓ 互补叠加（任意阶段都可加）
   │
26c 下修博弈（事件驱动，与双低正交）
26e 估值择时（给双低加减仓信号）
26y 资金流增强（小单净流出叠加双低）
   └─ 三者都是增强信号，叠加提升选券质量
```
