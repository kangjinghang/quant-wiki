## 一、策略定位

### 1.1 赚什么钱

**债基研究的核心难点是信息披露有限**——财报仅公布前五大重仓券，且占比通常仅 20%-30%，难以直接通过持仓洞见季度配置。中银量化的破解法：不依赖持仓穿透，而是从**利润表 + 所有者权益变动表**拆出债基收益的真实来源，推测其策略，评估其能力。

> 📖 [中银深度一](../../raw/articles/[202107160936]中银债基研究深度一债基收益来源的拆解方法.md)："信息披露有限是债券基金研究的核心难点。债基重仓券公开信息量较少，财报仅公布前五大重仓券，且前五大重仓券占比较低（通常 **20%-30%**），难以直接通过其持仓洞见季度节点个券配置情况。"

**本文做什么**：
- **B-1 四效应拆解**：把债基净值收益率拆成杠杆/分红/流动性/投资管理四效应（公开财报可得）
- **B-2 策略推测**：判定债基是波段操作还是票息策略（同业排名分位数）
- **B-3 风格评估**：用十年国债免费锚划牛熊区间，评估四维能力，选"确定优秀"

### 1.2 在家族里的角色

| 策略 | 角色 | 与本策略（29b）的关系 |
|---|---|---|
| **29b 债基拆解** | **债基读懂** | — |
| 29c 债基排雷 | 债基风控 | **29b 读懂能力 + 29c 排除踩雷 = 完整债基优选** |
| 29a 股基增强 | 股基主力 | 不同对象（股基 vs 债基）|
| 29d/29e | 转债/固收+ | 不同对象 |

### 1.3 不适合什么场景

- **追求组合绩效数字**：本文是方法论（识别能力），原文无组合收益绩效
- **转债基金**：转债仓位 >30% 的债基归入 29d（CL 模型）
- **重仓券穿透**：本文明确**不依赖持仓穿透**，只看利润表+净值

## 二、信号逻辑

### 2.1 全流程总览

```
半年频（半年报/年报披露后，3 月末 / 8 月末）：
  B-1 四效应拆解：用利润表 + 所有者权益变动表算四效应（16 分项）
      ↓
  B-2 策略推测：
      ├─ 先按转债仓位分类（15%/30% 阈值）
      ├─ 波段策略：债券价差收入同业排名分位数（利率债>10% + 前 40%）
      └─ 票息策略：利息收入排名 + 杠杆率 / 重仓券信用等级
      ↓
  B-3 风格评估：
      ├─ 划十年国债牛熊区间（>1 年趋势）
      ├─ 四维能力（杠杆/久期/信用/转债）排名分位数
      └─ 选"确定优秀"（排名持续靠前）
```

### 2.2 B-1：四效应拆解（核心，公开财报可得）

#### 为什么必须用四效应拆解而非传统"收入构成法"

传统"收入构成法"只看利润表"总收入"分项占比，**会误读**——大额申赎会扭曲。

> 📖 [中银深度一](../../raw/articles/[202107160936]中银债基研究深度一债基收益来源的拆解方法.md)：某纯债基 2016 下半年"净利润 **2825.99 万** 但单位净值收益率 **-0.97%**"——原因是巨额净赎回（份额只剩中报的 50%）扭曲。"收入构成法未能考虑大额申赎对基金经理流动性管理能力的考验。"

**实证案例**：净利润为正但净值收益为负，原因是市场大幅波动引发大额赎回，份额大幅波动对净值产生不利影响。

#### 16 分项完整框架

> 📖 [中银深度一](../../raw/articles/[202107160936]中银债基研究深度一债基收益来源的拆解方法.md)："主要分为杠杆效应、流动性管理效应、分红效应、利息收入、股息收入、债券价差收入、股票价差收入、公允值变动、其他收入、管理人报酬、销售服务费用、交易费用、利息成本共 **16 个部分**。"

| 类别 | 分项 | 含义/公式 |
|---|---|---|
| **四大效应** | 杠杆效应 | 见 §2.2 公式 |
| | 流动性管理效应 | 残差（见 §2.2）|
| | 分红效应（利润分配效应）| 见 §2.2 公式（⚠️ **派现影响，非票息**）|
| | 投资管理效应 | 见 §2.2 公式（≈ROE）|
| **收入端明细** | 利息收入 | 票息能力 |
| | 股息收入 | 股票分红能力 |
| | 债券价差收入 | 债券波段操作能力 |
| | 股票价差收入 | 股票买卖能力 |
| | 公允价值变动 | ⚠️ **弃用**（不披露资产明细，改用投资收益）|
| | 其他收入 | 杂项 |
| **成本端明细** | 管理人报酬 | 管理费 |
| | 销售服务费 | 获客成本（支付销售机构佣金）|
| | 交易费用 | 换手率代理（**波段交叉验证**）|
| | 利息成本 | 融资费用（与杠杆相关）|

#### 四效应精确公式

> 📖 [中银深度一](../../raw/articles/[202107160936]中银债基研究深度一债基收益来源的拆解方法.md) §三.2：

**① 投资管理效应**（核心，≈ROE）：

$$\text{投资管理效应} = \frac{\text{基金报告期净利润}}{\text{报告期平均净资产}}$$

> "该指标即为基金财报中'3.1 主要会计数据与财务指标'中的'**本期加权平均净值利润率**'，本质类似 **ROE** 的概念。"

💡 **可直接从财报读取**——无需自行复杂计算，读"本期加权平均净值利润率"即可（再除以报告期平均净资产）。

**② 杠杆效应**：

$$\text{杠杆效应} = \text{净值收益率} - \frac{\text{净值收益率}}{\text{区间平均杠杆率}}$$

其中：

$$\text{杠杆率} = \frac{\text{总资产}}{\text{净资产}} \quad ; \quad \text{平均杠杆率} = \text{mean}(\text{报告期内可得时点杠杆率})$$

> "平均杠杆率根据报告期内可获得的有限'**时点杠杆率**'进行**简单平均值估算**。"

**③ 分红效应（利润分配效应）**——⚠️ 关键修正：

$$\text{分红效应} = \frac{\text{本期向持有人分配利润产生的净值变动}}{\text{报告期平均资金占用}}$$

⚠️ **分红效应是"分红派现对净值的影响"，不是"持券票息"**——票息属于"利息收入"分项。

> 📖 [中银深度一](../../raw/articles/[202107160936]中银债基研究深度一债基收益来源的拆解方法.md) §三.2："根据季报'6.3 所有者权益（基金净值）变动表'，根据'**本期向基金份额持有人分配利润产生的基金净值变动 / 报告期平均资金占用**'来估算。"

**④ 流动性管理效应**（残差）：

$$\text{流动性管理效应} = \text{净值收益率} - \text{杠杆效应} - \text{投资管理效应} - \text{分红效应}$$

#### 同一基金多收费模式（A/B/C 类）需捏合

> 📖 [中银深度一](../../raw/articles/[202107160936]中银债基研究深度一债基收益来源的拆解方法.md) §三.2："同一基金经常存在不同收费模式（如 XXX 基金 A/B，XXX 基金 C）。这类基金在公布财报时，**其利润表的数据仅反映的是不同收费模式基金的利润汇总**。因此我们需要把不同收费模式基金的'**净值收益率**'和'**本期加权平均净值利润率**'进行**捏合**。"

### 2.3 B-2：推测债基策略（波段 vs 票息两路径）

#### 第一步：按转债仓位分类

> 📖 [中银深度二](../../raw/articles/[202107252039]中银债基专题二手把手教你推测债基的投资策略.md)："当转债的仓位高于 **15%** 时，其收益特征会对该基金产品产生一定影响，当转债仓位超过 **30%** 时，转债的收益可主导该基金产品的收益风格特征。"

| 转债仓位 | 处理 |
|---|---|
| <15% | 纯债基（本文研究对象）|
| 15%-30% | 转债有影响但非主导，单独评估 |
| **>30%** | **转债主导，归入 29d（CL 模型）** |

#### 第二步：判定策略路径（为什么用同业排名分位数）

> 📖 [中银深度二](../../raw/articles/[202107252039]中银债基专题二手把手教你推测债基的投资策略.md)："在特定的市场环境下，'不适合（或非常适合）波段操作'可能是公募基金经理的**共识**，故该分项的**绝对收益贡献值较难稳定**地衡量'偏好与能力'。而采用**同业排名**的方式可在一定程度上规避上述'市场不确定性'的扰动。"

**含义**：2018 年利率单边下行时所有债基都适合波段，绝对收益无法区分能力；同业排名才能识别"相对同业做得好"。

#### 两条策略路径判定法

> 📖 [中银深度二](../../raw/articles/[202107252039]中银债基专题二手把手教你推测债基的投资策略.md) §二：

| 策略 | 判定法 | 关键阈值 |
|---|---|---|
| **波段操作-利率债** | 看"债券价差收入"分项的**同业排名分位数** | 利率债占比 **>10%** 且价差收入排名**前 40%**；交叉验证：交易费用相对高 |
| **波段操作-信用债** | 同上 + 观察"前五大重仓券信用等级是否下降"区分子类 | 信用等级下降=下沉波段；稳定高等级=高等级波段 |
| **票息策略-高杠杆** | "利息收入"分项同业排名靠前 + 杠杆率高 | 利息收入排名靠前 + **杠杆率高** |
| **票息策略-信用下沉** | "利息收入"分项同业排名靠前 + 前五大重仓券平均信用等级较低 | 利息收入排名靠前 + **重仓券信用等级低** |

**交易费用交叉验证**（仅辅助）：

> 📖 [中银深度二](../../raw/articles/[202107252039]中银债基专题二手把手教你推测债基的投资策略.md)："由于波段操作策略的交易频率普遍偏高，我们还可以通过观察'**交易费用**'项的相对大小来对波段操作策略进行**交叉验证**……交易费用仅可用于交叉验证而无法作为判断波段操作的主要指标。"

#### 为什么弃用"公允价值变动"改用"投资收益"

> 📖 [中银深度二](../../raw/articles/[202107252039]中银债基专题二手把手教你推测债基的投资策略.md) §一.(二)："债基财报披露的'基金公允价值变动'项目……但基金财报**并不披露各资产在该项的贡献明细**……但是在'**投资收益**'项目中，财报会公布**各类资产的收益（亏损）明细**。"

**结论**：公允价值变动是各类资产浮盈浮亏之和，财报不披露明细，无法归因；改用投资收益（按资产类别披露明细）。

### 2.4 B-3：风格评估（十年国债免费锚 + 四维能力）

#### 总框架：先划利率牛熊区间，再判断操作对错

> 📖 [中银深度三](../../raw/articles/[202108051734]债基策略与风格划分与评估实证框架中银债基深度研究三.md)："在'较难拆解债基配置明细'的情况下，'**十年国债利率**'可作为一个近似有效的锚来代替各类债券的表现（不包含转债）。"

**牛熊划分规则**：

> 📖 [中银深度三](../../raw/articles/[202108051734]债基策略与风格划分与评估实证框架中银债基深度研究三.md)："将十年国债到期收益率划分为利率上升与利率下降区间，并找到利率拐点。通常情况下债券投资一般**仅会关注持续一年以上的利率上行/下行趋势**。"

| 区间 | 含义 | 债基应该的操作 |
|---|---|---|
| 利率下行（债市牛市）| 十年国债收益率趋势性下行 ≥1 年 | **加杠杆 + 拉长久期 + 信用下沉** |
| 利率上行（债市熊市）| 十年国债收益率趋势性上行 ≥1 年 | 降杠杆 + 缩短久期 + 提升信用等级 |

#### 四维能力评估

> 📖 [中银深度三](../../raw/articles/[202108051734]债基策略与风格划分与评估实证框架中银债基深度研究三.md) §二：

**① 杠杆能力**：

> "在利率下行（债市牛市）时及时提高杠杆增大收益，在利率上行时降低杠杆减少损失。"区分重点在于杠杆操作是否"**及时且正确**"（看利率拐点前后是否调整 + "杠杆效应"分项排名分位数）。

**② 利率与久期能力**：

> "在利率下行区间正确增配利率债并拉长久期；上行区间减配并缩短久期。"

**关键近似法**（因前五大重仓券难细分券种）：

> "我们统一用**基金披露的前 5 大重仓券的持有规模加权平均久期**来近似替代各类债券的久期变动"；"部分未上市但已进入前五大重仓券的债券，用其**上市日期时的久期**替代计算。"

**利率债口径**：国债 + 央票 + 政策性银行债。

**③ 信用能力**：

> "在'信用利差'扩大时，基金经理能不能及时提升信用债的仓位并进行有效的信用下沉，在'信用利差'收窄时能否及时降低信用债仓位并提升整体的信用等级。"

**④ 转债能力**：

> "通过测算基金可转债配置比例与可转债指数（**8841324.WI**）的走势情况"综合判断。

#### "两个确定与一个不确定"选基原则

> 📖 [中银深度三](../../raw/articles/[202108051734]债基策略与风格划分与评估实证框架中银债基深度研究三.md) §二："① 若基金在该项的排名**持续靠前**（**确定优秀**）；② 若该项收益的排名**持续靠后**（**确定不佳**）；③ 若该类收益的排名**波动很大**（**不确定**）……从优选基金角度，我们推荐直接考虑'**确定优秀**'的候选基金。"

| 类别 | 判据 | 结论 |
|---|---|---|
| **确定优秀** | 排名持续靠前 | **优选** |
| 确定不佳 | 排名持续靠后 | 规避 |
| 不确定 | 排名波动大 | 观望 |

### 2.5 信用压力测试（免费版，乐观/悲观情景）

> 📖 [中银深度三](../../raw/articles/[202108051734]债基策略与风格划分与评估实证框架中银债基深度研究三.md) §二.(三).2/4："**'乐观情景'** 的个券评级为各评级机构给出的有效评级中**最高评级**；**'悲观情景'** 为各机构有效评级的**最低评级**。"

| 情景 | 定义 |
|---|---|
| 乐观情景 | 各评级机构有效评级中**最高** |
| 悲观情景 | 各评级机构有效评级中**最低** |

**判读**：

> 📖 [中银深度三](../../raw/articles/[202108051734]债基策略与风格划分与评估实证框架中银债基深度研究三.md) §二.(三).4："若两者没有差距：代表基金平均信用等级较为可靠；若两者出现了较大的差异：代表基金产品所持有的债券中存在一部分处于'**灰色地带**'的债券……出现了一定程度的信用下沉。"

**信用评级清洗口径**：

> 📖 [中银深度三](../../raw/articles/[202108051734]债基策略与风格划分与评估实证框架中银债基深度研究三.md) §二.(三).1/2：

| 清洗项 | 规则 |
|---|---|
| 中债资信 | **剔除**（买方评级，属性差异大）|
| 穆迪/惠誉/标普 | **转换**为国内评级体系（仅有主体评级）|
| 评级有效期 | **1 年**（超期无效）|
| 多家评级 | 全保留（用于乐观/悲观压力测试）|
| 无评级券 | 计算时**忽略**（仅计算有有效评级的）|

### 2.6 算法完整流程（以某纯债基 2026 年半年报为例）

```
输入：某纯债基金 2026 年半年报（利润表 + 所有者权益变动表 + 前五大重仓券）

步骤 B-1 四效应拆解：
  ├─ 读取"本期加权平均净值利润率" → 投资管理效应（≈ROE）
  ├─ 算杠杆率 = 总资产/净资产（半年内各时点简单平均）→ 杠杆效应
  ├─ 从所有者权益变动表读"分红致净值变动" → 分红效应
  └─ 流动性管理效应 = 净值收益率 − 杠杆 − 投资管理 − 分红（残差）

步骤 B-2 策略推测：
  ├─ 检查转债仓位：<15% 继续（纯债基）；>30% 归入 29d
  ├─ 看债券价差收入同业排名分位数：
  │   ├─ 利率债占比 >10% 且价差前 40% → 波段操作-利率债（交叉验证交易费用高）
  │   └─ 前五大重仓券信用等级下降 → 波段操作-信用债（下沉波段）
  └─ 看利息收入同业排名分位数：
      ├─ 排名靠前 + 杠杆率高 → 票息-高杠杆
      └─ 排名靠前 + 重仓券信用等级低 → 票息-信用下沉

步骤 B-3 风格评估：
  ├─ 划十年国债牛熊区间（>1 年趋势）
  │   └─ 例：2024-2026 若利率下行 → 债市牛市
  ├─ 四维能力排名分位数：
  │   ├─ 杠杆能力：利率拐点前后是否加杠杆 + 杠杆效应排名
  │   ├─ 久期能力：前五大重仓券规模加权平均久期是否拉长
  │   ├─ 信用能力：信用利差扩大时是否下沉
  │   └─ 转债能力：转债仓位 vs 8841324.WI
  └─ 看排名是否"持续靠前" → "确定优秀" → 优选

⚠️ 前视检查：2026 半年报数据，必须等到 2026-08-31 才能用
```

## 三、选基规则

### 3.1 半年频例行流程（3 月末 / 8 月末）

```
半年末盘后（3 月末 / 8 月末，半年报/年报披露后）：
1. 对每只纯债基金（转债仓位<15%）：
   ├─ B-1 四效应拆解（读利润表 + 所有者权益变动表）
   ├─ B-2 策略推测（同业排名分位数）
   └─ B-3 四维能力评估（十年国债牛熊 + 排名分位数）

2. 按策略类型分组（波段-利率债/波段-信用债/票息-高杠杆/票息-信用下沉）
   └─ 每组内按四维能力排名

3. 筛"确定优秀"（排名持续靠前）→ 优选池

4. 配合 29c 排雷：从优选池剔除第 20 组（高风险）→ 最终选基
```

### 3.2 硬过滤条件（阈值表）

## 六、绩效预期与可信度

### 6.1 原文绩效（方法论，无组合数字）

⚠️ 本文是**方法论（识别能力）**，原文无组合收益绩效。B-1/B-2/B-3 的产出是"对每只债基的能力评估标签"，不是组合收益。

**可对标的指标**：
- 四效应拆解的准确性（用净利润 vs 净值收益率的对应关系验证）
- 策略推测的区分度（同业排名分位数的单调性）
- 风格评估的预测力（"确定优秀"基金后续表现）

### 6.2 个人投资者降级预期

本文是方法论，直接可用，无需打折。但需注意：

| 折扣因素 | 影响 | 应对 |
|---|---|---|
| 财报字段不完整 | 部分基金"本期加权平均净值利润率"缺失 | 缺失基金剔除或用净利润/平均净资产自算 |
| 评级覆盖不全 | 部分重仓券无公开评级 | 无评级券忽略（仅算有评级的）|
| 前五大重仓券代表性 | 仅占 20-30%，久期近似有偏差 | 近似法已是最优解（原文方法）|

### 6.3 信用压力测试的有效性

## 七、失效红线

| 红线 | 表现 | 监控动作 |
|---|---|---|
| 🔴 **大额申赎扭曲** | 净利润为正但净值收益为负（份额大幅波动）| 必须用四效应拆解，不能用收入构成法 |
| 🔴 **分红效应误读** | 把分红效应当票息 | ⚠️ 分红效应是派现影响，票息是利息收入分项 |
| 🔴 **公允价值变动弃用** | 用公允价值变动归因 | 改用投资收益（按资产明细披露）|
| 🔴 **同业排名共识扰动** | 绝对收益无法区分能力 | 用同业排名分位数 |
| 🟡 **信用评级阶段性失效** | AAA 级债券不违约现象首次被打破 | 配合 29c 排雷（净值联动）|
| 🟡 **风格漂移** | 基金经理换人/策略切换 | 半年频重新评估 |
| 🟡 **转债仓位变动** | 转债仓位跨过 30% 阈值 | 重新归类（归 29d）|
