# #29d 基金优选 · 转债基金 CL 模型归因 — 详细实现

> **定位**：本文是 [`29-fund-selection-fof.md`](../strategy-playbooks/29-fund-selection-fof.md) 配方 C 的**策略详细实现**——介于 playbook 与代码之间的中间层。读完本文，任何人都能照着写出代码，但本文不陷入代码细节。

> **角色**：基金优选家族的**转债基金能力评估工具**。用 CL 模型（类似 HM 模型）把转债基金收益拆成"下跌段/上涨段"两个 beta，判读其择时/择券能力。

## 一、策略定位

### 1.1 赚什么钱

**识别转债基金的择时/择券能力**——用 CL 模型把转债基金收益拆成下跌段（min）和上涨段（max）两个 beta，各配一个 beta 系数，判读基金经理在不同市场状态下的实际表现。

> 📖 [中金 2019.7](../../raw/articles/[201907291729]中金固收可转债转债基金择时择券能力如何区分及Python实现方法2019.md)："实际这个式子没有比 CAPM 复杂很多，只是把 Rm - Rf 再拆分成'下跌'和'上涨'两种状态，分别对应 beta1 和 beta2 两个敏感系数。"

⚠️ **本文是纯方法论**——中金原文是"程序实现方法"专题，无基金优选结论绩效（具体基金的择时择券排名在该系列配套的"转债周报"中，不在本篇）。

### 1.2 在家族里的角色

| 策略 | 角色 | 与本策略（29d）的关系 |
|---|---|---|
| 29b 债基拆解 | 债基读懂 | 29b 把转债仓位 >30% 的债基归入 29d |
| **29d 转债 CL 模型** | **转债能力评估** | — |
| 29e 固收+风格 | 固收+识别 | 29e 的转债基金类可用 29d 归因 |

### 1.3 不适合什么场景

- **测真实仓位**：CL 模型是归因模型，不是测仓位手段（beta 是"有效仓位"概念）
- **追求组合绩效**：本文无基金优选结论绩效
- **纯债基金**：纯债基金归 29b/29c

## 二、信号逻辑

### 2.1 CL 模型精确公式

> 📖 [中金 2019.7](../../raw/articles/[201907291729]中金固收可转债转债基金择时择券能力如何区分及Python实现方法2019.md)：

$$R_p - R_f = \alpha + \beta_1 \times \min(R_m - R_f, 0) + \beta_2 \times \max(R_m - R_f, 0) + e$$

| 变量 | 含义 | 取值 |
|---|---|---|
| $R_p$ | 基金收益率 | 基金日频净值收益率 |
| $R_f$ | 无风险/基准债收益率 | **长债基金指数 885008.WI**（不拿转债/股票的长债基金）|
| $R_m$ | 市场基准 | **转债指数 000832.CSI** |
| $\alpha$ | 截距项 | 手动加一列全 1 的 Ones 列（fit_intercept=False）|
| $\beta_1$ | 下跌段敏感系数 | 对应 min(Rm−Rf, 0) |
| $\beta_2$ | 上涨段敏感系数 | 对应 max(Rm−Rf, 0) |
| $e$ | 残差 | — |

> 📖 [中金 2019.7](../../raw/articles/[201907291729]中金固收可转债转债基金择时择券能力如何区分及Python实现方法2019.md)："Rf 怎么选一直是个问题……实际还是基金倾向于拿哪一类当'债'，哪一类就更合适……所以有一个还算稳定的方法是：用**不拿转债/股票的长债基金收益率**。"

### 2.2 择时/择券判读标准（核心打分依据）

> 📖 [中金 2019.7](../../raw/articles/[201907291729]中金固收可转债转债基金择时择券能力如何区分及Python实现方法2019.md)：

| 指标 | 含义 | 原文原话 |
|---|---|---|
| **alpha 显著大于 0** | 择券能力 | "alpha 显著大于 0，则可以认为是有择券效果" |
| **beta2 − beta1 较大**（且 beta2>0）| 择时能力 | "beta2 - beta1 比较大，说明基金能在上涨和下跌阶段，体现出不同的 beta 值来" |
| **beta2 很大、beta1 ≈ 0** | 精准逃顶 | "最理想的情况莫过于 beta2 很大，beta1 接近 0——这就是一般情况下说的精准逃顶了" |

### 2.3 ⚠️ 重要定性（归因模型，非测仓位手段）

> 📖 [中金 2019.7](../../raw/articles/[201907291729]中金固收可转债转债基金择时择券能力如何区分及Python实现方法2019.md)："这始终是个**归因模型，不是测仓位手段**，所以无论 beta1 还是 beta2 都与'仓位'这个概念有差异。无论如何，这里讨论的是实际效果，或者'**有效仓位**'的概念——不必纠结于实际仓位是多少。"

**含义**：beta 是"有效仓位"（满仓不同转债实际效果不同），不是真实仓位。勿把 beta 当仓位用。

### 2.4 局限

> 📖 [中金 2019.7](../../raw/articles/[201907291729]中金固收可转债转债基金择时择券能力如何区分及Python实现方法2019.md)：

| 局限 | 原文 |
|---|---|
| **alpha 和 beta 无法完全分离** | "alpha 和 beta 仍然不能完全被拆分开，比如有的品种就是拥有超大的 Beta 值（券商转债、周期转债、低溢价银行转债）" |
| **转债品种股性不同** | "尤其转债还存在不同品种股性完全不同的、以及 Gamma 大小差异很大的问题" |
| **择时择券难兼顾** | "择时和择券，两者兼顾很难很难" |

### 2.5 实操易错点

> 📖 [中金 2019.7](../../raw/articles/[201907291729]中金固收可转债转债基金择时择券能力如何区分及Python实现方法2019.md)："以下几点应当注意"：

**易错点 ①**：单看某一个数值容易出错

> "单看某一个数值总是容易出错，比如 beta2 - beta1 从数据上代表了择时能力，但**也要结合仓位和基金规模大小来看**。"

**易错点 ②**：alpha 也要结合 beta2 评判

> "alpha 也要注意结合 beta2 来评判，**25 分 45% 命中率，和 5 分 60% 命中率相比，还是前者更强一些**。"

**含义**：alpha 高 + beta2 高才更可靠；孤立看 alpha 易误判。

### 2.6 算法完整流程（以某转债基金 2024-2026 年为例）

```
输入：某转债基金 2024.1.1-2026.8.31 日频净值 + 转债指数 + 长债基金指数

步骤 1：准备数据
  ├─ 基金调整后净值（adjnav）→ 日收益率 Rp
  ├─ 转债指数（000832.CSI）收盘价 → 日收益率 Rm
  └─ 长债基金指数（885008.WI）收盘价 → 日收益率 Rf

步骤 2：构造回归变量
  ├─ x = Rm − Rf（转债超额收益）
  ├─ x1 = min(x, 0)（下跌段）
  ├─ x2 = max(x, 0)（上涨段）
  └─ ⚠️ 收益率放大 100 倍（×100）做回归

步骤 3：CL 回归
  ├─ 因变量：Rp − Rf（逐基金减去 Rf），×100
  ├─ 自变量：[Ones(全1), x1×100, x2×100]
  └─ sklearn LinearRegression(fit_intercept=False)
     → 输出 coef_ = [alpha, beta1, beta2]

步骤 4：判读
  ├─ alpha > 0 显著 → 择券能力
  ├─ beta2 − beta1 大（且 beta2>0）→ 择时能力
  └─ beta2 大、beta1≈0 → 精准逃顶

步骤 5：综合评判（结合仓位 + 规模）
  └─ alpha 高 + beta2 高 → 可靠的择时择券能力
```

## 三、选基规则

### 3.1 例行流程

```
按需（评估转债基金时）：
1. 取转债基金清单（转债仓位 >30%，归自 29b 分类）
2. 对每只转债基金，用过去 N 个月（建议 12-24 个月）净值做 CL 回归
3. 输出三维 [alpha, beta1, beta2]
4. 判读：
   ├─ 择券能力：alpha 显著 > 0
   ├─ 择时能力：beta2 − beta1 大（且 beta2>0）
   └─ 精准逃顶：beta2 大、beta1≈0
5. 综合评判：alpha 高 + beta2 高 → 优选
```

### 3.2 ⚠️ 前视偏差检查

CL 模型用日频净值 + 指数，无前视偏差风险（都是当日收盘数据）。但需注意：
- 基金净值 T+1 公布，回归时用 T 日数据需等 T+1
- 转债指数/长债基金指数当日收盘可得

## 七、失效红线

| 红线 | 表现 | 监控动作 |
|---|---|---|
| 🔴 **alpha/beta 不可完全分离** | 券商转债、周期转债、低溢价银行转债有超大 Beta | 结合品种股性，勿孤立看 alpha |
| 🔴 **归因非测仓位** | beta 是"有效仓位"，不是真实仓位 | 勿把 beta 当仓位用 |
| 🟡 **择时择券难兼顾** | 一端强势另一端不拖已是不错 | 综合评判，不强求两全 |
| 🟡 **Gamma 差异** | 低估值品种不对称性（跌无空间、涨无溢价压制）| 结合品种特性 |
