# #30b 关联溢出 · 价格相关性关联溢出 — 详细实现

> **定位**：本文是 [`30-supply-chain-centrality.md`](../../strategy-playbooks/30-supply-chain-centrality.md) 配方 D 的**量价正交版**——用纯价格数据（仅需日线）构建关联群，做关联溢出因子。与 30a（行业市值关联）机制正交，可叠加。
>
> **角色**：关联溢出家族的**量价版**。只用日线收盘价定义关联（过去 20 日共同涨跌天数占比 >50%），**完全不需要行业/基本面/资金流数据**——数据门槛最低，与 30a 正交性最好。
>
> **来源**：[中信建投 2024.9《股票关联与溢出效应因子构建》](../../../raw/articles/[202409180930]股票关联与溢出效应因子构建.md)（§2.2.5 价格关联溢出因子）。

---

## 一、策略定位

### 1.1 赚什么钱

**价格相关联的股票，动量/情绪会溢出**：两只股票过去 20 日的涨跌方向高度一致（共同涨跌天数占比 >50%），说明它们受相同信息驱动（可能是有未公开的供应链关系、相同概念、相同资金主力等）。当其中一群已经涨了/高换手了，另一群（本股）还没动，本股随后会**补涨**。

**alpha 来源**：与 30a 相同（投资者有限注意力 + 信息传导滞后），但**关联定义不同**——30a 用"同行业同市值"的显性关联，30b 用"价格涨跌同频"的隐性关联。隐性关联能抓到行业归属捕捉不到的关联（如跨行业的供应链、相同概念股）。

> 📖 [中信建投 2024.9](../../../raw/articles/[202409180930]股票关联与溢出效应因子构建.md) §2.2.5："我们考虑**股票涨跌的关联性而非具体的涨幅**，取两只股票过去 20 个交易日**共同涨跌的天数占比**，取该比值高于 50% 的股票作为关联股票……再与个股自身的指标相减计算关联溢出。"

### 1.2 这个策略在关联溢出家族里的角色

| 策略 | 关联定义 | 与本策略（30b）的关系 |
|---|---|---|
| 30a 行业市值 | 显性（同行业同市值）| 与 30b 正交（显性 vs 隐性）|
| **30b 价格相关** | **隐性（涨跌同频）**| — |
| 30c 6 类合成 | 综合 | 30b 是 6 类之一 |
| 30y 分析师+资金流 | 半公开 | 与 30b 正交 |

**与 30a 的核心区别**：
- 30a 的关联群 = 同行业同市值档（显性、静态、可能有跨行业的真实关联被漏掉）
- 30b 的关联群 = 价格涨跌同频的股票（隐性、动态、能抓到跨行业关联，但可能含噪音）

两套关联定义互补，合成后增量明显（见 30c）。

### 1.3 不适合什么场景

- **追求最高收益**：30b 单因子绩效（情绪多空 18.55%）不及 30a（情绪多空 24.67%），更不及 30c（多空 27%）；它的价值在于**与 30a 正交**
- **首组直接用**：30b 的动量版和情绪版**第一组（Q1）都非最优**，需取第 2-3 分位
- **极端市场**：市场普涨/普跌时，所有股票涨跌同频，关联群膨胀，信号失真

## 二、信号逻辑：价格相关性关联溢出怎么算

### 2.1 关联群怎么定义（20 日共同涨跌 >50%）

**第一步：算两只股票的共同涨跌天数占比**。对全市场任意两只股票 $i, j$：

$$\text{同频率}_{i,j} = \frac{\text{过去 20 日 } i, j \text{ 同涨同跌的天数}}{20}$$

- "同涨同跌" = 两只股票当日涨跌方向一致（都涨或都跌），**不看幅度，只看方向**
- 例如过去 20 日里，$i$ 和 $j$ 有 12 天同涨同跌 → 同频率 = 12/20 = 60%

**第二步：筛关联股票**。对每只股票 $i$，取所有与 $i$ 同频率 **>50%** 的股票作为关联群。

> 📖 [中信建投 2024.9](../../../raw/articles/[202409180930]股票关联与溢出效应因子构建.md) §2.2.5："取两只股票过去 **20 个交易日共同涨跌的天数占比**，取该比值**高于 50%** 的股票作为关联股票。"

**为什么用方向而非幅度**：原文明确"考虑股票涨跌的关联性而非具体的涨幅"。方向同频捕捉的是"是否受相同信息驱动"，幅度会受个股波动率/流动性干扰。

**为什么阈值 50%**：50% 是随机基准（抛硬币正反面），>50% 表示显著高于随机的同频。阈值越严（如 >70%），关联群越小但越精；越松（如 >50%），关联群越大但含噪音。原文用 50%。

### 2.2 关联群可能很大（工程注意）

⚠️ **工程陷阱**：全市场 5000 只股票，两两组合约 1250 万对。对每只股票，与它同频 >50% 的股票可能有几十到几百只——关联群可能很大。

**应对**：
- 关联群取均值时，群体越大越平滑（噪音互消），但也可能稀释信号
- 可选：关联群限制为同频率最高的 top 50 只（而非所有 >50% 的），提纯信号（原文未提此优化，属落地决策）

### 2.3 溢出指标 + 关联溢出公式

与 30a 完全一致（共用中信建投的溢出框架）：

$$\text{价格相关关联溢出}_i = \text{mean}_{j \in \text{同频}>50\%(i)}(\text{溢出指标}_j) - \text{溢出指标}_i$$

- 溢出指标 = 1 月涨跌（动量版）/ 1 月日均换手（情绪版）
- 关联群 = 与 $i$ 过去 20 日同频 >50% 的所有股票
- **关联溢出 > 0** = 关联群领涨/高换手、本股滞后 → 补涨信号

> 📖 [中信建投 2024.9](../../../raw/articles/[202409180930]股票关联与溢出效应因子构建.md) §2.2.5："计算其 1 个月动量/月均换手的均值作为关联指标，**再与个股自身的指标相减计算关联溢出**。"

### 2.4 算法完整流程（以 A 公司为例）

假设今天是 2026-07-31（月末盘后），要算 A 公司的价格相关情绪溢出：

```
步骤 1：算 A 与全市场每只股票的 20 日同频率
  ├─ 取 A 和每只股票 j 过去 20 日（2026-07-01 至 2026-07-31）的涨跌方向
  └─ 数同涨同跌的天数 / 20 = 同频率
  例：A 与 B 同频 13/20=65%，A 与 C 同频 8/20=40%，A 与 D 同频 11/20=55%...

步骤 2：筛关联群
  └─ 取所有同频率 >50% 的股票 = A 的关联群（例如 120 只）

步骤 3：算溢出指标（情绪版，截至 2026-07-31）
  ├─ A 公司 1 月日均换手率 = 例如 2.0%
  └─ 关联群 120 只股票各自算 1 月日均换手率，取均值 = 例如 3.5%

步骤 4：算关联溢出
  └─ 情绪溢出 = 3.5% − 2.0% = 1.5%（>0，补涨信号）

步骤 5：因子处理 + 全市场排序 + Q1 多头（同 30a）
```

## 三、选股规则

### 3.1 每月盘后例行流程

```
每月最后一个交易日盘后：
1. 拉全市场过去 20 日 OHLCV + 换手率

2. 算两两同频率矩阵（全市场 N×N，N≈5000）
   ⚠️ 计算量大，需优化（向量化/分块）

3. 对每只股票筛关联群（同频 >50%）

4. 算关联溢出（情绪版/动量版，按 §二 流程）

5. 因子处理：3σ 去极值 + 缺失值剔除 + 行业市值中性化（可选）

6. 全市场排序
   ├─ 情绪版：⚠️ 第一组非最优，建议取第 2-3 分位
   └─ 动量版：⚠️ 第一组非最优，建议取第 2-3 分位

7. 输出候选清单 → 次月首个交易日开盘买入
```

### 3.2 硬过滤条件

与 30a 一致（剔除停牌/一字板/上市 <半年/ST），见 [30a §3.2](30a-industry-cap-spillover.md)。

额外注意：
- **关联群大小过滤**：若某只股票的同频 >50% 关联群 < 10 只（统计无意义），剔除该股票或用全市场均值兜底
- **新上市股票**：上市 <20 日的股票无法算 20 日同频率，剔除

### 3.3 ⚠️ 前视偏差检查

**强制规则**：
- 同频率计算：用 $[T-20, T-1]$ 的涨跌方向（不能用 T 日当天）
- 溢出指标：用截至 T-1 日的过去 1 月数据
- 月末盘后（T 日收盘后）生成信号，次月首个交易日（T+1）开盘买入

## 六、绩效预期与可信度

### 6.1 原文绩效（中信建投 2024.9，2010.1-2023.12，月频，10 分位多空，全市场）

| 指标 | 价格相关·情绪 | 价格相关·动量 |
|---|---|---|
| 多空年化 | **18.55%** | 16.43% |
| 夏普 | **1.99** | 1.77 |
| IC 均值 | **6.14%** | 4.93% |
| 年化 IC_IR | **2.95** | 2.29 |
| Q1 多头年化 | 11.69% | 9.47% |
| 分层单调性 | **第一组非最优** | **第一组非最优** |

> 📖 [中信建投 2024.9](../../../raw/articles/[202409180930]股票关联与溢出效应因子构建.md) §2.2.5.1（动量）："因子年化多空收益 **16.43%**，夏普比率 **1.77**，IC 均值 **4.93%**，年化 IC_IR 达到 **2.29**……分层效果有一定的区分度……但**第一组的收益并非最优**。"

> 📖 [中信建投 2024.9](../../../raw/articles/[202409180930]股票关联与溢出效应因子构建.md) §2.2.5.2（情绪）："分层效果有一定的区分度……但**第一组的收益并非最优**。"（情绪版多空 18.55%/夏普 1.99/IC 6.14%/IC_IR 2.95/Q1 11.69%）

⚠️ **首组非最优的含义**：Q1（最高溢出分位）的收益不是 10 组里最高的——可能是 Q2 或 Q3 更高。这暗示**极高分位有过度投机/反转风险**，实操应取第 2-3 分位而非首组。

### 6.2 与 30a 的对比

| 指标 | 30a 行业市值·情绪 | 30b 价格相关·情绪 |
|---|---|---|
| 多空年化 | 24.67% | 18.55% |
| IC_IR | 3.12 | 2.95 |
| 分层单调性 | **极高** | 第一组非最优 |
| 数据需求 | 行业 + 市值 + 日线 | **仅日线** |
| 关联定义 | 显性（同行业同市值）| 隐性（涨跌同频）|

**结论**：30a 单因子绩效更强且分层更好；30b 的价值在于**数据门槛更低（仅需日线）+ 与 30a 正交**。两者合成进 30c 后增量明显。

### 6.3 个人投资者降级预期

与 30a 一致：原文的 **6-7 折**（情绪版多空 11-13%，而非 18.55%）。折扣因素：未计费用、未计涨跌停、数据时延、行业中性化影响。

## 七、失效红线

| 红线 | 表现 | 监控动作 |
|---|---|---|
| 🔴 **极端市场普涨/普跌** | 所有股票涨跌同频，关联群膨胀至全市场，信号失真 | 监控全市场涨跌一致性；极端期降仓位 |
| 🔴 **首组反转风险** | 动量/情绪版首组（Q1）非最优，极高分位有过度投机 | 取第 2-3 分位，不用 Q1 |
| 🟡 计算量爆炸 | 全市场 N×N 同频矩阵，N=5000 时约 1250 万对 | 向量化计算 + 分块；或限制关联群 top 50 |
| 🟡 关联群含噪音 | 50% 阈值较松，关联群可能含不相关股票 | 收紧阈值至 60-70%，或取同频 top N |
| 🟡 与动量因子相关 | 动量版与 Momentum_1m 强相关 | 与 [07 动量] 因子正交化 |
