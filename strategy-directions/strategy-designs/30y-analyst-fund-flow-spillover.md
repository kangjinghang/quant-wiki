## 一、策略定位

### 1.1 赚什么钱

**机构行为视角的关联溢出**：
- **分析师共同覆盖关联**：同一分析师覆盖的股票，基本面判断高度相关——当分析师覆盖的"一群股票"里某些已经涨了/高换手了，同分析师覆盖的其他股票（本股）还没动，本股随后会补涨
- **基金共同持仓关联**：同一基金重仓的股票，资金面联动——当某基金重仓的"一群股票"里某些已经涨了，同基金重仓的其他股票（本股）会跟随
- **共同资金流关联**：过去 20 日资金流同向（同流进/同流出）的股票，受相同资金主力驱动——当关联群已经涨了，本股会补涨

**alpha 来源**：机构行为（分析师判断、基金持仓、资金主力）的关联性 + 投资者对这种关联的反应滞后。

### 1.2 这个策略在关联溢出家族里的角色

| 策略 | 关联定义 | 数据门槛 | 与本策略（30y）的关系 |
|---|---|---|---|
| 30a 行业市值 | 同行业同市值 | ✅ 公开 | 正交（显性 vs 机构行为）|
| 30b 价格相关 | 涨跌同频 | ✅ 公开 | 正交 |
| 30c 6 类合成 | 综合 | ✅/🔵 | 30y 是 30c 的 3/6（半公开部分）|
| **30y 分析师+资金流** | **机构行为** | 🔵 需 Wind | — |

### 1.3 不适合什么场景

- 🔵 **无 Wind 数据**：分析师署名明细、基金重仓明细需 Wind/朝阳永续，akshare 缺失——无 Wind 时只能用共同资金流（东财可得）一类
- **大盘股为主**：分析师/基金覆盖集中在大盘股，小盘股覆盖少，信号稀疏
- **追求极简**：3 类半公开关联的工程量 + 数据成本较高，若只想快速验证走 30a

## 二、信号逻辑：3 类半公开关联溢出怎么算

### 2.1 分析师共同覆盖关联（ANALYST_COVER）

**关联定义**：同一分析师/分析师团队覆盖的股票互为关联。

> ⚠️ **原文缺口**：中信建投 §2.2.2 正文仅框架，具体关联建立规则在图（markdown 未捕获）。以下是落地建议（参考 [03d 分析师共同覆盖](03d-common-coverage-network.md) 的华泰方法）。

**关联群构造**：
```
对每只股票 i：
1. 取覆盖 i 的所有分析师/团队（上一期已披露）
2. 这些分析师覆盖的其他股票 = i 的关联群
3. （可选）关联度 = 共同覆盖分析师数
```

**绩效**（中信建投，2010.1-2023.12，月频，10 分位多空，全市场）：

| 指标 | 分析师·动量 | 分析师·情绪 |
|---|---|---|
| 多空年化 | **19.33%** | 16.84% |
| 夏普 | **2.26** | 2.26 |
| IC 均值 | **5.19%** | 5.17% |
| 年化 IC_IR | **2.82** | 3.21 |
| Q1 多头年化 | 12.77% | 13.29% |
| 分层单调性 | **极高** | **极高** |

> 📖 [中信建投 2024.9](../../raw/articles/[202409180930]股票关联与溢出效应因子构建.md) §2.2.2.1（动量）："因子年化多空收益 **19.33%**，夏普比率 **2.26**，IC 均值 **5.19%**，年化 IC_IR 达到 **2.82**……Q1 达 **12.77%** 的多头超额收益……分层效果区分度**非常高**，不同分组间具有单调的年化超额收益。"

> 📖 [中信建投 2024.9](../../raw/articles/[202409180930]股票关联与溢出效应因子构建.md) §2.2.2.2（情绪）："分层效果区分度**非常高**，不同分组间具有单调的年化超额收益。"（情绪版多空 16.84%/夏普 2.26/IC 5.17%/IC_IR 3.21/Q1 13.29%）

**关键**：分析师共同覆盖是**动量类最强的单因子**（多空 19.33%），仅次于共同资金流动量（20.36%）。且分层单调性极高，Q1 可直接用。

### 2.2 公募基金共同持仓关联（FUND_HOLD）

**关联定义**：同一基金重仓的股票互为关联。

> ⚠️ **原文缺口**：中信建投 §2.2.3 **整节缺失**（markdown 缺图表），"重仓定义"不明。绩效数字缺失。以下是落地建议（参考 [10g 基金持仓关联](10g-stock-correlation-network.md) 的开源方法）。

**关联群构造**（开源 Traction 方法）：
```
对每只股票 i：
1. 取重仓 i 的所有基金（季报前十大重仓，上一期已披露）
2. 这些基金重仓的其他股票 = i 的关联群
3. 关联度 K_ab = Σ min(I_a, I_b)（持仓市值/20日均成交额，开源方法）
   其中 I_a, I_b 是基金对股票 a, b 的持仓市值
```

**绩效**：⚠️ 中信建投原文 §2.2.3 整节缺失，无数字。参考开源 Traction（基金持仓关联）：
- 开源 RankIC 3.84%/ICIR 2.60，多空 14.3%/IR 2.6（见 [10g](10g-stock-correlation-network.md)）

> ⚠️ **诚实标注**：基金共同持仓关联的具体绩效，中信建投原文未披露（markdown 缺失）。开源 Traction 用的是"牵引预期差"（方向不同），不能直接对标。建议拿到原 PDF 后核对。

### 2.3 共同资金流关联（MONEY_FLOW）

**关联定义**：过去 20 日共同流进流出天数占比 >50% 的股票互为关联。

> 📖 [中信建投 2024.9](../../raw/articles/[202409180930]股票关联与溢出效应因子构建.md) §2.2.4："取两只股票过去 **20 个交易日共同流进流出的天数占比**，作为两只股票资金流向关联的强弱，取该比值**高于 50%** 的股票作为关联股票……再与个股自身的指标相减计算关联溢出。"

**关联群构造**：
```
对每只股票 i：
1. 算 i 与全市场每只股票 j 的 20 日共同流进流出天数占比
   ├─ "流进流出"判定：当日资金净流入/净流出（原文未明确口径，推测用大单或总资金流）
   └─ 同向（同流进或同流出）天数 / 20 = 共同资金流同频率
2. 取同频率 >50% 的股票 = i 的关联群
```

> ⚠️ **原文未明确"流进流出"判定口径**：是用大单净流入？总资金流？还是超大单？原文 markdown 未提。落地建议：用东财资金流的"主力净流入"（大单+超大单）方向。

**绩效**（中信建投，2010.1-2023.12，月频，10 分位多空，全市场）：

| 指标 | 共同资金流·动量 | 共同资金流·情绪 |
|---|---|---|
| 多空年化 | **20.36%** | 18.18% |
| 夏普 | **2.20** | 2.09 |
| IC 均值 | **5.86%** | 5.99% |
| 年化 IC_IR | **3.20** | 3.16 |
| Q1 多头年化 | 11.88% | 11.97% |
| 分层单调性 | 较高（前3组单调性不显著）| 较高 |

> 📖 [中信建投 2024.9](../../raw/articles/[202409180930]股票关联与溢出效应因子构建.md) §2.2.4.1（动量）："年化多空收益 **20.36%**，夏普比率 **2.20**，IC 均值 **5.86%**，年化 IC_IR 达到 **3.20**……Q1 达 **11.88%** 的多头超额收益……分层效果区分度较高……但**前 3 组单调性不显著**。"

**关键**：共同资金流·动量是**动量类最强单因子**（多空 20.36%/IC_IR 3.20），值得用 Wind/东财接入。

### 2.4 溢出因子公式（与 30a/b 统一框架）

$$\text{关联溢出}_i = \text{mean}_{j \in \text{关联群}(i)}(\text{溢出指标}_j) - \text{溢出指标}_i$$

- 溢出指标 = 1 月涨跌（动量版）/ 1 月日均换手（情绪版）
- 关联群 = 按 §2.1/2.2/2.3 三类半公开关联定义
- **关联溢出 > 0** = 关联群领涨/高换手、本股滞后 → 补涨信号

### 2.5 算法完整流程

```
每月最后一个交易日盘后：
1. 构建 3 类半公开关联图（截至 T-1 日可得数据）
   ├─ 分析师共同覆盖（上一期已披露）
   ├─ 基金共同持仓（上一期已披露）
   └─ 共同资金流（[T-20, T-1]）

2. 对每类关联算两个溢出因子（动量 + 情绪），共 6 个单因子

3. 因子处理：3σ 去极值 + 缺失值剔除 + 行业市值中性化

4. （可选）3 类等权合成
   ├─ 半公开动量合成 = 3 类动量等权
   └─ 半公开情绪合成 = 3 类情绪等权

5. 全市场排序 + Q1 多头
   ├─ 分析师·动量/情绪：分层单调性极高，Q1 可用
   └─ 资金流·动量：前3组单调性不显著，建议取第 2-3 分位

6. 输出候选清单 → 次月首个交易日开盘买入
```

## 三、选股规则

### 3.1 每月盘后例行流程

见 §2.5。

### 3.2 硬过滤条件

与 30a 一致（剔除停牌/一字板/上市 <半年/ST），见 [30a §3.2](30a-industry-cap-spillover.md)。

额外注意：
- **分析师/基金覆盖度差异**：大盘股覆盖好，小盘股覆盖少。无分析师覆盖/无基金持仓的股票，对应关联因子置 0 或剔除
- **资金流数据质量**：东财资金流（大中小单）是估算（按单笔成交金额拆分），非真实机构/散户资金，需注意口径

### 3.3 ⚠️ 前视偏差检查

| 关联类型 | 数据时点 | 规则 |
|---|---|---|
| 分析师覆盖 | 上一期已披露 | 用上季报披露的覆盖（不能用当季未披露的）|
| 基金重仓 | 上一期已披露 | 用上季报披露的重仓 |
| 共同资金流 | $[T-20, T-1]$ | 用截至 T-1 的 20 日资金流方向 |
| 溢出指标 | 截至 T-1 | 用截至 T-1 的过去 1 月数据 |

### 6.2 与 30a/30b 对比

| 因子 | 多空年化（情绪）| 多空年化（动量）| 数据门槛 |
|---|---|---|---|
| 30a 行业市值 | 24.67% | 16.56% | ✅ 公开 |
| 30b 价格相关 | 18.55% | 16.43% | ✅ 公开 |
| **30y 分析师** | 16.84% | **19.33%** | 🔵 需 Wind |
| 30y 基金 | ⚠️ 缺失 | ⚠️ 缺失 | 🔵 需 Wind |

**结论**：
- **情绪类**：30a 行业市值（24.67%）最强，30y 三类半公开情绪版（16-18%）略弱
- **动量类**：30y 资金流（20.36%）+ 分析师（19.33%）**强于** 30a（16.56%）和 30b（16.43%）
- **半公开关联在动量类有优势**，公开关联在情绪类有优势——两类正交，合成最优

## 八、升级路径

```
30y 分析师 + 资金流关联溢出（本策略，半公开增强）
   │
   ├─ 3 类半公开关联：分析师/基金/资金流
   ├─ 动量类强于公开关联（资金流20.36%/分析师19.33%）
   ├─ 需 Wind 接入
   │
   ↓ 合成到主力
   │
30c 6 类关联合成（配方 D 终极版）
   ├─ 30a 行业市值 + 30b 价格相关 + 基本面（纯公开）
   ├─ + 30y 分析师/基金/资金流（半公开）
   ├─ 等权合成，多空 23-27%/IC_IR 3.2-3.8
   └─ 30y 是 6 类中的 3 类半公开维度
   │
   ↓ 正交叠加（方向相反）
   │
[03d 分析师共同覆盖] / [10g 基金持仓关联] / [25m Traction 网络]
   └─ 这些是"牵引预期差"（局域反转），与本策略（正动量溢出）方向相反
   └─ 机制正交，合成有增量
   │
   ↓ 数据升级路径（需秩鼎）
```
