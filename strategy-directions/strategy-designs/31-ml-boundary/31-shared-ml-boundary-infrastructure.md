## 一、为什么 #31 是"反向手册"——边界即策略

与其它方向（如 #01 PEAD、#02 行业轮动）"配方 A/B/C/D 递进实现"的结构不同，#31 的核心是**划清边界**——用户明确"不碰重度机器学习"，所以本方向的所有策略都从"**什么不算重ML、可以接受**"出发。

### 1.1 三层边界（核心决策框架）

```
┌────────────────────────────────────────────────────────────────┐
│  重ML（🔴排除）—— 端到端黑箱预测 + 过拟合无法验证               │
│  ├─ 深度学习端到端选股（Transformer/GRU/GNN 直接预测收益）       │
│  ├─ 遗传规划因子工厂（GP 自动搜索因子表达式）                    │
│  ├─ GPT 因子工厂（多智能体 LLM 挖因子）                          │
│  └─ 强化学习择时                                                 │
│  排除理由：过拟合无法验证 + 黑箱风格漂移 + 策略同质化             │
│  （注意：算力不是 GP 的核心障碍——华泰双目标 GP 家用机 8h 可跑）  │
└────────────────────────────────────────────────────────────────┘
          ↓ 排除理由的原文硬证据见 §二
┌────────────────────────────────────────────────────────────────┐
│  轻ML（🟢可接受，作为工具）—— 提升树/简单损失做因子合成          │
│  ├─ 提升树因子加权（XGBoost/LightGBM）                          │
│  ├─ AdaBoost 复合 Rank                                          │
│  ├─ 有序回归 wmse 损失                                           │
│  └─ CCC 损失 + 异质集成                                          │
│  甜区规律：提升来自损失函数/集成方式改造，而非堆模型复杂度       │
└────────────────────────────────────────────────────────────────┘
          ↓ 详见 31a/b/c/d
┌────────────────────────────────────────────────────────────────┐
│  LLM 应用（🟡分路径，2023-2026 趋势）—— 三条轻量化路径          │
│  ├─ 路径①：文本选股增强（LLM 不直接出 Alpha，生成文本交树模型）  │
│  ├─ 路径②：LLM 做"路由器/分诊台"而非直接出 Alpha                │
│  └─ 路径③：研报/财报自动化解读（工具层，非直接交易）             │
│  共同规律：LLM 擅长"主观题"，不擅长端到端交易                   │
└────────────────────────────────────────────────────────────────┘

```

### 1.2 排除 vs 可接受的本质区别

> 📖 [华泰金工 2022.12《有序回归》](../../../raw/articles/[202212130800]华泰金工量化如何追求模糊的正确有序回归.md)：轻ML的甜区是"用树模型/简单损失做因子合成"，重ML的坑是"端到端黑箱预测"。

| 维度 | 重ML（排除） | 轻ML（可接受） |
|---|---|---|
| **模型形态** | 端到端（原始数据→收益预测） | 中间层（已有因子→合成/加权） |
| **可解释性** | 黑箱（Transformer/GRU 内部不可读） | 较强（树模型可看分裂规则、特征重要性） |
| **过拟合验证** | 无法事前验证（GP 自承"只能寄希望样本外"） | 可用滚动 CV 验证 |
| **算力门槛** | 高（深度学习需大量 GPU） | 低（家用机可跑） |
| **风格漂移风险** | 高（悄悄漂移，事后归因） | 低（输入因子已可控） |
| **失效可控性** | 低（黑箱出问题难修） | 高（可定位到哪个因子/损失出问题） |

## 二、重ML排除的原文硬证据（每条都有实证）

### 2.1 证据一：过拟合"无法事前验证"（最硬）

> 📖 [国君配置 2023.8《遗传规划解构与投资思考》](../../../raw/articles/[202308250906]国君配置金工遗传规划解构与投资思考解构机器学习系列之一.md)："在实际操作过程中，**我们无法使用未来数据验证因子过拟合情况**……只能……寄希望于挖掘到的因子在样本外表现也比较好""考虑到因子样本外寿命问题……仅以样本外**两个月**的数据为例"。

**含义**：GP 挖到的因子，连作者自己都只敢看"样本外两个月"——这是过拟合无法验证的直接自承。

### 2.2 证据二：端到端模型样本外大面积失效

> 📖 [华泰金工 2024.4《AI量价风控》](../../../raw/articles/[202404260733]华泰金工AI量价选股模型风控探讨.md)：华泰 AI 量价 500/1000 增强 2024Q1 超额最大回撤 **4.0%/4.3%**，归因"市值下沉 Beta 风险 + 策略同质化 Alpha 衰减 + 风格漂移"，且"AI 量价因子长期暴露反转/低波/低流动性风格，风格收益掩盖了 Alpha 本身的衰减"。

**精确风格漂移数据**：
- AI 量价因子与 Barra 市值因子截面相关系数历史均值仅 **0.047**（看似无大小盘倾向），但 **2024-02-07 跌至历史低点 -0.49**
- 与 10 日动量/波动/流动性因子相关系数均值分别为 **-0.28/-0.43/-0.41**
- 组合市值偏离与未来 5 日市值因子收益相关系数 0.21（有择时能力），但三个左上离群点精确对应 2021-01-05、2024-01-29、2024-02-27（尾部风险时点）

### 2.3 证据三：黑箱风格漂移"事后才归因"

> 📖 [华泰金工 2024.4《AI量价风控》](../../../raw/articles/[202404260733]华泰金工AI量价选股模型风控探讨.md)："模型偏好超跌股→2024年1月底小盘超跌→快速漂移至小盘风格→暴露市值风险"。

**含义**：黑箱模型会**悄悄风格漂移**，等回撤发生才事后归因。

### 2.4 证据四：策略同质化 + Alpha 衰减

> 📖 [国君配置 2023.8《遗传规划解构》](../../../raw/articles/[202308250906]国君配置金工遗传规划解构与投资思考解构机器学习系列之一.md)："GP 挖到的量价因子相似度高→**策略同质化**"。

> 📖 [华泰金工 2024.4《AI量价风控》](../../../raw/articles/[202404260733]华泰金工AI量价选股模型风控探讨.md)："AI 量价因子与低频量价因子相关度高""2021 下半年以来残差收益走弱"——重 ML 量价因子正快速衰减。

### 2.5 一个需要诚实记录的反例

重ML模型的**能力上限确实很强**（机构用专业算力 + 工程化防过拟合达到）：

> 📖 [东方证券 2024.6《基于风险注意力的因子挖掘模型》](../../../raw/articles/[202406050810]专题研究基于风险注意力的因子挖掘模型.md)：Risk-Attention 全A RankIC **0.106**/ICIR **6.30**、**多头年化超额 40.3%/Sharpe 5.23**（仅用行情+风险因子，无任何基本面）。

> 📖 [开源金工 2025.7《因子切割论与深度学习的结合应用》](../../../raw/articles/[202507271017]因子切割论与深度学习的结合应用开源金工.md)：DBD-GRU 中证1000 增强超额 11.8%/**回撤仅 3.94%**。

**结论**：个人投资者排除重 ML **不是因为它无效**，而是因为过拟合风险 + 黑箱 + 算力在个人侧不可控。

### 2.6 排除 GP 的理由不是算力（红线修正）

> 📖 [华泰金工 2024.5《双目标遗传规划应用于行业轮动》](../../../raw/articles/[202405240702]华泰金工双目标遗传规划应用于行业轮动.md)："在一台配置普通的计算机上完成（内存 24G、CPU i7-7700、GPU GTX1660-6G），不到 8 小时能运行完毕"。

**含义**：GP 类算力门槛对个人可及。本方向排除 GP 的核心理由是**过拟合无法验证 + 策略同质化**，而非算力。"算力高"的排除理由主要针对深度学习端到端。

## 三、轻ML/LLM 工程基础设施（所有策略共享）

### 3.1 轻ML的统一规律（关键认知）

> 📖 [华泰金工 2022.12《有序回归》](../../../raw/articles/[202212130800]华泰金工量化如何追求模糊的正确有序回归.md) + 📖 [华泰金工 2023.2《九坤Kaggle启示》](../../../raw/articles/[202302020800]华泰金工九坤Kaggle量化大赛有哪些启示.md)：轻ML的共同规律是**提升来自损失函数/集成方式的改造**（CCC、有序回归、异质集成），而非堆模型复杂度。

**反常识实证**：
- 华泰多任务学习（PLE）自陈"加注意力机制反而无改进"——**加复杂度 ≠ 更有效**
- 华泰集成实验：同类种子点 wmse 集成"反不及基线"——**集成的真因是"子模型损失函数异质"，不是集成本身**

### 3.2 LLM 的能力边界（中金实测）

> 📖 [中金转债 2025.11《如何实现AI交易模拟》](../../../raw/articles/[202511021436]中金转债如何实现AI交易模拟.md)：2025.7.1-10.17 测成交额最大 10 支转债，**Deepseek-V3.1-terminus 表现相对较好但仍不比等权持有强**。

**四大核心发现**（LLM 直接做投资决策的边界）：
1. **"业绩"不稳定**：大模型不擅长计算，多次出现"卖出数量大于已持仓数量"
2. **受上下文诱导是通病**：加入"溢价率"就偏好低溢价率品种（不理解价格与溢价率关系）；已亏损时因 RSI 超卖而加仓
3. **LLM 做交易本质是"从结果到使用结果"**，**不是端到端**（原始价格序列→交易信号）
4. **LLM 更适合做"主观题"**（多策略信号融合、非定量因素综合考量），而非"客观题"（因子策略/统计套利）

**含义**：LLM 应定位为"**文本/信号处理器 + 主观题求解器**"，不应定位为"端到端交易信号生成器"。

### 3.3 防 LLM 上下文诱导的工程规则

基于中金实测，使用 LLM 时强制遵守：

| 规则 | 做法 | 避免 |
|---|---|---|
| **指标供给克制** | 只给 LLM 真正需要解读的指标 | 把 RSI/MACD/溢价率一股脑塞给 LLM |
| **结构化输出** | 要求 LLM 输出 JSON 结构化字段 | 让 LLM 直接输出"买/卖/持有" |
| **后置规则校验** | LLM 输出后用规则引擎校验（如持仓检查）| 全信 LLM 的"卖出"指令 |
| **信息防火墙** | 用 ≤9B 小模型（财经训练少）做分类 | 用大模型直接关联股价变动 |

> 📖 [华泰金工 2025.7《LLMRouter-GRU》](../../../raw/articles/[202507180829]华泰金工LLMRouterGRU舆情分诊台赋能AI量价因子.md)："本文所使用 LLM 的最大参数规模为 **9B**……这在一定程度上构成了**'信息防火墙'**，使得'信息泄露'的风险相对可控""大模型发布后各策略的超额提升幅度，并未显著弱于发布前区间"。

## 四、防过拟合通用框架（轻ML也必须遵守）

### 4.1 滚动训练 + 训练/验证/测试分离

```
轻ML防过拟合标准流程：
├─ 训练集（样本内）：滚动 N 个月
├─ 验证集：未来 M 个月（5 折交叉验证选超参）
├─ 测试集（样本外）：更未来 K 个月
├─ 训练/验证/测试间隔 10-20 交易日（防数据泄露）
└─ 滚动步长：每 6 个月滚动一次
```

### 4.2 集成的正确姿势（反常识：不是"集成就好"）

> 📖 [华泰金工 2022.12《有序回归》](../../../raw/articles/[202212130800]华泰金工量化如何追求模糊的正确有序回归.md)："直接将不同种子点的 wmse 模型集成后，年化超额收益、信息比率反不及基线 wmse 模型。有序回归集成模型表现提升的核心原因，可能在于**和谁集成**，而非集成本身。如果子模型损失函数一致，仅仅是随机数种子的差异，那么内部相关性较高，集成未必有效。"

**集成三原则**：
1. **子模型损失函数要异质**（如 wmse + logistic有序回归 + CCC），不要同损失不同种子
2. **NN 类与决策树类互补**（决策树对异常值/缺失值不敏感，NN 能自动构造新特征）
3. **预测值集成优于组合权重集成**（华泰实证）

### 4.3 因子二次筛选硬规则（防过拟合）

> 📖 [国君配置 2023.8《遗传规划解构》](../../../raw/articles/[202308250906]国君配置金工遗传规划解构与投资思考解构机器学习系列之一.md)："**二次筛选硬规则**：与因子池任意因子相关性≤50%，因子多时与主成分（累计贡献>90%）相关性≤50%"。

> 📖 [中信建投 2024.8《FactorZooII》](../../../raw/articles/[202408090831]逐鹿Alpha专题报告二十二FactorZooII基本面因子挖掘统一框架.md)："因子值相关性与因子 IC 相关性可能显著差异（营收与净利润因子值相关 0.56 但 IC 相关 0.88），**推荐用 IC 相关性或因子收益率相关性**而非因子值相关性，否则组合表面分散但市场行为相似"。

**因子池筛选规则**：
| 规则 | 阈值 | 来源 |
|---|---|---|
| 因子值相关性 | ≤50%（与因子池任意因子）| 国君 |
| IC 相关性 | ≤50%（推荐，比因子值相关更准）| 中信建投 |
| 单因子 IC | >3%（财报类初筛）| 中银 |
| 单因子多头 G1 超额 | >5% | 中银 |
