# #31x 重ML边界 · LLM-FADT 文本选股增强 — 详细实现

> **定位**：本文是 [`31-ml-heavy-mining.md`](../strategy-playbooks/31-ml-heavy-mining.md) LLM 路径①的**主力策略**——用 LLM（Qwen3-8B）重构研报文本，再用 FinBERT 提取向量，最后用 XGBoost 合成因子。核心思想：**LLM 不直接出 Alpha，而是生成增量文本交给传统 NLP + 树模型**。
>
> **角色**：LLM 路径①的**代表实现**。与轻ML主线（31a/b/c/d）正交——后者用人工因子，本策略用 LLM 重构的文本因子。可作为轻ML主线的互补叠加。
>
> **来源**：📖 [华泰金工 2025.6《LLMFADT 大模型增强文本选股》](../../raw/articles/[202506120730]华泰金工LLMFADT大模型增强文本选股.md)。

## 一、策略定位

### 1.1 赚什么钱

**研报文本的增量信息 alpha**：分析师研报标题/摘要包含丰富信息，但原始文本写作风格各异、信息密度不均。LLM 能从 5 个角度重构文本，提取出"行情催化剂""言外之意""潜在风险"等增量信息，再用树模型合成因子。

**alpha 来源**：
1. **LLM 重构带来增量文本**——5 个角度中"行情催化剂"与原始文本相关性最低（约 0.6），具备独特增量信息
2. **树模型学习非线性合成**——XGBoost 自动学习 6 类文本的最优合成
3. **先训练后合成**——对 6 类文本各自训练 XGBoost 再取均值，多头/空头区分度最优

> 📖 [华泰 2025.6《LLMFADT》](../../raw/articles/[202506120730]华泰金工LLMFADT大模型增强文本选股.md)："前期报告的核心思想是以分析师研报文本的语义向量（词频向量或 FinBERT 隐藏层编码特征向量），以研报发布前后两日个股超额收益为标签，引导 XGBoost 模型学习研报文本中蕴含的超额信息。"

### 1.2 核心定位：LLM 不直接出 Alpha

> 📖 [华泰 2025.6《LLMFADT》](../../raw/articles/[202506120730]华泰金工LLMFADT大模型增强文本选股.md)：链路为"**Qwen3-8b 重构 5 角度文本 → 微调 FinBERT 提取 CLS 层 768 维向量 → XGBoost 合成因子**"。即 **LLM 不直接出 Alpha，而是生成增量文本交给传统 NLP + 树模型**。

**与 31z LLM 路由器的区别**：
- **31x（本策略）**：LLM 做"文本重构器"（输入文本→输出文本）
- **31z（路由器）**：LLM 做"情绪分诊台"（输入新闻→输出情绪标签）

两者都符合"LLM 不直接出 Alpha"的轻量化原则。

### 1.3 这个策略在 LLM 路径家族里的角色

| 策略 | 路径 | 角色 | 与本策略（31x）的关系 |
|---|---|---|---|
| **31x LLM-FADT** | ①文本选股增强 | **主力** | LLM 重构文本 + 树模型合成 |
| 31y 结构化情感 | ①延伸 | 深化 | LLM 结构化提取（分类体系）|
| 31z LLM 路由器 | ②路由 | 互补 | LLM 做情绪分诊（非文本重构）|
| 31w 工具层 | ③工具 | 辅助 | 研报/财报解读工具 |

### 1.4 不适合什么场景

- **无 LLM API 预算**：依赖 Qwen3-8B API，需预算
- **研报覆盖度低的股票**：小盘股研报稀疏，文本因子失效
- **追求极简**：三步链路（LLM → FinBERT → XGBoost）工程复杂

## 二、信号逻辑：LLM-FADT 三步链路

### 2.1 核心链路

```
分析师研报（标题 + 摘要）
   ↓ Step 1：Qwen3-8B 重构（5 个角度）
5 类重构文本 + 原始文本 = 6 类文本
   ↓ Step 2：FinBERT 微调 + CLS 层提取
6 × 768 维向量
   ↓ Step 3：XGBoost 合成（先训练后合成）
合成因子（6 个 XGBoost 预测值取均值）
   ↓ 截面排序
多头组合（Top25 / Top50 / Top100）
```

### 2.1 Step 1：Qwen3-8B 重构 5 个角度

**5 个重构角度**（Qwen3-8B 对原始研报文本重构）：

| 角度 | 含义 | Top25 超额/IR | 与原始文本相关性 |
|---|---|---|---|
| **行情催化剂**（最有效）| 提取短期催化因素 | **27.36% / 2.19** | 约 0.6（最低，增量最大）|
| 潜在风险 | 提取风险因素 | — | 约 0.5（最低）|
| 标题新解 | 重新解读标题 | 19.01% / 1.74（最弱）| 约 0.7 |
| "言外之意" | 隐含信息 | — | 约 0.7（空头收益最低，可作空头识别）|
| 收益指引 | 提取收益预测 | — | 约 0.7（月胜率最高 75.25%）|

> 📖 [华泰 2025.6《LLMFADT》](../../raw/articles/[202506120730]华泰金工LLMFADT大模型增强文本选股.md)："我们利用 Qwen3-8b 模型对原始分析师文本进行多角度重构，包括**标题新解、行情催化剂、'言外之意'、潜在风险、收益指引共 5 个角度**。"

> 📖 [华泰 2025.6《LLMFADT》](../../raw/articles/[202506120730]华泰金工LLMFADT大模型增强文本选股.md)："**行情催化剂文本年化超额收益率和信息比率最高**，分别为 17.57% 和 1.86，标题新解文本年化超额收益率和信息比率最低，分别为 14.30% 和 1.62。"（多头等权组合）

> 📖 [华泰 2025.6《LLMFADT》](../../raw/articles/[202506120730]华泰金工LLMFADT大模型增强文本选股.md)："行情催化剂文本年化收益率、年化超额收益率和信息比率仍旧最高，分别为 **25.64%、27.36% 和 2.19**，标题新解在年化收益率、年化超额收益率和信息比率三项指标上表现最差，分别为 17.56%、19.01% 和 1.74。相对基准月胜率指标上，**收益指引文本胜率最高，为 75.25%**。"

### 2.3 Qwen3-8B 选型与"快思考"（关键工程）

> 📖 [华泰 2025.6《LLMFADT》](../../raw/articles/[202506120730]华泰金工LLMFADT大模型增强文本选股.md)：Qwen3-8B 因研报文本量大限定为"**快思考**"状态（非慢思考）兼顾效果与效率。

**含义**：研报文本量大，用"慢思考"（如 DeepSeek-R1 的推理过程）成本太高、速度太慢。Qwen3-8B 的"快思考"模式兼顾效果与效率。

### 2.4 Step 2：FinBERT 微调 + CLS 层提取

FinBERT 是金融领域预训练的 BERT 模型。微调后提取 **CLS 层 768 维向量**作为文本特征。

> 📖 [华泰 2025.6《LLMFADT》](../../raw/articles/[202506120730]华泰金工LLMFADT大模型增强文本选股.md)："以研报发布前后两日个股超额收益为标签，引导 XGBoost 模型学习研报文本中蕴含的超额信息。"

**CLS 层**：BERT 的 `[CLS]` token 的最终隐藏状态，是整个句子的聚合表示（768 维）。

### 2.5 Step 3：XGBoost 合成（先训练后合成，关键决策）

**两种合成方案对比**：

| 方案 | 做法 | 单调性 | 多头/空头区分度 |
|---|---|---|---|
| **先合成后训练** | 6 类文本 CLS 向量先取均值，再训练 1 个 XGBoost | **更优** | 较弱 |
| **先训练后合成**（采用）| 6 类文本各自训练 XGBoost，预测值取均值 | 较弱 | **更优**（最终采用）|

> 📖 [华泰 2025.6《LLMFADT》](../../raw/articles/[202506120730]华泰金工LLMFADT大模型增强文本选股.md)："本文尝试对不同大模型文本因子进行合成，包括'先合成后训练'与'先训练后合成'两种方案……测试结果显示**'先训练后合成'方案更优**。"

> 📖 [华泰 2025.6《LLMFADT》](../../raw/articles/[202506120730]华泰金工LLMFADT大模型增强文本选股.md)："相比于'先训练后合成'，'先合成后训练'所得因子的分层回测单调性更优，不同层次间的区分度较为明显。而'先训练后合成'因子的**多头（分层 1）与空头（分层 10）则明显优于'先合成后训练'**，其分层 1 的绝对收益与超额收益也远高于其余分层。"

**结论**：选股更看重多头端，采用"先训练后合成"。

### 2.6 XGBoost 滚动训练（工程参数）

> 📖 [华泰 2025.6《LLMFADT》](../../raw/articles/[202506120730]华泰金工LLMFADT大模型增强文本选股.md)："我们采用滚动的方式对 XGBoost 模型进行训练，**每次滚动样本内为过去 6 个月，样本外为未来 12 个月**。""对于 XGBoost 模型，在每次滚动训练时，均采用**网格搜索**的方式来进行最优超参数的搜索，并采用 **5 折交叉验证**的方式对模型性能进行评估。"

| 参数 | 值 |
|---|---|
| 样本内 | 过去 6 个月 |
| 样本外 | 未来 12 个月 |
| 交叉验证 | 5 折 |
| 超参选择 | 网格搜索 |
| 滚动步长 | 6 个月 |

### 2.7 训练标签（关键）

> 📖 [华泰 2025.6《LLMFADT》](../../raw/articles/[202506120730]华泰金工LLMFADT大模型增强文本选股.md)："样本标签的时间区间表示每条样本中 Y 的计算区间，**T-1~T+1 即表示研报发布前 1 天至后 1 天**。"

**标签 = 研报发布前 1 天到后 1 天（T-1~T+1）的个股超额收益**。

**月末构建因子时追溯过去 3 个月**：

> 📖 [华泰 2025.6《LLMFADT》](../../raw/articles/[202506120730]华泰金工LLMFADT大模型增强文本选股.md)："月末构建因子时追溯过去 3 个月全部样本求均值。"

### 2.8 指增场景的标签定制（重要）

> 📖 [华泰 2025.6《LLMFADT》](../../raw/articles/[202506120730]华泰金工LLMFADT大模型增强文本选股.md)："对于该场景下的 LLM-FADT 策略构建，我们**调整 XGBoost 模型学习的标签为个股相对沪深 300 指数的异常收益**，以此提升 LLM-FADT 因子针对沪深 300 指数的增强效果。"

**含义**：做沪深300 增强时，标签改为"相对沪深300 的超额"；做中证500 增强时，标签改为"相对中证500 的超额"。标签口径要和目标基准对齐。

### 2.9 完整流程示例（以 A 公司某月末为例）

假设今天是 2026-06-30，要算 A 公司的 LLM-FADT 因子：

```
步骤 1：拉取 A 公司过去 3 个月（2026-04~06）的所有研报
   ├─ 研报 1（2026-04-15）：标题 + 摘要
   ├─ 研报 2（2026-05-20）：标题 + 摘要
   └─ 研报 3（2026-06-10）：标题 + 摘要

步骤 2：Qwen3-8B 重构（每篇研报 × 5 角度）
   ├─ 研报 1 → 5 类重构文本
   ├─ 研报 2 → 5 类重构文本
   └─ 研报 3 → 5 类重构文本
   共 3 × 6 = 18 条文本样本（含原始）

步骤 3：FinBERT 提取 CLS 向量
   └─ 每条文本 → 768 维向量

步骤 4：XGBoost 预测（6 个模型，先训练后合成）
   ├─ 标题新解模型 → 预测值
   ├─ 行情催化剂模型 → 预测值
   ├─ 言外之意模型 → 预测值
   ├─ 潜在风险模型 → 预测值
   ├─ 收益指引模型 → 预测值
   └─ 原始文本模型 → 预测值
   → 6 个预测值取均值 = A 公司该研报的因子值

步骤 5：过去 3 个月求均值
   └─ A 公司 LLM-FADT 因子 = （研报 1 + 研报 2 + 研报 3 因子值）/ 3

步骤 6：全市场排序
   ├─ 取 Top25 / Top50 / Top100
   └─ 次月首个交易日开盘买入

步骤 7：前视偏差检查
   └─ 确认所有研报在 2026-06-30 前已发布
```

## 三、选股规则

### 3.1 每月盘后例行流程

```
每月最后一个交易日盘后：
1. 拉取全市场过去 3 个月的研报（标题 + 摘要）

2. Qwen3-8B 重构 5 个角度（快思考模式）
   └─ 每篇研报 → 5 类重构文本 + 原始 = 6 类

3. FinBERT 提取 CLS 向量（768 维）

4. XGBoost 预测（6 个模型，先训练后合成）
   ├─ 训练样本：过去 6 个月（5 折 CV + 网格搜索）
   ├─ 标签：研报发布 T-1~T+1 超额收益（对齐基准）
   └─ 6 个预测值取均值

5. 过去 3 个月求均值 → 个股 LLM-FADT 因子

6. 全市场排序 → Top25 / Top50 / Top100

7. 输出多头组合 → 次月首个交易日开盘买入
```

### 3.2 硬过滤条件

| 过滤条件 | 阈值 | 作用 |
|---|---|---|
| 研报覆盖度 | 过去 3 个月至少 1 篇研报 | 砍无覆盖股 |
| 上市天数 | >250 | 砍新股 |
| ST/退市预警 | 剔除 | 砍风险股 |
| 涨跌停 | 当日涨停不买、跌停不卖 | 流动性 |

### 3.3 ⚠️ 前视偏差检查

- **研报发布日**：只能用 2026-06-30 前已发布的研报
- **训练标签**：T-1~T+1 超额收益，训练时用历史标签（不涉及预测时的未来）
- **滚动训练**：样本内过去 6 个月，不涉及未来

| **LLM API 成本** | -1~2% | DeepSeek/Qwen API 预算 |

| **研报数据获取** | -1~2% | akshare 无研报全文，需付费源 |
| **未计交易费用** | -2~3% | 双边千三 |
| **研报覆盖度下降** | 小盘股失效 | 聚焦中大盘 |

**预期实战绩效**：原文的 **5-6 折**（年化超额 14-17%，而非 27.60%）。主要折扣来自 LLM API + FinBERT 微调工程 + 研报数据获取。

## 七、失效红线

| 红线 | 表现 | 监控动作 |
|---|---|---|
| 🔴 **LLM API 不稳/涨价** | 文本重构中断 | 多供应商备份（DeepSeek/Qwen/GPT）|
| 🔴 **研报覆盖度下降** | 小盘股因子失效 | 聚焦中大盘；结合 31a 量价因子 |
| 🔴 **文本因子拥挤** | 2023 后分化加剧，可能同质化 | 监控多头超额衰减 |
| 🟡 FinBERT 微调漂移 | 向量质量下降 | 定期重新微调 |
| 🟡 基准错配 | 标签口径与基准不对齐 | 标签对齐目标基准 |
