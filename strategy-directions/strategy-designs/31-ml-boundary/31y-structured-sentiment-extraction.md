## 一、策略定位

### 1.1 赚什么钱

**研报情感结构化信息的 alpha**：传统研报情感分析是"黑箱评分"（一个总分），但分析师措辞普遍偏积极（正向 85.3%），简单评分区分度极低。结构化提取把研报拆解为三大类十小类，每类带情绪/出现顺序/篇幅占比，能识别出"渗透率提升靠前""业绩超预期篇幅大"等真正有信号价值的结构。

**alpha 来源**：
1. **结构化分类突破"情绪偏正"困境**——85.3% 正向情绪下，简单评分失效，结构化才能区分
2. **出现顺序/篇幅占比的反常识信号**——渗透率/业绩对比/股东行为"靠前"与收益正相关；但盈利改善/财务稳健性"靠前"反而负相关
3. **差异化窗口**——盈利改善密度 N=20 更优，业绩超预期密度 N=40 更优

> 📖 [华安 2025.8《让情绪有结构》](../../../raw/articles/[202508131549]华安金工让情绪有结构大模型如何挖掘研报新价值量化研究系列报告之二十三.md)："本文依托 DeepSeek 大模型，将情感分析从研报标题拓展至摘要，**实现从黑箱评分向结构化、可解释评分的转变**。"

### 1.2 核心范式转变：从黑箱评分到结构化

| 维度 | 黑箱评分（传统）| 结构化提取（本策略）|
|---|---|---|
| **输出** | 一个总分 | 三大类十小类 + 情绪/顺序/篇幅四维 |
| **可解释性** | 黑箱 | 可解释（每类有明确量化阈值）|
| **情绪偏正处理** | 失效（85.3% 正向）| 结构化区分（类别 + 顺序 + 篇幅）|
| **信号价值** | 弱 | 强（顺序/篇幅有反常识信号）|

> 📖 [华安 2025.8《让情绪有结构》](../../../raw/articles/[202508131549]华安金工让情绪有结构大模型如何挖掘研报新价值量化研究系列报告之二十三.md)："近年来分析师研报措辞普遍偏积极，特别是标题部分过于简略且不包含客观数据，**单纯依赖文字情绪易导致偏差**。"

### 1.3 这个策略在 LLM 路径家族里的角色

| 策略 | 路径 | 角色 | 与本策略（31y）的关系 |
|---|---|---|---|
| 31x LLM-FADT | ①文本选股增强 | 主力 | 31y 是 31x 的深化（重构→结构化）|
| **31y 结构化情感** | ①延伸 | **深化** | 结构化分类 + 四维量化 |
| 31z LLM 路由器 | ②路由 | 互补 | LLM 做情绪分诊 |
| 31w 工具层 | ③工具 | 辅助 | 研报/财报解读工具 |

### 1.4 不适合什么场景

- **无 LLM API 预算**：依赖 DeepSeek-V3-671B API
- **研报稀疏的小盘股**：覆盖不足时结构化信号失效
- **追求极简**：结构化分类 + 密度策略工程复杂

## 二、信号逻辑：结构化情感怎么做

### 2.1 核心链路

```
研报摘要（慧博投研 38.5 万篇）
   ↓ DeepSeek-V3-671B 结构化分类
三大类十小类 + 情绪/出现顺序/篇幅占比（JSON 输出）
   ↓ 个股层面聚合
利好密度因子（CatSentiRatio）
   ↓ 截面排序
多头组合（Top30 / Top50）
```

### 2.1 三大类十小类分类体系（核心）

> 📖 [华安 2025.8《让情绪有结构》](../../../raw/articles/[202508131549]华安金工让情绪有结构大模型如何挖掘研报新价值量化研究系列报告之二十三.md)："在综合分析多家卖方、多个类型的研报摘要后，我们将研报摘要中涉及的利好类别分为以下**三大类、十个子类**："

| 大类 | 子类（编号）| 量化阈值（部分）|
|---|---|---|
| **业务发展** | ①战略布局 | 跨周期（≥3 年）、跨业务/地域的重大资源调配 |
| | ②技术创新 | 研发费用率 ≥5%、专利授权、新产品上市 |
| | ③渗透率提升 | 市占率/客户数/客单价提升（可量化）|
| | ④经营效率提升 | 成本管控、周转率提升 |
| **财务表现** | ⑤盈利改善 | 毛利率同比 ≥2pct、营收/扣非净利同比 ≥10%、ROE 同比 ≥1.5pct |
| | ⑥财务稳健性提升 | 资产负债率同比降 ≥3pct、短期债务占比 ≤30%、经营现金流/净利 ≥80% |
| | ⑦业绩对比预期与同业 | 关键词：超预期/超同业/创纪录 vs 不及预期/弱于同业 |
| **其他因素** | ⑧股东行为 | 回购/增减持/股息政策 |
| | ⑨政策驱动 | 直接财务影响/间接需求驱动 |
| | ⑩市场驱动 | 资金驱动/赛道热度 |

### 2.3 四维量化输出（JSON 结构）

> 📖 [华安 2025.8《让情绪有结构》](../../../raw/articles/[202508131549]华安金工让情绪有结构大模型如何挖掘研报新价值量化研究系列报告之二十三.md)："输出格式要求以 **JSON 数组**形式呈现分析结果，其中每个数组元素对应一个提及的研报要素类别，包含**'类别'、'情绪'、'出现顺序'、'字数占比'**四个字段。"

**输出示例**：
```json
[
  {"类别": 4, "情绪": 1, "出现顺序": 1, "篇幅占比": 0.5},
  {"类别": 2, "情绪": -1, "出现顺序": 2, "篇幅占比": 0.2},
  {"类别": 8, "情绪": 0, "出现顺序": 3, "篇幅占比": 0.3}
]
```

**四维含义**：
- **类别**：1-10（十大子类编号）
- **情绪**：1（正面利好）/ -1（负面利空）/ 0（中性）
- **出现顺序**：在摘要中首次出现的顺序（1, 2, 3...）
- **篇幅占比**：该类别字数/摘要总字数（0-1，保留两位小数）

### 2.4 情绪分布严重偏正（85.3%）——结构化的根本原因

> 📖 [华安 2025.8《让情绪有结构》](../../../raw/articles/[202508131549]华安金工让情绪有结构大模型如何挖掘研报新价值量化研究系列报告之二十三.md)："从数据统计来看，所有报告的分类中，**正向情绪（+1）占比（正向情绪数量/总情绪数量）高达 85.3%**，中性（0）和负向（-1）情绪占比分别为 **6.1% 和 8.6%**。"

**含义**：85.3% 正向情绪下，简单评分几乎全部高分，区分度极低。必须用"类别 + 顺序 + 篇幅"的结构化信息才能区分。

### 2.5 模型选型反常识：选 V3-671B 而非 R1

> 📖 [华安 2025.8《让情绪有结构》](../../../raw/articles/[202508131549]华安金工让情绪有结构大模型如何挖掘研报新价值量化研究系列报告之二十三.md)：
> - **R1-32B**：推理过程基本符合逻辑，但**输出结果格式的准确率方面表现欠佳，正确率仅约 50%**

**最终选 V3-671B**：

### 2.6 出现顺序/篇幅占比的反常识发现（核心 alpha）

#### 顺序信号

> 📖 [华安 2025.8《让情绪有结构》](../../../raw/articles/[202508131549]华安金工让情绪有结构大模型如何挖掘研报新价值量化研究系列报告之二十三.md)："典型如 **③渗透率、⑦业绩对比预期和同业 和 ⑧股东行为**，在 CAR5、CAR20、CAR60 三个不同观察期中均展现出显著的正向收益预测能力。""部分基础财务类因子（**如经营效率、盈利改善、财务稳健性**）反而呈现出负相关，顺序越靠前，未来收益越差……大多数研报为业绩点评类，出于写作逻辑，会优先对财务表现进行描述，并不完全代表分析师的关注重心。"

#### 篇幅信号

> 📖 [华安 2025.8《让情绪有结构》](../../../raw/articles/[202508131549]华安金工让情绪有结构大模型如何挖掘研报新价值量化研究系列报告之二十三.md)："对于利好信息，部分类别展现出一定的正向关系，尤其是 **③渗透率，⑨政策驱动，②技术创新，①战略布局**。""对于 **⑤盈利改善与⑥财务稳健性**这两个基本面强相关类别，在短期（5 日、20 日）窗口中，利好的篇幅占比与未来收益甚至**呈负相关**。可能原因在于：相关研报多为业绩点评类，天然会占据较大篇幅；高频出现的'基本面陈述'未必具备稀缺性或超额信息含量。"

**反常识结论**：
| 类别 | 顺序靠前/篇幅大 → 收益 | 原因 |
|---|---|---|
| ③渗透率 / ⑦业绩对比 / ⑧股东行为 | **正相关** | 稀缺信息，靠前=关注重心 |
| ⑤盈利改善 / ⑥财务稳健性 | **负相关** | 常规性陈述，靠前=写作逻辑非关注重心 |

### 2.7 利好密度因子（CatSentiRatio）

> 📖 [华安 2025.8《让情绪有结构》](../../../raw/articles/[202508131549]华安金工让情绪有结构大模型如何挖掘研报新价值量化研究系列报告之二十三.md)："该占比指标（CatSentiRatio）用于衡量特定时间段内，某只股票所有报告的某一类别的利好情绪在该股票在区间内的所有报告涉及的全部情绪中的相对占比。"

**计算步骤**：
```
1. 确定报告时间 t
2. CatSentiSum = t-N 交易日内，个股全部报告的该分类情绪值总和
3. AllSentiNum = t-N 交易日内，个股全部报告的所有情绪（无论正负）数量
4. CatSentiRatio = CatSentiSum / AllSentiNum
```

### 2.8 差异化窗口参数（关键工程）

> 📖 [华安 2025.8《让情绪有结构》](../../../raw/articles/[202508131549]华安金工让情绪有结构大模型如何挖掘研报新价值量化研究系列报告之二十三.md)：

| 策略 | 最优 N | 原因 |
|---|---|---|
| **盈利改善密度**（分类⑤）| **N=20**（短期更优）| 盈利改善类研报多，长窗口（N=40）引入滞后信号 |
| **业绩超预期密度**（分类⑦）| **N=40**（长期更优）| 业绩超预期类研报少，短窗口样本不足引入偶发噪声 |

**含义**：不同分类的研报稀疏度不同，窗口参数要差异化。

### 2.9 综合评分因子（score_report_llm）

> 📖 [华安 2025.8《让情绪有结构》](../../../raw/articles/[202508131549]华安金工让情绪有结构大模型如何挖掘研报新价值量化研究系列报告之二十三.md)：最终合成因子 **score_report_llm**（个股层面，四类核心因子等权合成）。

### 2.10 完整流程示例

```
步骤 1：拉取 A 公司过去 N 天（N=20 或 40）的所有研报摘要

步骤 2：DeepSeek-V3-671B 结构化分类（批量 15 条/次）
   └─ 每篇摘要 → JSON 数组（类别/情绪/顺序/篇幅）

步骤 3：计算利好密度（以分类⑦业绩超预期为例，N=40）
   ├─ CatSentiSum = 过去 40 天 A 公司所有研报中分类⑦的情绪值总和
   ├─ AllSentiNum = 过去 40 天 A 公司所有研报的全部情绪数量
   └─ CatSentiRatio = CatSentiSum / AllSentiNum

步骤 4：（或用综合评分）score_report_llm = 四类核心因子等权合成

步骤 5：全市场排序
   ├─ 取 Top30 / Top50
   └─ 月末（或不定期：1/4/7/8/10 月底）调仓
```

## 三、选股规则

### 3.1 每月盘后例行流程

```
每月最后一个交易日盘后（或不定期：1/4/7/8/10 月底）：
1. 拉取全市场过去 N 天（N=20 或 40）的研报摘要

2. DeepSeek-V3-671B 结构化分类（批量 15 条/次）
   ├─ system：系统提示（任务规则）
   ├─ user：摘要 1 ... 摘要 15
   └─ 输出 JSON 数组（类别/情绪/顺序/篇幅）

3. 计算个股利好密度
   ├─ 分类⑤盈利改善密度（N=20）
   └─ 分类⑦业绩超预期密度（N=40）

4. （或）计算综合评分 score_report_llm

5. 全市场排序 → Top30 / Top50

6. 输出多头组合 → 次月首个交易日开盘买入
```

### 3.2 硬过滤条件

| 上市天数 | >3 个月 |
