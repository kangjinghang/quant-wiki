# #31z 重ML边界 · LLM 路由器思想（轻ML化版）— 详细实现

> **定位**：本文是 [`31-ml-heavy-mining.md`](../../strategy-playbooks/31-ml-heavy-mining.md) LLM 路径②的**轻ML化改编策略**——华泰 LLMRouter-GRU 原文用 GRU 深度学习基座（重ML，排除），本策略**抽离其"LLM 做情绪分诊台"的核心思想**，套到传统树模型/规则因子上，实现"路径②轻ML化"。
>
> **角色**：LLM 路径②的**轻ML化代表**。原文 LLMRouter 用 GRU 基座（重ML），个人投资者不可直接复现。本策略保留"LLM 做外生路由"的核心创新，把基座换成 31a/b/c/d 的轻ML模型，让路径②对个人投资者可用。
>
> **来源**：📖 [华泰金工 2025.7《LLMRouter-GRU 舆情分诊台赋能 AI 量价因子》](../../../raw/articles/[202507180829]华泰金工LLMRouterGRU舆情分诊台赋能AI量价因子.md)（核心思想）+ 31a/b/c/d（轻ML基座）。

## 一、策略定位

### 1.1 赚什么钱

**LLM 情绪分诊 + 传统因子分域的 alpha**：新闻舆情碎片化，直接做 Alpha 困难，但做"风格特征"容易。LLM 把新闻情绪分为乐观/悲观/中性三分位，作为"外生路由"把股票分域，再用传统因子在各域内选股。核心思想：**LLM 做它擅长的（情绪分类），不做它不擅长的（直接出 Alpha）**。

**alpha 来源**：
1. **LLM 情绪分诊的增量信息**——新闻舆情是量价/基本面因子没有的另类信息
2. **分域选股的精细化**——不同情绪域内，因子有效性不同
3. **多头端改善**——华泰实证"改善主要在多头端"

> 📖 [华泰 2025.7《LLMRouter-GRU》](../../../raw/articles/[202507180829]华泰金工LLMRouterGRU舆情分诊台赋能AI量价因子.md)："本文选取新闻舆情数据作为研究对象，从中挖掘另类信息。直觉上，**使用碎片化的新闻数据直接做出'另类 Alpha'是困难的，而以此做出另类风格特征是相对容易的**。"

### 1.2 核心创新：LLM 做外生路由（非内生路由）

| 路由类型 | 做法 | 问题 |
|---|---|---|
| **内生路由**（传统 MoE）| 用神经网络自己学路由 | 拉高参数量，小样本任务易过拟合 |
| **外生路由**（LLMRouter 创新）| 用预训练 LLM 做冻结参数的路由 | 不增参数量，避免过拟合 |

> 📖 [华泰 2025.7《LLMRouter-GRU》](../../../raw/articles/[202507180829]华泰金工LLMRouterGRU舆情分诊台赋能AI量价因子.md)："传统混合专家（MoE）架构以内生网络作为'路由器'的分诊依据。但在量化选股场景中，内生路由因为决策依据与量价信息同源，故相较于外生路由，其难以捕捉市场情绪等非结构化数据的隐含关联信息，Alpha 增厚的空间可能有限。并且笔者认为，**内生路由拉高了网络参数量，对于时间序列预测这类小样本任务，可能会适得其反，导致过拟合**。"

### 1.3 本策略的轻ML化改编（关键决策）

**原文 LLMRouter-GRU 用 GRU 深度学习基座（重ML，排除）。本策略的改编**：

```
原文（重ML，排除）：
  LLM 情绪分类 → MoE 稀疏路由 → GRU 专家网络（重ML）→ 预测

本策略（轻ML化）：
  LLM 情绪分类 → 三分位分域 → 传统因子（31a/b/c/d）分域选股 → 合成
```

**改编逻辑**：
1. **保留**："LLM 做外生情绪路由"的核心创新
2. **替换**：把 GRU 专家网络（重ML）换成 31a/b/c/d 的轻ML因子（XGBoost/AdaBoost）
3. **简化**：不做 MoE 多专家，直接按情绪三分位分域选股

⚠️ **改编的代价**：原文 GRU MoE 能学习"情绪×量价"的复杂交互，轻ML化版只能做简单分域，提升幅度会低于原文的 +3.0pct。但避开了重ML基座，对个人投资者可用。

### 1.4 这个策略在 LLM 路径家族里的角色

| 策略 | 路径 | 角色 | 与本策略（31z）的关系 |
|---|---|---|---|
| 31x LLM-FADT | ①文本选股增强 | 主力 | LLM 重构研报文本（vs 新闻）|
| 31y 结构化情感 | ①延伸 | 深化 | LLM 结构化分类（vs 情绪三分位）|
| **31z LLM 路由器** | ②路由 | **轻ML化** | LLM 做情绪分诊（非文本重构）|
| 31w 工具层 | ③工具 | 辅助 | 研报/财报解读工具 |

### 1.5 不适合什么场景

- **新闻覆盖度低的股票池**：中证1000 增强仅提升 0.9pct（覆盖度低）
- **无新闻数据源**：需财汇新闻或类似源
- **追求原文 +3.0pct 提升**：轻ML化版提升幅度低于原文

## 二、信号逻辑：LLM 路由器（轻ML化版）怎么做

### 2.1 核心链路

```
新闻舆情（财汇新闻）
   ↓ LLM 三模型平均（GLM-4-9B + Qwen2-7B + InternLM2-7B）
情绪二分类（乐观/悲观，不设"无情绪"）
   ↓ 滚动 30 自然日指数衰减聚合
个股舆情因子（[-1, 1]）
   ↓ 三分位离散化（乐观/悲观/中性）
情绪域划分
   ↓ 各域内用 31a/b/c/d 轻ML因子选股
分域合成因子
   ↓ 截面排序
多头组合
```

### 2.1 LLM 情绪分类（三模型平均）

> 📖 [华泰 2025.7《LLMRouter-GRU》](../../../raw/articles/[202507180829]华泰金工LLMRouterGRU舆情分诊台赋能AI量价因子.md)："为了提升实验结果的鲁棒性，我们选择了 **GLM-4-9B、Qwen2-7B、InternLM2-7B 三组不同的大模型基座**，后续实验中将对三组大模型的模型输出取平均得到最终值。"

**选型理由**：
1. **发布时间**：均 2024.6 底前发布，提供 1 年样本外验证
2. **模型能力**：中文财经文本理解与长文本推理强
3. **两两相关性 0.75+**：三模型一致性高

> 📖 [华泰 2025.7《LLMRouter-GRU》](../../../raw/articles/[202507180829]华泰金工LLMRouterGRU舆情分诊台赋能AI量价因子.md)："三种大模型推理得到的舆情因子相关性较高，**两两之间相关性均在 0.75 以上**。"

### 2.3 提示词四部分 + 不设"无情绪"（关键工程）

> 📖 [华泰 2025.7《LLMRouter-GRU》](../../../raw/articles/[202507180829]华泰金工LLMRouterGRU舆情分诊台赋能AI量价因子.md)："我们的提示词框架包含四个关键部分：1）**角色设定**：将模型定位为专业财经新闻情感分析师；2）**核心任务**：明确二分类目标；3）**分析指南**：引导模型忽略表面措辞，聚焦核心事实与数据；4）**输出规范**：限定输出仅为'乐观'或'悲观'，**不设置'无情绪'情感状态，防止出现模型分类类别模糊性（Class Ambiguity）**。"

**反常识**：故意不设"无情绪"——避免模型把难判断的样本归为"无情绪"而偷懒。

### 2.4 新闻数据规模

> 📖 [华泰 2025.7《LLMRouter-GRU》](../../../raw/articles/[202507180829]华泰金工LLMRouterGRU舆情分诊台赋能AI量价因子.md)："新闻舆情数据来源于大智慧财汇……我们选取 **2017-01-01 至 2025-06-30** 的舆情数据用于构造舆情因子。""基于以上提示词，我们对 2017 年至 2025 年间的全量 A 股公司相关新闻进行了标注，积累了**超过 1000 万条带情绪标签的新闻数据**。"

### 2.5 滚动聚合窗口（30 自然日 + 指数衰减）

> 📖 [华泰 2025.7《LLMRouter-GRU》](../../../raw/articles/[202507180829]华泰金工LLMRouterGRU舆情分诊台赋能AI量价因子.md)："1）**时序滚动区间为 30 个自然日**。且周一盘前发出的调仓信号，应包含上周末的完整舆情信息。2）**加权权重随时间做指数衰减**。"

### 2.6 直接逐条聚合平均（反常识，关键工程）

> 📖 [华泰 2025.7《LLMRouter-GRU》](../../../raw/articles/[202507180829]华泰金工LLMRouterGRU舆情分诊台赋能AI量价因子.md)："区别于'先日内平均、再日间平均'的两步平均法，本研究**直接对原始舆情数据做逐条聚合平均**。这是由于**日内的舆情数量、舆情密度也属于情绪强度的重要表征**。例如，某股突发并购利好传闻，单日正面舆情数量暴增，采取逐条聚合时，乐观得分的权重占比也会随之激增，这有利于模型捕捉'情绪爆发'信号。"

**含义**：日内新闻数量多 = 情绪强度大，所以不能"先日内平均"抹平数量信息。

### 2.7 三分位离散化（情绪域划分）

> 📖 [华泰 2025.7《LLMRouter-GRU》](../../../raw/articles/[202507180829]华泰金工LLMRouterGRU舆情分诊台赋能AI量价因子.md)："另一种做法是**稀疏路由（Sparse Router），通过三分位离散化将舆情因子映射为乐观、悲观、中性三类情绪变量**。每个训练样本仅激活 Top-k 的少量专家路由。"

**轻ML化版**：直接按三分位把股票分为三个情绪域，各域内分别用轻ML因子选股。

### 2.8 稀疏路由优于稠密路由（原文结论）

> 📖 [华泰 2025.7《LLMRouter-GRU》](../../../raw/articles/[202507180829]华泰金工LLMRouterGRU舆情分诊台赋能AI量价因子.md)："两种舆情分诊台结构中，**Sparse（稀疏结构）显著优于 Dense（稠密结构）**。直觉上，稠密结构在拉高训练成本的同时，还可能给模型带来过拟合风险。""本文设定 **k=1**，即'舆情分诊台'仅开启一个专家路由。"

**含义**：每个样本只归入一个情绪域（k=1），不做多域混合。

### 2.9 信息防火墙（防未来信息泄露）

> 📖 [华泰 2025.7《LLMRouter-GRU》](../../../raw/articles/[202507180829]华泰金工LLMRouterGRU舆情分诊台赋能AI量价因子.md)："本文所使用 LLM 的最大参数规模为 **9B**。通常来讲，该类中小模型的训练集以数学类、代码类及通用领域文本为主，直接涉及的新闻语料较少，财经新闻覆盖可能更为有限。且大模型在本文中仅用于新闻情绪分类任务，我们并未引导其建立与股价变动的直接关联。**这在一定程度上构成了'信息防火墙'**，使得'信息泄露'的风险相对可控。""**大模型发布后各策略的超额提升幅度，并未显著弱于发布前区间**。这代表大模型引入'未来信息'的风险是有限的。"

**含义**：用 ≤9B 小模型（财经训练少）+ 只做情绪分类（不关联股价），构成信息防火墙。

### 2.10 轻ML化完整流程示例

```
步骤 1：拉取 A 公司过去 30 自然日的所有新闻

步骤 2：LLM 情绪分类（三模型平均）
   ├─ 每条新闻 → GLM-4-9B → 乐观/悲观
   ├─ 每条新闻 → Qwen2-7B → 乐观/悲观
   ├─ 每条新闻 → InternLM2-7B → 乐观/悲观
   └─ 三模型平均 → 每条新闻的情绪分（[-1, 1]）

步骤 3：逐条聚合平均（30 自然日，指数衰减加权）
   └─ A 公司舆情因子 = Σ(情绪分 × 时间衰减权重) / Σ(权重)
   → 例如 = 0.4（偏乐观）

步骤 4：三分位离散化
   ├─ 截面 1/3 分位 → 乐观域
   ├─ 截面 2/3 分位 → 中性域
   └─ A 公司（0.4）→ 乐观域

步骤 5：各情绪域内用轻ML因子选股
   ├─ 乐观域：用 31a/b/c/d 因子选股（情绪催化，择股）
   ├─ 中性域：用 31a/b/c/d 因子选股（无情绪干扰）
   └─ 悲观域：降低权重或剔除（情绪逆风）

步骤 6：合成 + 截面排序 → 多头组合
```

## 三、选股规则

### 3.1 每周/每月盘后例行流程

```
调仓日盘后：
1. 拉取全市场过去 30 自然日的新闻

2. LLM 情绪分类（三模型平均）
   ├─ GLM-4-9B + Qwen2-7B + InternLM2-7B
   ├─ 提示词四部分（角色/任务/指南/输出）
   └─ 输出：乐观/悲观（不设无情绪）

3. 逐条聚合平均（指数衰减加权）
   └─ 个股舆情因子（[-1, 1]）

4. 三分位离散化 → 情绪域划分

5. 各域内用 31a/b/c/d 轻ML因子选股
   ├─ 乐观域：轻ML因子 + 情绪催化权重
   ├─ 中性域：轻ML因子（标准权重）
   └─ 悲观域：降权或剔除

6. 合成 + 截面排序 → 多头组合
```

### 3.2 硬过滤条件

同 31a/b/c/d。新闻覆盖度低的股票（过去 30 天 <3 条新闻）剔除。

### 3.3 ⚠️ 前视偏差检查

- **新闻发布时间**：只能用调仓日前已发布的新闻
- **LLM 发布时间**：华泰用 2024.6 底前的模型，确保回测时段模型已发布（信息防火墙）

## 六、绩效预期与可信度

### 6.1 原文绩效（华泰 LLMRouter-GRU，重ML基座，**轻ML化版会低于此**）

| 指增场景 | 年化超额提升 | 备注 |
|---|---|---|
| 沪深300 增强 | **+3.0pct** | 舆情覆盖度高 |
| 中证500 增强 | +2.2/2.3pct | — |
| 中证1000 增强 | +0.9/1.3pct | 舆情覆盖度低 |
| 中证红利 增强 | +2.1pct | — |
| 国证成长 增强 | +1.9/3.7pct | — |

> 📖 [华泰 2025.7《LLMRouter-GRU》](../../../raw/articles/[202507180829]华泰金工LLMRouterGRU舆情分诊台赋能AI量价因子.md)："在舆情覆盖度较高的 **300 增强、500 增强、红利增强、成长增强**场景下，模型年化超额分别提升 **3.0pct、2.2pct、2.1pct 和 3.7pct**，最大回撤明显改善；在舆情覆盖度较低的 **1000 增强**下……年化超额提升 **0.9pct**。"

⚠️ **口径标注**：提升幅度（vs 普通 GRU 基座）、2022.12-2025.6 回测。

### 6.2 方法边界：覆盖度决定效果

> 📖 [华泰 2025.7《LLMRouter-GRU》](../../../raw/articles/[202507180829]华泰金工LLMRouterGRU舆情分诊台赋能AI量价因子.md)："**大市值股票池的舆情覆盖度显著高于小市值股票池**；可以预见，在后续实验中，舆情覆盖度越高的股票池中，策略的边际提升将越明显。"

**含义**：300/500/红利/成长（大中盘）效果好，1000（小盘）效果差。本策略适合大中盘。

### 6.3 反常识：改善主要在多头端

> 📖 [华泰 2025.7《LLMRouter-GRU》](../../../raw/articles/[202507180829]华泰金工LLMRouterGRU舆情分诊台赋能AI量价因子.md)："可见 **AI 舆情融合因子改善主要体现在多头端**。多头收益、多头端区分度都有显著提升。**RankIC 指标无明显改善**。"

**含义**：策略价值在"选强势股"而非"全截面排序"——RankIC 不变但多头端提升。

### 6.4 稳健性测试

> 📖 [华泰 2025.7《LLMRouter-GRU》](../../../raw/articles/[202507180829]华泰金工LLMRouterGRU舆情分诊台赋能AI量价因子.md)："我们选取了某个自然月的 **15 万余条舆情数据进行多次运行，发现多次运行结果之间的差异率仅在 1.5% 以下**，这一结论对三个大模型基座均成立。"

**含义**：通过调 Top-K/P/Temperature，LLM 输出稳定性高（差异率 1.5%）。

### 6.5 个人投资者降级预期（轻ML化版）

| 折扣因素 | 影响 | 应对 |
|---|---|---|
| **轻ML化替换 GRU** | -1~2pct（vs 原文）| 接受，换可用性 |
| **LLM API 成本**（三模型）| -1~2% | 可先用单模型（如 Qwen2-7B）|
| **新闻数据源** | -1~2% | 财汇新闻（付费）/ akshare 部分 |
| **舆情覆盖度** | 小盘股失效 | 聚焦 300/500 |

**预期实战绩效**：轻ML化版的提升幅度约为原文的 **3-5 折**（+0.5-1.5pct，而非 +3.0pct）。但避开了重ML基座，对个人投资者可用。

## 七、失效红线

| 红线 | 表现 | 监控动作 |
|---|---|---|
| 🔴 **重要张力：GRU 基座风格漂移** | 原文 GRUa 2024.9 回撤 | 轻ML化版无此问题（基座是树模型）|
| 🔴 **新闻覆盖度下降** | 小盘股失效 | 聚焦大中盘 |
| 🔴 **LLM 上下文诱导** | 受"溢价率"等指标诱导 | 只给新闻文本，不给量价指标 |
| 🟡 三模型一致性下降 | 两两相关 <0.7 | 检查模型版本/提示词 |
| 🟡 情绪偏正 | 乐观占比 >80% | 强化三分位（非二分类）|
