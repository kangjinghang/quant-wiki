## 一、策略定位

### 1.1 赚什么钱

**日内重点时段的量价微观结构 alpha**：把每个交易日的分钟时段，按**成交量（成交金额）、涨跌幅、股价**等指标划分为"重点时段"（如大成交金额时段、横盘时段、低价时段等），再统计这些重点时段内的量价特征。不同时段的微观交易行为蕴含未来收益信息。

**alpha 来源**：日内不同时段的交易行为反映不同类型投资者的意图——大成交金额时段（主力/知情交易者参与）、横盘时段（方向不明，后市偏弱）、低价时段（价值低估区间）、量价背离时段（信息冲突）——把这些时段的统计特征量化成因子，能捕捉分钟 K 看不到的时段选择效应。

> 📖 [广发 2025.12](../../raw/articles/[202512051506]广发金工用逐笔订单数据改进分钟频因子海量Level2数据因子挖掘系列六.md)："基于**成交量、涨跌幅、股价**等指标对日内重点分钟时段进行区分，然后统计这些重点时段内的量价特征。"

### 1.2 在家族里的角色

| 策略 | 角色 | 复杂度 | 与本策略（32b）的关系 |
|---|---|---|---|
| [32a 华泰 DL 融合](32a-huatai-tick-dl-fusion.md) | 主力（最强 IR）| 高（DL + 周频）| DL 因子，可正交合成 |
| **32b 广发 KeyPeriod** | **系统工程（月频落地首选）**| 中（人工因子）| — |
| [32c 招商 AFH](32c-cms-afh-behavior.md) | 行为路径（月频）| 中 | 行为因子，小盘多头导向 |
| [25 配方 B 逐笔族](25i-long-short-big-small.md) | 同族 L2 逐笔 | 中 | 长短单/大小单，2 个成交金额类因子与此部分重叠 |

### 1.3 不适合什么场景

- **无 L2 数据权限**：核心输入是逐笔订单（需主买/主卖区分），日线代理丢失时段划分能力
- **追求单因子极致收益**：KeyPeriod 是月频单因子 RankIC 5-11% 级别，强在**正交性**和**因子库丰富度**，非单点爆发
- **大盘股纯多头**：原文未给市值依赖实证（见 §七），建议先在中小盘验证

## 二、信号逻辑（核心：KeyPeriod 重点时段因子）

### 2.1 因子构造总框架：4 大类 × 阈值划分 × 主买卖区分

```
逐笔订单数据（L2）
   │
   ├─ 时段划分：按"成交量/涨跌幅/股价"给日内每个分钟时段打标
   │   └─ 筛出"重点时段"（如 top30pct / low5pct / low50pct / zero）
   │
   ├─ 统计重点时段内的量价特征 → 4 大类因子
   │   ├─ 涨跌类（KeyPeriod_ret）33 个
   │   ├─ 价格类（KeyPeriod_price）30 个
   │   ├─ 成交金额类（KeyPeriod_amount）30 个
   │   └─ 量价协同类（KeyPeriod_sync）30 个
   │   └─ 合计 123 个因子
   │
   └─ 两个正交维度
       ├─ ① 不同阈值的指标划分标准（top30pct / low5pct / low50pct / zero 等）
       └─ ② 主买/主卖区分（基于逐笔订单"订单类别"字段）
```

### 2.2 4 大类因子构成

|---|---|---|---|---|

#### ② 主买/主卖区分

> 📖 [广发 2025.12](../../raw/articles/[202512051506]广发金工用逐笔订单数据改进分钟频因子海量Level2数据因子挖掘系列六.md)："逐笔订单数据包含了……其中的关键信息包括精确到毫秒的订单时间、逐笔序号、频道代码、价格、数量、金额、**买入卖出订单号和订单类别**等详细数据。"

主买/主卖区分基于逐笔订单数据中的"**订单类别**"字段（区分主动买入/主动卖出）。这是 L2 数据相对分钟 K 的核心增量——分钟 K 无法区分主动买卖，而 KeyPeriod 因子可按主买/主卖分别统计。

⚠️ **原文未给出"加主买卖区分 vs 不加"的对比绩效**，仅作为因子构造的一个正交维度。

**方向判断**（据 RankIC 符号）：正 RankIC = 正向因子（取前列做多）；负 RankIC = 反向因子（取负号后取前列，或取后列做空/规避）。

**关键观察**：
1. **成交金额类信号最强**（amount_top30pct +11.23% / amount_low50pct -10.50%）——大成交金额时段是正向 alpha，小成交金额时段是反向 alpha（镜像对）
2. **横盘时段因子反向但胜率最高之一**（ret_zero -5.36%/胜率 85.1%）——横盘 = 后市偏弱，作反向信号
3. **量价背离/低价/下跌时段均为正向**（5-6%）——反映价值低估/信息冲突区间的修复机会

### 2.6 量价协同类（KeyPeriod_sync）的构造逻辑

⚠️ **量价协同/量价背离的精确定义和计算公式原文以图片呈现，文字正文未给出公式**。从因子命名和上下文推断：

- `sync` 反映"成交量与价格变动的协同性"

### 2.8 算法完整流程（以某只股票某月为例）

```
每月盘后（需逐笔订单数据）：
1. 数据准备（当月每个交易日）：
   └─ 逐笔订单：订单时间、价格、数量、金额、订单类别（主买/主卖）

2. 时段划分（对每个交易日的分钟时段）：
   ├─ 按成交量打标：大成交金额时段（top30pct）/ 小成交金额时段（low50pct）
   ├─ 按涨跌幅打标：下跌时段（low5pct）/ 横盘时段（zero）
   ├─ 按股价打标：低价时段（low5pct）
   └─ 按量价协同度打标：量价背离时段（low50pct）

3. 统计重点时段量价特征：
   ├─ 对每类重点时段，统计该时段内的成交金额/涨跌幅/价格/量价协同
   ├─ 按主买/主卖分别统计（正交维度②）
   └─ 输出 4 大类 123 个因子值

4. 全市场排序（以 amount_top30pct 正向因子为例）：
   ├─ 按 RankIC 符号确定方向（正向取前列/反向取负号后取前列）
   ├─ 取前 10%（或前 50，看覆盖度）
   └─ 剔除 ST、停牌、涨停股

5. ⚠️ 正交化（与现有因子库合成时）：
   ├─ 4 个涨跌/价格/量价协同类因子（<10%）→ 可直接合成
   └─ 2 个成交金额类因子（<50%）→ 先与 #25 大小单/长短单正交化

6. 输出候选清单 → 次月首个交易日开盘买入
```

## 三、选股规则

### 3.1 每月盘后例行流程

```

1. 计算 4 大类 123 个 KeyPeriod 因子（或精选 6 个）
```
