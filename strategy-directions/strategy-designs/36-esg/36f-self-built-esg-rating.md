## 一、策略定位

### 1.1 赚什么钱 / 解决什么问题

本策略**不是直接的选股 alpha**，而是**自建 ESG 评分的工程方法论**——解决"如何不买付费数据，自己造一套 ESG 评分"的问题。

**为什么海外评级不适合中国金融业**：

> 📖 [光大金工 2023.2](../../raw/articles/[202302161501]光大金工构建金融行业ESG评级体系议题选择权重设置如何更具子行业可比性E.md) §2.2："以 MSCI ESG、标普道琼斯&SAM ESG 为代表的海外 ESG 评级体系中**没有涉及脱贫、乡村振兴、普惠金融等社会性指标**。"

中国金融业特色社会责任含"六稳六保、服务实体经济、脱贫攻坚、普惠金融、低碳转型、反腐败"等，海外评级全面缺位。这套方法论示范了如何针对中国国情自建 ESG 评级。

### 1.2 这个策略在 ESG 家族里的角色

| 策略 | 角色 | 与本策略（36f）的关系 |
|---|---|---|
| 36a ESG 评分选股 | 用付费 ESG 评分 | 36f 教你**自建** 36a 所需的 ESG 评分 |
| 36d 社会责任因子自建 | 自建 2 个子因子 | 36f 方法论可**扩展** 36d 到完整 E/S/G 三维 |
| 36e 争议事件因子 | 自建负面端 | 36f 可**纳入**争议事件作为负面指标 |
| **36f 自建 ESG 评级** | **工程指南（🟡）** | — |

**定位**：36f 是 36d/36e 的**方法论升级版**——36d/36e 是单因子/单维度自建，36f 教你**自建完整的多维 ESG 评级体系**（含议题选择、权重设置、打分方法、跨行业可比）。

### 1.3 不适合什么场景

- **追求现成选股绩效**：本策略无现成指增绩效，需自建回测验证
- **仅做单因子**：若只需股东责任或争议事件单因子，直接用 36d/36e 更简单
- **工程能力不足**：完整 ESG 评级需议题筛选+权重设计+多类型打分，工程量大

## 二、信号逻辑：自建 ESG 评级四大核心环节

光大自建方法论的四大核心环节，构成完整的"如何造一套 ESG 评分"答案：

```
自建 ESG 评级体系四大环节：
  │
  ├─ 环节 1：议题选择（四道筛选法）→ 选哪些指标
  │
  ├─ 环节 2：指标体系结构 → E/S/G 各几个二级议题
  │
  ├─ 环节 3：权重设置（两级法）→ 二级议题权重 + 四级指标 A/B/C
  │
  └─ 环节 4：打分方法（五大指标类型）→ 二元/强度/百分比/披露/分层
     └─ PS + DS 双分数 + 子行业可比性处理
```

### 2.1 环节 1：议题选择——四道筛选法

四道筛选从国际到国内、从通用到行业特有，逐层聚焦：

| 筛选道 | 内容 | 目的 |
|---|---|---|
| **第一道** | 筛国际 ESG 信息披露要求指标（以 **GRI/TCFD** 为基准）| 国际可比性，剔除不适用的国际指标 |
| **第二道** | 筛交易所 ESG 披露框架聚焦议题（**上交所/深交所/联交所**指引）| 找数据可获得的指标 |
| **第三道** | 筛涉及金融机构的 ESG 信息披露政策（《关于推动银行业和保险业高质量发展的指导意见》《金融机构环境信息披露指南》等）| 行业政策聚焦 |
| **第四道** | 从中国政策文件中筛金融业社会责任实质性议题（中国特色社会责任）| 中国国情（脱贫/乡村振兴/普惠金融）|

> 📖 [光大金工 2023.2](../../raw/articles/[202302161501]光大金工构建金融行业ESG评级体系议题选择权重设置如何更具子行业可比性E.md) 摘要："第一道筛选是筛选国际 ESG 信息披露要求的指标……第二道筛选是筛选交易所 ESG 披露框架的聚焦议题……第三道筛选是筛选涉及金融机构的 ESG 信息披露政策……第四道筛选是从中国的政策文件中筛选金融业社会责任实质性议题。"

**迁移到其他行业**：把第三道换成目标行业的政策文件（如制造业用《制造业绿色低碳转型行动方案》、采矿业用《绿色矿山建设规范》），第四道换成该行业的中国特色议题。

### 2.2 环节 2：指标体系结构（金融业案例）

光大金融业案例的 E/S/G 二级议题结构：

| 维度 | 二级议题数 | 议题清单 | 其中行业特有 |
|---|---|---|---|
| **环境 E** | **5 个** | 能耗管理 / 排放物 / **绿色金融** / 气候变化应对 / 环境管理 | 绿色金融 |
| **社会 S** | **8 个** | 供应链 / 相关者权益 / 员工 / 社区投资 / **服务实体经济** / **乡村振兴** / **普惠金融** / 服务其他国家战略 | 服务实体/乡村振兴/普惠金融 |
| **治理 G** | **4 个** | 治理 / **风险管理** / 董事会组成 / 合规经营 | 风险管理 |
| **合计** | **17 个** | — | **5 个金融业特有** |

> 📖 [光大金工 2023.2](../../raw/articles/[202302161501]光大金工构建金融行业ESG评级体系议题选择权重设置如何更具子行业可比性E.md) §4.1："环境方面，二级议题有 5 个……社会方面，二级议题有 8 个……治理方面，由治理、风险管理、董事会组成和合规经营 4 个二级议题构成"；"子行业在大部分议题上具有共同属性，但在**绿色金融、服务国家实体经济、助力乡村振兴、普惠金融和风险管理**上具有明显的行业特征。"

**5 个金融业特有议题**：绿色金融、服务实体经济、乡村振兴、普惠金融、风险管理——这 5 个是海外评级缺位的中国金融特色。

### 2.3 环节 3：权重设置——两级法

#### 二级议题权重（三角度 + 众数法）

从三个角度综合定权重，重要性汇总用**众数法**：

| 角度 | 权重判断标准 |
|---|---|
| **ESG 信息披露角度** | 定量 > 定性 > 无要求 |
| **社会责任角度** | 政策重点反复提及 > 提及过 > 未提及 |
| **公司和利益相关者角度** | 参考实质性分析矩阵 |

> 📖 [光大金工 2023.2](../../raw/articles/[202302161501]光大金工构建金融行业ESG评级体系议题选择权重设置如何更具子行业可比性E.md) §4.2.1："我们将从三个角度思考金融业 ESG 评级二级指标的权重大小，分别是：ESG 信息披露角度、社会责任角度、公司和利益相关者角度"；§4.2.2："在重要性汇总时，我们将采用**众数的方法**进行统计。"

#### 四级指标权重（A/B/C 三级，3:2:1）

| 级别 | 定义 | 权重 |
|---|---|---|
| **A 级** | 能很好衡量议题表现的**定量指标** | **3** |
| **B 级** | 不能很好衡量的定量指标 | **2** |
| **C 级** | **定性指标** | **1** |

**多角度衡量同一议题**：指标权重均分。

> 📖 [光大金工 2023.2](../../raw/articles/[202302161501]光大金工构建金融行业ESG评级体系议题选择权重设置如何更具子行业可比性E.md) §4.4："A级指标定义为能很好衡量议题表现的定量指标、B 级指标定义为不能很好的衡量议题表现的定量指标、C 级指标为定性指标"；"将四级指标按 A/B/C 级赋予 **3：2：1** 的权重"；"对多角度衡量同一议题的四级指标权重进行均分"。

### 2.4 环节 4：打分方法——五大指标类型差异化处理

不同类型的指标用不同的打分方法，这是光大方法论最有技术含量的部分：

| 指标类型 | 打分方法 | 示例 |
|---|---|---|
| **二元指标** | Y=10 分 / N=0 分（二元正面）；负面相反 | 是否设立 ESG 委员会 |
| **强度指标**（6 个）| **对数回归模型**（强度 vs 经营指标如营收/员工/绿色贷款余额取对数回归，真实值与预测值差值求标准差打分）| 总能耗/耗水/范畴 1·2 温室气体排放/减排 CO2/减排标准煤 |
| **百分比指标** | **Beta 分布累积分布函数**（调 α/β 使均值匹配，如拨备覆盖率全部减 150% 特殊处理）| 拨备覆盖率、不良贷款率 |
| **披露指标** | 定量披露 4/5 分、定性 2 分、未披露 0 分 | 各类披露项 |
| **分层指标** | 仅对极端表现赋低分 | 主观判断较强的绝对数值 |

> 📖 [光大金工 2023.2](../../raw/articles/[202302161501]光大金工构建金融行业ESG评级体系议题选择权重设置如何更具子行业可比性E.md) §5.1.1：二元"对于二元正面指标，Y（是）赋 10 分，N（否）赋 0 分"；强度"我们倾向于使用**对数回归模型**"；百分比"**Beta 分布的累积分布函数**可以很好地对百分比指标进行衡量"；披露"对定量披露的情况分别赋 4/5 分，对定性披露赋 2 分，未披露赋 0 分"；分层"仅对表现相对极端的情况赋予低分"。

**强度指标的对数回归法**（6 个：总能源消耗/耗水量/范畴 1·2 温室气体排放/减排 CO2 当量/减排标准煤当量）：
```
步骤 1：对同行业公司，用 log(强度指标) vs log(经营指标) 做回归
        例：log(总能耗) = α + β · log(营收) + ε
步骤 2：算每家公司的预测值 ŷ
步骤 3：真实值 y 与预测值 ŷ 的差值 = 残差
步骤 4：用残差求标准差，转百分制打分
        （残差越小 = 实际能耗低于预期 = 越环保 = 高分）
```

**百分比指标的 Beta 分布 CDF 法**：
```
步骤 1：对百分比指标（如拨备覆盖率），全部减去阈值（如 -150%）特殊处理
步骤 2：拟合 Beta 分布，调 α/β 使均值匹配实际分布
步骤 3：用 Beta 分布的累积分布函数（CDF）转百分制打分
        （CDF 值 = 该公司在分布中的百分位）
```

### 2.5 PS + DS 双分数（彭博方法论借鉴）

每个四级指标打**表现分数（PS）+ 披露分数（DS）**双分数，三级聚合时用 DS 修饰 PS：

| 分数 | 含义 | 作用 |
|---|---|---|
| **PS（Performance Score）** | 表现分数（实际指标值）| 核心打分 |
| **DS（Disclosure Score）** | 披露分数（是否披露/披露质量）| 修饰 PS |

**修饰规则**：
- **设上限（UL）**：鼓励更多披露（尤其 0 到 1 的披露），PS 上限受 DS 约束
- **设下限（DL）**：对定量表现差的指标补偿，PS 下限受 DS 兜底

> 📖 [光大金工 2023.2](../../raw/articles/[202302161501]光大金工构建金融行业ESG评级体系议题选择权重设置如何更具子行业可比性E.md) §5.1.1/5.1.2："借鉴彭博的方法论而引入披露分数的主要目的是为了使本评价体系更加合理，即对披露程度好的企业进行鼓励、对披露程度较差的企业评价结果进行调整"；"设置上限是为了鼓励企业进行更多披露尤其是从 0 到 1 的披露数据；设置下限是为了对定量数据表现较差的指标进行补偿"。

### 2.6 子行业可比性处理

为保证不同子行业（银行 vs 券商）评分可比：

| 方法 | 内容 | 目的 |
|---|---|---|
| **固定二级议题权重** | 优先固定二级议题权重（非四级）| 跨子行业可比 + 体系稳定性 |
| **模块化设计** | 共有指标 + 行业特有指标（特有指标集中在 5 大板块）| 灵活扩展 |
| **暂不做保险业** | 中信行业分类仅 6 家保险公司，数据可比性差 | 避免分数巨大波动 |

> 📖 [光大金工 2023.2](../../raw/articles/[202302161501]光大金工构建金融行业ESG评级体系议题选择权重设置如何更具子行业可比性E.md) 摘要："我们优先固定金融业 ESG 评级二级议题的权重，既有助于子行业评分的可比性，又方便以后持续扩容新指标"；§4.3："目前保险行业在 ESG 方面数据可比性较好的指标较少……加上中信行业分类中保险公司仅有 6 家，行业特有指标的分数可能会出现巨大波动"。

## 三、选股规则（自建评级后如何选股）

### 3.1 自建评级选股流程

```
年报披露季后（次年 4-5 月，全部年报披露完毕）：
  │
  ├─ 1. 对目标行业每家公司，按 §二 四大环节算 ESG 评级
  │   ├─ 议题选择（四道筛选，确定指标清单）
  │   ├─ 权重设置（二级三角度众数 + 四级 A/B/C 3:2:1）
  │   ├─ 打分（五大类型 + PS/DS 双分数）
  │   └─ 聚合到 E/S/G 三维 + 综合 ESG 评级
  │
  ├─ 2. 行业内按 ESG 评级排序
  │
  ├─ 3. 选 top（如行业前 30% 或前 10 只）
  │
  ├─ 4. 跨行业组合（如有多个行业）
  │   └─ 固定二级权重保证跨行业可比
  │
  └─ 5. 输出候选清单 → 次月开盘买入
```

### 3.2 硬过滤

| 过滤条件 | 阈值 | 作用 |
|---|---|---|
| 上市时间 | >2 年 | 家族共用 |
| ST | 剔除 | 通用 |
| 涨跌停 | 剔除 | 通用 |
| ESG 披露完整度 | DS 过低（如 <3）剔除 | 无披露无法打分 |

## 四、调仓与持仓

### 4.1 调仓频率

**年度调仓**（年报披露后）。数据更新频率：
- **年度更新**：年度报告、年度社会责任报告、环境信息披露报告
- **半年度更新**：债券承销发行数据、融资数据

**行业内等权**（top N）或**流通市值加权**。跨行业时固定二级权重保证可比。

## 六、绩效预期与可信度

### 6.1 原文打分结果（无选股绩效，仅排名）

光大对 **15 家银行 + 14 家券商**打分排序：

| 子行业 | ESG 均值 | 标准差 | 特征 | 排名居前 |
|---|---|---|---|---|
| **券商**（14 家）| **68.6** | **10.4** | "强者恒强、两极分化" | **中信建投、中信证券**（承销绿债/帮助绿色低碳企业融资突出）|
