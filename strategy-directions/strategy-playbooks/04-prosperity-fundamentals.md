## 一、策略本质：赚的是什么钱

"景气度"通俗说就是**一个企业或行业当前经营状况好不好、是在变好还是变差**。景气度投资就是**买经营状况正在改善的公司**，卖（或避开）经营状况恶化的公司。

**赚的是什么钱**：景气度向上的公司，盈利在加速增长（比如 ROE 逐季提升、营收增速加快），这种基本面改善会持续几个季度，而市场对这种改善的定价是渐进的、滞后的——所以你提前识别出"景气向上"的公司，就能吃到盈利增长 + 估值提升的"戴维斯双击"。

**核心证据（为什么这个方向值得做）**：

> **原文佐证**（开源金工 2021）："无论市场的牛熊震荡还是风格切换，**净利润增速越高的分组整体收益越高**。"
> 📖 [景气度研究：量化与主动的多视角](../../raw/articles/[202112241428]景气度研究量化与主动的多视角开源金工.md)

### 这个方向的两个层次

景气度策略分**两个应用层次**，下面配方都会覆盖：

| 层次 | 选什么 | 典型策略 |
|---|---|---|
| **个股层面** | 选景气向上的公司 | 广发"景气向上持续增长"、华安"盈利加速度" |
| **行业层面** | 选景气向上的行业 | 开源"复合景气度"、中银"估值泡沫保护的高景气" |

（行业层面的景气度轮动和 [02-行业轮动](02-industry-rotation.md) 有交叉，本篇聚焦"景气度这个因子本身怎么用"，行业轮动篇聚焦"多路径合成"。）

### 三个必须知道的关键认知

**① 景气度的"变化"比"高低"更重要**——一个行业从"很差"变"没那么差"，比一个本来就"很好"的行业更值得买。

> **原文佐证**（开源 2021）："景气度排名变化（而非绝对水平）是超额收益的主要来源，即**'景气改善幅度'比'景气绝对高低'更重要**。"

**② 历史景气 + 预期景气，合成才最强**——单看已公布的财报（历史）有滞后，单看分析师预期（未来）有偏差，两者合成效果最好。

> **原文佐证**（开源 2021）："综合历史景气度与预期景气度信号合成构建复合景气度指标，行业轮动效果显著提升，**因子 IC 达到 9.49%，ICIR 为 1.60**。"（单独的历史景气 IC 仅 5.52%，预期景气 IC 8.19%）

**③ 致命陷阱：高景气 + 高估值 = 泡沫**——纯追景气度不看估值，会在 2021 年抱团瓦解时栽大跟头。必须叠加估值保护。

> **原文佐证**（中银 2022）："原追高景气度行业轮动策略的超额收益实现显著增强，**策略年化超额收益接近 20%**。"（加了估值泡沫保护后）

## 三、策略配方

### 配方 A：个股——盈利加速度（华安，最巧妙的单因子）

> 来源：[📖 华安金工 成长因子再升级：盈利加速度](../../raw/articles/[202009221510]华安金工成长因子再升级盈利加速度基本面量化系列报告之二.md)（2020.9）

**一句话**：别看公司利润增长快不快，要看它**利润增长的加速度**（增速在加快还是放缓）。

**问题背景**：传统的"成长因子"（净利润同比增速）效果一般——

> **原文佐证**（华安 2020）："以归母净利润 TTM 同比增速为代表的传统成长因子效果一般……三个基础成长因子中，相对表现最好的是毛利润 TTM 同比增速因子，Rank IC 为 2.23%，年化 ICIR 为 1.27……**多头组合相对于基准的年化超额收益仅为 1.56%**，说明该因子的超额收益主要集中在空头。"

简单说：传统成长因子多头端几乎不赚钱，主要靠空头（避开差公司）。

**华安的创新——盈利加速度**：不直接用增速，而是用**增速的变化**（二阶导）。

```
盈利加速度 = 当期同比增速 − 去年同期同比增速
```

**直觉**：一家公司利润增速从 20% 提到 30%（加速度为正，在加速），比一家维持 30% 增速的（加速度为零，匀速）更值得关注——因为"加速"意味着基本面拐点，市场还没充分定价。

> **原文佐证**（华安 2020）："我们计算**业绩指标同比增速的同比变化作为盈利加速度因子**以反映企业历史业绩增速的趋势。"

**最优构造**：华安测了多种组合，最强的是 **OPER_PROFIT_EAV**（营业利润作基础指标 × 营业利润标准差作分母）：

> **原文佐证**："单因子测试结果表明加速度因子整体相对于传统成长因子的选股能力有较大的提升，其中 **OPER_PROFIT_EAV 因子表现最为出色，Rank IC 均值为 2.68%，年化 ICIR 为 2.30**，多头组相对市场等权组合的年化超额收益达 6.87%。"

**进阶——"稳健加速增长"模式**：当公司满足"当期和去年同比增速都为正，**且当期增速 > 去年同期增速**"时，选股效果最佳。据此构建的精选 50 策略：

> **原文佐证**："以此构建的**'稳健加速增长精选 50 策略'** 2009 年 1 月以来在全市场样本内相对中证全指的**年化超额收益约 17.64%**，仅在 2017 年跑输基准，其余年份均跑赢指数。"

#### 配方 A 操作流程

```
每月末盘后：
1. 拉单季度财务数据（东财 em_quarterly：营业利润、净利润、营收）
2. 算同比增速：g_t = (本季营业利润 − 去年同季) / |去年同季|
3. 算盈利加速度：EAV = g_t − g_{t-4}（当期增速 − 去年同期增速）
4. 标准化：EAV / 过去 8 季度营业利润的标准差
5. 筛"稳健加速增长"模式：g_t > 0 且 g_{t-4} > 0 且 g_t > g_{t-4}
6. 在筛选出的股票里取 EAV 最高的 50 只，等权持仓
7. 月频调仓
```

**预期表现**：精选 50 年化超额 17.64%（除 2017 年外年年跑赢）。

### 配方 B：个股——景气向上持续增长（广发，多维度精选）

> 来源：[📖 广发金工 如何挖掘景气向上持续增长企业](../../raw/articles/[202109122206]广发金融工程如何挖掘景气向上持续增长企业基本面量化策略.md)（2021.9）

**一句话**：用"盈利+成长"做核心，加上"质量+价值"做过滤，选出景气向上且能持续的好公司。

**核心选股维度**（广发给了完整的筛选逻辑）：

> **原文佐证**（广发 2021）："根据盈利与成长为选股核心变量，筛选出 **ROE 较高、具备 ROE 长期趋势向上、销售毛利率改善**以及**注重投入资产的现金回报率**，如**剔除现金流相对较差的个股**、考虑个股的资产质量及资产负债率，**剔除资产质量一般以及资产负债率过高的个股**，最后形成组合。"

拆成几个维度看：

| 维度 | 具体指标 | 在筛什么 |
|---|---|---|
| **盈利（核心）** | ROE 高 + ROE 长期趋势向上 | 赚钱能力强，而且在变强 |
| **成长（核心）** | 销售毛利率改善 | 主营业务在扩张 |
| **现金流（过滤）** | 投入资产现金回报率；剔除现金流差的 | 赚的是真钱不是账面利润 |
| **资产质量（过滤）** | 剔除资产负债率过高的 | 别是杠杆堆出来的 |

**预期表现**（广发 2021 跟踪报告，回测期较长）：

| 组合 | 年化收益 | 超额（vs 中证800）| IR | 平均持股 |
|---|---|---|---|---|
| 等权 | **30.32%** | **19.84%** | 1.45 | ~52 只 |
| 市值加权 | 28.39% | 17.97% | 1.31 | ~52 只 |

> **原文佐证**："在回测期内，基于等权重组合累计收益率为 2809.34%，**年化收益率为 30.32%**……其中等权重组合相对中证 800 **年化超额收益率为 19.84%**。"

#### 配方 B 操作流程

```
每期调仓（季频，跟随财报披露）：
1. 拉 ROE（绝对水平 + 近 4 季趋势）、销售毛利率（环比改善）
2. 拉现金流（投入资产现金回报率）、资产负债率、资产质量指标
3. 筛选：
   ├─ 核心：ROE 高 + 趋势向上 + 毛利率改善
   └─ 过滤：剔除现金流差 / 资产负债率过高 / 资产质量差
4. 取筛选后的股票等权持仓（约 50 只）
5. 季频调仓（财报披露后更新）
```

### 配方 C：行业——复合景气度（开源，历史+预期合成）

> 来源：[📖 开源金工 景气度研究：量化与主动的多视角](../../raw/articles/[202112241428]景气度研究量化与主动的多视角开源金工.md)（2021.12）

**一句话**：把"已公布的财报"（历史景气）和"分析师预期变化"（预期景气）合成，得到最强的行业景气度信号。

#### 历史景气度（捕捉盈余动量）

**核心思想**：用已公布的财报数据（含业绩预告/快报补时效），聚合到行业层，捕捉"盈余动量"。

**怎么高频化**（关键技巧）：财报是季度的，但开源金工把它变成日频信号——

> **原文佐证**（开源 2021）："每当有成分股披露最新财报，其盈利信息就会体现在行业指标上，因此高频化聚合反映了行业短期的盈利变化。"

> 💡 **数据优先级**："以最新报告期优先、信息确定性优先的原则选用最新可获取的财务数据。即每日使用最新报告期财务数据，在相同报告期下，**优先使用定期报告、其次使用业绩快报、最后使用业绩预告**。"

**三个财务指标等权合成**：

> **原文佐证**："三个财务指标中**净利润 TTM 环比指标表现最强，IC 为 5.29%，ICIR 为 1.024**。进一步我们将三个指标等权合成为复合财报指标，该指标 **IC 提升至 5.52%，ICIR 为 1.054**。"

效果：高景气组年化 17.2%，低景气组 5.5%，多空 11.1%/IR 1.324。

#### 预期景气度（捕捉戴维斯双击）

**核心思想**：分析师上调业绩预期 → 盈利预期改善 + 估值支撑增强 = 戴维斯双击。

**三个关键发现**：

> **原文佐证**："（1）分析师预期绝对水平横向比较不是核心定价因素，**预期的边际变化才是核心定价因素**；（2）短期（FY1）分析师预期比长期分析师预期数据更有效；（3）分析师未覆盖个股在行业中位数填补缺失值后合成行业景气指标效果更稳定。"

⚠️ **注意一个和 [03-分析师预期](03-analyst-expectation.md) 矛盾的点**：开源这篇说"FY1 比长期更有效"，而中银行业轮动报告说"F3>F2>F1"。这个分歧的原因可能是**应用场景不同**（个股选股 vs 行业轮动）+ **数据处理不同**（开源用规模加权，中银用等权）。建议你在自己回测里两种都试。

**聚合方式**（和历史景气不同）：

> **原文佐证**："与历史财务基本面指标的等权聚合方式不同，分析师对大市值的龙头股跟踪更紧密、覆盖度更高，且行业未来的盈利状况更多受行业龙头股影响，因此**分析师预期采用规模进行加权聚合**更为合理。"

效果：复合预期指标 IC **8.19%**（比历史景气的 5.52% 更强）。

#### 合成：历史 + 预期

两者等权合成：

> **原文佐证**："综合历史景气度与预期景气度信号合成构建复合景气度指标，行业轮动效果显著提升，**因子 IC 达到 9.49%，ICIR 为 1.60，IC 胜率达 70%。在行业五分组下，高景气组的年化收益 20.2%，低景气组的年化收益 1.1%，多空年化收益 19.2%，信息比率达 1.62**。"

#### 配方 C 操作流程

```
每月末盘后：
1. 历史景气度（按行业等权聚合）：
   ├─ 每日取成分股最新可获取财报（定期>快报>预告）
   ├─ 算净利润TTM环比、营收TTM环比、ROE变化
   └─ 三指标等权合成复合财报指标（IC 5.52%）
2. 预期景气度（按行业规模加权聚合）：
   ├─ 取分析师一致预期（FY1 优先）的边际变化
   ├─ 未覆盖个股用行业中位数填补
   └─ 规模加权聚合到行业（IC 8.19%）
3. 合成：历史景气 + 预期景气 等权（IC 9.49%）
4. 行业五分组，选高景气组（年化 20.2%）
5. ETF 落地，月频调仓
```

### 配方 D：行业——估值泡沫保护的高景气（中银，加风控）

> 来源：[📖 中银量化 规避估值泡沫的高景气行业轮动策略](../../raw/articles/[202208101221]重磅深度规避估值泡沫的高景气行业轮动策略中银量化行业轮动深度五.md)（2022.8）

**一句话**：在配方 C 的高景气基础上，再用"剩余收益模型"算出每个行业的"估值泡沫"，剔除泡沫大的——这样就不会在抱团顶部接盘。

**问题背景**：纯高景气策略在 2021 年抱团瓦解时回撤巨大，因为"高景气"的行业往往已经被炒到高估值。

**中银的解法——测算"绝对估值泡沫 AVB"**：

用三阶段剩余收益模型（基于 DCF），结合分析师未来 3 年 ROE 预期，算出每个行业的"公允估值"，再和当前市价对比：

> **原文佐证**（中银 2022）："基于未来三年各中信一级行业分析师一致预期 ROE、预期净资产及各行业股东要求回报率，我们可以得到各行业的'公允估值'（VB）。而后基于各行业的公允估值，进一步对比市场价格并测算标的'**绝对估值泡沫**'（Absolute Value Bubble，AVB），**当行业公允价值高于其同时刻价格时（即 AVB 为负时），行业处于被低估的状态，反之则被高估**。"

**三种典型行业特征**（很有洞察）：

> **原文佐证**："估值泡沫围绕零均值回复行业：如煤炭、汽车；估值长期存在高泡沫行业：如电力设备及新能源、计算机、电子、医药；估值长期处于低估行业：如银行、地产（2017 年后）。"

**策略效果**：在高景气轮动基础上叠加估值泡沫保护——

> **原文佐证**："原追高景气度行业轮动策略的超额收益实现显著增强，**策略年化超额收益接近 20%**。"

| **层次** | 个股 | 个股 | 行业 | 行业 |
| **核心** | 增速的二阶导 | ROE+毛利率+现金流 | 历史+预期合成 | 高景气+估值泡沫剔除 |
| **年化超额** | 17.64% | **19.84%** | 多空 19.2% | **~20%** |
| **复杂度** | 低 | 中 | 中 | 高（需剩余收益模型）|
| **适合** | 入门单因子 | 个股精选 | 行业轮动 | 想控回撤 |

## 四、落地到 QMT（完整执行流程）

**信号频率**：个股版季频（跟随财报），行业版月频
**持仓周期**：季度到半年（景气半衰期 2-4 个月）
**QMT 用法**：**盘后批量**

```
【个股版（配方 A/B）】每季财报披露后：
1. 拉单季度财务（东财 em_quarterly：营业利润/净利润/营收/ROE/毛利率/现金流/资产负债率）
2. 按配方算因子：
   ├─ A：盈利加速度 EAV = 当期增速 − 去年同期增速，标准化
   └─ B：ROE水平+趋势 + 毛利率改善 + 现金流过滤 + 资产质量过滤
3. 筛选 + 排序，取前 50 只
4. 等权持仓，季频调仓

【行业版（配方 C/D）】每月末：
1. 历史景气：成分股最新财报等权聚合到行业 → 复合财报指标
2. 预期景气：分析师一致预期边际变化，规模加权聚合到行业
3. 合成复合景气度（IC 9.49%）
4.（配方D）算各行业估值泡沫 AVB，剔除高泡沫行业
5. 选高景气行业，ETF 落地，月频调仓
```

## 六、关键风险与机构间分歧（照着避坑）

| 风险点 | 说明 | 来源 |
|---|---|---|
| **高景气+高估值=泡沫** | 纯追景气不看估值，2021 抱团瓦解时栽大跟头。必须加估值保护（配方 D）| 中银 2022 |
| **分析师预期拐点滞后** | 盈利拐点处一致预期往往滞后，过度依赖预期指标会在拐点回撤 | 行业景气度综合分析 |
| **FY1 vs F3 分歧** | 开源说 FY1 更有效（规模加权），中银说 F3>F2>F1（等权）。场景/数据处理不同，回测两种都试 | 开源 2021 vs 中银 2021 |
| **景气半衰期 2-4 月** | 信号有时效，过期信号不仅无效甚至反向。月频调仓别拖 | 行业景气度综合分析 |
| **传统成长因子多头不赚钱** | 净利润同比增速因子超额主要在空头，要用"加速度"改进 | 华安 2020 |
| **周期股景气择时易踩"低估值陷阱"** | 景气下行期估值便宜但业绩持续恶化，不能光看估值低就买 | 上游周期板块择时 |
| **板块特异性** | 上游周期看 PPI/库存，消费看 CPI-PPI 剪刀差，TMT 缺高频前瞻指标。统一框架不如板块定制 | 行业景气度综合分析 |
