## 一、策略本质：赚的是什么钱

"风格"是指股票的某种共同特征——最经典的两对是**成长 vs 价值**（高成长股 vs 低估值股）和**大盘 vs 小盘**（大市值 vs 小市值）。风格轮动就是**判断接下来哪类风格会占优，提前切换配置**。

**赚的是什么钱**：A 股不同风格的相对强弱会周期性切换——某几年成长股碾压价值股（如 2019-2020 核心资产），某几年又反过来（如 2021 抱团瓦解后价值回归）。如果你能判断切换的拐点，在成长强时配成长、价值强时配价值，就能吃到风格切换的巨大价差。

**为什么风格会"凝结成隐形力量"**：

> **原文佐证**（招商定量 2024）："一方面，风格本身代表着一批具有某一共同特征的个股……特定的宏观环境，可能会导致某一特征的个股出现普遍受益的情况。另一方面，形成共同趋势的股票组合将会受到'共识'的正反馈影响机制……投资者们会本能地将这些股票打上一个相同的标签，并且在交易时无意间形成正反馈。"
> 📖 [如何从赔率和胜率看成长价值轮动](../../raw/articles/[202409030800]招商定量深度报告巡礼之九如何从赔率和胜率看成长价值轮动.md)

### A 股风格轮动的三个关键认知

**① 成长/价值轮动是主旋律，大盘/小盘轮动特征不明显**：

> **原文佐证**（开源金工 2021）："借鉴海外研究经验，我们可以做出大胆推论：**未来 A 股大盘小盘轮动特征并不明显，而成长价值风格轮动是市场的主旋律**。"
> 📖 [A股风格轮动规律认知与策略实践](../../raw/articles/[202107040902]A股风格轮动规律认知与策略实践开源金工.md)

**② A 股一轮成长价值周期约 5-7 年，每次持续 2-4 年**：

> **原文佐证**（开源 2021）："A 股自 2006 年以来共出现过 6 次成长价值的风格切换，**每次风格持续 2-4 年不等。通过频谱分析估算 A 股市场的一轮成长价值周期约为 5.1 年~7.7 年之间**。"

**③ 行业即风格**——这是开源金工最重要的洞察：

> **原文佐证**（开源 2021）："**行业的风格贡献是市场风格的核心驱动力**。具体从行业的风格贡献看，2019 年之前较弱，而在 2019 年之后，成长超额显著走强，价值超额走弱。"

也就是说：A 股的"成长 vs 价值"本质上是"成长性行业 vs 价值性行业"的轮动。所以风格轮动和 [02-行业轮动](02-industry-rotation.md) 高度相关——可以一体化做。

## 三、策略配方

### 配方 A：赔率-胜率框架（招商，最完整可执行）

> 来源：[📖 招商定量 如何从赔率和胜率看成长价值轮动](../../raw/articles/[202409030800]招商定量深度报告巡礼之九如何从赔率和胜率看成长价值轮动.md)（2024.9）

**一句话**：用"赔率"（估值便宜程度）和"胜率"（宏观+微观支持力度）两个维度，判断该配成长还是价值。

#### 赔率维度（用估值定）

**核心假设**：风格估值越高，赔率越低（已经是"强弩之末"）；估值越低，赔率越高（"价值洼地"）。

> **原文佐证**（招商 2024）："我们根据逻辑推演得到了一个假设，**市场风格的估值水平与投资赔率呈负相关**。即高估值水平的市场风格已经是'强弩之末'，而低估值水平的市场风格往往是'价值洼地'。"

**赔率怎么算**：一段收益率序列的赔率 = 平均正收益 / |平均负收益|。赔率 > 1 表示押对赚得多于押错亏的。

#### 胜率维度（5 宏观 + 3 微观因素）

> **原文佐证**："在胜率方面，我们基于**五个宏观因素（十年国债收益率、六个月美债收益率、PMI、中长期贷款余额、CPI-PPI 剪刀差）、三个微观因素（动量、强势股占比、北向资金）**对成长/价值的轮动进行了分析。并根据复合指标得到一个相对有效的胜率信号模型。"

**这些因素的直觉**：
- **十年国债收益率 ↓** → 流动性宽松 → 成长占优（成长股久期长，对利率敏感）
- **PMI ↑** → 经济向好 → 风险偏好升 → 成长占优
- **CPI-PPI 剪刀差** → 反映利润在上下游分配，影响不同风格
- **北向资金流入** → 外资偏好 → 往往利好成长/大盘

#### 合成：条件赔率 + 条件胜率

> **原文佐证**："在时间截面上，根据估值水平、宏观因素和微观因素得到成长/价值的**条件胜率和条件赔率估计**。在推导得到市场风格的投资期望之后，通过比较投资期望进而构建得到了一个具有稳健收益的市场风格轮动模型。"

**效果**：

> **原文佐证**："根据测试结果，模型可获得**年化收益 32.09%，夏普比率 1.20，相对市场等权年化超额收益为 16.85%**，相对价值成长等权组合的年化超额收益为 10.84%。"

#### 配方 A 操作流程

```
每月末盘后：
1. 赔率维度：
   ├─ 算成长风格指数 / 价值风格指数的估值分位
   └─ 估值低的 → 赔率高（更有吸引力）
2. 胜率维度（8 因子打分）：
   ├─ 宏观（5）：十年国债收益率、六个月美债收益率、PMI、中长贷余额、CPI-PPI剪刀差
   └─ 微观（3）：风格动量、强势股占比、北向资金流向
   → 合成胜率信号（支持成长还是价值）
3. 合成：比较成长 vs 价值 的（赔率 × 胜率）期望值
4. 配置期望值高的风格（用成长ETF/价值ETF落地）
5. 月频调仓
```

### 配方 B：PB-ROE 行业风格划分（开源，行业即风格）

> 来源：[📖 开源金工 A股风格轮动规律认知与策略实践](../../raw/articles/[202107040902]A股风格轮动规律认知与策略实践开源金工.md)（2021.7）

**一句话**：既然"行业即风格"，那就在 PB-ROE 框架下给每个行业打"成长/价值"标签，再用行业轮动信号驱动风格切换。

**PB-ROE 框架**：
- **PB（市净率）**：衡量估值贵不贵
- **ROE（净资产收益率）**：衡量盈利能力强不强

把行业画在 PB-ROE 坐标系里——**高 ROE + 低 PB = 价值洼地；高 ROE + 高 PB = 成长溢价**。动态划分每个行业当前是偏成长还是偏价值。

> **原文佐证**（开源 2021）："在 PB-ROE 的框架下计算行业的成长、价值分类，以行业轮动信号为基础，构建风格轮动判断。"

**效果**：

> **原文佐证**："自 2015 年以来，利用国证风格指数进行风格轮动，组合的**多空年化收益 15.6%，信息比率 1.22，月度胜率为 64.9%，盈亏比 1.34**。"

> 💡 这条线和 [02-行业轮动](02-industry-rotation.md) 的宏观路径（板块配置轮盘）天然一体化——宏观象限同时给行业和风格信号。

### 配方 C：大小盘三维预判（方正，龙虎榜左侧信号）

> 来源：[📖 方正金工 多维度解析大小盘风格轮动](../../raw/articles/[201911061941]方正金工多维度解析大小盘风格轮动市场风格研判系列1.md)（2019.11）

**一句话**：虽然大盘小盘轮动不如成长价值明显，但用三维信号（技术+资金+基本面）仍可预判，尤其龙虎榜信号有"左侧"特性。

**三个维度**：
- **技术面**：动量/趋势
- **资金面**：龙虎榜活跃度（小资金活跃 → 小盘占优）
- **基本面**：市值因子的基本面驱动

**龙虎榜信号的独特价值**：

> **原文佐证**（方正 2019）："市场小规模资金更加青睐小市值股票，而通过龙虎榜数据的分析则能够间接揭示此类资金的活跃程度，从而判断大小盘强弱。基于此构建的信号在 2013-2019 获得了 **65.79% 的胜率，在 2017 年之后获得了 77.78% 的胜率**。**多空对冲年化收益 22.43%，收益回撤比 1.957**。"
>
> "另外，此信号展现了更多的'**左侧**'特性，能够预判拐点……一方面意味着其能与市场上绝大部分'右侧'信号互补性配合。"

#### 配方对比

| | 配方 A 赔率胜率 | 配方 B PB-ROE 行业 | 配方 C 大小盘三维 |
|---|---|---|---|
| **风格对** | 成长/价值 | 成长/价值（行业层）| 大盘/小盘 |
| **年化** | **32.09%** | 多空 15.6% | 多空 22.43% |
| **胜率** | — | 64.9% | **77.78%**（2017后）|
| **信号** | 5宏观+3微观+估值 | PB-ROE+行业轮动 | 技术+龙虎榜+基本面 |
| **特色** | 最完整框架 | 与行业轮动一体化 | 龙虎榜左侧信号 |
| **适合** | 主力 | 行业派 | 大小盘择时 |

## 四、落地到 QMT（完整执行流程）

**信号频率**：月频（宏观+估值慢变量）
**持仓周期**：季度到半年（风格切换周期 2-4 年，但月频跟踪拐点）
**QMT 用法**：**盘后批量**，用成长/价值 ETF 或大小盘 ETF 落地

```
每月末盘后（配方 A 为主线）：
1. 赔率维度：
   ├─ 算国证成长/国证价值指数的估值分位（PB/PE 历史分位）
   └─ 估值低的一方赔率高
2. 胜率维度（8 因子）：
   ├─ 宏观：十年国债收益率、美债6月、PMI、中长贷、CPI-PPI剪刀差（akshare/金十）
   └─ 微观：风格动量、强势股占比、北向资金流向
   → 合成胜率（支持成长还是价值）
3. 决策：比较成长 vs 价值 的（赔率 × 胜率）
   ├─ 高胜率+高赔率 → 重配该风格
   ├─ 信号矛盾 → 等权/观望
   └─ 政策打断（如重大监管）→ 人工干预
4. 落地：成长ETF / 价值ETF / 大盘ETF / 小盘ETF
5. 月频调仓

（配方 B/C 作为辅助信号交叉验证）
```

## 六、关键风险与机构间分歧（照着避坑）

| 风险点 | 说明 | 来源 |
|---|---|---|
| **估值回归 vs 动量延续分歧** | 估值极致分化后必然回归？还是流动性宽松下可长期维持？低估值非切换充分条件 | 综合分析 |
| **宏观 vs 微观优先级之争** | 宏观定大方向但滞后；微观（个股分化度）领先但噪声大。需结合 | 综合分析 |
| **信号冲突** | 同一时点不同因子可能指向相反方向。赔率胜率框架用乘积解决，但参数有主观性 | 综合分析 |
| **周期嵌套复杂** | 中周期（8-10年）和短周期（3-4年）叠加，短周期成长占优可能在中周期价值占优的大背景里 | 综合分析 |
| **政策敏感性** | 监管/产业政策可短期打破因子规律（如教育"双减"）。需预留政策打断机制 | 综合分析 |
| **风格纯度** | 国证成长/价值指数受市值加权影响，不够纯粹。招商用个股因子合成更纯 | 招商 2024 |
| **大盘小盘不如成长价值明显** | 大小盘轮动特征不明显，重心应放成长价值 | 开源 2021 |
| **因子衰减** | 量化参与增多，已知风格信号可能衰减，需动态评估 | 综合分析 |
