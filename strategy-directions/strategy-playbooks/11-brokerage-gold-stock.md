## 一、策略本质：赚的是什么钱

每月各券商会发布自己的"金股组合"（推荐的本月重点股票），这是分析师**融合行业判断、选股择时后的精华观点**。券商金股策略就是**跟踪这些金股名单，从中提取 alpha**。

**赚的是什么钱**：金股是卖方分析师精挑细选的"精华"，本身质量高。但金股池里的股票并非个个都好——通过量化手段在金股池里进一步筛选/优化权重，能"青出于蓝而胜于蓝"。

> **原文佐证**（开源金工 2021）："金股组合月度对外披露，是分析师融合行业风格选择、选股择时后的精华观点。本文基于量化拥抱主动的基本思想，以金股组合作为基本面股票池，构建'金股+'量化组合，实现**青出于蓝而胜于蓝**的增强效果。"
> 📖 [如何构建金股组合](../../raw/articles/[202104261539]如何构建金股组合开源金工.md)

### 金股池内部的两个关键划分

**① 新进金股 vs 重复金股**（最重要的洞察）：

> **原文佐证**（开源 2021）："新进金股整体市值低于重复金股，重复金股抱团水平高于新进金股。**新进金股的风格偏向中等市值、抱团程度低的相对冷门股，重复金股的风格偏向大市值、抱团程度较高的相对热门股**。"

这两类金股适合**完全不同的因子**（见配方 B）。

**② 多家推荐 vs 单家推荐**：

> **原文佐证**："**多家推荐金股组合年化收益率 18.2%，单家推荐金股组合年化收益率 13.2%**。"（多家券商同时推荐的更好）

## 三、策略配方

### 配方 A：金股池 + 多家推荐（最简版）

> 来源：[📖 开源金工 如何构建金股组合](../../raw/articles/[202104261539]如何构建金股组合开源金工.md)

**一句话**：跟踪券商金股名单，优先选多家券商同时推荐的。

**操作**：
```
每月初：
1. 拉各券商当月金股名单（akshare/东财，🔵 需爬或免费源）
2. 统计每只股票被几家券商推荐
3. 优先选多家推荐（≥2家）的金股
4. 等权持仓，月初建仓，月频调仓
```

> ⚠️ **及时性很重要**：开源金工发现"随着组合调仓时点的逐渐提前，金股组合收益表现逐渐提升"——越早拿到金股名单越好。金股月初就披露，要尽快建仓。

**预期表现**：多家推荐组合年化 18.2%。

---

### 配方 B：新进/重复金股差异化优化（进阶，最强）

> 来源：[📖 开源金工 券商金股的内部收益结构](../../raw/articles/[202109010745]券商金股的内部收益结构开源金工.md)

**核心洞察**：新进金股和重复金股适合完全不同的因子——

| 金股类型 | 特征 | 适合的因子 | 原因 |
|---|---|---|---|
| **新进金股** | 中等市值、低抱团、冷门 | 聪明钱、理想振幅、**分析师预期** | 冷门股信息未扩散，信息发现类因子有效 |
| **重复金股** | 大市值、高抱团、热门 | **长端动量**、**大单资金流** | 热门股机构共识，趋势+资金类因子有效 |

> **原文佐证**（开源 2021）："聪明钱因子、理想振幅因子在新进金股中选股效果显著，长端动量因子、大单资金流强度在重复金股中选股效果显著，**分析师预期因子在新进金股中的选股效果明显优于重复金股**（ICIR 1.42 vs 0.39）。"

**差异化优化方案**：

> **原文佐证**："新进金股……选择聪明钱因子、理想振幅因子和分析师预期因子，按照过去 12 个月因子 ICIR 作为权重，加权得到合成因子……**优化后新进金股组合年化收益率提升至 41.3%，收益波动比提升为 1.73**。"
>
> "重复金股……选择长端动量因子、大单资金流强度因子和分析师预期因子……**优化后重复金股组合年化收益率提升至 34.6%，收益波动比提升为 1.34**。"

#### 配方 B 操作流程

```
每月初：
1. 拉券商金股名单，划分：
   ├─ 新进金股（本月新进入名单的）
   └─ 重复金股（上月已在名单的）
2. 新进金股池内：
   ├─ 算聪明钱因子 + 理想振幅 + 分析师预期（FYR）
   ├─ 按过去12月ICIR加权合成
   └─ 取合成得分最高的，权重优化
3. 重复金股池内：
   ├─ 算长端动量 + 大单资金流强度 + 分析师预期
   ├─ 按ICIR加权合成
   └─ 取合成得分最高的，权重优化
4. 两池合并（可等权或按规模分配）
5. 月初第1交易日建仓，月频调仓
```

**预期表现**：新进金股优化年化 41.3%，重复金股优化 34.6%。

---

### 配方 C：行业金股 + 六维评价（进阶）

> 来源：[📖 开源金工 券商行业金股组合的alpha挖掘](../../raw/articles/[202208111630]券商行业金股组合的alpha挖掘开源金工.md) + [📖 六维评价体系](../../raw/articles/[202207082012]券商金股的六维评价体系开源金工.md)

**行业金股**：券商除了推荐个股金股，还会推荐"行业金股"（看好的行业）。行业金股组合年化 15.3%，优于十大金股组合 7.3%。

**六维评价体系**：从六个维度系统评价金股质量（收益、胜率、行业景气、因子匹配等），用于筛选优质金股。

#### 配方对比

| | 配方 A 多家推荐 | 配方 B 新进/重复优化 | 配方 C 行业金股 |
|---|---|---|---|
| **复杂度** | 低 | 高 | 中 |
| **年化** | 18.2% | 新进**41.3%**/重复**34.6%** | 15.3% |
| **核心** | 多家推荐 | 差异化因子 | 行业维度 |
| **适合** | 入门 | 主力 | 行业派 |

## 四、落地到 QMT（完整执行流程）

**信号频率**：月频（金股月初披露）
**持仓周期**：月度
**QMT 用法**：**月初批量建仓**

```
每月初：
1. 拉各券商当月金股名单（akshare/东财）
2.（配方A）筛多家推荐（≥2家）
3.（配方B）划分新进/重复：
   ├─ 新进池：聪明钱+理想振幅+FYR，ICIR加权合成，权重优化
   └─ 重复池：长端动量+大单资金流+FYR，ICIR加权合成，权重优化
4.（配方C）叠加行业金股/六维评价筛选
5. 合并目标清单
6. 月初第1交易日开盘批量建仓（越早越好），月频调仓
```

## 六、关键风险与机构间分歧（照着避坑）

| 风险点 | 说明 | 来源 |
|---|---|---|
| **金股名单获取及时性** | 越早拿到收益越好，延迟建仓损失大 | 开源 2021 |
| **新进/重复因子不通用** | 新进金股的分析师因子 ICIR 1.42，重复仅 0.39。不能一刀切 | 开源 2021 |
| **历史推荐效果好≠当月好** | "分析师历史推荐效果越好，其当月金股表现并没有最好"，稳健的中间组最好（年化25.5%）| 开源 2021 |
| **金股池受关注度上升影响** | 2019-2020 是金股超额主要来源，随关注度上升 alpha 可能衰减 | 开源 2021 |
| **数据源稳定性** | 金股名单依赖爬虫/免费源，需保证稳定获取 | — |
