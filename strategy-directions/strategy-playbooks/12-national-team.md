## 一、策略本质：赚的是什么钱

"国家队"是指**代表国家意志、稳定资本市场的几大资金主体**——中央汇金、证金、社保基金等。它们在股市低迷时入场护盘，在高位前离场。国家队策略就是**跟踪国家队的持仓与动向**，跟着"国家聪明钱"走。

**赚的是什么钱**：国家队有独特的**逆向投资**特征——"股市低位入场、先于高位离场"。这与北向资金、普通机构的行为逻辑都不同。跟随国家队入场，等于在市场底部区域建仓，胜率高。

> **原文佐证**（中银量化 2024）："国家队资金往往在股市低迷行情中以稳定市场为目的入场护盘，**跟随增量资金买入股票往往能够获得超额收益**；而在其他时期，国家队往往没有大额增量资金入场，以存量配置为主或者逐步退出。"
> 📖 [如何追踪国家队构建股票优选组合](../../raw/articles/[202408200956]如何追踪国家队构建股票优选组合中银量化多因子选股系列专题.md)

### 国家队的六大主体

> **原文佐证**："从国家队主体看，最早可追溯到 2000 年成立的**全国社保基金**，后来**中央汇金**在 2008 年金融危机时期积极介入……随后**国新投资**、**外管局投资平台梧桐树**和**国家集成电路产业基金**等平台相继成立，国家队开始以更加多元化和分工更加明确的主体参与资本市场投资建设。"

| 主体 | 角色 |
|---|---|
| **中央汇金** | 主力，控股大行 |
| **证金公司** | 2015 股灾救市主力 |
| **全国社保基金** | 最早（2000），长期配置 |
| **外管局梧桐树** | 外汇储备投资平台 |
| **国新投资** | 国资运营 |
| **集成电路产业基金** | 产业战略投资 |

### 两个关键认知

**① 国家队的逆向特征（核心 alpha 来源）**：

> **原文佐证**："国家队资金强度变化与中证 800 **负相关**，整体呈现为**在股市低位入场，先于高位离场**。" 且"自 2021 年初至今，国家队持股稳定跑赢中证 800 指数及基金重仓指数"。

**② 数据完全公开可得**：

> **原文佐证**："由于无法获知国家队的具体持仓数据，我们**从各上市公司的年报、半年报及季报披露的'十大股东'及'十大非限售股东'信息中提取**国家队机构的部分持股信息。"

也就是说——国家队持仓从上市公司季报的"十大股东"里就能提取，**完全免费公开**，是个人投资者能拿到的独特"聪明钱"信号，且与北向/机构调研低相关。

## 三、策略配方

### 配方：国家队择时 + 三因子选股（中银完整方案）

> 来源：[📖 中银量化 如何追踪国家队构建股票优选组合](../../raw/articles/[202408200956]如何追踪国家队构建股票优选组合中银量化多因子选股系列专题.md)

**一句话**：先用"市值比 Z-score"判断国家队是否在入场，入场期跟它的增量买入，非入场期跟它的存量重仓。

#### 第一步：从季报提取国家队持仓

> **原文佐证**："Step 1：确定可以判定为国家队的机构的主体名称范围……Step 2：从所有上市公司披露的'十大股东情况'中，筛选属于国家队的机构，并提取'持股数量'……Step 3：从'十大非限售股东情况'中补充提取……Step 4：整理合并后的数据，得到国家队持有各股票的非限售股股数的面板数据。"

**数据流程**：
```
每季财报披露后：
1. 拉全市场上市公司"十大股东"和"十大非限售股东"
2. 筛选国家队主体（汇金/证金/社保/外管局/国新/集成电路基金）
3. 提取持股数量、非限售持股
4. 合并 → 国家队各股票持仓面板数据
```

#### 第二步：国家队入场择时（市值比 Z-score）

**核心指标**：国家队市值比 Z-score，衡量国家队资金强度的变化。

> **原文佐证**："引入市值比 Z-score 用来衡量国家队资金强度变化，**滚动计算该指标的斜率作为择时指标**。将**斜率大于 0 定义为国家队资金入场时期**；斜率小于等于 0 定义为其他时期。"

**直觉**：国家队持股市值占比在快速上升（斜率>0）= 它在大举买入护盘 = 入场期，这时候跟它买超额收益高。

#### 第三步：三因子选股（入场期 vs 其他期差异化）

中银构建了三个因子，根据是否入场期差异化使用：

| 因子 | 衡量什么 | 何时用 |
|---|---|---|
| **因子1：持仓变动** | 国家队买入市值变动（增量）| **入场期**用 |
| **因子2：股价空间** | 有基本面支撑的股价反转（潜在空间）| 两期都用 |
| **因子3：持仓市值** | 国家队持仓市值（存量）| **其他期**用 |

> **原文佐证**："在国家队入场时期，通过**因子1 与因子2 等权复合**，优选国家队买入、未来股价空间大的股票；在其他时期，通过**因子2 与因子3 等权复合**，优选国家队存量配置中当前持仓少、未来安全边际较高的股票。"

**差异化逻辑**：
- **入场期**：国家队在大举买入，跟它的"增量"（因子1）+ 有上涨空间的（因子2）
- **其他期**：国家队没怎么动，看它的"存量重仓"（因子3）+ 安全边际高的（因子2）

#### 完整操作流程

```
每季财报披露后：
1. 提取国家队持仓（十大股东筛选）
2. 算市值比 Z-score 的滚动斜率：
   ├─ 斜率 > 0 → 入场期
   └─ 斜率 ≤ 0 → 其他期
3. 算三因子：
   ├─ 因子1：国家队买入市值变动
   ├─ 因子2：股价空间（基本面支撑的反转）
   └─ 因子3：国家队持仓市值
4. 分期选股：
   ├─ 入场期：因子1 + 因子2 等权，选国家队买入+空间大的
   └─ 其他期：因子2 + 因子3 等权，选存量重仓+安全边际高的
5. 构建组合，每年三次换仓
```

**预期表现**：较沪深300 年化超额 9.9%，中证500 超额 10.8%，万得全A 超额 10.4%。换手率低（每年三次）。

## 四、落地到 QMT

**信号频率**：季频（跟随财报披露）+ 择时信号更新
**持仓周期**：季度（每年三次换仓）
**QMT 用法**：**盘后批量**

```
每季财报披露后盘后：
1. 拉十大股东数据，提取国家队持仓
2. 算市值比 Z-score 斜率，判断入场期/其他期
3. 三因子计算 + 分期等权复合
4. 选股 → 目标清单
5. 次日批量建仓，季频调仓
```

## 五、这个策略需要什么数据

| 数据 | 用途 | 来源 | 门槛 |
|---|---|---|---|
| 上市公司十大股东/十大非限售股东 | 提取国家队持仓 | 东财（季报披露）| ✅ 已有 |
| 国家队主体名称范围 | 识别国家队 | 中银报告给了清单 | ✅ |
| 股价 + 基本面（算股价空间因子）| 因子2 | 东财 | ✅ |
| 宽基指数（择时基准）| Z-score | QMT/东财 | ✅ |

## 六、关键风险与避坑

| 风险点 | 说明 | 来源 |
|---|---|---|
| **持仓数据滞后** | 十大股东季报才披露，国家队动向有滞后。结合其他高频信号 | 中银 2024 |
| **非重仓股不可见** | 十大股东只能看前十大，国家队非重仓的持股看不到 | 中银 2024 |
| **入场期判断有延迟** | Z-score 斜率是滚动计算，确认入场期可能滞后于实际入场 | — |
| **超额相对温和** | 年化超额 ~10%，不如 PEAD/超预期（40%+）。但稳健、低换手 | 中银 2024 |
| **与北向低相关是优点** | 国家队和北向资金逻辑不同，两者组合能分散 | 中银 2024 |

## 七、与其他方向叠加

| 叠加方向 | 怎么协同 |
|---|---|
| **+ 资金流/北向** | 国家队 + 北向 = 两类不同逻辑的聪明钱，低相关，组合分散（见 [05](05-fund-flow-northbound.md)）|
| **+ 仓位管理** | 国家队入场期本身就是市场底部信号，可作仓位择时辅助 |
