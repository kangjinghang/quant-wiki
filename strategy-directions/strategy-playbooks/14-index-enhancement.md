## 一、策略本质：赚的是什么钱

指数增强 = **在跟踪某个宽基指数（沪深300/中证500/中证1000）的基础上，通过多因子选股拿超额收益**。它不是独立的新策略，而是**前述所有因子方向（PEAD/景气度/估值/质量…）的"组合出口"**——把因子研究成果打包成一个增强组合。

**赚的是什么钱**：宽基指数本身是市值加权（大权重股主导），效率低。通过多因子选股，超配因子看好的、低配不看好的，在控制跟踪误差的前提下拿超额。

### 指数增强的核心约束——跟踪误差

> **原文佐证**（中银量化 2024）："在实际产品构建中，一般要求沪深 300、中证 500 及中证 1000 指数增强基金的**日均跟踪误差控制在 0.5% 以内，年化的跟踪误差控制在 7.75% 以内**……跟踪误差的本质为组合与基准指数日度收益率之差的标准差。"

**为什么必须控制跟踪误差**：指数增强不是"随便选股"，而是"不能偏离指数太远"。如果跟踪误差失控，要么是赌错了某个行业/风格（偏离基准），要么是个股权重太集中。

## 三、策略配方

### 配方 A：组合优化器（中银，标准框架）

> 来源：[📖 中银量化 指数增强组合优化器](../../raw/articles/[202403242120]指数增强组合优化器从零构建全攻略中银量化多因子选股七.md)

**一句话**：用多因子给成分股打分，在控制跟踪误差+行业市值中性+权重约束的前提下，最大化预期收益。

**为什么不能简单等权/市值加权**：

> **原文佐证**（中银 2024）："如果只是简单的等权或者市值加权多头股票组合，多头组合的跟踪误差会出现高于指增组合跟踪误差阈值上限的情况，因此需要构建一个'**组合优化器**'来实现在控制组合跟踪误差的条件下，获得尽可能高的超额收益的目的。"

**优化器三要素**：

> **原文佐证**："从最优化问题的'决策变量'、'目标函数'及'约束条件'三要素的角度，详细介绍一种能够满足跟踪误差控制要求、计算简便、且能处理真实业务中遇到的各种实际问题的组合优化器。"

| 要素 | 内容 |
|---|---|
| **决策变量** | n 个成分股的权重向量 w |
| **目标函数** | 最大化预期收益（= 因子得分 × 权重）|
| **约束条件** | 个股权重偏离、行业市值中性、换手率、成分股占比等 |

**简化的线性优化目标**（中银推荐）：

> **原文佐证**："我们推荐基于'**最优化预期收益**'这一线性优化目标下，通过添加多种约束条件（如持仓个股权重偏离度，行业市值以及换手率等限制条件）来实现对跟踪误差的有效控制……这一简化方法稳健且有效。"

#### 配方 A 操作流程

```
每月末盘后：
1. 选定基准指数（沪深300/中证500/中证1000）
2. 多因子给成分股打分（合成预期收益）：
   ├─ 因子库：PEAD/景气度/估值/质量/动量/分析师预期（见前述各篇）
   └─ 大类合成（等权/ICIR加权）
3. 先剔除暴雷股（见 09 盈利质量 配方B，建高质量池）
4. 组合优化器求解：
   ├─ 目标：max(预期收益)
   ├─ 约束：跟踪误差≤阈值、行业中性、市值中性、个股权重偏离、换手率
   └─ 成分股权重占比≥80%（保证不脱离基准）
5. 输出目标权重，次日批量调仓
6. 月频调仓
```

### 配方 B：行业配置增强（开源，行业偏离拿超额）

> 来源：[📖 开源金工 行业量化配置在沪深300增强上的应用](../../raw/articles/[202102180801]开源量化评论行业量化配置在沪深300增强上的应用.md)

**一句话**：除了选股，还在**行业层主动偏离**——超配看好的行业、低配不看好的，这是独立于选股的 alpha。

> **原文佐证**（开源 2021）："行业层面的主动偏离是指数增强的重要 alpha 来源……**行业动量信号与个股 alpha 因子具有较低的相关性，能够提供增量信息**。"

**效果**：超额夏普 **2.21**（见 [02-行业轮动](02-industry-rotation.md)）。

## 四、落地到 QMT

```
每月末盘后：
1. 选基准指数（300/500/1000）
2. 多因子打分（PEAD/景气/估值/质量/动量/分析师预期）
3. 财务危机剔除（高质量池）
4. 组合优化器：max收益 s.t. 跟踪误差/行业中性/权重约束
5.（可选）行业配置偏离增强
6. 输出权重，次日批量调仓，月频
```

## 六、关键风险与避坑

| 风险点 | 说明 |
|---|---|
| **跟踪误差失控** | 不用优化器、简单等权会导致跟踪误差超阈值 |
| **行业/市值偏离** | 不做中性化会变成赌行业/赌大小盘，偏离增强本意 |
| **因子过拟合** | 历史回测好不代表样本外好，需控制因子数量、做样本外验证 |
| **换手率过高** | 月频调仓换手可能很高，交易成本侵蚀 alpha |
| **先剔暴雷再增强** | 不剔暴雷，一个 ST 股就能拖垮组合 |
