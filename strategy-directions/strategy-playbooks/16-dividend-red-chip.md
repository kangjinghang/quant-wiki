## 一、策略本质：赚的是什么钱

红利/央企/中特估策略是**稳健型"固收+"的权益端核心**——买入高股息（红利）、低波动、央企（国企重估）的股票，赚的是**股息现金流 + 估值重估 + 确定性溢价**三笔钱。

**赚的是什么钱（三重逻辑）**：

**① 股息收益（类债券属性）**：成熟企业把赚到的钱稳定分给股东，提供持续现金流。在利率下行的环境里，高股息股票就像"涨了价的债券"——股息率 5% 的股票，比 2% 的国债有吸引力。

**② 央企价值重估（中特估）**：央企长期被低估（PB 低），但它们保障国家战略安全、承担稳增长重任、治理良好——这些价值在传统估值体系里没体现，在"中国特色估值体系"下有望被重估。

> **原文佐证**（国君配置 2022）："央企在保障国家战略安全、承担稳增长重任以及良好内在治理机制方面具有优势，**在中国特色的估值体系下，央企的内在价值有望进一步被市场所认可，配置价值提升**。"
> 📖 [国企改革背景下央企配置价值提升](../../raw/articles/[202211302257]国君配置国企改革背景下央企配置价值提升资产配置思考系列之六.md)

**③ 确定性溢价（防御属性）**：熊市/震荡市里，资金避险涌向确定性高的红利股，使它们抗跌。

### 为什么这个方向对个人投资者特别合适

红利央企策略有几个**天然适合个人投资者**的特征：
- **低换手**（年化换手率低，交易成本小）
- **持仓周期长**（季频/年频调仓，不用盯盘）
- **数据简单**（股息率/PB/央企标签，都是公开免费数据）
- **防御性强**（熊市抗跌，心理压力小）

## 二、央企价值重估的四重逻辑（国君完整框架）

> 来源：[📖 国君配置 国企改革背景下央企配置价值提升](../../raw/articles/[202211302257]国君配置国企改革背景下央企配置价值提升资产配置思考系列之六.md)

国君配置从四个维度论证央企的配置价值：

### 逻辑 1：保障国家战略安全（传统估值未体现）

> **原文佐证**："国企大多处在关系国家安全、国民经济命脉和国计民生的重要行业和关键领域，对于保障中国国家战略安全起到重要的作用。**在中国特色估值体系下，国企对国家战略安全的保障能力极其具有投资价值，而这在现有的估值体系下并未得到充分体现**。"

**直觉**：央企守护的是"国家安全"（能源/通信/军工/粮食），这种战略价值没法用 PE/PB 衡量，但在地缘风险上升的时代越来越重要。

### 逻辑 2：中央加杠杆稳增长（央企直接承担）

> **原文佐证**："在地方债务偏高而加杠杆受限的背景下，**预计中央将通过加杠杆来承担更多稳增长的重任，央企将直接承担这艰巨的任务**。"
>
> "资本开支偏弱的行业后续有望受益于中央加杠杆而增加固定资产投资，需求上升的确定性较强。目前电力、银行、交通运输、新能源、化工等行业央企的资本开支偏弱。"

**直觉**：地方政府债务高、不能再加杠杆了，稳增长靠中央 → 央企拿到更多项目/投资 → 业绩有保障。

### 逻辑 3：良好治理机制

> **原文佐证**："中国特色估值体系下，上市公司不仅仅需要考虑对股东的经济效益，还需考虑企业的内在治理机制与对社会的外部性。**能够平衡经济效益与社会效益的公司，具有更高的投资价值。央企具有较好的内在治理机制**。"

### 逻辑 4：即使传统角度看估值也偏低

> **原文佐证**："除去央企在保障国家战略安全、承担稳增长重任以及具有良好内在治理机制方面的优势，**即使从传统的估值角度来看，其估值也仍偏低**。"

### 三个核心选股标签

> **原文佐证**："带有'**国改基本完成的国企（最好是央企）**'、'**估值较低**'、'**涉及经济安全**'这三重标签的上市公司将符合更多投资者的审美偏好，具有更高的预期投资回报率。相关标的较为集中的板块可能包括**信息技术、高端制造、资源品和农产品**等。"

| 标签 | 含义 | 怎么筛 |
|---|---|---|
| **央企/国改完成** | 治理改善、战略价值 | 东财/同花顺央企标签 |
| **估值低** | PB 历史分位低 | PB < 行业中位数 或 历史分位 <30% |
| **涉及经济安全** | 战略安全行业 | 信息技术/高端制造/资源品/农产品/军工 |

## 四、策略配方

### 配方 A：红利低波 Plus（华安，最完整的稳健组合）

> 来源：[📄 华安金工 红利低波plus组合](../../wiki/concepts/红利低波plus组合.md)（2022.5）

**一句话**：以红利+低波为基石筛股票池，用"负面清单"剔尾部风险，叠加价值+盈利因子增强，波动率倒数加权。

这是华安"量化绝对收益之路"系列的核心方案，专为稳健型固收+的权益端设计。

#### 第一步：基石筛选（红利 + 低波）

用红利因子（股息率）和低波因子（波动率）筛选基础股票池——高股息 + 低波动的股票。

#### 第二步：负面清单剔除尾部风险（关键的风控层）

华安用三条规则剔除"可能暴雷"的股票：

| 负面规则 | 剔除什么 | 为什么 |
|---|---|---|
| **应收账款占比异常** | 财务风险（赚的是账面利润不是真钱）| 配合 [09-盈利质量](09-quality-profitability.md) |
| **特异度指标过高** | 走势异常（脱离基本面炒作）| 个股收益中无法被因子解释的部分 |
| **股价业绩偏离度过大** | 基本面脱节（股价和业绩不匹配）| 防接盘 |

#### 第三步：因子增强

在过滤后的池子里，叠加**价值因子**（低 PB）和**盈利因子**（高 ROE）提升收益。

#### 第四步：波动率倒数加权

> **原文佐证**（华安概念页）："加权方式：**波动率倒数加权**，降低高波动个股权重。"

**直觉**：波动大的股票给小权重，波动小的给大权重 → 组合整体波动更低、更稳。

#### 效果

> **原文佐证**："自 2013 年以来：**年化收益 17.51%**；2018 年熊市下跌：19.09%；2022 年熊市下跌：9.86%；抗跌性显著，适合作为稳健型固收+的权益端。"
>
> "作为稳健型（R2）固收+策略的权益端核心方案，与债券端搭配……实现整体组合年化收益 6.72%、夏普比 2.40。"

#### 配方 A 操作流程

```
每季/半年频：
1. 基石筛选：股息率排名前 X% + 波动率排名后 X%（低波）
2. 负面清单剔除：
   ├─ 应收账款占比异常（财务风险）
   ├─ 特异度指标过高（走势异常）
   └─ 股价业绩偏离度过大（基本面脱节）
3. 因子增强：在剩余池里按价值（PB低）+ 盈利（ROE高）打分
4. 波动率倒数加权（波动大的降权）
5. 持仓，季频/年频调仓（低换手）
```

### 配方 B：央企三标签精选（国君，中特估主线）

> 来源：[📖 国君配置 央企配置价值](../../raw/articles/[202211302257]国君配置国企改革背景下央企配置价值提升资产配置思考系列之六.md)

**一句话**：专挑"国改完成央企 + 估值低 + 涉及经济安全"三重标签的股票。

**操作流程**：

```
每季频：
1. 筛央企/国企标签（国改完成的优先）
2. 筛估值低：PB 历史分位 <30%（或行业中位数以下）
3. 筛涉及经济安全行业：
   ├─ 信息技术、高端制造、资源品、农产品
   ├─ 军工、有色、电新（专精特新中国企占比高）
   └─ 电力、银行、交运、化工（资本开支偏弱，受益中央加杠杆）
4. 三标签交集 → 精选组合
5. 等权持仓，季频/年频调仓
```

> 💡 **进阶提示**：国君提到"资本开支偏弱的行业后续有望受益于中央加杠杆"——电力、银行、交运、新能源、化工这些行业的央企，如果中央开始加杠杆投资，它们最先受益。

### 配方 C：预期股息率因子（开源，Forward-looking 红利）

> 来源：[📄 开源金工 预期股息率因子](../../wiki/concepts/预期股息率因子.md)（2023.11）

**一句话**：别只看历史股息率，要**预测未来股息率**——用净利润增长率推算未来分红。

**问题**：历史股息率是滞后的（看过去的分红），但真正影响股价的是"未来能分多少"。

**预期股息率的简化算法**：

> **原文佐证**（开源概念页）："**核心假设：股息支付率保持不变。增长率预测：分红的增长率等于净利润的时序累计增长率。**基于上述假设，推算出未来的预期分红金额，再除以当前股价，即得到预期股息率。"

```
预期股息率 = (历史股息 × (1 + 净利润累计增长率)) / 当前股价
```

**效果**：

> **原文佐证**："该因子在低估股票池内具备良好的分组能力，**三分组多空对冲年化收益 6.07%，信息比率 1.21**。"

> 💡 这个因子在**低估股票池**内最有效——配合估值因子用，先筛低估值再按预期股息率排序。

#### 配方对比

| | 配方 A 红利低波Plus | 配方 B 央企三标签 | 配方 C 预期股息率 |
|---|---|---|---|
| **核心** | 红利+低波+负面清单+增强 | 央企+低估值+战略安全 | 预测未来股息率 |
| **年化** | **17.51%**（华安回测）| — | 多空 6.07%/IR 1.21 |
| **防御性** | **极强**（2022仅跌9.86%）| 强（央企抗跌）| 中（单因子）|
| **频率** | 季/年频（低换手）| 季频 | 月/季频 |
| **适合** | 稳健型固收+权益端 | 中特估主线 | 红利因子增强 |

> 💡 **三个配方可组合**：A 做主体（红利低波+负面清单），B 加央企偏好（在 A 池里优先央企），C 用预期股息率替代历史股息率（forward-looking 增强）。

## 五、落地到 QMT（完整执行流程）

**信号频率**：季频或年频（红利策略换手低，不用频繁调仓）
**持仓周期**：半年到一年（持仓稳定）
**QMT 用法**：**盘后批量**，低频调仓

```
每季末（或年报/半年报披露后）盘后：
1. 基石筛选：
   ├─ 算股息率（近12月分红/股价），取前 X%
   └─ 算波动率（近60日），取后 X%（低波）
2.（可选）预期股息率增强（配方 C）：
   └─ 用净利润增长率推预期股息率，替代历史股息率
3. 负面清单剔除（配方 A 风控）：
   ├─ 应收账款占比异常
   ├─ 特异度指标过高
   └─ 股价业绩偏离度过大
4.（可选）央企偏好（配方 B）：
   └─ 在剩余池里优先央企/国企 + 低估值 + 战略安全行业
5. 因子增强：价值（PB低）+ 盈利（ROE高）打分
6. 波动率倒数加权
7. 输出目标持仓，季频/年频调仓
```

## 七、关键风险与避坑

| 风险点 | 说明 | 来源 |
|---|---|---|
| **价值陷阱** | 高股息可能是股价跌出来的（分母小），或一次性特别分红。要用预期股息率 + 盈利质量过滤 | 开源 2023 |
| **周期股伪红利** | 周期股景气顶点时股息率高，但不可持续（如煤炭2022）。要看分红持续性 | 综合 |
| **央企重估节奏不确定** | 中特估是长期逻辑，短期可能不兑现。不能当短线炒 | 国君 2022 |
| **低波≠无回撤** | 2018 红利低波仍跌 19%。低波是相对抗跌不是绝对不亏 | 华安 2022 |
| **利率环境影响** | 加息周期里，股息率相对债券的吸引力下降 | 综合 |
| **负面清单需维护** | 特异度/股价业绩偏离度等指标需定期重新计算 | 华安 2022 |
