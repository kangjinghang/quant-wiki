## 一、策略本质：赚的是什么钱

打新策略包含两类：① **新股申购**（IPO 上市首日卖出赚差价）；② **可转债抢权配售**（转债发行前买入正股，获原股东优先配售权，赚转债上市首日收益）。两者都是**事件型策略**，QMT 适合做执行（批量下单）。

**赚的是什么钱**：
- **新股**：IPO 定价相对二级市场有折价（一级市场买到便宜筹码），上市后估值回归赚差价
- **转债抢权**：转债上市首日通常有正收益（"上不封顶下有保底"），通过提前买入正股拿到优先配售权来"打新"转债

### 两个必须知道的关键现实

**① 注册制后，新股打新不再无风险——破发常态化**：

> **原文佐证**（光大金工 2022）："我国 IPO 定价机制经历三个阶段：2005 年以前的审批制，2005-2019 年的核准制，2019 至今的注册制……2016 年至今，发行机制逐步市场化，提高了新股发行时相对所属行业估值的溢价，**打新收益逐渐下滑**。**2021 年 10 月以来新股破发频现，2021 年 10 月-2022 年 6 月 24 日上市新股中破发占比约 25%**，对新股上市表现的策略研究越发重要。"
> 📖 [新股上市如何表现](../../raw/articles/[202207051155]光大金工新股上市如何表现制度影响因素与策略意义量化打新系列报告之二.md)

**结论**：注册制前"闭眼打新"可行（连续涨停），**注册制后必须筛选**——不是所有新股都赚。

**② 转债抢权配售也非无风险——正股会跌**：

> **原文佐证**（光大 2022）："考虑正股可能下跌风险，**抢权配售并非无风险策略**。此外每股配售金额这个参数决定了获配一手转债投入资金大小。**若获配比例较低、投入资金较多且正股下跌幅度较大，极有可能拖累实际收益**。"
> 📖 [可转债抢权配售决策框架](../../raw/articles/[202203311506]光大金工可转债抢权配售决策框架量化打新系列报告之一.md)

**抢权的正股"先涨后跌"现象**：

> **原文佐证**："抢权投资者一般对公司没有长期观点，因此在获得转债份额后，倾向于抛售为抢权而购买的股票，**造成正股价格在股权登记日前后走势先涨后跌的现象**。"

## 三、策略配方

### 配方 A：新股申购筛选（注册制后必筛）

> 来源：[📖 光大金工 新股上市如何表现](../../raw/articles/[202207051155]光大金工新股上市如何表现制度影响因素与策略意义量化打新系列报告之二.md)

**一句话**：注册制后不能闭眼打，要用 7 个因素（4 正向 + 3 负向）筛选，只打高分的新股。

**影响新股上市表现的 7 个因素**：

> **原文佐证**："市场牛熊环境、发行市值、发行价格、是否属于风口行业、发行估值溢价率、投机资金盈余、网下超额认购对新股表现有重要影响。"

| 类型 | 因素 | 逻辑 |
|---|---|---|
| **正向** | 创业板近月上涨 | 大盘环境好，新股首日表现好 |
| **正向** | 风口行业（近12月涨幅 top5 行业）| 风口行业新股更受追捧 |
| **正向** | 新开户数多 | 散户热情高，补充投机资金 |
| **正向** | 网下超额认购多 | 机构定价能力强，看好 |
| **负向** | 发行市值高 | 大盘新股涨幅低 |
| **负向** | 发行价格高 | 高价股涨幅低 |
| **负向** | 发行估值相对行业溢价高 | 一级市场已透支 |
| **负向** | 近期 IPO 募资金额多 | 消耗投机资金 |

#### 配方 A 操作流程

```
每次新股发行前/申购日：
1. 对每只新股按 7 因素打分：
   ├─ 正向：大盘环境(创业板近月涨幅)、是否风口行业、新开户数、网下超额认购
   └─ 负向：发行市值、发行价、估值溢价率、近期IPO募资额
2. 综合打分，只申购高分新股（规避破发风险高的）
3. 申购（网上/网下）
4. 中签后上市首日/首周卖出
```

> ⚠️ 注册制后，**低分新股（发行价高+估值溢价高+非风口）破发概率高，坚决不打**。

### 配方 B：可转债抢权配售（期望收益决策框架）

> 来源：[📖 光大金工 可转债抢权配售决策框架](../../raw/articles/[202203311506]光大金工可转债抢权配售决策框架量化打新系列报告之一.md)

**一句话**：在转债发行前的股权登记日买入正股，获优先配售权赚转债上市收益——但必须算"期望收益"，只参与正的。

#### 抢权现象（时序规律）

> **原文佐证**："以可转债优先配售的股权登记日为界，我们发现**股权登记日（含）前 3 天正股平均有明显上涨**。股权登记日前一天上涨最明显，可能是公司发布提示公告所致。**股权登记日后两天正股有比较明显的下跌**。"

**为什么前涨后跌**：登记日前，抢权资金涌入买正股（涨）；登记日后，抢权者拿到转债配售权就抛售正股（跌）。

#### 期望收益决策框架（核心——决定参不参与）

> **原文佐证**：
> "**预期正股下跌风险**：我们把股权登记日前的正股上涨幅度作为持有正股的预期下跌幅度，结合参与配售所需购买正股资金量，计算参与配售的潜在风险。"
>
> "**预期可转债上市首日收益**：以股权登记日前最近上市的 10 只可转债首日涨幅作为该次可转债首日收益估计值。"
>
> "**期望收益 = 一手可转债的预期上市首日收益 − 预期正股下跌风险**。"

通俗解释这三个量怎么算：

```
预期正股下跌风险 = 登记日前正股涨幅 × 获配一手转债需买的正股资金
  （登记日前涨了5%，配一手要买10万正股 → 风险 = 5% × 10万 = 5000元）

预期转债收益 = 近10只转债首日涨幅均值 × 一手转债面值(1000元)
  （近10只首日均涨20% → 收益 = 20% × 1000 = 200元）

期望收益 = 预期转债收益 − 预期正股下跌风险
  （200 − 5000 = -4800元 → 负的，放弃！）
```

> ⚠️ **关键洞察**：抢权的收益来自转债（小，一手就1000元面值），但风险来自正股（大，要买几万到几十万正股）。**如果配售比例低（要买很多正股才能配一手转债），正股下跌风险远大于转债收益，期望收益为负，必须放弃**。

#### 期望收益的预测效果

> **原文佐证**："**期望收益对实际收益有明显的分类预测效果，期望收益 > 0 元的样本实际收益明显较高**。"

#### 决策规则

> **原文佐证**："对于未持有正股的抢权配售投资者，**若期望收益过低可考虑放弃抢权**。对于持有正股的股东，如果观察到近期转债上市首日涨幅低迷，且股权登记日前正股上涨较多造成期望收益下降，可考虑先卖出正股再买回的价差策略，放弃优先配售。"

#### 配方 B 操作流程

```
每次可转债发行（公告发行日 → 股权登记日 → 上市）：
1. 确认股权登记日 + 每股配售金额（配售比例）
2. 算预期正股下跌风险：
   ├─ 登记日前正股累计涨幅（如前3日涨多少）
   └─ × 获配一手转债需要购买的正股资金量
3. 算预期转债首日收益：
   └─ 近10只上市转债首日涨幅均值 × 一手面值(1000元)
4. 算期望收益 = 转债收益 − 正股下跌风险
5. 决策：
   ├─ 期望收益 > 0 → 参与抢权（登记日前买入正股）
   ├─ 期望收益 < 0 → 放弃
   └─ 已持有正股 → 考虑登记日前卖出再买回（价差策略）
6. 参与的：登记日前买入正股 → 获配售 → 转债上市首日卖转债 → 正股登记日后择机卖
```

#### 配方对比

| | 配方 A 新股申购 | 配方 B 转债抢权 |
|---|---|---|
| **机制** | 一级市场折价 | 优先配售权 |
| **风险** | 破发（注册制后~25%）| 正股下跌（非无风险）|
| **筛选** | 7因素打分 | 期望收益>0 |
| **频率** | IPO 时（不定期）| 转债发行时（不定期）|
| **资金效率** | 高（中签才付）| 低（要买正股）|

## 四、落地到 QMT（完整执行流程）

**信号频率**：事件触发（新股/转债发行公告时）
**持仓周期**：极短（T+0/T+1，上市首日/首周卖）
**QMT 用法**：**批量下单执行**

```
【新股申购】每次新股发行：
1. 7因素打分（大盘/风口/新开户/超额认购 vs 市值/价格/溢价/募资）
2. 高分 → 申购
3. 中签 → 上市首日/首周卖出
（QMT 批量执行申购 + 上市卖出）

【转债抢权】每次转债发行：
1. 确认股权登记日 + 配售比例
2. 算期望收益（转债收益 − 正股下跌风险）
3. 期望收益 > 0：
   ├─ 登记日前：QMT 批量买入正股
   ├─ 登记日：获配售权
   ├─ 转债上市首日：卖出转债
   └─ 正股：登记日后择机卖出
4. 期望收益 < 0：放弃
```

## 六、关键风险与避坑

| 风险点 | 说明 | 来源 |
|---|---|---|
| **注册制后破发** | 2021.10 后破发率 ~25%，不能闭眼打。低分新股坚决不打 | 光大 2022 |
| **抢权正股下跌** | 登记日后正股下跌可能远大于转债收益。配售比例低时尤其危险 | 光大 2022 |
| **期望收益为负** | 必须算期望收益，只参与正的。负的放弃 | 光大 2022 |
| **转债首日涨幅低迷** | 市场悲观时转债也可能破发（2013/2018）。用近10只均值做估计 | 光大 2022 |
| **低频事件型** | 不能作主力策略，是收益增强/现金管理补充 | 综合 |
| **资金占用** | 抢权要买正股，资金占用大、效率低 | 光大 2022 |
