## 一、策略本质：赚的是什么钱

交易所回购（GC001/GC007）是**债券质押式回购**——你把闲钱借给别人（收质押），赚取**回购利率**的利息。它是**权益策略空仓时现金仓位的增益器**：钱不躺平，买回购吃息。

**赚的是什么钱**：利用交易所回购利率的**周期性规律**（日内/周内/月内波动），在利率高时借出（吃高息），规避利率低/紧缩时点。

> **原文佐证**（中金固收 2023）："GC001 和 GC007 作为交易所回购的主要交易品种，成交量远超交易所其他回购品种……投资者可以利用这一点，**合理进行资金管理**。"
> 📖 [基于量化视角看交易所回购交易策略](../../raw/articles/[202303222142]中金固收量化基于量化视角看交易所回购交易策略.md)

### 与其他方向的定位

> 💡 这不是独立 alpha，而是**横切基础设施**——和 [20-仓位管理](20-position-risk-management.md) 互补：仓位管理说"减仓"，回购说"减仓后的钱去哪"。

## 二、回购利率的周期性规律（中金完整画像）

中金固收从日内、周内、月内、节假日四个维度刻画了 GC001/GC007 的规律：

### 日内：开盘高、尾盘低

> **原文佐证**："从日内角度来看，它们的成交利率通常**开盘高，尾盘低**，伴有成交分布的高度一致性。"
>
> "尾盘（特别是下午 3 点后）由于**闲置资金集中释放**，利率往往大幅跳水。"

**直觉**：尾盘各机构的闲钱集中涌出借出（都要盘后处理资金），供大于求 → 利率跳水。

### 周内：周四最松

> **原文佐证**："**周四资金面通常最松，尾盘利率跌幅最深**；周一、周五偏紧。"

**特别机制（关键）**：

> **原文佐证**（[交易所回购概念页](../../wiki/concepts/交易所回购.md)）："自 2017 年 5 月起，质押式回购计息天数修改为实际占款天数，**导致周四买入 GC001 的资金实际可占用 3 天（周五至周日）**。"

**直觉**：周四买 GC001，钱被占用周五到周日三天，但只算 1 天利息 → 周四 GC001 利率会反映这三天占用，尾盘跌得最深。

### 月内：月初/月中/月末易走高

> **原文佐证**："**月初、月中（16 号左右缴税期）、月末（21 号起跨月跨季）资金利率容易走高**。"

**直觉**：缴税、跨月跨季资金需求集中 → 利率升高。这些时点借出（吃高息）更划算。

### 节假日：节前第三天最高

> **原文佐证**："**节前第三天利率最高**，节前最后一天尾盘 GC007 往往超跌；节后首日资金面依然偏紧。"

## 三、策略配方

### 配方：利用利率周期规律的现金管理

**操作原则**：利率高时借出（吃息），利率低时等待。

```
现金仓位管理规则：
1. 非月末、非缴税期：
   ├─ 周四尾盘买 GC001（占款3天，尾盘利率最低）
   └─ 其他日期视利率水平决定
2. 月末/跨季（21号起）：
   └─ 切 GC007（跨月资金，利率走高时借出吃息）
3. 节假日前：
   ├─ 节前第三天：利率最高，借出吃息
   └─ 节前最后一天尾盘：GC007 往往超跌，谨慎
4. 规避：月末紧缩时点、节后首日（资金面偏紧，不利借出方）
```

> 💡 **本质是"反向操作"**：利率跳水（资金宽松）时是借入方有利；利率冲高（资金紧张）时是借出方有利。作为现金管理（借出方），要在利率高时出借。

## 四、落地到 QMT

**信号频率**：日频（盘中/盘尾执行）
**QMT 用法**：权益空仓资金 → 回购

```
每日盘后：
1. 判断当前处于利率周期的哪个阶段（日/周/月/节假日）
2. 决定：借出（买回购）还是等待
3. 借出时点：
   ├─ 非月末周四尾盘 → GC001
   ├─ 月末/跨季 → GC007
   └─ 利率冲高时 → 借出
4. QMT 执行回购交易
```

## 六、关键风险

| 风险 | 说明 |
|---|---|
| **利率波动** | 回购利率受资金面影响波动大，非稳赚 |
| **质押券风险** | 质押券违约风险（罕见但存在）|
| **机会成本** | 回购收益有限，是现金管理非主力 alpha |
| **时点判断错误** | 误判资金松紧会买在利率低点 |
