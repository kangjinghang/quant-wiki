## 一、策略本质：赚的是什么钱

情绪/另类数据策略用**非传统数据源**（新闻舆情、招聘、社交媒体、卫星等）捕捉市场情绪和基本面变化的**早期信号**——这些信息往往领先于传统财报和价格数据。

**赚的是什么钱**：另类数据能提供传统数据没有的**增量信息**。比如招聘数据反映企业扩张意愿（领先于财报披露），新闻舆情边际变化反映市场关注度的拐点。

> **原文佐证**（开源金工 2021）："新闻舆情数据作为其中另类数据的模块之一，**蕴含丰富的股票情感信息**。"
> 📖 [新闻舆情数据选股能力初探](../../raw/articles/[202107092032]新闻舆情数据选股能力初探开源金工.md)

### 这个方向的核心规律——"边际变化 > 绝对水平"

这是另类数据最重要的发现：**数据的"变化"比"绝对值"更有定价意义**。

> **原文佐证**（开源 2021，新闻舆情）："原始的新闻舆情分数平均值（MS）因子直接用于选股效果不佳，但其**边际变化**——即过去 N 天舆情分数平均值的变化量（ΔMS）——构成的因子却表现出显著的有效性。这一发现揭示了一个重要的市场微观结构规律：**市场对新闻舆情的边际变化比绝对水平更有定价意义**。"

**直觉**：一只股票一直是新闻热点（绝对水平高）已被定价，没有 alpha；但"突然变热"或"突然变冷"（边际变化）是新的信息，市场还没反应。

## 三、策略配方（可得子集）

### 配方 A：新闻舆情边际变化 ΔMS（开源，可得降级版）

> 来源：[📖 开源金工 新闻舆情数据选股能力初探](../../raw/articles/[202107092032]新闻舆情数据选股能力初探开源金工.md)

**一句话**：算新闻舆情分数的"边际变化"（ΔMS），买舆情突然变负的（反转）、卖变正的。

**关键——边际变化而非绝对水平**：

> **原文佐证**："原始的新闻舆情分数平均值（MS）因子直接用于选股效果不佳，但其**边际变化**（ΔMS）却表现出显著的有效性。"

**怎么算**：

> **原文佐证**："计算过去 N 天舆情分数平均值的变化量：ΔMS = MS(N) − MS(前N天)。"

**效果**：

> **原文佐证**："在回看天数下，多空收益波动比为 2.2，多头相对中证 500 的年化收益率为 4.6%……**双周频上该因子的多空对冲年化收益率为 12.00%，因子的年化 ICIR 为 -2.3**。"

**纯度高（剔除常见因子仍有效）**：

> **原文佐证**："与过去 20 日涨跌幅的相关性接近 0.1，与其余常见因子的相关性较弱……剔除常见 10 个因子后，**多空收益波动比达 2.64，年化 ICIR -2.27**。"

**数据降级方案**：开源原版用通联数据（商业源）。降级版可用**问财/东财新闻 + LLM 情感打分**替代（开源 2023 后的多篇报告已用 ChatGPT/LLM 处理文本）。

#### 配方 A 操作流程

```
双周频：
1. 拉个股新闻（问财/东财，🔵）
2. 用 LLM 对每条新闻情感打分（-1 到 1）
3. 算过去 N 天舆情分数均值 MS(N)，及变化量 ΔMS = MS(N) − MS(前N天)
4. 按 ΔMS 排序（负向因子：舆情突然变负的，反转回升）
5. 剔除常见10因子后取残差（提升纯度）
6. 双周频调仓
```

### 配方 B：概念热度 / 主题（可得，辅助）

**一句话**：跟踪概念板块的热度变化，做主题轮动。

**数据**：同花顺概念热度（🔵 可补）。

**用法**：作为 [02-行业轮动](02-industry-rotation.md)/[13-ETF轮动](13-etf-rotation.md) 的辅助信号——概念热度上升的行业/主题优先配置。

---

### 配方 C：月历效应（✅ 已有，简单有效）

**一句话**：A 股存在显著的月历效应（如"春季躁动"），用日历规律做择时辅助。

> **原文佐证**（中金固收，转债月历）：转债市场也有月历效应，可做转债择时辅助。

> 💡 月历效应是**最易得的另类信号**（只需日历），但单独价值有限，作为其他策略的择时辅助。

---

### 配方 D：研报文本情感（LLM 时代可得）

**一句话**：用 LLM（ChatGPT/BERT）处理分析师研报文本，提取情感因子。

> **原文佐证**（华安 2023）：ChatGPT 与研报文本情绪结合，量化研究系列。

> 💡 过去研报文本情感需专业 NLP（通联数据付费），**现在用 LLM 可低成本实现**——这是个人投资者的新机会。

#### 配方对比

| | 配方 A 新闻ΔMS | 配方 B 概念热度 | 配方 C 月历 | 配方 D 研报情感 |
|---|---|---|---|---|
| **可得性** | 🔵 LLM降级 | 🔵 | ✅ | 🔵 LLM |
| **效果** | ICIR -2.3 | 辅助 | 辅助 | — |
| **适合** | 主力另类因子 | 主题轮动辅助 | 择时辅助 | LLM新机会 |

> ⚠️ **不可得子集**：招聘数量（❌ 商业源）、卫星/ESG争议（❌ 付费）、股吧发帖量/点击量（❌ 难爬）——这些开源金工验证有效但个人投资者拿不到，如实排除。

## 四、落地到 QMT

**信号频率**：双周频（新闻舆情）/ 月频（概念热度/月历）
**QMT 用法**：盘后批量

```
双周频（配方A）：
1. 拉个股新闻（问财/东财）
2. LLM 情感打分
3. 算 ΔMS（舆情均值变化量）
4. 剔除常见因子取残差
5. 选股，双周调仓

月频（辅助）：
6. 概念热度（同花顺）→ 主题轮动辅助
7. 月历效应 → 择时辅助
8. 研报情感（LLM）→ 增强分析师预期（见[03]）
```

## 六、关键风险与避坑

| 风险点 | 说明 | 来源 |
|---|---|---|
| **绝对水平无效，要边际变化** | MS 直接用效果差，ΔMS 才有效 | 开源 2021 |
| **商业数据源依赖** | 原版用通联数据（付费），需 LLM 降级 | 开源 2021 |
| **招聘/卫星不可得** | 商业另类数据个人拿不到，如实排除 | 开源 2021 |
| **LLM 打分一致性** | LLM 情感打分可能不稳定，需 prompt 工程 | 华安 2023 |
| **另类数据衰减快** | 随关注度提升，另类 alpha 可能快速衰减 | 综合 |
| **新闻噪声大** | 新闻数据需去重、时间戳修正（开源/通联都强调）| 通联/李立 |
