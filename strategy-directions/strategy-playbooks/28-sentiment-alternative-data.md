## 一、策略本质：赚的是什么钱

情绪/另类数据策略用**非传统数据源**（新闻舆情、招聘、社交媒体、卫星、文本、投资者关注度等）捕捉市场情绪和基本面变化的**早期信号**——这些信息往往领先于传统财报和价格数据。

**赚的是什么钱**：另类数据能提供传统数据没有的**增量信息**。比如招聘数据反映企业扩张意愿（领先于财报披露），新闻舆情边际变化反映市场关注度的拐点，研报文本措辞藏着分析师没写进评级里的真实态度。

> **原文佐证**（开源金工 2021）："新闻舆情数据作为其中另类数据的模块之一，**蕴含丰富的股票情感信息**。"
> 📖 [新闻舆情数据选股能力初探](../../raw/articles/[202107092032]新闻舆情数据选股能力初探开源金工.md)

### 这个方向的两条核心规律

**①"边际变化 > 绝对水平"**——这是新闻舆情最重要的发现（**经验事实来自原文，措辞为编者提炼**）：

> **原文佐证**（开源 2021，新闻舆情，原话要点）：用过去 N 天舆情分数均值 MS 作单因子测试，"不管是全样本、沪深300 还是中证500 选股域，回测结果均不尽如人意"；改为变化量 ΔMS 后"该因子的多空收益比在全样本区间内表现良好，尤其在中证500 选股域上表现优异"。（**编者提炼**："MS 水平无效、ΔMS 变化有效" → "边际变化 > 绝对水平"。原文未明示"市场微观结构规律"等概括。）

**直觉**：一只股票一直是新闻热点（绝对水平高）已被定价，没有 alpha；但"突然变热"或"突然变冷"（边际变化）是新的信息，市场还没反应。

**②"关注度绝对水平高 → 未来收益差"（负向因子）**——这是投资者关注度的发现，和"边际变化"相反相成：

> **原文佐证**（开源 2022，投资者关注度）："谚语有云，'**人多的地方不要去**'。对于个股而言，高点击量占比是否意味着个股的市场关注度过高，投资者情绪达到极端值，导致相关个股未来的潜在回报为负？从测试结果来看，**符合前述猜测**……**投资者个股关注度因子具有稳健的负向选股能力**。"
> 📖 [自选股与点击量投资者关注度的选股能力](../../raw/articles/[202203271728]自选股与点击量投资者关注度的选股能力开源金工.md)

**直觉**：关注度绝对水平高 = 情绪过热 = 已被定价甚至过度反应 → 未来反转回落。注意这和规律①的角度不同——①看舆情的**变化**（边际），②看关注度的**水平**（绝对）；两者都指向"已被充分关注的信息没有 alpha"。

> 💡 **通联/李立新闻量化的两条独家洞察**（开源金工未覆盖，可作为配方 A 的工程增强）：
> - **抗 look-ahead 的标注设计**：训练标签只标"新闻在讲什么事件类型"（强相关/弱相关/不相关三分类），**不用次日行情反推情感**——既避免未来数据，又消除标注者主观性（这是比"用 T+1 涨跌做标签"更稳的工程范式，与 §六"文本情感标注忌用行情反推"呼应）。
> - **12 小时有效时间规则**：新闻时间戳可能是文章写好时间而非审批发布时间，且只有日级精度会带来开盘前/后歧义。原文处理——"发布时间与当前间隔超 **12 小时**视为历史新闻用 publish time，未超则用数据商实际时间"，且"绝大部分新闻 10 分钟内入库"。配套：原文新闻去重后有效比例仅 **40-50%**（2018 以来），需重清洗；覆盖度沪深300 ~97%、中证800 ~95%、全A 70-80%。

### 配方 A：新闻舆情边际变化 ΔMS（开源，可得降级版）

> 来源：[📖 开源金工 新闻舆情数据选股能力初探](../../raw/articles/[202107092032]新闻舆情数据选股能力初探开源金工.md)

**一句话**：算新闻舆情分数的"边际变化"（ΔMS），买舆情突然变负的（反转）、卖变正的。**注意：alpha 集中在空头端，多头端很弱，更适合做负向过滤。**

#### 关键——边际变化而非绝对水平

> **原文佐证**（开源 2021，原话）："我们用过去 N 天舆情分数的平均值（MS）作为选股因子……不管是全样本、沪深300 还是中证500 选股域，回测结果**均不尽如人意**。" 对 MS 做变化量得 ΔMS 后，"该因子的多空收益比在全样本区间内表现良好，尤其在中证500 选股域上表现优异"。
>
> （playbook 概括为"边际变化 > 绝对水平"——这是基于上述经验事实的**编者提炼**，原文未用此措辞；但"水平无效、变化有效"的事实是确定的。）

#### 打分方向与数据清洗（落地关键）

> **原文佐证**："使用通联数据中'getNewsRelatedScoreV2'……主要是对上市公司的新闻进行**情感分数打分（SentimentScore），分数值越高通常意味着新闻对该个股有正面情绪**。"另用 `getNewsTagInd`（新闻关联标签行业表）做行业标签/过滤。
>
> 数据清洗规则："保留属于上市公司的新闻……已对数据进行初筛，**删除包括属于月度数据、是定期报告、属于图片新闻的记录**。"

> 💡 **LLM 降级时的符号**：情感分越高=越正面，由于 ICIR 为负（-2.3），ΔMS 与未来收益负相关——ΔMS 越负（舆情突然变差）→ 未来收益越高（反转）。**注意：反转/负向因子的方向是从负 ICIR 推断的，原文未明示反转机制**。用 LLM 打分时务必保持"高分=正面"的口径，否则符号全反。样本规模参考：开源初筛后共 **487 万条**新闻，日均覆盖约 **1600 只**个股，**4 月**（年报+一季报）新闻频次达年内最高，整体情感分布**略偏正向**（可作为 LLM 分数分布的校准检查）。

#### 怎么算

> **原文佐证**："计算过去 N 天舆情分数平均值的变化量：**ΔMS = MS(N) − MS(前N天)**。"（注：原文公式渲染缺失，此为对"过去 N 天平均值的变化量"的合理重构。）
>
> **回看天数 N 的参数扫描**：原文图 6 做了不同 N 的扫描并选最优 N 用于月度调仓的中证500 测试（多空收益波动比 2.2、多头超额 4.6%）——**playbook 此前完全没提 N 扫描**，落地时务必做 N 的敏感性测试而非拍定单一值。

#### 效果（双周频 vs 月频，口径务必分清）

> **原文佐证**（手续费**双边千三**）："因子在三种不同换仓频率下的表现：**双周频 > 月频 > 周频**。在双周频上该因子的多空对冲年化收益率为 **12.00%**，**多头相对中证500 年化收益率仅 1.72%**，因子的年化 ICIR 为 **-2.3**；月频下，该因子的多空对冲年化收益率 11.92%，**多头相对中证500 的年化收益率为 4.61%**，因子年化 ICIR 为 **-2.00**。"

> ⚠️ **口径修正**：此前正文把"多头超额 4.6%"与"双周频多空 12%"并列引用，易误读为"双周频多头超额 4.6%"——实际**双周频多头超额仅 1.72%**（4.61% 是月频）。双周频 alpha 集中在空头端。

**纯度高（剔除常见因子仍有效）**：

> **原文佐证**："与过去 20 日涨跌幅的相关性接近 0.1，与其余常见因子的相关性较弱……剔除常见 10 个因子后，**多空收益波动比达 2.64，年化 ICIR -2.27**，多头相对中证500 年化收益率 4.86%。"（单因子测试用**五分组**。）

**数据降级方案**：开源原版用通联数据（商业源）。降级版可用**问财/东财新闻 + LLM 情感打分**替代（华安 2023 已验证 ChatGPT 处理研报文本可行，见配方 D）。配套参考 §二李立的**事件型标注抗 look-ahead** + **12 小时有效时间规则**（时间戳歧义的处理）。

#### 配方 A 操作流程

```
双周频（做对冲/负向剔除）或月频（做多头），手续费双边千三：
1. 拉个股新闻（问财/东财，🔵），清洗：剔除定期报告/月度数据/图片新闻/非个股新闻
   ── 去重（通联实测有效新闻仅 40-50%）+ 12 小时有效时间规则修正时间戳
2. 用 LLM 对每条新闻情感打分（-1 到 1，保持"高分=正面"口径；标注事件类型而非用次日行情反推）
3. 算过去 N 天舆情分数均值 MS(N)，及变化量 ΔMS = MS(N) − MS(前N天)
   ── 做 N 参数扫描（参考开源图 6），选 IC 最优的 N
4. 按 ΔMS 五分组排序（负向因子：舆情突然变负的，反转回升）
   ── 双周频：alpha在空头端，宜做空头剔除/对冲
   ── 月频：多头端稍强（超额4.61%），可做多头
5. 剔除常见10因子后取残差（提升纯度，ICIR -2.27）
6. 调仓（双周或月）
```

### 配方 C：月历效应（✅ 已有，简单有效）

**一句话**：A 股/转债存在显著的月历效应，用日历规律做择时辅助。

> **原文佐证**（中金固收 2023，转债月历）："**七八月往往是基本面策略占优的时间段**……上市公司开始密集发布上半年业绩，并对全年业绩与后续展望提供指引。以 EPS 排序来作为择优方式……2014 年以来排序靠前的标的，普遍在 7-8 月提供较高赢率"，"组合在 6-8 月相对等权指数有一定增厚"。
> 📖 [可转债月历效应](../../raw/articles/[202307231426]中金固收可转债月历效应与基于预期的转债基本面择优.md)

> 💡 月历效应是**最易得的另类信号**（只需日历）。中金固收发现转债基本面组合的超额在 **6-8 月最显著**（驱动是半年报密集披露；**注意：原文未提"春季躁动"，"而非春季躁动"是编者对比推断**）。但单独价值有限，作为其他策略的择时辅助。
>
> **关键细节**（playbook 此前简化了）：①**实际择券不是纯 EPS 排序**，而是两步——先按"二级行业（净利润增长排序 + 历史分位数排序）加总"筛前 50% 行业，再用转债 EPS≥1 过滤；②**为何用"预期"而非已实现 EPS**：7 月中旬转债半年报披露率仅约 30%，故用市场一致预期净利增速作代理，"若'预知'未来半年 EPS，整体赢率能进一步提高"（量化了预期 vs 实现的信息差）；③回测起点 2018，统计的是"EPS 偏高 50% 标的"的月度涨跌幅；④**叠加 EasyBall 效果更佳**——"基于业绩预期的增厚，尤其在 EasyBall 的基础之上布局"。本篇主体（转债基本面择优/EasyBall增强）属转债策略，详见 [26-可转债](26-convertible-bond.md)。

### 配方 D：研报文本情感（LLM 时代可得，多头端最强）

**一句话**：用 NLP/LLM 处理分析师研报文本，提取情感因子。这是个人投资者过去拿不到（需付费 NLP）、**现在用 LLM 可低成本实现**的新机会。通联/华泰/华安三家机构给出了从早期 NLP → BERT → ChatGPT → LLM 改写文本的完整四阶段演进。

#### 为什么"文本情感"是独立的 alpha（相对分析师评级/预期的增量）

分析师的评级和盈利预测调整频率很低，但研报文本每篇都有，能捕捉藏在措辞里的态度：

> **原文佐证**（通联/李立 2021）："分析师大约间隔 **226 天**会调整一次所覆盖公司的股票评级……净利润和营收的调整大约是间隔 **94 天**……而基于文本分析的研报情感态度数据，它的研报篇数的间隔是 **1**，在每篇研报发布后都可以得到数据。"而且"分析师发现覆盖公司存在隐忧或一些负面变化……**不会很张扬地通过研报中的预测和评级来表达他的态度**……通过基于文本数据来分析研报中的措辞，是可以把握分析师情绪的变化情况，尤其是负面情绪的变化。"
> 📖 [基于文本的研报情感数据应用](../../raw/articles/[202104132050]李立基于文本的研报情感数据应用开源金工沙龙.md)

#### 演进一：早期 NLP（通联/李立 2021）——四分类 + 三权重

> **原文佐证**："用研报摘要核心观点……对每个核心观点进行打分……通常的做法是将各段情感打分等权求和，但……**给负面情感得分的权重设置得更大一些**"；时间序列"往前看 **120 天**……**时间衰减权重**（越近权重越高）、**数字权重**（数字越多可信度越高）、**热度权重**（浏览量越高权重越高）"；并强调"只用公司报告"（行业/宏观报告用词更模糊）。
>
> **四分类的具体设计**（非显然的关键）：四类 = **负面 / 中性 / 一般正面 / 强烈正面**。原文："在研报情感中**负面数据会特别少**……所以在这里面**我们把正面分为一般正面和强烈正面**，拆完之后样本的均衡性会变好很多"——即把"正面"拆成两档以平衡罕见的负面样本（分析师报告天然偏正面）。摘要而非全文：理由是"分析师大多看摘要部分，剩下的内容可能交给实习生写"（召回率更高）。两段负面加权 caveat："加大后效果比等权好，但**不是好得特别明显**，简单等权也可用"。
>
> 效果（中证800 周度调仓）："提纯后的因子 IC 为 **3.25%，ICIR 为 1.88，t 值为 5.37，胜率在 62% 左右"；纯因子（最大化夏普 + 行业市值暴露归零的优化器构造）"年化收益率 **5.31%**，IR 等于 **2.96**，换手率大概为 6 倍"。**中性化口径**：IC 是对"传统 10 个风格因子 + 申万 28 个行业"提纯后算的；月度调仓也可，日度调仓预期较差（"研报情感是偏长期逻辑的因子"）。

**增量 alpha 的证据（与既有分析师因子的正交性）**：

> **原文佐证**："与分析师预期、分析师预期上下调、净利润上下调、营收上下调等的相关性最高也就 **40% 左右**"；与风格因子"和**长端动量**的相关性最高约 **0.45**，其余都较低"——即相对既有分析师/动量因子仍有增量，可叠加。

**研报情感 vs 新闻情感的本质区别**（这是研报情感能进基本面模型的理论依据）：

> **原文佐证**（李立 2021）："研报情感因子**更多从公司基本面角度刻画**，因为分析师是比较专业的群体，相比散户更客观，没有特别明显的'追涨杀跌'现象……研报数据更多刻画公司基本面信息，而不是对情绪变化的反映。"而新闻情感"短期反映市场情绪，窗口拉长才和基本面相关性强"——这解释了为何研报情感适合作为基本面因子的补充，新闻情感适合做反转/择时。

> ⚠️ **方法论告诫**（李立 2021）："我们不能使用行情数据来给文本进行情感打分……这是一件非常危险的事情，最终文本的情感的结果是客观的，它不应该随着市场行情变化而改变。"——即**文本情感标注应人工标注，忌用次日行情反推标签**（会引入 look-ahead 偏误）。个人投资者用 LLM 自建标注集时务必注意。**配套现实指标**：该团队的 NLP 模型情感识别准确率 85%-90%，"市面上有 95%+ 的可能是 overfitting"。覆盖度：中证800 ~80%、沪深300 ~90%（2015 千股跌停期异常降低）。

#### 演进二：BERT 化（华泰 FADT 2022）——FinBERT 编码 + XGBoost

**FADT 框架**："以分析师研报文本的词频向量为特征，以**研报发布前后两日个股超额收益为标签**，引导 XGBoost 模型学习研报情绪蕴含的超额信息"——即把"这份研报文本 → 随后涨还是跌"的映射学出来。因子值由"上涨和下跌类别 log-odds 值之差作为文本得分……将个股过去一个季度有关盈利预测调整的全部点评研报文本得分求均值"。标签分上涨(前30%)/震荡(30-70%)/下跌(后30%)三类，滚动训练样本内6个月、样本外12个月。

**"再探"的升级点——FinBERT 隐藏层编码替代词频向量**：

> **原文佐证**（华泰 2022）："我们将词频向量替换为 **FinBERT 隐藏层编码**的特征向量……隐藏层编码蕴含更丰富的文本语义信息，相比词频信息损失更少。"并解释词频的缺陷——"'成本上调'是负向、'盈利预测上调'是正向，词频模型无法学习"。
>
> 效果："升级以后的文本因子十分层多头第一层年化收益由原版的 **22.87% 提升至 27.50%**，相对中证500 超额收益由 **14.75% 提升至 19.19%**（回测期 20090123-20220930）。"

**正交性（可叠加的依据）**：

> **原文佐证**："文本因子与动量因子正相关性相对较高，历史均值大约在 0.3 左右；与 BP 因子负相关性相对较高……**与其余风格因子整体相关性偏低**……文本因子与传统因子相关性也较低，**历史每个截面期的相关系数均值都不超过 0.5**。"

#### 演进三：ChatGPT 时代（华安 2023）——低成本 LLM 实现

这是"个人投资者用 LLM 低成本实现"的关键依据，工程细节此前完全没展开：

**打分方法（标题而非全文，1-10 连续分）**：

> **原文佐证**（华安 2023）：用 gpt-3.5-turbo 对"公司研究"类研报**标题**打分（非全文），样本 2016.01.01-2023.06.30 共 **24 万余条**；"要求 ChatGPT 给出 **1-10 连续的分数**，而非积极(+1)、消极(-1)、中性(0)这三种离散的结果"；采用"**系统提示(system role) + Temperature=0.5**"控随机性，"批量请求 + 只返回评分"每次 15-20 条标题，"**成本下降了 4/5，约 15 个小时便能完成全部标题评分**"。

> 💡 **打分口径 + 工程细节**（落地关键）：①**评分基准**——5 分为中性；"不及预期/低于预期"等明显消极词应得 1-7 分（若同时含积极词可高于中性），>9 分作为"GPT 超预期"阈值。②**防偷看**——标题前加公司名（少量标题会提及他司），**不输入点评日期**避免 LLM 借日期推断。③**成本精算**——gpt-3.5-turbo 输入 $0.0015/1k tokens、输出 $0.002/1k tokens，系统信息约 600 tokens、标题 20-60 tokens、回复约 103 tokens；TPM=90000/RPM=3500。**￥2635 是逐条请求的理想成本，批量模式再降 4/5**（约￥527/15 小时/3-6 天）。④**评分分布**——高分段（9-10）占 14%、8-9 分占 50%+、<5 分不到 6%，整体偏正（与分析师报告天然偏正面一致）。

**为何 LLM 优于传统 NLP（BERT 三大局限）**：

> **原文佐证**：BERT ①"离散情感值的局限性"；②"对细微情感表达的不敏感性（'再超预期''大超预期'比'略超预期'更积极但 BERT 评分无差异，'大超预期'标题竟被判负面）"；③"情感评估的逻辑不一致性"。而 ChatGPT"**评分时具有连续性，且能精确识别句子中的关键信息和其情感倾向**"。

**效果**：

> **原文佐证**：中证500 域"GPT 合成因子 gpt_score 的 **RankIC 为 3.6%，ICIR 1.53，IC 月胜率 74%，多头年化超额 9.3%**，多头组合**每年均为正超额**，近三年超额分别为 **7.04%、17.09% 和 2.96%**"；全A"gpt_avgRecord 的 RankIC 为 2.8%，ICIR 为 1.6……多头年化超额 5.2%，多空年化超额 12.7%"。
> 📖 [ChatGPT 与研报文本情绪的碰撞](../../raw/articles/[202308141622]华安金工ChatGPT与研报文本情绪的碰撞量化研究系列报告之十一.md)

> 💡 **GPT 因子构造细节**（华安 2023，工程落地关键）：①**三个单因子**——gpt_avgRecord（等权评分，正向）、gpt_ewaRecord（指数衰减加权，正向）、gpt_stdRecord（评分波动，**负向**）；中证500 合成因子 gpt_score = 三者等权合成，全A 用 gpt_avgRecord（近1月+近2月等权）。②**有效记录认定**：评分 > 0 + 剔除最低 10% 异常值；窗口 1m/2m/3m（**3m 明显弱于 1m/2m**）。③**缺失值处理**：距离最近一次盈余公告 3 个月（60 日）内用因子前值填充（JOR 同款 delay 逻辑）。④**中性化**：MAD 去极值 + 行业市值中性化 + z-score 标准化（非中性化版 gpt_avgRecord_1m RankIC 3.22%/多头超额 9.8% 但稳定性差）。⑤**相关性**：与分析师因子仅 **0.3**、与成长因子 0.2，是**新型另类因子**。

> ⚠️ **衰减警告**（华安 2023）：全A gpt_avgRecord 的 RankIC 有衰减趋势，**2021-2022 年表现较差**（全A 仅 2021 年多头超额为负）；中证500 合成因子五分组非严格单调（多头 8.81% > 空头 5.15%，属多头因子）；沪深300 域整体表现不尽人意。

#### 演进四：LLM 改写文本（华泰 2025）——LLM-FADT 大模型增强

> 来源：[📖 华泰金工 LLM-FADT 大模型增强文本选股（2025.6）](../../raw/articles/[202506120730]华泰金工LLMFADT大模型增强文本选股.md)

这是 FADT 系列的最新一篇（人工智能 57 词频 → 63 FinBERT → 92 LLM 改写），把"人读研报时所做的个性化推理"用大模型模拟出来：

**核心创新——LLM"博观"文本改写（5 个新视角）**：

> **原文佐证**（华泰 2025）：用 **Qwen3-8B**（开源、阿里通义千问；强制"快思考"模式以应对海量研报）把原始研报文本从 5 个角度**重新生成**：(1) **标题新解**、(2) **行情催化剂**、(3) **"言外之意"**、(4) **潜在风险**、(5) **收益指引**——理由是"人读研报时会做个性化推理演绎，LLM 可模拟，其他模型难以做到"。

**流程**：6 份文本（1 原文 + 5 份 LLM 改写）→ 各自用**演进二微调好的 FinBERT**（CLS 768 维）编码 → 每份文本单独训 XGBoost → **"先训练后合成"**（train-then-combine，取预测均值）优于"先合成后训练"（后者单调性更好但顶/底层区分度弱）。沿用演进二的滚动训练（样本内 6 月/样本外 12 月）、3 类标签、网格搜索+5 折交叉验证。

**效果（回测 20170126-20250530）**：

> **原文佐证**：单文本因子（10 分层第 1 层等权，相对中证500）中"行情催化剂"最强（年化超额 **17.57%**/IR 1.86），"标题新解"最弱（超额 14.30%/IR 1.62）；**LLM-FADT 合成 Top25 增强组合相对中证500 年化超额 27.60%、IR 2.21、相对月胜率 74.26%**，2017 年以来每年正超额（最大超额回撤 22.64% 发生在 2024-02-07，但快速修复）。

**LLM 相对 BERT 的增量**（关键卖点）：

> **原文佐证**："LLM 增强后的多头等权组合**持续优于 BERT-FADT**……多项指标均优于"（多头等权组合的净值比 LLM/BERT 稳步上行，仅 2021-07→2022-08 有回撤）。⚠️ **持仓数敏感性（两类组合方向不同，勿混）**：①**多头等权组合**——LLM 稳定优于 BERT，净值比总体上行；②**因子增强 Top25 组合**——LLM/BERT 净值比"先升后降"，原文归因于"组合成分股过少"；当增大到 **Top50/Top100** 时，净值比"下降趋势减缓甚至转而上升"（即增强效果需一定数量成分股才充分体现）。

**两个应用案例（标签定制化）**：① 沪深300 Top25 增强（标签 = 相对沪深300 超额）年化超额 **12.16%**/月胜率 59%；② 医药行业增强（标签 = 相对中证医药卫生超额 + 组合优化保证成分股不出指数）年化超额 **18.53%**/月胜率 69%/双边换手 3.34。

> ⚠️ **LLM 特有风险**（华泰 2025）："大模型输出准确性可能存在风险；不同大模型效果存在差异，需谨慎选择；**非本地大模型处理敏感数据或有信息泄露风险**"——个人/机构用云端 LLM 处理未公开研报时务必注意数据合规。

#### GPT 评分作为"样本筛选器"增强其他因子（独立机制）

华安这篇还有一条独立主线——用"GPT 评分 > 9 分"定义"GPT 超预期"样本（约 3 万份，多于"文本超预期"约 2 万份且收益更出色），用它增强盈余跳空 JOR 因子：

> **原文佐证**："GPT 超预期空间下 JOR 因子 ICIR 从 2.37 提升至 **2.94**，多头年化 17.1%"，"GPT 超预期 JOR 50 等权组合年化 **26.4%**，相对中证500 超额 **27.2%**"，夏普 0.98→1.04、信息比 2.3→2.5、调仓胜率 78.1%→84.4%；调仓月集中在盈余公告多、覆盖度高的 **1/4/7/8/10 月**底。

**JOR 因子定义**（便于交叉引用）：原文——"JOR（Jump of Report Date）因子从技术面构建盈余公告跳空因子，以盈余公告后次日(t)最低价相对公告当日(t-1)收盘价的跳空，剔除市场因素（相对中证500），作为股价跳空幅度"。delay40/delay60 两个版本，**delay60（缺失值填充更多）效果更好**；JOR_gptsue（GPT 超预期版）覆盖度 20% > JOR_txtsue（文本超预期版）13%。

**"GPT 超预期" vs "文本超预期"——为何 GPT 更强**：文本超预期用规则——jieba 分词 + 必选词组1（预期/预计/承诺/预告上限/一致预期）AND 必选词组2（超/超出/高于/好于/优于）− 屏蔽词组（料/或/将/望/有望/可能/待），约 2 万份。GPT 超预期优于它有两个场景：①**主体识别**（"超预期"但主体是非经常损益/成本/自营下行/价格竞争，文本误纳入，GPT 评分低）；②**上下文语义**（"消极+积极"组合 GPT 给中性偏正而非≥9）。两者重合度 67%（GPT 超预期含 85% 文本超预期）。

这条与 [01-PEAD](01-pead-earnings-surprise.md)（JOR 属 PEAD 家族）和 [03-分析师预期](03-analyst-expectation.md) 交叉——GPT 评分作为前置样本筛选器，可增强盈余类因子。

#### 配方 D 操作流程（LLM 时代，个人可做）

```
月频调仓：

   ├─ 【演进三·最省力】LLM 对研报【标题】打 1-10 连续分（system prompt + Temp=0.5）
   │   ── 批量请求控成本：每次15-20条只返回评分（华安实测￥2635/24万条）
   ├─ 【演进二·最强单模型】FinBERT 微调 + CLS 768维编码 + XGBoost
   │   ── 标签=研报前后两日超额，3类（涨30%/震荡/跌30%），滚动6月训/12月测
   └─ 【演进四·SOTA】Qwen3-8B 把原文改写成5视角(催化剂/言外之意/风险等) → 演进二流程 → 先训练后合成

5. 可选：GPT评分>9 作"GPT超预期"样本筛选器，增强JOR/PEAD因子
```

### 配方 E：凸显性收益因子 STR（招商，可得的行为金融因子）

> 来源：[📖 招商定量 行为金融新视角：凸显性收益因子 STR](../../raw/articles/[202409241422]招商定量深度报告巡礼之二十五行为金融新视角凸显性收益因子STR.md)

**一句话**：基于行为金融"凸显理论"（Salience Theory），用日收益率构造一个"凸显性收益"因子——**仅需日行情，完全可得**，是本篇唯一不依赖外部另类数据源、纯从行为金融视角衍生的因子。

#### 行为金融根基——凸显理论

> **原文佐证**（招商 2024）："BGS（2012）认为在资产的横向比较中，**投资者的注意力往往会被吸引到平均而言最具有凸显性的回报上**，而不凸显的回报往往会被忽略。"凸显性有三大特征——"**距离性、无向性、边际递减性**"。

**与前景理论的区别**（原文专门对比）："在凸显理论中，极端收益被加权的原因**并不是因为它们的发生概率小，而是因为它们在截面上相对市场平均收益来说具有凸显性**。"即：不是"暴涨暴跌"本身被加权，而是"相对市场平均最突出的那些日子"被投资者过度关注→定价偏差。

**机制**："当 STR 为显著正时……成为风险寻求者；当……STR 显著为负，相关的股票可能面临低估"——即 STR 衡量个股收益的凸显性结构，预测未来反转/修正方向。

#### STR 因子三步构造（仅需日行情，月度窗口）

> **原文佐证**：构造以**当月作为时间窗口**，对个股**当月的日收益率**进行排序（约 20 个交易日）。

> **Step 1 — 式(4) 凸显性系数 σ**：
> $$\sigma_{i,s} = \frac{|r_{i,s} - \bar{r}_s|}{|r_{i,s}| + |\bar{r}_s| + \theta}$$
> 原文："以资产的报酬 $x_{i,s}$ 相对于全市场的突出程度作为其凸显性"。**关键细节**：$\bar{r}_s$ 取**全市场收益率中位数**（非均值，规避异常值），$\theta$ 用 BGS(2012) 经验参数控制零收益影响，$\sigma \in [0,1)$。三大特征对应：分子 = **距离性**（偏离越远越凸显），分母含 $|\bar{r}_s|$ = **边际递减性**（市场整体波动大时单日凸显性被稀释），分子取绝对值 = **无向性**（涨跌同样凸显）。

> **Step 2 — 式(5) 凸显性权重 ω**：
> $$\omega_{i,s} \propto \pi_s' \cdot \delta^{(k_{i,s}-1)}, \quad \sum_s \omega_{i,s}=1, \quad \mathbb{E}[\omega]=1$$
> 原文："在时序上对个股当月的日收益率进行排序，以 $k_{i,s}$ 作为序号……$\delta$ 用来衡量投资者的认知能力"。$\pi_s' = 1/T$（随机游走的客观概率），$k_{i,s}$ = 日收益按凸显性从高到低排序的序号，$\delta \in (0,1]$（$\delta=1$ 完全理性等权，$\delta \to 0$ 仅关注最凸显日）。

> **Step 3 — 式(6) STR 因子**：
> $$\text{STR} = \text{cov}[\omega, r]$$
> 原文："以 $\omega_{i,s}$ 和股票收益率 $r_{i,s}$ 的**协方差作为最终的'凸显性收益'选股因子 STR**"。即凸显性权重与收益率的协方差——若一只股票的**最高收益**恰具有最高凸显性，STR 取大正值（**被高估**）；若**最负收益**最凸显，STR 取大负值（**被低估**）。

> 💡 **可得性**：STR 仅需"日收益率 + 全市场日收益率中位数"即可构造（式4-6），是 playbook 已有数据——这与本篇其他"不可得"子集（招聘/卫星/点击量）形成鲜明对比。覆盖度：沪深300/中证500/中证1000 几乎 100%，全A 自 2005 年起始终 80%+，围绕 90% 中枢波动。

> ⚠️ **参数标注**：原文给出 $\delta \in (0,1]$、$\theta$ 用 BGS(2012) 经验值，但具体数值在图表中（Cosemans et al. 2021 常用 $\delta \approx 0.1$、$\theta \approx 0.01$，仅供复现参考，原文未在正文明列）。

#### 与反转因子的关键差异——2020-2021 失效期仍有效

这是 STR 相对传统反转的核心增量卖点：

> **原文佐证**："自 2020 年的'抱团'行情以来，**A 股的反转效应明显减弱**……而基于凸显理论的 **STR 因子依然能够稳定相对市场获得超额收益**，因此在 2020 年和 2021 年，改进模型相较基准模型的相对超额收益获得了**显著的跃升**"。

**多因子模型对比（用 STR 替换反转因子 REV，非叠加）**：

> **原文佐证**："我们将模型中的反转因子**替换**为本文所构建的 STR 因子"——基准模型（FF6 去投资因子 + 异常换手 ABTOV，含 REV）"累计收益 1610%、年化 20.25%、夏普 0.527"；用 STR 替换 REV 后"累计收益 **2958%**、年化 **24.88%**、夏普 **0.686**、年化超额 **19.78%**"（年化增益 **+4.63%**），且 2008 年以来多空净值长期稳定跑赢 REV 版。

且经二维分组 + 截面回归证明"STR 因子对股票价格的影响**并非出于短期反转效应、投资者有限关注或者小市值效应**，是一种全新的行为金融指标"（STR 与反转中度相关但控制 REV 后 STR 仍单调、与异常换手 0.29 弱相关、与规模 <1%；截面回归 Newey-West 调整后 STR 风险溢价仍显著）。

#### 配方 E 操作流程（日行情可得）

```

```

## 四、落地到 QMT

**信号频率**：双周频（新闻舆情 ΔMS）/ 月频（研报情感/STR/概念热度/月历）

## 六、关键风险与避坑

| 风险点 | 说明 | 来源 |
|---|---|---|
| **绝对水平无效，要边际变化** | MS 直接用效果差，ΔMS 才有效 | 开源 2021 |
| **新闻ΔMS多头端弱（口径修正）** | 双周频多头超额仅1.72%（多空强但alpha在空头）；月频多头4.61%但ICIR降。选多头用月频，做对冲/剔除用双周频 | 开源 2021 |
| **新闻ΔMS方向是从负ICIR推断** | 原文未明示"反转/负向因子"机制，方向由 ICIR 为负（-2.3）+ 情感分越高=越正面 联合推断；落地时先小样本验证方向 | 开源 2021 |
| **关注度是负向因子（标签修正）** | 正文原标"关注度溢价"实为**关注度折价**——"人多的地方不要去"，三类因子 RankIC -10%/-6.10%/-7.58%，alpha在空头端 | 开源 2022 |
| **关注度是"水平"而非"方向"在起作用** | 原文核心发现："影响个股未来表现的，是投资者关注度的高低，而非投资者关注度的方向"——即不论关注度上升或下降，只要绝对水平高未来就差。这比"高关注→反转"的直觉更深 | 开源 2022 |
| **关注度alpha主要在散户/小资金端** | "低资金投资者点击量占比高的个股未来表现相对更差"；低资金用户自选股池信息更偏负面——"散户/dumb money"机制 | 开源 2022 |
| **招聘因子不能直接用** | 沪深300无效、全域首年多空为负（失效风险）、净值波动大且绝对收益不显著；仅在ROE分域(高成长池)后才有意义(IR 1.15→1.46/多头超额15%，且高低域IC呈一正一负的符号翻转) | 开源 2021 |
| **招聘因子需要成长性才有意义** | 机制："企业处于行业景气周期或高速发展阶段时……招聘需求不断释放"——故沪深300(成熟大公司)无效，高成长域才有效 | 开源 2021 |
| **文本情感标注忌用行情反推** | 不能用次日涨跌给文本打标签，否则引入look-ahead偏误；应人工/LLM客观标注；李立/通联的做法是只标"事件类型"（强/弱/不相关三分类），彻底回避行情标签 | 通联/李立 2021 |
| **研报四分类要把"正面"拆两档** | 分析师报告天然偏正面，负面样本极少；需把正面拆成"一般正面/强烈正面"以平衡样本（负面不拆）| 通联/李立 2021 |
| **研报情感 vs 新闻情感本质不同** | 研报情感刻画基本面（分析师专业、不追涨杀跌），新闻情感短期反映情绪；前者进基本面模型，后者做反转/择时 | 通联/李立 2021 |
| **GPT评分因子有天花板** | 分析师对盈余的评论主要是文字描述，很少涉及数值，故全A RankIC仅2.8%；中证500域3.6%较好；沪深300域整体表现不尽人意 | 华安 2023 |
| **GPT因子有衰减** | 全A gpt_avgRecord 的 RankIC 有衰减趋势，2021-2022年表现较差（全A仅2021年多头超额为负）| 华安 2023 |
| **LLM打分一致性** | 需 system prompt + Temperature=0.5 控随机性；批量请求控成本（￥2635是逐条理想成本，批量再降4/5）| 华安 2023 |
| **LLM-FADT持仓数敏感（方向需分组合看）** | 多头等权组合：LLM 稳定优于 BERT，净值比上行；因子增强 Top25 组合：LLM/BERT 净值比"先升后降"（成分股过少），增大到 Top50/100 后下降减缓甚至转升（增强效果需一定数量成分股才充分体现）。非本地大模型有数据泄露风险 | 华泰 2025 |
