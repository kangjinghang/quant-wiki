## 一、策略本质：赚的是什么钱

情绪/另类数据策略用**非传统数据源**（新闻舆情、招聘、社交媒体、卫星、文本、投资者关注度等）捕捉市场情绪和基本面变化的**早期信号**——这些信息往往领先于传统财报和价格数据。

**赚的是什么钱**：另类数据能提供传统数据没有的**增量信息**。比如招聘数据反映企业扩张意愿（领先于财报披露），新闻舆情边际变化反映市场关注度的拐点，研报文本措辞藏着分析师没写进评级里的真实态度。

> **原文佐证**（开源金工 2021）："新闻舆情数据作为其中另类数据的模块之一，**蕴含丰富的股票情感信息**。"
> 📖 [新闻舆情数据选股能力初探](../../raw/articles/[202107092032]新闻舆情数据选股能力初探开源金工.md)

### 这个方向的两条核心规律

**①"边际变化 > 绝对水平"**——这是新闻舆情最重要的发现：

> **原文佐证**（开源 2021，新闻舆情）："原始的新闻舆情分数平均值（MS）因子直接用于选股效果不佳，但其**边际变化**——即过去 N 天舆情分数平均值的变化量（ΔMS）——构成的因子却表现出显著的有效性。这一发现揭示了一个重要的市场微观结构规律：**市场对新闻舆情的边际变化比绝对水平更有定价意义**。"

**直觉**：一只股票一直是新闻热点（绝对水平高）已被定价，没有 alpha；但"突然变热"或"突然变冷"（边际变化）是新的信息，市场还没反应。

**②"关注度绝对水平高 → 未来收益差"（负向因子）**——这是投资者关注度的发现，和"边际变化"相反相成：

> **原文佐证**（开源 2022，投资者关注度）："谚语有云，'**人多的地方不要去**'。对于个股而言，高点击量占比是否意味着个股的市场关注度过高，投资者情绪达到极端值，导致相关个股未来的潜在回报为负？从测试结果来看，**符合前述猜测**……**投资者个股关注度因子具有稳健的负向选股能力**。"
> 📖 [自选股与点击量投资者关注度的选股能力](../../raw/articles/[202203271728]自选股与点击量投资者关注度的选股能力开源金工.md)

**直觉**：关注度绝对水平高 = 情绪过热 = 已被定价甚至过度反应 → 未来反转回落。注意这和规律①的角度不同——①看舆情的**变化**（边际），②看关注度的**水平**（绝对）；两者都指向"已被充分关注的信息没有 alpha"。

## 三、策略配方（可得子集）

下面给五个配方，**按可得性和效果排序**：

**可得且强（个人投资者主力）**：
- **配方 A**：新闻舆情边际变化 ΔMS（开源，LLM 降级可得）—— 多空强但多头弱，宜做负向过滤。
- **配方 D**：研报文本情感（华泰 FADT / 华安 ChatGPT，LLM 时代可得）—— **多头端最强**（超额 9-19%），是个人投资者用 LLM 的新机会。
- **配方 E**：凸显性收益因子 STR（招商，**仅需日行情**）—— 行为金融因子，2020-2021 反转失效期仍有效。

**辅助**：
- **配方 B**：概念热度 / 主题（可得，主题轮动辅助）。
- **配方 C**：月历效应（✅ 已有，择时辅助）。

> ⚠️ **不可得但已验证有效的两条**（招聘、投资者关注度）见 §六风险表的"方法论记录"，待数据可得后可启用。

### 配方 A：新闻舆情边际变化 ΔMS（开源，可得降级版）

> 来源：[📖 开源金工 新闻舆情数据选股能力初探](../../raw/articles/[202107092032]新闻舆情数据选股能力初探开源金工.md)

**一句话**：算新闻舆情分数的"边际变化"（ΔMS），买舆情突然变负的（反转）、卖变正的。**注意：alpha 集中在空头端，多头端很弱，更适合做负向过滤。**

#### 关键——边际变化而非绝对水平

> **原文佐证**："原始的新闻舆情分数平均值（MS）因子直接用于选股效果不佳，但其**边际变化**（ΔMS）却表现出显著的有效性。"

#### 打分方向与数据清洗（落地关键）

> **原文佐证**："使用通联数据中'getNewsRelatedScoreV2'……主要是对上市公司的新闻进行**情感分数打分（SentimentScore），分数值越高通常意味着新闻对该个股有正面情绪**。"（即 ΔMS 为**负向因子**——舆情变负的反而未来涨，做反转）
>
> 数据清洗规则："保留属于上市公司的新闻……已对数据进行初筛，**删除包括属于月度数据、是定期报告、属于图片新闻的记录**。"

> 💡 **LLM 降级时的符号**：情感分越高=越正面，所以 ΔMS 越负 = 舆情突然变差 = 反转信号（买入）。用 LLM 打分时务必保持"高分=正面"的口径，否则符号全反。样本规模参考：开源初筛后共 **487 万条**新闻，日均覆盖约 **1600 只**个股，**4 月**（年报+一季报）新闻频次达年内最高。

#### 怎么算

> **原文佐证**："计算过去 N 天舆情分数平均值的变化量：**ΔMS = MS(N) − MS(前N天)**。"

#### 效果（双周频 vs 月频，口径务必分清）

> **原文佐证**："因子在三种不同换仓频率下的表现：**双周频 > 月频 > 周频**。在双周频上该因子的多空对冲年化收益率为 **12.00%**，**多头相对中证500 年化收益率仅 1.72%**，因子的年化 ICIR 为 **-2.3**；月频下，该因子的多空对冲年化收益率 11.92%，**多头相对中证500 的年化收益率为 4.61%**，因子年化 ICIR 为 **-2.00**。"

> ⚠️ **口径修正**：此前正文把"多头超额 4.6%"与"双周频多空 12%"并列引用，易误读为"双周频多头超额 4.6%"——实际**双周频多头超额仅 1.72%**（4.61% 是月频）。双周频 alpha 集中在空头端。

**纯度高（剔除常见因子仍有效）**：

> **原文佐证**："与过去 20 日涨跌幅的相关性接近 0.1，与其余常见因子的相关性较弱……剔除常见 10 个因子后，**多空收益波动比达 2.64，年化 ICIR -2.27**，多头相对中证500 年化收益率 4.86%。"

**数据降级方案**：开源原版用通联数据（商业源）。降级版可用**问财/东财新闻 + LLM 情感打分**替代（华安 2023 已验证 ChatGPT 处理研报文本可行，见配方 D）。

#### 配方 A 操作流程

```
双周频（做对冲/负向剔除）或月频（做多头）：
1. 拉个股新闻（问财/东财，🔵），清洗：剔除定期报告/月度数据/图片新闻/非个股新闻
2. 用 LLM 对每条新闻情感打分（-1 到 1，保持"高分=正面"口径）
3. 算过去 N 天舆情分数均值 MS(N)，及变化量 ΔMS = MS(N) − MS(前N天)
4. 按 ΔMS 排序（负向因子：舆情突然变负的，反转回升）
   ── 双周频：alpha在空头端，宜做空头剔除/对冲
   ── 月频：多头端稍强（超额4.61%），可做多头
5. 剔除常见10因子后取残差（提升纯度，ICIR -2.27）
6. 调仓（双周或月）
```

### 配方 C：月历效应（✅ 已有，简单有效）

**一句话**：A 股存在显著的月历效应（如"春季躁动"），用日历规律做择时辅助。

> **原文佐证**（中金固收 2023，转债月历）："**七八月往往是基本面策略占优的时间段**……上市公司开始密集发布上半年业绩，并对全年业绩与后续展望提供指引。以 EPS 排序来作为择优方式……2014 年以来排序靠前的标的，普遍在 7-8 月提供较高赢率"，"组合在 6-8 月相对等权指数有一定增厚"。
> 📖 [可转债月历效应](../../raw/articles/[202307231426]中金固收可转债月历效应与基于预期的转债基本面择优.md)

> 💡 月历效应是**最易得的另类信号**（只需日历）。中金固收发现转债基本面组合的超额在 **6-8 月最显著**（驱动是半年报密集披露，而非春季躁动）。但单独价值有限，作为其他策略的择时辅助。本篇主体（转债基本面择优/EasyBall增强）属转债策略，详见 [26-可转债](26-convertible-bond.md)。

### 配方 D：研报文本情感（LLM 时代可得，多头端最强）

**一句话**：用 NLP/LLM 处理分析师研报文本，提取情感因子。这是个人投资者过去拿不到（需付费 NLP）、**现在用 LLM 可低成本实现**的新机会。三家机构给出了从早期 NLP → BERT → ChatGPT 的完整演进。

#### 为什么"文本情感"是独立的 alpha（相对分析师评级/预期的增量）

分析师的评级和盈利预测调整频率很低，但研报文本每篇都有，能捕捉藏在措辞里的态度：

> **原文佐证**（通联/李立 2021）："分析师大约间隔 **226 天**会调整一次所覆盖公司的股票评级……净利润和营收的调整大约是间隔 **94 天**……而基于文本分析的研报情感态度数据，它的研报篇数的间隔是 **1**，在每篇研报发布后都可以得到数据。"而且"分析师发现覆盖公司存在隐忧或一些负面变化……**不会很张扬地通过研报中的预测和评级来表达他的态度**……通过基于文本数据来分析研报中的措辞，是可以把握分析师情绪的变化情况，尤其是负面情绪的变化。"
> 📖 [基于文本的研报情感数据应用](../../raw/articles/[202104132050]李立基于文本的研报情感数据应用开源金工沙龙.md)

#### 演进一：早期 NLP（通联/李立 2021）——四分类 + 三权重

> **原文佐证**："用研报摘要核心观点……对每个核心观点进行打分……通常的做法是将各段情感打分等权求和，但……**给负面情感得分的权重设置得更大一些**"；时间序列"往前看 **120 天**……**时间衰减权重**（越近权重越高）、**数字权重**（数字越多可信度越高）、**热度权重**（浏览量越高权重越高）"；并强调"只用公司报告"（行业/宏观报告用词更模糊）。
>
> 效果（中证800 周度调仓）："提纯后的因子 IC 为 **3.25%，ICIR 为 1.88，t 值为 5.37，胜率在 62% 左右"；纯因子"年化收益率 **5.31%**，IR 等于 **2.96**，换手率大概为 6 倍"。

> ⚠️ **方法论告诫**（李立 2021）："我们不能使用行情数据来给文本进行情感打分……这是一件非常危险的事情，最终文本的情感的结果是客观的，它不应该随着市场行情变化而改变。"——即**文本情感标注应人工标注，忌用次日行情反推标签**（会引入 look-ahead 偏误）。个人投资者用 LLM 自建标注集时务必注意。

#### 演进二：BERT 化（华泰 FADT 2022）——FinBERT 编码 + XGBoost

**FADT 框架**："以分析师研报文本的词频向量为特征，以**研报发布前后两日个股超额收益为标签**，引导 XGBoost 模型学习研报情绪蕴含的超额信息"——即把"这份研报文本 → 随后涨还是跌"的映射学出来。因子值由"上涨和下跌类别 log-odds 值之差作为文本得分……将个股过去一个季度有关盈利预测调整的全部点评研报文本得分求均值"。标签分上涨(前30%)/震荡(30-70%)/下跌(后30%)三类，滚动训练样本内6个月、样本外12个月。

**"再探"的升级点——FinBERT 隐藏层编码替代词频向量**：

> **原文佐证**（华泰 2022）："我们将词频向量替换为 **FinBERT 隐藏层编码**的特征向量……隐藏层编码蕴含更丰富的文本语义信息，相比词频信息损失更少。"并解释词频的缺陷——"'成本上调'是负向、'盈利预测上调'是正向，词频模型无法学习"。
>
> 效果："升级以后的文本因子十分层多头第一层年化收益由原版的 **22.87% 提升至 27.50%**，相对中证500 超额收益由 **14.75% 提升至 19.19%**（回测期 20090123-20220930）。"

**正交性（可叠加的依据）**：

> **原文佐证**："文本因子与动量因子正相关性相对较高，历史均值大约在 0.3 左右；与 BP 因子负相关性相对较高……**与其余风格因子整体相关性偏低**……文本因子与传统因子相关性也较低，**历史每个截面期的相关系数均值都不超过 0.5**。"

#### 演进三：ChatGPT 时代（华安 2023）——低成本 LLM 实现

这是"个人投资者用 LLM 低成本实现"的关键依据，工程细节此前完全没展开：

**打分方法（标题而非全文，1-10 连续分）**：

> **原文佐证**（华安 2023）：用 gpt-3.5-turbo 对"公司研究"类研报**标题**打分（非全文），样本 2016.01.01-2023.06.30 共 **24 万余条**；"要求 ChatGPT 给出 **1-10 连续的分数**，而非积极(+1)、消极(-1)、中性(0)这三种离散的结果"；采用"**系统提示(system role) + Temperature=0.5**"控随机性，"批量请求 + 只返回评分"每次 15-20 条标题，"**成本下降了 4/5，约 15 个小时便能完成全部标题评分**"，理想成本约 **￥2635 元**。

**为何 LLM 优于传统 NLP（BERT 三大局限）**：

> **原文佐证**：BERT ①"离散情感值的局限性"；②"对细微情感表达的不敏感性（'再超预期''大超预期'比'略超预期'更积极但 BERT 评分无差异，'大超预期'标题竟被判负面）"；③"情感评估的逻辑不一致性"。而 ChatGPT"**评分时具有连续性，且能精确识别句子中的关键信息和其情感倾向**"。

**效果**：

> **原文佐证**：中证500 域"GPT 合成因子 gpt_score 的 **RankIC 为 3.6%，ICIR 1.53，IC 月胜率 74%，多头年化超额 9.3%**，多头组合**每年均为正超额**，近三年超额分别为 **7.04%、17.09% 和 2.96%**"；全A"gpt_avgRecord 的 RankIC 为 2.8%，ICIR 为 1.6……多头年化超额 5.2%，多空年化超额 12.7%"。

#### GPT 评分作为"样本筛选器"增强其他因子（独立机制）

华安这篇还有一条独立主线——用"GPT 评分 > 9 分"定义"GPT 超预期"样本（约 3 万份，多于"文本超预期"约 2 万份且收益更出色），用它增强盈余跳空 JOR 因子：

> **原文佐证**："GPT 超预期空间下 JOR 因子 ICIR 从 2.37 提升至 **2.94**，多头年化 17.1%"，"GPT 超预期 JOR 50 等权组合年化 **26.4%**，相对中证500 超额 **27.2%**"。

### 配方 E：凸显性收益因子 STR（招商，可得的行为金融因子）

> 来源：[📖 招商定量 行为金融新视角：凸显性收益因子 STR](../../raw/articles/[202409241422]招商定量深度报告巡礼之二十五行为金融新视角凸显性收益因子STR.md)

**一句话**：基于行为金融"凸显理论"（Salience Theory），用日收益率构造一个"凸显性收益"因子——**仅需日行情，完全可得**，是本篇唯一不依赖外部另类数据源、纯从行为金融视角衍生的因子。

#### 行为金融根基——凸显理论

> **原文佐证**（招商 2024）："BGS（2012）认为在资产的横向比较中，**投资者的注意力往往会被吸引到平均而言最具有凸显性的回报上**，而不凸显的回报往往会被忽略。"凸显性有三大特征——"**距离性、无向性、边际递减性**"。

**与前景理论的区别**（原文专门对比）："在凸显理论中，极端收益被加权的原因**并不是因为它们的发生概率小，而是因为它们在截面上相对市场平均收益来说具有凸显性**。"即：不是"暴涨暴跌"本身被加权，而是"相对市场平均最突出的那些日子"被投资者过度关注→定价偏差。

**机制**："当 STR 为显著正时……成为风险寻求者；当……STR 显著为负，相关的股票可能面临低估"——即 STR 衡量个股收益的凸显性结构，预测未来反转/修正方向。

#### STR 因子三步构造（仅需日行情）

> **原文佐证**：
> **Step 1（凸显性系数）**："以资产的报酬 x_{i,s} 相对于全市场的突出程度作为其凸显性"（式4）。
> **Step 2（凸显性权重）**："在时序上对个股当月的日收益率进行排序，以 k_{i,s} 作为序号……δ 用来衡量投资者的认知能力"（式5）。
> **Step 3（STR 因子）**："以 ω_{i,s} 和股票收益率 r_{i,s} 的**协方差作为最终的'凸显性收益'选股因子 STR**"，即 **STR = cov(ω, r)**"（式6）。

> 💡 **可得性**：STR 仅需"日收益率 + 市场平均收益率"即可构造（式4-6），是 playbook 已有数据——这与本篇其他"不可得"子集（招聘/卫星/点击量）形成鲜明对比。覆盖度：沪深300/中证500/中证1000 几乎 100%，全A 自 2005 年起始终 80%+。

#### 效果（IC 极强、多头突出）

> **原文佐证**："在全 A 股样本中的 IC 均值及 T 统计量分别为 **-0.065 和 -9.348**……ICIR 分别为 -6.5% 和 **-6.78%**……**IC 胜率达到了 76.3%**"；分位数测试"STR 因子的 Top 组合……年化收益率和夏普比率分别为 **22.18% 和 0.691**"。
>
> 选股策略（2007.2-2022.11，扣单边 0.3%）："在沪深 300、中证 500 和全 A 股票池中的年化收益分别为 **10.84%、10.61% 和 17.14%**，相对基准指数的年化超额分别为 **7.7%、3.59% 和 12.05%**"。

> ⚠️ **口径区分**：原文同时给了"分位数 Top（全A 年化 22.18%，五分组单调性测试）"和"选股策略等权（全A 年化 17.14%/超额 12.05%，扣费后多头选股）"两个口径，引用时勿混。

#### 与反转因子的关键差异——2020-2021 失效期仍有效

这是 STR 相对传统反转的核心增量卖点：

> **原文佐证**："自 2020 年的'抱团'行情以来，**A 股的反转效应明显减弱**……而基于凸显理论的 **STR 因子依然能够稳定相对市场获得超额收益**"；"基准模型（REV）的年化收益率和年化超额分别为 20.25% 和 15.16%，而……改进后的多因子模型（加 STR）年化收益率和年化超额分别为 **24.88% 和 19.78**"。

且经二维分组 + 截面回归证明"STR 因子对股票价格的影响**并非出于短期反转效应、投资者有限关注或者小市值效应**，是一种全新的行为金融指标"（STR 与反转中度相关、与异常换手 0.29 弱相关、与规模 <1%）。

#### 配方 E 操作流程（日行情可得）

```
月频调仓：
1. 拉每只股票当月日收益率 + 市场平均日收益率（✅ 已有）
2. 三步算 STR：
   ├─ Step1：算每日收益相对全市场的凸显性系数
   ├─ Step2：按日收益排序得凸显性权重ω（δ 衡量认知能力）
   └─ Step3：STR = cov(ω, r) （凸显性权重与收益率的协方差）
3. 按 STR 排序选股（负向因子：STR 显著负→低估→看多）
4. 可作短期反转因子的替代/增强（2020-2021 反转失效期仍有效）
```

## 四、落地到 QMT

**信号频率**：双周频（新闻舆情 ΔMS）/ 月频（研报情感/STR/概念热度/月历）
**QMT 用法**：盘后批量

```
【盘后批量生成信号】
配方 A（新闻ΔMS，双周/月频，🔵 LLM降级）：
  1. 拉个股新闻（问财/东财），清洗剔除定期报告/图片新闻/非个股新闻
  2. LLM 情感打分（-1~1，保持"高分=正面"口径）
  3. 算 ΔMS = MS(N) − MS(前N天)，按负向排序
  4. 剔除常见10因子取残差（提升纯度）
  5. 双周频做对冲/负向剔除；月频做多头（超额4.61%）

配方 D（研报情感，月频，🔵 LLM）：
  1. 拉分析师研报（东财），只用"公司研究"类
  2. LLM 对标题打 1-10 连续分（system prompt+Temp=0.5，批量请求控成本）
  3. 个股聚合（过去1季度盈利调整类研报均值）
  4. 按 GPT 情感分排序选股（中证500域 多头超额9.3%）
  5. 可选：GPT>9 作"GPT超预期"样本筛选器增强JOR

配方 E（STR，月频，✅ 日行情）：
  1. 拉当月日收益率 + 市场平均日收益率
  2. 三步算 STR = cov(凸显性权重ω, 收益率r)
  3. 按 STR 负向排序选股（全A多头超额12.05%）
  4. 可替代/增强短期反转因子

辅助（月频）：
  6. 概念热度（同花顺）→ 主题轮动辅助
  7. 月历效应 → 择时辅助（6-8月基本面策略占优）
```

## 六、关键风险与避坑

| 风险点 | 说明 | 来源 |
|---|---|---|
| **绝对水平无效，要边际变化** | MS 直接用效果差，ΔMS 才有效 | 开源 2021 |
| **新闻ΔMS多头端弱（口径修正）** | 双周频多头超额仅1.72%（多空强但alpha在空头）；月频多头4.61%但ICIR降。选多头用月频，做对冲/剔除用双周频 | 开源 2021 |
| **关注度是负向因子（标签修正）** | 正文原标"关注度溢价"实为**关注度折价**——"人多的地方不要去"，三类因子 RankIC -10%/-6.10%/-7.58%，alpha在空头端 | 开源 2022 |
| **招聘因子不能直接用** | 沪深300无效、全域首年多空为负（失效风险）、净值波动大；仅在ROE分域(高成长池)后才有意义(IR 1.15→1.46/多头超额15%) | 开源 2021 |
| **文本情感标注忌用行情反推** | 不能用次日涨跌给文本打标签，否则引入look-ahead偏误；应人工/LLM客观标注 | 通联/李立 2021 |
| **GPT评分因子有天花板** | 分析师对盈余的评论主要是文字描述，很少涉及数值，故全A RankIC仅2.8%；中证500域3.6%较好 | 华安 2023 |
| **LLM打分一致性** | 需 system prompt + Temperature=0.5 控随机性；批量请求控成本 | 华安 2023 |
| **商业数据源依赖** | 新闻舆情原版用通联数据（付费），招聘用通联数据，需 LLM 降级 | 开源 2021 |
| **STR vs 反转** | STR 与反转中度相关但非反转效应本身（与异常换手0.29/规模<1%）；2020-2021反转失效期 STR 仍有效，可作反转替代/增强 | 招商 2024 |
| **另类数据衰减快** | 随关注度提升，另类 alpha 可能快速衰减 | 综合 |
| **新闻噪声大** | 新闻数据需去重、时间戳修正、剔除定期报告/图片新闻 | 开源/通联 |

> 📋 **不可得但已验证有效的方法论记录**（数据可得后可启用）：
> - **招聘数量因子**（开源 2021）：因子 = 月新增招聘广告总量，市值+行业中性化，宽基3分/全A5分。高成长(ROE分域)池 IR 1.46、多头超额15%；**行业景气先行指标**——"某个行业下多个企业开始集中发布招聘信息时，也许是行业景气上行的先行指标"（汽车招聘覆盖率提升显著、传媒/房地产下滑）。📖 [上市公司招聘数据的选股能力](../../raw/articles/[202105120829]上市公司招聘数据的选股能力开源金工.md)
> - **投资者关注度因子**（开源 2022，负向）：①个股点击量占比 = 个股当天点击量/全市场点击量（RankIC -10%/多空19.83%）；②新闻点击量占比（RankIC -6.10%/多空9.71%）；③自选股占比 = 个股自选股用户数/合计（RankIC -7.58%/多空16.51%/夏普1.94）。需取对数处理厚尾 + 市值行业中性化。中证1000增强年化超额4.7%/回撤4.4%。📖 [自选股与点击量投资者关注度的选股能力](../../raw/articles/[202203271728]自选股与点击量投资者关注度的选股能力开源金工.md)
