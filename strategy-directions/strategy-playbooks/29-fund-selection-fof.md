## 一、策略本质：赚的是什么钱

基金优选/FOF 策略**不选个股，选基金**——通过分析公募基金的持仓、业绩归因、风格特征，优选绩优基金（或借鉴其持仓）来构建组合。

**赚的是什么钱**：
1. **选基金**：识别有真Alpha的基金经理（而非靠运气/风格的）
2. **借鉴持仓**：绩优基金的持仓本身就是高质量的选股域

> **原文佐证**（华安金工 2021）："近年来，随着投资者对'好的赛道，好的公司'的认知逐步一致……公募基金作为市场主要参与者，其力量与日俱增。"
> 📖 [如何借鉴赛道型基金持仓](../../raw/articles/[202109101509]华安金工如何借鉴赛道型基金持仓基于业绩归因视角量化基本面系列报告之四.md)

### 两类基金研究的不同难点

| 基金类型 | 难点 | 核心方法 |
|---|---|---|
| **股基** | 持仓粉饰（季末调仓掩盖真实持仓）| 业绩归因（FF3/Brinson）+ 换手率/虚实净值差筛选 |
| **债基** | 信息披露更少（重仓券仅前5且占比低20-30%）| 收益来源拆解（四效应）|

### 债基研究的核心难点

> **原文佐证**（中银量化 2021）："信息披露有限是债券基金研究的核心难点。**债基重仓券公开信息量较少**，财报仅公布前五大重仓券，且前五大重仓券占比较低（通常 20%-30%），难以直接通过其持仓洞见季度节点个券配置情况。"
> 📖 [债基收益来源的拆解方法](../../raw/articles/[202107160936]中银债基研究深度一债基收益来源的拆解方法.md)

## 三、策略配方

### 配方 A：赛道型基金持仓借鉴 + 增强（华安，股基，可得）

> 来源：[📖 华安金工 如何借鉴赛道型基金持仓](../../raw/articles/[202109101509]华安金工如何借鉴赛道型基金持仓基于业绩归因视角量化基本面系列报告之四.md)

**一句话**：分赛道选出真正有选股能力的绩优基金，借鉴它们的持仓构建组合，再用多因子增强。

#### 第一步：初筛基金池（剔除粉饰）

> **原文佐证**："我们先用**换手率和虚实净值差**初筛选基金池，一定程度上可以缓和**静态持仓假设和持仓粉饰**所带来的问题。"

**为什么要筛**：基金季报只披露期末持仓，基金经理可能季末调仓"粉饰"持仓。换手率低 + 虚实净值差小的基金，持仓更可信。

#### 第二步：业绩归因分赛道选绩优

> **原文佐证**："参考 FAMA-French 三因子模型以及 Brinson 模型从基金收益率序列和持仓对基金业绩进行归因，从**选股能力和选股能力稳定性**两个维度……选出板块内选股收益最高的 50 只基金的持仓作为该板块的优选持仓。"

**四个打分指标**：FF3 alpha、改进版 Brinson 选股收益、FF3 alpha 夏普比、Brinson 选股收益夏普比。

#### 第三步：多因子增强

> **原文佐证**："以精选持仓组合为基准，利用组合优化和多因子选股模型构建增强策略，**策略年化收益达 26.04%，相对股基年化超额收益为 17.03%**……融入优秀配置基金行业观点后的增强策略的年化收益提升至 **26.94%**。"

#### 配方 A 操作流程

```
每季频（基金季报披露后）：
1. 初筛：换手率 + 虚实净值差 → 可信持仓基金池
2. 业绩归因：FF3 + Brinson，4指标打分
3. 分赛道（大类板块）选选股收益最高的50只基金
4. 汇总优选持仓 → 分赛道精选持仓组合
5. 多因子增强：以精选持仓为基准，组合优化+多因子
6.（可选）融入优秀配置基金行业观点调板块约束
7. 季频调仓
```

### 配方 B：债基收益拆解 + 踩雷识别（中银，债基）

> 来源：[📖 中银量化 债基收益来源的拆解方法](../../raw/articles/[202107160936]中银债基研究深度一债基收益来源的拆解方法.md)

**一句话**：把债基收益拆成四个来源，识别哪些是真能力、哪些是杠杆/运气；再识别"踩雷"债基（重仓违约券）。

**四效应拆解**：

> **原文佐证**："将收益率拆解为**杠杆效应、分红效应、流动性管理效应和投资管理效应**，并对投资管理效应进一步拆分。"

| 效应 | 衡量什么 |
|---|---|
| **杠杆效应** | 加杠杆增厚的收益 |
| **分红效应** | 持券的票息 |
| **流动性管理效应** | 应对申赎的管理能力 |
| **投资管理效应** | 真正的择券/波段能力（核心）|

**踩雷识别**：识别重仓违约信用债的债基。⚠️ 注意：踩雷识别的精确版依赖**中债估值数据**（付费），个人投资者可用公告/新闻的违约事件近似（降级版）。

> ⚠️ **数据门槛**：债基踩雷识别依赖中债估值（❌ 付费），这是本方向归 🟡 的主要原因。股基侧（配方A）完全可得。

### 配方 C：转债基金优选（中金，转债基金）

> 来源：[📖 中金固收 转债基金择时择券能力](../../raw/articles/[201907291729]中金固收可转债转债基金择时择券能力如何区分及Python实现方法2019.md) + [📄 转债基金五维画像体系](../../wiki/concepts/转债基金五维画像体系.md)

**一句话**：用 CL 模型对转债基金归因（拆择时/择券贡献），优选有能力圈的转债基金。

#### 配方对比

| | 配方 A 股基持仓借鉴 | 配方 B 债基拆解 | 配方 C 转债基金 |
|---|---|---|---|
| **对象** | 股基 | 债基 | 转债基金 |
| **方法** | FF3+Brinson+增强 | 四效应拆解 | CL模型归因 |
| **效果** | 增强**26.04%** | 识别真能力 | 五维画像 |
| **可得性** | ✅ | ⚠️（踩雷需中债估值）| ✅ |

## 四、落地到 QMT

**信号频率**：季频（基金季报）
**QMT 用法**：盘后批量


## 六、关键风险与避坑

| 风险点 | 说明 | 来源 |
|---|---|---|
| **持仓粉饰** | 基金季末调仓掩盖真实持仓，需换手率/虚实净值差筛 | 华安 2021 |
| **债基信息少** | 重仓券仅前5且占比低(20-30%)，难直接看持仓 | 中银 2021 |
| **债基踩雷需中债估值** | 精确识别依赖付费数据，个人用违约公告降级 | 中银 2021 |
| **"收入构成法"局限** | 大额申赎会扭曲收入构成，要用四效应拆解 | 中银 2021 |
| **运气 vs 能力** | 短期超额可能是运气/风格，需稳定性指标（夏普比）| 华安 2021 |
| **风格漂移** | 基金经理换人/风格切换，历史归因可能失效 | 综合 |
