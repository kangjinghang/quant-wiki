# EVL因子 / Extra-Large Order Residual Factor

## Definition / 定义

EVL因子（Extra-Large Order Residual Factor）是从超大单成交占比因子中通过线性回归剔除大单成交占比因子后得到的残差因子。它衡量的是股票交易者结构中，超大单相对大单的"超额"活跃程度——即在控制了大单交易水平之后，超大单交易的异常偏离。

该因子由[[开源金工]]团队（魏建榕、傅开波等）在2020年5月的研究报告[[交易者行为与市值风格]]中提出。研究基于A股全市场2008-2020年的数据，按挂单金额将交易者划分为超大单（>100万元）、大单（20-100万元）、中单（4-20万元）、小单（<4万元）四类。

## Construction / 构建方法

### 基础因子：成交占比因子

对每只股票取过去20个交易日，计算各类成交额之和并除以总成交额：

$$\text{ratio}_{\text{type}} = \frac{\sum_{i=1}^{20} \text{volume}_{\text{type},i}}{\sum_{i=1}^{20} \text{volume}_{\text{total},i}}$$

其中 type 可取 exlarge（超大单）、large（大单）、median（中单）、small（小单）。

### EVL因子提纯

由于各成交占比因子之间存在较强的相关性，直接做市值中性化后效果不佳。EVL采用回归残差法：

1. 在截面时刻 $t$，记超大单占比因子值为 $y_t$，大单占比因子值为 $x_t$
2. 做线性回归：$y_t = a \cdot x_t + b + \varepsilon_t$
3. 取残差 $\varepsilon_t$ 作为[[evl因子]]

### EVL / EVM / EVS 变体

同理，分别从超大单占比中剔除不同类别的占比因子：

| 因子名称 | 提纯方式 | 含义 |
|---------|---------|------|
| EVL | 超大单占比 - 剔除大单占比 | 超大单相对大单的"异常"活跃 |
| EVM | 超大单占比 - 剔除中单占比 | 超大单相对中单的"异常"活跃 |
| EVS | 超大单占比 - 剔除小单占比 | 超大单相对小单的"异常"活跃 |

三个因子均有不俗表现，其中EVL因子效果最优。

## Performance / 实证表现

回测区间为2008-2020年，A股全市场：

### EVL因子原始表现

| 指标 | 数值 |
|------|------|
| 年化多空收益 | 18.66% |
| ICIR | 1.85 |

### EVL因子市值中性化后

| 指标 | 数值 |
|------|------|
| 年化多空收益 | 11.44% |
| ICIR | 2.39 |
| 最大回撤 | 6.09% |

市值中性化后ICIR从1.85提升至2.39，说明EVL因子中包含的信息独立于[[市值因子]]，且中性化后因子的稳定性进一步提升。

## Intuition / 因子逻辑

EVL因子的核心逻辑是捕捉**超大单与大单之间的"异常"分离**：

- 超大单和大单都代表机构资金，但超大单通常代表更大规模、更具信息优势的资金
- 当超大单的活跃度超出了大单所能解释的部分（即残差为正），意味着超大级别的资金正在"异常"介入
- 剔除大单的共同趋势后，残差部分捕捉的是超大单资金的独立判断，具有更强的alpha信号

这一思路与[[聪明钱因子]]同属[[开源金工]]的市场微观结构研究系列，都是通过细分交易者类型来挖掘持仓和交易行为中的信息。EVL因子从订单规模切入，与[[反转因子]]研究中W式切割方法从时间维度切入形成了互补。
