## Definition / 定义

Traction-SI因子（Small-order flow Infra-network Traction Factor）是基于[[小单资金流关联网络]]构建的牵引因子。核心思路是：在关联网络中，高关联股票的涨跌对个股具有牵引力。通过放大高关联股票涨跌幅权重重构个股预期收益基准，再提取真实收益与预期收益的预期差作为因子值。

## 构建步骤

1. **构建关联网络**：基于[[同向比例]]建立[[小单资金流关联网络]]
2. **加权预期收益**：$\hat{r}_i = \sum_{j} w_{ij} \cdot r_j$，其中 {ij}$ 为关联度权重
3. **提取预期差**：$\text{Traction-SI}_i = r_i - \hat{r}_i$
4. **中性化处理**：经过[[反转因子]]、[[市值因子]]、[[行业中性化]]处理

## 回测表现

| 指标 | 数值 |
|------|------|
| RankIC均值 | 3.98% |
| RankICIR | 2.74 |
| 多空年化收益 | 13.91% |
| 年化IR | 2.99 |
| 与常见因子相关性 | 较低 |

## 因子变体

### Traction45p-SI（稀疏化）
- 剔除关联度低于45%的连线
- 多空组合最大回撤从较高水平降至3.86%
- 稀疏化处理有效提升了因子有效性

### Traction5d-SI（平滑）
- 采用滚动5日小单累计净流入数据计算[[同向比例]]
- 增强数据连续性和因子稳定性

### TractionCorr-SI（规模协同）
- 综合考虑小单净流入方向协同与规模协同
- 基于小单净流入成交占比计算余弦相似度
- 余弦相似度同时捕捉方向与规模信息

### Traction-LI（大单版本）
- 基于[[大单资金流]]同向比例构建
- 选股效果弱于基于小单的Traction-SI因子

### Traction-SIO（反向协同）
- 基于小单净流入反向协同比例构建
- 表现弱于基于同向协同的版本

## 合成增强

Traction-SI因子与[[Traction-F因子]]（基于[[基金持仓行为]]构建）具有低相关性（仅13%），两者合成后：
- 多空组合年化收益：18.48%
- 年化IR：3.26

这说明散户行为网络和机构行为网络提供了互补的信息。
