# 买方交易基础设施 / Buy-side Trading Infrastructure

## Definition / 定义

量化私募等买方机构进行策略交易所需的核心系统架构。随着机构化加速，买方系统越来越复杂（几十个模型×几十个产品×十几家券商×上百个账户），需要专业化的系统解决方案。

## How It Works / 工作原理

### 三大模块

```
┌──────────────────────────────────────────┐
│           买方交易基础设施                  │
├─────────────┬──────────────┬─────────────┤
│   数据模块    │  投研计算模块  │  交易执行模块  │
├─────────────┼──────────────┼─────────────┤
│ · Level-2   │ · 因子计算     │ · OGS（订单路由）│
│ · 快照/逐笔  │ · 回测引擎     │ · OMS（订单管理）│
│ · 历史数据   │ · 并行计算     │ · PMS（组合管理）│
│             │              │ · AMS（投后管理）│
└─────────────┴──────────────┴─────────────┘
```

### 核心组件详解

- **OGS（Order Gateway System）**：订单路由系统，连接到券商各柜台网关
- **OMS（Order Management System）**：订单管理，包括策略接入服务、事前风控、交易流量/流速/撤单/委托控制
- **PMS（Portfolio Management System）**：投资组合管理
- **AMS（Asset Management System）**：投后管理，分策略清算（多模型×多产品×多账户的维度层级清算）

### 低频 vs 高频需求差异

| 维度 | 低频算法交易 | 高频交易 |
|------|------------|---------|
| 系统要求 | 相对较低 | 极高（Model与Trading紧耦合） |
| 延迟要求 | 不敏感 | 毫秒级敏感 |
| 金融科技赋能 | 后续随规模增加 | 当前已非常明显 |

## Why It Matters / 为什么重要

- 国外对冲基金IT投入千万美金级别/年，中国买方投入趋势加速
- 高频策略对系统性能的依赖度极高——系统本身就是核心竞争力的一部分
- 量化私募不外包投研系统（核心竞争力），但交易系统可由专业厂商提供
