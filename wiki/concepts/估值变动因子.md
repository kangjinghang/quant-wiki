# 估值变动因子 (dEP)

## Definition / 定义

估值变动因子（Valuation Change Factor, dEP）是传统估值因子EP的时序变化量，定义为当前EP与60个交易日前EP的差值：

$$\text{dEP} = \text{EP}(t) - \text{EP}(t-60)$$

其中EP(t) = E(t)/P(t)，E为股票盈利，P为股票价格。dEP是一个正向选股因子——dEP越大（即EP在近期上升越多）的股票，未来收益预期越好。其投资哲学是**动态价值投资**：不关注"哪些股票当前估值最便宜"（静态价值投资），而是关注"哪些股票的估值正在变得越来越便宜"。

这一因子由[[开源金工]]团队在2020年提出，作为传统估值因子近年持续失效后的优质替代指标。详见[[估值因子坏了怎么修]]。

dEP与[[反转因子]]（动量因子MoM）有天然联系——当盈利未变化时，dEP = -EP × MoM，但依次剔除估值因子和动量因子后仍有显著收益。dEP的逻辑与[[聪明钱因子]]"高频数据低频因子"范式互补——前者从基本面变化时序提取Alpha，后者从微观交易行为提取Alpha。

## Construction & Decomposition / 构建与拆解

### 因子构建

dEP的计算步骤：
1. 取股票当前EP(t) = E(t)/P(t)
2. 取60个交易日前的EP(t−60) = E(t−60)/P(t−60)
3. 计算差值 dEP = EP(t) − EP(t−60)

选择60个交易日间隔的原因：约等于1个季度的交易日数量，与盈利变动频率大致匹配。文中测试了不同间隔天数的表现，确认60个交易日为较优选择。

### R/G拆解

设R = P(t)/P(t−60)（价格变动比率），G = E(t)/E(t−60)（盈利变动比率），则：

$$\text{dEP} = \text{EP}(t) \times \left(1 - \frac{R}{G}\right)$$

调整系数(1 − R/G)的经济含义：
- **R < G**：价格增速小于盈利增速，市场对盈利反应过于悲观 → 调整系数为正
- **R > G**：价格增速大于盈利增速，市场对盈利反应过于乐观 → 调整系数为负

### 简化形式（G=1情形）

由于定期报告（季报、半年报、年报）的发布间隔不均匀——三季报与年报的发布最长可相隔半年，而年报与一季报则往往同月甚至同日披露——回溯60个交易日时盈利数据很可能仍属同一报告期，导致G = 1。此时：

$$\text{dEP} = \text{EP}(t) \times (1 - R) = -\text{EP} \times \text{MoM}$$

其中MoM为过去60日区间收益率（即动量因子）。这一简化形式揭示：在大量交易日中，估值变动因子本质上是估值因子与动量因子的乘积。由此可以理解dEP与EP、MoM之间天然的相关性——dEP与EP截面相关系数0.26，与MoM截面相关系数−0.28。但关键的是，依次剔除估值因子和动量因子后，dEP仍然有显著的剩余收益，说明其蕴含了超越两者简单组合的额外信息。

## Performance / 表现

### 全市场表现

市值行业中性化后，dEP因子的核心指标：

| 指标 | 数值 |
|------|------|
| IC均值 | 0.043 |
| ICIR | 2.70 |
| 多空年化收益 | 22.9% |

与传统EP因子的对比优势：
- **收益结构**：dEP的多头与空头收益均比EP更显著，分组收益单调性更好
- **持续性**：2019年后传统EP因子逐渐失效，但dEP仍然表现优异
- **因子暴露**：dEP多头组合相比EP多头组合有更大的市值（更强的实用性）、更高的BP（市净率）、相对较低的ROE

### 行业表现

在全部一级行业中：
- 除银行行业外，dEP的选股能力均优于EP
- dEP在所有行业中IC均值都在0.03以上
- EP在部分行业（石油石化、基础化工、医药等）中选股能力微弱甚至为负向指标，而dEP不存在此问题

### 细分行业表现

2018年10月以来，dEP多头组合相对EP多头组合的超额收益：

| 细分行业 | 超额收益 |
|----------|----------|
| 半导体 | 13.1% |
| 生物医药 | 18.3% |
| 白酒 | 10.8% |

## Static vs Dynamic Value / 静态vs动态价值投资

dEP因子与EP因子的本质区别在于投资哲学的不同：

| 维度 | EP（静态价值） | dEP（动态价值） |
|------|---------------|----------------|
| 核心问题 | 哪些股票当前估值最便宜？ | 哪些股票估值正变得越来越便宜？ |
| 时间视角 | 截面比较 | 时序变化 |
| 选股逻辑 | 低估值 → 预期均值回归 | 估值改善 → 预期趋势延续 |
| 因子方向 | 正向（低EP → 高收益） | 正向（dEP上升 → 高收益） |
| 近期表现 | 2018年后持续失效 | 2019年后仍表现优异 |
| 多头组合特征 | 较小市值、高BP | 更大市值、高BP、低ROE |

动态价值投资的优势在于：它不仅关注当前的估值水平，还捕捉了估值变化的趋势信息。当一只股票的EP在上升时，要么是价格在下跌（市场悲观），要么是盈利在增长（基本面改善）——无论哪种情况，如果市场尚未充分反映这一变化，就存在获利机会。
