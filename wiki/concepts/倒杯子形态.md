# 倒杯子形态 / Inverted Cup Pattern

## Definition / 定义

倒杯子形态是一种**熊市持续形态**（bearish continuation pattern），由华创金工（王小川、秦玄晋）原创提出。形态是威廉·欧奈尔 [[杯柄形态]] 的镜像反转：股价在下跌趋势中出现圆弧顶（倒杯），随后短暂盘整（柄），突破后延续下跌。

```
价格
  ↗  ╭─╮        ← 倒杯（圆弧顶，倒 U 形）
 │  │  │
 │  ╰──╯  ╭─╮   ← 柄（短暂盘整，吸引抄底资金）
 │         │  │
 │         ╰──╯←── B 点（突破点，成交量放大）
 ↓              ↓  ← 延续下跌
```

## How It Works / 工作原理

1. **前期下跌**（≥30%）后，股价出现圆弧顶反弹（倒杯）
2. 反弹后进入短暂盘整（柄），成交量萎缩，吸引抄底资金
3. 突破 B 点（次低点），成交量放大 40%–50% 以上
4. 抄底投资者信心崩溃抛售，股价延续下跌

## Identification Criteria / 识别标准

| 参数 | 要求 | 说明 |
|------|------|------|
| 前期下跌 | ≥ 30% | 需要充分下跌才能形成有效形态 |
| 形态高度 | 15%–30% | 从左侧低点到杯顶的涨幅 |
| 形态长度 | ≥ 7 周 | 保证充分的筹码交换 |
| 柄深 | < 12% | 柄在倒杯下半部分形成 |
| 柄成交量 | 微弱 | 仅吸引抄底投机者 |
| 突破日成交量 | 高于均值 40%–50% | 机构抛售信号 |

## Why It Matters / 为什么重要

- 提供了技术形态**量化识别+统计验证**的完整框架
- 作为负面形态监控工具，补充了舆情和事件监控
- 2007–2018 年 3681 次样本中，杯长 6 周的 30 天胜率达 69.75%

- 喜临门（603008.SH）
