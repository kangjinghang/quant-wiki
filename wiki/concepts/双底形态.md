# 双底形态 / Double Bottom (W Pattern)

## Definition / 定义

双底形态（Double Bottom / W Pattern）是威廉·欧奈尔在《笑傲股市》中定义的**牛市持续形态**。股价在上涨趋势中形成两个底部（W 形），第二个底部应低于第一个底部以淘汰意志薄弱的投资者。与 [[倒杯子形态]]（熊市持续）形成互补。

```
价格
  ↑                    ↑ E（买入点=C）
  │   ╱╲        ╱╲   │
  │  A  │      │  │   │
  │     │   C──│──│───│
  │     B      D  │
  │                │
  └────────────────┘
    第一底  中间高  第二底
```

关键点：A=起点，B=第一底，C=中间高点，D=第二底（低于 B），E=买入点（价格=C）

## How It Works / 工作原理

1. **前期上涨**（≥30%）后股价回撤，形成第一底 B
2. 反弹至中间高点 C 后再次回撤，形成第二底 D（低于 B，淘汰弱者）
3. 突破买入点 E（=C 点价格），成交量放大 ≥20%
4. 突破后 5–6 个交易日回调，之后稳定上涨

## Identification Criteria / 识别标准

| 参数 | 要求 | 说明 |
|------|------|------|
| 前期上涨 | ≥ 30% | 与 [[杯柄形态]] 一致 |
| 形态深度 | 15%–30% | 从 A 到 D 的跌幅 |
| 形态长度 | 7–65 周 | 最佳 15–18 周 |
| 第二底 | 低于第一底 | 淘汰弱者，否则为"类双底" |
| 成交量突破 | 高于均值 ≥ 20% | 机构买入信号 |

## Why It Matters / 为什么重要

### 最佳参数

- **长度 15–18 周**：胜率 >54%，盈亏比稳定
- **深度 20%–25%**：胜率、收益率、盈亏比均最优

### 策略表现（2009–2019）

| 指标 | 值 |
|------|-----|
| 年化收益 | 11.9% |
| 超额收益（vs 上证综指） | 10% |
| 夏普比率 | 0.33 |
| 最大回撤 | 47.3% |

### 市场环境影响

- **上升市**：形态多且胜率高（如 2013–2015 区间，20 天胜率 >56%，盈亏比 >1.7）
- **下跌市**：形态少，表现差

## Examples / 示例

- 全新好（2015 年 3 月 13 日突破），持有 9 个交易日后超额收益 >7%
