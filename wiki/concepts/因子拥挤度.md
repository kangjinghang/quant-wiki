# 因子拥挤度 / Factor Crowding

## Definition / 定义

因子拥挤度（Factor Crowding）衡量资金在某个因子上的聚集程度。过多的资金追逐同一因子可能引发尾部风险（如2009年美股动量因子大回撤、2016年底A股市值因子失效），但适度的拥挤反而是因子取得优秀表现的必要条件——必须有资金流入才能推动因子收益。

## Measurement / 度量方法

[[招商定量]]在[[因子拥挤度择时研究]]中构建了4类8个相对值指标：

### 1. 估值价差
多头组合估值上升、空头组合估值下降→拥挤度上升。取E/P、B/P、S/P的差值。
$$VS = \frac{E/P_{long} - E/P_{short}}{2} + \frac{B/P_{long} - B/P_{short}}{2} + \frac{S/P_{long} - S/P_{short}}{2}$$

### 2. 配对相关性
多头/空头组合内部股票收益同涨同跌→拥挤。过去3个月组内成分股与组合收益相关系数之和。

### 3. 因子波动率
因子多空收益波动上升→拥挤。多头波动/市场波动 + 多空波动差异。

### 4. 因子长期反转
因子过去3年/4年累积收益过高→可能过度拥挤。A股因子回撤周期约48个月（美国约3年）。

## Key Findings / 关键发现

- 拥挤度与因子收益**正相关而非负相关**（拥挤推动收益，过度拥挤才危险）
- 对[[市值因子]]的尾部风险提示最明显（2016年底拥挤度顶峰→大回撤）
- XGBoost和LSTM择时均失败——A股因子Alpha太强，"每期做多"已是高胜率策略
- PCA合成指标加权多因子组合小幅跑赢等权

## A-Share Specificity / A股特殊性

A股因子拥挤度的择时效果不显著，原因推测：
- 个人投资者为主，难以形成同一方向的资金合力
- 即使拥挤度指标处于高位，可能仍远未达因子资金容量上限
- A股因子Alpha属性显著强于海外，做空机制不完善限制了拥挤到崩溃的传导

## Industry-Level Application / 行业层面应用

[[广发金工]]（[[史庆盛]]）在[[考虑拥挤度的细分行业动量策略重构量化行业轮动框架技术篇]]中发现，虽然拥挤度作为因子择时工具效果不显著，但在行业层面作为**剔除信号**效果突出。该团队构建了[[拥挤度复合因子]]（成交量/成交额/换手率及其乖离率共6个单因子），以3信号阈值剔除交易过热行业，与[[行业动量]]策略复合后年化超额收益约29%。这一发现表明拥挤度的有效应用场景可能在于"做减法"——从动量筛选的行业池中剔除高危标的，而非直接用于择时方向判断。^[raw/articles/[202108131147]广发金融工程考虑拥挤度的细分行业动量策略重构量化行业轮动框架技术篇.md]
