# 基本面量化 / Fundamental Quant

## Definition / 定义

基本面量化（Fundamental Quant）是将量化投资方法与主观投资判断相融合的投资方法论。其核心思路是：在量化因子模型的基础上，通过结构化的框架（如[[black-litterman模型]]）将投资经理的主观观点、市场判断和基本面研究融入模型，而非完全依赖数据驱动的因子信号。这种方法既保留了量化投资纪律性强、覆盖面广的优势，又充分发挥了投资经理对宏观环境、行业周期和市场结构的定性判断能力。

## Why It Matters / 为什么重要

### 传统Alpha因子挖掘的瓶颈

近年来，传统Alpha因子的挖掘逐渐进入瓶颈期。随着量化策略的普及和数据的透明化，简单因子（如价值、动量、质量等）的溢价不断收窄，因子拥挤度上升。纯数据驱动的因子选股策略面临收益递减的困境，寻找新的Alpha来源成为行业共识。

### 量化赛道的拥挤与分化

量化赛道日益拥挤，同质化策略之间的竞争加剧了因子周转和信号衰减。在此背景下，如何利用投资经理的独特洞察形成差异化优势，成为量化团队的核心竞争力之一。[[基本面量化]]正是这一趋势下的自然演进方向。

### 海外实践

海外头部量化基金早已在基本面量化方向布局。桥水（Bridgewater）通过宏观基本面判断驱动资产配置；AQR在因子投资中融入基本面维度；文艺复兴（Renaissance Technologies）虽以纯量化著称，但其在特定策略中也融入了基本面信息。这些实践表明，量化与主观的融合并非退回传统主动投资，而是在量化框架内系统地利用主观判断。

### 理论基础：因果推断视角

[[中银量化]]（郭策）从因果推断角度为[[基本面量化]]提供了更深层的理论支撑。其核心论点：量化模型依赖统计相关性 $P(Y|X)$ 建模，但无法回答因果性问题 $P(Y|\text{do}(X))$。当外部环境发生结构性变化时，基于相关性的模型容易失效。[[基本面量化]]的"主观逻辑定方向+量化模型做测算"路径，本质上是用人脑的因果判断能力弥补统计相关性的不足。^[raw/articles/[202101060800]量化与主观思考的对立与统一.md]

## Implementation / 实现路径

### B-L模型作为核心框架

[[black-litterman模型]]是实现[[基本面量化]]的核心工具之一。该模型最初用于资产配置，由Black和Litterman于1992年提出，核心思想是将市场均衡（先验）与投资者主观观点（后验）进行贝叶斯融合。

在因子权重优化的应用中，[[方正金工]]的报告提出了精妙的类比：

- **因子IC**（Information Coefficient，截面相关系数）= 资产收益
- **因子IC协方差矩阵** = 资产风险矩阵
- **先验权重** = 由[[风险平价]]确定，使各因子风险贡献相等
- **主观观点** = 因子动量、因子估值、个人判断

B-L模型的后验权重公式将先验与观点加权融合：

$$w_{BL} = [(τΣ)^{-1} + P'Ω^{-1}P]^{-1}[(τΣ)^{-1}w_{eq} + P'Ω^{-1}Q]$$

观点的不确定性（$Ω$）控制了主观观点对最终权重的影响程度——高确信度的观点会更大程度地偏离先验。

### 观点来源

在[[基本面量化]]实践中，主观观点的来源主要包括三类：

1. **[[因子动量]]观点**：基于各因子过去一段时间的IC表现（如12个月IC均值），判断因子短期强弱。[[因子动量]]是有效的择时信号，但波动较大，需要加入约束条件（如权重偏离限制在等权 $\pm 4\%$）以控制风险。实证中，加入动量观点可将组合夏普比从1.96提升至2.17。

2. **因子估值观点**：通过因子多头组的估值水平（如BP值的z-score）判断因子拥挤度。估值偏高的因子可能面临反转风险，估值偏低的因子则可能存在修复机会。估值观点信号强度通常弱于动量，但可作为有效的辅助信号。

3. **个人主观观点**：投资经理基于宏观环境、政策变化、市场结构等维度形成的定性判断。例如，在去杠杆周期中看空质量与成长因子、看多价值因子。这类观点的独特性最高，但也最依赖投资经理的个人能力。

## Evidence / 实证表现

根据[[方正金工]]（严佳炜）2020年4月的实证研究（[[主观观点如何融入量化因子模型]]），在2007–2019年、中证500成分股、6因子框架下：

| 配置方式 | 夏普比 |
|---|---|
| 因子等权 | 1.96 |
| [[风险平价]]先验 | ~2.0+ |
| 加入[[因子动量]]观点 | 2.17 |
| B-L完整模型（动量+估值+主观） | **2.28** |

B-L模型将夏普比从1.96提升至2.28，提升幅度约16%。收益特征为"部分年度小幅跑输，部分年度大幅跑赢"，表明主观观点的加入在趋势性市场中贡献尤为突出。该方法在沪深300和全A股中同样验证有效。

### 财报披露日的信息含量

除了上述B-L框架将主观观点融入因子模型之外，[[基本面量化]]的另一个维度是从基本面信息的时间特征中挖掘Alpha。[[财报披露日因子]]（Financial Report Disclosure Date Factor）是一个典型案例——[[招商定量]]任瞳、麦元勋在[[越早披露财报公司基本面越好]]中发现，上市公司财报披露日期本身蕴含重要信息：越早披露财报的公司 EPS/ROE/GROW 越高，披露日同比提前预示业绩改善。dReport 因子（披露日变化）全A IC 0.027/ICIR 1.09，与价值、成长、情绪、反转、市值、交易行为等6大类因子相关性极低（<3%），提供独特的增量选股信息。这一方向与[[估值变动因子]]dEP（"哪些股票估值正在变得越来越便宜？"）和[[盈利加速度]]（增速的变化趋势）有异曲同工之妙——都从基本面信息的动态维度而非静态维度挖掘Alpha。

### 天弘基金的实践经验

[[天弘基金]][[杨超]]在2021年开源量化论坛上分享了[[基本面量化]]的实践路径：将主动基本面研究的行业逻辑转化为可量化跟踪的数据指标，进而反向设计Alpha因子。典型案例是将光伏行业的产业周期与早期家电行业进行类比，从产业逻辑出发构建量化因子。此外，天弘在组合优化层面采用"单因子分别优化后叠加"的方法，通过调整风险约束来动态改变Alpha空间。^[raw/articles/[202105182142]杨超基本面研究和增强策略开源量化论坛.md]
