# 基金业绩归因 / Fund Performance Attribution

## Definition / 定义

基金业绩归因是将基金的超额收益分解为不同来源的方法。对于转债基金，核心问题是区分**择时能力**（在正确时间调整仓位）、**择券能力**（选择正确的个券）和**风格暴露**（基金在特定策略上的偏好）。[[中金固收]]团队在转债基金归因领域发展了两类方法：CL模型（择时+择券分解）和风格回归分解（风格暴露+纯Alpha），两种方法互补。该研究与[[可转债定价]]、[[转债因子模型]]共同构成了转债投资的方法论基础。

## How It Works / 工作原理

### CL 模型（中金固收采用）

$$R_p - R_f = \alpha + \beta_1 \cdot \min(R_m - R_f, 0) + \beta_2 \cdot \max(R_m - R_f, 0) + \epsilon$$

- 将市场收益 $R_m - R_f$ 拆分为下跌（$\min$）和上涨（$\max$）两种状态
- 分别对应 $\beta_1$（下跌敏感度）和 $\beta_2$（上涨敏感度）

### 参数解读

| 参数 | 含义 | 理想值 |
|------|------|--------|
| $\alpha$ | 择券能力（超额收益） | > 0 |
| $\beta_2 - \beta_1$ | 择时能力 | 大 |
| $\beta_2$ | 上涨敏感度 | 大 |
| $\beta_1$ | 下跌敏感度 | ≈ 0 |

### Python 实现

使用 `sklearn.linear_model.LinearRegression`，数据源支持 SQL 和 Wind API。

### Rf 选择

用不拿转债/股票的长债基金收益率，而非国债或企业债收益率——取决于基金倾向拿哪类债。

### 风格回归分解（中金固收采用）

将基金超额收益$R_t - Q_m$分解为风格收益和纯Alpha：

$$R_t - Q_m = \underbrace{(R_t - R_s)}_{\text{纯Alpha}} + \underbrace{(R_s - Q_m)}_{\text{风格收益}}$$

其中$R_s = \sum \beta_i \cdot R_i$为基金在各风格指数上的加权收益。通过带约束线性回归（`scipy.optimize.leastsq`）估计$\beta_i$，约束条件：所有$\beta \geq 0$、总$\beta \leq 140\%$、股票$\beta \leq 20\%$。

**四类转债风格指数**：

| 风格 | 代号 | 特征 |
|------|------|------|
| 大盘转债 | Big | 占指数、流动性好、价位不高 |
| 双低策略 | LP | 低价格+低溢价率 |
| 纯低溢价率 | LPrem | 高价、侵略性强 |
| 优质股 | EQ | 万得"基金重仓股指数" |

**核心发现**（详见[[转债基金风格分解]]）：转债基金整体基本没有独立于风格的纯Alpha——双低、低溢价、优质股三个策略已基本穷尽转债市场大面积获超额收益的方式。20亿元是风格收益的规模瓶颈。但部分基金仍能保持统计显著的纯择券Alpha，且与规模无关。

**两种方法的比较**：CL模型从时间维度（涨/跌市场状态）分离择时与择券能力；风格回归从策略维度（四类风格指数）分离风格暴露与纯Alpha。两者回答不同问题——CL回答"基金经理是否在涨跌市中仓位调整正确"，风格回归回答"基金经理的超额收益是来自风格选择还是真正的选券能力"。

## Why It Matters / 为什么重要

- 区分择时和择券，帮助投资者选择合适的基金和管理人
- 量化评估基金经理的核心能力
- 归因结果可指导基金投资组合配置

### 模型局限

- $\alpha$ 和 $\beta$ 无法完全分离（转债不同品种股性差异大）
- 归因模型 ≠ 仓位测量（"有效仓位"而非实际仓位）
- 低估值品种天然不对称性可能混淆归因结果
- 需结合基金规模和仓位综合判断

## Examples / 示例

- 满仓特发 vs 满仓山高 EB → 有效 beta 完全不同
- α=25 分命中 45% vs α=5 分命中 60% → 前者更强
