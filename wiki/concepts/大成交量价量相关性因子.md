## Definition / 定义

[[大成交量价量相关性因子]]（corr\_VPlarge）是筛选分钟成交量排名前1/3的大成交量时刻，仅在这些时刻计算成交量与收益率的相关系数。属于[[特定时段采样因子]]类别。

## 计算方法

1274\text{corr\_VPlarge} = \text{Corr}(V_i, r_i) \quad \text{where } V_i \in \text{top 1/3}1274

## Performance / 表现

| 指标 | 数值 |
|------|------|
| IC均值 | -6.42% |
| 年化ICIR | 5.38 |
| 多空收益率 | 49.82% |
| 平滑方法 | MA5 |

## Key Findings

- 年化ICIR 5.38在全部46个因子中最高
- 多空收益率49.82%，仅次于[[尾盘半小时收益率因子]]
- 通过聚焦大成交量时刻，有效过滤散户噪声，突出机构交易行为
- 是[[日内价量相关性因子]]（corr\_VP）的增强版本，ICIR从4.74提升至5.38
- 负IC说明大单时刻价量正相关的股票（机构买入推高价格）后续倾向于反转
