## 定义 / Definition

大模型投研Agent是指以[[大语言模型]]作为核心推理引擎（“帷幄之中的运筹者”），结合外部工具、知识库和自动化工作流，能够自主感知环境并执行复杂投研任务的智能体系统。大模型本身缺乏对外部环境的感知和操作能力，而Agent框架完美补全了这一劣势。

## 方法/机制 / Methodology

构建投研Agent通常包含以下核心组件：
1. **核心大模型**：如[[深度求索|DeepSeek-V3]]用于日常任务，DeepSeek-R1用于深度推理。
2. **工作流编排**：将复杂任务拆解为多个步骤。例如“概念股捕捉”工作流包含：关键词提取 -> 新闻搜索 -> 主体及关联理由提取 -> 上市公司鉴别 -> 格式化输出。
3. **工具调用**：赋予Agent上网检索、查询本地数据库等能力。
4. **开发平台**：可利用低代码/无代码平台（如扣子平台）或开源LLMOps平台（如Dify）进行快速构建与部署。

## 应用案例 / Cases

- **DeepSeek犀照**：基于扣子平台构建，用于自动化搜集特定概念相关的上市公司，并输出概念关联理由。
- **DeepSeek-Researcher**：基于Dify平台构建，接受特定研究主题，自动进行互联网资料检索并生成结构完整的研究报告。
