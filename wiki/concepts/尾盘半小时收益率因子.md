## Definition / 定义

[[尾盘半小时收益率因子]]（ret\_H8）是收盘前30分钟的收益率，通过特定时段采样提取。属于[[特定时段采样因子]]类别。

## 计算方法

1059\text{ret\_H8} = \frac{P_{close} - P_{T-30min}}{P_{T-30min}}1059

## Performance / 表现

| 指标 | 数值 |
|------|------|
| IC均值 | -4.35% |
| 年化ICIR | 4.01 |
| 多空收益率 | 50.04% |
| 平滑方法 | MA5 |

## Key Findings

- 多空收益率50.04%，在全部46个高频因子中最高
- IC为负，说明尾盘拉升的股票未来收益倾向于反转
- 尾盘时段是机构调仓和做市商行为最密集的时段，该因子捕捉了尾盘操纵或跟风行为的逆向信号
- 与[[尾盘成交额占比因子]]（华安金工APL\_20）关注同一时段，但角度不同：APL关注成交量分布，ret\_H8关注价格变化
