## Definition / 定义

[[已实现偏度因子]]（real\_skew）是日内分钟收益率序列的三阶矩（skewness），衡量日内收益率分布的不对称程度。属于[[日内价格相关因子]]类别。

## 计算方法

1047\text{real\_skew} = \frac{1}{N} \sum_{i=1}^{N} \left(\frac{r_i - \bar{r}}{\sigma}\right)^31047

其中 $ 为分钟收益率，$\bar{r}$ 为均值，$\sigma$ 为标准差。

## Performance / 表现

| 指标 | 数值 |
|------|------|
| IC均值 | -4.48% |
| 年化ICIR | 5.05 |
| 多空收益率 | 29.27% |
| 平滑方法 | MA5 |

## Key Findings

- IC为负，说明日内正偏度高的股票未来收益较差（散户追涨行为的逆向指标）
- 年化ICIR 5.05在所有46个因子中排名靠前，表现极为稳定
- 是[[日内价格相关因子]]中表现最稳定的因子
- MA5平滑效果优于原始日频和MA20
