# 拥挤度

## Definition / 定义

拥挤度（Crowding）衡量特定资产、行业或因子上资金交易集中程度，是识别微观交易结构恶化和潜在反转风险的关键指标。[[拥挤交易]]指动用大量资金买卖特定资产导致价格在无基本面变化下发生重大变化的现象。

## 指标体系 / Indicator Framework

### 因子拥挤度指标（招商定量）

4类8个相对值指标：

| 类别 | 指标 | 说明 |
|------|------|------|
| 估值价差 | PE/PB/PS 价差 | 多空组合估值差异 |
| 配对相关性 | 多+空组合 | 因子多空组合内个股相关性 |
| 因子波动率 | 多/多空 | 因子收益波动 |
| 因子长期反转 | 3年/4年 | 因子长期累积收益 |

### 行业拥挤度指标（国君配置团队）

从6个维度构建275个常规因子：

- 微观结构、波动率、流动性、相关性、乖离率、分布特征
- 关键改进：引入**动量均线系统**筛选近期上涨且开始步入下跌趋势的行业
- 最终合成**拥挤度复合因子**：收盘价波动率 + 换手率 + 收盘价峰度 + 量价相关系数 + 金额价格相关系数 + [[兴登堡预兆]]

### 海外双指标体系

1. **资产集中度**：通过PCA和吸收比衡量资产在市场回报可变性中的驱动程度
2. **相对估值**：估值历史标准化 + 横截面相对化

## 策略应用 / Strategy Applications

### 行业轮动

- **泡沫识别象限模型**：高集中度+非高估值→泡沫上升期（做多），高集中度+高估值→泡沫抛售期（做空）
- 拥挤度复合因子超额年化 6.09%（相对市场基准）
- 应用于原有行业轮动模型后：年化由18.56%→26.49%，最大回撤由49.28%→28.11%^[如何规避交易拥挤行业-通过拥挤度构建行业轮动策略-行业配置研究系列05]

### 因子择时

- XGBoost预测准确率60%+，但**不如"每期做多"简单策略**（交易行为因子做多胜率84.08%）
- LSTM学到的是"始终做多"（sigmoid输出始终>0.5）
- PCA合成指标对多因子组合加权小幅跑赢等权基准^[因子拥挤度择时研究]

## A股特殊性 / A-Share Specifics

1. **择时效果有限**：A股因子Alpha属性太强，长期做多胜率已高，拥挤度难以提供增量择时价值
2. **非单调关系**：拥挤度与收益并非单调负相关——资金流入推动因子有优秀表现
3. **投资者结构**：个人投资者为主，难以形成同一方向的资金合力，因子拥挤度即使在高处也远未达资金容量上限
4. **海外模型失效**：资产集中度+相对价值的美国模型在A股失效，定义的"泡沫破裂组"反而有显著超额

## 关键引用

> "因子拥挤度指标本身并非一个因子收益的负向指标，因为必须有资金流入才能推动因子有优秀的收益表现。"

> "个人投资者在交易的时候很难形成同一方向的合力……即使在最高处，可能也远远没有达到这些常用因子的资金容量上限。"
