# 指数增强

## Definition / 定义

指数增强（Index Enhancement / Enhanced Indexing）是一种介于被动指数投资与主动量化投资之间的策略类型。其核心目标是在控制组合与基准指数之间跟踪误差（Tracking Error）的前提下，通过因子选股、权重优化等手段系统性地获取超额收益（Alpha）。与纯被动指数基金不同，指数增强允许在有限范围内偏离基准权重；与完全主动管理不同，它受到严格的风格、行业和跟踪误差约束，力求在收益增强与风险控制之间取得平衡。

## How It Works / 工作原理

指数增强策略的构建通常包含以下三个核心环节：

### 1. 因子选股 / Factor Selection

从多因子模型中筛选出在目标指数成分股范围内具有显著预测能力的因子。筛选标准通常以多空信息比率（IR）为门槛——例如，[[开源金工]]在沪深300增强研究中采用IR ≥ 1.5作为筛选条件。

典型的有效因子类别包括：

- **技术面因子**：成交量比率、流动性、[[聪明钱因子]]、[[理想振幅因子]]等
- **基本面因子**：ROE、ROA（经过市值中性化处理）等

### 2. 因子复合 / Factor Combination

将多个有效因子合成为综合得分。常见方法包括：

- **ICIR加权**：滚动计算各因子的ICIR作为权重，在因子大类内复合
- **大类因子等权**：将各大类复合因子等权相加，得到最终综合因子值F

### 3. 组合优化 / Portfolio Optimization

以综合因子F驱动的预期收益率为目标函数，在多重组约束下求解最优权重。典型约束条件包括：

| 约束类型 | 具体设定 | 说明 |
|----------|----------|------|
| 跟踪误差 | ≤ 5% | 控制组合与基准的偏离幅度 |
| 个股权重 | ± 2.5% | 相对基准的偏离上下限 |
| 换手率 | ≤ 50% | 降低交易成本损耗 |
| 市值中性 | 风格暴露约束 | 消除市值因子的系统性暴露 |
| 行业中性 | 行业暴露 = 0 | 基础模型中的默认设定 |
| 卖空限制 | w ≥ 0 | 不允许做空 |
| 成分股比例 | ≥ 80% | 确保与基准的关联性 |

## Why It Matters / 为什么重要

指数增强是公募量化产品竞争的主战场，尤其是沪深300指数增强产品，近年来数量和规模持续增长。其重要性体现在：

1. **行业集中度问题**：沪深300的行业分布高度不均衡，前五大行业（非银金融、银行、食品饮料、医药生物、电子）权重占比达56.13%，远高于中证500的45.19%。这意味着在沪深300上做增强时，行业的主动偏离对策略效果的影响尤为显著。

2. **行业轮动的增量贡献**：利用[[行业动量]]信号（如龙头股模型、黄金律模型）调整行业暴露，可以显著提升增强策略的表现。根据[[开源金工]]的测试，在基础增强策略上叠加行业轮动信号后：
   - 基础策略：超额年化7.42%，夏普1.88
   - 龙头股模型叠加（η=0.04）：超额年化8.53%，夏普2.07
   - 黄金律模型叠加（η=0.04）：超额年化9.24%，夏普2.21

3. **参数权衡**：行业偏离参数η增大时，收益提高但波动也增加，夏普比率呈先涨后跌的趋势，需在收益增强与风险控制之间寻找最优平衡点。

4. **行业配置分化度增大**：[[行业量化配置在沪深300增强上的应用]]通过[[brinson归因分析]]揭示，近年来沪深300指数增强基金的行业配置分化度越来越大。2020年增强基金总规模达480亿元创历史新高，全体基金超额收益中位数13.37%。行业配置收益与超额收益呈明显正相关，最高一只基金行业配置收益达29.8%。这验证了行业轮动信号在指数增强中的核心价值。

5. **纯行业权重调整增强**：[[开源金工]]在[[行业量化配置在沪深300增强上的应用]]中提出了一种不同于因子选股+组合优化的增强路径——直接将四维行业轮动信号转化为行业主动权重。行业主动权重=行业因子值/(β×因子值绝对值之和)，叠加在基准权重上。β=2参数下2012-2021年全区间年化超额5.31%，超额夏普1.97，月度胜率70.64%。β参数具有风险调节功能，投资者可灵活选择。

## Examples / 示例

- [[结合行业轮动的沪深300指数增强测试]]（[[开源金工]]，2020）——将[[行业动量]]的龙头股模型和黄金律模型叠加到沪深300增强策略，黄金律模型全样本超额夏普2.21，2020年超额夏普达3.80
- [[基于沪深300规模效应的指数增强策略]]（[[中银量化]]，2020）——从[[规模效应]]和[[股权集中度]]两个正交因子构建双因子策略，超额年化15.3%，夏普2.74，方法简洁（仅选股不优化权重）
- 沪深300指数增强产品是公募量化规模最大的赛道之一，多家基金公司均有相关产品
- [[行业量化配置在沪深300增强上的应用]]（[[开源金工]]，2021）——四维行业模型直接转化为行业主动权重的纯行业增强路径，β=2年化超额5.31%，超额夏普1.97
