# 振幅切割动量因子

## Definition / 定义

振幅切割动量因子是由[[开源金工]]团队提出的一种因子构造方法，核心思想是按日度振幅（intraday amplitude，即日内最高价减最低价除以前收盘价）对回看窗口内的交易日进行排序，将涨跌幅因子切割为两个部分：低振幅交易日的涨跌幅加总构成A因子（呈现动量效应），高振幅交易日的涨跌幅加总构成B因子（呈现反转效应）。

具体构造步骤如下：

1. **选择回看窗口**：确定回看天数N（如N=160个交易日）
2. **按振幅排序**：对每只股票，将其N个交易日按日度振幅从低到高排序
3. **切割加总**：取振幅最低的λ比例交易日的涨跌幅加总，得到A因子；取振幅最高的(1-λ)比例交易日的涨跌幅加总，得到B因子

关键参数：切割比例λ控制低振幅与高振幅的分界点，回看窗口N控制因子的回看时间跨度。最优参数组合为A(λ=70%, N=160)。

## Motivation / 动机

A股市场具有强反转特征，这是构造动量因子的核心障碍。20日涨跌幅因子IC达-0.054（强反转），即使拉长至240日回看窗口，IC仍维持在-0.02左右。[[反转因子]]在A股的强势表现使得传统涨跌幅因子无法直接用作动量信号。

传统的时间维度切割方案同样失效。以经典的6个月涨跌幅减1个月涨跌幅（6m-1m）为例，IC仅-0.002。将6个月涨跌幅拆分为6个独立月度涨跌幅后发现，除最近1个月具有强反转效应外，其余月份均无明显的动量或反转效应。时间维度上动量与反转交织分布，简单的减法切割无法有效分离。

[[开源金工]]团队因此转向交易行为维度：不同交易活跃程度下，动量和反转效应是否存在差异性？这一思路与[[聪明钱因子]]、[[理想振幅因子]]的研究脉络一脉相承，均从市场微观结构的角度拆解因子结构。

## Performance / 表现

### 全市场表现

切割得到的动量因子A(λ=70%, N=160)在全市场范围内表现稳健：

| 指标 | 数值 |
|------|------|
| IC均值 | 0.036 |
| ICIR | 1.31 |

在全区间内，A因子多空对冲净值表现稳健，分组收益呈单调排列，多头组合超额收益优势显著。

涨跌幅因子的内在结构分析揭示了切割的有效性基础：将160个交易日按振幅等分为十组后，第一组至第七组（低振幅区间）涨跌幅因子呈现显著动量效应，第八组动量效应开始衰减，第九组至第十组（高振幅区间）转为反转效应。动量与反转的分布和强度具有不对称性——反转效应集中在高振幅尾部，且强度更大。

### 沪深300样本空间表现

在沪深300样本空间内，切割动量因子表现更为优异：

| 指标 | 数值 |
|------|------|
| IC均值 | 0.051 |
| ICIR | 1.04 |
| 多头年化收益 | 9.72% |
| 同期沪深300年化收益 | 3.05% |

多头组合采用千分之三交易费率、月度调仓，自2010年4月以来超额收益在全区间内稳健。

### 切割比例λ的敏感性

随着λ从10%逐步增大至70%，A因子的IC均值与ICIR均呈先增后降走势，在λ=70%处达到峰值。这一走势与内在结构分析相互印证：λ从10%增至70%的过程中，增量部分（第一组至第七组）动量效应显著，整体A因子动量效应增强；λ从70%进一步增至100%时，增量部分（第八组至第十组）逐渐转为反转效应，整体A因子动量效应减弱，λ=100%时退化为原始涨跌幅因子（呈现反转效应）。

### 与其他切割指标的比较

除日度振幅外，研究还测试了换手率和单笔成交金额两种交易活跃度指标的切割效果：

| 切割指标 | IC均值 | ICIR |
|----------|--------|------|
| 日度振幅 | 0.036 | 1.31 |
| 单笔成交金额 | 0.027 | 0.83 |
| 换手率 | 0.015 | 0.45 |

三类指标切割得到的动量因子均呈现动量效应，其中日度振幅的切割效果最为优异。

## Economic Interpretation / 经济学解释

振幅切割动量因子的经济学基础来自行为金融学对反转效应的解释：反转效应是投资者过度反应引发的市场现象，资金的过度涌入与过度流出都会导致股价反转。

**低振幅交易日→信息驱动→动量效应**：交易日振幅较低意味着市场分歧小、交易清淡，此时股价变动更多反映基本面信息的持续驱动，而非情绪化的过度反应。因此，低振幅日的涨跌幅包含更多"信息含量"，具有延续性，呈现动量效应。

**高振幅交易日→过度反应→反转效应**：交易日振幅较高意味着市场分歧大、交易活跃，此时股价变动受情绪驱动的过度反应影响更大。资金的过度涌入推高股价后面临回调压力，过度流出压低股价后存在反弹空间，因此高振幅日的涨跌幅呈现反转效应。

这种解释与[[聪明钱因子]]的"聪明钱在交易清淡时入场"逻辑相呼应，也与[[理想振幅因子]]中振幅作为信息含量度量指标的思路一脉相承。
