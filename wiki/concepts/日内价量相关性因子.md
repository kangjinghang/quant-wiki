## Definition / 定义

[[日内价量相关性因子]]（corr\_VP）是日内分钟级成交量与收益率序列的Pearson相关系数，衡量价量联动程度。属于[[日内价量相关因子]]类别。

## 计算方法

914\text{corr\_VP} = \text{Corr}(V_i, r_i)914

其中 $ 为第 $ 分钟成交量，$ 为第 $ 分钟收益率。

## Performance / 表现

| 指标 | 数值 |
|------|------|
| IC均值 | -6.15% |
| 年化ICIR | 4.74 |
| 多空收益率 | 47.57% |
| 平滑方法 | MA5 |

## Key Findings

- IC为负且绝对值较大（-6.15%），说明日内价量正相关程度高的股票未来收益较差
- 多空收益率47.57%，在全部46个因子中排名靠前
- 价量正相关反映了散户追涨行为，负IC表明知情交易者不表现出价量正相关
- 与[[大成交量价量相关性因子]]（corr\_VPlarge）同源但后者仅筛选大成交量时刻，ICIR更高（5.38）
