## Definition / 定义

[[日内收益率因子]]（ret\_intraday）是从开盘到收盘的日内总收益率，是最直接的日内价格变化度量。属于[[日内价格相关因子]]类别。

## 计算方法

631\text{ret\_intraday} = \frac{P_{close} - P_{open}}{P_{open}}631

## Performance / 表现

| 指标 | 数值 |
|------|------|
| IC均值 | -4.94% |
| 年化ICIR | 2.66 |
| 多空收益率 | 34.23% |
| 平滑方法 | MA5 |

## Key Findings

- IC为负，说明日内涨幅大的股票未来收益倾向于反转
- 多空收益率高达34.23%，但2017年后预测能力明显下降
- 本质上是[[反转因子]]的高频版本，与[[昼夜分离反转因子]]中的日内成分高度相关
- 与隔夜收益率共同构成完整的日收益率分解框架
