# 杯柄形态 / Cup-with-a-Handle

## Definition / 定义

杯柄形态（Cup-with-a-Handle）由威廉·欧奈尔（William O'Neil）提出，是一种**牛市持续形态**（bullish continuation pattern）。形态由两部分组成：

- **杯**：在一段上涨后形成的圆弧底（U 形而非 V 形），体现筑底过程中的筹码交换
- **柄**：杯完成后出现的短暂盘整，随后突破延续上涨趋势

```
价格
  ↑              ↑  ← 延续上涨
  │  ╭──╮  ╭─╮  │
  │  │  │  │ │  │
  ↘  ╰──╯  ╰─╯  ↗
     杯      柄     ← 突破买入点
```

## How It Works / 工作原理

1. 股价在上涨趋势中回调，形成圆弧底（杯）
2. 杯底 U 形筑底洗出投机者，卖压减轻
3. 短暂盘整（柄）后放量突破，延续上涨

部分股票不做柄直接拉升，即圆弧底形态。
