# 留存收益市值比

## Definition / 定义

留存收益市值比（Retained Earnings to Price, REP）是由[[华安金工]]团队在量化基本面系列第一篇中提出的估值因子改进方法。核心思想是将传统账面价值（Book Value）拆分为留存收益（REP = 未分配利润 + 盈余公积）和投入资本（CCP = 股本 + 资本公积），分别构建估值因子。

$$\text{BP} = \text{REP} + \text{CCP}$$
$$\text{REP} = \frac{\text{未分配利润} + \text{盈余公积}}{\text{总市值}}$$
$$\text{CCP} = \frac{\text{股本} + \text{资本公积}}{\text{总市值}}$$

## How It Works / 工作原理

### 账面价值的经济含义差异

传统BP因子将账面价值视为整体，但实际上REP和CCP具有不同的经济含义：

- **REP（留存收益）**：反映企业历年累积盈利能力，是内部创造的股东权益。高REP意味着企业具有持续的盈利积累能力，代表"滚雪球"式的价值增长。
- **CCP（投入资本）**：反映外部股东投入的资本，包括IPO和增发融资。高CCP可能反映历史融资规模大，但未必代表经营效率。

### 因子表现差异

REP因子的预测能力显著优于CCP因子：

| 指标 | REP | CCP | BP |
|------|-----|-----|-----|
| ICIR | 2.46 | 1.09 | 1.61 |
| 多空年化 | 13.27% | 7.10% | - |
| 月度胜率 | 66.7% | - | - |

REP的优势来源于其更强的盈利预测能力——高REP公司具有更高的ROE持续性。

### 牛熊周期轮动

REP与CCP的相对表现与市场环境高度相关：

- **牛市环境**：CCP因子更优（2014-2015、2019年）。牛市中外部融资驱动的公司（高CCP）容易获得市场追捧。
- **熊市环境**：REP因子更优（2011、2015下半年、2018年）。熊市中市场更青睐有真实盈利积累的公司（高REP）。

基于价量趋势信号构建双因子轮动策略，动态调整REP与CCP权重，年化超额收益15.51%（相对中证全指）。

## Why It Matters / 为什么重要

1. **估值因子改进**：REP因子从账面价值结构出发改进传统BP因子，与[[估值变动因子]]dEP从时间维度改进估值因子的思路形成互补，两者均试图解决传统估值因子在A股市场表现不稳定的问题。

2. **经济含义清晰**：REP拆分赋予账面价值更清晰的经济含义——留存收益代表内部价值创造，投入资本代表外部融资，这种拆分使估值因子更具可解释性。

3. **动态配置价值**：REP与CCP的周期性互补为因子轮动提供了理论基础，推动了从静态因子配置向动态因子配置的演进。
