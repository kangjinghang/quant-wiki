# 研报情感因子

## Definition / 定义

研报情感因子（Analyst Report Sentiment Factor）是基于[[文本情感分析]]技术，将分析师研报摘要中的情感倾向转化为量化选股信号的多空因子。该因子由[[通联数据]]李立团队开发，利用NLP模型对每篇公司研报摘要进行四分类情感打分（负面/中性/一般正面/强烈正面），再通过时间衰减权重、数字权重和热度权重合成最终因子值。

## How It Works / 工作原理

### 数据生产流程

1. **结构化处理**：PDF研报→HTML结构化→提取摘要核心观点
2. **情感打分**：对每段核心观点进行四分类情感打分（多分类NLP模型）
3. **情感汇总**：将多段情感得分汇总为研报综合得分（可等权或加大负面权重）
4. **因子构建**：往前看120天，对多份研报得分施加三种权重：
   - **时间衰减权重**：距计算日越近的研报权重越高
   - **数字权重**：研报中数字越多，可信度越高
   - **热度权重**：最近浏览量越高的研报权重越高

### 关键设计决策

- **仅使用公司报告**：行业报告用词更模糊，公司报告信息更丰富
- **四分类而非三分类**：将正面拆分为一般正面和强烈正面，改善样本均衡性
- **人工标注而非行情标注**：文本情感应客观，不随市场行情变化而改变
- **加大负面权重**：分析师很少给出负面评价，负面信息的信息含量更高

### 核心指标

| 指标 | 值 |
|------|-----|
| IC（中证800，中性化后） | 3.25% |
| ICIR | 1.88 |
| t值 | 5.37 |
| 月度胜率 | ~62% |
| 纯因子年化收益 | 5.31% |
| 纯因子IR | 2.96 |
| 换手率 | ~6倍/年 |
| 沪深300覆盖率 | ~90% |
| 中证800覆盖率 | ~80% |

## Why It Matters / 为什么重要

研报情感因子解决了传统分析师数据的两大痛点：

1. **及时性**：传统[[一致预期]]和评级调整间隔长（评级调整间隔226天/4.2篇，盈利调整94天/1.8篇），而情感数据每篇研报即可获取
2. **精确性**：分析师发现隐忧时倾向于通过措辞隐晦表达（如"归母净利润增速低于净利润增速"隐藏在正面描述中），NLP可精确捕捉此类隐忧

因子与分析师预期/评级上下调相关性最高仅约40%，与长端动量最高0.45，与其他传统因子相关性低，具有显著的独立信息增量。
