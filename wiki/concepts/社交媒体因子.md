## Definition / 定义

[[社交媒体因子]]（Social Media Factor, SMF）是根据[[股吧发帖数量]]构建的多空因子，具体为低发帖量组合减去高发帖量组合的收益率差。该因子捕捉[[社交媒体效应]]，为[[投资者认知假说]]提供了实证支持。

## 构建方法

1. 数据来源：[[东方财富股吧]]每只股票的月度发帖数量
2. 分组排序：按月度发帖量将股票分为多组
3. 多空组合：低发帖量组（低认知度）减去高发帖量组（高认知度）

## 因子表现

| 指标 | 数值 |
|------|------|
| 多空年化收益 | ~32% |
| 夏普比率 | 1.168 |
| FF三因子alpha | 显著正向 |
| FF五因子alpha | 显著正向 |
| Carhart四因子alpha | 显著正向 |
| R²增加 | 10-20% |

## 与传统因子的关系

SMF与传统Fama-French因子、Carhart动量因子低相关，具有显著的增量Alpha能力。该因子不能被情绪代理变量（换手率、交易量、MAX效应）所解释。
