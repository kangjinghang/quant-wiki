# 神奇公式 / Magic Formula

## Definition / 定义

神奇公式（Magic Formula）是乔尔·格林布拉特（Joel Greenblatt）在其著作《The Little Book That Beats the Market》中提出的价值选股方法。通过两个指标——ROC（资本收益率，衡量盈利质量）和 EY（股票收益率，衡量估值水平）——分别排名后相加，选取综合排名靠前的股票。

## How It Works / 工作原理

### 两个核心指标

$$ROC = \frac{EBIT}{\text{净营运资本} + \text{固定资产}}$$

$$EY = \frac{EBIT}{\text{总市值} + \text{带息负债} + \text{其他权益工具} + \text{少数股东权益}}$$

### 选股流程

1. 排除金融股、ST 股
2. 按 ROC 倒序排列打分（负值降序）
3. 按 EY 降序排列打分
4. ROC 排名 + EY 排名 = 综合排名
5. 选取前 80 只股票
6. 等权配置

### 价值回报指数应用

- 代码：930949.CSI
- 每半年调整一次
- 2006-2019 全收益累计上涨 1432%
- 格力电器入选 25/28 次
- 选股池为全市场非金融股

## Why It Matters / 为什么重要

- 将价值投资从主观判断转化为可量化、可复制的规则
- 同时兼顾质量和估值，避免"价值陷阱"（仅低估值）和"戴维斯双杀"（仅高质量但高估值）
- A 股实证表明长期有效，中小盘价值风格突出
- 指数化后费率低、透明度高，适合个人投资者

## Examples / 示例

- 高 ROC + 高 EY = "便宜又好的公司"
- 低 ROC + 低 EY = "昂贵又差的公司"（回避）
- 茅台案例：PE-EPS 拆分显示盈利驱动估值提升→戴维斯双击
