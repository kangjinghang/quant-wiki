# 股东户数变化因子

## Definition / 定义

[[股东户数变化因子]]（PCT_N）是衡量上市公司股东户数增减变动的选股因子。其核心逻辑基于行为金融学假设：当股东户数持续下降时，通常意味着主力资金在逐步收集个人投资者手中的筹码（吸筹），未来股价上涨阻力减小；反之，股东户数持续上升意味着主力资金派发，未来股价倾向于走弱。

## How It Works / 工作原理

**构建方法**（[[开源金工]]）：

1. **数据来源**：上市公司定期报告（一季报/半年报/三季报/年报）披露的股东户数数据
2. **日期调整**：根据实际发布日期（非报告期截止日）避免未来数据
3. **隔季选取**：在回溯期（1年）内隔季选取股东户数，避免相邻月份重复值
4. **时序ZSCORE**：对选取的股东户数序列计算时序ZSCORE得到因子值
5. **市值行业中性化**：因股东户数与市值高度相关，必须进行截面中性化处理

**关键区分**：
- 股东户数绝对值因子（ABS_N）：中性化后无选股能力，超额收益源于市值效应
- 股东户数变化因子（PCT_N）：中性化后仍有稳定选股能力 → "户数本身不重要，变化才重要"

## Why It Matters / 为什么重要

- 股东户数变动蕴含主力资金吸筹/派发的微观交易信息，是少数能直接反映筹码集中度变化的因子
- 与常见风险因子（市值/估值/动量等）相关性较低，具有独立的选股信息增量
- 2019年以来多空区分度进一步提升，可能与A股机构化加速有关
- 为[[高频合成股东户数变化因子]]提供了低频基准版本

## Performance / 表现

| 指标 | PCT_N |
|------|-------|
| 多头累计净值 | 4.58 |
| 多空累计净值 | 1.73 |
| 多头年化收益率 | 21% |
| 夏普比率 | 0.72 |

- 测试区间：2013.01 – 2020.11
- 股票池：深交所全部上市公司
- 月末调仓，剔除上市不满1年个股
