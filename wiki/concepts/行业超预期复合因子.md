## 定义 / Definition

行业超预期复合因子是[[国泰君安配置团队]]提出的行业轮动因子，以[[盈余惯性|PEAD]]为核心逻辑，借鉴[[行业多因子研究框架]]，将个股超预期因子通过自由流通市值加权合成为行业层面因子后，等权合成12个有效单因子。

## 构建方法

1. **个股因子计算**：在个股层面计算12个超预期相关因子
2. **行业因子合成**：自由流通市值加权（优于等权法，不做市值行业中性化）
3. **复合因子合成**：12个单因子等权合成（避免过拟合）

## 12个组成因子

| 类别 | 因子 | 说明 |
|------|------|------|
| 公告后异常收益 | ABR_0_1 | 公告后1天异常收益（最佳） |
| 公告后异常收益 | ABR_0_3 | 公告后3天异常收益 |
| 公告后异常收益 | JUMP | 公告次日跳空 |
| SUE类 | 单季归母净利润SUE（带漂移项） | 表现最好的SUE因子 |
| SUE类 | 单季营业利润SUE | 营业利润口径 |
| SUE衍生类 | 超分析师预期幅度 | 实际vs预期偏离度 |
| SUE衍生类 | ROA的SUE衍生 | 资产回报率超预期 |
| SUE衍生类 | ROE的SUE衍生 | 净资产收益率超预期 |
| 分析师调整 | 券商上下调比例（90d/180d） | 分析师边际看法 |
| 分析师调整 | 报告上下调比例 | 报告覆盖调整 |
| 分析师调整 | 盈利调整因子 | 盈利预测修正 |
| 其他 | — | 共12个有效因子 |

## 回测表现

- 多头组年化收益：15.32%
- 空头组年化收益：-2.71%
- **多空年化收益：18.03%**
- 分组测试单调性较好

## 与其他因子关系

- 公告后异常收益因子与其他类因子相关性低（<30%），信息增量显著
- SUE因子与SUE衍生因子相关性较高（约0.8），等权合成可避免过度集中于同源信息
