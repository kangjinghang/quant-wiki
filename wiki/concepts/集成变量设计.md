## 定义

集成变量设计（Integrated Variable Design）是一种使用Python面向对象编程（OOP）将散落的转债数据表（价格、成交额、溢价率等）封装为统一字典（DB）对象的编程模式。

## 核心机制

### DB对象封装

```python
class BondDB:
    def __init__(self):
        self._db = {}  # 核心数据字典
    
    def __getitem__(self, key):
        return self._db[key]
    
    def __getattr__(self, name):
        return self._db.get(name)
```

### 关键设计点

1. **统一入口**：所有数据表通过同一DB对象访问
2. **灵活调用**：支持`db['price']`和`db.price`两种语法
3. **懒加载**：按需加载数据，避免内存浪费

## 应用场景

- [[转债数据库规范]]的底层实现技术
- 支持[[转债异常样本过滤]]中的矩阵运算
- 为转债策略回测提供高效数据接口

## 与传统方法的对比

| 维度 | 传统方法 | 集成变量设计 |
|------|----------|-------------|
| 数据存储 | 多个独立DataFrame | 统一DB对象 |
| 调用方式 | 记忆变量名 | 统一接口 |
| 扩展性 | 新增变量需修改多处 | 新增class属性即可 |
| 维护性 | 分散管理 | 集中管理 |
