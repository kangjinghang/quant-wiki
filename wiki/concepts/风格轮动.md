# 风格轮动

## Definition / 定义

风格轮动（Style Rotation）指A股市场中不同风格资产（如大小盘、成长价值）在不同时期呈现周期性相对强弱切换的现象。风格轮动是 [[多因子模型]] 和 [[资产配置]] 研究中的核心课题，直接影响指数增强、FOF 组合构建等实战策略的绩效。

## 风格定义重构 / Style Definition Refinement

传统风格定义依赖宽基指数（沪深300 vs 中证1000），存在代表性不足、边界不清晰的问题。改进方案：

| 风格维度 | 传统定义 | 改进定义 |
|----------|----------|----------|
| 大小盘 | 市值排序分三组 | 分位数 + 流动性筛选 |
| 成长价值 | BP 单因子 | 大类得分相减 + 单项阈值 |

改进后风格定义具有**动态代表性**和**互斥性**，有效避免传统宽基指数的成分股漂移问题。^[风格轮动三部曲-重构-探索和实践]

## 三维轮动模型 / Three-Dimensional Rotation Model

### 1. 宏观维度

- **事件驱动法**："逻辑先导 + 统计后验"的双轨框架
- **Softmax 风格轮动模型**：采用 [[softmax风格轮动模型]]（交叉熵损失多分类逻辑回归），利用宏观基本面慢变量预测未来一个季度四类风格的占优概率
- **最优变量组合**：PMI(3MA) + PMI(12MA) + M1-M2 + 十年国债利率
- 回测（2009-2021）：年化绝对收益 13.5%，月度胜率 61%，年度胜率 87%^[解密a股风格轮动下篇中银量化资配专题]

### 2. 赔率-胜率框架

- **赔率**：风格相对估值水平与预期赔率呈显著负相关，高估值风格"强弩之末"
- **胜率**：宏观（国债收益率、PMI、CPI-PPI）+ 微观（动量、强势股占比、[[北向资金流]]持仓变化）
- 复合模型年化收益 32.09%，Sharpe 1.20^[如何从赔率和胜率看成长价值轮动]

### 3. 微观维度

业绩、资金和量价因子在风格层面呈现显著的**动量效应**，为短期风格轮动提供信号。

## 策略应用 / Strategy Applications

- **价值成长轮动**：年化超额 21.16%，IR 2.27
- **BP 因子改进**：结合轮动信号后多头年化超额由 3.74% 提升至 11.48%
- **ETF 落地**：基于沪深300/中证1000的 ETF 策略展现稳健超额收益

## 核心争议 / Key Tensions

1. **预测周期**：季度预测效果显著优于月度预测（中银量化）
2. **模型局限**：对新逻辑风格（如公募抱团大盘成长）捕获不足，容易低估历史未出现过的新风格
3. **A股特殊性**：A股风格切换受政策驱动显著，纯宏观模型可能遗漏关键变量
