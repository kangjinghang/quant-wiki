## 定义 / Definition

[[高频宏观因子]]是通过[[factor-mimicking因子模拟]]方法构建的周频宏观因子体系。[[华泰金工]]团队采用自上而下的方法，构建了7个维度的宏观因子组合：增长、生活端通胀、生产端通胀、无风险利率、信用利差、期限利差、汇率。每个因子组合的净值同比走势与对应真实宏观指标同比增速高度相关，甚至具有一定领先性，因此高频宏观因子可视为买方的宏观预期指数。

## 构建方法 / Methodology

对于每个宏观维度，factor mimicking的步骤如下：
1. **选择代理资产**：从数学统计和经济学逻辑出发，确定各宏观维度的代理资产。例如增长因子选取恒生指数、CRB工业现货指数、南华沪铜指数的多头序列和7-10年国债净价指数的空头序列。
2. **频率处理**：对每个资产的收盘价序列开展滚动4周移动平均，取每周五的数值，得到周频收盘价序列。
3. **加权**：计算滚动3年各代理资产年度同比收益率序列的标准差，对标准差的倒数归一化，作为各代理资产的权重。
4. **组合构建**：用权重序列对各代理资产周度环比收益率序列进行加权，得到因子组合的周频净值序列。

## 七个因子维度 / Seven Factor Dimensions

| 因子 | 代理资产 |
|------|----------|
| 增长 | 恒生指数(多)、CRB工业现货(多)、南华沪铜(多)、7-10年国债净价(空) |
| 生活端通胀 | 南华生猪指数(多) |
| 生产端通胀 | 布伦特原油(多)、南华螺纹钢(多)、南华动力煤(多) |
| 无风险利率 | 1-3年国债财富指数(多)、货币基金指数(多) |
| 信用利差 | 1-3年企业债AA(多)、1-3年国开债(空) |
| 期限利差 | 狭义：7-10年国债(多)+1-3年国债(空)；广义：中证800成长(多)+中证800价值(空) |
| 汇率 | 上海金(多)、伦敦金现(空)，基于无抛补利率平价 |

## 应用 / Applications

- **直接投资宏观观点**：看好经济增长则直接购买增长因子组合
- [[宏观风险配置模型]]的输入：通过滚动回归计算宏观-行业暴露矩阵
- [[戴维斯双击]]：使用高频宏观因子实时预测行业Δg和ΔPB

## 冗余性检验 / Redundancy Test

依次删除单个宏观因子，用剩余因子复现戴维斯双击策略，结果无论删除哪一个因子策略效果均变差，说明7个因子维度不存在严重冗余性问题。
