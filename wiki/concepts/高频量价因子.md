# 高频量价因子

## Definition / 定义

高频量价因子（High-Frequency Price-Volume Factor）是一类基于日内分钟级别价格与成交量关系构建的选股因子体系。其核心思路是将传统日度量价因子的研究方法论迁移到高频数据上：利用分钟级别的价格、成交额、收益率等数据，通过相关性计算和错期匹配等技术，提取微观交易结构中蕴含的Alpha信号。[[方正金工]]在[[量价关系的高频乐章]]中系统性地提出了COPA、CORA_A、CORA_R三个因子，等权合成后在2014-2019年回测期内表现出色。

与日度量价因子相比，高频量价因子的关键差异在于：日内分钟成交额呈U型/W型分布，量价同向关系被打破（相关性均值从日度的0.43降至接近0），涨跌幅对成交额冲击的对称性提升（散户追涨效应在分钟级别减弱）。

## How It Works / 工作原理

### COPA因子（Correlation between Price and Amount）

$$\text{COPA}_i = \frac{1}{10}\sum_{d=1}^{10} corr(P_{i,t}, A_{i,t})$$

计算日内分钟收盘价 $P_t$ 与成交额 $A_t$ 的Pearson相关系数，取月末10个交易日平均作为月度因子值。COPA因子值越高代表股票呈现"放量上涨、缩量下跌"的投机过热特征，次月具有负向Alpha。中性后IC均值为-3.62%，年化ICIR达-3.94，月度胜率84.51%。COPA暴露于高[[反转因子]]与高换手，推荐直接使用原始价格与成交额计算，避免过度数据处理。

### CORA_A因子（Amount before Return，量在价先）

$$\text{CORA\_A}_i = \frac{1}{10}\sum_{d=1}^{10} corr(A_{i,t-1}, |Ret_{i,t}|)$$

计算前1分钟成交额与后1分钟涨跌幅绝对值的相关系数。该因子捕捉"量在价先"的异常交易行为——因子值越大表示知情交易者（informed trader）或庄家在价格变动前提前出手，暗示信息提前泄露。优化后（成交额标准化 + 剔除零收益分钟）ICIR达-3.25，多空年化IR 3.19。与[[聪明钱因子]]捕捉的知情交易逻辑一致。

### CORA_R因子（Return before Amount，价在量先）

$$\text{CORA\_R}_i = \frac{1}{10}\sum_{d=1}^{10} corr(|Ret_{i,t-1}|, A_{i,t})$$

计算前1分钟涨跌幅绝对值与后1分钟成交额的相关系数。该因子捕捉"价在量先"的异常交易行为——因子值越大表示市场投资者对股价极度敏感，价格变动后大量投资者急于成交，反映情绪驱动交易。优化后ICIR达-3.19，多空年化IR 3.20。

### 数据处理

1. **日内成交额分布标准化**: 分钟成交额天然呈U型/W型分布（开盘/收盘放量，盘中缩量），使用前20交易日同分钟均值进行标准化，剔除分布特征对相关性计算的干扰
2. **剔除零收益分钟**: 涨跌幅为0的分钟数据信息含量低，且低流动性股票零收益比例高，剔除后因子表现显著提升——CORA_A的IR从2.50升至3.19，CORA_R的IR从2.73升至3.20

### 合成因子表现

三个因子简单等权合成（避免数据挖掘），中性后表现：

| 指标 | 数值 |
|------|------|
| IC均值 | -5.03% |
| RankIC均值 | -5.73% |
| 年化ICIR | -4.31 |
| 多空年化收益 | 22.51% |
| 多空年化IR | 4.11 |
| 月度胜率 | >85% |
| 最大回撤 | 4.92% |

## Why It Matters / 为什么重要

- **Alpha迁移路径**: 证明了日度量价因子方法论可以系统性地迁移到高频数据，为中低频Alpha被逐渐挖掘后的因子研发提供了新方向——转向高频数据挖掘
- **日内量价关系的独特性**: 日内量价同向关系被打破（与日度截然不同），错期匹配在高频上同时发现"量在价先"和"价在量先"两种Alpha（日频上仅前者有效），说明高频数据蕴含日频无法捕捉的微观交易结构信息
- **稳健性提升**: 相比日频因子，高频因子在测试期内表现更稳定，月度胜率更高，最大回撤更小，投机资金较难操纵日内240分钟每一分钟的价量数据
- **交易行为刻画**: 因子从微观层面捕捉量价纠缠，反映宏观层面的个股投机与泡沫——日内交易平稳的股票次月更容易上涨
