# 东吴固收

## Overview / 概述

东吴证券固定收益研究团队，以李勇（宏观债券研究）为核心研究员。李勇此前在[[东北证券]]从事可转债定价研究，2020年在东吴证券延续该方向，发表了对303只可转债的蒙特卡洛定价研究报告。该团队在[[可转债定价]]领域有持续深度的积累，核心贡献是将赎回、回售和[[下修条款]]的不确定性引入MC定价模型。

## Key Facts / 关键事实

- 所属机构：东吴证券（Soochow Securities）
- 核心研究员：李勇
- 研究领域：固定收益、可转债定价、转债策略
- 关键贡献：引入条款不确定性概率的MC转债定价模型
- 与[[东北证券]]团队的联系：李勇此前在东北证券发表可转债MC定价研究（2018.4），后转至东吴证券继续深化该方向
- 相关研究：
