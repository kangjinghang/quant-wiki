# 中金固收

## Overview / 概述

中国国际金融股份有限公司（中金公司/CICC）固定收益研究团队。核心成员包括分析员杨冰（SAC S0080515120002）、分析员姬江帆（SAC S0080511030008）、联系人房铎。该团队在可转债研究领域有系列深度报告，尤其注重模型实现和 Python 编程技巧。

## Key Facts / 关键事实

- 所属机构：中金公司（China International Capital Corporation）
- 核心研究员：杨冰、姬江帆、陈健恒、房铎、吴若磊
- 研究领域：固定收益、可转债定价与策略、基金归因、转债因子模型、转债技术分析、转债策略库、正股风险识别、固收+基金风格测算、债基久期测算
- 研究特色：注重模型实战实现，附带完整 Python 代码；融合量化与经典技术分析；正客"体检"排除法；分步过滤法测算基金风格；有效波动比矫正久期测算时滞
- 研究时间线：
  - 2018.11：《说没用也有点用的转债定价：顺便聊聊转债研究员的Python技巧》
  - 2019.5：《简易的转债策略测试框架——以及python实现方法》
  - 2019.7：《转债基金择时、择券能力如何区分》（杨冰、吴若磊、陈健恒）
  - 2019.11：《新券定位：方法、边际变化与python实现》（杨冰、房铎、吴若磊、陈健恒）
  - 2020.06：《转债也能做因子模型吗？》（杨冰、房铎、吴若磊、陈健恒）——转债多因子框架+Python
  - 2020.08：《转债技术分析体系篇》（杨冰、房铎、吴若磊、陈健恒）——利弗莫尔+缠论应用于转债
  - 2020.11：《转债基金的风格分解与Python实现》——四类风格指数+带约束回归分解基金Alpha
  - 2020.11：《是时候，选出更好的策略了：转债策略库及测试》——4大类75个转债策略系统测试
  - 2020.12：《为了不后悔——关于转债正股的"体检"》——影线实体比/K线变异系数/质押风险识别正股暴跌
  - 2021.01：《如果一定要看"偏债"》——低价转债排雷5大特征+Python选券代码，应对破面比例30%极端环境
  - 2021.03：《"固收+"们也换风格了吗？》——分步过滤法测算固收+基金风格分布，转债基金+头部产品保持原有风格
  - 2021.05：《久期测算的探索：细节处理与Python实践》（杨冰、吴若磊、罗凡、陈健恒）——有效波动比矫正+扩散指标观察市场久期
  - 2021.07：《余弦与固收+基金策略识别》（杨冰、吴若磊、罗凡、陈健恒）——基于夹角余弦的转债基金策略识别
  - 2021.08：《简单策略的一加一大于二及Python实现》（杨冰、罗凡、陈健恒）——转债策略组合优化框架（策略分仓+策略叠加）
  - 2022.01：《"当赎回也不再确定"的后续》（罗凡、房铎、杨冰、陈健恒）——赎回决策树模型与发行人学习效应
  - 2022.04：《风格轮动：规律、策略与Python实现》（杨冰、房铎、罗凡、陈健恒）——风格轮动边界阈值+转债/固收+策略
