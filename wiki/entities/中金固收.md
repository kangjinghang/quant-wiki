# 中金固收

## Overview / 概述

中国国际金融股份有限公司（中金公司/CICC）固定收益研究团队。核心成员包括分析员杨冰（SAC S0080515120002）、分析员姬江帆（SAC S0080511030008）、联系人房铎。该团队在可转债研究领域有系列深度报告，尤其注重模型实现和 Python 编程技巧。

## Key Facts / 关键事实

- 所属机构：中金公司（China International Capital Corporation）
- 核心研究员：杨冰、姬江帆、陈健恒、房铎、吴若磊
- 研究领域：固定收益、可转债定价与策略、基金归因
- 研究特色：注重模型实战实现，附带完整 Python 代码
- 研究时间线：
  - 2018.11：《说没用也有点用的转债定价：顺便聊聊转债研究员的Python技巧》
  - 2019.5：《简易的转债策略测试框架——以及python实现方法》
  - 2019.7：《转债基金择时、择券能力如何区分》（杨冰、吴若磊、陈健恒）
