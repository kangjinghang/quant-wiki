# 中金固收

## Overview / 概述

中国国际金融股份有限公司（中金公司/CICC）固定收益研究团队。核心成员包括分析员[[杨冰]]（SAC S0080515120002）、分析员姬江帆（SAC S0080511030008）、联系人[[房铎]]。该团队在[[可转债定价]]研究领域有系列深度报告，尤其注重模型实现和 Python 编程技巧。

## Key Facts / 关键事实

- 所属机构：中金公司（China International Capital Corporation）
- 核心研究员：杨冰、姬江帆、陈健恒、房铎、吴若磊
- 研究领域：固定收益、可转债定价与策略、基金归因、转债因子模型、转债技术分析、转债策略库、正股风险识别、固收+基金风格测算、债基久期测算

- [[行业分化度]] — 基于PCA主成分分析提取的行业涨跌幅方差解释比例，用于刻画市场是否存在明显的主线或处于普涨普跌状态。
- [[相对换手率因子]] — 衡量近期换手率相对历史水平高低的技术指标，本文发现其在2023年具有显著的相对回报预测能力。
- [[随机森林]] — 一种基于决策树的集成机器学习算法，通过构建多个决策树并输出类别或回归均值来提高预测准确率，文中用于预测转债财务退市风险。
- [[lstm模型]] — 一种适合处理和预测时间序列中间隔和延迟相对较长的重要事件的循环神经网络（RNN）变体，本文用于预测市场波动率。
- [[确定性溢价]] — 在宏观环境缺乏明确主线且市场风险偏好抬升较慢的弱波动修复期，市场资金更倾向于给予基本面稳固、增长能力确定性高的标的以估值溢价。
- [[波动率预测模型]] — 利用历史波动率、换手率、市值及机构持股数量等特征，通过机器学习算法（如XGBoost或神经网络）预测正股未来波动率，以筛选高弹性转债的量化模型。
- [[百元溢价率]] — 衡量转债估值水平的核心指标，中金固收研究指出当该指标达到27%时，转债市场往往面临回调压力和亏损风险。
- [[大单净流入强度因子]] — 衡量正股大户资金净流入强度的指标，通过剥离涨跌幅影响和转债估值中性化处理，用于挖掘同等涨跌幅和估值下资金更踊跃流入的转债标的。
- [[小单净流出交易性因子]] — 衡量正股散户资金净流出情况的指标，反映自然人投资者“错卖”造成的交易性机会，在剥离大单影响后结合转债规模和活跃度能显著提升超额收益。
- [[转债择时体系]] — 针对可转债市场构建的包含估值、情绪、结构等多维度的综合择时指标框架，旨在通过客观可验证的数据体系取代主观直觉判断。
- [[弱势品种表现指标]] — 衡量规模大且溢价率高的转债在短期内债底溢价率提升情况的指标，主要用于捕捉资金推动下的市场过热现象。
- [[转债市场情绪指标]] — 结合换手率（量）与超买比例（价）构建的短期情绪高低点揭示指标，有效期大约为10天至60天。
- [[甜点转债数]] — 基于期权定价视角，通过Delta、Theta、Gamma等希腊字母计算得出的性价比较高、容易获利的转债数量指标。
- [[债性转债债底溢价率偏离]] — 考察平价70元以内的债性转债平均债底溢价率的短期（如21日、55日）偏离率，用于寻找市场调整带来的错杀机会。
- [[决策树择时模型]] — 在转债整体择时中，为保持模型可读性而采用的浅层决策树模型，用于混合多个估值与情绪指标并生成可解释的交易规则。
- [[真实收益率]] — 一种将债性转债的到期收益率（YTM）与基于BS模型测算的转股预期收益相结合的综合性收益率指标，用于衡量低价转债的真实投资价值。
- [[转债波粒二象性]] — 借用物理学概念，指可转债在到期或转股前处于股债“混合态”，其溢价（时间价值）在面临确定性假设时会“坍缩”的特性。
- [[甜点转债]] — 指同时具备较低下行风险和较高向上弹性，处于风险收益比较好区间的可转债品种。
- [[负gamma现象]] — 指转债在特定平价区间内，因退市风险消退或条款博弈影响，其价格对正股波动的二阶导数（凸性）变为负值，导致越涨弹性越弱的现象。
- [[转债波动率倾斜]] — 指转债市场中，平价较低的偏债品种隐含波动率（估值）显著高于平价较高的股性品种的现象，通常反映市场风险偏好和条款博弈预期。
- [[平衡性转债红利区]] — 指平价在90~105元附近的转债区间，在波动率倾斜的市场环境下，该区间品种在上涨和下跌情景下均具备较好的敏感度和保护性，性价比最高。
- [[会计准则差异]] — 指不同国家或地区（如中国CAS、国际IFRS、美国US GAAP）在财务报表编制、确认和计量方面存在的规定和实务处理差异。
- [[公允价值计量]] — 一种基于当前市场条件对资产或负债进行估价的会计计量属性，在IFRS下应用广泛，而在CAS和US GAAP下使用相对谨慎。
- [[企业合并]] — 指企业通过股权交易等方式获取其他企业控制权的行为，不同会计准则在合并范围确定和同一控制下合并的会计处理上存在显著差异。
- [[金融工具分类]] — 企业对持有的股票、债券、衍生品等金融资产根据业务模式和合同现金流特征进行的会计分类，不同准则下的分类标准和报表列报存在差异。
