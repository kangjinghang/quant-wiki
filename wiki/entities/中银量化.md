# 中银量化

## Overview / 概述

中银量化团队（郭策），在[[指数增强]]和风险模型两个方向有独特贡献。该团队从[[规模效应]]和[[股权集中度]]两个正交因子出发构建沪深300指数增强策略，与开源金工的多因子复合方法形成互补。同时对[[barra-cne5模型]]进行了深度解读，采用EUE3异常值处理方法和多重填补法自主复现了CNE5风格因子，关注Barra模型的技术细节和实战应用。

## Key Facts / 关键事实

- 所属机构：中银国际证券（BOCI Securities）
- 核心研究员：郭策
- 研究领域：量化投资、指数增强、多因子风险模型
- 核心贡献：
  - 沪深300[[规模效应]]+[[股权集中度]]双因子增强策略（超额年化15.3%）
  - [[barra-cne5模型]]深度解读与技术细节复现（EUE3异常值处理+多重填补法）
