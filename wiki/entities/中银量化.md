# 中银量化

## Overview / 概述

中银量化团队（[[郭策]]），在[[指数增强]]、风险模型和[[行业轮动]]方法论三个方向有独特贡献。该团队从[[规模效应]]和[[股权集中度]]两个正交因子出发构建沪深300指数增强策略，与开源金工的多因子复合方法形成互补。同时对[[barra-cne5模型]]进行了深度解读，采用EUE3异常值处理方法和多重填补法自主复现了CNE5风格因子，关注Barra模型的技术细节和实战应用。此外，该团队在方法论层面也有深度思考——[[量化与主观思考的对立与统一]]一文引入[[朱迪亚-珀尔|珀尔]]的因果推断理论剖析量化模型局限，倡导[[基本面量化]]路径。行业轮动方法论方面，提出[[多策略配置]]优于[[多策略轮动]]的配置理念。

## Key Facts / 关键事实

- 所属机构：中银国际证券（BOCI Securities）
- 核心研究员：郭策
- 研究领域：量化投资、指数增强、多因子风险模型
- 核心贡献：
  - 沪深300[[规模效应]]+[[股权集中度]]双因子增强策略（超额年化15.3%）
  - [[barra-cne5模型]]深度解读与技术细节复现（EUE3异常值处理+多重填补法）
  - CNE5实证分析：揭示2013年后解释力衰减根因（个股离散度Rho与Adj R-Square相关75%），推断模型在熊市表现优于牛市
  - 量化方法论思考：引入珀尔因果推断理论，剖析量化模型相关性vs因果性局限，倡导基本面量化路径
  - 行业轮动方法论：提出[[多策略配置]]优于[[多策略轮动]]，[[残差周期对冲]]是配置体系的核心机制
  - [[盈利预期行业轮动]]：基于分析师盈利预期的行业轮动策略，复合因子样本内年化超额12.1%/样本外11.9%

- [[凝聚分层聚类]] — 一种无监督学习的层次聚类算法，通过自下而上地将每个对象作为一个簇，然后合并这些原子簇为越来越大的簇，直到满足终结条件。

- [[极端估值保护机制]] — 一种通过剔除当前PB分位数处于历史极端高位（如95%以上）的行业，以规避估值泡沫风险的风控机制。
- [[分层聚类法]] — 一种用于处理大量相似因子，通过聚类遍历找出最优因子组合并进行等权复合的机器学习方法。
- [[估值泡沫]] — 指资产价格在短期内急剧上涨，远超其内在价值，通常伴随极高的估值分位数，存在均值回归的下跌风险。
- [[锚定反转因子]] — 一种结合行为金融学中锚定偏误与处置效应构建的改进型反转因子，通过以近期股价高低点为锚点计算相对涨跌幅来捕捉更真实的投资者非理性行为。
- [[锚定偏误]] — 行为金融学概念，指投资者在进行定量估测时，倾向于将某些特定数值（如持股成本或近期高低点）作为起始值，从而制约其估测决策的心理现象。
- [[处置效应]] — 指投资者倾向于卖出已盈利的股票，而继续持有亏损股票的非理性投资行为，通常与锚定偏误密切相关。
- [[价值盲区掘金因子]] — 由业绩超预期、市场交易充分度和估值预期重估强度三个维度复合而成的选股因子，旨在挖掘基本面超预期但市场定价修正不及时的个股。
- [[核心利润]] — 由张新民（2014）提出的一种利润改造指标，剔除了投资收益、公允价值变动和资产减值等非日常经营活动影响，侧重反映企业纯粹的经营获利能力。
- [[换手波动率]] — 衡量一定时期内换手率波动程度的指标，相较于平均换手率，它能更好地反映市场对错误定价修正的剧烈程度和充分性。
- [[价值掘金因子]] — 由中银量化团队提出的深度价值类复合因子，通过结合基本面错误定价程度与市场定价修正效率（特异质换手波动率）来获取超额收益。
- [[特异质换手波动率]] — 一种市场定价效率因子，通过剥离主流风格对换手率的影响，计算残差换手率的波动程度，以反映市场对个股错误定价的修正激烈程度。
- [[基本面错误定价]] — 指股票的市场价格偏离其基于基本面（如剩余收益模型）计算出的内在价值的现象，是构建价值掘金因子的核心逻辑之一。
