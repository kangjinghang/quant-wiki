# 中银量化

## Overview / 概述

中银量化团队（郭策），在[[指数增强]]方向有独特贡献。该团队从[[规模效应]]和[[股权集中度]]两个正交因子出发构建沪深300指数增强策略，与开源金工的多因子复合方法形成互补。核心发现是沪深300成分股中大市值股票长期稳健跑赢指数，且股权集中度因子与规模因子驱动逻辑完全不同（相关系数-0.01），两者叠加后增强效果显著。

## Key Facts / 关键事实

- 所属机构：中银国际证券（BOCI Securities）
- 核心研究员：郭策
- 研究领域：量化投资、指数增强
- 核心贡献：沪深300规模效应+股权集中度双因子增强策略
