# 华创金工

## Overview / 概述

华创证券金融工程研究团队。主要研究成员包括首席分析师陈杰、高级分析师王小川、研究员卢威、研究员邵文、助理研究员秦玄晋。研究领域涵盖[[业绩超预期]]因子、[[形态选股]]、[[分析师关注度|分析师行为]]等，提出了自定义[[一致预期]]算法、[[esp因子|ESP]]/[[sue因子|SUE]] 因子体系和原创[[倒杯子形态]]。

## Key Facts / 关键事实

- 所属机构：华创证券（HuaChuang Securities）
- 核心研究员：陈杰（首席）、王小川（高级）、卢威、邵文
- 研究领域：量化选股、因子投资、分析师行为
- 核心贡献：自定义一致预期算法、ESP/SUE 因子、业绩超预期选股策略、原创倒杯子形态、AAT 分析师关注度信号
- 研究时间线：
  - 2018.4：《一致预期及业绩超预期深度解析》
  - 2018.6：《季度超预期再构建及业绩超预期因子分析》
  - 2018.9：《形态选股系列之一：基于倒杯子形态的识别与交易探索》
  - 2018.9：《分析师推荐信号深入挖掘》（卢威）
  - 2019.3：《基于双底形态的识别与交易探索》（秦玄晋）
  - 2019.4：《成交量的奥秘：另类价量共振指标的择时》
- 配套网站：hcquant.com（形态监控、负面信息预警）
  - 2026.06：《K线形态研究开篇：形态学初识与应用》
  - 2026.06：《形态学研究之二：如何利用形态信号进行市场择时》
  - 2026.06：《基于排序学习的行业轮动模型》
  - 2026.06：《K线形态学研究系列之三：十字孕线》

- [[排序学习]] — 一种监督学习方法，通过训练模型解决排序问题，广泛应用于信息检索，近年来被引入量化投资以解决资产筛选和行业轮动问题。
- [[lgbmranker模型]] — 基于LightGBM的排序学习模型，专门用于处理排序任务，通过引入排序相关的损失函数和评估指标，在量化投资中常用于构建行业轮动或多因子选股策略。
- [[ndcg指标]] — 归一化折损累计增益，一种常用于评估排序学习模型性能的指标，能够综合考虑排序结果的质量和位置因素。
- [[十字孕线]] — 一种由长实体K线与紧随其后的十字线组成的二日K线反转形态，分为正面（阴线+十字线）和负面（阳线+十字线）形态。
