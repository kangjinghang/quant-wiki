# 华创金工

## Overview / 概述

华创证券金融工程研究团队。主要研究成员包括首席分析师陈杰、高级分析师王小川、研究员卢威、研究员邵文、助理研究员秦玄晋。研究领域涵盖[[业绩超预期]]因子、[[形态选股]]、[[分析师关注度|分析师行为]]等，提出了自定义[[一致预期]]算法、[[esp因子|ESP]]/[[sue因子|SUE]] 因子体系和原创[[倒杯子形态]]。

## Key Facts / 关键事实

- 所属机构：华创证券（HuaChuang Securities）
- 核心研究员：陈杰（首席）、王小川（高级）、卢威、邵文
- 研究领域：量化选股、因子投资、分析师行为
- 核心贡献：自定义一致预期算法、ESP/SUE 因子、业绩超预期选股策略、原创倒杯子形态、AAT 分析师关注度信号
- 研究时间线：
  - 2018.4：《一致预期及业绩超预期深度解析》
  - 2018.6：《季度超预期再构建及业绩超预期因子分析》
  - 2018.9：《形态选股系列之一：基于倒杯子形态的识别与交易探索》
  - 2018.9：《分析师推荐信号深入挖掘》（卢威）
  - 2019.3：《基于双底形态的识别与交易探索》（秦玄晋）
  - 2019.4：《成交量的奥秘：另类价量共振指标的择时》
- 配套网站：hcquant.com（形态监控、负面信息预警）

- [[k线形态学]] — 研究股票价格在下跌、盘整、上升过程中的价格轨迹图形、形态及特征的理论，其本质是多空双方资金博弈留下的轨迹。
- [[多空形态比率剪刀差]] — 一种基于全市场个股K线形态看多与看空比例差值构建的市场中期择时指标。
- [[推波助澜模型]] — 华创金工开发的基于A股涨跌停个股数量比率剪刀差构建的一系列市场择时模型。
- [[hma平滑]] — 赫尔移动平均线，一种旨在减少滞后性并提供更平滑信号的移动平均技术，常用于量化择时指标的处理。
- [[排序学习]] — 一种监督学习方法，通过训练模型解决排序问题，广泛应用于信息检索，近年来被引入量化投资以解决资产筛选和行业轮动问题。
- [[lgbmranker模型]] — 基于LightGBM的排序学习模型，专门用于处理排序任务，通过引入排序相关的损失函数和评估指标，在量化投资中常用于构建行业轮动或多因子选股策略。
- [[ndcg指标]] — 归一化折损累计增益，一种常用于评估排序学习模型性能的指标，能够综合考虑排序结果的质量和位置因素。
- [[十字孕线]] — 一种由长实体K线与紧随其后的十字线组成的二日K线反转形态，分为正面（阴线+十字线）和负面（阳线+十字线）形态。
- [[母子线]] — 由两根K线组成的二日K线反转形态，分为看涨（正面）母子线和看空（负面）母子线，常用于预示股价短期趋势的反转。
- [[三内部上涨下跌线]] — 一种由三根K线组成的看涨或看跌反转形态，表明当前趋势失去动力，结合均线或基本面指标可提升预测胜率。
- [[乌云压顶线]] — 一种二日看空K线形态，第一根为阳线，第二根跳空高开但收盘价收于第一根K线实体内，常用于提示顶部反转风险。
- [[停顿线]] — 一种由三根K线组成的看空形态，前两根为大中阳线，第三根为小实体阳线，预示上涨动能衰竭和潜在的反转下跌。
- [[lambda-mart算法]] — 结合LambdaRank梯度函数和MART（GBDT）的排序学习算法，通过决策树对梯度进行建模。
- [[滚动训练]] — 一种动态调整模型超参数的训练方法，使用过去一段时间的数据训练并在未来时点预测，以保证模型的时效性。
- [[并行计算]] — 一种同时使用多种计算资源解决计算问题的计算模式，通过将任务从单指令单数据(SISD)向多指令多数据(MIMD)转变以加速执行。
- [[多进程]] — 操作系统层面实现并行计算的一种方式，通过在内存中开辟独立空间运行多个程序实例，适用于计算密集型且需要高稳定性的任务。
- [[多线程]] — 程序执行层面实现并行的方式，线程是CPU调度的基本单位，适用于I/O密集型任务，但存在同步复杂和子线程相互影响的问题。
- [[gpu加速]] — 利用图形处理器(GPU)的大规模并行计算能力来加速通用计算任务，特别适用于海量金融数据的合并、聚合与统计。
- [[cuda架构]] — 由英伟达推出的统一计算设备架构，允许开发者利用C语言或Python在GPU上编写通用并行计算程序。
