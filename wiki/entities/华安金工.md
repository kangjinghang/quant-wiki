# 华安金工

## Overview / 概述

华安证券研究所金融工程团队，立足精品报告，发力卖方研究。研究特色包括市场微观结构剖析系列（日内[[高频因子|高频选股因子]]）、[[基本面量化|量化基本面]]系列（[[估值因子]]改进）和交易制度研究（[[t0交易制度|T+0制度比较]]）。

## Key Facts / 关键事实

- 所属机构：华安证券（Hua'an Securities）
- 核心研究员：尹沿技（首席分析师，S0010520020001）、朱定豪（S0010520060003）、严佳炜（S0010520070001）、邹坤（S0010520040001）、方晨（S0010120040043）
- 研究领域：市场微观结构、日内高频因子、交易制度研究、估值因子、量化基本面
- 研究特色：市场微观结构剖析系列（共九篇）、量化基本面系列（REP/CCP+盈利加速度），从行为金融学和信号处理视角捕捉市场异常
- 研究时间线：
  - 2020.06：《高频视角下成交额蕴藏的Alpha》（尹沿技）——尾盘成交额占比因子APL_20，市场微观结构系列之七
  - 2020.06：《T+0交易制度的境外发展与境内探索》（邹坤、方晨）——境外T+0制度比较与A股展望
  - 2020.07：《信息提纯：寻找高质量反转因子》（朱定豪、严佳炜）——EMD信噪比因子SNR+增强反转，市场微观结构系列之八
  - 2020.08：《留存收益、投入资本视角下的估值因子改进》（朱定豪、严佳炜）——REP/CCP因子拆分+双因子轮动，量化基本面系列之一
  - 2020.09：《昼夜分离：隔夜跳空与日内反转选股因子》（严佳炜、朱定豪、钱静闲）——昼夜分离反转因子，市场微观结构系列之九
  - 2020.09：《成长因子再升级：盈利加速度》（严佳炜、朱定豪、吴正宇）——盈利加速度因子OPER_PROFIT_EAV，量化基本面系列之二
  - 2021.07：《社交媒体效应、投资者认知和股票横截面收益》（严佳炜、朱定豪）——学海拾珠系列之五十一，社交媒体因子SMF
  - 2021.09：《如何借鉴赛道型基金持仓？基于业绩归因视角》（严佳炜、朱定豪、吴正宇）——基于业绩归因视角的赛道型基金持仓借鉴策略
  - 2021.11：《企业生命周期理论如何运用在选股中》（严佳炜、吴正宇）——量化基本面系列报告之五
  - 2022.05：《固收组合构建白皮书：大时代的小尝试（上）》（严佳炜、吴正宇）——量化绝对收益之路系列首篇，稳健型固收+策略年化6.72%

- [[宏观事件驱动法]] — 一种通过定义宏观指标的特定事件模式（如创新高、边际改善等），研究宏观变量处于极端状态下资产收益规律的量化方法。
- [[宏观行业映射模型]] — 利用逻辑回归模型，将宏观事件触发的标签得分转化为二级行业跑赢基准概率的预测模型。
- [[可比公司法]] — 一种借鉴主动研究逻辑，通过量化模型寻找在财务特征上高度相似的企业集合，并以此为基础重构价值因子的估值方法。
- [[关联价值因子]] — 基于可比公司法，从基准、空间和时间三个维度提取可比公司估值信息，合成得到的具有更强预测能力和稳定性的改进型价值因子。
- [[估值个性度]] — 衡量目标公司估值能被可比公司解释的程度，用于在构建基准类因子时对可比公司估值和目标公司自身估值进行加权。
- [[余弦相似度]] — 一种通过计算两个向量在多维空间中的夹角余弦值来衡量个体间相似程度的指标，本文用于度量公司间财务特征的相似性。
- [[gpt评分因子]] — 基于ChatGPT对分析师研报标题的情感评分构建的量化选股因子，包括等权、指数衰减加权和波动因子，属于新型另类因子。
- [[gpt超预期]] — 指利用ChatGPT对分析师盈余点评标题进行情感评分，将评分大于9分的样本定义为业绩超预期的股票池。
- [[收益-波动非对称性]] — 指股票收益与波动率之间存在的动态跨期不平衡关系，表现为波动率随价格下降而上升、随价格上升而下降的特征。
- [[波动超前因子]] — 一种基于波动率反馈效应构建的因子，使用历史波动率和未来收益计算皮尔逊相关系数，具有正向的选股能力。
- [[波动滞后因子]] — 一种基于杠杆效应构建的因子，使用历史收益和远期波动率计算皮尔逊相关系数，具有负向的选股能力。
- [[同期效应因子]] — 使用同期收益和波动率计算的皮尔逊相关系数构建的因子，反映收益和风险同源的特性，具有负向预测能力。
- [[风格轮动策略]] — 利用宏观、市场状态和微观三维信号，对大小盘或价值成长风格进行动态配置的量化策略。
- [[风格微观动量效应]] — 指在风格层面，历史业绩更佳、资金偏好或交易活跃的风格，未来仍会保持相对强势的现象。
- [[bp因子改进]] — 结合风格轮动信号对传统BP（市净率倒数）因子进行改造，以提升其选股效果的方法。
- [[m-v因子]] — 市值与公司“真实价值”之比，通过分行业回归估算公司基本面价值，以替代传统PB因子衡量市场定价偏差。
- [[val因子]] — 结合截面估值偏差（M/V）与时序增长潜力（Vts/B）重塑的新估值因子，剔除了行业时序估值波动的干扰。
- [[加速换手因子]] — 一种动态流动性因子，通过计算特定时序择时信号（如放量上涨）触发时的换手率变化量来预测股票未来收益。
- [[dam-gat模型]] — 一种动态属性敏感图注意力网络，用于处理股票间属性敏感的动量溢出并自动学习公司间的动态关联网络。
- [[动量溢出效应]] — 指一家公司股价的变化（动量）通过某种关联传导并影响其他关联公司股价的现象。
- [[pred5d因子]] — 由DAM-GAT模型生成的预测股票未来5日收益的因子，在全域和各指数域均表现出优秀的选股能力。
- [[另类分析师因子]] — 从分析师目标价、报告页数和发布时点等非传统维度提取的选股因子，与传统基本面和量价因子相关性低，能提供独立的alpha来源。
- [[目标收益因子]] — 基于分析师给出的目标价计算的预期收益率因子，经过可比性调整、发布时点分析和时间序列标准化后，具有显著的选股能力。
- [[报告页数因子]] — 利用分析师研报的页数数据构建的因子，作为分析师关注度的另类表达方式，其时间序列偏离度具有显著的选股效果。
- [[报告发布天数因子]] — 衡量分析师报告发布时间与最近财报公告时间间隔的因子，反映分析师覆盖的及时性和优先级，具有负向选股能力。
- [[理论分红模型]] — 一种基于未分配利润变化、盈利能力（ROE）和资本结构（D/A）构建的截面回归模型，用于估算企业单季度理论上可自由支配的现金流。
- [[td-m因子]] — 理论分红/市值因子，通过理论分红模型估算的企业单季度理论分红金额与总市值的比值构建，具有显著的收益预测能力。
- [[未分配利润]] — 企业在一定会计期间内实现的利润中尚未分配给股东的部分，是衡量企业分红能力的关键指标。
