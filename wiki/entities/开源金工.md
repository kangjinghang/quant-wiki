# 开源金工

## Overview / 概述

开源证券研究所金融工程团队，首席分析师魏建榕博士（复旦大学理论物理学），核心成员傅开波、高鹏。团队格守「原创、深度、讲逻辑、可验证」的研究准则，在实证行为金融学和[[市场情绪指标|市场微观结构]]研究领域有独创性贡献。

## Key Facts / 关键事实

- 所属机构：开源证券（Open Source Securities）
- 核心研究员：魏建榕（首席，复旦大学理论物理博士）、傅开波、高鹏
- 研究领域：行为金融学、市场微观结构、因子研究、CTA策略
- 研究特色：注重逐笔成交数据的微观分析，独创W式切割方法
- 代表系列：《反转因子的精细结构(W式切割)》、《聆听高频世界的声音》、《蜘蛛网CTA策略》
- 研究时间线：
  - 2018.12：《反转因子的精细结构(W式切割)》（魏建榕、傅开波）
  - 2019.12：《A股反转之力的微观来源》（魏建榕、傅开波、高鹏）
