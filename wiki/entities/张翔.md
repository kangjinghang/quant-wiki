# 张翔

## Overview / 概述

[[张翔]]是[[开源金工]]分析师，研究领域覆盖资产配置、基金研究和行业轮动。参与了[[北向资金行业轮动]]策略系列和[[行业配置的量化解决方案]]四维综合模型的研究工作。

## Key Facts / 关键事实

- 所属机构：[[开源金工]]（开源证券金融工程团队）
- 研究方向：资产配置、基金研究、行业轮动
- 参与报告：《北上资金行业配置的双轮驱动力》、《行业配置的量化解决方案》

- [[高频宏观因子]] — 利用资产收益率通过统计或回归方法拟合出的周频宏观指标，旨在解决传统宏观指标更新慢、滞后性强的问题，用于高频资产配置与风险管理。
- [[普林格周期]] — 由马丁·普林格提出，在美林时钟基础上引入先行指标（信贷/利率），将经济周期划分为六个阶段（逆周期调节、复苏初期、复苏末期、过热、滞涨、萧条）的资产配置模型。
- [[风险暴露管理]] — 一种基于宏观因子的投资组合优化框架，通过根据宏观因子的趋势动量对基准组合施加微小的因子暴露偏移，在不大幅偏离基准权重的前提下实现“宏观增强”。
- [[久期择时策略]] — 基于利率债预期收益框架，动态选择预期收益最高的期限品种持有，以获取超额收益并应用于资产配置增强的策略。
- [[nelson-siegel模型]] — 一种经典的收益率曲线拟合模型，通过水平、斜率和曲率三个参数因子来刻画截面上的期限结构，具有参数少、解释性强的优点。
- [[水平因子]] — Nelson-Siegel模型中的核心参数之一，代表收益率曲线的水平位置，经济含义上等同于长债收益率，其预测精度是决定长端利率预测效果的关键瓶颈。
- [[滚动lars回归]] — 一种使用最小角回归（LARS）算法进行滚动变量选择的方法，用于从众多宏观变量中筛选出对目标变量具有稳定预测效果的变量组合。
- [[动态中枢均值回复]] — 一种假设金融时间序列围绕动态变化的政策利率中枢进行均值回复的预测方法，常用于改进长端利率预测模型。
- [[百元转股溢价率]] — 一种通过反比例回归法将不同平价的转股溢价率标准化至平价为100元时的溢价率指标，用于在时序上比较转债整体估值水平。
- [[转债综合估值因子]] — 融合转股溢价率偏离度与蒙特卡洛模拟理论价值偏离度的复合因子，用于筛选低估值的可转债以进行增强配置。
- [[转债风格轮动]] — 基于市场情绪指标（动量与波动率偏离度），在偏股、平衡、偏债转债低估风格指数之间进行动态轮动配置的策略。
- [[修正ytm]] — 剥离了转债内含期权价值及条款影响后的到期收益率，使其与普通信用债的YTM具备直接可比性。
- [[行业轮动3-0模型]] — 开源金工提出的基于“一级行业+双周频率”，融合交易行为、景气度、资金流、筹码结构、宏观驱动和技术分析六个维度，并采用动态最小化排名跟踪误差方法合成信号的综合行业轮动体系。
- [[筹码结构模型]] — 通过假设每日存量持仓按换手率均匀换仓来估算市场筹码分布，结合行为金融学中的前景理论和处置效应，利用市场赚钱效应构建持仓收益与阻力支撑因子的行业轮动模型。
- [[etf轮动框架]] — 一种将行业轮动信号落地为ETF产品投资的实战框架，遵循“行业选择（轮动信号）-指数选择（高弹性）-产品选择（高流动性）”的三步流程。
- [[动态合成模型]] — 采用最小化排名跟踪误差方法，动态优化多个子模型权重的信号合成技术，能够自适应地调整失效模型和主导模型的权重分配。
