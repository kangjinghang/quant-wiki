# 徐龙炳和吴文彬

## Overview / 概述

2023年在《中国管理科学》发表《过度反应、跳跃收益与A股动量策略》，发现A股市场的[[反转效应]]主要由[[股价跳跃识别|股价跳跃]]所带来的，扣除跳跃后的非跳跃收益呈[[动量效应]]。该研究为[[跳跃因子反转机制]]提供了重要的学术支撑。

## Key Facts / 关键事实

- 发现A股反转效应主要由股价跳跃贡献
- 扣除跳跃后的非跳跃收益呈现动量效应
- 论文发表在《中国管理科学》2023年
