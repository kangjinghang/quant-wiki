# 方正金工

## Overview / 概述

方正证券研究所金融工程研究团队（公众号"金工严选"）。首席分析师严佳炜，核心成员包括朱定豪（Smart Beta、量价因子）、宋家骥（FOF 选基、大类资产配置）、邱捷铭（因子选股、行业轮动、AI 研究）。该团队在 Smart Beta 价值指数、大小盘风格轮动和基金研究领域有深度报告。核心创新包括[[龙虎榜指标]]（基于交易所数据的资金面择时信号）、多维度[[风格择时]]框架和[[vcvar因子]]（基于CVaR的日内尾部风险因子）。

## Key Facts / 关键事实

- 所属机构：方正证券（Founder Securities）
- 核心研究员：严佳炜（首席）、朱定豪、宋家骥、邱捷铭
- 研究领域：Smart Beta、价值指数、基金研究、因子选股、行业风格轮动、择时、市场微观结构、基本面量化
- 公众号：金工严选
- 研究时间线：
  - 2019.10：《价值指数投资在A股的实践》（朱定豪、严佳炜）
  - 2019.11：《多维度解析大小盘风格轮动》（严佳炜、邱捷铭）——提出龙虎榜指标、三维风格择时框架
  - 2019.12：《资产配置研究系列之一：通过风险平价与Black-Litterman打造稳定收益组合》（宋家骥、严佳炜）——RPBL融合策略
  - 2020.02：《市场微观结构剖析系列之一：分钟线的尾部特征》（邱捷铭、严佳炜）——VCVaR因子
  - 2020.02：《市场微观结构剖析系列之六：量价关系的高频乐章》（朱定豪、严佳炜）——COPA/CORA高频量价因子
  - 2020.04：《主观观点如何融入量化因子模型》（严佳炜）——B-L模型用于因子权重优化，基本面量化方向
