# 杨冰

## Overview / 概述

杨冰是[[中金固收]]（中金公司固定收益研究团队）的核心分析员，SAC执业证书编号S0080515120002。他是中金固收转债研究系列报告的主要作者之一，参与撰写了从[[可转债定价|转债定价]]、[[回测|策略回测]]、[[转债因子模型|因子模型]]到[[转债技术分析|技术分析]]、[[基金业绩归因|基金归因]]等方向的多篇深度报告，所有报告均附带完整的Python实现代码。

## Key Facts / 关键事实

- 所属机构：中金公司固定收益研究团队
- SAC执业证书：S0080515120002
- 研究领域：可转债定价、策略回测、因子选券、技术分析、基金归因
- 研究特色：注重模型实战化，所有报告附带Python代码
- 合作者：姬江帆、房铎、吴若磊、陈健恒

- [[相对换手率因子]] — 衡量近期换手率相对历史水平高低的技术指标，本文发现其在2023年具有显著的相对回报预测能力。
- [[转债退市风险]] — 指可转债因正股触发交易所退市规则（如股价低于1元、市值低于3亿元或财务指标不达标）而面临终止上市的风险。
- [[随机森林]] — 一种基于决策树的集成机器学习算法，通过构建多个决策树并输出类别或回归均值来提高预测准确率，文中用于预测转债财务退市风险。
- [[波动率预测模型]] — 利用历史波动率、换手率、市值及机构持股数量等特征，通过机器学习算法（如XGBoost或神经网络）预测正股未来波动率，以筛选高弹性转债的量化模型。
- [[百元溢价率]] — 衡量转债估值水平的核心指标，中金固收研究指出当该指标达到27%时，转债市场往往面临回调压力和亏损风险。
- [[月历效应]] — 指金融资产（如可转债）的收益率或特定策略的超额收益在特定月份或时间段内呈现规律性异常的现象。
- [[基本面择优策略]] — 一种通过筛选市场预期较好且当前经营效力（如EPS）较高的资产以获取超额收益的量化投资策略。
- [[easyball-plus策略]] — 结合EasyBall低估值粗选与正股动量因子的可转债进阶策略，旨在实现攻防一体的收益表现。
- [[希腊字母策略]] — 基于Black-Scholes定价模型和希腊字母，通过拆解转债驱动力并引入预测变量（如XGBoost预测波动率）进行定量择券的可转债策略框架。
- [[转债择时体系]] — 针对可转债市场构建的包含估值、情绪、结构等多维度的综合择时指标框架，旨在通过客观可验证的数据体系取代主观直觉判断。
- [[弱势品种表现指标]] — 衡量规模大且溢价率高的转债在短期内债底溢价率提升情况的指标，主要用于捕捉资金推动下的市场过热现象。
- [[转债市场情绪指标]] — 结合换手率（量）与超买比例（价）构建的短期情绪高低点揭示指标，有效期大约为10天至60天。
- [[甜点转债数]] — 基于期权定价视角，通过Delta、Theta、Gamma等希腊字母计算得出的性价比较高、容易获利的转债数量指标。
- [[债性转债债底溢价率偏离]] — 考察平价70元以内的债性转债平均债底溢价率的短期（如21日、55日）偏离率，用于寻找市场调整带来的错杀机会。
- [[决策树择时模型]] — 在转债整体择时中，为保持模型可读性而采用的浅层决策树模型，用于混合多个估值与情绪指标并生成可解释的交易规则。
- [[真实收益率]] — 一种将债性转债的到期收益率（YTM）与基于BS模型测算的转股预期收益相结合的综合性收益率指标，用于衡量低价转债的真实投资价值。
- [[转债波粒二象性]] — 借用物理学概念，指可转债在到期或转股前处于股债“混合态”，其溢价（时间价值）在面临确定性假设时会“坍缩”的特性。
- [[甜点转债]] — 指同时具备较低下行风险和较高向上弹性，处于风险收益比较好区间的可转债品种。
- [[下修意愿预测模型]] — 基于剩余期限、现金覆盖比、正股资质及重算间隔等特征，量化预测可转债发行人执行下修条款概率的统计分析框架。
- [[固收-测算框架]] — 一种将择券策略与资产配置策略分离，并引入交易成本与流动性规模约束的多资产（股、债、转债）组合回测模型。
- [[固收-择时与择券]] — 在固收+组合管理中，资产配置层面的择时（如股债配比调整）对组合业绩的贡献和重要性通常高于单一资产内部的择券。
- [[顶底分型]] — 技术分析中用于识别趋势转折点的基本K线形态，由三根K线组成，分为顶分型（高点最高）和底分型（低点最低）。
- [[模型微调]] — 在预训练模型的基础上，固定大部分网络参数，仅对小部分参数进行重新训练，以适应新数据并防止过拟合的技术。
- [[nelson-siegel模型]] — 一种用于拟合和预测利率期限结构的静态参数模型，通过水平、斜率和曲率三个因子及衰减参数来刻画收益率曲线的形状。
- [[收益率曲线预测]] — 利用统计模型或机器学习方法对未来不同期限债券的收益率分布及形态进行预测，是固收量化交易的核心环节。
- [[久期择时策略]] — 一种根据对收益率曲线变动的预测，动态调整债券投资组合久期以获取超额收益或控制回撤的交易策略。
- [[红利固收]] — 将红利资产视为长久期债券，结合利率预测模型动态调整股债权重的固收增强策略。
- [[大语言模型应用场景]] — 探讨大语言模型（包括非推理模型与推理模型）在金融研究特别是转债领域的具体应用场景、局限性及优势。
- [[ai辅助复盘]] — 利用大语言模型（LLM）结合结构化提示词，对可转债市场的整体走势、结构分化及异动个券进行快速总结与逻辑提炼的复盘方法。
- [[agent持有率择时策略]] — 一种通过遍历全市场可转债个券的强化学习Agent状态，统计处于“买入”或“持有”状态的品种比例，并以此比例作为整体组合仓位的自下而上量化择时策略。
- [[转债个券强化学习模型]] — 将强化学习算法应用于单支可转债的择时与交易决策模型，通过设置较高的交易成本和随机探索机制，解决个券交易中的局部最优和泛化难题。
- [[划线基金]] — 指净值曲线相对单调向上、持续具备赚钱能力，给投资者带来良好视觉持有体验的基金产品。
- [[修正后欧氏距离]] — 一种衡量基金净值曲线与货币基金指数相似度的量化指标，对向下偏离给予更高惩罚，用于识别低波稳健型基金。
- [[资产间网络系统]] — 将多维市场特征通过KNN算法转化为资产间相关性网络，利用中心性指标进行行业轮动和资产配置的分析系统。
- [[枢纽中心性]] — 网络分析中衡量某一节点在所有节点对最短路径上出现频次的指标，用于识别资金跨板块流动的必经之路。
- [[网络累计影响力]] — 基于PageRank算法计算的网络节点重要性指标，用于度量单一板块在资产网络中的累积影响力。
- [[转债量化研究体系]] — 中金固收团队总结的转债量化建模方法论，涵盖期权定价基础、样本量与复杂度平衡、可解释性要求及机构实践难点。
- [[ai交易模拟]] — 利用大语言模型（LLM）作为决策引擎，通过自然语言处理市场数据并输出交易指令的自动化回测与交易框架。
