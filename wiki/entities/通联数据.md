# 通联数据

## Overview / 概述

国内金融[[另类数据]]服务商，提供基于NLP[[文本情感分析]]技术的分析师研报情感数据和上市公司招聘数据产品。首席量化工程师[[李立]]领导的另类数据团队，专注于从非结构化数据中提取可交易信号。研报情感数据为独家数据源，招聘数据来源于主流招聘网站。

## Key Facts / 关键事实

- 金融另类数据服务商
- 研报情感数据为独家数据源
- 上市公司招聘数据来源于主流招聘网站，覆盖沪深300超80%
- 另类数据团队由[[李立]]总负责
- 情感识别模型采用四分类（负面/中性/一般正面/强烈正面）
- 仅使用公司报告作为数据源（信息更丰富、用词更精确）
- 数据形式：段落级情感得分 + 研报综合情感得分
- 标注原则：人工标注，不使用行情数据
