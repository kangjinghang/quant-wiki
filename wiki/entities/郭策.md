# 郭策

## Overview / 概述

郭策是[[中银量化]]团队首席分析师。研究覆盖多因子风险模型（[[Barra-CNE5模型]]）、[[规模效应]]、[[股权集中度]]、[[行业轮动]]方法论、量化与主观思考等方向。方法论思考深入，擅长从底层逻辑角度构建研究框架。

## Key Contributions / 主要贡献

- **Barra CNE5深度解读**：上下两篇报告，揭示2013年后解释力衰减根因为个股离散度Rho
- **规模效应+股权集中度**：沪深300内双因子增强策略，超额年化15.3%
- **行业轮动方法论**：提出"以配置理念做行业轮动"，[[多策略配置]]优于[[多策略轮动]]
- **盈利预期行业轮动**：基于分析师一致预期构建行业轮动策略，远期预期（F3）信息含量最高，样本外年化超额11.9%
- **量化vs主观思考**：引入因果推断理论（[[朱迪亚-珀尔]]的do算子），揭示量化模型局限性
