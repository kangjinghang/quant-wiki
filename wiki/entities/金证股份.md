# 金证股份

## Overview / 概述

国内领先金融IT企业，伴随中国证券市场近30年发展（从红马甲到电子化交易）。与恒生电子共同推动了中国证券市场电子化交易进程。在证券交易系统领域占据主导地位，承担A股50%交易量的系统建设，双A券商市占率超60%，公募基金等大资管领域市占率约30%。子公司[[丽海弘金]]专注量化交易金融科技。

## Key Facts / 关键事实

- **市场地位**：A股50%交易量系统、双A券商市占率60%+、大资管市占率30%
- **子公司**：[[丽海弘金]]（量化交易金融科技）、金智维（RPA流程自动化）
- **发展历程**：从人工报单→电话委托→小键盘→热自助→电子化交易
- **竞争对手**：恒生电子
