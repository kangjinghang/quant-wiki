# 高鹏

## Overview / 概述

开源证券金融工程团队分析师，研究方向为基金研究与因子模型。作为[[开源金工]]团队核心成员，高鹏参与了多个重要研究项目，包括[[聪明钱因子]]2.0版本参数优化、[[理想振幅因子]]研究、[[估值变动因子]]dEP、[[a股反转之力的微观来源]]等。在[[如何构建金股组合开源金工]]中担任报告联系人。

- [[不换手机构专用]] — 指在龙虎榜上呈现单向交易（只买入或只卖出）的机构专用席位，能代表真实机构动向，其行为信息含量和事件收益相对更高。

- [[大宗交易折溢价因子]] — 基于大宗交易成交价相对收盘价的折溢价水平构建的因子，在机构专用买入样本中，低折溢价组具有显著的正向超额收益。
- [[机构关注度]] — 使用近期调研数量和机构持仓占比来衡量个股受机构关注的程度，关注度低的个股在被调研或机构介入后往往蕴含更高的alpha。
- [[机构行为事件组合]] — 基于龙虎榜、机构调研、大宗交易等多头机构行为事件构建的组合，全区间年化收益率达30.9%，表现优于宽基指数。
- [[雪球大v用户]] — 指在雪球股票投资交流平台上粉丝数量超过500的活跃用户，其投资观点和行为具有较高信息含量。
- [[自选股事件收益]] — 指投资者将某只股票加入自选股后，该股票在未来一段时间内（如60个交易日）产生的超额收益。
- [[模拟组合事件收益]] — 指雪球用户在模拟组合中进行买入或增仓操作后，相关个股在未来一段时间内产生的超额收益。
- [[大v用户五维评价体系]] — 开源金工构建的用于评估雪球大V用户投资能力的五个维度：收益能力、收益稳定性、交易能力、黑马能力、白马能力。
- [[自选股绩效优选组合]] — 基于大V用户历史自选股超额收益波动比进行筛选，构建的具有显著超额收益的事件驱动选股组合。
- [[分钟理想振幅因子]] — 将过去N天的1分钟交易数据合并，按分钟收盘价高低切割后相减得到的反映高频价格博弈的因子。
- [[日内振幅切割因子]] — 对每日1分钟交易信息按情绪指标进行日内切割，合成日度序列后构建的反映日内微观结构的因子。
- [[高频振幅合成因子]] — 将分钟理想振幅因子与日内振幅切割因子等权合成得到的综合选股因子，具有优异的预测能力和样本外表现。
- [[分钟资金流切割残差因子]] — 利用分钟价格、涨跌幅或振幅等指标对分钟资金流进行切割后提取残差构建的选股因子，其中基于50%较高振幅切割的方案效果最优。
- [[分钟资金流时段残差因子]] — 通过筛选日内特定交易时段（如前半小时）的分钟资金流信息构建的选股因子，利用了不同类型投资者对日内交易时段偏好的差异。
- [[分钟资金流情景残差因子]] — 根据市场整体情景状态（如5min涨跌幅）筛选特定交易时刻的分钟资金流构建的选股因子，在三类分钟资金流因子中表现最优。
