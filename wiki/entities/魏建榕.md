# 魏建榕

## Overview / 概述

开源证券金融工程团队首席分析师，复旦大学理论物理学博士，专注量化投资研究近10年。历任东方证券研究员、上投摩根基金研究员、方正证券高级分析师、东吴证券联席首席分析师。在实证行为金融学、市场微观结构研究等领域取得多项独创性成果，在国际学术期刊发表论文7篇。2016年获新财富最佳分析师第6名、金牛分析师第5名、水晶球分析师第6名、第一财经最佳分析师第5名。

## Key Facts / 关键事实

- 复旦大学理论物理学博士
- 执业证书编号：S0790519120001
- 代表研报：《蜘蛛网CTA策略》系列、《高频选股因子》系列、《[[因子切割论]]》系列
- 2016年新财富最佳分析师第6名
- 国际学术期刊发表论文7篇

- [[自选股绩效优选组合]] — 基于大V用户历史自选股超额收益波动比进行筛选，构建的具有显著超额收益的事件驱动选股组合。
- [[久期择时策略]] — 基于利率债预期收益框架，动态选择预期收益最高的期限品种持有，以获取超额收益并应用于资产配置增强的策略。
- [[nelson-siegel模型]] — 一种经典的收益率曲线拟合模型，通过水平、斜率和曲率三个参数因子来刻画截面上的期限结构，具有参数少、解释性强的优点。
- [[水平因子]] — Nelson-Siegel模型中的核心参数之一，代表收益率曲线的水平位置，经济含义上等同于长债收益率，其预测精度是决定长端利率预测效果的关键瓶颈。
- [[滚动lars回归]] — 一种使用最小角回归（LARS）算法进行滚动变量选择的方法，用于从众多宏观变量中筛选出对目标变量具有稳定预测效果的变量组合。
- [[动态中枢均值回复]] — 一种假设金融时间序列围绕动态变化的政策利率中枢进行均值回复的预测方法，常用于改进长端利率预测模型。
- [[涨跌停效应]] — A股涨跌停限价机制导致涨停或跌停股票受到市场额外关注，对其自身及同行业股票后续走势产生显著负向alpha的现象。
- [[nl因子]] — 基于涨跌停效应构建的行业反转因子，通过回归剔除非涨跌停股票的动量影响，具有高显著性和稳定性。
- [[r-limit因子]] — 行业内涨跌停股票在过去一段时间的平均涨跌幅，表现为显著的行业反转因子。
- [[r-nolimit因子]] — 行业内非涨跌停股票在过去一段时间的平均涨跌幅，表现为弱动量效应。
- [[dl因子]] — 由ND动量因子与NL反转因子合成的复合因子，兼具两者的优点，在不同市场环境下表现优异。
- [[行业反转]] — 行业过去一段时间表现越差，未来相对表现越好的现象，近年来在A股行业轮动中逐渐显著。
- [[kyfactor特色因子体系]] — 开源金工团队构建的涵盖交易行为、资金流、基本面和关联网络四个维度的特色因子库，包含18个细分因子。
- [[均线收敛与发散]] — 通过计算不同周期均线在截面的标准差来衡量均线形态的聚集或分离程度，用于预测个股未来的收益方向。
- [[换手率收敛因子]] — 衡量不同周期换手率均线收敛程度的因子，表现优于单纯的价格或成交量收敛因子，具有显著的收益预测能力。
- [[价格收敛因子]] — 衡量不同周期价格均线收敛程度的因子，主要作为股价变盘点的前兆信号，但单独使用的收益预测能力较弱。
- [[成交量收敛因子]] — 衡量不同周期成交量均线收敛程度的因子，用于锚定股价位置高低，低位缩量个股未来上涨概率显著较高。
- [[价量双收敛因子]] — 结合价格收敛因子与成交量收敛因子的复合因子，用于挖掘处于阶段低位且面临变盘的个股。
- [[成交额收敛因子]] — 衡量不同周期成交额均线收敛程度的因子，直接囊括价量信息，效果优于手工合成的价量双收敛因子。
- [[涨跌停情绪外溢]] — 指股票A触及涨停板导致买入受限时，投资者寻找关联股票进行交易，进而导致关联股票随后出现价格上涨的现象。
- [[traction-lud因子]] — 基于涨跌停外溢关联网络构建的牵引因子，通过将反转基准从全市场缩小至高关联股票，刻画局域反转逻辑下的补涨空间。
- [[局域反转逻辑]] — 相对于以全市场为基准的传统反转逻辑，局域反转以高关联股票的涨跌幅为基准判断个股的超涨超跌，更精准地刻画补涨空间。
- [[百元转股溢价率]] — 一种通过反比例回归法将不同平价的转股溢价率标准化至平价为100元时的溢价率指标，用于在时序上比较转债整体估值水平。
- [[转债综合估值因子]] — 融合转股溢价率偏离度与蒙特卡洛模拟理论价值偏离度的复合因子，用于筛选低估值的可转债以进行增强配置。
- [[转债风格轮动]] — 基于市场情绪指标（动量与波动率偏离度），在偏股、平衡、偏债转债低估风格指数之间进行动态轮动配置的策略。
- [[修正ytm]] — 剥离了转债内含期权价值及条款影响后的到期收益率，使其与普通信用债的YTM具备直接可比性。
- [[etf资金流因子]] — 衡量ETF在个股或行业层面资金流入流出情况的指标，主要包括持仓占比变动与资金流入/市值两类，具有显著的负向收益预测能力。
- [[行业轮动3-0模型]] — 开源金工提出的基于“一级行业+双周频率”，融合交易行为、景气度、资金流、筹码结构、宏观驱动和技术分析六个维度，并采用动态最小化排名跟踪误差方法合成信号的综合行业轮动体系。
- [[筹码结构模型]] — 通过假设每日存量持仓按换手率均匀换仓来估算市场筹码分布，结合行为金融学中的前景理论和处置效应，利用市场赚钱效应构建持仓收益与阻力支撑因子的行业轮动模型。
- [[etf轮动框架]] — 一种将行业轮动信号落地为ETF产品投资的实战框架，遵循“行业选择（轮动信号）-指数选择（高弹性）-产品选择（高流动性）”的三步流程。
- [[动态合成模型]] — 采用最小化排名跟踪误差方法，动态优化多个子模型权重的信号合成技术，能够自适应地调整失效模型和主导模型的权重分配。
- [[筹码结构]] — 对投资者在不同价格上的资金持仓分布的估计，用于推算市场的平均持仓成本和买卖力量博弈状态。
- [[市场赚钱效应]] — 全市场股票的筹码收益因子加权均值，用于衡量市场整体盈亏状态及风险偏好。
- [[筹码收益调整因子]] — 利用市场赚钱效应指标对筹码收益因子的动量与反转特征进行动态调节而构建的选股因子。
- [[筹码收益增强因子]] — 将筹码收益调整因子的多头端与反转因子的空头端结合构建的复合选股因子，兼具两者优势。
- [[量峰量岭量谷]] — 一种基于日内分钟成交量局域分布特征的状态划分框架，将成交量划分为量峰（孤立喷发）、量岭（连续喷发）和量谷（温和成交量），用以刻画不同投资者的交易行为。
- [[量峰分钟数因子]] — 统计过去20日量峰发生的分钟数，衡量日内知情交易参与频率的高频因子，因子值越高代表知情交易参与度越高。
- [[量谷相对加权价格因子]] — 计算每日量谷成交量加权价格与当日总成交量加权价格的比值，反映交易低迷时点价格相对水平的高频因子。
- [[量峰间隔峰度因子]] — 计算过去20日同日前后两个量峰之间时间间隔分布的峰度，反映知情交易节奏的高频因子。
- [[喷发成交额跟随比例因子]] — 计算喷发成交时点下一分钟总成交额与喷发成交时点总成交额的比值，衡量大额成交后资金跟随程度的高频因子。
- [[dbd-gru模型]] — 结合因子切割论与GRU神经网络的双分支差异网络模型，用于提取切割后变量的差异化深度特征。
- [[分钟理想振幅因子]] — 将过去N天的1分钟交易数据合并，按分钟收盘价高低切割后相减得到的反映高频价格博弈的因子。
- [[日内振幅切割因子]] — 对每日1分钟交易信息按情绪指标进行日内切割，合成日度序列后构建的反映日内微观结构的因子。
- [[高频振幅合成因子]] — 将分钟理想振幅因子与日内振幅切割因子等权合成得到的综合选股因子，具有优异的预测能力和样本外表现。
- [[虚拟指数]] — 通过拟合指数增强型基金持仓重构成分股权重而形成的官方指数替换版本，具有分布近似和低集中度特征。
- [[基金持仓复制]] — 通过拟合基金季报持仓及高频收益率数据，还原基金真实持仓权重的方法论。
- [[ccass数据]] — 香港交易所中央结算及交收系统提供的个股托管明细数据，可近乎无损还原南下资金指标并估算各经纪商的资金流向与持仓分布。
- [[绩优经纪商优选策略]] — 一种基于历史表现筛选出优秀经纪商，并复制其持仓构建股票组合的量化投资策略。
- [[分钟资金流切割残差因子]] — 利用分钟价格、涨跌幅或振幅等指标对分钟资金流进行切割后提取残差构建的选股因子，其中基于50%较高振幅切割的方案效果最优。
- [[分钟资金流时段残差因子]] — 通过筛选日内特定交易时段（如前半小时）的分钟资金流信息构建的选股因子，利用了不同类型投资者对日内交易时段偏好的差异。
- [[分钟资金流情景残差因子]] — 根据市场整体情景状态（如5min涨跌幅）筛选特定交易时刻的分钟资金流构建的选股因子，在三类分钟资金流因子中表现最优。
- [[股商联动]] — 指商品价格与股票价格之间的联动关系，其机制因企业在产业链中所处位置（上游、中游、下游）的不同而存在显著差异。
- [[商品弹性]] — 衡量股票价格对商品价格变动敏感度的指标，通过回归模型中商品收益率的系数来计算。
- [[商品解释度]] — 指商品价格波动因素对股票价格涨跌的解释比例，反映商品因素在股价驱动中的重要性。
- [[产业链多空组合]] — 基于股商联动机制，将产业链上游股票构建为商品多头组合，下游股票构建为商品空头组合，并结合商品择时信号进行轮动的策略。
- [[多铜策略]] — 通过筛选商品弹性为正的铜矿企业构建多头组合，并使用TCRC等择时指标进行买卖的策略。
- [[空铜策略]] — 通过筛选商品弹性为负的电缆企业构建组合，并在TCRC指标暗示铜价下跌时买入的策略。
- [[多铝策略]] — 通过筛选商品弹性为正的电解铝企业构建多头组合，并使用制造业PMI等指标进行择时的策略。
- [[多黄金策略]] — 通过筛选商品弹性为正的黄金开采企业构建多头组合，并使用黄金预期收益因子进行择时的策略。
- [[多原油策略]] — 通过筛选原油开采企业构建多头组合，并使用裂解利润和布油价格信号进行择时的策略。
- [[空原油策略]] — 通过筛选涤纶、改性塑料等下游化工企业构建组合，并在原油相关商品价格低位时买入的策略。
- [[空金属策略]] — 利用家电和汽车行业指数构建的组合，在铜、钢等金属价格处于低位时买入，以获取成本红利。
