# A股反转之力的微观来源

## Abstract / 摘要

[[开源金工]]魏建榕团队在2018年提出[[反转因子]]的W式切割方法后，于2019年12月进一步深入微观机制。通过用分位数替代平均值作为切割标准，发现切割标准越高（即越关注大单成交区），W式切割效果越好。结合假想实验，得出核心结论：**反转之力的微观来源是大单成交**。基于此提出的高阶方案（13/16分位切割）多空IR 2.00，且成功规避了2019年2月传统反转因子的大幅回撤。

## Key Facts / 关键事实

- **核心结论**：反转之力的微观来源是大单成交，而非小单成交
- A股逐笔成交金额呈畸形金字塔：中位数0.8万元，80%分位2.4万元，10万元以上凤毛麟角
- 分位数越高作为W式切割标准，$M_{high}$与$M_{low}$之间的IC差距越大（"喇叭口"效应）
- 小单成交贡献动量效应（IC>0），大单成交贡献反转效应（IC<0）
- **理想反转因子**（均值切割）：IR 2.51，月度胜率74%
- **新因子$M_{high}^{13/16}$**：IR 2.00，月度胜率72%，IC -0.070，rankIC -0.087
- 新因子成功规避了2019年2月传统反转因子的大幅回撤

## Methodology / 方法论

### W式切割

1. 对每只股票取过去20日数据
2. 计算每日平均单笔成交金额（成交金额/成交笔数）
3. 按单笔成交金额高低分为两组各10日，$M_{high}$和$M_{low}$
4. 理想反转因子 $M = M_{high} - M_{low}$

### 分位数改进

用第$q$分位数替代均值作为切割标准，测试$q = 1/16, 2/16, \ldots, 15/16$。结果呈"喇叭口"：$q$越高，$M_{high}$反转特性越强，$M_{low}$反转特性越弱甚至转为动量。

### 假想实验

假设每日成交金额分布相同，新增一笔成交观察其对IC的贡献。随着新增成交金额从小到大，贡献从微弱动量迅速变为强反转。
