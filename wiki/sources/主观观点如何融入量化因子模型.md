# 主观观点如何融入量化因子模型

## Abstract / 摘要

[[方正金工]]团队（严佳炜）于2020年4月发布本文，探索[[基本面量化]]方向，核心创新在于将[[black-litterman模型]]从传统的资产配置领域移植到多因子选股框架中。报告将因子IC（Information Coefficient）类比为资产收益，将因子IC的协方差矩阵类比为资产风险，通过B-L模型融合由[[风险平价]]确定的先验权重与主观观点（[[因子动量]]、估值、个人判断），最终将6因子组合的夏普比从1.96（等权基准）提升至2.28。回测区间为2007–2019年，基准指数为中证500，并在沪深300和全A股中验证了有效性。

## Key Facts / 关键事实

- **研究团队**：方正金工·严佳炜，2020年4月
- **核心创新**：将[[black-litterman模型]]从资产配置领域移植到因子权重优化领域，构建"因子IC = 资产收益，因子IC协方差 = 资产风险"的类比框架
- **回测设定**：2007–2019年，中证500成分股，6个因子（波动、换手、质量、价值、成长、动量）
- **先验权重**：使用[[风险平价]]确定，相比等权先验年化收益提升约0.5%
- **最终表现**：B-L优化后因子组合夏普比从1.96提升至2.28
- **跨市场验证**：在沪深300和全A股同样有效
- **收益特征**：部分年度小幅跑输等权基准，部分年度大幅跑赢

## Methodology / 方法论

### B-L模型在因子框架中的应用

[[black-litterman模型]]最初由Black和Litterman于1992年提出，用于资产配置中的组合权重优化。本报告的核心创新在于将该模型移植到因子权重确定环节。类比关系如下：

| 资产配置领域 | 因子权重领域 |
|---|---|
| 资产收益 | 因子IC（截面相关系数） |
| 资产收益协方差矩阵 | 因子IC协方差矩阵 |
| 市场均衡权重 | [[风险平价]]确定的先验权重 |
| 投资者主观观点 | 因子动量、估值、个人判断 |

B-L模型的后验权重公式：

$$w_{BL} = [(τΣ)^{-1} + P'Ω^{-1}P]^{-1}[(τΣ)^{-1}w_{eq} + P'Ω^{-1}Q]$$

其中 $w_{eq}$ 为先验权重（[[风险平价]]），$Σ$ 为因子IC协方差矩阵，$Q$ 为主观观点向量，$P$ 为观点矩阵，$Ω$ 为观点不确定性矩阵，$τ$ 为缩放参数。

### 先验权重：风险平价

报告比较了等权先验与[[风险平价]]先验两种方案。等权先验假设各因子对组合的贡献相同，忽略了因子IC波动率的显著差异（如波动因子IC标准差较大，质量因子IC标准差较小）。[[风险平价]]根据各因子IC的波动率倒数分配权重，使每个因子对组合风险的贡献相等。

实证结果显示，使用[[风险平价]]作为先验相比等权先验，年化收益提升约0.5%，且收益分布更加均衡。这一改进使得先验权重本身已经是一个较优的起点，为后续主观观点的融入提供了更稳健的基准。

### 主观观点的构建

#### 因子动量观点

因子动量（Factor Momentum）观点基于各因子过去12个月的IC均值构建。直觉上，近期IC表现好的因子在未来一段时间内可能继续表现优异。然而，因子动量虽然有效，但波动较大——直接使用未加约束的动量信号可能导致极端权重分配。

报告采用约束处理：将动量观点限制在等权权重 $\pm 4\%$ 的范围内。加入动量观点后，组合IC提升至9.68%，IR达到2.5，夏普比从1.96提升至2.17。这表明[[因子动量]]是有效的观点来源，但需要合理约束以控制波动。

#### 因子估值观点

因子估值（Factor Valuation）观点通过计算因子多头组的BP值（Book-to-Price），并进行z-score标准化来构建。当某一因子多头组合的BP值较低（即估值偏高）时，可以认为该因子当前较"贵"，未来收益可能下降。

实证中，估值观点同样有效，但信号强度弱于动量观点。估值观点更适合作为辅助信号，与动量观点形成互补。

#### 个人主观观点

个人主观观点是投资经理基于宏观环境、市场判断形成的定性观点。报告中给出的典型案例是2016–2018年的去杠杆时期：

- **看空质量和成长因子**：去杠杆环境下，高杠杆企业承压，质量因子（偏好低杠杆、高ROE企业）和成长因子面临逆风
- **看多价值因子**：去杠杆环境下，低估值的价值股更具防御属性

加入个人主观观点后，B-L模型进一步增强了组合表现。这体现了[[基本面量化]]的核心理念——发挥投资经理的主观能动性，将判断融入量化模型。
