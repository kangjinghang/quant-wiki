# 交易者行为与市值风格

## Abstract / 摘要

本文从市场微观结构视角出发，系统研究了[[市值因子]]与交易者行为之间的深层关联。研究团队按挂单金额将交易者划分为超大单、大单、中单、小单四类，构建成交占比因子，并通过线性回归提纯方法得到[[evl因子]]。核心发现包括：机构偏好大盘股、散户偏好小盘股；成交额因子在剔除市值影响后仍显著，反之则不成立；小单成交额因子（年化多空14.67%，ICIR -1.90）表明散户过度涌入的股票后续收益显著下降。

## Key Facts / 关键事实

- **研究团队**: [[开源金工]]魏建榕（首席）、傅开波、高鹏、苏俊豪（联系人）、胡亮勇
- **发布时间**: 2020年5月12日
- **回测区间**: 2008-2020年，全A股票池
- **核心因子**: [[evl因子]]（年化多空18.66%，ICIR 1.85，市值中性化后ICIR 2.39）、小单成交额因子（年化多空14.67%，ICIR -1.90）
- **核心结论**: 小单交易者过度涌入的股票，过后更容易下跌

## Methodology / 方法论

### 交易者分类与成交占比因子

按照挂单金额对每笔成交进行分类：

| 类型 | 挂单金额范围 | 代表含义 |
|------|-------------|---------|
| 超大单（exlarge） | >100万元 | 机构/大资金 |
| 大单（large） | 20万-100万元 | 中大型机构 |
| 中单（median） | 4万-20万元 | 中等投资者 |
| 小单（small） | <4万元 | 散户 |

对每只股票取过去20个交易日，计算各类成交额之和并除以总成交额，得到四类成交占比因子（exlarge ratio、large ratio、median ratio、small ratio）。

### 成交占比因子与市值的关系

成交占比因子与对数市值高度相关：市值越小，超大单与大单占比越低，中单与小单占比越高。这与机构偏好流动性好的大盘股、散户偏好小盘股的直觉一致。当小市值风格占优时，大单以上成交占比与市值的相关性下降，说明此时小市值股票中大单和超大单的占比相对提升。

### EVL因子提纯方法

各成交占比因子之间存在较强相关性，直接做市值中性化后效果不佳。研究团队采用回归残差法进行提纯：

1. 在时刻 $t$，记超大单占比因子值为 $y_t$，大单占比因子值为 $x_t$
2. 做线性回归：$y_t = a \cdot x_t + b + \varepsilon_t$
3. 取残差 $\varepsilon_t$ 作为新因子，即[[evl因子]]

同理，分别从超大单占比中剔除中单占比、小单占比，得到EVM因子和EVS因子。三个因子均有效，其中EVL因子表现最优。

### 成交额因子与分类成交额

成交额因子本身比市值因子收益更高，且在剔除市值因子后仍有显著收益（反之，市值因子剔除成交额后不显著）。将成交占比因子与成交额因子相乘，得到分类成交额因子：超大单成交额、大单成交额、中单成交额、小单成交额。其中小单成交额因子市值中性化后年化多空收益14.67%，ICIR -1.90，表现最佳。

## Key Findings / 核心发现

### 发现一：市值风格转向伴随资金流动

[[市值因子]]与成交额强相关。市值风格转向时，资金在大盘股与小盘股间流动，导致相关程度变化：小市值占优时，市值与成交额的相关系数下降（小市值吸引资金流入，推高其成交额）；大市值占优时，相关性走高。

### 发现二：机构交易大盘股、散户交易小盘股

成交占比因子与市值高度相关：市值越小，超大单与大单占比越低，中单与小单占比越高。机构投资者倾向于交易流动性好的大盘股，散户更热衷于小盘股。

### 发现三：EVL因子具有稳健alpha

[[evl因子]]年化多空收益18.66%，ICIR 1.85。市值中性化后多空年化收益11.44%，ICIR提升至2.39，最大回撤仅6.09%。这说明超大单相对大单的"异常"活跃程度包含了独立于市值的有效信息。

### 发现四：小单过度涌入预示下跌

小单成交额因子（ICIR -1.90）表明：同等市值条件下，小单成交额越高（散户越活跃），后续收益越低。从交易角度解读：散户过度涌入的股票，前期被过度关注炒作，未来预期收益走低。
