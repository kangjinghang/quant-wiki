# 低价股溢价效应解析

## Abstract / 摘要

[[招商定量]]任瞳、崔浩瀚在2019年12月发布市场异象系列首篇报告，系统研究A股[[低价股溢价效应]]的三大成因假设。利用素镜科技财务诚信数据验证后发现：低估值能解释部分溢价（$R^2 < 0.1$），低质量成因不成立（高财务风险反而带来负收益），而个人投资者的[[名义价格幻觉]]是重要驱动因素。剔除机构持股和分析师覆盖后的低价股组合超额收益最显著。

## Key Facts / 关键事实

- 申万低价股指数2010-2019年跑赢中价股和高价股指数
- **低估值验证**：行业中性化PB对股价有显著正解释力，但$R^2$从未超过0.1
- **低质量验证**：2016Q3后低质量与低价格显著负相关（$t < -4$），但高财务风险带来负收益而非正溢价
- **高风险组多空收益33.70%**，低风险组多空收益-10.15%——高风险低价股溢价更强
- 个人投资者参与度越高，低价股溢价效应越明显（罗进辉等2017）
- 机构投资者参与和分析师覆盖可缓解溢价效应
- 百度指数显示"低价股"搜索在2015牛市和2019春牛期间井喷

## Strategy Tests / 策略回测

5个低价股组合（2010.1-2019.10，月频调仓，对冲中证800）：

| 组合 | 特点 | 超额收益 |
|------|------|----------|
| 纯低价股 | 收盘价最低10% | 明显，但波动过大 |
| 剔除机构高持股 | +剔除机构持股较高的一半 | 略有提升 |
| 剔除分析师覆盖 | +剔除近2月有盈利预测的 | 提升较显著 |
| **综合考虑** | **同时剔除机构+分析师** | **最显著** |
| 中证800成分股 | 池子限定中证800 | 显著下降 |

核心结论：低价股溢价主要来自个人投资者行为，剔除专业投资者覆盖后效应最强。

## Evidence / 原文证据摘录

> "低估值对于低价格的解释能力是显著的，但是它能解释的部分却很有限，R2一直没有超过0.1。"

> "高财务风险并没有带来高收益，在回测区间的大部分时间中，高财务风险会对收益有显著的负向解释能力。"

> "个人投资者参与度越高，个股的低价股溢价效应越明显；而机构投资者的参与和分析师的关注可以减轻低价股的溢价效应。"
