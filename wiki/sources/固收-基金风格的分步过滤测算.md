# 固收+基金风格的分步过滤测算

## Abstract / 摘要

[[中金固收]]（杨冰、姬江帆）2021年3月报告，提出[[分步过滤测算模型]]解决[[固收-基金]]风格测算中的多重共线性问题。该方法先通过一元线性回归确定拟合优度最高的[[主风格指数]]，再对其他指数进行残差提纯，最后进行带约束的多元回归以测算真实风格分布。实证分析了2021年初市场波动下转债基金和固收+产品的风格变化。

## Key Facts / 关键事实

- [[分步过滤测算模型]]解决基金收益分解中的多重共线性问题，比岭回归、PCA等方法更具稳定性和直观性
- 方法论三步走：一元回归找[[主风格指数]]（最高$R^2$）→ 残差提纯其他指数 → 带约束多元回归（$\beta \geq 0$，总$\beta \leq 140\%$）
- 2021年初市场震荡期间，转债基金整体并未转向双低小票或国证2000代表的小盘股，反而提升了大盘转债占比
- 稳健型固收+基金（二级债基与偏债混基）仓位略有提高，主要加仓在"基金重仓股"上
- 头部大固收+产品倾向于保持原有风格，仅在总仓位上做加减法，未发生明显结构性转向
- 低溢价策略指数因与正股区别较小，其暴露度可直接在股票指数（如基金重仓指数）上反映，无需单独作为变量引入模型

## Method / 方法详解

模型使用7个风格指数作为解释变量：大盘转债、双低转债、低溢价转债、基金重仓股、中证500、国证2000、利率债。[[分步过滤测算模型]]的核心流程：

1. **一元回归**：基金净值回报与每个风格指数逐一做线性回归，选$R^2$最高者为[[主风格指数]]
2. **残差提纯**：其他风格指数对主风格指数回归取残差，消除共线性
3. **带约束多元回归**：以提纯后的指数为自变量，约束系数非负且总和不超过140%（允许20%现金/其他）
