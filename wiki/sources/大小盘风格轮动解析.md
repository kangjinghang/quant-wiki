# 大小盘风格轮动解析

## Abstract / 摘要

[[方正金工]]团队严佳炜、邱捷铭于2019年11月发布本报告，以[[市值因子]]为例，从技术面（动量）、资金面（龙虎榜数据）、基本面（国债期货）三个维度构建[[大小盘风格轮动]]的预判模型。核心创新是提出[[龙虎榜指标]]——通过交易所龙虎榜成交额间接度量游资活跃度，该信号表现出罕见的"左侧"特性，2017年后胜率达77.78%。三个信号等权合并后的综合模型显著改善[[市值因子]]的多空表现。

## Key Facts / 关键事实

- 大小盘风格轮动在A股和美股均长期存在，2017年后A股轮动加速
- 市值因子曾是"最强Alpha因子"，后转为"风险因子"，历史上两次重大回撤（2014年底、2017年）
- **动量策略**：基于市值因子多空净值的低通滤波方向判断，年化36.26%，最大回撤15.41%，收益回撤比2.353
- **龙虎榜策略**：剔除市值前30%后计算龙虎榜成交额/沪深300成交额，年化22.43%，最大回撤11.46%，收益回撤比1.957
- **国债期货策略**：基于5年期国债期货价格趋势，年化30.85%，最大回撤22.85%，收益回撤比1.350
- 三个信号相关性低，等权合并后综合模型效果优于任一单策略
- 龙虎榜策略总胜率65.79%，2017年后胜率77.78%，具备"左侧"预判拐点能力
- 2017年后若看空时反向持有因子，年化收益可增至近2倍

## Methodology / 方法论

报告以[[市值因子]]五分组多空对冲净值为择时标的，三个维度分别构建信号：

1. **技术面（动量）**：月末观察上月市值因子多空净值经低通滤波后的变化方向，参数$d=5$
2. **资金面（龙虎榜）**：龙虎榜成交额（剔除市值前30%的大盘股）/ 沪深300成交额，月末观察指标变化方向，参数$d=30$
3. **基本面（国债期货）**：5年期国债期货当季连续合约价格趋势，参数$d=320$

低通滤波公式：$LP(T) = \alpha \times P(T) + (1-\alpha) \times LP(T-1)$，其中$\alpha = 2/(1+d)$

回测期统一为2013.09.06 - 2019.09.05。

## Key Findings / 关键发现

### 龙虎榜指标的左侧特性

龙虎榜策略信号与绝大部分"右侧"交易信号不同，展现出"左侧"特征——能够在市场风格拐点前发出信号。这解释了其2017年后风格频繁切换环境下仍保持高胜率的原因，也意味着该信号与右侧信号天然互补。

### 2017年前后市场结构变化

2017年前[[市值因子]]月度IC为正的比例极高（接近"永远持有"即可），2017年后风格切换加速，传统动量策略表现下降。龙虎榜策略在这两段时间均保持稳健。

### 综合模型的优势

三个维度信号相关性低（动量vs龙虎榜vs国债期货逻辑独立），简单等权合并即可显著改善表现，验证了"多维度[[风格择时]]"思路的可靠性。

## Evidence / 原文证据摘录

> "若每年仅做一次风格判断，便有可能获得远超基准的收益。若在更高频率上做好轮动，则具有更多的收益机会。"

> "与绝大部分右侧交易信号不同，龙虎榜策略的信号并没有体现出右侧特征，相反其更接近于一个左侧信号。"

> "将动量、龙虎榜、国债期货三个策略简单等权合并，最终的效果明显优于其中任一策略。"
