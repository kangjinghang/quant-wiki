# 如果一定要看偏债

## Abstract / 摘要

[[中金固收]]（杨冰、姬江帆）2021年1月17日发布。报告针对转债市场[[转债破面比例]]接近30%、[[转债破底比例]]达11%的极端环境，系统研究了低价、偏债类转债策略的可行性。基于2010年后118个破面转债（剔除EB）样本统计，51.2%可在1年内站上115元，69.5%可在18个月内站上115元。报告通过机器学习与逻辑验证提炼5大负面排雷特征，并提供完整Python选券代码。

## Key Facts / 关键事实

- **历史统计**：2010年后247个破面品种，剔除EB后2019年前样本118个（35个经历过下修），51.2%在1年内站上115元，69.5%在18个月内站上115元
- **5大负面特征**：（1）5年营收成长率为负（业务难有起色）；（2）正股与股指相关系数<0.4且波动率低；（3）收现比<90%或ROE<5%；（4）低P/B（不利下修博弈）与高股息率（转股价调整机制不利）；（5）溢价率过高
- **注册制新约束**：需额外剔除股价<5元或市值<50亿元的标的，防范[[转债退市风险]]的虹吸效应
- **策略逻辑**：全样本6条规则剔除 → 按价格+债底溢价率综合排序 → 取前N只构建组合
- **市场定位**：2021年1月破面比例处于快速上升期，"可比历史"（2006年、2012-2013年、2018年中）均对应转债年度级别底部

## Strategy Details / 策略细节

排雷规则（6条剔除条件）：

1. 5年营收成长率<0 且 ROE<5% → 过往成长性不佳且盈利能力不足
2. 5年营收成长率<0 且 溢价率>30% → 无成长性且溢价率不低
3. 股价与股指相关系数<0.35 且 收现比<90% → 财务不稳健导致股价与市场脱节
4. P/B<1.1x，股价<5元或市值<50亿元 → 注册制退市风险
5. 大股东质押比例>85% → [[股份质押风险]]
6. 溢价率>50% → 高溢价稳定亏损

筛选后：按价格（升序）+ 债底溢价率（升序）排名之和排序，取前N只。

## Key Insights / 核心洞见

- 终结低价券的契机基本都是**股市的趋势性回暖**，尤其是低价券密集板块
- 投入时间是低价策略的主要成本——2018年为类比，当时站在2018年中而非年末位置
- [[下修条款]]可以恢复股性，但**无法化解退市风险**——这是当前区别于历史的关键
- 低P/B不利于下修博弈（公司融资困难+股价趋势差），高股息率因转股价调整机制对低平价转债不利

## Evidence / 原文证据摘录

> "按个数考虑，当下市场转债破面比例已经接近30%、破债底比例则达到11%附近：不少、上升得也很快，但放在历史上并不极端。"

> "51.2%的品种可以在1年之内站上115元、69.5%的品种可以在18个月内站上115元——我们的任务无非是绕开那些未能'上岸'的品种。"

> "一个2元的股票，下跌50%后，就有了退市的风险——相比于大单价股，它容错空间很小了。"

> "凡考虑这类策略的投资者，都要做出在更长时间里去等待回报的准备——既然位置低，那投入时间，是最主要的成本。"
