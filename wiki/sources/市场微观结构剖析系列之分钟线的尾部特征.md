# 市场微观结构剖析系列之分钟线的尾部特征

## Abstract / 摘要

方正金工市场微观结构剖析系列首篇。报告提出使用CVaR（Conditional Value at Risk）模型对股票日内分钟线收益率进行尾部风险度量，引入VWAR（成交量加权平均收益率）降低成交稀疏时段的噪声。基于此构建的[[vcvar因子]]正交化后全A IC达0.0701，IC_IR为2.64，多空对冲夏普2.75。因子在中证500和沪深300成分股内仍有效。

## Key Facts / 关键事实

- **来源团队**：[[方正金工]]（邱捷铭、严佳炜），2020.02.04
- **核心问题**：传统Alpha因子挖掘进入瓶颈期，市场微观结构成为Alpha新来源
- **理论基础**：[[低波动异象]]——低波动低风险股票具有更高超额收益
- **方法论**：CVaR模型度量日内分钟收益率尾部风险 → VWAR成交量加权降噪 → VCVaR因子
- **关键发现**：原始CVaR因子正交后无效（Alpha主要来源于风格偏离）；VWAR加权后VCVaR因子正交后有效
- **全A表现**：IC_IR 2.6377，多空对冲夏普 2.7502（2016.01–2019.09）
- **指数成分股**：500内夏普1.85（IC_IR 1.98），300内夏普1.46（IC_IR 1.45）
- **单因子组合**：优化器约束后，500内夏普2.03，300内夏普1.78
- **左右尾一致性**：左侧与右侧VCVaR因子具有近似的风险特征，尾部风险越低越容易产生超额收益

## Methodology / 方法论

### Step 1: CVaR模型
- 给定置信区间α，使用T交易日的分钟收益率序列计算CVaR值
- CVaR = 超过VaR的损失的期望值，比VaR更稳健地估计尾部风险
- 每日计算左侧5%CVaR值，每月末取算术平均得到月频因子

### Step 2: VWAR成交量加权
- 定义VWAR = Σ(Volume_t × Return_t) / Σ(Volume_t)
- 成交稀疏时段被淡化，买卖力量形成的价格信息被强化
- VWAR序列比原始收益率序列具有更强的非正态性（尖峰厚尾更突出）

### Step 3: VCVaR因子
- 对VWAR序列计算CVaR值，得到VCVaR因子
- 正交化处理：剥离市值、行业、换手、反转、波动五个因子
