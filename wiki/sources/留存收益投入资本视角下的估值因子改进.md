# 留存收益投入资本视角下的估值因子改进

## Abstract / 摘要

华安金工量化基本面系列报告第一篇，分析师朱定豪（S0010520060003）、严佳炜（S0010520070001）。本报告将传统账面价值拆分为留存收益（Retained Earnings, REP）和投入资本（Contributed Capital, CCP）两个维度，分别构建REP市值比和CCP市值比因子。REP因子ICIR达2.46（远超传统BP的1.61），且在不同市场环境下与CCP因子表现呈现互补性。基于价量趋势信号的双因子轮动策略，年化超额收益15.51%（相对中证全指），多头超额2.39%（相对BP多头）。

## Key Facts / 关键事实

- 发布机构：[[华安金工]]，分析师朱定豪、严佳炜
- 系列定位：量化基本面系列报告之一
- 核心方法：将账面价值（Book Value）拆分为留存收益（REP = 未分配利润 + 盈余公积）和投入资本（CCP = 股本 + 资本公积）
- REP因子表现：ICIR 2.46（vs BP 1.61），月度胜率66.7%，多空年化13.27%
- CCP因子表现：ICIR 1.09，多空年化7.10%，预测能力弱于REP
- REP与CCP的周期性互补：
  - 牛市中CCP因子表现更优（2014-2015、2019）
  - 熊市中REP因子表现更优（2011、2015下半年、2018）
- 双因子轮动策略：使用价量趋势信号判断市场环境，动态调整REP与CCP权重
  - 年化超额收益15.51%（相对中证全指）
  - 多头超额2.39%（相对BP多头）
- 回测区间：2010.01-2020.06，全A股，月度调仓
- 与[[估值变动因子]]dEP的比较：REP从账面价值结构出发，dEP从估值因子时间变化出发，两者视角不同
