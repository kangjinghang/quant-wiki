# 短期市场的矛与盾

## Abstract / 摘要

招商定量（任瞳、崔浩瀚）在2021年3月A股市场震荡期间发布的短期技术分析评论。报告将趋势指标和资金势能指标比作市场的"矛"（推动价格脱离原有点位），将支撑位和压力位比作市场的"盾"（趋势的阻力），二者相互制约也彼此转化。通过计算指数成分股的筹码分布获利盘占比，结合四种常见支撑位指标（布林带、多空布林带、CDP、ENV）的历史突破统计，判断市场短期走势是否企稳。

## Key Facts / 关键事实

- **核心框架**："矛"（资金势能/获利盘）vs "盾"（支撑位/压力位），二者相互制约且可转化
- **获利盘计算方法**：个股筹码分布按每日换手率在最高价-最低价-均价间三角形分布假设滚动计算，指数获利盘为成分股加权平均
- **2021年3月数据**：创业板指获利盘从73%（2/10）降至24.2%；沪深300从66.9%（2/19）降至41.1%；上证指数从55.1%（2/19）降至45.6%
- **支撑位指标**：布林带（BOLL）、多空布林带（BBIBOLL）、CDP逆势操作、ENV指标
- **历史统计**：2010年以来各指数向下突破支撑位后的平均持续天数、回撤幅度等
- **结论**：获利盘比例已从高位回落至适中水平，场内资金面因素暂时出清，短期大盘走势或已步入企稳
- **分析师**：任瞳、崔浩瀚

## Core Analysis / 核心分析

### 筹码分布与获利盘

筹码分布假设每日换手筹码在当日最高价、最低价和均价之间三角形分布，通过滚动计算各价位筹码存量。获利盘（持仓成本低于当前价的筹码）占比过高意味着获利回吐压力大，占比过低则意味着主力被套后有拉升动力。

### 支撑位指标

- **多空布林带（BBIBOLL）**：BBIBOLL=(MA3+MA6+MA12+MA24)/4，上下轨为M倍标准差
- **布林带（BOLL）**：中轨=N日均线，上下轨=中轨±2倍标准差
- **CDP逆势操作**：CDP=(H+L+C×2)/4，衍生AH/AL/NH/NL四个价位
- **ENV指标**：UPPER=SMA×1.06, LOWER=SMA×0.94

### 历史突破统计

统计2010年以来指数向下穿透各支撑位后的持续天数、回撤幅度等，作为当前点位是否安全的参考。

## Evidence / 原文证据摘录

> "趋势指标像是A股市场上的'矛'，是资金势能的体现；支撑位和压力位仿佛市场上的'盾'，是趋势的阻力，穿透压力位和支撑位需要资金势能，但在突破之后往往会有新一波趋势。"

> "从数据上看，当前由于市场下跌已经持续一段时间，各指数的获利盘比例已经大幅下降。"
