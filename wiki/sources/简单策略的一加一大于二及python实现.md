## 核心内容

本文是[[中金固收]]团队（[[杨冰]]、[[罗凡]]、[[陈健恒]]）关于转债策略组合与优化的实践研究，提供了完整的Python回测框架。

### 策略分仓 / Strategy Allocation

通过按比例分配资金给两个低相关性的基础策略（如50% [[转债策略库|EasyBall]] + 50% 低溢价），在不降低名义仓位的情况下降低组合波动和最大回撤。

- **核心原理**：低相关性策略组合的波动低于单一策略
- **计算优势**：远高于全局遍历的计算效率
- **适用场景**：有严格回撤约束的资金方

### 策略叠加 / Strategy Overlay

将一个策略作为基础，用另一个策略的逻辑进行二次过滤，生成具备新风险收益特征的强化策略。

- **典型例子**：以EasyBall为基础，叠加低溢价率排序过滤
- **风险特征**：高盈亏比但可能牺牲部分绝对收益

### 约束条件下的组合搜索

- 在最大回撤、波动率等约束条件下，搜索最优策略配比
- 大票AAA转债策略虽然收益风险比不佳，但能显著降低组合回撤
- 提高换仓频率对控制最大回撤具有实质性意义

### 拓展至固收+产品

- 以2:8（转债:债券）分仓构建具备特定风格的二级债基产品
- 通过程序框架搜寻符合特定参数标准的产品配置方案

## Key Findings

1. 通过策略分仓组合低相关性策略，是降低转债组合最大回撤的最有效途径之一
2. 大票AAA转债策略虽然收益风险比不佳，但能显著在不降名义仓位的前提下降低组合回撤
3. 提高换仓频率对控制转债策略的最大回撤具有实质性意义
4. 该框架不仅适用于转债，还可拓展至以2:8分仓构建具备特定风格的二级债基产品
