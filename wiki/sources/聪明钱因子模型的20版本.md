# 聪明钱因子模型的20版本

## Abstract / 摘要

开源金工对2016年7月提出的[[聪明钱因子]]模型进行重要改进。核心发现：原始聪明度指标S = |R|/√V（β=0.5）的选股能力远未达到最优，将β参数调至0.1（S = |R|/V^0.1）或使用对数成交量（S = |R|/ln(V)）可大幅提升因子效果。改进后全市场五分组多空信息比率达3.7，显著优于原始模型（IR=1.69）。

## Key Facts / 关键事实

- **来源团队**：[[开源金工]]（魏建榕、高鹏、傅开波），2020.02.09
- **核心贡献**：优化聪明度指标S的构造方式，显著提升聪明钱因子选股能力
- **原始模型问题**：2017年初之后原始聪明钱因子选股能力明显减弱
- **改进方案一**：将S指标中的β参数从0.5降至0.1，信息比率从1.69提升至3.67
- **改进方案二**：对分钟成交量做对数变换（S=|R|/ln(V)），信息比率达3.74
- **截止值验证**：机构投资者交易占比约10%-20%，选取20%作为截止值具有合理性
- **样本空间**：因子对中小市值股票选股能力更稳健（中证1000内IR达3.65-3.81）
- **回测框架**：2013.04–2019.12，全A股，月频调仓，剔除ST和上市未满60日

## Methodology / 方法论

### 原始聪明钱因子

1. 构造聪明度指标 S = |R|/√V（R为分钟涨跌幅，V为分钟成交量）
2. 按S值从大到小排序，取成交量累积占比前20%的分钟视为聪明钱交易
3. 计算聪明钱交易的Smart Money因子

### 改进方案

**参数优化**：将S指标一般化为 S = |R|/(V^β)
- β = 0.7 → 因子几乎无效（IC≈0）
- β = 0.5 → 原始模型（IR=1.69）
- β = 0.1 → **最优区间**（IR=3.67）
- β < 0.1 → IR缓慢下降但仍高于2.5

**对数变换**：S = |R|/ln(V)，效果最佳（IR=3.74）
