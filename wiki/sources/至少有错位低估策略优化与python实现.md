# 至少有"错位"：低估策略优化与Python实现

## Abstract / 摘要

[[中金固收]]团队（杨冰、房铎、陈健恒）在2021年4月发布的报告中，针对转债市场成交低迷、投资者注意力涣散的环境，提出并优化了转债"低估"策略。文章首先对比了[[双排名法|双分位数法]]、[[双排名法]]和隐含波动率法三种简易低估值方法，结论是双排名法（价格+溢价率综合排名）最为稳健。在此基础上，利用KNN算法寻找个券"最近邻"并拟合估值曲线，提出[[分组定价法]]——选取"同类中定价偏低"而非绝对估值最低的品种，有效解决了传统低估策略引入小票或正股趋势差等风格偏向的问题。

## Key Facts / 关键事实

- 在转债市场成交低迷时，相对低估值的做法应有回报，且低估策略长期优于高估策略
- 三种简易低估值方法对比：[[双排名法]]最为稳健，效果最好，是诸多高阶策略的基础
- 传统一味追求"低估值"的策略容易引入小票或正股趋势差等风格偏向，是导致策略阶段性失效的主因
- [[分组定价法]]通过KNN+OLS回归构建，选取"同类中定价偏低"的个券，相比双排名法具有更好的单调性和关键风格中性
- [[转债退市风险]]的剔除是补齐低估策略短板的"特效"方法，有效避免"便宜没好券"的陷阱
- 市场处于磨底期时，应绕开前期抱团品种，结合转债不高的估值，积极利用低估值策略进行布局

## Key Findings / 核心发现

### 简易低估策略对比

1. **双分位数法**：分别对价格和溢价率设定分位数阈值（如价格<30%分位 & 溢价率<30%分位），取交集。问题在于参数选择敏感、出勤率不稳定
2. **[[双排名法]]**：对价格和溢价率分别从小到大排名并加总，选择总排名靠前的品种。在考虑换仓和参数敏感性后最为稳健
3. **隐含波动率法**：利用BS模型反推隐含波动率，选低隐波品种。效果不如价位+溢价率组合

### 分组定价法的创新

- 利用个券关键属性（市值、分析师覆盖度等）通过KNN寻找"最近邻"
- OLS回归拟合平价-溢价率曲线：$\text{溢价率} = \alpha + \beta \times \text{平价}$
- 计算个券实际价格与理论估值的差值（"错位"程度）
- 选取同类中被低估而非绝对估值最低的品种，实现风格中性

### 风格偏向问题

传统低估策略的核心问题是引入了风格偏向：
- **小票偏向**：低价转债往往对应小市值正股
- **趋势偏向**：低溢价率品种往往正股趋势已差
- 分组定价法通过在"同类"（属性相近的个券）内部比较，自然消除了这些偏向
