# 蒙特卡洛方法用于可转债定价

## Abstract / 摘要

[[东吴固收]]李勇在本文中使用蒙特卡洛模拟方法对2020年8月市场上303只处于交易状态的可转债进行定价。核心创新在于引入赎回、回售和[[下修条款|下修]]的不确定性概率参数，使模型更贴近中国市场实际情况。模型对偏离度较大的可转债预测效果较好——价差百分比前10%的可转债一周内平均涨跌幅1.13%，后10%为-2.59%，多空收益3.72%。

## Key Facts / 关键事实

### 中国可转债市场三阶段发展

1. **萌芽期（1993-2000年）**：第一只宝安转债1993年上市，转股失败；1998年市场重启
2. **发展期（2001-2016年）**：2001年证监会颁布发行实施办法，2006年进一步完善监管框架
3. **爆发期（2017年至今）**：2017年定增收紧+转债信用申购改革，2017-2019年分别发行53、92、160只转债；2020年1-8月已发行137只

### 模型七项假设

1. 将股票视为期权标的资产（而非公司价值）
2. 正股股价服从几何布朗运动（GBM）
3. 转股条款作欧式期权处理（除非赎回或到期不提前转股）
4. 忽略利率风险，使用国债到期收益率作为无风险利率
5. 考虑违约风险，使用同等级企业债收益率折现债券部分
6. **赎回概率p=0.75**：历史上131只触发赎回，100只赎回、17只不赎回、14只未公告
7. **回售/下修概率**：q≤0.2回售（20%）、0.2<q<0.7下修（50%）、q≥0.7存续（30%）；下修价格比条款最低价格平均高出5%

### 定价结果

- 每只转债模拟1000条股价路径
- 模型收敛性好：振德转债100次计算均值552.537元（收盘价550.463元），标准差0.559
- **全市场方向一致率仅56%**，因模型误差和新信息影响
- **前10%偏离度转债胜率80%，后10%胜率70%**
- 多空周收益3.72%，超越中证转债指数（-0.11%）
