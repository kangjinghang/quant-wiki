# 行业轮动系列（一）以配置的理念做行业轮动

## Abstract / 摘要

中银量化团队（[[郭策]]）从方法论和底层逻辑角度探讨[[行业轮动]]的核心问题：如何应对单策略的[[策略周期失效|阶段性失效]]。文章提出"单策略阶段性失效是其长期有效的必要条件"，并论证了通过[[多策略配置]]（残差周期对冲）实现行业轮动优于[[多策略轮动]]（择时切换）的观点。

## Key Facts / 关键事实

- **核心命题**：单策略的阶段性失效是其长期有效的必要条件。策略实际收益率可拆解为预期超额收益、基准收益贡献和不确定性残差三部分
- **关键论点**：[[多策略配置]]通过"[[残差周期对冲]]"主动拥抱不同维度的风险敞口，使各单策略残差在周期维度上对冲，降低组合波动率
- **配置约束**：在A股不能做空的情境下，若整体策略组合预期超额收益为R，配置池中至少存在一个单策略的预期超额收益要高于R
- **行业剔除效应**：实证表明每月仅剔除表现最差的5个行业（约1/6）即可显著跑赢沪深300指数及主动股基指数
- **公募基金归因**：自2017年起公募基金超额收益主要来源于选股贡献，而非行业配置

## Key Concepts / 核心概念

- [[多策略配置]] — 主动拥抱不同风险敞口，通过残差对冲降低波动的配置体系
- [[多策略轮动]] — 对单策略阶段性有效/失效进行择时切换的体系
- [[策略周期失效]] — 任何长期有效的单策略必然出现阶段性失效的内在机制
- [[残差周期对冲]] — 利用不同策略残差的周期差异实现组合风险对冲
