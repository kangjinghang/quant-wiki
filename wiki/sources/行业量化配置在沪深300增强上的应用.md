# 行业量化配置在沪深300增强上的应用

## Abstract / 摘要

开源金工团队基于2020年11月发布的[[行业配置的量化解决方案]]中四维行业轮动模型，提出将其行业信号转化为沪深300指数增强策略。策略核心是将行业因子值转化为行业主动权重叠加在基准指数权重上。同时揭示了一个重要现象：通过[[brinson归因分析]]验证，近年来沪深300指数增强基金的行业配置分化度越来越大，行业配置收益与超额收益呈明显正相关。

## Key Facts / 关键事实

- **2020年沪深300增强基金爆发**：总规模创历史新高达480亿元，全体基金超额收益中位数高达13.37%（2017-2020年分别为3.59%/2.67%/3.68%/13.37%）
- **行业配置分化度增大**：Brinson归因分析显示行业配置收益与超额收益明显正相关，2020年最高一只基金行业配置收益达29.8%
- **四维模型增强策略**：基于[[行业动量]]四维模型（交易行为+资金偏好+景气度变化），原始模型多空年化12.4%，月度胜率62.4%
- **增强策略参数β**：行业主动权重 = 行业因子值 / (β × 行业因子值绝对值之和)，β具有风险调节功能
- **β=2策略表现**：2012-2021全区间年化超额5.31%，超额夏普1.97，月度胜率70.64%，每年均获正超额

## Strategy Details / 策略细节

策略构建5步骤：
1. 每月末获得一级行业因子值，进行正态分布转化
2. 计算月末沪深300一级行业权重及成分股权重
3. 行业主动权重 = 行业因子值 / (β × |行业因子值|之和)
4. 调整后行业权重 = 沪深300行业权重 + 主动权重
5. 将行业权重按比例反推到个股权重

参数β的风险调节特征：β增大时超额收益降低但波动率也随之降低（β→∞时近似沪深300指数走势），投资者可根据风险偏好灵活选择。
