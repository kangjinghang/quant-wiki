# 转债因子模型

## Abstract / 摘要

[[中金固收]]（杨冰、房铎、吴若磊、陈健恒）于2020年6月发布的报告，核心回答"转债能否做因子模型"——答案是肯定的。报告将转债价格直接当作普通价格变动处理，转债特性通过定制因子反映，构建了完整的转债多因子框架。模型使用 WLS（Weighted Least Squares，加权最小二乘法）替代 OLS，以转债存量市值作为权重解决异方差问题，并提供了完整的 Python 实现代码。其因子测试方法论与[[可转债定价]]体系紧密关联，也可通过[[转债策略测试框架]]进行复现。

- **团队**：中金公司固定收益研究团队——杨冰、房铎、吴若磊、陈健恒
- **发布时间**：2020年6月7日
- **核心问题**：转债能否做因子模型？答案是可以，转债价格直接当普通价格变动处理，转债特性通过定制因子反映

## Methodology / 方法论

### 转债因子模型框架

报告的核心模型将转债收益率分解为：

$$r_{cb} = \alpha + \sum(X_{ij} \cdot r_{ind\_j}) + \sum(X_{ik} \cdot r_{f\_k}) + \varepsilon$$

其中：
- $r_{ind\_j}$：行业因子收益（哑变量回归）
- $r_{f\_k}$：风格因子收益
- $X_{ij}$、$X_{ik}$：因子暴露
- $\varepsilon$：残差项

模型直接将转债价格当作普通资产价格处理，转债的特殊性通过定制因子（如溢价率、转债规模）来体现，而非修改模型结构本身。

### 转债特殊处理 / CB-Specific Adaptations

针对转债市场特点，报告提出了五项关键适配：

1. **WLS 替代 OLS**：以转债存量市值作权重，解决转债之间市值差异导致的异方差（Heteroscedasticity）问题
2. **转债存量市值 > 正股市值**：用转债存量市值而非正股市值作为规模因子，t 值更大、更有效
3. **rankCV 极值处理**：因子极值处理使用排序中心化（rank Central Value）而非传统 Winsorize（缩尾处理），对转债样本更稳健
4. **行业映射**：行业因子用正股行业映射到转债；2018年前转债数量少，需用更粗的6大类分类
5. **剔除"双高品种"**：剔除换手率过百（即日换手率超过100%）的高价高溢价率异常品种

### WLS 异方差修正 / WLS Heteroscedasticity Correction

转债市场中，不同个券的存量市值差异悬殊（从几亿到数百亿），直接使用 OLS 会导致：
- 大市值券的残差方差被低估
- 小市值券的残差方差被高估
- 回归系数估计效率降低

使用 WLS 以转债存量市值为权重 $w_i$，目标函数变为：

$$\min \sum w_i (r_i - \hat{r}_i)^2$$

其中 $w_i$ 为第 $i$ 只转债的存量市值。这使得大券对因子收益估计的贡献更大，与流动性加权的直觉一致。

### 因子测试结果（2018年后）/ Factor Test Results

报告对2018年后的转债样本进行了系统因子测试：

- **规模因子**：转债规模（存量市值）比正股市值更有效，但属于风险因子而非收益型因子——小券略胜大券，但差异不大
- **转债特质因子**：溢价率 > 债底溢价率 > 价位，其中**溢价率**是最有效的转债特质因子。溢价率与其他因子负相关约 -0.6
- **价值因子**：P/B 有效但较弱，低 P/B 并没有产生超额收益（与直观认知不同）
- **成长因子**：营收 TTM（Trailing Twelve Months）成长可接受

### "easy ball" 策略

报告提出"easy ball"策略：$2 \times \text{价格分位数倒序} + \text{溢价率分位数倒序}$

即选择低价 + 低溢价率的转债组合。该策略在历史回测中持续有效，本质上是对转债"双低"策略的因子化表达。
