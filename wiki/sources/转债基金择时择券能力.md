# 转债基金择时择券能力

## Abstract / 摘要

中金固收（杨冰、吴若磊、陈健恒）使用 CL 模型对转债基金进行[[基金业绩归因|择时/择券能力归因]]。模型将市场收益拆分为上涨和下跌两种状态，分别回归得到 β₁（下跌敏感度）和 β₂（上涨敏感度），α 代表择券能力，β₂−β₁ 代表择时能力。附 Python 实现（sklearn LinearRegression）。

## Key Facts / 关键事实

- **CL 模型**：$R_p - R_f = \alpha + \beta_1 \cdot \min(R_m - R_f, 0) + \beta_2 \cdot \max(R_m - R_f, 0) + \epsilon$
- **α > 0**：择券能力（超额收益）
- **β₂ − β₁ 大**：择时能力（上涨高 beta、下跌低 beta）
- **理想情况**：β₂ 大、β₁ ≈ 0（精准逃顶）
- **Rf 选择**：不拿转债/股票的长债基金收益率
- **基准指数**：转债指数（000832.CSI）、长债基金指数（885008.WI）
- **Python 实现**：`sklearn.linear_model.LinearRegression`，支持 SQL/Wind API 数据源
- **模型局限**：α 与 β 无法完全分离；归因模型非仓位测量；需结合基金规模和仓位综合判断
- **注意**：低估值品种天然有不对称性，可能以择券形式产出择时效果
