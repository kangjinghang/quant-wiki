# 转债基金风格分解

## Abstract / 摘要

[[中金固收]]杨冰等2020年11月发布的转债基金[[基金业绩归因|风格分解]]方法。报告构建四类转债风格指数（大盘转债、双低策略、纯低溢价率、优质股），通过带约束线性回归将基金超额收益分解为风格收益和纯Alpha。核心发现：转债基金整体基本没有独立于风格的纯Alpha——"双低、低溢价、优质股三个策略已基本穷尽转债市场大面积获超额收益的方式"；**20亿元是风格收益的规模试金石**；但部分大型基金仍能保持统计显著的纯择券能力。

## Key Facts / 关键事实

- **样本筛选**：至少2年季报披露 + 过去2年转债平均仓位≥50% + 平均规模≥1亿元
- **收益分解**：$R_t - Q_m = (R_t - R_s) + (R_s - Q_m)$，其中$R_s$为风格收益，$Q_m$为转债指数回报
- **四类风格指数**：
  - **Big**（大盘转债）：占指数、流动性好、价位不高
  - **LP**（双低策略）：低价格+低溢价率（[[转债因子模型]]中"easy ball"策略的变体）
  - **LPrem**（纯低溢价率）：高价、侵略性更强
  - **EQ**（优质股）：万得"基金重仓股指数"替代
- **回归约束**：所有β≥0、总β≤140%（开放基金上限）、股票β≤20%
- **核心发现一**：转债基金整体基本没有独立于风格的纯Alpha（alpha范围窄且对称分布）
- **核心发现二**：20亿元是规模试金石——超过20亿后风格收益获取难度提升
- **核心发现三**：部分基金仍能保持统计显著的纯择券Alpha，且与规模无关，大型基金普遍较强

## Core Content / 核心内容

### 风格指数构建

三类转债风格指数需自行编制（优质股用万得基金重仓股指数替代），使用[[转债策略测试框架]]中的`frameStrategy`函数。四类指数虽然大体同向但分化程度足够做分析。

### 回归方法

带约束线性回归（`scipy.optimize.leastsq`实现）：
- 约束一：所有风格β ≥ 0
- 约束二：总β ≤ 140%（开放基金仓位上限）
- 约束三：股票β ≤ 20%（二级债基合同限制）

输入基金代码和窗口天数n，输出纯择券alpha、风格收益Ri、各风格指数上的β暴露。

### 转债基金Alpha的真相

"纯Alpha"难度高的原因：双低、低溢价、优质股三个策略已基本穷尽转债市场大面积获超额收益的方式（不含主动仓位调整）。风格指数看似简单且换仓频率不高，但能跟住已经是能力。

**篮球比喻**："篮球世界里，总能在最好的位置（篮下、三分线）出手，不仅是选择，而且是种能力。转债基金也一样，总能拥有那样的'风格'，是种能力。"

**规模效应**：仅从风格收益看，20亿元是试金石——明显偏高的风格收益都在此金额之下。基金规模超过20亿元后获取风格红利的难度提升。但最大的几个基金因持续管理能力总体表现也不差。

**纯择券Alpha**：存在部分基金保持统计显著的纯择券收益，且与规模无关——反而规模较大的几个产品普遍较强。
