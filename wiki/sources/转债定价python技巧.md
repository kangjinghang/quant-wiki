# 转债定价Python技巧

## Abstract / 摘要

中金固收团队（杨冰、房铎、姬江帆）认为转债理论定价"说没用也有点用"——实战中价格是交易出来的，但模型有助于理解产品、衡量估值（隐含波动率是纵向最优指标）和情景分析。文章实现了 BS、二叉树、Monte-Carlo 三种[[可转债定价|定价模型]]并附 Python 代码，讨论各模型在 A 股转债的适用性。与[[转债策略测试框架]]构成定价→回测的完整工具链。

## Key Facts / 关键事实

- **BS 模型**：转债 = 债底 + 欧式看涨期权，8 行核心代码，适合实时监控和 Delta 计算
- **BS 关键细节**：r 用同等级信用债收益率（非无风险利率），执行价 = 转股价 × 到期赎回价 / 100
- **二叉树模型**：A 股提前转股罕见（基本只在赎回触发后），实战价值低；改造后可做"穷人版 MC"
- **Monte-Carlo**：可处理赎回压制和回售保护，计算慢但适合情景分析
- **MC 简化**：跳过最小二乘法步骤（A 股转债不触发赎回则不转股）
- **赎回/回售经验阈值**：平价 ≥150（熊/震荡市 140）触发赎回，≤50 触发回售
- **Python 技巧**：私有函数加 `_` 前缀、用 `enumerate` 替代 `range`、numpy `cumprod` 替代循环
