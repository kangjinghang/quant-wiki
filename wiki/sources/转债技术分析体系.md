# 转债技术分析体系

## Abstract / 摘要

中金固收转债研究团队（杨冰S0080515120002、房铎S0080519110001、吴若磊S0080119030020、陈健恒S0080511030011）2020年8月报告，系统阐述将经典技术分析方法应用于[[可转债定价|可转债]]分析。报告融合利弗莫尔（Livermore）趋势理论与缠论两大体系，构建了适合转债特点的技术分析框架：关键点突破判断趋势、中枢识别震荡区间、三类买卖点定义进出场时机、背驰确认趋势衰竭。

## Key Facts / 关键事实

- 发布机构：[[中金固收]]，分析师杨冰、房铎、吴若磊、陈健恒
- 核心方法：融合利弗莫尔趋势理论与缠论的转债技术分析框架
- 关键点突破（Livermore）：当价格突破前期关键高点/低点时确认趋势方向
- 中枢（缠论）：至少三段次级别走势重叠区域，代表震荡区间
- 三类买卖点（缠论）：
  - 第一买点：下跌趋势最后一个中枢下方，背驰确认
  - 第二买点：第一买点后回调不破前低
  - 第三买点：突破中枢上沿后回调不进入中枢
- 背驰（Divergence）：通过MACD面积比较确认趋势衰竭
- 转债适用阈值：
  - 价格<105元：关键点阈值3%
  - 价格<120元：关键点阈值5%
  - 价格>120元：关键点阈值7%
- Easy Ball策略兼容性：技术分析体系与[[转债因子模型]]中的Easy Ball策略不矛盾
- 回测验证：三类买点在转债历史数据中均有较好的风险收益比
