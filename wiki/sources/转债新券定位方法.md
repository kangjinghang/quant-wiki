# 转债新券定位方法

## Abstract / 摘要

[[中金固收]]团队杨冰、房铎、吴若磊、陈健恒在2019年11月提出了一套[[可转债定价|转债新券]]自动化定价方法。该方法通过多维度匹配可比老券（K近邻法）并进行最小二乘回归，预测新券上市价位。更重要的是，报告将新券实际定位与模型预测值的差异（"边际变化"）作为判断市场承接力和情绪状态的工具，并给出了"供给冲击"的量化阈值。

## Key Facts / 关键事实

- **定价方法**：K近邻法（KNN）+ OLS回归，基于4个维度匹配可比品种
- **匹配维度**：发行规模（对数化）、平价水平、基金重仓数目、正股近30日涨幅
- **K值设定**：最少6个，不超过样本10%，最多取样本一半
- **定价差异的含义**：新券实际定位 vs 模型预测的差异反映市场真实承接力
- **供给冲击阈值**：5支平均差价达3.5元以上视为供给冲击开始，4元附近为极限水平
- **2019.11时点判断**：首日平均差价约2元（历史平均水平），供给冲击尚未形成

## Methodology / 方法论

### 定价流程

1. **取新券数据**：发行规模、平价水平、上市日期
2. **取正股数据**：基金重仓数目（代表机构接受度）、正股近30日涨幅（代表趋势）
3. **数据预处理**：规模取对数（因个券间差异大），其余做中心化
4. **K近邻匹配**：按欧氏距离排序，取最近的K个老券作为可比品种
5. **OLS回归定价**：用近邻的平价和溢价率回归，得到溢价率 = $\alpha + \beta \times$ 平价，代入新券平价得出预测价位

### 市场情绪判断

通过比较新券实际上市价格与模型预测值，判断市场状态：
- **差价小（~2元）**：正常水平，供给冲击未形成
- **差价大（3.5元+）**：供给冲击开始显现
- **新券高于老券**：市场情绪过热，不应作为买点
- **新券低于老券**：市场均值回复中，积极信号

## Key Findings / 关键发现

- 新券比老券更能检验市场真正的承接力——老券可通过"抱团"暂时维持价格，而新券打新抛压必须用资金承接
- 转债正确的买点从来不在情绪高位，新券定位差可帮助判断情绪位置
- 个券层面已有品种上市即成"easy ball"，投资者应"当买则买"，无需等待整体供给冲击
