# 转债策略测试框架

## Abstract / 摘要

[[中金固收]]（[[杨冰]]、[[房铎]]）提供完整的 Python [[可转债|转债]]策略[[回测]]框架。框架包括初始化（时间段、转债范围）、每日净值计算、调仓日择券加权，以及可扩展的接口设计。投资者可自定义择券策略、加权方法和调仓频率，用于策略验证或自定义指数构建。

## Key Facts / 关键事实

- **框架入口**：`frameStrategy(obj, start, defineMethod, selMethod, weightMethod, roundMethod)`
- **核心流程**：初始化 → 循环（每日计算净值 + 调仓日择券加权）→ 返回净值+持仓日志
- **择券接口**：`selMethod` 可传入自定义函数（如低价策略、低溢价率策略）
- **加权方法**：等权（默认）、按发行额加权（"假市值"，类似中证转债指数）、市值加权
- **调仓频率**：每日或每隔 N 个交易日（默认 21 日）
- **流动性过滤**：前 5 个交易日最少 10 万成交额 + 存量不低于 3000 万
- **Python 技巧**：函数作为参数传入、`enumerate` 迭代、`pandas` 逻辑过滤、`[::n]` 间隔取样
- **数据结构**：`obj.DB` 为 pandas DataFrame，index 为日期，columns 为转债代码
- **姊妹篇**：与 [[转债定价python技巧]] 构成定价→回测的完整工具链
