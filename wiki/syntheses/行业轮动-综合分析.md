# 行业轮动

## Overview / 概述

[[行业轮动]]是量化投资中获取超额收益的核心手段之一。然而，A股市场行业分化剧烈、风格切换频繁，单一维度的逻辑（如纯基本面或纯资金面）往往在特定宏观环境下失效。本综合分析整合了来自开源金工、广发金工、中银量化、中金固收及招商定量等不同卖方与研究机构的15篇深度研报，旨在构建一个多维度的行业轮动知识图谱。

通过将这些来源放在一起审视，我们可以打破单一研报的视角局限，全景式地审视行业轮动在**基本面（盈利预期与景气度）**、**资金面（北上资金与外资动态）**、**技术面（动量与情绪极值）**以及**风格与宏观（PB-ROE与经济周期）**等不同维度上的驱动力。这不仅有助于提炼出具有普适性的Alpha因子，更能揭示不同方法论之间的内在冲突与边界条件，为构建稳健的[[多策略配置]]体系提供理论依据。

## Key Findings / 核心发现

基于对多份来源报告的提炼，行业轮动的核心发现可归纳为以下几个维度：

1. **基本面景气度与预期的多维刻画**
   - **远期预期更有效**：在分析师一致预期中，预期年限越远，因子有效性越强（F3 > F2 > F1 > F0），且ROE相关因子优于净利润因子 [[基于盈利预期的行业轮动策略]]。
   - **景气度需前瞻与同步结合**：广发金工提出“同步指标+前瞻驱动指标”两步法，通过宏观环境、产业链供需等领先指标预测行业综合景气度，避免了纯时间序列回归的过拟合 [[景气视角下的行业轮动策略]]。
   - **微观基本面聚合**：上游周期板块可通过中高频产业跟踪数据（如价格、产量、库存）结合逻辑回归进行月频基本面择时 [[上游周期板块的择时模型]]。

2. **资金面的“存量与增量”双轮驱动**
   - **北上资金拆解**：北上资金行业配置的超额收益来源于存量信息（持仓规模/历史偏好）与增量信息（净流入金额/边际变化）的双轮驱动。剥离规模偏差后的净流入残差因子提供显著增量信息，合成后多空夏普达2.4 [[开源量化评论北上资金行业配置的双轮驱动力]]。
   - **资金属性的时序演变**：外资的“交易”与“配置”属性在不同时期发生偏移。2019年后，4周净流入规模对多数行业的绝对收益指导意义最大，但不同行业（如消费 vs TMT）的最优观察窗口存在显著差异 [[基于外资资金特征的行业优选策略]]。

3. **技术面、情绪与动量修复**
   - **情绪极值比例（ER）**：行业内个股因子值创近一年新高/低的比例，比传统行业因子均值更能准确刻画投资者情绪浓烈程度，2008-2015年间多空胜率达75.58% [[基于个股极值比例的行业轮动策略]]。
   - **动量修复与次优策略**：在极端排名动量导致反转纠偏后，市场进入收敛与修复期。“次高组（排名7-12名）”是经得住考验的进攻选择，而最高排名组反而易受反转冲击 [[基于动量修复的板块及个券选择]]。

4. **风格、宏观与行业轮动的深度绑定**
   - **行业即风格**：多期Brinson归因证明，行业的风格贡献是市场风格（成长 vs 价值）的核心驱动力，2019年后这一现象尤为显著 [[A股风格轮动规律认知与策略实践]]。
   - **宏观周期的消费映射**：经济周期（复苏、过热、滞涨、衰退）直接决定大消费板块中可选消费与必选消费的相对强弱。净利润同比景气度可作为消费板块轮动的主信号 [[大消费板块的轮动与选股]]。

5. **另类因子的跨界应用**
   - **ESG因子**：经过行业中性化和市值加权处理的股票ESG得分，在合成行业得分后具有显著的轮动预测能力。二级行业ESG多头轮动策略在2017-2021年年度胜率达100% [[ESG可以用于行业轮动吗]]。

## Tensions and Contradictions / 分歧与矛盾

尽管各来源均致力于构建有效的行业轮动策略，但在方法论和实证结论上存在明显的分歧：

1. **资金面 vs 基本面的时效性冲突**
   - [[基于外资资金特征的行业优选策略]] 指出，疫情后部分行业（如石油石化、商贸零售、计算机）的北上资金属性从“配置主导”向“交易主导”偏移，短期（1周/4周）动量特征增强。
   - 然而，[[开源量化评论北上资金行业配置的双轮驱动力]] 仍强调“历史偏好（存量）”是稳定的压舱石。这说明在不同市场阶段，资金的长线定价权与短线情绪驱动力在不断博弈。

2. **动量（追高）与反转（避险）的矛盾**
   - [[基于动量修复的板块及个券选择]] 明确指出“最高排名组容易遭受反转效应冲击”，推荐买入“次高组”作为矛。
   - 但在 [[基于个股极值比例的行业轮动策略]] 中，核心买入信号恰恰是“行业内个股大量创近一年新高（ER极高）”，即追逐情绪最浓烈的极端动量。这反映了“板块截面动量”与“个股情绪极值”在微观结构上的解释力冲突。

3. **基本面策略的估值盲区**
   - [[基于盈利预期的行业轮动策略]] 坦承，纯盈利预期策略在2021年2-3月核心资产抱团瓦解时失效，原因是“未考量估值对行业收益率的影响”。
   - 这与 [[A股风格轮动规律认知与策略实践]] 提出的“PB-ROE动态划分”形成矛盾：脱离了估值（PB残差）单纯看景气度或ROE，容易买入成长性被透支的“价值陷阱”或高估泡沫。

4. **多策略：配置还是轮动？**
   - [[基于个股极值比例的行业轮动策略]] 实证发现“多策略配置优于多策略轮动”。
   - 但多数报告（如广发金工、中银量化）仍在致力于寻找单一维度的“最优轮动开关”。这暗示了顶层资金在“追求绝对轮动Alpha”与“追求策略高Sharpe”之间的取舍矛盾。

## Emerging Thesis / 初步结论

基于现有证据，关于A股行业轮动可得出以下初步结论（部分仍具试探性）：

1. **行业轮动是风格轮动的微观体现**：在存量资金博弈的市场中，行业轮动的本质是资金在不同PB-ROE特征板块间的迁移。因此，脱离宏观流动性（Shibor等）和估值约束的纯景气度追踪，其有效性呈衰减趋势。
2. **“资金面+情绪面”主导短期，基本面主导中长期**：北上资金的净流入残差和个股极值比例（ER）对月频或周频的收益预测具有增量意义；而分析师远期预期（F3）和产业链前瞻指标则决定了季度级别的行业主线。
3. **次优属性的普遍性**：由于A股反转效应强烈，绝对排名靠前的行业/个股往往面临拥挤交易。无论是动量修复中的“次高组”，还是外资策略中剔除胜率极低行业后的“改良组合”，均表明**规避极端拥挤、寻找边际改善（次优）**是更具稳健性的轮动哲学。

## Open Questions / 未解问题

1. **资金定价权的长期衰减**：随着A股机构化程度提升和北上资金流入趋缓，基于北上资金“历史偏好”和“净流入”的因子在2022年以后是否已经发生结构性失效？
2. **基本面因子的非线性特征**：盈利预期（F1-F3）在牛市和熊市中的预测效力是否存在非对称性？分析师一致预期在市场底部是否具有显著的反向指示意义（即拥挤度极值）？
3. **高频产业数据的降维**：上游周期板块依赖中高频产业跟踪数据，但对于下游（如消费、TMT）或中游制造业，缺乏高频前瞻指标，如何利用替代数据构建等效的景气预测模型？
4. **ESG因子的内在驱动力**：ESG行业轮动策略的超额收益，究竟来源于企业基本面的长期稳健，还是在特定市场环境下对“机构抱团/避险情绪”的被动刻画？
