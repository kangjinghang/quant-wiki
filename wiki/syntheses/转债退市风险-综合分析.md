# 转债退市风险

## Overview / 概述

本综合分析旨在解决可转债市场在“低估值”策略演进与极端信用风险爆发交织下的定价与风控难题。随着转债市场扩容以及退市新规的落地，传统量化策略面临着前所未有的挑战。

将上述来源放在一起看，是因为它们完整勾勒了转债策略从“无脑双低”向“精细化、风控前置”演进的必然性：从 [[中金固收]] 提出的经典 [[双排名法]] 与 [[分组定价法]] 的定价体系优化，到2023年“低”类策略因 [[规模效应]] 和退市风险导致的集体失效，再到利用机器学习进行信用风险定量规避。结合转债十二年历史周期与基础交易规则，我们可以清晰地看到，**转债退市风险**已经从偶发的“黑天鹅”转变为系统性策略必须剔除的结构性风险因子。

## Key Findings / 核心发现

1. **退市新规重塑了转债生命周期**：根据沪深交易所规则，退市新规下转债终止上市与正股完全同步，直接取消了暂停上市和恢复上市环节。这意味着正股的退市风险即刻传导至转债，形成了转债退市的硬性制度基础 [[可转债市场规则-可转债框架系列之基础篇-上]]。
2. **传统低估策略极易沦为“退市风险接盘侠”**：一味追求绝对低估值（如简易低价、低溢价策略）天然带有小票偏向和正股趋势差的风格暴露。在退市新规下，这些“便宜”的品种往往正是面临退市和信用危机的垃圾债（如搜特、正邦、鸿达） [[至少有错位低估策略优化与python实现]]。
3. **“低”类策略的阶段性失效归因**：2023年初以来，低价与双低策略大幅跑输基准，核心原因除了组合在规模因子上的错误正向暴露（大盘转债缺乏弹性）外，更致命的是包含了大量存在退市和信用风险的品种，导致高波动因子“极盛而衰” [[谈近期-低-类策略的迷失]]。
4. **机器学习成为规避退市风险的“特效药”**：为了在不牺牲收益的前提下精准排雷，研究者提出使用随机森林模型，结合9个核心财务指标对转债隐含违约率进行定量建模，从而圈定并剔除极少数“高风险”券 [[谈近期-低-类策略的迷失]]。
5. **历史轮回中的信用冲击常态化**：复盘2013-2024年市场，信用风险担忧（如2018年辉丰转债事件）与流动性危机不断重演。2024年的信用冲击再次证明，缺乏退市风险防御的策略在极端行情下面临毁灭性打击，但也为具备纯债替代价值的错杀券提供了最佳布局机会 [[转债十二年市场记录-这一次-都早有先例]]。

## Tensions and Contradictions / 分歧与矛盾

1. **“便宜没好券” vs. “极度便宜孕育大机会”**：
   - 在策略构建层面，[[至少有错位低估策略优化与python实现]] 与 [[谈近期-低-类策略的迷失]] 均强调必须强力剔除低价垃圾券，认为传统低价策略带有致命的风格偏向和退市风险。
   - 然而，[[转债十二年市场记录-这一次-都早有先例]] 指出，在流动性危机或信用冲击造成的极端下跌中，系统性的错杀往往会孕育最佳的入场点（如早期的YTM策略）。这里的矛盾在于：**个券的退市风险**与**市场整体的信用错杀**在价格表现上极具相似性，如何区分“价值陷阱”与“黄金坑”是策略回测中的最大难点。
2. **规模因子暴露的方向性争议**：
   - [[谈近期-低-类策略的迷失]] 明确指出，近期低价/双低策略跑输基准是因为在规模因子上存在**正向暴露**（即过多配置了缺乏弹性、流动性差的大盘转债）。
   - 但 [[至少有错位低估策略优化与python实现]] 在讨论传统低估策略的缺陷时，指出其容易引入**小票偏向**（小市值正股更容易出现低价、低溢价）。这表明，在不同的历史阶段和市场扩容节奏下，低估值策略捕获的规模因子属性会发生动态反转。

## Emerging Thesis / 初步结论

基于现有证据，我们提出以下初步结论：

1. **（确立的结论）转债退市风险是现代转债策略的“一票否决”项**。在注册制与退市新规下，缺乏信用风控的低估策略等同于裸奔。任何长期有效的策略（如 [[分组定价法]] 或 [[easyball策略|Easyball]]），其底层架构必须包含基于财务指标（如机器学习模型）或市场微观结构的退市风险过滤层。
2. **（试探性的结论）相对定价法是解决退市风险暴露的优雅路径**。相比于绝对的双低阈值，通过 KNN+OLS 回归寻找“同类中定价偏低”的个券，能够在保持关键风格中性的同时，自然过滤掉那些因为基本面恶化（面临退市）而导致绝对价格长期低迷的品种。
3. **（试探性的结论）极端退市风险爆发时的流动性危机，是检验策略负债端稳定性的试金石**。当转债退市风险引发系统性暴跌时，数学模型往往会失效，此时 [[纯债价值]] 和到期收益率（YTM）才是定价的绝对锚。
