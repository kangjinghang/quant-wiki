# 风险平价：综合分析

## Overview / 概述

[[风险平价]]（Risk Parity）是一种以风险贡献均等化为目标的资产配置方法，其核心思想是让组合中每类资产对总风险的边际贡献相等，从而避免传统市值加权组合中股票因高波动而主导整体风险的结构性缺陷。本文综合五篇来源，从模型融合、择时应用、因子框架延伸、战略定位和风格配置五个维度，梳理风险平价在中国量化投资实践中的演化路径。

五篇来源覆盖了风险平价的不同应用层次：方正金工（2019）将风险平价与 [[black-litterman模型]] 融合构建 RPBL 策略；开源金工（2020）将风险平价嵌入 [[股债轮动]] 的风险预算规则；方正金工（2020）进一步将风险平价从资产配置移植到 [[因子动量]] 权重优化；国君配置从宏观视角将风险平价定位为资产配置研究二次成长期的基石模型之一；而"5-5波动率分析框架"报告则在 [[风格轮动]] 领域将风险平价模型主动化，引入分风格波动率调整系数。

## Key Findings / 核心发现

### 1. 风险平价作为稳健先验显著优于等权和市值加权

多份实证一致表明，风险平价作为先验权重在风险调整后收益方面表现优异。方正金工（2019）回测显示，股债风险平价策略年化 5.03%、波动 2.80%、夏普 1.79，远优于股债等权的夏普 0.87。四资产风险平价策略夏普达 1.70。方正金工（2020）在因子权重领域同样发现，[[风险平价]] 先验相比等权先验年化收益提升约 0.5%，收益分布更均衡。

### 2. 风险平价与 Black-Litterman 模型的融合是当前最主流的增强路径

两篇方正金工报告均采用"风险平价先验 + [[black-litterman模型|Black-Litterman]] 观观点融合"的框架。RPBL 策略用风险平价权重替代传统市值权重作为先验，解决了 A 股市值波动大、新股频发导致市值权重不稳定的问题。叠加动量观点后，四资产 RPBL 年化达 14.67%，最大回撤仅 -6.82%。在因子权重领域，同一框架将因子 IC 类比为资产收益，将因子 IC 协方差矩阵类比为资产风险，使六因子组合夏普从 1.96 提升至 2.28。

### 3. 风险平价在择时框架中作为"防御基底"使用

开源金工的 [[股债轮动]] 模型将风险平价作为"看空股票"情景下的默认配置：当技术信号 S = -1 或宏观信号不看多时，采用 1:1 的风险平价配置（股债风险权重均等）。仅在信号看多时才切换到激进的风险预算（10:1 或 100:1）。这一设计充分利用了风险平价低波动、低回撤的特性，使其在择时模型中充当"安全垫"角色。

### 4. 风险平价的被动特性在风格配置中需要主动化改造

"5-5波动率分析框架"报告指出，[[风险平价|RP]] 模型因算法特性，统一上调波动率后权重保持不变——这意味着单纯的风险平价无法响应市场环境变化。解决方案是引入分风格的波动率调整系数：基于经济周期、地产周期、交易拥挤度、估值压力、盈利增速预期五个维度对风格稳定性评分，据此差异化调整各风格的波动率预期。调整后 RP 模型建议金融和稳定风格配置比例提高到 22% 以上。

### 5. 风险平价在资产配置研究演进中被定位为"理论与现实碰壁期"的关键模型

国君配置借用 Gartner 技术成熟度曲线，将资产配置研究划分为四个阶段：懵懂阶段（60/40 组合）→ 理论快速发展阶段（[[均值方差模型]]）→ 理论与现实碰壁阶段（[[black-litterman模型]] / [[风险平价]]）→ 二次成长期（宏观预测与因子挖掘）。风险平价被视为从"理想化理论"向"现实可行方案"过渡的关键节点。

## Tensions and Contradictions / 分歧与矛盾

### 矛盾一：风险平价是"终点"还是"起点"？

方正金工的 RPBL 框架将风险平价视为"先验"——一个需要被主观观点修正的起点，核心论点是"风险平价策略虽然能够有效控制策略的波动，但相应的收益率却比较低"。而开源金工的股债轮动模型将风险平价作为"防御模式"的完整配置方案，不做进一步修正。两者对风险平价的角色定位存在根本分歧：前者认为风险平价不足够、需要增强；后者认为风险平价在某些情景下已经是最优选择。

### 矛盾二：协方差矩阵估计窗口差异显著

方正金工使用 18 个月滚动窗口估计协方差矩阵（月频调仓），而开源金工使用 60 个交易日（约 3 个月）滚动窗口。两者窗口长度相差约 6 倍，反映了对"历史信息有效性"的不同判断：前者认为需要较长历史才能稳定估计风险，后者倾向于快速响应风险结构变化。这一参数选择直接影响风险平价权重的稳定性和时效性。

### 矛盾三：被动与主动的张力

"5-5波动率分析框架"报告揭示了风险平价的内在矛盾：作为一个被动规则，风险平价在波动率环境系统性变化时（如 2021 年 A 股波动率见底后中枢抬升 13.3%）无法自适应调整。但风险平价的支持者恰恰认为"不主动调整"是其优势——规避了择时错误的风险。国君配置提出的"弱者思维"（承认预测能力有限，规避无效风险）本质上支持被动方法，但其四大战略方向（通胀类资产、新型低相关性资产等）又需要强烈的主动判断。

### 矛盾四：回测表现的可信度边界

各来源的回测区间高度重叠（2006-2020 年前后），且均报告了优异的风险调整后收益。但需注意：这一时期包含了中国债券市场的长期牛市和 A 股的数轮牛熊周期，债券在风险平价组合中提供了稳定的正贡献。如果进入利率上行周期（如 2022-2023 年），债券端的正贡献可能逆转，风险平价的低回撤特性可能被打破。各来源均未对这一尾部风险进行充分讨论。

### 分歧五：风险平价在因子领域的类比是否成立

方正金工（2020）将风险平价从资产配置移植到因子权重优化，核心类比是"因子 IC = 资产收益，因子 IC 协方差 = 资产风险"。但这一类比的有效性存疑：资产收益的协方差矩阵具有经济含义（如股票和债券的负相关），而因子 IC 的协方差结构是否具有类似的稳定性？报告虽展示了正面的实证结果，但缺乏对类比前提的理论论证。

## Emerging Thesis / 初步结论

综合五篇来源，可以提炼出以下初步结论：

1. **风险平价已从独立的配置策略演化为量化投研体系中的基础设施**。在资产配置层面，它作为先验权重嵌入 [[black-litterman模型|Black-Litterman]] 框架；在择时框架中，它作为防御性基底配置；在因子权重优化中，它作为因子贡献均衡化的先验。这种"基础设施化"趋势表明风险平价的价值不在于独立使用，而在于为后续的主动增强提供稳健的基准。

2. **风险平价在中国市场的核心挑战是"收益不足"与"被动惰性"的双重困境**。方正金工通过 B-L 融合解决收益不足问题，5-5 框架通过分风格波动率调整解决被动惰性问题，但两种增强路径的叠加效果尚无实证验证。

3. **风险平价的未来演化方向可能是与宏观因子的深度整合**。国君配置提出的"二次成长期"方向——宏观预测与因子挖掘——暗示风险平价需要从单纯的风险统计量估计进化为对宏观风险因子的均衡配置。这一方向与 Bridgewater 的 [[全天候策略|All Weather]] 理念一脉相承，但在中国市场的实证实现仍处于早期阶段。

4. **参数选择的差异（协方差窗口、跟踪误差约束等）可能导致同一理论框架下的策略表现差异巨大**，这一敏感性尚未得到充分重视。

2. **开源金工**（魏建榕等，2020.04）—"股债轮动模型 1.0"：从技术视角与宏观视角构建股债轮动框架，将风险平价作为看空股票时的默认配置，综合方案年化 8.14%、最大回撤 3.07%。
3. **方正金工**（严佳炜，2020.04）—"主观观点如何融入量化因子模型"：将 B-L 模型从资产配置移植到因子权重优化，以风险平价确定先验权重，融合因子动量和估值观点，夏普从 1.96 提升至 2.28。
4. **国君配置**（时间不详）—"资产配置研究进入二次成长期"：将风险平价定位为资产配置研究"理论与现实碰壁期"的关键模型，提出四大战略方向（通胀类资产、新型低相关性资产、老龄化主题、ESG）。
5. **来源不详**（约 2022）—"5-5 波动率分析框架下的风格配置"：提出 5 维度稳定性评分体系，对风险平价模型进行主动化改造，分风格差异化调整波动率预期。

## Open Questions / 未解问题

1. **尾部风险**：风险平价在利率上行周期（如 2022-2023 年全球加息）中的表现如何？债券和股票同时下跌时，风险平价的低回撤特性是否仍然成立？所有来源的回测区间均未覆盖这一情景。
2. **杠杆依赖**：纯风险平价策略要获得与股票相当的收益率，通常需要加杠杆。各来源中低波动版本（如 RPBL 1%）年化仅 5-6%，高收益版本（如 RPBL 无约束）依赖激进的观点偏离，杠杆使用情况未明确披露。
3. **协方差估计稳健性**：18 个月 vs 60 个交易日的窗口选择差异巨大，是否存在最优窗口？在线性衰减或指数加权等替代方案下的表现如何？
4. **因子类比的有效性**：将风险平价从资产配置移植到因子权重优化的理论前提是否充分成立？因子 IC 协方差矩阵的时变特性与资产协方差矩阵是否存在本质差异？
5. **交易成本与容量**：各来源均未讨论交易成本、滑点对月频调仓策略净值的影响，以及策略的资金容量限制。
6. **Point-in-Time 问题**：开源金工使用社融和 PPI 等宏观数据，这些数据存在发布滞后，回测中是否严格使用了 Point-in-Time 数据？
7. **跨市场适用性**：风险平价在中国市场的优异表现是否得益于中国债券市场在此期间的特殊表现？在美股、日股等市场是否有类似的增强效果？

## Notes / 笔记

- 五篇来源中有三篇来自方正金工团队，存在团队视角的系统性偏差。国君配置的宏观视角和开源金工的技术视角提供了部分补充，但整体来看来源多样性不足。
- 各来源的回测区间高度重叠（2006-2020 年），缺乏样本外验证。RPBL 策略在 2019 年后的表现（特别是 2020 年疫情冲击、2022 年股债双杀）是评估策略稳健性的关键。
- 国君配置报告未提供具体的量化回测数据，以定性论述为主，其四大战略方向的实证支撑有待检验。
- "5-5波动率分析框架"报告的发布时间和作者信息缺失，其波动率调整系数的具体构建方法需要回溯原始报告确认。
- 风险平价与 [[全天候策略|All Weather]] 的关系是理解风险平价演进的重要线索，但五篇来源中均未深入讨论 Bridgewater 的原创实现及其与中国实践的异同。
